## 1 要检验的命题

第 3 轮（m20537）在 μ = 0.55 的定容双轴剪切上测得 φ_cv = 14.31°，
比 Rowe(1962) D=0 极限 arctan(0.55) = 28.81° 低 50.3 %。
第 4/5/6 轮把候选原因逐一排除到只剩两条：

* **R4/R6**：滚动摩阻旋钮在本内核（无转动自由度）里等价于附加滑动摩擦（加和性），
  不可能是缺口补丁；
* **R7**：接触切向律是速率正则化库仑 `F_t = -μ F_n tanh(v_t/v_reg)`，`v_reg` 坐在本构里；
  但 R7 的宏观五臂扫描 **NOT RUN**（递交模板事故）。

**从未被检验的第三条、也是最基本的一条**：φ_cv 到底是不是由**颗粒间摩擦系数 μ** 控制？
若库仑/Rowe 理论成立，零剪胀极限下应有 φ_cv → arctan(μ)。
若 φ_cv 对 μ 不敏感，则说明本算例测到的「摩擦角」不是材料摩擦的宏观表现，
而是无转动运动学（rotationless disc）与数值正则化共同决定的**模型常数**——
那么本锚点的 ref 选择（Rowe 28.81° / Bolton 33° / Bolton 平面应变 38°）在该模型类里**不可达**，
算例池该条目的 ref 必须重写。

## 3 判据（阈值先于运行固定）

对每一臂先用第 3 轮的四闸门（`tensordem.biaxial_critical_state`：
`isochoric` / `deviator_stationary` / `window_consistency` / `boundary_closure`）判定临界状态是否成立；
**闸门不通过的臂，φ_cv 记为 WITHHELD，不参与 H1–H3 的判定**。

* **H1（库仑控制，方向性）**：φ_cv 随 μ 单调不减，且阶梯两端差
  φ_cv(1.50) − φ_cv(0.10) ≥ **10°**。→ 若成立，μ 是主控参数，缺口可归为运动学/形状。
* **H2（μ 不敏感 = 引擎缺陷判据）**：五臂 φ_cv 极差 (max − min) < **2.0°**。
  → 若成立，说明测得的宏观摩擦角不由材料摩擦控制，锚点在当前模型类下无物理意义。
* **H3（模型类上界）**：φ_cv(μ = 1.50) < **28.81°**（= arctan 0.55，Rowe D=0 极限）。
  → 若成立，则**任何** μ 的无转动二维圆盘组件都达不到锚点 ref，锚点 ref/几何必须重写。
* **H4（能量互检，独立于应力口径）**：定容稳态剪切下
  `q · ε̇_a · V`（宏观输入功率）对 `P_fric + P_damp`（接触层耗散功率）的偏差
  |residual| ≤ **15 %**（取 ε_a ≥ 0.40 尾窗均值）。
  → 若成立，说明测得的 q 与接触层耗散自洽，14° 不是应力归一化的记账错误；
  → 若不成立，优先怀疑应力/体积归一化或墙体功率漏项，本锚点结论整体降级。

## 4 判定的读法（避免事后挑窗）

* 不新增选窗自由度：临界点一律取**最后 25 %** 应变记录（ε_a ∈ [0.45, 0.60]），
  另报最后 10 % 作敏感性；
* φ 的角定义固定为 `sin φ = (σ_v − σ_h)/(σ_v + σ_h)`（平面应变，c = 0），
  与第 2/3 轮一致，不因结果好坏更换口径；
* 主应力取**墙反力**口径（与第 3 轮同）；Love-Weber 内应力口径只作旁证。

## 5 已知局限（写进文档，不许事后淡化）

1. 二维圆盘 + 无转动自由度：与三维砂（Bolton 1986 的 33°/38°）本就不是同一模型类；
   本单不下「DEM 引擎算错」的结论，只判「该模型类能否达到该 ref」。
2. μ = 1.50 是数值外推臂（真实冰/砂 μ < 1），只用于探测饱和上界。
3. 单种子：每臂一个 seed（20261031），不做系综；因此 ±σ 只反映窗内波动，不是实现间散度。
4. 若某臂被 compute gate 限时截断，则该臂记 NOT RUN / WITHHELD，不补猜。
