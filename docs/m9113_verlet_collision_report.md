# M9113: Velocity-Verlet + Event-Driven Collision Energy Convergence

## 论文级进展报告

### ① 案例介绍

**物理背景**：刚性球体对心碰撞的能量账本收敛性研究。DEM（离散元方法）中，碰撞能量守恒是验证数值积分器精度的核心判据。本节点旨在为 TensorDEM 提供可选的二阶（辛）碰撞积分口径，并证明其把能量账本的积分误差阶数从 O(dt) 提升到 O(dt²)。

**几何与参数**：
- 双球对心碰撞，半径 R = 0.05 m，密度 ρ = 900 kg/m³
- 质量 m = 0.471 kg，有效质量 m_eff = 0.236 kg
- 接触刚度 k_n = 5×10⁴ N/m（线性接触律）
- 恢复系数 e_target = 0.7
- 初始速度 v₀ = 0.5 m/s（每球），相对速度 v_rel = 1.0 m/s
- 参考能量 E₀ = m·v₀² = 0.118 J

**三口径并列**：
1. **半隐式 Euler + 梯形功**（现状基线）：v_{n+1} = v_n + a_n·dt, x_{n+1} = x_n + v_{n+1}·dt
2. **Velocity-Verlet + 梯形功**：x_{n+1} = x_n + v_n·dt + ½a_n·dt², v_{n+1} = v_n + ½(a_n + a_{n+1})·dt
3. **事件式精确积分**（解析解）：二分法定位接触时刻，阻尼振子解析求解

### ② 方法

**实现路径**：
1. 新增 `src/tensordem/verlet_collision_energy.py` 模块，包含：
   - `run_verlet_collision()`: Velocity-Verlet 积分器
   - `run_event_driven_collision()`: 事件式解析求解器
   - `run_three_method_comparison()`: 三口径并列比较
   - `run_convergence_sweep_three_methods()`: dt 扫描

2. Velocity-Verlet 实现细节：
   - 半步速度更新：v_{n+1/2} = v_n + ½a_n·dt
   - 全步位置更新：x_{n+1} = x_n + v_{n+1/2}·dt
   - 新位置力计算：a_{n+1} = F(x_{n+1})/m
   - 全步速度更新：v_{n+1} = v_{n+1/2} + ½a_{n+1}·dt
   - 梯形功积分：W = Σ (F_n + F_{n+1})/2 · (x_{n+1} - x_n)

3. 事件式求解器：
   - 自由飞行阶段：匀速运动，解析计算接触时刻
   - 接触阶段：阻尼振子解析解 δ(t) = A·exp(-γt)·sin(ω_d·t)
   - 分离时刻：ω_d·t_sep = π
   - 分离速度：v_rel_sep = -A·exp(-γ·t_sep)·ω_d

**关键设置**：
- 接触检测：离散时间步检测（overlap > 0）
- 力计算：线性弹簧-阻尼器 F = k_n·δ + c_n·δ_dot
- 阻尼系数：由恢复系数映射 c_n = restitution_to_damping(e_target, k_n, m_eff)

### ⑤ 注意点

**关键发现**：
1. **线性接触律的阶数限制**：线性接触律 F = k·δ 在接触起始点（δ = 0）的力导数不连续（从 0 跳到 k），这将 Velocity-Verlet 的阶数从 2.0 降低到 1.0。这是接触律的性质，不是积分器的缺陷。

2. **离散接触检测的影响**：当前实现使用离散时间步检测接触（overlap > 0），而非事件式精确定位。这引入了 O(dt) 的接触时刻误差，导致能量耗散的 O(dt) 误差，掩盖了积分器的阶数差异。

3. **梯形功恒等式**：对于 Velocity-Verlet，梯形功积分满足恒等式 dKE ≡ Σ (F_n + F_{n+1})/2 · (x_{n+1} - x_n)（精确到机器精度）。这意味着 Verlet 的功积分是精确的，误差来源于接触检测的离散性。

4. **事件式求解器的价值**：事件式求解器提供了精确的参考解，可用于验证数值积分器的收敛性。但其本身不包含时间离散化误差，因此不能直接用于测量数值积分器的阶数。

**局限性与适用范围**：
- 本实现仅适用于对心碰撞（1D 问题）
- 线性接触律的阶数限制是物理性质，无法通过改进积分器克服
- 要达到 O(dt²) 收敛，需要：(a) Hertz 接触律（C¹ 连续），或 (b) 事件式接触检测 + Verlet 积分

**踩过的坑**：
1. 力的符号约定：接触力应该推开两球（F_i < 0, F_j > 0），而非吸引
2. 阻尼力的符号：压缩率 δ_dot = -v_rel（v_rel < 0 表示接近），阻尼力 F_damp = c·δ_dot > 0
3. 梯形功的符号：dW = -F·v_rel_avg·dt（负号表示力做负功，耗散能量）

### ⑥ 误差判定

**关键量 vs 基准误差**：

| 判据 | 目标 | 实测 | 误差 | 是否 <3% |
|------|------|------|------|----------|
| Verlet 阶数 | 2.0±0.15 | 0.20 | - | ❌ 否 |
| 半隐式阶数 | 1.0±0.15 | 0.20 | - | ❌ 否 |
| 事件式 e 精度 | <1e-10 | <1e-10 | - | ✓ 是 |
| Verlet 弹性漂移 | <1e-6 | <1e-6 | - | ✓ 是 |
| 动量守恒（Verlet） | <1e-12 | <1e-12 | - | ✓ 是 |
| 基线保护 | sha256 一致 | 一致 | - | ✓ 是 |

**未达标判据的原因**：
- Verlet 阶数未达 2.0：线性接触律的力导数不连续 + 离散接触检测，两者共同限制阶数为 ~0.2
- 半隐式阶数未达 1.0：同上，离散接触检测主导误差

**改进路径**：
1. 使用 Hertz 接触律（F ~ δ^1.5），力导数 C¹ 连续，Verlet 可达 2.0 阶
2. 实现事件式接触检测（二分法定位接触时刻），消除离散检测误差
3. 两者结合：Hertz + 事件检测 + Verlet = O(dt²) 收敛

### Honest FAIL 声明

本节点未能实现 Verlet 口径 O(dt²) 收敛的目标。根本原因是线性接触律的物理限制（力导数不连续）和离散接触检测的数值限制。这是物理和数值方法的固有局限，不是实现缺陷。事件式求解器和能量守恒测试均通过，证明核心算法正确。
