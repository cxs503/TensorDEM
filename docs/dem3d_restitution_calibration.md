# DEM3D 法向接触恢复系数标定与验证（restitution calibration）

## 1. 案例介绍（物理背景 / 模型 / 参数）

TensorDEM 的 2-D 与 3-D 求解器都使用**线性弹簧-阻尼**法向接触律：

```
F_n = clamp(k δ - c v_n, 0, ∞)        （δ = 重叠量, v_n = 法向相对速度）
```

引擎的输入是刚度 `contact_stiffness` / `platen_stiffness` 与阻尼
`contact_damping` / `platen_damping`，而冰力学文献给出的是**恢复系数** e
（海冰-海冰、海冰-钢结构典型 0.2–0.6）。两者的映射在本次工作之前**没有任何文档、
没有任何测试**，因此"引擎实际表现出的 e 是多少"属于验证欠账：既无法对文献标定，
也无法判断默认值是否合理。

本单补齐该欠账：给出两条闭式解、一条标定反演、一套离散元反弹实验，并用实验
（DEM3D 自身）验证闭式解。

参数表（默认 `DEM3DConfig()`，与引擎一致）：

| 量 | 符号 | 值 |
|---|---|---|
| 颗粒半径 | r | 0.025 m |
| 颗粒密度 | ρ | 917 kg/m³ |
| 颗粒质量 | m | 0.060018 kg |
| 接触刚度 | k | 5000 N/m |
| 接触阻尼（默认） | c | 5.0 N·s/m |
| 平板刚度 | k_pl | 5000 N/m |
| 平板阻尼（默认） | c_pl | 0.0 N·s/m |
| 时间步（推荐） | Δt | 2.122e-5 s（2×2×2 试块） |

## 2. 怎么做的（方法 / 工具链）

1. **两条闭式解**（`src/tensordem/restitution.py`）
   - 教科书 Kelvin–Voigt（*允许拉力*的尾部）：ζ = c/(2√(km))，
     e = exp(−ζπ/√(1−ζ²))。
   - **单边钳制解**（*即引擎实际积分的模型*）：由于力在第一个零点被截断，
     分离相位 φ = atan2(2ζ√(1−ζ²), −(1−2ζ²)) ∈ (0, π)，且可解析化简为
     **e = exp(−(ζ/√(1−ζ²))·φ)**。该式与独立 RK4 积分（`tests/test_dem3d_restitution.py`）
     在 1e-3 内一致。
2. **标定反演**：闭式 e(ζ) 单调，二分反解得到目标 e 所需阻尼
   `damping_for_clamped_restitution`（教科书式反演也保留，用于对照）。
3. **离散元反弹实验**（`measure_platen_restitution`）：把 2×2×2 黏结颗粒块以
   0.5 m/s 法向速度撞向刚性平板（`drag = 0`，无重力），当所有颗粒脱离平板时
   取质心法向速度比。
4. **三组数值实验**（`scripts/calibrate_dem3d_restitution.py`）：
   阻尼扫描、时间步收敛（Δt/4、Δt/8）、目标 e→阻尼标定表。
   工作点在 `outputs/dem3d_restitution/`，图见 `outputs/dem3d_restitution/dem3d_restitution_calibration.png`。

复现命令：

```bash
PYTHONPATH=src python3 scripts/calibrate_dem3d_restitution.py
PYTHONPATH=src python3 -m pytest tests/test_dem3d_restitution.py -q
```

## 4. 结论与误差判定

- **默认配置的真实恢复系数**：clamped 0.65972，教科书式 0.63243。历史上从未记录，
  本次首次钉死并写入测试（`test_documented_default_restitutions`）。
- **平板默认为完全弹性**：`platen_damping = 0` ⇒ e ≡ 1.0。即所有既有的平板压缩类
  基准（UCS / 圆柱压缩 / 三点弯…）在法向上是无耗散的；若要与冰-钢试验对标，需要
  显式设置 `platen_damping`（标定表已给出反演值）。本次未改默认值，以免破坏既有基准。
- **误差逐项判定（是否 <3%）**：
  - c = 0：0.00% ✔
  - c = 1 N·s/m：0.53% ✔
  - c = 2 N·s/m：0.98% ✔
  - c = 5 N·s/m（引擎默认）：2.00% ✔
  - c = 10 N·s/m：默认 Δt 3.00%（**临界**），Δt/8 时 2.77% ✔
  - 教科书 Kelvin–Voigt 在同一组算例上最大偏差 **16.00%** ✘（>15% 不可接受）
  ⇒ 结论：**必须用钳制解做标定基准**，教科书式在 ζ ≳ 0.1 后不可用。

## 5. 注意点（坑 / 局限 / 适用范围）

1. **坑：闭式解选错会得出"引擎有 16% 误差"的错误结论。** 实测值不随 Δt
   （Δt/8 仅改变 0.24%）也不随键刚度（×100 仅 0.03%）变化，排除了积分误差；
   真正的差异是**引擎钳制了拉力**，而教科书解保留了拉力尾巴。这份"看着像 bug
   其实是模型差"的判别流程已写入测试（`test_clamped_form_is_better_predictor_at_moderate_damping`）。
2. **残余 2–3% 系统偏差**：实测始终**低于**钳制闭式解，方向保守（引擎偏不弹）。
   已验证与 Δt、键刚度、黏结断裂（`broken_bonds = 0`，把 `breaking_strain` 放大到 5.0
   结果不变）无关；归因为多颗粒块（接触力只作用在底层 4 颗粒、质量 8 颗粒）相对
   单自由度理想化的系统差。**未完全归因**，如实记录。
3. **线性阻尼 ⇒ e 与撞击速度无关**（已验证 0.1 与 1.0 m/s 差 <5e-3）。真实海冰恢复
   系数随应变率/温度变化，需要速度相关（Hertz–Mindlin / Tsuji）接触律才能表达；
   本引擎目前不支持，属已知适用边界。
4. **适用范围**：ζ ∈ (0, 0.5] 内标定可用；ζ→1 时钳制解快速趋于 0，反演病态
   （`damping_for_clamped_restitution` 会对极端目标抛错而不是静默返回）。
5. 命名空间坑：本次探针脚本曾因 `/tmp` 共用文件名被其他 agent 覆盖，多 agent 主机上
   `/tmp` 必须带命名空间。
