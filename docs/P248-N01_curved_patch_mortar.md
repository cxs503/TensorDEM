## 1 案例介绍

### 1.1 物理背景

冰–结构 / DEM–FEM–BEM 耦合的可信度不在“能不能传数据”，而在界面算子的三条性质：
守恒、相容、对称。m5436 及其 tri-tri 后继把 3D 非共面单元对被处理成 **面片投影**：
把从面单元正交投影到主面单元平面、在平面内裁剪重叠、再用 `1/|cos(二面角)|` 搬运测度。
在**曲面**界面上这一构造只有一阶精度：逐面片的覆盖缺陷 `sum_i m_ij/|Gamma_j| - 1` 是 O(κh) 且被测度为零的细长片主导，因此上一节点只能把它降级为**诊断量**，仅对全局和设门。

全局门看不见局部通量失衡：一对相邻面片可以一个超额覆盖、一个欠额覆盖而总和恰好相等，
耦合系统于是在界面处**每步人为注入或耗散能量**。本节点把界面测度换成真实曲面度量，
把面片投影换成 Newton 投影求交，把全局门升级为**逐面片门**，并把间隙/渗透显式记账。

### 1.2 几何与参数

| 项 | 球面片 | 图面片 |
|---|---|---|
| 参数化 | $x=R(\sin\theta\cos\varphi,\sin\theta\sin\varphi,\cos\theta)$，$\theta\in[0.35,1.20]$，$\varphi\in[0.30,1.30]$，$R=1$ | $x=Lu\,e_1+Wv\,e_2+A\sin(\pi u)\sin(\pi v)\,n$，$L=W=1$，$A=0.12$ |
| 曲面面积 (m²) | 0.577 | 1.03 |
| 曲率尺度 κ·L | 0.76 | 2.41 |
| 求积规则 | 三角锥积 Gauss n=8（15 阶）× 复合细分 | 同左 |

两侧网格：主面 $n\times n$、从面 $(n+3)\times(n+2)$，内部节点按 $O(0.3h)$ 抖动、
边界节点固定在参数矩形边界上（因此各自**精确铺满**参数域，这是逐面片门的前提）。
曲率来源：$\kappa = 1/R$（球）/ $2\pi^2A/L^2$（图）。

## 2 怎么做的

### 2.1 模块结构（新增 `src/tensordem/interface_operators/curved_patch_mortar.py`）

| 组件 | 内容 |
|---|---|
| `ParamPatch` / `SpherePatch` / `GraphPatch` | 解析图表 $x(u,v)$ 及一、二阶导数、$J=|x_u\times x_v|$、复合求积的 `area()` / `centroid()` |
| `ParamPatch.project` | 2×2 Newton 求 `x(u,v)=p` 的驻点（法方程形式），二次收敛；3D 网格顶点即由此落到曲面上 |
| `CurvedSide` | 参数域三角剖分；每个面片是**曲面单元**，测度 $\int_T J$，质心 $\int_T x J/\int_T J$ |
| `pair_measures` | 参数域**真交集**：两个凸三角形精确裁剪为凸多边形 $R_{ij}$，$m_{ij}=\int_{R_{ij}}J$，$\mu_{ij}=\int_{R_{ij}}(x-c_i)J$（15 阶求积） |
| `coverage_arrangement` | 覆盖重数 $c(x)$ 的**精确多边形排布**，给出 $V_{gap,j}$、$V_{pen,j}$ 与恒等式残差 |
| `CurvedMortarOperator` | $M_{ji}=(m_{ij}+g_i\cdot\mu_{ij})/|\Gamma_j|$，二阶重构（最小二乘梯度）；`measure=` 提供三种对照 |
| `adjoint_apply` / `adjoint_diagnostics` | 度量相容的**转置（伴随）算子**，把主面侧重构也带上，检验二阶转置一致性 |
| `first_order_coupling` | 两个一阶系统经曲面界面耦合的时域账本 |

### 2.2 关键公式

真交集与逐面片平衡（$c$ 为从面覆盖重数）：

$$m_{ij}=\int_{R_{ij}}J\,du\,dv,\quad |\Gamma_j|+V_{pen,j}-V_{gap,j}=\sum_i m_{ij},$$

$$V_{gap,j}=\int_{P_j}\max(1-c,0)J,\qquad V_{pen,j}=\int_{P_j}\max(c-1,0)J.$$

时域耦合（$R=1/k_{gap}$，`closure` 形即标准 mortar 受体形式）：

$$v_j=(Mu_A)_j,\quad \lambda_j=(u_{B,j}-v_j)/R,\quad \dot u_{A,i}=-a_Au_{A,i}-(\textstyle\sum_j m_{ij}\lambda_j)/|S_i|,\quad \dot u_{B,j}=-a_Bu_{B,j}+c_j\lambda_j.$$

据此 $\dfrac{d}{dt}\sum(\cdot)=\sum_j(|\Gamma_j|c_j-\sum_i m_{ij})\lambda_j$：**只有当逐面片守恒成立时界面项才恒等于零**，这正是本节点要求的物理目标。

## 5 注意点（踩过的坑 / 局限）

1. **求积是门的瓶颈**：单块单位方块上 15 阶规则只剩 ~1e-7 相对精度（图面片实测），必须做成复合细分（`area(subdiv=8)`）。逐面片门之所以能到 1e-15，是因为单元尺寸 $h\le0.25$；若把整个界面当成一个单元，门必然失败。

2. **测度为零的细长片会伪造重数**：两套网格在边界上共用节点时，排布会产出面积 $<10^{-18}$ 的碎块并报告重数 2。报告的最大重数只统计面积 $>10^{-12}|\Gamma_j|$ 的分块，否则“渗透”会被数值噪声误报。

3. **曲面单元 vs 平板单元**：本实现的从/主面片是参数域三角的曲面像；只有上一节点（`plane_projection_defect`）才把它们当平板三角形。若真实代码提供的是平板网格，曲面像与平板之间的透镜体积应并入 $V_{gap}$ 记账——本节点给出的是记账机制，透镜项本身未在此单独测量。

4. **时域账本的余项是 $O(dt)$ 时间离散**：`energy_bookkeeping_residual_rel` 用显式更新的精确代数恒等式（含 $\frac{1}{2}dt^2\sum W f^2$），因此是舍入级；物理残差里的 $O(dt)$ 项来自显式 Euler，不是界面缺陷，报告已分别列出。

5. **只有间隙很小时曲面参数化才唯一**：`project` 对大间隙/折叠界面需要初值搜索（本实现的 7×7 粗搜）；若两侧间距与曲率半径同量级，法向投影会多值，本模块不适用。

## 8 结论

逐面片局部守恒门（E2）通过、间隙/渗透记账（E3）通过、时域能量账（E4）通过、二阶转置一致性（E5）通过。面片投影（上一节点）在同算例上逐面片缺陷 $O(10^{-1})$–$O(10^{-2})$，平面度量在均匀态下产生 $\max|\lambda|$ 量级的伪通量并把总能量抬高数倍——即“界面处的人为注入/耗散”被本节点的曲面真交集 + 逐面片门消除。

**未做 / 局限**：未与真实 DEM–FEM 求解器时间推进耦合（只做算子级两一阶系统）；未处理折叠/大间隙界面的多值投影；平板网格的透镜体积项未单独量化（只给出记账位置）。
