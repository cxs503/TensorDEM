## 1. 案例介绍

**物理背景。** 冰区船舶总体性能里，DEM 冰场与船体/冰–冰接触的切向分量直接决定接触摩阻力、
碎冰堆积角与破冰阻力中「摩擦—挤压」贡献。当前库提供的接触模型有两块：

1. **法向粘壶（恢复系数映射）**：`restitution_to_damping(e, k_n, m_eff)` 把目标恢复系数 e
   映射为法向阻尼 gamma_n，依据单自由度质量–弹簧–粘壶碰撞的解析关系
   `e = exp(-pi*zeta/sqrt(1-zeta^2))`，`zeta = gamma_n / (2 sqrt(k_n m_eff))`。
2. **切向 Coulomb 弹簧（Cundall–Strack 增量模型）**：`integrate_tangential_displacement`
   累积切向相对位移，`compute_tangential_force` 施加 `F_t = k_t delta_t` 并按 `|F_t| <= mu F_n` 截断。

这两块此前只有**单体公式级**测试（饱和值、增量、往返映射），从未在**时间推进**下与闭式解对照；
即「公式写得对」≠「按求解器的方式用它是对的」。本单补的正是这条验证欠账。

**几何/工况（无实体几何，两个单接触基准）。**

| 参数 | 符号 | 值 | 备注 |
|---|---|---|---|
| 法向刚度 | k_n | 1000 N/m | Anchor R 与 T 同为量级基准 |
| 有效质量 | m_eff | 1.0 kg | 对偶接触折合质量 |
| 初始撞击速度 | v0 | 1.0 m/s | 纯法向 |
| 法向力 | F_n | 100 N | Anchor T 恒值 |
| 切向刚度 | k_t | 1000 N/m | 摩擦锥极限位移 a_stick = 0.03 m |
| 摩擦系数 | mu | 0.3 | 对应 F_limit = 30 N |
| 驱动振幅 | a | 0.01 … 0.4 m | 跨过 a_stick 检验粘着/滑移转换 |

## 2. 怎么做的（方法与工具链）

**Anchor R（恢复系数映射）。**
以半隐式（辛）Euler 积分 `m_eff x_ddot + gamma_n x_dot + k_n x = 0`（x(0)=0, x_dot(0)=v0，
压缩为正），这正是 `dem.py` 核的积分格式；检测 x 由正穿零回到自由（v<0）时的事件，
在穿零点对速度做线性插值得到回弹速度，`e_meas = |v_reb| / v0`。
- 判据：`|e_meas - e_target| / e_target < 0.5 %`（本单设定的验证容差）。
- 离散化序列：每接触周期 1000/2000/4000/8000 步，检验一阶收敛。
- 另有 `e -> gamma_n -> e` 往返闭合检验（机器精度）。

**Anchor T（切向粘滑滞回）。**
单接触、恒法向力，切向位移按 `delta(t) = a sin(2 pi t / T)` 谐波驱动（准静态，模型率无关），
位移增量**只经由库函数** `integrate_tangential_displacement` 累积，力**只经由**
`compute_tangential_force` 计算；第 n 步做功按梯形求积 `0.5 (F_t^n + F_t^{n+1}) * dd`
累加，取第 3 个循环的环路面积。
- 闭式基准（平行四边形滞回环面积）：
  `W = 4 mu F_n (a - mu F_n / k_t)`，`a >= a_stick = mu F_n / k_t`；否则 W = 0（纯粘着 shake-down）。
- 判据：相对误差 < 0.5 %；低于 a_stick 的振幅要求 `|W| < 1e-9 J`。
- **负控（negative control）**：同一切向驱动，但把「未截断的原始位移」当作新状态回灌
  （即修复前 `compute_tangential_force` 第二个返回值的语义）。此时力变成驱动位移的单值函数，
  滞回环面积为 0 —— 用来证明「状态投影」不是形式主义，而是摩擦耗散的唯一来源。

**工具链。** torch 2.7.1 (CPU, float64)，matplotlib 3.10 出图，pytest 跑测试；
单接触小算例，全流程 CPU 分钟级，不占 GPU、不触发重算力。

## 3. 计算结果

完整的机器生成表见 `docs/m2220/outputs/tangential_friction_verification/tables.md`（R1/R2/R3/T1/T2）。

**Anchor R（恢复系数）**：目标 e ∈ {0.1, 0.3, 0.5, 0.7, 0.9}，最细 dt = 2.484e-5 s 时
实测 e 与目标的相对误差分别为 0.0822 % / 0.0194 % / 0.0062 % / 0.0016 % / 0.0001 %，
最差 0.0822 %。dt 细化（e=0.5）误差 0.0496 % → 0.0247 % → 0.0123 % → 0.0062 %，
每减半 dt 误差约减半，**一阶收敛**与半隐式 Euler 的预期一致。

**Anchor T（粘滑滞回）**：a = 0.05/0.1/0.2/0.4 m 时闭式 W = 2.4/8.4/20.4/44.4 J，
实测 2.399999/8.400000/20.399988/44.399982 J，相对误差 ≤ 1e-4 %；
滑移时间占比随振幅单调升（0.413 → 0.615 → 0.739 → 0.820）。
a ≤ 0.03 m（= a_stick）时实测与闭式均为 0（|W| < 1e-15 J 量级），滑移占比 0，纯粘着被正确识别。
负控（未截断状态）在全部振幅下 W ≈ 1e-17 … 1e-15 J，即**零耗散**，与解析预期完全吻合。

## 5. 注意点（坑 / 适用范围）

**5.1 发现并修正的状态更新缺陷（本单唯一代码行为变更）。**
修复前 `compute_tangential_force` 返回 `(F_t, F_t_raw)`，文档称第二个值为 "updated disp proxy"；
调用者若照此回灌，`delta` 恒等于驱动器累计位移，`F_t = clamp(k_t delta)` 成为单值函数，
**滞回环面积为 0，摩擦完全零耗散**（负控给出了这个数量级的实测证据）。
修复：第二个返回值改为锥投影后的状态 `delta_next = F_t / k_t`（Cundall–Strack 标准做法），
并新增 `tangential_cycle_dissipated_work` 闭式基准函数；`k_t <= 0`、`mu < 0` 现抛 `ValueError`。
影响面：树内除测试外无调用者（`benchmarks/ice_floe_physics.py` 只用恢复系数两个函数），
属非破坏性修正；语义变更已在 docstring 显式说明并附验证文档指针。

**5.2 局限（不得越界解读）。**
- 恒法向力、单接触、无颗粒旋转：**滚动阻力（`rolling_mu` 仍为占位）未验证**，扭矩/力偶累积不在本单范围。
- 驱动为准静态谐波；未验证高频加载下的率相关性（Coulomb 模型本身率无关，但离散化误差随步数变化，见 T2）。
- 未做实验对标：闭式基准是**模型内部自洽性**验证（模型定义 → 解析积分），不是物理正确性证明；
  真实冰–钢摩擦的 mu 需材料标定（见 `docs/dem3d_material_calibration_roadmap.md`）。
- 法向验证只覆盖「映射 → 回弹比」这一条链，未覆盖法向力–压痕律与多体堆叠。

| 回弹比 e（e_t=0.5） | 0.5 | 0.499969 | 0.0062 % | 是 |
| 回弹比 e（e_t=0.9） | 0.9 | 0.899999 | 0.0001 % | 是 |
| 每循环耗散功 W（a=0.2 m） | 20.4 J | 20.399988 J | 0.00006 % | 是 |
| 每循环耗散功 W（a=0.05 m） | 2.4 J | 2.399999 J | 0.00004 % | 是 |
| shake-down 振幅（a=0.03 m） | 0 J | ~1e-16 J | 绝对量 < 1e-9 J | 是 |

结论：两个锚点在设定的离散化水平下相对误差均 **远小于 3 %**（最差 0.0822 %，来自 e=0.1 这种

负控的 100 % 偏差是被验证的**缺陷复现**，修复后转正。
