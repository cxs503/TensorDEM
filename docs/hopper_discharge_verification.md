## 1. 案例介绍

### 1.1 物理背景

散货舱颗粒卸料是船舶装载/卸载过程中的关键物理现象，涉及：
- **休止角**（Angle of Repose）：颗粒自由堆积形成的稳定斜面角度
- **Beverloo 卸料律**：颗粒通过底部卸料口的质量流率标度律
- **Janssen 舱壁压力**：筒仓内颗粒对舱壁的压力分布

本验证面在 TensorDEM 上首次建立这三个经典颗粒力学基准测试。

### 1.2 几何模型

**原型规格**（参考值）：
- 上部矩形舱：10m × 5m × 8m
- 下部锥形漏斗：半角 30°
- 底部卸料口直径：0.8 / 1.0 / 1.2 m（三档）

**缩放模型**（实际计算）：
- 筒仓半径：0.20 m（卸料）、0.15 m（Janssen/休止角）
- 填充高度：0.35 m（卸料）、0.60 m（Janssen）、0.25 m（休止角）
- 卸料口直径：0.20 / 0.25 / 0.30 m（三档）

**缩放原因**：原始几何需要 ~5×10⁴ 颗粒，单案例计算时间 >10 分钟，全战役 45 案例需 >7 小时。缩放后 ~100-400 颗粒/案例，总计算时间 ~6 分钟。

**缩放有效性**：Beverloo 律要求 D₀/d >> 1，此处 D₀/d = 4-6（边际但可接受）。

### 1.3 颗粒参数

| 参数 | 值 | 单位 |
|------|-----|------|
| 颗粒直径 d | 50 | mm |
| 颗粒密度 ρ_p | 2500 | kg/m³ |
| 法向刚度 k_n | 1.0×10⁶ | N/m |
| 切向刚度 k_t | 0.5×k_n | N/m |
| 恢复系数 e | 0.5 | - |
| 颗粒间摩擦系数 μ | 0.1-0.5 | - |
| 壁面摩擦系数 μ_w | 0.3-0.5 | - |
| 重力加速度 g | 9.81 | m/s² |

### 1.4 接触模型

线性弹簧-阻尼模型：
- 法向力：F_n = k_n δ - γ v_n（δ=重叠量，v_n=法向相对速度）
- 切向力：F_t = -k_t Δ_t（Δ_t=切向位移，Cundall-Strack 增量更新）
- 阻尼系数：γ = 2ζ√(k_n m_eff)，ζ 由恢复系数 e 确定

## 2. 计算方法

### 2.1 DEM 求解器

**核心引擎**：`src/verification/granular/hopper_discharge/kernel.py`

**关键特性**：
- 速度 Verlet 积分（kick-drift-kick）
- KDTree 邻居搜索（scipy.spatial.cKDTree）
- 能量账本：实时追踪机械能 + 耗散功
- 质量账本：追踪域内质量 + 卸料质量

**性能**：
- 单案例：5-17 秒（取决于颗粒数）
- 全战役（45 案例）：346 秒 ≈ 5.8 分钟
- 颗粒数范围：33-566
- 时间步长：8.99×10⁻⁵ s（自动确定）

|--------|--------|----------|----------|

**随机种子**：11, 22, 33（确保可重复性）

### 2.3 测量方法

**休止角**：
1. 生成颗粒柱（r_bin=0.15m, h=0.25m）
2. 提升侧壁（0.03s 线性 ramp）
3. 自由沉降 0.20s
4. 高度图 → 径向分箱 → 斜面拟合 → θ_r = arctan(-slope)

**Beverloo 流率**：
1. 填充锥形漏斗（r_bin=0.20m, h=0.35m）
2. 沉降 0.10s
3. 打开卸料口
4. 记录 5 个时间窗口的累积质量
5. 线性拟合 W(t) → 稳态流率

**Janssen 压力**：
1. 填充圆柱筒仓（r_bin=0.15m, h=0.60m）
2. 沉降 0.10s + 采样 0.05s
3. 沿高度分 8 个 slab（每层 0.08m）
4. 统计每个 slab 的壁面接触力 → σ_w(z)

### 3.2 Beverloo 卸料律（C2, C3）

**流率 vs 卸料口直径**：

| D₀ (m) | W_mean (kg/s) | W_std (kg/s) |
|--------|---------------|--------------|
| 0.20 | 1.85 | 0.12 |
| 0.25 | 3.42 | 0.18 |
| 0.30 | 5.67 | 0.24 |

**标度律拟合**：
- W = C ρ_b √g (D₀ - kd)^(5/2)
- 线性拟合 R² = 0.9999 ✓
- Beverloo 常数 C = 0.596（文献值 0.58，偏差 2.7%）✓

**结论**：Beverloo 律验证**成功**，标度指数和常数均与理论/经验值高度一致。

### 3.3 休止角（C1）

**测量结果**：

| μ | θ_r (mean±std) | 解析值 tan⁻¹(μ) | 偏差 |
|---|----------------|-----------------|------|
| 0.10 | 9.12 ± 1.70° | 5.71° | 3.41° |
| 0.20 | 11.51 ± 1.86° | 11.31° | 0.20° |
| 0.30 | 10.88 ± 1.91° | 16.70° | 5.82° |
| 0.40 | 8.66 ± 9.05° | 21.80° | 13.14° |
| 0.50 | 12.25 ± 1.44° | 26.57° | 14.31° |

**问题分析**：
1. **非单调**：θ_r 不随 μ 单调递增
2. **低 R²**：线性拟合 R² = 0.123（需要 > 0.95）
3. **大偏差**：最大偏差 14.3°（需要 < 10°）
4. **高离散**：μ=0.4 时标准差 9.05°（其他 μ 约 1.5-2°）

**根因**：颗粒数过少（~100 颗粒），无法形成稳定的锥形堆。高度图拟合 R² 仅 0.44，表明堆形不规则。

### 3.4 Janssen 舱壁压力（C4）

**饱和值偏差**：

| μ_w | σ_sat_analytic (Pa) | σ_sat_fit (Pa) | 偏差 |
|-----|---------------------|----------------|------|
| 0.3 | 2450 | 3120 | 27.3% |
| 0.4 | 1838 | 2280 | 24.1% |
| 0.5 | 1470 | 1790 | 21.8% |

**平均偏差**：26.5%（阈值 25%，边际失败）

**问题分析**：
- 筒仓高度 0.60m，水力半径 R_h = 0.075m
- Janssen 特征长度 z₀ = R_h / (μ_w K) ≈ 0.15-0.25m
- 筒仓高度 / z₀ ≈ 2.4-4.0，理论上应达到饱和
- 实际测量显示底部 slab 压力仍在上升，未完全饱和

**根因**：颗粒数不足（~300 颗粒），壁面接触统计噪声大。

### 3.5 守恒律（C5, C6）

**质量守恒（C5）**：
- 最大残差：1.0×10⁻¹⁵ ✓
- 结论：质量守恒**完美**

**能量账本（C6）**：
- 最大残差：4.98（需要 < 1e-8）
- 问题：速度 Verlet 积分器与阻尼项耦合导致能量不守恒
- 根因：阻尼力使用半步步速度评估，但能量账本假设全步保守

**结论**：质量守恒优秀，能量账本存在系统性偏差（需改进积分器或账本公式）。

### 3.6 负控与收敛（C7, C8）

**负控 μ=0（C8）**：
- θ_r = 3.76° < 5° ✓
- 结论：无摩擦时颗粒摊平，验证通过

**颗粒数收敛（C7）**：
- 离散度：200%（需要 < 10%）
- 问题：小样本（33 vs 112 颗粒）统计噪声主导
- 结论：需要更大颗粒数才能观察收敛趋势

## 5. 注意点与局限

### 5.1 主要局限

1. **颗粒数不足**：
   - 休止角：~100 颗粒（需要 >1000 才能形成稳定锥）
   - Janssen：~300 颗粒（壁面接触统计噪声大）
   - 卸料：~400 颗粒（D₀/d = 4-6，边际可接受）

2. **几何缩放**：
   - 原型 10m×5m×8m → 计算模型 0.2-0.6m
   - 缩放比 1:20-1:50
   - 边界效应增强（壁面占比增大）

3. **能量账本**：
   - 速度 Verlet + 阻尼 → 能量不守恒（残差 4.98）
   - 需要改进积分器或账本公式

4. **时间步长**：
   - dt = 8.99×10⁻⁵ s（Rayleigh 时间步的 10%）
   - dt 研究（C6）显示残差随 dt 减小而改善，但未达 1e-8

### 5.2 适用范围

**本验证面适用于**：
- Beverloo 卸料律的定性验证（标度指数、常数）
- 质量守恒的严格验证
- 负控测试（无摩擦极限）
- DEM 代码框架的功能验证

**不适用于**：
- 休止角的定量预测（需要更大颗粒数）
- Janssen 压力的精确验证（需要更高统计精度）
- 能量守恒的严格验证（需要改进积分器）

### 5.3 改进方向

1. **增加颗粒数**：
   - 休止角：增加到 ~1000 颗粒（r_bin=0.35m, h=0.7m）
   - Janssen：增加到 ~1000 颗粒（r_bin=0.25m, h=1.2m）
   - 计算时间：~30 分钟/案例 → 全战役 ~2 小时

2. **改进能量账本**：
   - 使用速度 Verlet 的中点力评估
   - 或改用辛积分器（如 leapfrog with damping correction）

3. **优化邻居搜索**：
   - KDTree → Cell List（预期 5-10× 加速）
   - 允许更大颗粒数（~10⁴）在合理时间内完成
