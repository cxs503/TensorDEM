## ① 案例介绍

Lube, Huppert, Sparks & Freundt (2004, *JFM* **508**, 175-199, doi:10.1017/S0022112004009036)
用圆柱形颗粒柱（初始半径 $r_i$、高 $h_i$、长宽比 $a=h_i/r_i$）在抽去侧壁后的**轴对称坍塌**给出**两条**
经验律，全部写在该文摘要里：

* 跑距律：$r_\infty/r_i = 1+1.24a\ (a<1.7)$；$=1+1.6a^{1/2}\ (a>1.7)$
* 埋置时间律：$t_\infty = 3(h_i/g)^{1/2} = 3(a r_i/g)^{1/2}$

平台 `src/tensordem/granular_column/axisym.py` **两条都实现了**（
`lube_2004_runout_ratio`、`lube_2004_emplacement_time`），每个逐例 JSON 也都记录了
`reference_emplacement_time` 与 `t_reach`。但轮 1–5 只对**第一条**下过裁决。

复算所用的算例（轮 5 "闭合臂"，主判据 5 例 + 4 例收敛控制）：

| 项 | 值 |
|---|---|
| 几何 | $r_i=0.48$ m，$a\in\{0.5,1,1.5,2,3\}$，HCP 排布，`packing_gap` 0.02 |
| 颗粒 | 单分散球，$r=0.03$ m（8 粒/柱半径，收敛控制例 12 粒/半径），$\rho=2500$ kg/m³，981–19687 粒 |
| 接触 | 线性弹簧-阻尼法向 + Cundall-Strack 切向（饱和 $\mu|F_n|$）+ 滚动弹簧（饱和 $\mu_r R|F_n|$） |
| 参数（闭合臂） | $\mu=0.5$，$\mu_r=0.5$，$\mu_{\rm wall}=0.8$，$e=0.5$，$k_n=6\times10^4$ N/m，$\Delta t\approx4.8\times10^{-4}$ s |
| 终止 | 全部 `stop_reason = 'at_rest'`（无截断，且 $t_{\rm reach}<t_{\rm end}$ 逐例断言） |
| 备注 | 未记录 `mu_wall` 键的算例（`w5_const_*`、`w5_law_*`）走 kernel 默认 $\mu_{\rm wall}=\mu$，故**不属**闭合臂、只进入 25 例总体统计 |

## ② 怎么做的（方法 / 流程 / 工具链）

1. **取原始逐例 JSON**（轮 5 工作树 `work/m17111/runs/case_column_collapse_lube2004/cases/`，25 例）。
2. **归约**：每例抽 31 个标量（几何、材料、协议、跑距、三个到达分数下的时间、能量账），
   逐文件写 `sha256`（`manifest_sha256.json`）→ 得到可入库的 `cases_reduced.csv`（12 KB，替代 7.6 MB 原始件）。
3. **重算参考值**（不抄任何存下来的目标数）：`lube_emplacement_time` 由几何重新求值，
   并**断言等于**求解器存的 `reference_emplacement_time`（相对 1e-9）——两条独立代码路径互校。
4. **两个"定义"轴**做敏感性：
   * **到达定义**：`t_reach_by_fraction` 的 90 % / 95 % / 99 % 三个已记录变体；
   * **长宽比口径**：参考律按**名义** $a$ 还是按**实测** $a$（HCP+gap 使实测柱更高，$a_{\rm meas}>a_{\rm nom}$ 最多 +10 %）。
5. **统计量**：15 % 带内外计数、中位/最大绝对误差、符号检验（双侧二项，$p=2\sum_{i\ge k}\binom{n}{i}/2^n$）、
   双对数斜率（含 Pearson $r$）。
6. **预登记假设**（在跑出结果前写在脚本 docstring 里）：`H_TIME`、`H_NOMINAL`、`H_EXPONENT`、
   `H_TIME_SHALLOW`（判据见 `adjudicate()`）。
7. **机器门**：13 项 pytest（机械量用合成输入测；数据量用入库 CSV 回归，报告里每个数字都被断言住）。

工具链：Python 3.11 + numpy/matplotlib（Agg）；**未启动任何 DEM 进程**；全程单进程 < 1 s。

## ⑤ 注意点（坑、局限、适用范围）

1. **到达时刻的定义是这套算例的结构性未登记项**。轮 1–5 的表格始终并列 `t_inf` 与 `ref t_inf`，
   但从未给出"到达"的可判定定义；本审计表明中位误差在 90 %→99 % 之间被拉动 **21 个百分点**
   （+0.4 %→+21.5 %，表 2/表 3）。因此**任何**基于单一分数的 t_inf 判决都要连同定义一起报。
   论文的 $t_\infty$ 是"前缘停住"的时刻，物理上更接近 99 % 而非 90 %，但 DEM 的爬行尾使 99 % 偏晚——
   两者都不是干净的代理，正确做法是另立**速度阈值**定义（需重跑，见"未做"）。
2. **长宽比口径不闭合**（本轮新量化的既有欠账）：跑距比的分母是**实测** $r_i$，而目标律用**名义** $a$。
   因 `packing_gap`=0.02，实测柱更高（$a_{\rm meas}=0.550$ vs 名义 0.500，+10 %），
   自洽口径应两者都实测。裁决不变（仍 5/5），但"最大误差 6.0 %"这一裕度**被低估约 4 个百分点**（真实 9.9 %）。
3. **全臂标度拟合是混淆的**：把 $\Delta t/2$ 与 12 粒/半径控制例混进一条幂律拟合会得到 0.385，
   看似"标度不对"；条件在 $a\ge1$ 的主判据 4 例上得到 **0.470（r=0.991）**，与 0.5 一致。
   故**不得**用全臂拟合作标度结论——时间律在 $a\ge1$ 是**成立**的，问题集中在 $a=0.5$。
4. **证据不可复取（已缓解）**：轮 5 文档引用的 `runs/.../cases/*.json`（7.6 MB、25 件）**没有进仓**
   （被门禁滤除），仓内无法回溯其引用的 provenance。本单提交 `cases_reduced.csv`（12 KB）+ 
   逐源文件 `sha256`（`manifest_sha256.json`）作为可入库替代，机器门直接对它回归。
5. **未做（如实申报）**：① 没有重跑 DEM（容量纪律），故没有新的到达定义；② 单种子、单一初始构型
   （HCP+gap，无 jitter），无系综散布；③ 未与 Lube 原文的散点/图逐点比对（只比摘要给的两条闭式律）；
   ④ 未做多分散/形状（$r_\infty$ 与 $\phi$ 初值关系）的敏感性；⑤ 未改 `feature_ledger` 状态（见判读）。

## ⑥ 误差判定（逐项，显式回答「是否 <3 %」）

| 关键量 | 基准 | 误差 | <15 % 判据 | <3 % ? |
|---|---|---|---|---|
| 跑距 $r_\infty/r_i$（5 例，名义 $a$） | Lube 2004 闭式律 | −6.0…+5.6 %，最大 6.0 % | 5/5 通过 | **否**（最大 6.0 %） |
| 跑距（5 例，自洽实测 $a$） | 同上 | −9.9…+4.5 %，最大 9.9 % | 5/5 通过 | **否**（最大 9.9 %） |
| 埋置时间 $t_\infty$（5 例，99 % 到达） | $3(a r_i/g)^{1/2}$ | 中位 +21.5 %，最大 +53.7 % | **1/5 通过（不成立）** | **否**，且 >15 % 不可接受 |
| 埋置时间（5 例，90 % 到达） | 同上 | 中位 +0.4 %，最大 +27.3 % | 4/5（$a{=}0.5$ 越线） | **否** |
| 埋置时间（$a=0.5$，三种定义全取） | 同上 | +27.3 / +38.4 / +53.7 % | **全部越线** | **否** |
| 时间标度指数（$a\ge1$） | 0.5 | 0.470（r=0.991） | 落在 ±15 % 带内 | 差 6 %，**否** |

**结论一句话**：跑距律（第一预言）在 15 % 判据下**独立复现成立**且对长宽比口径稳健；
埋置时间律（第二预言）**在浅柱端 $a=0.5$ 不成立**（任何到达定义下都超 15 %），
在 $a\ge1$ 只在宽松达到定义下成立、标度指数正确。

## ⑦ 裁决（adversarial-review 处置）

| 严重度 | 发现 | 证据 | 处置 |
|---|---|---|---|
| **高（阻断"锚点已闭合"的范围声明）** | 第二预言 $t_\infty=3(a r_i/g)^{1/2}$ 轮 1–5 从未裁决；在 $a=0.5$ 上三种到达定义全越线（+27.3 %…+53.7 %），25 例同号（$p=6\times10^{-8}$） | 表 2、表 3；`summary.json:verdict.H_TIME_SHALLOW` | **要求变更**：锚点只能记「跑距已闭合 / 时间未闭合」，不能记"与 Lube 2004 闭合" |
| 中 | t_inf 判决被未登记的"到达定义"主导（中位误差在 90 %→99 % 间移动 21 个百分点） | 表 2/表 3；`test_time_verdict_is_definition_sensitive` | 需预登记速度阈值定义后重跑（超出本单） |
| 中低 | 目标律按名义 $a$、跑距比分母按实测 $r_i$，口径不自洽；实测 $a$ 高 10 %，使最优裕度被低估 4 个百分点（6.0 %→9.9 %） | 表 1；`test_runout_verdict_is_robust_to_the_aspect_convention` | 裁决不变；建议后续一律用实测 $a$ 求目标 |
| 低 | 全臂时间-标度拟合（0.385）混淆了收敛控制例，易被误读成"标度错误"；$a\ge1$ 上实为 0.470 | 表 3；`test_time_scaling_matches_the_law_above_aspect_ratio_one` | 已在本文档纠正口径 |
| 中（证据可复取性） | 轮 5 引用的逐例 JSON 未入库，仓内无法回溯 | `manifest_sha256.json` + `cases_reduced.csv` | **已缓解**：提交归约表 + sha256 |

**disposition**：对**跑距闭合**主张 **approve with notes**（独立复现、口径稳健）；
对**"锚点整体闭合"**主张 **request changes**（时间律未验证且在浅柱端失败）。
本审计**只读**，未改动任何历史文档、未改 `feature_ledger` 状态——是否把锚点拆成
「跑距（verified）/ 时间（open）」由调度侧决定；建议新增条目
`CASE-COLUMN-COLLAPSE-TIME`（算例池，船舶：颗粒-结构相互作用基元），
验收：**预登记到达定义（前缘速度 < 1 % 峰值）后，$a\in\{0.5,1,1.5,2,3\}$ 的 $t_\infty$ 全部 <15 %**。

**独立性声明**：审计者与被审计的轮 5 非同一单；但正本审计只做**后验**分析（同一批数据），
"独立"仅指判据与代码独立重建，不指新数据（新数据需重跑，本单未做）。
