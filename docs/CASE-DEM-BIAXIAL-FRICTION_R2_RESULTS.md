# CASE-DEM-BIAXIAL-FRICTION · 第 2 轮结果（honest 部分分）

**任务** m20304｜仓库 TensorDEM｜锚点 `CASE-DEM-BIAXIAL-FRICTION`｜判据：ref = 经典临界状态，容差 <8%
**本轮判定：honest-FAIL（数值判据未达成）**
- `fail_stage = critical-state acquisition`（未获得任一满足不变量闸门的临界状态窗）
- `failure_reason = 侧向伺服压力边界在 ε_a≈0.4 的剪切段无法建立受控围压`：`servo_velocity_limit` 过大 → 墙以 2 m/s 撞入/撞出、实际围压漂移为 σ₃/(1−ε_a)（`servo_width` 陈旧，已修）；过小（0.02 m/s）→ 伺服无量纲权力不足，实际 σ_h 冲到 3059 kPa（30× 设定值）。两种控制设定下均无"等体积 + 应力比平稳"窗，故 **ref vs got 的 8% 判定本轮不成立，不给数字结论**。

**本轮真实增量（可复核）**：
1. 定位并修复生产引擎 `biaxial_shear_band` 的**侧向伺服标度缺陷**（`servo_width` 不随试样高度更新），带回归测试；
2. 新增**临界状态判据模块**（等体积 + 应力比平稳 + 窗一致性 + 伺服闭环四闸门 + Rowe 应力-剪胀交叉校验），12 项不变量测试通过；
3. 完成 OSS/文献调研与选型沉淀（`docs/RESEARCH_CASE-DEM-BIAXIAL-FRICTION_R2.md`，`oss_solutions` 入表）；
4. 把前轮"峰值 40.36° PASS"的方法学缺陷逐条证伪（见调研文档 §0）。

## ① 问题设定与基准出处

平面应变双轴压缩：无胶结圆盘组件，侧墙摩擦 0、顶板位移控加载、侧墙常围压伺服。物理量：Mohr-Coulomb 角 `sin φ = (σ₁−σ₃)/(σ₁+σ₃)`（c=0）。

**基准（预声明，先于分析固定）**

| 编号 | ref | 值 | 出处 | 用途 |
|---|---|---|---|---|
| P（主判据） | Rowe (1962) 应力-剪胀关系在 D=0 的极限 | `φ_cv = arctan μ = 28.81°`（μ=0.55） | Rowe, *Proc. R. Soc. Lond. A* **269**: 500-527, `σ₁/σ₃ = tan²(45°+φ_μ/2)(1−dε_v/dε₁)` | 形状匹配（无咬合圆颗粒）的经典临界状态极限 |
| S（对照） | 角形石英砂临界状态角 | `φ_crit = 33°` | Bolton (1986) *Géotechnique* **36**(1): 65-78 | 量化"圆颗粒 vs 角形砂"咬合缺口 |

容差 8%（算例池）。**前轮 38° 锚点不予沿用**：与 Bolton 自式反解矛盾（D_r≈0.37 而非声明的 0.80），见调研文档 §0 D1。

## ② 方法与实现

```
run_biaxial_shear_band  (src/tensordem/biaxial_shear_band.py)            ← 复用引擎（本轮修 1 处缺陷）
  └─ stress_path (ε_a, σ_v, σ_h, q, ε_v)
       └─ biaxial_critical_state.critical_state_from_stress_path()       ← 新增：临界状态四闸门
            ├─ 尾部窗规则：ε_a ≥ 0.20，取末 20%（预声明，不选窗）+ 10/20/30% 敏感性
            ├─ isochoric:        |dε_v/dε_a| ≤ 0.02
            ├─ deviator_stationary: 窗内 q 相对变化（线性拟合）≤ 5%
            ├─ window_independent:  三窗离散 ≤ 1.5°
            └─ servo_on_target:     实测 σ₃ 与设定值偏差 ≤ 10%
       └─ biaxial_critical_state.rowe_stress_dilatancy()                 ← Rowe (1962) 交叉校验
       └─ judge_against_reference(φ, ref, 0.08)
```

**关键代码指针**：`src/tensordem/biaxial_critical_state.py:74`（`phi_deg_from_stresses`）、`:137`（`critical_state_from_stress_path`）、`:259`（`rowe_stress_dilatancy`）、`:317`（判据）；入口 `benchmarks/case_dem_biaxial_friction/analyse_critical_state.py`；运行脚本 `scripts/m20304_probe_cs2.py`。

**本轮修复的引擎缺陷**（`src/tensordem/biaxial_shear_band.py:455-472`）：侧向伺服以 `force/(servo_width·t)` 读压力，而 `servo_width` 建样后从不更新，于是伺服实际调节的是"以初始高度归一"的应力，真实围压按 `σ₃/(1−ε_a)` 漂移。实测证据（cj2626，16×32，μ=0.55，设定 100 kPa）：

| ε_a | 实测 σ_h [kPa] | 陈旧标度预测 100/(1−ε_a) [kPa] | 比值 |
|---|---|---|---|
| 0.075 | 128.1 | 108.1 | 1.19 |
| 0.165 | 141.7 | 119.8 | 1.18 |
| 0.255 | 159.7 | 134.2 | 1.19 |
| 0.315 | 174.2 | 146.0 | 1.19 |

比值恒定的 1.19 即"陈旧 `servo_width`"效应（残差 19% 为比例伺服的静态偏差，已如实记录为控制局限）。回归测试：`tests/test_biaxial_servo_pressure.py`。

## ⑤ 收敛性 / 参数敏感性（已获得的部分）

- **分辨率**：16×32 vs 24×48（cj2626，同设定）：φ_cv 6.95° vs 5.58°（差 1.4°），φ_peak 40.55° vs 37.09°（9.3% 分辨率敏感）→ 峰值本身对尺寸敏感，进一步说明"用峰值对 ref"不可靠。
- **围压**：100 → 200 kPa：φ_cv −1.82° vs 6.95°、σ_h 漂移更严重（319 kPa）→ 压力边界失控随围压加剧。
- **颗粒摩擦**：μ=0.55 → 0.30：φ_cv 6.95° → 18.48°（**下摩擦给出更高残余角**，与物理相反）→ 这一反常是本轮最硬的"控制失效"证据：低摩擦样更易重排、应变率更快，伺服更跟不上。
- **窗敏感性**：10/20/30% 三窗在 3/4 工况一致（≤1.5°），说明失稳来自压力边界而非窗选择。
- **Péclet/惯性**：I = 7.18e-4（准静态），排除率相关伪影。
