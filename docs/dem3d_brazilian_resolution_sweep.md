# 巴西劈裂试件：晶格分辨与接触弧加密扫描（m2445 两项欠账的定谳）

## 1. 案例介绍

`docs/dem3d_brazilian_hondros_closure.md` 用静力松弛给巴西（径向压缩）试件的中心场定了谳：中心主应力比 `-2.015`（Hondros 点载荷解 `-3`）、中心拉应力比 `2P/(pi D t)` 高 `+30.4%`，并明确留下两项未做：①加密晶格与接触弧后重跑（“加密后能否进 15% 未知”）；②把基准换成有限接触宽的解析参考。本单把这两项都做完，用数字代替预期：

- **能否靠加密进 15%**：不能。3.00× 加密后中心拉应力误差 从 +30.45% 只降到 +22.71%，线性外推极限 +18.91%；主应力比从 -2.0149 到 -2.0260，外推极限 -2.0331，**与 -3 的距离不随加密收缩**。
- **能否用有限接触宽基准解释**：不能。实测接触弧比 0.0223 下，有限弧闭式解只把基准下移 -0.06%（主应力比移动 -0.044%），两个数量级都不到 30% 的缺口。

因此 m2445 的 FAIL 结论**维持并升级为“结构性且已定界”**：缺口来自中心力格点非各向同性（Born 常数 C12=C44、Zener=2.33），既不是瞬态、也不是分辨率、也不是接触宽度。

| 参数 | 取值 | 说明 |
|---|---|---|
| 试件直径 D | 0.3000 m | 全部分辨率恒定（0.30 m） |
| 试件厚度 t | 0.0600 m | t/D = 0.20 恒定 |
| 晶格间距 d | 6.667–20.000 mm | 4 档，最大加密 3.00× |

| 基准 | Hondros(1959)/ASTM D3967 | 点载荷 + 有限接触弧闭式解 |

## 2. 怎么做的

### 2.1 加密族：只加密晶格，不改材料
固定 D=0.30 m、t=0.06 m，按 `d = D/(2 nx)` 加密；`nx` 取**奇数且为 5 的倍数**，这样 (a) 顶端有唯一颗粒承压（见 §5 平顶陷阱）、(b) `ny = nx/5` 为整数，`t/D = 0.20` 精确恒定。键刚度按 `k ∝ d` 缩放：中心力格点的 Born 常数标度为 `C ~ k/d`，于是每一档的`C11/C12/C44 = 433.3/233.3/233.3 kPa`、`E = 270 kPa`、`nu = 0.35`、Zener = 2.33 **逐档相同**，中心场的任何变化都只能归因于离散化，而不是材料被悄悄换了。

### 2.2 求解：静力平衡（复用 m2445 已验收的求解器）
`scripts/brazilian_lattice_static.py::solve_static_equilibrium`：对键+压板弹性势做 L-BFGS 最小化 + 20 段载荷连续化，收敛判据是物理量 `|F|_inf / d^2 <= 1e-4 Pa`。它是显式 ramp 的 `t -> inf` 极限，避免用动力学截断污染收敛判断。

### 2.3 有限接触宽基准：闭式解，不引外部软件
`src/tensordem/brazilian_reference.py`：直径上的一对集中力 `dF` 在圆心给出 `sigma = (dF/(pi R t)) [m⊗m - 3 n⊗n]`（Hondros 点载荷中心值 + 圆盘转动对称，故配对可任意倾斜）；半角 α 的均布接触载荷是这类配对的连续族，`P = 2 p t R sin α`，积分得

```
sigma_xx(0) = +(P/(pi R t)) (sin 2a - a)/sin a
sigma_zz(0) = -(P/(pi R t)) (sin 2a + a)/sin a
sigma_zz/sigma_xx = -(sin 2a + a)/(sin 2a - a)
```

α→0 精确回到 `+2P/(pi D t)`、`-6P/(pi D t)`（比值 -3）。平压板与半径 R 圆盘的接触弦宽 `w = 2 R sin α`，故实测接触弧比 `w/D = sin α`，`α = arcsin(w/D)`——基准取**实测弧比**，不是假设值。闭式解另用“弧上离散配对直接求和”独立复核（`finite_arc_centre_field_discrete`）。

### 2.4 接触弧轴与偶数分辨率对照
在固定分辨率（nx=25）下扫压板刚度，检验“接触弧比”能否作为独立变量；实测结果是它几乎不动——弧宽由离散冠部几何（单个冠部颗粒的压入深度）决定，不由压板刚度决定。因此接触宽的影响改用闭式解在 α 上直接扫出（§3.3 红线），实测只作为该曲线上的落点。另跑一档偶数 `nx=20` 作为**平顶对照**：它不是收敛点，只用来记录“偶数分辨率没有冠部颗粒”这一几何陷阱。

## 4. 注意点（坑与局限）

1. **偶数分辨率是陷阱（本单新发现）**：圆柱 `cylinder_xz` 用整数格点裁圆，偶数 `nx` 时圆心落在格点之间，冠部变成一整排等高颗粒，平压板一次性压住几十个颗粒——实测接触弧比可达 0.36–0.45，远超 manifest 的 0.2 上限，试件已经不是“径向点载荷”构型。首轮扫描（nx=20/30）因此得出 `-2.75/-2.45` 的假收敛序列，改用奇数 `nx` 后才回到 `-2.02` 的稳定值。后人做分辨扫描必须先查冠部接触颗粒数。
2. **压板刚度不能按 `k ∝ d` 缩放**：第一轮我照键刚度同样缩放压板刚度，接触模量随加密变软，接触弧比从 0.067 涨到 0.45，把构型改掉了。本单改为压板刚度固定物理值（5000 N/m，与 manifest 一致），把它作为接触弧轴的自变量。
3. **加密≠收敛**：拉应力误差随加密缓慢下降（30.5% → 23.9%），但主应力比几乎不动，说明缺口的主项是格点各向异性（Zener 2.33），离散化只是次项；把误差当成“分辨率不够”会白烧算力。
4. **有限弧闭式解的两处易错点**：`m⊗m` 与 `n⊗n` 的方向不能互换（互换会把 σxx 的符号翻掉）；上半弧求和已把每个直径配对算一次，再乘 2 就整体翻倍（本单初版即如此，被离散求和测试抓出）。
5. **局限**：静力解是同一力律的平衡态，不是实验对照；本单只判“结构 vs 分辨率 vs 接触宽度”，不标定冰的拉伸强度。各向异性连续体中心场无闭式解，故外推极限只作定界（3–4 点线性外推），不作为收敛阶证明。
