## 3 方法（三段）

**A 逐字核销审计（M1，失败）**。不做记忆抄录。脚本执行一次声明式离线检索并落审计轨迹：
仓内文献目录/globs（`*lindqvist*`、`*POAC*`、`*poac*` → 0 命中）、DNS 探针、
以及 urllib 直连 Crossref 的书目探针（**可达**，但按题名检索到的前两条是
OMAE2019-96131 与 BSI 标准，POAC'89 会议论文集不在 Crossref，无全文/无页码可取）。
同时逐字引用仓内三处既有 `WITHHELD` 声明（`docs/LEVEL_ICE_RESISTANCE_DEM.md:25`、
`docs/threefield/FORMULAS.md:70`、`src/tensordem/level_ice/formula.py:38`）。
因此 4 项三元组（引句/页码/数值）**全部为 `null`**，M1 记 FAIL —— 抄记忆里的页码等于造假。

**B 同口径换算（M2，通过）**。以仓内已分级实现（结构 REAL / 系数 WITHHELD，
`COEFFICIENT_LEDGER` SHA-256 入工件）为载体，把 Lindqvist 三项 + 附加阻力换算到 §2 口径：

```
R_c = 0.5 σ_c h² (tanα + μ/cosα)      R_b = 0.25 σ_f B h² / L
R_s = ρ_w g h² B (0.9 + 0.05 μ L/B)   R_v = 0.5 ρ_w B h V²
```

三重复算：(i) 脚本内**独立重写**的闭式 vs 仓内模块（最大相对差 3.07e-16）；
(ii) JSON 往返重算（0.0）；(iii) 由 R_total 反解 h 的二分（残差 0.0，54 次迭代）。
**α 是本案的结构性缺口**：矩形箱体为直立艏（α→90°），R_c 在此发散（脚本实测 α=89.9° 时为 α=20° 的 1442.1 倍，
工件 `R_c_diverges_at_alpha_90`），故换算只能用 α∈{15,20,30}° 的声明带——**属定义域外替代**。

**C/D 机检（M3/M4，通过）**。量纲用 M/L/T 指数代数：加法算子对不同量纲直接抛异常，
五个分量全部归约到 N（kg·m·s⁻²），因此"和式齐次"不是假设而是被强制。内部一致性 9 条：
h² 齐次性、欧拉齐次式 `h dR/dh = 2(R_c+R_b+R_s)+R_v`（中心差分，容差 1e-9）、
速度只进 R_v 且二次、R_v∝h、R_b/R_v 对 B 线性、R_s 对 B **仿射而非线性**
（槽道摩擦项含 1/B —— 本条曾在初版写错，被机检捕获后更正）、R_c 与 B 无关、
R_c 对 α 单调、α→90° 发散、无吃水依赖。

## 5 注意点与局限

1. **本单没有、也不可能有"锚验证"**：M1 失败是环境事实（无纸本、POAC'89 不在 Crossref、无全文源），
   不是执行不力。任何"Lindqvist 公式给出 X kN，与实验差 Y%"的论文写法在锚核销前都是侵权的引用。
2. **箱体几何在公式定义域之外**：α=90° 使 R_c 发散，表 4.1 的 α 带是替代值，R_total 的绝对水平
   主要由 R_c（48.8–68.8%）决定，因此换算总值的带宽（240.8–401.1 kN）主要反映 α 选择而非物理。
3. **模型形式错配**：算例是 0.80 覆盖率的破碎冰场（77 块、平均半径 4.88 m），Lindqvist 是平整冰公式；
   两者相差 2.9–4.9 倍，方向上与"破碎冰/预破冰阻力低于平整冰"的预期一致，但**不能**据此声称算术验证。
4. R_s 对 B 是仿射（含 1/B 的摩擦项），初版误写为线性被机检捕获——量纲/恒等式机检的价值即在于此。

| R_anchor vs R_domain | 领域 DEM 82.66 kN | −65.7% … −79.4% | **否 —— 且不作达标声明**（锚 WITHHELD，M5 不计门） |
