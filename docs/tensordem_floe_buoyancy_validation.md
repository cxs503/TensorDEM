# TensorDEM 2-D 浮冰浮力/湿阻模型的解析基准验证（垂荡模态）

本文件由 `scripts/benchmark_floe_buoyancy.py` 生成（数值全部来自
`outputs/floe_buoyancy/results.json`，零手抄）。仓库内 `docs/dem3d_*` 已声明
"buoyancy / floe motion / heave 不在当前模型内"，而 `src/tensordem/buoyancy_wet.py`
早在 SI-2 阶段就已合入并有单元测试，却**从未被任何求解器调用**、也从未对解析基准
复核过——本次清偿这条验证欠账。

## ① 案例介绍

二维圆盘（及由相切圆盘组成的浮冰块）在静水面上的垂荡（heave）模态。几何与参数：

| 量 | 值 |
|---|---|
| 浮冰块半径 R / 挤出厚度 t | 0.5 m / 1.0 m |
| 冰密度 rho_i / 海水密度 rho_w | 917.0 / 1025.0 kg/m^3 |
| 密度比 rho_i/rho_w | 0.894634 |
| 重力 g | 9.81 m/s^2 |
| 单盘质量 m | 720.2101 kg |
| 解析垂荡周期 T | 1.958315 s （K = rho_w g t c(h_eq) = 7414.023 N/m，h_eq = -0.337767 m） |

物理背景：海冰-船体相互作用中的碎冰浮沉、冰缘子块升沉都依赖浮力与湿阻；若浮力核
本身对不上阿基米德/线性波理论，后续冰载荷统计就没有可信边界。

## ② 怎么做的

1. **解析锚（四条，全部闭式）**：
   - 静水平衡：submerged fraction `f_sub(h) = rho_i/rho_w`，h_eq 由二分法求
     circular-segment 关系（**不用**薄板线性化 `h = -(1-rho_i/rho_w)R`）；
   - 垂荡刚度与周期：`K = -dF_b/dh = rho_w g t c(h_eq)`，`c = 2 sqrt(R^2-h^2)`，
     `T = 2 pi sqrt(m/K)`；
   - 湿阻阻尼比：`zeta = C_wet f* / (2 m omega)`，由对数衰减率反测；
   - 几何独立参考：对 submerged fraction 做**逐列弦长数值积分**（与引擎的
     `acos` 段面积公式无共享代码）。
2. **动力学积分**：`RigidHeaveFloe` 单自由度刚体垂荡，每步调用**产线核**
   `compute_buoyancy_force` / `compute_wet_drag_force`（不是重写一份力），
   velocity Verlet；周期用 y = y_eq 上穿点线性插值，阻尼比用峰值的 ln A 最小二乘。
3. **离散浮冰块**：相切圆盘六方晶格（等面积等价半径 R_eq），以及竖直侧壁的
   板状浮冰（`slab`）——后者有与分辨率无关的闭式刚度，用于严格收敛判定。
4. 工具链：PyTorch CPU 单线程；工件 `outputs/floe_buoyancy/`（JSON + 2 张 PNG +
   `summary.md`）；回归测试 `tests/test_floe_buoyancy_validation.py`（14 passed，
   14.5 s）；总benchmark 墙钟 87.6 s。

## ③ 计算结果

完整表格见下方由脚本注入的 `summary.md` 内容。要点：

- 几何：41 个偏移点上 |引擎 - 逐列积分| 最大 **6.36e-08**；
- 静水吃水：f_sub 相对误差 **≤5e-7**；薄板线性化吃水误差 **74%–94%**（须弃用）；
- 垂荡周期：幅值 0.5%–10% R 时误差 **0.000%–0.399%**；
  dt 从 T/250 到 T/2000 误差 **0.001%–0.004%**（无系统漂移）；
- 湿阻阻尼：zeta = 0.02, 0.05, 0.10 三档，误差
  **0.20%** 以内；
- 能量：无阻尼 10 周期漂移 **0.0040%**（0.5 K A^2 归一）；
- 离散浮冰块（等面积圆盘对照）：聚合吃水误差 **0.000%**，周期对自身闭式刚度误差
  **≤0.144%**，但水线弦长刚度
  K_N 与等面积圆盘差 **0.29%–10.02%**（非单调，见 ⑤）；
- 板状浮冰：band 平均刚度对恒等式 `rho_w g t A_solid/H_band` 误差
  **0.89%–1.31%**，
  但**瞬时刚度阶梯振荡 112%–113%**，
  且 **1.7%** 的水线相位上没有任何圆盘跨过水面（K≈0，中性窗口）。

## ⑤ 注意点 / 局限

- **薄板公式陷阱**：`h = -(1-rho_i/rho_w)R` 只对吃水 << R 的薄板成立；圆盘在
  rho_i/rho_w = 0.8946 时真实中心在 -0.338 R（不是 -0.053 R）。既有
  `benchmarks/ice_floe_physics.py` 的注释里仍写着该式，虽然未进入判据，仍应视为
  文档隐患（本次未改该文件，避免动他人已发布证据）。
- **离散浮冰刚度带固有偏差**：K_N 对等面积圆盘的误差 0.29%–10.02% 且非单调
  （7/19/37/61/91 颗时为 0.29/10.02/3.25/5.68/0.50%），根源是六方格点在轮廓与
  水线处的几何错配，不是分辨率不足；因此"加密网格必然改善"在此不成立。
- **阶梯振荡与中性窗口**：板状浮冰瞬时刚度随水线相位变化 ~113%，
  且小部分相位无圆盘跨越水面（K≈0）→ 小振幅垂荡在这些相位上无回复力，周期概念退化。
  这意味着离散浮冰的 heave 周期对"起始吃水相位"敏感，是本模型（非物理）固有属性。
- **无附加质量**：解析周期是模型自洽基准而不是物理预测；真实浮冰 T_phys =
  T_model sqrt(1+Ca)，Ca 未建模。
- **未接入求解器**：`compute_buoyancy_force` 仍未被 `dem.py` / `dem3d.py` 调用，
  本次验证的是核与刚体垂荡层，不是"浮冰-船体耦合"能力；三维浮力同样缺失。
- **无自由面变形 / 无辐射阻尼**：线性湿阻是唯象替代，不是波浪辐射模型。

## ⑥ 误差判定（关键量 vs 基准，逐项）

| 量 | 基准 | 实测误差 | 是否 <3% |
|---|---|---|---|
| submerged fraction（41 点） | 逐列弦长数值积分 | 6.36e-08（绝对） | ✔ |
| 静水吃水 f_sub | rho_i/rho_w（阿基米德） | ≤5e-7 | ✔ |
| 薄板线性化吃水（对照） | 精确 segment 解 | 74%–94% | ✘（该公式弃用） |
| 垂荡周期（幅值扫描） | 2 pi sqrt(m/K) | 0.000%–0.399% | ✔ |
| 垂荡周期（dt 收敛） | 同上 | 0.001%–0.004% | ✔ |
| 阻尼比（三档） | zeta = C f*/(2 m omega) | ≤0.20% | ✔ |
| 无阻尼能量漂移 | 0.5 K A^2 | 0.0040% | ✔ |
| 离散块聚合吃水 | rho_i/rho_w | 0.000% | ✔ |
| 离散块周期 | 离散闭式 T(K_N) | ≤0.144% | ✔ |
| 离散块刚度 K_N | 等面积圆盘 K | 0.29%–10.02%（形状限制） | 部分 ✘（如实记录） |
| 板状浮冰 band 平均刚度 | rho_w g t A_solid/H_band | ≤1.31% | ✔ |

**显式回答**：浮力核、静水吃水、垂荡周期、湿阻阻尼、能量守恒五项全部 <3%（多数
<0.5%）。唯一超 3% 的是"离散圆盘块水线刚度 vs 等面积连续圆盘"（最高 10.02%），
归因于方点轮廓几何而非积分/求根误差——这是离散化的物理限制，不作粉饰。
