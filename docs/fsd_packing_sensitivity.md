模块：`src/tensordem/fsd_packing.py`（新）

## 1 物理背景与对象

H1（IN11-H1，`src/tensordem/ice_channel.py`）把碎冰场建成**单分散**圆盘点阵：浮冰半径
= 一个六角晶胞的等面积圆。真实碎冰区是多分散的——浮冰尺寸谱（floe-size
distribution, FSD）跨越一个量级——而船舶穿越阻力不仅取决于密集度，也取决于 FSD。
本节点把 H1 的单分散场推广为 **FSD 驱动的多分散场生成器**，并把 FSD 当作不确定源，
量化它对清空宽度与冰阻力的敏感度。

| 要素 | 取值 / 模型 |
|---|---|
| 浮冰几何 | 平放圆盘：半径 `R`（多分散）、厚度 `t`、密度 `rho_i`（H1 默认） |
| 参照中位半径 | **5.0 m**（H1 的 4.6–5.4 m 带内；全部 FSD 族中位数解析值 = 5.000） |
| 覆盖率 φ | 0.60 / 0.70 / 0.80 / 0.85（6/10–8.5/10） |
| 域（生产） | 160 m × 80 m；穿越标定用 H1 全套接触/水动力参数 |
| 船体（穿越） | 等宽矩形 80 m × 20 m，航速 1.6 m/s，y = 40 m，x0 = −40 m |
| 穿越积分 | dt = 8 ms，5000 步（40 s 物理时间），每 100 步记录 |
| 采样 | 分层随机（randomized stratified）与 iid 两种，默认分层 |

FSD 六族（`artifacts/fsd_packing.json → families`）：

| 族 | 参数 | 中位 [m] | CV | m1 [m] | m2 [m²] | 支撑（0.1–99.9 %）[m] |
|---|---|---|---|---|---|---|
| 幂律 | κ = 1.5, 窗口比 3 | 5.000 | 0.321 | 5.387 | 32.01 | 3.11–9.33 |
| 幂律 | κ = 2.5 | 5.000 | 0.321 | 5.561 | 34.12 | 3.54–10.63 |
| 幂律 | κ = 3.5 | 5.000 | 0.303 | 5.587 | 34.08 | 3.88–11.65 |
| 对数正态 | CV = 0.3 | 5.000 | 0.300 | 5.220 | 29.70 | 2.02–12.39 |
| 对数正态 | CV = 0.5 | 5.000 | 0.500 | 5.590 | 39.06 | 1.16–21.52 |
| 双峰 | 粗 7.2 m / 细 2.2 m | 5.000 | 0.566 | 4.902 | 31.73 | 0.77–13.28 |
| H1 单分散 | δ(5 m) | 5.000 | 0.000 | 5.000 | 25.00 | 5.00 |

**参数耦合说明（必须读）**：三族幂律在“中位数固定 5 m + 支撑窗口比固定 3”下 CV 几乎相同
（0.303–0.321）——窗口比若随 κ 变化，κ 与 CV 就被混叠，敏感性无法归因。因此 κ 的效应
是“同宽度下的质量重分布”，而 CV 的效应由对数正态族单独承担。这一解耦是刻意的选择，
代价是 κ 单独作用偏弱（见 §3.4）。

## 2 方法

### 2.1 FSD 解析层

各族给出闭式 `cdf` / `quantile` / 矩：幂律在有限支撑上的截断解析矩，对数正态
`E[r^k] = exp(k μ + k²σ²/2)`，双峰为两成分混合（细料数密度份额 `w` 由二分法解到混合中位数
精确 = 5.0），`DeltaFSD` 为单分散极限。判据用矩与 512 点 Gauss–Legendre 数值积分交叉
验证（相对偏差 < 2e-4，测试 `test_analytic_moments_match_quadrature`）。

采样默认 **随机化分层**（`u_i = (i+U_i)/N` + 随机置换）：每块浮冰的边际分布正确，
但积分量的抽样方差大幅下降，场覆盖率与 m1/m2 贴近解析值。

### 2.2 放置（压实）路线

三条路线都在模块内、都可复现、都被实测：

1. **`lattice`（默认，面积匹配六角压实）**：域内生成 N 个六角格点，逐点分配浮冰；相邻对
   的目标间距 `d_ab >= λ (r_a + r_b)`，`λ = sqrt(π/(2√3 φ))`（λ = 1.033 @ φ=0.85，
   1.229 @ φ=0.60，即“该覆盖率下的六角间距”），随后在成对约束下做 Jacobi 投影松弛
   （含四壁），使大块局部挤占邻居空间；最后加 1.5 % 位置抖动并做有界消解。
   这是 H1 点阵思路对**尺寸分布**的推广。
2. **`compaction`（无序顺序压实）**：按半径降序逐块放置，每块在 `probes = 24` 个随机位置中
   取“与已放置浮冰和四壁间隙最大”处，再做局部邻域压实（投影推开邻居），最后全局碰撞消解。
   这是纯 RSA 的替代：RSA 只能拒绝，压实能把浮冰**挤进去**。
3. **`rsa`（负控）**：随机顺序吸附，连续失败 2000 次即判定堵塞。

### 2.3 生成质量度量

实测覆盖率 `ΣπR²/(L·W)`、初始最大重叠（与 `IceChannelSimulation.initial_overlap` 完全同口径
`max(0, r_i+r_j−|x_i−x_j|)`）、配位数（间隙 ≤ 0.02 m 的接触对，`2·pairs/N`）、尺寸矩
m0/m1/m2、迭代次数、生成墙钟。

### 2.4 单分散极限回归锁

退化 FSD（`CV ≤ 1e-6`，即 `LogNormalFSD(0.0)` 或 `DeltaFSD`）时，生成器**自动**分派到
`IceChannelSimulation.from_field` 并沿用 H1 关键字集（`mean_radius = 5.0`、
`radius_jitter = 0.08`、`radius_range = (2, 8)`、`thickness_range = (0.4, 1.0)`），
返回逐位相同的场与 `state_digest`。这是把“多分散生成器在 CV→0 时必须退化回 H1”变成
机器可判的回归锁，而不是口头约定。

### 2.5 穿越与敏感度

同一船体、同一 dt、同一种子，穿过 H1 单分散场与六个 FSD 场（φ = 0.80），记录
清空宽度（H1 定义：船后走廊内最小横向间隙的两倍）与冰阻力（船-冰接触力在航向的
反作用合力 `Σ F_x` 的绝对值；工件中存为 `-Σ F_x`，负号表示冰阻碍前进）。取航程后 60 %
的尾段均值作统计量。

## 3 结果

### 3.1 覆盖率控制（判据 a）：24/24 通过

24 个（6 族 × 4 覆盖率）生成场的覆盖率绝对偏差**最大 2.2e-16**（机器精度），远优于 0.5 %
判据。原因：半径集按矩匹配后只对总面积做一次乘性校正 `λ = sqrt(φ/φ_realised)`（表 `radius_correction`
= 1.0000），覆盖率是构造量，不是拟合量。

### 3.2 排列质量（判据 b）：φ ≤ 0.70 通过，φ = 0.80/0.85 部分失败（honest FAIL）

初始最大重叠 [m]（6 族取最大）：

| φ | 0.60 | 0.70 | 0.80 | 0.85 |
|---|---|---|---|---|
| max 重叠 | 0.0009 | 0.0009 | **0.125**（κ=1.5） | **1.17**（CV=0.5） |
| 判据 ≤ 0.06 | 通过 | 通过 | 失败（单族） | 失败（全族） |

0.80 时 6 族中 5 族 ≤ 0.045 m，只有 κ = 1.5（粗尾最重、`R_max = 9.3 m` 占 80 m 域宽的 23 %）
超到 0.125 m。0.85 时全部族的残余重叠 0.70–1.17 m。**这是模型边界不是实现缺陷**：

- 二维圆盘的无序随机堆积极限（RCP）≈ 0.84；本 FSD 的有效尺寸比仅 3–6，0.85 已越过 RCP。
- 三条路线独立复现该边界：RSA（0.36–0.49）、无序压实（0.80 可行 / 0.85 残余 0.9 m）、
  面积匹配六角点阵（0.85 残余 0.7–1.2 m）。
- 单独试验的“尺寸分级六角排布”（按半径分行、六角间距、最后各向异性拉伸）在 160×80 域上
  的足迹高度仍超出域高 12–20 %（行端浪费），未能达标，因此**未进入交付模块**（诚实记录）。
- 结论：8.5/10 多分散场的无重叠生成需要“按浮冰尺寸自适应剖分的广义镶嵌（power diagram
  类）”或放宽到多边形浮冰；H1 能在 0.85 做到，是因为它单分散、有序点阵（上限 0.907）。

### 3.3 尺寸矩（判据 d）：8/10 全族通过；低覆盖率的重尾族失败

φ = 0.80 时 `m1` 相对偏差：κ1.5 0.09 %、κ2.5 0.24 %、κ3.5 0.17 %、CV0.3 0.70 %、
CV0.5 0.78 %、双峰 0.02 %（全部 < 1 %）。全扫描最大 2.17 %（对数正态 CV0.5 @ φ=0.60，
N = 63）。有限尺寸扫描（`m1_finite_size_study`，φ=0.80）：

| 族 | N = 42–55 | N = 334–439 |
|---|---|---|
| 幂律 κ1.5 | 0.102 % | 0.038 % |
| 幂律 κ2.5 | 0.164 % | 0.020 % |
| 幂律 κ3.5 | 0.048 % | 0.056 % |
| 对数正态 CV0.3 | 0.123 % | 0.023 % |
| 对数正态 CV0.5 | **0.459 %** | 0.309 % |
| 双峰 | 0.314 % | 0.024 % |

即残差是**有限场抽样项**（重尾族的巨型浮冰在 N 个浮冰的场里出现不了），随 N 衰减，
不是采样器偏置。判据按“对全解析 m1”执行，故 φ=0.60 的对数正态族记为 FAIL。

### 3.4 穿越敏感度（本次的核心物理结果）

φ = 0.80，同一船体/工况/种子，尾段均值：

| 场 | 清空宽度 [m] | Δ vs H1 | 冰阻力 [kN] | Δ vs H1 | 位移 > 1 m 比例 |
|---|---|---|---|---|---|
| H1 单分散 δ(5 m) | 51.72 | — | 102.0 | — | 0.947 |
| 幂律 κ=1.5 | 60.39 | **+16.8 %** | 26.0 | **−74.5 %** | 0.971 |
| 幂律 κ=2.5 | 54.14 | +4.7 % | 73.3 | −28.1 % | 0.896 |
| 幂律 κ=3.5 | 36.70 | **−29.0 %** | 53.3 | −47.7 % | 0.906 |
| 对数正态 CV0.3 | 41.50 | −19.8 % | 153.3 | +50.3 % | 0.900 |
| 对数正态 CV0.5 | 43.62 | −15.7 % | 124.0 | +21.6 % | 0.952 |
| 双峰 | 59.25 | +14.5 % | 144.4 | +41.6 % | 0.971 |

要点：
1. **同覆盖率下 FSD 造成的阻力差异达 ±75 %**，远超 3 % 判据——密集度（tenths）不足以
   表征冰况，FSD 是一阶不确定源。
2. 清空宽度与阻力**不单调同向**：κ=1.5 场清空更宽但阻力最小（细碎料多、单块质量小，
   船首推开更易）；CV0.3 场清空最窄而阻力最大（尺寸集中、单块大，形成更强堆积拱）。
3. 双峰场（细料 47 % 数密度、粗料主导面积）阻力 +42 %，说明“大块+细碎”混合不是
   简单的插值，细料在块间起“拱填料”作用。

### 3.5 种子离散（判据 e）：失败，50.5 %

同一 FSD（双峰）、φ=0.80、三种子（20261106/07/08）的清空宽度 59.25 / 36.17 / 41.56 m，
极差/均值 = 50.5 %，远超 5 %。原因清楚：H1 的清空宽度定义是“走廊内**最小**横向间隙”，
是单块浮冰的极值统计量；8/10 场内每 100 块浮冰里只要一块离航道近，整条走廊的最小值就被
它决定。同一 FSD 的阻力离散为 144 / 67 / 94 kN（±37 %），也说明**单次穿越不足以给出
5 % 量级的清空宽度结论**——工程上应做 10 次以上种子的集合平均，或改用“走廊内平均间隙”
这类非极值统计量（下一步工作，未在本节点实现）。

### 3.6 放置路线与堵塞负控（判据 f）

| 路线 | 请求 φ | 实测覆盖率 | 是否堵塞 |
|---|---|---|---|
| RSA δ(5 m) | 0.60→0.85 | 0.490 / 0.485 / 0.468 / 0.471 | 全部堵塞 |
| RSA 幂律 κ2.5 | 0.60→0.85 | 0.383 / 0.366 / 0.434 / 0.363 | 全部堵塞 |
| 无序压实 κ2.5 | 0.80 / 0.85 | 0.800 / 0.850 | 不堵塞（0.85 有 0.96 m 残余重叠） |
| 六角点阵 κ2.5 | 0.80 / 0.85 | 0.800 / 0.850 | 不堵塞（0.85 有 0.7–1.2 m 残余重叠） |

RSA 堵塞在 **0.36–0.49**（H1 记录的 0.55 是单分散、无限域、无厚度截止的值；本实现多分散、
有限域、连续失败 2000 次判堵，故更低）。压实/点阵路线在 0.85 能“生成”目标覆盖率，
但残余重叠使其不满足判据 b，故 f 记为 FAIL（覆盖率维度通过、无重叠维度不通过）。

### 3.7 生成时间（判据 g）

固定 φ=0.80、域面积随 N 线性增长：N = 42/83/167/334/668，墙钟 5.39/5.69/6.66/3.93/8.66 s，
log–log 斜率 **0.084**。斜率远小于 1 并不表示“超线性更快”，而是**成本被固定迭代预算
主导**（初始消解 + 每步松弛的轮数上限与 N 无关，邻域搜索用均匀网格哈希是 O(N·occupancy)）。
按每浮冰成本看 128→13 µs 递减，结论是生成成本**不随 N 超线性增长**，判据通过；
但要如实说明：这是“有界迭代预算 + 网格邻域”的产物，不是渐近复杂度证明。

### 3.8 回归锁（判据 c）与工件注入（判据 h）

单分散极限：生成器 `state_digest = 684aa4c4…d316c` 与
`IceChannelSimulation.from_field` **完全相同**，`pos`/`radius`/`thickness` 逐位相同。
工件 `artifacts/fsd_packing.json` 由基准脚本一次运行程序化写出（468.6 s），
每条判据带数值、阈值、pass 标志与来源脚本路径，无手抄。

## 5 注意点与局限

1. **0.85 覆盖率的残余重叠是本节点最重要的负面结果**：判据 b/f 在 8.5/10 不通过。
   物理解释（2D RCP ≈ 0.84 + 三条路线一致复现）与实现细节（尺寸分级六角排布尝试失败）
   都写进了工件，未做任何粉饰。
2. **清空宽度是极值统计量**，种子离散 50 %；用它做 5 % 判据的结论需要集合平均，
   本节点未做（诚实记 FAIL）。
3. **FSD 族的参数耦合**：幂律族在等中位数、等窗口比下 CV 近似相同，κ 与 CV 的效应只能
   分别由幂律（κ）与对数正态（CV）承担；若要让 κ 与 CV 完全独立，需要按目标 CV 反解
   窗口比（可作后续工作）。
4. **点阵族是“有序”构造**：面积匹配六角点阵在 φ ≤ 0.70 完全无重叠，但它比无序堆积更
   有序，配位数在 φ ≥ 0.80 才升到 2–3.8（0.60 时 0–0.5，浮冰互不接触，符合 6/10 冰的
   物理图像）。阻力结果因此对应“有序多分散场”，与真实碎冰的无序拓扑仍有差距——这是
   当前整条 H1 谱系（含 H1 自身）的共同局限。
5. 穿越仅取 40 s 物理时间（5000 步），船的航程 64 m（域长 160 m），未覆盖全航道；
   阻力为尾段均值，未做 dt 敏感性（H1 已做过 dt/2 的清空宽度敏感性，可复用其结论）。
6. `probes`/`local_sweeps`/`max_overlap_target` 为可调项；默认值在 φ ≤ 0.70 给出
   机器精度级的无重叠场，在更高覆盖率下 `converged=False` 会被工件显式标出。

## 6 误差判定（逐项）

| 量 | 基准 | 误差 | 是否满足 |
|---|---|---|---|
| 覆盖率（判据 a，0.5 %） | 目标 φ | ≤ 2.2e-16 | **是** |
| 初始最大重叠（判据 b，0.06 m） | H1 同口径 | φ≤0.70: ≤ 0.0009 m；0.80: 0.125 m；0.85: 1.17 m | φ≤0.70 是，0.80/0.85 **否** |
| 单分散回归锁（判据 c） | H1 场/digest | 逐位相同 | **是** |
| 尺寸矩 m1（判据 d，1 %） | FSD 解析 m1 | 0.02–2.17 %（8/10 全族 ≤ 0.78 %） | 8/10 是，低覆盖率重尾族 **否** |
| 种子离散（判据 e，5 %） | — | 50.5 % | **否** |
| 0.85 可生成（判据 f） | RSA 堵塞为负控 | 覆盖率可达、无重叠不可达 | **否** |
| 生成时间（判据 g） | 线性 | log–log 斜率 0.084 | **是**（有界预算口径） |
| 程序化工件（判据 h） | — | 一次运行写出 | **是** |

对“是否 < 3 %”：本节点无实验/文献基准值可直接对标（H1 亦无航道清空宽度的实测对标，
其自身以解析解与守恒律作验证）。可对标的解析基准是 FSD 矩（m1/m2 vs 闭式解析，
8/10 场 < 0.8 %，**是**）与覆盖率（**是**）；FSD 敏感度本身是新结果，其误差结构由
种子离散（50 %）主导，故**不能声称 3 % 精度**，只报告量级与方向。

## 7 结论与后续

- 交付了可复用的多分散碎冰场生成模块（六族 FSD + 三条放置路线 + 全套质量度量 +
  单分散回归锁），覆盖率控制达机器精度，H1 回归锁逐位通过。
- 定量结论：**同密集度下 FSD 使冰阻力变化 −75 %…+50 %、清空宽度变化 −29 %…+17 %**，
  FSD 是冰阻力的一阶不确定源；密集度（tenths）不足以表征冰况。
