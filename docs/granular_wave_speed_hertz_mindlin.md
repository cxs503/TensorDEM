# 颗粒介质微-宏观波速验证：Hertz–Mindlin 有效介质与 v ~ p^(1/6)

**节点**：IN98-N03 · **仓库**：TensorDEM · **模块**：`tensordem.granular_wave`
**工件**：`artifacts/granular_wave/wave_speed_study.json`、两张图
**脚本**：`python scripts/run_granular_wave_speed.py`
**测试**：`pytest tests/test_granular_wave_speed.py`（18 项）

---

## 1 物理背景与目标

颗粒介质的宏观弹性来自**接触网络**而不是晶格键：两球间的 Hertz 法向刚度
`k_n = 2E*√(R*δ)` 与接触重叠量 `δ` 相关，而 `δ` 由围压 `p` 决定
（`F ~ E*√(R*)δ^{3/2}`、`p ~ Z F /(面积)`），因此

```
k_n, k_t ~ p^(1/3)   ⇒   K, G ~ p^(1/3)   ⇒   v_p, v_s ~ p^(1/6)
```

这条 **1/6 幂律**是 Hertz–Mindlin 有效介质（Digby 1981；Mavko 等《Rock Physics
Handbook》"Hertz-Mindlin" 模型）最强的可证伪预言：它把**微观接触参数**
`(k_n, k_t, μ, Z)` 与**宏观波速**定量连起来，且指数与材料常数无关。

本节点的目标：给 TensorDEM 装上「微-宏观波速测量工装」，在受围压的摩擦球堆积上
实测 `v_p(p)`、`v_s(p)`，验证：

* 双对数斜率 = 1/6；
* 绝对值与 Digby 预测一致；
* 由 `v_p/v_s` 反算的泊松比与接触参数设定自洽；
* `μ→0` 时剪切刚度塌陷（无摩擦球堆积的**边缘刚性**）而压缩刚度不塌陷；
* 尺寸无关性。

## 2 方法

### 2.1 接触律（`engine.py`）

| 量 | 式子 | 说明 |
|---|---|---|
| 法向力 | `F_n = (4/3)E*√(R*)δ^{3/2}` | Hertz 1882，`E*=E/(2(1-ν²))`（同质球） |
| 法向切线刚度 | `k_n = 2E*√(R*δ)` | 与上式严格互为导数 |
| 切向刚度 | `k_t = 8G*√(R*δ)` | Mindlin 无滑移，`G*=G/(2(2-ν))` |
| 库仑上限 | `|F_t| ≤ μ F_n` | Cundall–Strack 滑移投影（滑动时把切向状态拉回摩擦锥） |
| 刚性压板 | `E*_w = E/(1-ν²)`, `G*_w = G/(2-ν)` | 球-刚体极限 |
| 耗散 | 法向/切向 dashpot，临界阻尼比 ζ | 接触级，不引入全局阻尼 |

转动自由度保留（`I = 2/5 mR²`），这是 `μ→0` 负控成立的前提：无摩擦光滑球的接触
网络只有法向约束，切变是一个机构（边缘刚性），剪切刚度趋于零而体积模量不塌陷。

### 2.2 围压伺服（复用真三轴工装）

压力控制器直接调用真三轴协议的**同一函数**
`tensordem.dem3d_triaxial.servo_velocity(error, gain, v_max)`
（本次把该速度比例律从 `TriaxialRunner._servo` 中提取成模块级纯函数，两条流程共用，
`tests/test_granular_wave_speed.py::test_servo_law_is_shared_with_true_triaxial`
锁定该复用）。围压由六块压板的法向反力测得（压板实际感受到的力），并逐轴报告
各向异性。

### 2.3 试件制备（关键，两次踩坑）

松散格点 + 硬接触是最坏的起点：**最先接触的少数颗粒承担全部荷载**（"轻力链"），
压力目标被满足时大多数颗粒仍未接触，之后再改变盒子只会把堆积**卸载到解卡状态**或
把储能放大到爆掉。因此制备分两步：

1. **软接触压实**：接触刚度取 `E/50`、时间步放大 `√50/1.75`（仍稳定）、dashpot 加硬、
   速度淬火，用仿射应变增量把格点压到略过挤点；
2. **等刚度比升硬**：把 `E/50 → E` 平滑升回。因为 `δ ~ (p/E)^{2/3}`，在
   `p/E` 保持不变的路径上升硬，几何几乎不动，不会产生"升硬→膨胀→解卡"的失稳。

踩坑记录（两条都是真实缺陷，已修）：

* **陈旧邻居表**：弛豫循环里只在每个应变子步重建一次邻居表，颗粒在 600 步内可移动
  超过 skin，导致颗粒**穿模**（实测最近邻距离降到 `0.07×2R`，max overlap > 1R），
  压力被少数穿模对支配。修法：所有弛豫循环每 20 步重建邻居表；
  修前/修后判据：同一路径 `mean_contact_overlap` 由 0.48R（穿模）回到 0.036R（正常）。
* **压板初始间距用平均半径**：最大颗粒一开始就嵌入压板 0.15R，产生 ~10 kN 伪初始力。
  修法：压板放在最外层球心外 `R_max` 处。

### 2.4 宏观量测量

| 量 | 方法 |
|---|---|
| 围压 `p` | 六块压板法向反力 / 面积，逐轴报告 |
| 配位数 `Z` | 几何接触（`δ > 1e-4 R`），`Z = 2N_c/N`；同时给力承载 `Z` |
| 孔隙率 `φ` | `1 - Σ(4/3)πR³ / V`，`V` 取六压板围成体积 |
| 静剪切模量 `G` | 上下压板反向切向位移 `γ=2e-5`，弛豫后由切向反力算 `τ/γ`（与波源耦合无关） |
| 静体积模量 `K` | 六个恒体积状态的 `p(ln ρ)` 三点差分（`K = dp/dlnρ`） |
| 波速（静态路线） | `v_p=√((K+4G/3)/ρ)`、`v_s=√(G/ρ)` |
| 波速（动态路线） | 脉冲走时（互相关，抛物线亚步插值）＋正弦扫频（锁相相位斜率） |
| 衰减 `Q⁻¹` | 峰值幅值比 与 谱比斜率 两种估计 |

## 4 注意点与局限

1. **动态波速测量在本箱尺下不可靠**。试件只有 ~50 个颗粒直径、约 3 个接触振荡周期
   的走时，脉冲一走就被箱体整体模态与力链"超音速"前驱污染：实测两个接收层的
   互相关滞后经常为**负**（远层先动），扫频相位斜率同样为负。这类结果在
   `PulseResult.valid=False` / `SweepResult.valid=False` 中如实标记并把速度写成
   `NaN`，不做任何修饰；判据 (b)(f) 因此 **FAIL**。要真正做动态波速，试件需要
   ≥ 200 个颗粒直径（走时 ≫ 脉冲宽度 ≫ 接触周期），属于后续算例。
2. **静态路线给出的是长波极限（低频）模量**，它与有效介质理论对标正是恰当的；
   但它不是"声速"的独立测量，判据 (b) 的"两法互证"只能由动态路线完成。
3. 试件是**由格点压实**得到的，配位数偏低（Z≈4–6）且有残余晶格序；理想随机密堆
   （RCP）需要更长的压实路径或专用堆积生成器，见 §6。
4. 全部状态为**恒体积**（oedometric）压入，压力是输出量；伺服只用于"若放开盒子会
   怎么动"的对照，不让压力控制决定状态（近边缘堆积上比例伺服会过冲/解卡）。

后续（已定位的具体缺口）：

* 试件尺度 ≥ 200 颗粒直径 + 更软的颗粒材料（降低 `v_p`，拉长走时/接触周期比），
  使动态两法互证可判；
* RCP 堆积生成（Lubachevsky–Stillinger 膨胀法或重力沉积），把 Z 提到 6 附近；
* 衰减 `Q⁻¹` 的第三种独立估计（共振峰半功率带宽）。
