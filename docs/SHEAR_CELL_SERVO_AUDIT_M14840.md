## 1. 结论先行（三条，全部有数字）

| # | 级别 | 结论 | 证据 |
|---|---|---|---|
| **F1** | 缺陷（已修） | 压板伺服在**实验室参考系**上做速度阻尼，离散稳态是 `ΔN = M_p·v_z·(1-e^{-dt/τ})/dt`，即**只要压板还在跟随床面蠕变（v_z≠0），载荷必然带一个与 v_z 成正比的偏置**。m14721 把它记为"床面致密蠕变导致的装置偏置"，实测 `v_z = 1.49e-3 m/s`、`ΔN_实测 = 0.324 N`、拖曳律预测 `0.298 N`（差 8.2%）⇒ 是**控制器增益/离散化误差**，可解析、可修。 | `scripts/m14840/probe_servo_offset.py` 输出；表 2 |
| **F2** | 缺陷（已修） | 报告的剪切率/惯性数用**名义 fill_height = 0.05 m**，压实后床高实测 **0.0293–0.0297 m** ⇒ γ̇ 被低估 **1.68×**（名义 1.0 s⁻¹，实际 **1.68 s⁻¹**），I 同比低估。"准静态区 I ≲ 0.3"的判定因此建立在错的分母上。 | 表 3；`simulate_shear_cell` 新增 `bed_height_mean / shear_rate_actual / inertial_number` |

## 3. 怎么做的

1. **重建执行路径**：`prepare_bed` → `simulate_shear_cell`（symplectic Euler，力在 t）→ 伺服更新 → 积分 → 牵引测量。逐行核对量纲/符号/参考系。
2. **把"偏置"做成可判伪的预测**：由伺服更新式解析出离散稳态 `ΔN = M_p·v_z·(1-e^{-dt/τ})/dt`；用 `diagnostics=True` 记录的 `vz` 做零参数检验（F1）。
3. **修正伺服参考系**（`servo_mode="bedref"`）：阻尼改为相对**压板所骑床面颗粒的平均法向速度** `v_bed`（`fn_p>0` 的颗粒），于是稳态蠕变时阻尼不耗散、`ΔN → 0`。`servo_mode="drag"` 保留 m14721 的实验室系律（`ref=0`，逐位一致）作对照。
4. **修正速率记账**：从稳态窗内的床面高度均值给 `bed_height_mean`，据此报 `shear_rate_actual` 与 `inertial_number`。
5. **加稳态门**：`stationarity_tol` 打开时，`|drift| > tol` 的运行被有效性门拒绝（不给出 μ），把"窗平均冒充稳态值"堵死。
6. **A/B 证据矩阵**：`scripts/m14840/run_matrix.py` 三级应力 × 两种伺服模式 + γ=1.00 长剪切，结果落 `artifacts/shear_cell_m14840/*.json`；图表与全部表格由 `scripts/m14840/make_figures.py` **程序化注入**（零手抄）。

## 5. 注意点（坑 / 局限 / 适用范围）

1. **不要用单点 μ 作判据**：78 颗粒、压板接触数 3–10 个，μ 的块标准误 ≈ 0.04（20%），且 τ 仍漂移。要判"μ vs 实验 <10%"，先得让装置进稳态：床层 ≥ 6–8 层、颗粒数 ~10³、仍用应力伺服 + `stationarity_tol` 门。
2. **A/B 的协议口径**：本单矩阵用 `consol_time = 0.03 s`（案例默认），m14721 正文用 0.04 s；两种模式的差别是同一口径下的差分，故 F1 结论不受影响，但**绝对数值不可与 m14721 表逐格对比**。
3. **artifacts 里的 I 列**按名义 γ̇ 记账（这正是被审计的旧约定，测试用 `rel=2e-2` 锁定该事实）；修正值 I_actual = I_nominal × 1.68 见表 3 最后一列。
4. **`inertial_number` 的量级**：γ̇=1.68 s⁻¹、σ_n≈2–8 kPa 时 I ≈ 0.006–0.019，比 m14721 正文标注的 0.14–0.28 小两个量级——该标注按 `γ̇·2r/√(σ/ρ)` 与本文参数**不可复算**，属报告级错误（不影响代码），建议后续单按本文公式重出该行。
5. 适用范围：I ≲ 0.3 准静态、单分散球、无黏结；`bedref` 伺服只解决**载荷保持**，不解决**稳态性**（F3 仍在）。

## 6. 误差判定（逐项，显式回答"是否 <3%"）

| 关键量 | 基准 | 误差 | <3% ? |
|---|---|---|---|
| σ_n 保持（bedref，2000/4000/8000 Pa） | 伺服目标值（可机器判定的精确基准） | −0.59 / −0.21 / −0.12 % | **是** |
| σ_n 保持（drag，同上） | 同上 | −30.88 / −3.56 / −5.44 % | 否 |
