# Audit — m20055 Beverloo D5: dt-convergence ladder and the size of the discretisation error

Generated by `benchmarks/m20055_beverloo/dt_ladder.py --analyse` from `runs/m20055_beverloo_dt_ladder/*.json`. No number below is typed by hand.

*Design*: `prereg/p20055_dt_ladder.md` (written before the runs). *Reference*: Beverloo (1961), C = 0.58, k = 1.4 (`cited, NOT re-digitized: no copy of the 1961 paper and no outbound network in this worktree, so the original table/points could not be re-read programmatically`), C-range [0.55, 0.6], k-range [1.2, 1.6].

## 1. Why this ladder was run

The filed m20055 verdict is an honest FAIL of the primary case D5 (+20.6 %). The filed matrix also contains a single dt/2 arm that moved the answer by 8.9 % of the reference toward the literature value. A two-point sensitivity is not a convergence statement, so the verdict could not be separated from a discretisation artefact. This ladder quantifies it.

## 4. What the k-range alone can explain

A single orifice diameter makes the comparison sensitive to the literature's own k-uncertainty through (D − k d)^(5/2). At this case that band is -8.9 … +20.4 % of the reference. Consequently a single-D/d error bar cannot be read as a DEM defect smaller than that band; the honest statement is the band, and a joint (C, k) fit over ≥ 3 orifice diameters (`tensordem.silo_discharge.beverloo_fit`) is the only way to make the pair identifiable from DEM data alone.
