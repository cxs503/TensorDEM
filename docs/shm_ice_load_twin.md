## 1. 案例介绍

### 1.1 物理背景

冰区航行时船体梁只能测到应变, 而疲劳评估、操作决策与结构安全需要的是**冰载荷本身**。本节点在 TensorDEM 中建立从应变监测数据到冰载荷时历、刚弹分离、疲劳累积、以及与 DEM 预报在线对比的完整反演孪生链路, 并把上游 `tensordem.whipping`（已验证的干/湿模态、模态精确积分器、ASTM 雨流计数、DNV-RP-C203 S-N 曲线、DEM 冰载荷记录生成器）作为正问题算子复用。

反演链（每 1 s 采集窗口在线执行）:

```
eps(x_k,t)  --modal filter-->  q_n(t)  --EOM inversion-->  p_n(t)  --projection-->  F_ice(t)
                                  |                        |
                                  |                        +--> <0.5 Hz / >0.5 Hz 刚弹分离
                                  +--> sigma = sum w_n q_n --> 雨流计数 --> Miner 累积 D(t)
F_ice(t)  <--在线对比-->  DEM 预报 (相关系数 / 峰值误差 / 能量误差, >30% 触发模型修正)
```

## 2. 方法、流程与关键设置

### 2.1 结构降阶模型 ROM

干模态: 自由-自由梁 2 节点 Hermite 单元一致质量矩阵（60 单元），`K phi = omega^2 M phi` 去掉 2 个刚体模态后质量归一化; 湿模态: 以 2-D BEM 剖面附连水（`whipping.pipeline.hull_added_mass_per_length`）在干模态基上做 Ritz 缩聚 `(I + M_a) a = (1/omega_wet^2) diag(omega_dry^2) a`。该广义问题通过对 `I + M_a = C C^T` 的对称变换求解（`A = C^-1 K C^-T`），避免对非对称矩阵 `(I+M_a)^-1 K` 直接 `eigh` 引入的单侧三角误差 —— 与上游 `whipping.modes.wet_modes` 直接求解相比频率散布为 0.53 %（审计项, 见 §5）。解出的湿模态再归一化为广义质量 1, 于是每阶运动方程为 `q''+2 zeta omega q'+omega^2 q = phi_n(x_F) F(t)`。

应变模型: `eps(x_k) = -y_k w''(x_k)`, 即 `H[k,n] = -y_k phi_n''(x_k)`; 载荷反演用单位点载荷的最小残差投影 `F = phi^T p / (phi^T phi)`, 空间分布估计 `f(x) = sum_n p_n phi_n(x) / sum_n phi_n(x_F)^2`。

### 2.2 模态滤波

逐样本最小二乘 `q = argmin ||eps - H q||^2 + lambda ||q||^2`（默认 lambda=0, Gram 矩阵条件数超限时拒绝而非静默放大）。解析锚（单模态正弦）另提供**谐波（锁相）估计器**: 在 `q_n` 上做 `a0 + b sin(omega_n t) + c cos(omega_n t)` 的滑动窗口最小二乘, 窗口 5.0 s; 白噪声按 `~sqrt(2/(T fs))` 衰减, 纯正弦无偏。

### 2.3 载荷反演与带宽

由 `q(t)` 数值求导（Savitzky-Golay, 窗长 51 点 = 0.51 s, 3 阶多项式）得 `q'`、`q''`, 代入运动方程得 `p_n = q'' + 2 zeta omega q' + omega^2 q`。求导器的带宽 1.73 Hz; 二次求导对噪声放大 ∝ f², 因此**比较一律在反演自身带宽内进行**: 参考时历与估计时历经同一 2 Hz 零相位 Butterworth 滤波后统计峰值/能量/相关系数, 同时**如实报告未滤波 (raw) 的峰值误差**。

### 2.4 刚弹分离 / 疲劳 / DEM 在线对比

刚弹分离: 4 阶 Butterworth 低通 0.5 Hz, 高频带取严格补集（`elastic = x - rigid`）, 分类用**波动（AC）能量**占比（静态偏置属于准静态带, 已在诊断字段单独给出）。疲劳: 流式 ASTM E1049-85 雨流计数（带迟滞门 `gate = 1.0 MPa` ≈ 4.85 µε 钢应变分辨率）+ DNV-RP-C203 D 曲线, 闭合环的损伤在闭合瞬间增量累加（成本与记录长度无关）; 同时给出 `damage_closed`（单调, 运行显示用）与含残段的 `damage`（与批量雨流可比的终值）。DEM 对比: 每个冰事件统计相关系数、峰值误差、能量误差; 任一超 30 % 或相关系数低于 0.70 即触发模型修正并给出幅值修正增益。

## 5. 注意点 / 局限 / 适用范围

1. **解析锚必须用锁相估计器**: 逐样本最小二乘在 20 dB 下误差 4.79 %（噪声底, 与 ||A||_F·sigma_noise 成比例）; 谐波估计器用 `sqrt(2/(T fs))` 的相干平均把它压到 0.415 %。两者都实现、都报告, 不可相互冒充。

2. **瞬时卸放锯齿是反演的极限工况**: 0.5 Hz 锯齿的卸载是测度零的跃变, 其能量在 1.7 Hz 以上, 超出二次求导的可观测带宽; 该工况下疲劳损伤误差可达数十个百分点（§3.4 最后一行）。连续挤压循环（工程上真实冰载的有限升/降速率）误差 <10 %。

3. **DEM 记录是形状而非量纲**: 二维模型尺度压入算例的力（~4 kN）通过单一力因子缩放到 10 MN 满尺度峰值; 几何/应变率相似律未建模（未做 Froude/Cauchy 缩放）, 因此只使用其时历形状与频谱, 不与全尺度 DEM 冰载的绝对量级对标。

4. **载荷作用位置视为已知**（x_F=0.06L）。位置估计属上游贝叶斯校准节点的工作; 本模块的 `load_field()` 给出的是在已知作用点假设下的分布载荷估计。

5. **反演带宽 1.7 Hz 是 100 Hz 采样 + 20 dB 噪声下的设计点**: 提高采样率或 SNR 可放宽; 带宽上限由二次求导的噪声放大 ∝ f² 与 SG 窗长共同决定, 报告了带宽而非隐藏它。

6. **湿模态求解细节**: 对非对称矩阵 `(I+M_a)^-1 K` 直接 `eigh` 会单侧取三角, 与本文的对称变换解法相比频率散布 0.53 %; 本模块采用对称解法并把该散布作为审计数字输出。

7. **雨流门 (1 MPa)**: 反演应力含残余噪声, 无门时噪声摆动会造出上万伪半环并使损伤上偏数倍; 门与传感器分辨率挂钩（4.85 µε 钢应变）, 门=0 时与批算法逐环一致（已在测试中证明）。
