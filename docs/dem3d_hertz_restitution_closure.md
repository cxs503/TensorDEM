# DEM3D Hertz 分支的恢复系数闭合：`restitution_coefficient` 是不是物理参数？

协议 `tensordem-dem3d-hertz-restitution-closure-v1`。verifier 席自找活（验证欠账类）。

## 1 案例介绍

**物理背景与要判定的问题。** `tensordem.dem3d` 的法向接触有两条分支：legacy 线性罚函数（默认）与 Hertz 非线性（`contact_model="hertz"`）。两者共用同一个恢复系数→阻尼映射 `zeta = |ln e| / sqrt(pi^2 + ln^2 e)`、`gamma_n = 2 zeta sqrt(m_eff k)`，但 Hertz 分支的 `k` 是**随重叠变化的割线刚度** `k_s(delta) = 2 E* sqrt(R_eff) sqrt(delta)`，于是等效阻尼 `gamma ~ delta^(1/4)`（Tsuji 型非线性阻尼）。线性弹簧-阻尼器理论只对常刚度成立，所以「`restitution_coefficient` 是否真的等于实测恢复系数、且与冲击速度无关」必须实测。在本单之前，引擎级恢复系数证据只覆盖线性分支（`docs/dem3d_restitution_verification.md`），而 `docs/dem3d_hertz_contact_verification.md` 的局限节写着「阻尼沿用 legacy 绝对 `c_n`，冲击恢复系数无法通过物理参数控制」——本单判定这句话是否仍然成立。

**几何与参数（两球对撞，等径等质量）。**

| 参数 | 数值 |
|---|---|
| 颗粒半径 R | 0.025 m |
| 密度 rho | 917 kg/m^3 |
| 杨氏模量 E / 泊松比 nu | 1e+09 Pa / 0.3 |
| 折合模量 E* | E / (2 (1 - nu^2)) |
| 有效半径 R_eff | R / 2（等径球） |
| 折合质量 m_eff | m / 2（`dem3d.py` 的等质量假设） |
| 冲击速度扫描 | 0.1, 0.25, 0.5, 1, 2 m/s（每球，相对闭速度 2v） |
| 恢复系数目标 | 0.5, 0.8 |
| 常阻尼标度锚的阻尼 | c = 60 N s/m |

黏结拓扑全部置死（`sim.alive[:] = False`），只保留一个无黏结接触对；压头（`tool`）停在 10 m 之外，其余 6 个格点球停放在 1 m 之外，保证接触集恰为一对。

## 2 怎么做的

三组基准都不依赖被测代码：

- **R1 独立 RK4 参考解**：在相对坐标积分同一条接触律 `m_eff ddot(delta) = -(k_s(delta) delta + gamma dot(delta))_+`，代码路径与 `dem3d.py` 完全不相交；它自身的时间步收敛性单独核验。
- **R2 解析标度**：常阻尼 + Hertz 弹簧时 `delta_max ~ v^(4/5)`、接触时长 `~ v^(-1/5)`，故耗散能量 `dE ~ c v^(9/5)`、`1 - e ~ c v^(-1/5)`，双对数斜率应为 **-0.2**。该指数只由 Hertz 运动学的量纲分析得到，与两个实现都无关。
- **R3 弹性极限**：`c = 0` 时 `e = 1` 精确，且峰值重叠满足 `delta_max = (15 m_eff v^2 / (16 E* sqrt(R_eff)))^(2/5)`。

**引擎侧测量**：两球沿 z 相向而行，逐时间步推进；以 `(v_1 - v_0) . n` 取闭速度，接触结束（分离距离重回 2R 且转为张开）时取反弹速度，`e = |u_out| / |u_in|`。工具链：`scripts/verify_dem3d_hertz_restitution.py` → `docs/dem3d-hertz-restitution/{results.json,checks.csv,figures/}`；本报告由 `scripts/render_dem3d_hertz_restitution.py` 从该 JSON 程序化注入。

## 4 误差判定（逐项，回答「是否 < 3%」）

| 关键量 | 基准 | 相对误差 | 是否 < 3 % |
|---|---|---|---|
| 弹性极限 e | 1（精确） | 5.196e-07 | 是（机器精度量级） |
| 弹性峰值重叠 | 闭式 delta_max | 74.1 % | **否** |
| 常阻尼标度指数 | -0.2 | 27.5 % | **否** |
| 线性分支 e 闭合（对照） | e_target = 0.5 | 10.6 % | **否** |
| Hertz 分支 e 闭合（全速度） | e_target | 16.4 % | **否** |
| 引擎 vs 独立 RK4 | RK4 | 0.102 % | 是 |

**判定：实测偏差超过 3 % 判据，「e 是物理参数」在 Hertz 分支上并未闭合（见 §5）。**

## 5 注意点与局限

- **只覆盖等径等质量对撞**：`dem3d.py` 里 `m_eff = cfg.mass / 2` 是写死的等质量折合质量。颗粒与固定支撑（`fixed`）碰撞时正确折合质量是 `m`，本次未验证该情形，属已知建模近似。
- **速度区间有限**：扫描覆盖 0.1–2 m/s。更低速度受无黏附截断 `clamp_min(0)` 与离散化地板影响，更高速度越过准静态假设。
- **这是数值一致性验证**：它证明引擎按声明的接触律产生声明的恢复系数，不证明冰-冰/冰-钢的 e 取值正确（本仓无实验数据）。
- **默认数值路径不变**：本单不改任何接触律，只把「e 物理可控」从 WITHHELD 升为实测 REAL，并修正 `docs/dem3d_hertz_contact_verification.md` 里过期的局限陈述。
