**预注册**：`prereg/rubble_rheology_prereg.json`（含 Amendment 1）

## 1. 物理背景与目标

碎冰（rubble）堆积体是离散介质，但船舶冰阻力与冰载荷模型需要**等效连续介质参数**。本节点把
DEM 颗粒场 + 接触力集合转换为三件可用于连续模型的量：

1. 守恒孔隙率场 φ(x,t)（网格 h = 5 d₅₀）；
2. 力链网络统计：强/弱链划分、配位数 Z、组构各向异性 A_c；
3. 宏观流变点 (I, μ)，I = γ̇ d₅₀/√(P/ρ)，μ = τ/P，并拟合二次律
   μ(I) = μ₀ + α I + β I²，得到等效黏度 η = μ P/γ̇。

## 2. 方法

### 2.1 后处理（`rubble_postprocess.py`，纯 NumPy/SciPy，与求解器解耦）

| 量 | 做法 | 证据等级 |
|---|---|---|
| φ(x,t) | 圆–矩形交面积**闭式解**（累积测度 Q(X,Y) 的容斥，`circle_box_area`）把每个颗粒的实体面积精确分摊到网格单元；周期轴用「不裁剪单元索引 + 取模折叠」，闭壁用裁剪 | REAL |
| 孔隙守恒审计 | `porosity_conservation_audit` 从**场本身**重新积分并与独立计算的全局孔隙率比对（判据 (a) ≤1e-6） | REAL |
| Voronoi/Delaunay | 中心点 Voronoi 镶嵌（周期像 / 闭壁镜像），φᵢ = 1 − A_disk/A_cell；Delaunay 边长/d₅₀ | REAL（多分散下为孔隙尺度描述量，非守恒场，已在代码中声明） |
| 应力 | Love–Weber 位力：σ = −(1/V)Σ f⊗b，压为正，Pa = 2D 应力/厚度；P = tr σ/2，τ = (σ₁−σ₂)/2，μ = τ/P | REAL |
| 力链 | 按接触力分位（默认上 20%）划分强/弱链；方向直方图（折叠到 [0,π)）；结构张量 R = ⟨n n⟩，A_c = 2(λ₁−λ₂)/(λ₁+λ₂)；强子图连通分量与横跨判定 | REAL |
| μ(I) 拟合 | 最小二乘二次拟合，报 R²、残差标准差、参数标准误、adj. R² | REAL |

**判据 (e)（无接触时 μ(I) 未定义必须报错）是结构性保证**：`contact_stress`、`force_chain_statistics`、
`inertial_number`、`rheology_point`、`fit_mu_i_quadratic` 在接触集为空 / P≤0 / 数据点不足时抛
`RubbleNoContactsError` / `RubbleRheologyError`，不存在「静默返回 0」的代码路径。

### 2.2 DEM 场景（`rubble_scenarios.py`，基于 `tensordem.granular2d`）

| 场景 | 构型 | 应变率控制 | 等效剪切率 γ̇ = √(2 D:D) |
|---|---|---|---|
| 简单剪切 `couette_shear` | 平面应变、x 周期、上下**粗糙滑动壁**（±v/2，几何不动；为此给引擎新增了逐段壁面速度，见 §5） | 壁速差 v | 主体速度剖面最小二乘斜率（**实测**，不用名义 v/H） |
| 平面应变压缩 `biaxial_compression` | x 周期 + 活塞（顶壁）；**等面积**：x 方向按活塞因子同步拉伸（固体分数恒定） | 轴向应变率 ε̇ | 2\|ε̇\| |
| 碎冰航道 `ice_channel` | 周期航道 + 固定船体，碎冰场受拖曳漂移流过（`make_channel_system`） | 漂移速度 | 自由航道平均流向速度剖面的斜率 |

**单元试验（element test）必须均匀且定常**，因此：
* 压缩用**等面积**平面应变（改动原因见 §5 的实测对比：受限压缩池在 φ→0.9 后应力比永不进入定常，μ 被系统性压低到 0.07–0.15）；
* 航道场景是**非均匀、拖曳主导**的复合流动，只作为**样本外验证**，不进入标定（预注册 Amendment 1 已记录）。

每 run（一场景 × 一速 × 一 seed）取样 10–12 个定常快照；每个快照在**同一本体切片**（离壁 ≥3 r̄）
上同时取 γ̇ 与应力，保证 (I, μ) 自洽。

## 3. 结果（数值见 `artifacts/rubble_rheology/summary.json`，报告表由程序注入）

* 60 runs / 11 个 (场景, 速率) 条件，d₅₀ = 0.0235 m，ρ = 917 kg/m³。
* **判据 (a)**：全部 run 的孔隙率场守恒误差 ≤ 1e-12（浮点舍入），远优于 1e-6。
* **判据 (b)**：全部 run 强弱链接触数残差 = 0，力求和相对残差 ≤ 1e-10；强链（上 20% 接触）承担 41–51% 的载荷。
* **判据 (c)**：
  * 简单剪切单元试验：μ = 0.250 + 1.311 I + 0.904 I²，R² = 0.990，残差 σ = 0.0050（adj. R² = 0.979）→ 满足；
  * 两单元试验合并（预注册主判据）：R² = 0.759，残差 σ = 0.0177 → **不满足（honest FAIL）**；
  * run 级（预注册变体）：R² = 0.626 → 不满足。
  * 失败原因是**结构性**的：低 I 端压缩条件比剪切律高 0.02–0.03（应变路径/Lode 角依赖），残差不是随机的。
* **判据 (d)**：参考态 P = 10 kPa、γ̇ = 0.1 s⁻¹ → μ = 0.2608，η = 2.61e4 Pa·s ∈ [1e3, 1e5] ✓（2–20 kPa 均在窗内，50 kPa → 1.3e5 略微出窗，已在表中如实列出）。
* **判据 (e)**：负控测试通过（无接触抛错；损坏场被守恒审计判负；重叠强弱链被自洽审计判负）。
* 微结构：Z = 2.64–3.38（二维近似等静定带），A_c = 0.064–1.11（随 I 增大而增强），强链最大连通团
  占强链接触的 19–66%，x 向贯穿率 96%、y 向 36%。
* 航道验证（样本外）：实测 μ 比单元试验律预测低 0.18 ± 0.04 → 单元试验律**不能**直接外推到航道复合流动。

## 5. 注意点（踩坑与实测对比）

1. **受限压缩池是无效单元试验**（sweep 1，已归档 `artifacts/rubble_rheology/sweep1/`）：
   半径生长到 φ=0.80 后在定宽池内压缩，φ→0.92 逼近随机密堆，应力比既不均匀也不定常，
   给出 μ = 0.065–0.145（剪切为 0.25–0.32）。改为**等面积**平面应变后 μ = 0.29–0.33，
   与剪切律同量级；三场景合并 R² 从 0.41 提升到 0.65（sweep1 vs sweep2，run 级）。
2. **壁面滑动驱动需要壁速**：原引擎壁面接触按「静止壁」计算切向相对速度，移动壁只能靠法向推动，
   无法做 Couette。为此在 `granular2d.engine` 增加 `wall_velocity`（默认 `None` = 历史行为逐位不变），
   `_segment_contacts` 额外返回段索引。**这是本次唯一的共享内核改动**；集群上 `test_granular2d_energy_minimization.py` / `test_granular2d_force_chain_jamming.py` / `test_granular_benchmarks.py` 共 90 项通过，唯一失败项 `test_generate_figures` 是节点缺 matplotlib 的环境问题（非本改动引入）。
3. **误差变量（errors-in-variables）**：单 run 实测 γ̇ 本身有 10–20% 波动，run 级拟合会同时低估斜率、
   抬高残差；因此主判据用**条件均值 + seed 作为重复**（条件级 R² = 0.759 仍不足 0.95，见 §3）。
4. **有限尺寸涨落**：N≈400 圆盘，定速下 seed 间 μ 标准差 ≈0.012–0.023；12 快照平均后条件标准误 0.005–0.010。
5. **二维、无黏结、无破碎**：破损碎冰块形状（棱角度、扁平度）被单一摩擦系数吸收；未含冻结黏结与再破碎。
6. **文献锚点**：Guimarães et al. 2022 只用作 η 的量级窗口；未数字化逐点数据，逐点对比标注 WITHHELD。

## 6. 误差判定（是否 < 3%？）

| 比较 | 基准类型 | 结果 | 是否 < 3% |
|---|---|---|---|
| 圆–矩形交面积（`circle_box_area`） | 蒙特卡洛 4e5 抽样 / 解析极限值 | 最大相对误差 3e-3 | 是 |
| 孔隙率场守恒 | 全局孔隙率（同一几何独立求和） | ≤1e-12 | 是（远优于） |
| μ(I) 拟合系数 | 合成真值 0.55/0.80/−1.10 | 1e-8 | 是 |
| μ(I) 残差 | 自洽（相对拟合曲线） | 合并 0.0177，剪切 0.0050 | 合并约 6% → **否**；剪切约 1.8% → 是 |
| η(0.1 s⁻¹, 10 kPa) | 文献量级窗 [1e3,1e5] Pa·s | 2.61e4 | 窗内（无逐点基准，不作 % 判定） |
| 航道场景 μ | 单元试验律外推 | −0.18 ± 0.04（相对 −4.9） | **否**（模型形式误差，非数值误差） |

**结论**：数值/守恒/拟合器层面误差 ≤0.3%；物理层面「三场景单一 μ(I)」判据 honest FAIL，
其原因是应变路径依赖这一**真实力学效应**，不以调参掩盖；可交付的等效连续介质参数为
**剪切单元试验律**（R² = 0.990，残差 1.8%），并附应变路径不确定度 ±0.03（μ）。

## 7. 适用范围

* 平面应变、干颗粒、刚性圆盘、摩擦 μ_p = 0.5、滚动摩擦 0.05、kn = 3e4 N/m；
* I ≈ 3e-4 … 0.07（本轮覆盖），μ ≈ 0.25 … 0.34；
* 用于碎冰航道阻力模型时应只取**剪切驱动**状态的 μ，或把 ±0.03 的 μ 偏移（≈±10% 剪应力）
  作为模型形式不确定度参与传播；不要把单元试验律直接用于拖曳主导的整体流动。
