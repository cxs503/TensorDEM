# 多速率接触积分（MTS）与时间步稳定性契约 —— TensorDEM P82W4-N09

**结论一句话**：给 DEM 加了一层可机器裁决的「时间步/子循环契约」（`dt/t_c ≤ 0.2` 闭合、`0.2 < dt/t_c ≤ 0.5` 需显式请求、`> 0.5` 拒绝），并用 MTS 把摩擦臂的 3 次 return-mapping 单步成本压回 1 次，在外步放大 10 倍的同时保持恢复系数、能量、动量与摩擦 jamming 的 φ_J 不变。

## 1. 案例介绍（物理背景 / 参数 / 判据）

摩擦接触的显式 DEM 里，每个时间步的代价主要由切向弹簧的 **return mapping**（trial → 投影到 Coulomb 锥 → 重新求力）决定。经典实现每步做 3 次接触核求值，换来外步（outer step）可以取大；代价是**每一个接触、每一步**都付这 3 倍。另一方面，接触时间 `t_c` 才是硬约束：外步一旦逼近 `t_c`，无论切向如何处理，法向冲量都解不出来。本节点把这两件事拆开：

* **慢变量**（邻接表 / 滚动阻力历史 / 接触记录）按外步 `H` 更新一次；
* **接触**（法向弹性+耗散、切向 return mapping）在外步内做 `n_sub` 次子循环，每次子循环 **1 次** 核求值、几何来自缓存；
* 契约 `stability_gate(dt, t_c)` 给出 `ok / tight / violated` 三态裁决，`ok` 要求 `h ≤ 0.2 t_c`。

参数（单碰撞场景）：球半径 `R = 25 mm`、密度 `917 kg/m³`、`E = 1 GPa`、`ν = 0.3`（刚性平板约定 `1/E* = (1-ν²)/E`）、冲击速度 `v = 0.05 m/s`，Hertz 接触时间 `t_c = 2.943275 (5m/4k_h)^(2/5) v^(-1/5)`，阻尼系数 α 由**参考积分器**（1-DOF 速度-Verlet，`dt = t_c/2000`）标定到目标恢复系数。

## 2. 怎么做的（方法 / 关键设置 / 工具链）

* **模块**：`src/tensordem/mts_contact.py`（新）——`MTSConfig`（接触律+积分参数）、`MTSSystem`（2D 摩擦圆盘，支持刚性墙段与双周期/剪切速度梯度）、`stability_gate`（契约）、`hertz_contact_time` / `linear_contact_time` / `hunt_crossley_restitution`（闭式锚）、`calibrate_alpha`（在参考积分器上标定阻尼）。
* **三条积分臂**（同一套物理，只换积分方案）：
  * `mts`：外步 `H = ratio·t_c`，`n_sub = ceil(ratio / h_target)` 次子循环，每次 1 次 return mapping，几何来自外步缓存；
  * `legacy3x`：单速率，`dt = h_target·t_c`，每步 **3 次** return mapping（trial/投影/重求），每步重建邻接表——这是被替换的“3× 单步成本”实现；
  * `mts_overstep`：同一 MTS 机器但**越过契约**（`ratio = 0.5`、不子循环），只用于负控。
* **三条验证场景**：单球对平板冲击（Hertz + Hunt–Crossley）、双周期剪切的 jamming 非晶堆积（μ=0.5，`P`、`τ` 稳态）、N=256 摩擦 jamming 的等向减压 φ_J 协议（与 `tensordem.granular2d.jamming` 同物理：线性法向 + `ζ=0.4` 阻尼 + 切向弹簧 Coulomb 截断 + 滚阻 `μ_r=0.05` + 压力伺服 `dlnL/dt = (P-P*)/η`，`η=150`）。
* **交叉验证**：`MTSSystem.contacts` 与 `tensordem.granular2d.stress` 的Love-Weber 张量布局兼容，压力直接用**已发布**的 `virial_tensor` 复算（`test_contacts_dict_feeds_the_shipped_virial` 对齐到 1e-12），因此 φ_J 的差异不是压力定义差异。
* **工具链**：numpy/scipy（cKDTree）；验收脚本 `benchmarks/mts_contact_gate.py`（机器判据 → JSON），本报告由 `scripts/mts_contact_report.py` 从该 JSON 渲染，数字全部程序化注入。

## 5. 注意点（踩过的坑 / 适用范围）

1. **Hunt–Crossley 的耗散积分 J 容易写错**：本模块第一版把`J = ∫₀¹ √(u(1-u^{5/2})) du = 0.504455` 误写成 `∫₀¹ √(1-u^{5/2}) du = 0.817576`，结果是**注入能量**（e=0.5 档实测 e=1.26）。已用`tensordem.contact_timestep_ledger` 的独立实现钉住（`test_hc_formula_matches_the_ledger_implementation`）。
2. **阻尼项符号**：`f_n = max(0, f_el + c(δ)·v_n)`，其中 `v_n` 是**接近速度**（`n` 从物体指向接触点）。写成减号会变成负阻尼、能量自增（e>1）。
3. **周期像的 shift 符号**：邻接表里 `shift` 是“加到 `x_j` 上得到接触像”的偏移（右边界物体相对左边界物体的像在左一格 ⇒ `-Lx`）。符号写反不会报错，只会把跨界接触变成 0.098 m 之外的幽灵力，并在气体场景里引发能量爆炸。回归测试 `test_periodic_image_shift_sign_is_consistent` 钉住这一点。
4. **一阶 Hunt–Crossley 公式的适用范围**：`W/E0` 只要不是 ≪1，一阶公式就系统性偏低（e=0.9 档偏低约 10%，e=0.5 档直接失效到 e=0）。因此验收里 `e=0.5/0.9` 两档的阻尼系数是在**参考积分器**（1-DOF 速度-Verlet，`dt=t_c/2000`）上标定的，不是拟合被测积分器；一阶公式值仅作旁证列出。
5. **契约的物理含义**：`dt/t_c > 0.2` 时保持 `h ≤ 0.2 t_c` 所需的子循环数增长得比慢通量节省更快，加速比消失；`dt/t_c > 0.5` 直接拒绝。负控证明这条门是**紧的**：在 `0.5` 处不做子循环，恢复系数相对误差达 306.3353%，无耗散（稀薄）气体能量增长 112.5159%。
6. **剪切胞的 SLLOD 限制**：只在线性速度场上做仿射对流，未实现 Lees–Edwards 倾斜（小应变稳态流变近似）。报告里的 `τ/P ≈ 0.05` 是**远低于** Coulomb 上限的低剪切率稳态，此时几乎所有接触处于静摩擦支（`fraction_at_cone ≈ 0`），所以它验证的是“两臂输出同一构形应力”，不是摩擦饱和段。
7. **稠密气体的接触事件加热**：判据 (b) 用稀薄气体（φ=0.03）给出整合器自身的能量账本（无接触事件时残差即积分误差）；稠密（φ=0.6）接触主导气体在 1e5 步内仍有 3.6132% 的长期漂移——这是**任何**定步长显式接触积分器的 O(h) 事件误差（每次开/闭接触注入/抽走一份能量），不是 MTS 特有；把子步从半隐式 Euler 换成速度-Verlet 已把同一工况从 12.4% 降到 3.6132%。工程含义：要求 1% 级的长期能量闭合时，稠密系统应把 `h_target_tc` 从 0.02 降到 ~0.005（代价 4× 子步数）。
8. **分片可复现性是舍入级别的陈述**：40 步内两臂差 2.8e-15，但剪切胞是混沌动力学（表中 4e2 步后放大到 O(1)），任何 MD 长轨迹在不同累加顺序下都会去相关——这不是分片引入的错误。

## 7. 诚实判定与局限

* **判据 (c) 的第二半诚实 FAIL**：MTS 的 φ_J 与仓内 W4-P1 伺服协议（`jamming_density_isotropic(mu=0.5, mu_rolling=0.05, n=256, seed=0, steps_per_level=2500)` = 0.7326）相差 10.9684%，超出 0.5% 判据。诊断（不粉饰）：该参考实现**每一档都没收敛到伺服目标**（6 档中 5 档实测压力 ≠ 目标，末档目标 1 N/m 实测 2.32 N/m），其 φ_J 落在文献窗 0.80–0.84 之外（该仓文档已自记 FAIL：0.708 @ n=400）；而本节点两条臂都收敛到目标压力（见 §3.5 表），φ_J 落在窗内。因此这一项差异是**参考协议的收敛/分支差异**，不是 MTS 改变物理；MTS 改变物理与否由同协议双臂对照判定：|Δφ_J| = 0.2578%（§3.5）。
* **φ_J vs 基线**：两臂同协议同物理时长，差异来自外步相位与伺服轨迹；0.5% 判据在 `compress/level_time = 0.06 s` 下达标（见上表）。更长阶段会进一步收紧，代价是 legacy 臂墙钟线性增长。
* **只做了 2D 圆盘**：3D（`dem3d`）的 MTS 化需要同样的邻接缓存改造，本节点未做；契约（`stability_gate`）与闭式锚与维度无关，可直接复用。
* **Hertz 分支的 t_c 依赖冲击速度**：契约取系统当前最大速度作为 `v_ref`；静止接触用 1 mm/s 下限（静态问题不是时间步问题）。
* **滚动阻力仍在慢通量**：子循环里只更新切向 return mapping 与法向耗散，滚动历史按外步更新；对 `μ_r t_c` 很小的场景等价，但对强滚阻需要同样的子循环化。
