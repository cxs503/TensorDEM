# DEM → PBM 颗粒破碎耦合验证面（`tensordem.breakage_pbm`）

本页记录 `tensordem.breakage_pbm` 的物理模型、数值方法、机器判据、结果与局限。
全部数字由 `scripts/run_breakage_pbm_verification.py` 程序化写入
`artifacts/breakage_pbm/summary.json`，本页结果表由
`scripts/append_breakage_pbm_doc_table.py` 从该 JSON 注入（零手抄）。

## 1. 为什么放在 TensorDEM

TensorDEM 已拥有两部分相关能力，但都不覆盖本节点：

| 既有模块 | 坐标/测度 | 用途 | 本节点缺什么 |
|---|---|---|---|
| `tensordem.single_particle_crushing` / `tensordem.granule_crush` / `tensordem.crushing` | 单颗粒 | Weibull 强度律、Gaudin–Schuhmann 子代谱、质量/动量台账 | 没有群体平衡（PBM）；破碎谱是**假设**而非从 DEM 直接测得的产物分布 |
| `tensordem.fsd_evolution.pbe` | 冰浮冰块**面积**（`m ~ d²`） | 浮冰尺寸分布演化 | 测度是面积不是颗粒体积（`m ~ d³`）；破碎率常数；无 DEM 标定/交叉验证 |

本节点补的是 **标定链 + 交叉验证**：DEM 单颗粒破碎（bonded-sphere 压缩）→
Weibull 强度分布与子代分布 → 群体平衡数值解 → 用独立的 10⁴ 颗粒单轴压缩 DEM
检验 PBM 的 PSD 演化预测。生产用破碎 DEM（`tensordem.crushing` /
`tensordem.dem3d`）保持不变。

## 2. 物理模型

### 2.1 单颗粒破碎（`bonded_cluster_crushing`）

- 母颗粒离散为立方格点上的子球（默认 `n_axis=4` → 32 个子球、156 条键），
  子球半径 = 格距一半，最近邻相切；键的静止长度 = 初始距离，初始状态零力。
- 键模型：法向弹簧 `k_n`（拉压对称）+ 切向弹簧 `k_t`（追踪弹性切向位移）+
  法向阻尼。键的强度独立抽样自两参数 Weibull 律
  `P(σ_b) = 1 - exp(-(σ_b/σ_b0)^m_b)`；当 `|F_n|/A_b` 或 `|F_t|/A_b` 超过该键
  强度即断裂，断键退化为单边排斥接触（碎块之间仍按软球 DEM 相互作用）。
- 加载：位移控制的刚性压板（余弦缓启），**机器刚度**判据——压板反力从峰值
  跌落到 `lock_ratio` 以下即视为颗粒已破坏（真实刚性试验机卸载），
  记录的破碎力 = 该跌落前的峰值反力，破碎应力 `σ = F/D²`
  （与 `weibull_breakage.particle_stress` 同一约定）。
- 碎块：断裂事件后完整键图的连通分量；碎块体积 = 子球个数 × 单子球体积，
  即子代分布在 `1/N_sub` 上有分辨率下限（真实 DEM 分辨率限制，KS 检验必须
  在同一分辨率下对比，见 3.2）。
- 批量化：B 个样本共享同一几何与同一对相互作用表，只对键强度独立抽样，
  因此 10⁴ 次破碎试验的代价 ≈ 单次试验 × 批次数。

### 2.2 强度标定（`weibull_breakage`）

- CDF 最小二乘（线性化 `ln(-ln(1-F)) vs ln σ`）与 MLE（尺度用剖面似然
  `σ0^m = mean(σ^m)`，用 `logsumexp` 保持数值稳定）两套估计。
- 尺寸效应：`σ_c(V) = σ0 (V0/V)^{1/m}`（最弱链）。
- **破碎率** `S(V,t)`：单调加载下 `P_surv = exp(-(σ_eff/σ_c(V))^m)`，故
  `S = m σ_eff^{m-1} σ̇_eff / σ_c(V)^m`。
- **有效应力**：Weibull 应力积分 `σ_eff = (E[σ_p^m])^{1/m}`，把压实颗粒床的
  力链非均匀性折算成一个标量（这是 PBM 需要的唯一微观-宏观输入）。

### 2.3 群体平衡（`dpbm`）

体积坐标 `v`（球 `m = ρv`，`v = πd³/6`）下的纯破碎方程

```
∂n(v,t)/∂t = -S(v,t) n(v,t) + ∫_v^∞ S(v',t) b(v|v') n(v',t) dv'
```

离散：体积几何网格 + 两结点（Kumar–Ramkrishna）分配，质量 `Σ v_k n_k`
按构造守恒（测试验证到 1e-15）；时间积分用 BDF（刚性）。

闭式解（`S = const`、均匀子代 `b(v,v') = 2/v'`）：按「代数」求和

```
n(v,t) = e^-τ [ δ(v-v0) + Σ_{k≥1} (2τ)^k/k! · (1/v0) · (ln(v0/v))^{k-1}/(k-1)! ]
```

满足 `∫n dv = e^τ`、`∫v n dv = v0`（前者由测试验证）。`analytic_cell_density`
把它按初始状态叠加并做单元积分，作为 C3 的对照解。

### 2.4 子代分布（`daughter_distribution`）

- `UniformDaughter`：`b(v,v') = 2/v'`，`f = v/v' ~ U(0,1)`，平均 2 个子代。
- `LognormalDaughter`：`n_d` 个权重 `z_i ~ LogNormal(-s²/2, s)` 归一化
  `f_i = z_i/Σz_j`，即
  体积严格守恒的对数正态子代分布；`s → 0` 退化为等分。
- 两者质量守恒误差均为机器精度（测试验证）。

## 3. 机器判据与实现

| 判据 | 定义 | 阈值 |
|---|---|---|
| C1 | DEM 破碎应力样本的 Weibull CDF 拟合 `R²` | > 0.95 |
| C2 | DEM 子代体积分数 vs 假设分布，两样本 KS `p`（模型样本按 `1/N_sub` 量化） | > 0.05 |
| C3 | 分段 PBM vs 闭式解，累积质量分数最大偏差 | < 3% |
| C4 | DEM-PBM 的 PSD 演化，体积加权直径分布的一阶 Wasserstein 距离 / 初始平均直径 | < 0.1（t=1,2,4,8 s） |
| C5 | 破碎事件质量守恒（子代体积和 vs 母体积）与系统质量残差 | < 1% |
| C6 | 负控：`σ0 → ∞` PSD 不变 `<1e-6`；`σ0 → 0` PSD 退化到子代分布 `<3%` | 见左 |
| C7 | `tests/test_breakage_pbm.py` 用例数 | ≥ 15 |

实现要点与陷阱（踩过的坑，供后续节点复用）：

1. **时间步必须按最小颗粒定**：破碎生成的小子代质量下降 `f³`，用平均质量
   选 `dt` 会在细子代出现后立刻失稳（本次实测：`dt` 取 0.2·√(m̄/k) 时速度
   在数十步内涨到 10² m/s）。现按子代分辨率下限 `min_daughter_fraction`
   的质量取步长。
2. **压板阻尼符号**：`c_wall·(v_particle − v_platen)` 必须只在闭合方向生效，
   否则阻尼把颗粒往压板上拽，形成能量泵。
3. **近重合接触**：碎块瞬时重合时 `r/dist` 会给出非单位方向，必须夹断
   （本实现把 `dist < 1e-9` 的接触力置零），否则一步内注入巨大能量。
4. **子球重合法向力上界**：碎块插入造成的深重叠（形状已不保持）用
   `max_overlap_fraction` 截断，作为数值稳定器并在文中声明。
5. **C2 必须同分辨率对比**：DEM 碎块是子球整数倍，直接用连续分布做 KS 会因
   量化而永远拒绝（n≫1 时 KS 统计量下限 ~1/(2N_sub)）；因此模型样本用
   `quantize_fractions` 按最大余数法量化到同一栅格，并另给参数自举 p 值。

## 5. 局限与未完成项
### 5.1 本次结果的诚实判定与诊断

| 判据 | 实测 | 判定 | 诊断 |
|---|---|---|---|
| C1 | R²=0.980 (m=4.71, σ0=14.5 MPa) | 通过 | bonded-sphere 破碎力分布确实是 Weibull 型 |
| C2 | KS p≈1e-295（两种假设均拒绝） | **未通过** | 32 子球分辨率下 DEM 碎块谱是"1~2 个大块 + 大量单子球"，均值 9.1 块、最大块占比中位数 0.47；连续两参数族（均匀/对数正态）无法同时刻画大块端与细端 |

| C4 | W1/d0 = 0.89–1.18（阈值 0.1） | **未通过** | κ=20.5 使 σ_eff 远大于宏观应力，PBM 预测的平均粒径（0.25 mm）比 DEM（2.9 mm）小一个量级。κ 在"压密阶段"窗口用均值比测得，此时 σ_macro 很小，κ 明显被高估；应改为在固定宏观应力水平下的条件平均，或把 κ 与破碎起始时刻一并识别 |
| C5 | 4e-15 | 通过 | 子代体积和 = 母体积（机器精度），系统质量台账闭合 |
| C6 | σ0→∞ 漂移 0.0（通过）；σ0→0 与子代分布累积一致 0.943（阈值 0.97） | **部分通过** | 瞬时全碎极限下残余母颗粒 -1e-18（正确清空），但累积曲线仍有 5.7% 偏差，来源同样是 C3 诊断出的结点分配误差 |

结论：**判据 C1、C5、C7 达成；C2、C3、C4、C6 未达成**（honest FAIL，未做任何粉饰）。
本节点的价值在于把失败定位到了三个具体机制上（子代谱分辨率、两结点算子在
floor 处的计数亏损、κ 的可识别性），并给出了可复现的判据与工件。

### 5.2 规模限制（重要）

归档的 `artifacts/breakage_pbm/summary.json` 来自 **缩小规模**运行
（破碎试验 400 次、装配体 N=150、加载 0.15 s）。满规模运行（破碎 10⁴ 次、
装配体 N=10⁴、t=1/2/4/8 s）已在本会话内启动但**未在本次时间预算内完成**：
装配体 DEM 在破碎率不加限幅时会以每步指数增长的方式繁殖颗粒（本次已把
`max_breaks_per_step` 降到 5 以限制雪崩），单步开销随颗粒数上升，10⁴ 颗粒
× 8 s 估计需数十分钟至数小时的集群时间。因此：

* C1/C5 的结论与规模无关（统计量已饱和，n=400 时 R² 已稳定到 0.98）；
* C2/C3/C6 的判定与子球分辨率/算子有关，与装配体规模无关；
* **C4 必须在满规模重跑后才有最终结论**——本页报告的 C4 数字只说明
  "当前 κ 识别方式 + 当前 PBM 算子"在缩小规模上失败，不作为满规模的结论。


- **子代分布的分辨率**：32–136 个子球的 bonded 颗粒在破坏后几何上难以给出
  丰富的子代谱；子代分布的形状受子球分辨率限制，KS 对比只在同分辨率下有意义。
- **宏观有效应力比 κ**：PBM 的破碎率需要 `σ_eff = κ σ_macro`。κ 在
  **首次破碎之前**的窗口内测得（单标量，DEM 输入），之后的时间全部是预测；
  但该窗口内压板仍处于压密阶段，κ 的不确定度直接线性放大到 PBM 的破碎时刻。
- **质量缩放**：DEM 用 `mass_scale` 放大密度以提高稳定步长（准静态加载下
  标准做法），未做两种质量缩放的对照（列为本节点的后续工作）。
- **摩擦**：装配体计算默认 `mu = 0`（无摩擦），力链形态偏弱，κ 因此可能低估。
- 单轴压缩为**侧限（oedometric）**条件：四周固定刚性墙，与三轴试验不同。
