# G25 验证欠账闭合：刚度梯级上的 z 是阈值伪影（非物理缺陷）

**锚点**：`CASE-DEM-RCP-PACKING-FRACTION`（feature_ledger）。

## 背景

稳态审计（`steady_state_audit.py`，m17063）发现 `G25_stiffness_ladder_coordination_converged` **FAIL**：在*硬*接触阈值（`overlap > 0`）下，刚度梯级上的平均配位数 `z` 随 `k_n` 增大而跌破 等静值 `z_c = 2d = 6`（无摩擦）——最硬一级读得 `z = 5.41 < 6`，即床层看似*欠静*（hypostatic）。

## 闭合判据

本脚本证明该跌落是**阈值伪影**，不是物理缺陷：

* **硬阈值 `z` 是真实配位数的下界**——只数严格正重叠的接触对；随 `k_n` 增大，沉降重叠收缩（`mean_overlap/d`：`1.2e-3` → `2.2e-5`），更多*边缘*接触跌出数值 `overlap > 0` 判据；
* **有限间隙容差 `t` 下的 `z` 是上界**（还数近接触对）；真实 jamming `z` 介于两者之间；
* 在匹配本算例自身重叠尺度的容差（`t = 1e-3`，即沉积测量所用的 `overlap_tolerance`）下，`z` 是**收敛**序列且每级都*高于* `z_c`（`mu=0`：`6.49 → 6.23 → 6.17 → 6.09`），等静值被恢复，床层*并非*欠静。

`phi`（体积分数）在同一梯级上的收敛*不受*此影响（`mu=0`：`0.6424 → 0.6379 → 0.6368 → 0.6357`，干净地趋向 RCP 极限 `0.6366`）：G25 只涉 `z`，从不涉 `phi`。
