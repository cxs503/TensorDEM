## 1 案例介绍

随机密堆（Random Close Packing, RCP）是颗粒物质物理中的经典基准问题：单分散球体在无序堆积状态下能达到的最高体积分数。该问题在船舶工程中应用于散货装载密度估算、冰脊孔隙率建模、床层耦合传热等场景。

**参考文献**：
- Scott, G. D. (1960). "Packing of Spheres". *Nature* **188**, 908.
- Bernal, J. D. & Mason, J. (1960). "Packing of Spheres". *Nature* **188**, 910. DOI: 10.1038/188910a0
- Pournin, L. et al. (2001). "Three-dimensional random close packings of spheres". *Phys. Rev. E* **63**, 031304.

**验收标准**（feature_ledger）：
- 体积分数 φ ∈ [0.62, 0.66]
- 10000 球，无摩擦（μ=0）和低摩擦（μ=0.1）两档
- 对标文献误差 < 3%

## 2 方法

TensorDEM 提供两种 RCP 测量方法：

### 2.1 几何压缩算法
`make_random_close_packing()` — 准静态压缩算法：
1. 在周期性立方胞中随机放置 N 个球（稀相）
2. 小步压缩胞体，每步后松弛重叠
3. 达到目标孔隙率后执行最终重叠松弛

### 2.2 物理 DEM 沉降
`run_deposition()` — 真实动力学沉降：
1. 随机顺序添加（RSA）在稀相放置粒子（无晶格种子）
2. 重力作用下自由落体、碰撞、耗散
3. 当 KE/(Nmgd) < 5×10⁻⁴ 持续 4 个重力时间后停止
4. 通过自由表面几何读取体积分数（云网格分 bin，剔除壁面层）

**关键设置**：
| 参数 | 值 |
|---|---|
| N | 10000（生产），有限尺寸扫描 1000/2000/4000/10000 |
| 直径/密度/g | 1/1/1（无量纲） |
| 胞体 | 方形底面 L×L，x/y 周期，z=0 摩擦地板 |
| 接触律 | 线性弹簧-阻尼，e=0.1，k_t=k_n/2 |
| 刚度扫描 | 4000/16000/64000/256000（Richardson 外推至硬球极限） |
| 时间步 | dt = t_c/20（生产），t_c/40（时间步探针） |
| 摩擦档 | μ=0, μ=0.1 |
| 种子 | 每档 ≥3 个独立种子 |

## 7 注意点与局限

1. **软球系统性**：k_n=4000 时重叠 ~1.1%，导致床层压缩 ~0.7-0.9%。这是软球 DEM 的内禀系统性，通过 Richardson 外推可消除。
2. **μ=0.1 外推阶 p=0.58**：偏离线性弹簧预期的 p=1，表明摩擦接触的非线性使刚度收敛变慢。第四刚度水平（k_n=256000）已提交集群计算（cj3048），待完成后将更新外推。
3. **周期性侧壁**：x/y 方向周期性消除了侧壁效应，但 z 方向地板摩擦影响沉降动力学。
4. **单分散假设**：实际散货/冰脊为多分散系统，RCP 值会变化。
