# P35-N2 — 湿冰颗粒团聚的毛细桥 cohesion 模型（TensorDEM）

**节点**：P35-N2（战役 DAG，物理域） **仓**：TensorDEM **分支**：`agent/m6796`
**能力**：`tensordem.wet_ice_cohesion`（新增，领域目录 4 模块 + 1 study + 1 figures）
**证据分级**：毛细桥力律 = REAL；精确轴对称 Young–Laplace 参考 = REAL（仓内已有，独立自洽检查）；DEM 团聚/内聚力 = REAL；Timco & Weeks 关系分支 = 文献关系（WITHHELD 作为实验证据）

## 1. 案例介绍（物理背景 / 几何 / 参数）

干冰颗粒只靠排斥+摩擦相互作用；一旦有液相（孔隙水/卤水/雪浆/融化层），颗粒颈部形成
**摆式液桥（pendular bridge）**，给颗粒组装体增加抗拉/内聚能力。本节点把这一物理机制做成
TensorDEM 的一个能力面，并用机器判据标定。

**参考算例（毛细桥）**：等径球 R = 0.5 mm，水在 0 °C 的表面张力 γ = 0.0759 N/m，液桥体积
V/R³ ∈ [0.006, 0.18]，无量纲间距 s/R ∈ [0, 0.15]，接触角 θ ∈ [0°, 45°]。
基准量 F₀ = 2πγR = 2.384×10⁻⁴ N（经典小液桥极限）。

**团聚算例**：N = 600 单分散球（a = 1），立方周期盒（边长 36.91 a，初始体积分数 0.05），
线性剪切场 γ̇ = 1，总应变 γ̇t = 2。

**内聚力算例（2D DEM 拉伸池）**：250 个双分散圆盘（r ∈ [0.85, 1.15]R），面分数 φ = 0.80，
上下平面墙（x 周期），顶墙上拉速度 0.01，毛细桥体积 V/R³ = 0.02，γ = 0.3（DEM 单位）。

## 2. 怎么做的（方法 / 流程 / 工具链）

### 2.1 三个力律（`capillary.py`）

1. **任务书给的闭式**（`seeded_campaign_force`）：
   `F = 2πRγcosθ · [1/(1+s/2h) − 1/√(1+s/h)]`
   原样实现并**证伪**（详见 §5）：括号项 = 1/(1+x) − 1/√(1+2x)，x = s/2h，
   在 s = 0 处恒为 0，且对一切 s > 0 为**负**（一阶展开两项相同，二阶 −0.5x² < 0），
   即它给出的是"随间距增大而增强的排斥"，不可能是液桥吸引律。
2. **经典小液桥解析锚**（`small_bridge_limit`）：`F → 2πγRcosθ`（V/R³ → 0, s → 0）。
3. **DEM 级闭式**（`capillary_force`，本节点交付的模型）：
   ```
   F = 2πγR·cosθ·(1 − c θ²)·K(u)·D(x),  u = (V/R³)^(1/3),  x = (s/R)/u
   K(u) = (1 + a u)/(1 + b u)                 体积修正（a = 0.165041, b = 0.789773）
   D(x) = 1/(1 + p x + q x²)                  间距衰减（p = 0.821491, q = 6.612248）
   ```
   五个常数只在**训练集**上标定；报出的误差全部来自**与训练集不相交的留出集**。

### 2.2 判定参考（benchmark）

判定基准是仓内**已有的精确轴对称 Young–Laplace 求解器**
`tensordem.liquid_bridge.solve_axisymmetric_bridge`（零重力、精确自由面，`liquid_bridge.py`
自带一阶积分自洽检查）。本节点对每一行都复核了该一阶积分（颈截面力 vs 接触线力）：
最大相对差 **1.22 %（train）/ 1.39 %（validate）**，说明参考本身可信；求解器在极小液桥
（V/R³ ≲ 0.005）与 θ ≈ 90° 附近不收敛，这些行原样保留在 JSON 里（`converged=False`），
分析时按残差 > 1e-2 剔除，绝不静默替换。

参考表由 `scripts/gen_wet_ice_capillary_reference.py` 生成并入库
（`artifacts/wet_ice_cohesion/capillary_reference.json`，R/γ/n_steps 全部记录在 meta 中，
可一键重算；耗时 4.2 s）。

### 2.3 团聚体尺寸分布（`aggregation.py`）

粒子级：仿射剪切 + Lees–Edwards 镜像 + 等价球半径 R_k = a k^(1/df)（df = 3），
两团聚体等价球重叠即合并（粘附概率 = 1，对应毛细桥抗拉能力远大于接触剪切力）。
平均场：离散 Smoluchowski 方程
`dn_k/dt = ½Σ_{i+j=k}K_ij n_i n_j − n_k Σ_j K_kj n_j`，正交剪切核
`K_ij = (4/3)γ̇(R_i+R_j)³`（Smoluchowski 1917），用 Radau 积分。
**两侧用同一核**，因此比较检验的是平均场闭合（分子混沌）而不是拟合参数。

### 2.4 内聚力与增强因子（`cohesion_cell.py` + `ice_resistance.py`）

2D 直接拉伸池：行沉积 + 位置式压缩（纯运动学，无动力学爆风险）→ 固定墙松弛 →
顶墙匀速上拉，记录墙牵引力时程，**峰值即内聚强度 c**。γ = 0 走同一条代码路径（毛细项恒零），
因此干/湿对照是"同一个程序关掉一个项"，不是两套代码。

阻力增强因子 `F_enh = (σ_n tanφ + c)/(σ_n tanφ)`。参考侧（微观-宏观）：
各向同性桥网络对平面的投影 `c_ref = Z⟨F_b⟩/(π A_p)`（= Rumpf/virial 值 `Z⟨F_b⟩/(2A_p)` 的 2/π 倍）。
`Z`、`⟨F_b⟩` 全部在**同一池子**里实测，因此比较是同类比的。

### 2.5 工具链

`python scripts/gen_wet_ice_capillary_reference.py`（参考表）→
`python scripts/wet_ice_cohesion_study.py`（全部判据 → `campaign.json` + 4 张图）→
`pytest tests/test_wet_ice_cohesion.py`（18 项断言，130 s）。

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

1. **任务书的闭式是错的，而且错得很彻底**。`1/(1+s/2h) − 1/√(1+s/h)` 对一切 s ≥ 0 非正：
   相切两球液桥力为 0，间距一拉开反而"越推越开"。按判据 (g) 记 honest FAIL 并给替代物，
   替代物在留出集上峰值误差 0.32 %。这不是"装饰性修复"，而是把种子公式的不可用性量化入库。
2. **2D 常应力剪切池失败**（负结果，保留在报告里）。两种做法都不成立：
   (i) 墙高被比例伺服控制时，环增益 ≈ servo_gain·dt·|dσ/dH|、而近 jamming 时
   dσ/dH ~ k_n N_c/L_x ≈ 10³，环路振铃，H 发散到 10¹⁵⁸；
   (ii) 定高剪切时材料剪胀脱离顶墙，σ_n 掉到目标值的 5 %。
   改用**拉伸池**（无伺服、无自由墙自由度）后稳定，且直接测到内聚力这个本节点真正要的量。
   代价：只有 c，没有 φ；φ 取 30°（μ = 0.5 对应 26.6°）作为显式假设。
3. **阻尼器的显式刚度限制**：临界阻尼 `c_crit = 2√(k_n m_eff)` 在 dt = 4×10⁻³ 下使显式格式变硬，
   实测 cn = 31.7 发散的同一算例在 cn = 6.3（0.2 c_crit）下稳定。代码里写死 0.04 系数并注明原因。
4. **初始堆积必须无重叠**：随机撒点 + 松弛会残留 18 % 重叠（k_n·Δ = 354 的量级），
   一步就炸；改为"行沉积 + 向上整定"（0 重叠）+ 位置式压缩（纯运动学）后可复现。
5. **精确 YL 求解器的脆性**：V/R³ ≲ 0.005、θ ≳ 60° 时不收敛（残差到 10¹）。
   参考表保留这些行并标注，分析时按残差阈值剔除；这不影响判据 a（阈值内 14/15 行可用）。
6. **适用范围**：闭式标定域 0 ≤ θ ≤ 45°、0.006 ≤ V/R³ ≤ 0.18、s/R ≤ 0.15；
   超出后仅定性可用。2D 池给出的是**指标**（index）不是 3D 碎冰体强度；df = 3 的紧实团聚假设
   在强剪切絮体（df ≈ 2–2.5）下会高估碰撞半径，未标定（仓内无数据可诚实标定）。
7. **物理窗口**：Bond 数 Bo = ρgR²/γ，水/冰体系 Bo = 1 对应 R ≈ 2.9 mm。毛细内聚只有在
   **R ≲ 3 mm**（雪浆/油脂冰/细粒冰）才可能显著改变宏观阻力；cm 级碎冰体的毛细增强只有百分之几
   （见 fig4）。这条标度律比任何单点数字更有用，也解释了 T&W 分支为何与 DEM 分支差 23 %。

## 6. 误差判定（逐项回答"是否 < 3 %"）

| 关键量 | 基准 | 误差 | < 3 %？ |

| 液桥**峰值**力（留出集 8 点） | 精确 Young–Laplace | 0.32 %（最大） | **是** |
| 液桥峰值力（现场求解 2 点） | 精确 YL（现算） | 0.27 %（最大） | **是** |

| 全曲线力（最坏点） | 精确 YL | 12.5 % | 否（角点，已声明） |
| ⟨D⟩（团聚，后半程最大） | Smoluchowski | 5.88 % | 否（但 < 15 % 判据线，PASS） |
| 团簇数（同一时刻） | Smoluchowski | ~22 % | 否（已如实登记） |
| 内聚强度 c（2D 池） | 平切微观参考 | 13.4 % | 否（判据 (c) 定义在增强因子上） |
| 增强因子 F_enh | 微观-宏观参考 | **2.86 %** | **是** |
| 增强因子 F_enh | Timco–Weeks 关系分支 | 23.3 % | 否（见下） |
| γ = 0 干对照（毛细力 / 池内聚 / 不粘连） | 严格零 | 0.0 / 0.0 / 0 | **是（恰为零）** |

**关于 Timco & Weeks (2010)**：该文献是海冰**材料**性质汇编（卤水体积、密度、压/剪强度、摩擦），
**没有**"湿/干颗粒冰阻力比"这类数据。本节点用它的卤水体积关系与孔隙限强度式
（`σ_c = 37 ε̇^0.22 (1−√(v_b/0.29))²`）构造了唯一可算的对照分支，并在 JSON 中把该分支
标为 `grade = literature-relation`，**不冒充实验值**。判据 (c) 的通过项是"DEM 增强因子 vs
微观-宏观参考"（2.86 %）；文献分支差 23.3 % 被明确记为未通过，原因已定位（见 §5.7 的 Bond 标度）：
连续性海冰强度式描述的是固体矩阵，与颗粒尺度的毛细内聚不是同一个量，两者只应在 R ≲ 3 mm
的窗口内可比。

**honest FAIL 清单（不可覆盖）**
* (g) 种子闭式：不可用（恒非正）。
* 2D 常应力剪切池：两版实现均失败，已弃用并记录原因。
* 增强因子 vs Timco–Weeks 文献分支：23.3 % > 20 %。
