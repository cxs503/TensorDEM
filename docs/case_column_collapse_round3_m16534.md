# CASE-COLUMN-COLLAPSE 第 3 轮 — 球体 DEM 的单一接触摩擦能否复现 Lube (2004) 整条 runout 曲线？（TensorDEM · m16534）

锚点：**CASE-COLUMN-COLLAPSE**（feature_ledger status=open；轮 1 = m15324 `docs/case_column_collapse_lube2004.md`，
轮 2 = m15996 `docs/case_column_collapse_round2_m15996.md`）。本轮判据**未改**（< 15 %），容差**未放宽**，
参考式**未重打**（运行时由 `tensordem.granular_column.axisym.lube_2004_*` 求值）。

## ① 案例介绍

轴对称颗粒柱坍塌：半径 $r_i$、高 $h_i = a\,r_i$ 的圆柱 HCP 颗粒柱在 $t=0$ 释放，重力驱动径向流动并在地面沉积。
参考文献（逐字引用，目标值运行时求值，零手抄）：

> Lube, Huppert, Sparks & Freundt (2004), *Axisymmetric collapses of granular columns*,
> J. Fluid Mech. **508**, 175–199, doi:10.1017/S0022112004009036 —
> $r_\infty = r_i(1+1.24a)$（$a<1.7$）；$r_\infty = r_i(1+1.6a^{1/2})$（$a>1.7$）；
> $t_\infty = 3(h_i/g)^{1/2} = 3(r_i/g)^{1/2}a^{1/2}$。

几何与材料参数（全部取自 `benchmarks/case_column_collapse_lube2004.py::BASE`，本轮只动 $\mu$ 与 $a$）：

| 量 | 值 | 量 | 值 |
|---|---|---|---|
| 颗粒半径 $r$ | 0.03 m | 接触刚度 $k_n$ | $6\times10^4$ N/m |
| 密度 $\rho$ | 2500 kg/m³ | $k_t/k_n$ | 0.5 |
| 柱半径 $r_i$ | 0.48 m | 恢复系数 $e$ | 0.5 |
| 滚动阻力 $\mu_r$ | 0.4（轮 1 标定值，**固定**） | 初始格隙 | HCP + 2 % |
| 接触摩擦 $\mu$ | **0.5 / 0.6 / 0.7 / 0.8（本轮扫描轴）** | 时间步 dt | $4.82\times10^{-4}$ s（速度 Verlet） |
| 纵横比 $a$ | 0.5 / 1.0 / 1.5 / 2.0 / 3.0 | 颗粒数 | 981 / 1955 / 2737 / 3718 / 5673 |

**本轮问题（预登记，写进代码常量 `MU_SWEEP`/`SWEEP_ASPECTS` 后才跑）**：轮 2 发现 $a=2$ 处 $\mu=0.8$ 把 runout 误差
从 +22.8 % 压到 +0.02 %，但那是**一个格点**，无法与「点巧合」区分。本轮问的是**曲线级**问题：
*是否存在单一 $\mu$ 值，在 $\mu_r=0.4$ 下同时让 $a\in\{0.5,1,1.5,2,3\}$ 的 runout 全部落在 15 % 内？*
（假设 H1。若 H1 成立，则轮 1 把 +23 % 归因于 $\mu_r$ 标定是误判；若不成立，则需给出结构性解释。）

## ② 怎么做的

1. **最小代码改动（`benchmarks/case_column_collapse_lube2004.py`）**：新增
   `MU_SWEEP = (0.5,0.6,0.7,0.8)`、`SWEEP_ASPECTS = (0.5,1.0,1.5,2.0,3.0)` 与 `wave3_cases()`（20 个预登记点，
   除 $\mu$、$a$ 外一切参数逐位相同）、`--wave3` 与 `all_cases()` 统一入口；`--case <id>` 可单点跑（集群分片语义复用）。
2. **后验控制（明确标注 post-hoc）**：`wave3_control_cases()`——扫描里 $\mu=0.7,a=0.5$ 与 $\mu=0.7,a=1.0$ 以
   `stop_reason=time_limit` 结束（未触发 at_rest），故把 `duration_factor` 8 → 16 重跑同一格点，检验 runout 是否被截断。
   这两点**不进预登记判据**，只用于检验判据是否被截断限制。
3. **确定性检验**：同一 id（$\mu=0.6,a=3$）原样重跑一次，比对 runout / t99 / stop_reason。
4. **执行**：20 个格点 + 2 个控制 + 1 次重跑，单核进程、10 路并行（本机 128 核，load15 ≈ 60–79 < 100，符合容量纪律），
   全程 ~10 min，单例墙钟 14.8–145 s。每例落 `runs/case_column_collapse_lube2004/cases/<id>.json`
   （参数签名 + front 时程 + 能量账本 + 判据 = provenance）。
5. **归约（`scripts/analyze_column_collapse_m16534.py`，只读 JSON）**：出 `sweep_table.csv`、`cases_slim.json`、
   `curve_summary.json` 与 4 张图；参考值一律由 axisym 模块公式求值，报告里没有一个手打数字。
   归约里额外实现两件有独立意义的量：`required_mu()`（把一个 $a$ 处的 runout–$\mu$ 族**反解**出「达到参考文献所需 $\mu$」，
   越界即标 EXTRAPOLATED）与 `tilt_fit()`（$\mathrm{err}$ 对 $a$ 的最小二乘斜率 = 结构性倾斜）。

### 结论 1（预登记假设 H1 被证伪）——不存在单一 $\mu$ 复现整条曲线

| $\mu$ | max\|err\| | rms err | 过判据格点 |
|---|---|---|---|
| 0.5 | 23.20 % | 15.5 % | 3/5 |
| 0.6 | 29.56 % | 14.9 % | 4/5 |
| **0.7** | **15.85 %** | 12.3 % | 3/5 |
| 0.8 | 16.06 % | **10.3 %** | 3/5 |

最优单值（最坏情形口径）$\mu=0.7$ 仍以 15.85 % 越线 0.85 个百分点 → **H1 = False**。

### 结论 2（真正的结构性发现）——失配是「倾斜」而非「平移」，且断层被夹在参考律换支点 $a=1.7$ 所在的 $(1.5,2)$ 区间内

`tilt_fit`（$\mathrm{err} = c_0 + c_1 a$）：$c_1 = +7.6 \sim +15.9$ %/a 全为正，$c_0 = -23.9 \sim -5.7$ %，
残差 rms 仅 4.7–5.7 % ⇒ 误差几乎是一条**斜率**误差，不是常数偏置；**任何常数 $\mu$ 都只能平移曲线、不能改斜率**，
所以调 $\mu$ 永远只能让谷底点穿过 15 % 带而两端同时出界。按参考律换支点分段：

| 分段 | 最好 $\mu$ | max\|err\| | 过判据 |
|---|---|---|---|
| 线性支 $a\le1.5$ | 0.5（0.6 同量级：11.7 %） | **10.6 %** | **3/3** |
| 平方根支 $a\ge2$ | 0.8 | **4.3 %** | **2/2** |

### 结论 3（反解）——参考律「要求」的摩擦随 $a$ 单调抬升，$a=1.5\to2$ 跳 +0.27

| $a$ | 0.5 | 1.0 | 1.5 | 2.0 | 3.0 |
|---|---|---|---|---|---|
| required $\mu$ | 0.453 *(外推)* | 0.570 | 0.529 | 0.801 *(外推)* | 0.837 *(外推)* |

线性支内 required $\mu$ 稳定在 0.53–0.57（$a=1$ 处 0.570、$a=1.5$ 处 0.529，均值 0.55；一片平坦 ⇒ 该支**确实**可被单一 $\mu$ 复现）；
跨过参考律换支点 $a=1.7$（采样上夹在 $a=1.5$ 与 $a=2$ 之间）后跳到 0.80–0.84。球体 DEM 的常数 $\mu$ 无法两端同时满足 ⇒
真实砂的**速率相关/有效摩擦（$\mu(I)$）**是缺的那一块，而这正是总账锚点 CASE-DEM-PLANE-SHEAR-MUIDI 的标定量。

### 结论 4（时间判据是定义差异，不是接触律失效）

同一批算例、同一 front 时程，只换「何时算停」：

| 停止判据 | 中位 \|err\| | 平均 err | max\|err\| | 过判据 |
|---|---|---|---|---|
| $t_{99}$（轮 1/2 主判据） | 35.0 % | +35.1 % | 65.1 % | 1/20 |
| $t_{95}$ | 19.7 % | +22.3 % | 53.4 % | 5/20 |
| **$t_{90}$** | **9.3 %** | +12.2 % | 40.7 % | **13/20** |

误差随判据从「完全静止」前移到「走到 90 % runout」而单调坍缩 ⇒ 轮 1/2 的 $t_\infty$ 全体 FAIL 主要来自
**蠕变尾段与文献高速摄影判读的定义差异**（量级：约 25 个百分点），不是接触律误差。

### 结论 5（控制与确定性）——判据不被截断限制，且代码路径确定性

* 截断控制（post-hoc）：$\mu=0.7,a=0.5$：`time_limit` 1.370 → `at_rest`（时长 ×2）**1.370**；
  $\mu=0.7,a=1.0$：2.088 → **2.088**（逐位同值）；控制跑后两例的 `stop_reason` 变 `at_rest`，runout 不变 ⇒ **runout 已收敛**。
* 确定性：$\mu=0.6,a=3$ 原样重跑 → 4.886 / $t_{99}$=1.515 / `at_rest`，与原跑一致 ⇒ 本轮所有差异是系统性差异，不是随机噪声。

## ⑤ 注意点 / 局限

* **$a=3$ 在 $\mu=0.6$ 处非单调**（4.646 → 4.886 → 4.369 → 3.934 随 $\mu$=0.5→0.8）：已用原样重跑排除随机性（结论 5），
  故它是确定性的体系行为（探针：$r_{p99.5}$ 在薄前锋上对局部卡锁敏感），但**未做独立机理归因**，如实标注为未解释点。
* **required $\mu$ 在 $a=0.5$、$a=2.0$、$a=3.0$ 是外推**（交点落在采样 $\mu$ 区间外）：只能当「所需摩擦 $\gtrsim$ 实测边界」读，
  不能当测量值引用；$a=1.0$、$a=1.5$ 是区间内插值（可信）。
* **换支位置未定位**：$a=1.5$ 与 $a=2$ 之间没有采样点，故「换支与文献 $a=1.7$ 吻合」只能读作**不矛盾**，
  不是已验证；要证实需在 $a\in\{1.6,1.8\}$ 补两点（各 ~90 s）。
* **$\mu_r$ 固定 0.4**：轮 1 在 $a=0.5$、$\mu=0.5$ 上标定；本轮改 $\mu$ 后严格说标定已失配，故结论 3 的 required-$\mu$
  数值是「在 $\mu_r=0.4$ 条件下」的下界，不是 $(\mu,\mu_r)$ 二维最优 —— 二维联合标定未做（honest not_run）。
* **能量账本残差 1.7 %–13.6 %**（占释放势能，随 $a$ 增大而增大）：$a=3$ 时 12.6–13.6 % 不小，说明大 $a$ 的沉积细节受
  阻尼/截断记账影响；runout 的 15 % 判读需带上这个不确定度背景。
* **分辨率轴未在本轮重扫**：轮 2 已证 6→8→11 粒/$r_i$ 在 8 粒后饱和（+28.5 %→+22.8 %→+21.9 %），本轮沿用 8 粒/$r_i$。
* 单核串行语义、10 路并行共享机器：墙钟不是性能基准。
* 参考文献的 $\mu$、$e$ 未逐字给出实测量（砂材料相关）；因此「required $\mu$」是**等效摩擦**，不能与砂的实测量直接等同。

## ⑥ 误差判定（逐项，是否 <15 %／<3 %）

| 关键量 | 最佳配置 | 最佳误差 | <15 %? | <3 %? | 说明 |
|---|---|---|---|---|---|
| runout，$a\le1.5$（线性支，单值 $\mu=0.5$） | $\mu=0.5$，$\mu_r=0.4$ | −3.7 %…+10.6 % | **是（3/3）** | 否（a=1: +10.6 %） | 该支可用单一 $\mu$ |
| runout，$a\ge2$（平方根支，单值 $\mu=0.8$） | $\mu=0.8$，$\mu_r=0.4$ | +0.02 %…+4.3 % | **是（2/2）** | **$a=2$ 是（0.02 %）；$a=3$ +4.3 % 否** | 该支可用单一 $\mu$ |
| runout，**全曲线单一 $\mu$**（H1） | $\mu=0.7$ 最坏情形 | 15.85 % | **否**（越线 0.85 pp） | 否 | 预登记假设被证伪 |
| runout 误差对 $a$ 的斜率 | 全部 $\mu$ | +7.6…+15.9 %/a | — | — | 结构性倾斜 ⇒ 常数 $\mu$ 无法拟合 |
| $t_\infty$（$t_{99}$ 定义） | 全场最好 $\mu=0.7,a=1.5$ | +13.8 %（1/20 过） | 1/20 | 否 | honest FAIL，判据未改 |
| $t_\infty$（$t_{90}$ 定义，敏感性） | 20 格点 | 中位 9.3 %（13/20 过） | 部分 | 否 | 定义差异量化，不作主判据 |
| 接触摩擦等效值 | 线性支 / 平方根支 | 0.53–0.57 / 0.80–0.84 | — | — | 后者为外推下界 |

**是否 <3 %？** 只在**单格点**意义上是：$\mu=0.8,a=2$ runout +0.02 %（$<3$ %）。
**曲线级与时间判据均未达 3 %**，也**未达 15 % 的统一判据**。能力的诚实表述：
**本轮把「Lube 2004 可复现」从「$\mu=0.8$ 于 $a=2$ 的一点巧合」细化为「参考律两支各需一个不同的常数 $\mu$
（0.5／0.8），且跳变区间 $(1.5,2)$ 含参考律自身的换支点 $a=1.7$（位置未逐点定位）；单一 $\mu$ 覆盖全曲线的假设被证伪」**。
这不是粉饰后的 PASS：全局判据仍为 FAIL，锚点保持 open。

## 给下一轮的建议（不属本单）

1. **二维联合标定 $(\mu,\mu_r)$ + 分段**：本轮固定 $\mu_r=0.4$，线性支与平方根支的 required $\mu$ 是在此条件下的下界；
   做一个 $(\mu,\mu_r)$ 各 3 档的网格即可判断「单支两参数、两支同一 $\mu_r$」是否成立（约 18 算例 × <150 s）。
2. **$\mu(I)$ 速率相关摩擦**：结论 3 指向有效摩擦随惯性数上升，建议与 CASE-DEM-PLANE-SHEAR-MUIDI 标定出的
   $\mu(I)$ 曲线耦合，检验其能否用**一条**本构同时覆盖 $a=0.5$–3。
3. **$a=3$、$\mu=0.6$ 的非单调点**：用 $r_{p99}$/$r_{p99.9}$ 双口径与接触网络统计（配位数、力链）做机理归因。
