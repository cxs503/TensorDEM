## (1) 案例介绍（物理背景 / 几何 / 参数）

平面应变双轴压缩的无胶结圆盘试样（10×20 抖动三角格，190 颗，r = 0.75 m，ρ = 917 kg/m³，
kn = 1×10⁷ N/m，kt/kn = 0.5，μ = 0.55，`freeze_bond_fraction = 0`，墙摩擦 0，固结 σ₃ = 100 kPa 伺服，
剪切等体积 `lateral_control="isochoric"`）。Mohr-Coulomb 角 `sin φ = (σ_v − σ_h)/(σ_v + σ_h)`（c = 0）。

**R8 遗留问题（H4）**：等容胞元的**能量预算不闭合**——R8 小样（ε̇ = 0.05，应变 0.30）实测
接触层摩擦耗散 **24.53 MW** 而边界输入功 **1.595 MW**（残差 **−1464 %**），且计量仪恒等式已用受控滑动对
验证为精确（27 500 W 进 = 27 500 W 出）。R8 的读法是：无转动自由度内核里接触切向滑移速率由**非仿射**运动决定
（0.18 m/s，约为仿射估计 ε̇·d = 0.075 m/s 的 2.4 倍），在 `v_reg = 0.01` 下摩擦一律饱和，
于是接触层在「高滑移 × 满库仑」上耗散，而边界应力比只反映 net 力链——两者不自洽。

**本单要检验的命题（H4 速率驱动）**：若该预算缺陷是**速率驱动**的（非仿射滑移随 ε̇ 缩放），
则把 ε̇ 降 20 倍（0.05 → 0.0025）后残差应**收缩**向 ≤15 % 闸门；若它**不随速率变**（非仿射滑移是固定几何特征），
则残差保持或恶化——说明临界态协议本身需要重审。
