## 1. 案例介绍

`tensordem.moving_plane_boundary.MovingPlaneNetwork` 是控制体冰网络的可选"移动工具"
边界：一条按 C2 五次多项式 `smooth_plane(t)` 从 `x = L` 压入网络的平面，代替船体对冰
网络的作用。它在 `moving_step()` 里累积两个账本，其中

    tool_impulse -= mean_force * dt,     mean_force = ½ (F_ext(t) + F_ext(t+dt)) · 1

是**工具受冲量**（执行器给网络的冲量取负）。此前的验证只覆盖了能量侧（`tool_work` 对
闭式静力解，REAL）与**冻结网络极限**（冲量求积对闭式，5.2e-14）；**动态**（升压→保持
全窗口）的 ∫F dt 从未有过独立参考，因此在上一单里被如实标为 WITHHELD。

| 参数 | 值 |
|---|---|
| 网格 | `nx × ny = 8 × 2`（方形，`dx = dy = 0.125 m`） |
| 节点 / 总自由度 / 自由自由度 | 27 / 54 / **24**（全 y 固定，左列 x 固定） |
| 右端接触节点 | 8, 17, 26（x-dof 自由） |
| 域 / 厚度 | L = 1.0 m，H = 0.25 m，t = 0.1 m |
| 材料 | E = 1.0e5 Pa，ρ = 900 kg/m³（中心力弹簧，法向冻结） |
| 罚刚度 | `penalty = 50E/L = 5.0e6 N/m` × 支流面积（Σ = 0.025 m²，Σp = 1.25e5 N/m） |
| 时间步 | `dt = 4.314178e-4 s`（模块自定 0.15 × 临界） |
| 行程 / 升压 / 保持 | δmax = 1.0e-3 m，ramp = 0.5 s，hold = 0.05 s |
| 终点时刻 | T = 1275·dt = **0.550058 s**（引擎按整步推进，非名义 0.55 s） |
| 模态 | 24 阶，ω ∈ [34.16, 326.06] rad/s（对 M 归一化） |

## 2. 怎么做的

**关键发现：接触活动集全程冻结。** 罚接触是单侧的 `gap.clamp_min(0)`，一旦某步 gap 被
截断为 0，系统就不再是线性的。实测（引擎与 RK4 两条独立路径）`gap > 0` 全程成立
（RK4 的 `open_fraction = 0`；引擎最小 gap 6.4e-12 只是浮点"贴住"），因此**冻结活动集
的线性模型就是引擎真实积分的模型**，可以给出闭式解。

**(1) 模型钉在引擎上**：`K`、`mass`、罚向量 `p` 全部由模块自身的
`edges/k/n/mass/penalty/areas` 数组组装，并用随机位移 + 指定平面位置复现
`forces()` 的外力（恒等式检查，残差必须是 0，不允许"另写一套模型"）。

**(2) 闭式解（解析基准）**：冻结活动集时

    M q̈ + (K+P) q = P (x_f − s(t) 1),   P = diag(p) 在 3 个右端 x-dof 上

代入特解 `q_p = a + b s(t)`（`(K+P)a = −P x_f`，`(K+P)b = +P 1`；因 `x_f ≡ 1` 故
`q_p = b(s − 1)`，在 s=1 处恰好零位移），余项满足

    M ξ̈ + (K+P) ξ = −M b s̈(t),   ξ(0) = ξ̇(0) = 0

`(K+P)` 对 `M` 归一化后取模态 `ω_k, φ_k`（scipy `eigh(K+P, M)`），得

    η_k(t) = A_k cos ω_k t − (c_k/ω_k) ∫₀ᵗ sin ω_k(t−σ) s̈(σ) dσ,  c_k = φ_kᵀ M b

`s̈` 在 `[0, ramp]` 上是三次多项式（`s` 是五次），故 Duhamel 积分与其一、二次积分
**全部有闭式**：用 `∫P(σ)e^{−iωσ}dσ = e^{iωσ}Σ_m(−1)^m P^{(m)}(σ)/(iω)^{m+1}` 化为
解析式。于是

    J(T) = ∫₀^T [pᵀ(x_f + q(τ)) − (Σp) s(τ)] dτ
         = T(pᵀx_f + pᵀa) + (pᵀb − Σp)∫₀^T s dτ + Σ_k (pᵀφ_k) ∫₀^T η_k dτ

右端三项分别是：常数项、`∫s dτ`（升压段多项式积分 + 保持段线性）、以及模态贡献
`∫η_k dτ = A_k sin ω_kT/ω_k − (c_k/ω_k)·[ (ṡ(T)−ṡ(0)) − Re(e^{iω_kT}H(ω_k)) ]/ω_k`，
其中 `H(ω) = ∫₀^min(T,ramp) s̈(σ)e^{−iωσ}dσ`。

**(3) 独立数值基准（交叉验证闭式代数）**：对同一条力律（含单侧 clamp）做 RK4，步长
`dt/16, /32, /64`，力冲量按 RK4 网格上的梯形求积累积，再做 Richardson 外推。它与闭式
路线**不共享任何代码**，因此能抓住代数错误——事实上它抓住了两次（见 §5）。

**(4) 引擎扫描**：`substeps = 1, 2, 4, 8`（每个外步内细分，力是端点半步格式），比较
`tool_impulse` 与基准。

## 5. 注意点（踩过的坑与局限）

- **闭式路线两次算错，都是被独立 RK4 抓出来的**：①`s̈` 三次多项式的系数整体错位
  一次（写成 `P(σ)` 有常数项），导致 `H(ω)` 与真值差 10 倍；②`∫₀^T s dτ` 在
  `T > ramp` 后仍按"继续下压"延拓，而实际保持段 `s ≡ 1 − depth`，使保持段贡献算成 0。
  两次都表现为"升压段对、保持段漂 16.7%"。教训：**闭式解必须配一条独立数值基准**，
  否则代数的自洽（自己对自己的积分）会给出漂亮的假精确。
- **曾误判"接触张开"**：保持段闭式与 RK4 偏差 16.7% 时，第一假设是单侧接触在振铃中
  张开，实测 `open_fraction = 0`（全程 gap > 0）**证伪**了该假设。把它写在这里，是因为
  "物理假设先行、数值证伪"是本单的主要时间开销。
- **引擎误差随 h 非单调**（2.5e-7 → 2.0e-8 → 2.9e-8 → 4.0e-8，拟合阶 0.74）：总冲量是
  近静态力的时间积分，误差由**无阻尼振铃的相位**决定而非梯形求积；剖面在 1e-7 平台
  上抖动。因此本单**不主张任何收敛阶**，只主张量级（≤2.5e-7）。RK4 自收敛阶 2.15 也
  偏离教科书 4 阶，同样受无阻尼振荡积分限制，仅作基准可信度的量级证据。
- **适用范围**：二维控制体网络（线性中心力弹簧、小应变、法向冻结、单侧罚接触），
  非三维键合 DEM；结论不外推到 `IceDEM3D`。本单验证**账本算术**，不验证冰的物理参数
  （E、罚刚度、阻尼均未标定），也不主张 `tool_impulse` 是船体冲量的物理真值。
- **引擎最小 gap 6.4e-12** 是罚接触"贴住"的浮点残量，并非接触张开；`open_fraction`
  在 dt/64 的 RK4 里出现过 1.2e-5 的单步触及，属于同一类的数值贴零，不影响线性模型
  的有效性判断（这类步占比 1e-5，且未改变轨迹）。

## 6. 误差判定（关键量 vs 基准，是否 < 3 %）

| 关键量 | 基准 | 相对误差 | < 3 % ? |
|---|---|---|---|
| 组装罚外力 | 引擎 `forces()` 外力 | 0（精确） | **是** |
| 闭式 `J`（升压段） | 独立 RK4（dt/32） | 3.78e-06 | **是** |
| 闭式 `J`（全窗口） | 独立 RK4 + Richardson | 2.27e-12 | **是** |
| RK4 基准自收敛散布 | Richardson 外推 | 1.3e-10 | **是** |
| **动态 `tool_impulse`**（子步 1） | 闭式 `J` | **2.54e-07** | **是** |
| 动态 `tool_impulse`（子步 2/4/8） | 闭式 `J` | 2.0e-08 / 2.9e-08 / 4.0e-08 | **是** |
| 逐点历史最大偏差 | 闭式 `J(t)` | 2.03e-07 | **是** |
| 静态 `tool_work` / 冰物理精度 | — | 上一单已判，本单未涉及 | 不适用 |

**WITHHELD 解除判定**：动态 `tool_impulse` 现在有两条独立基准（闭式解析解 + Richardson
外推的 RK4），引擎账本对二者的偏差 ≤ 2.5e-7 ≪ 3 %。证据等级 **REAL**；
