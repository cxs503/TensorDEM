# DEM3D 库仑摩擦历史的坐标系传输与脱开清零（在求解器内的解析复核 + 两处物理缺陷修复）

状态：**已完成**。新增解析基准测试 `tests/test_dem3d_tangential_frame_transport.py`（7 项全绿），
修复 `src/tensordem/dem3d.py` 中 Cundall–Strack 切向历史的两个真实物理缺陷，
复现脚本 `scripts/verify_dem3d_tangential_frame.py`，数字与图见 `docs/dem3d-tangential-frame/`。

## 1. 案例介绍（为什么这是验证欠账）

SIR-PC2|F05 把库仑摩擦接进了 `IceDEM3D.forces()`：每个接触对维护切向位移 `delta_t`，
按 `delta_t += v_t dt` 累积，`F_t = k_t delta_t`，并用 `|F_t| <= mu |F_n|` 截断
（`docs/dem3d_coulomb_friction_cone_verification.md` 内核级验证 + `dem3d_rolling_resistance_verification.md`）。
但**接线之后**的覆盖只有 `tests/test_friction_rolling.py`，其断言是"跑完不报错"和
"|F_t| 不超过锥"，没有任何一条检查切向力的**数值、方向**，也没有检查历史量在
法向转动/接触消失时的含义。这是典型的"已合并功能、未对解析基准复核"的验证欠账：
摩擦是唯一能把剪切力传进冰-结构接触的通道，方向错了不会报错，只会算错阻力。

物理设定（与试件无关，纯接触律测试）：两球、等半径 `R = 0.025 m`、法向穿透 `delta_n = 2.0e-3 m`、
线性罚弹簧 `k_n = 5000 N/m`（无阻尼，`contact_damping = 0`、`contact_damping_model="absolute"`），
因此 `|F_n| = k_n delta_n = 10.0 N` 是精确值；切向刚度 `k_t = k_n`；库仑系数 `mu`。
全部键被删除（`alive[:] = False`），所以 `forces()` 返回的节点力里只有这一个接触对。

## 2. 怎么做的（方法 / 判据）

教材 Cundall–Strack 更新（这就是判据，无自由参数）：

```
delta_t <- R(n_old -> n_new) delta_t + (v_rel - (v_rel.n) n) dt
F_t      = -k_t delta_t          (作用在 i 上)，  +k_t delta_t (作用在 j 上)
|F_t|   <= mu |F_n|
```

由此两条可证伪推论：

1. **法向零泄漏**：切向弹簧嵌在**接触坐标系**里，`F_t . n == 0` 对任意构型成立。刚体转动接触对
   （中心距不变 → `|F_n|` 不变、材料滑移历史不变）后，弹簧必须随坐标系转动：`|F_t|` 保持，
   并且法向分量仍为 0。若把 `delta_t` 存在全局系里，就会出现 `|F_t| sin(theta)` 的假法向力，
   它直接加减法向接触力（既不保能量也不保锥方向）。
2. **脱开清零**：接触消失即忘记历史；否则再接触的球凭空带着已饱和的切向力回来
   （"记忆型黏连"），既非物理也不保能量。

判据取相对容差 `1e-12`（闭式对标，非实验对标），并另设负控：把同一构型下的
"全局系存储"闭式解 `k_t Delta s |sin theta|` 与实测并列，证明测试有分辨力（不是恒等于 0 的空断言）。

## 5. 修复内容（`src/tensordem/dem3d.py`，最小改动）

1. 新增模块级 `_transport_tangential(disp, n_old, n_new)`：用 Rodrigues（非归一化四元数 `(1, n_old x n_new)`）
   把历史切向位移随接触坐标系转动；反向平行（`1+cos -> 0`）退化时退化为投影，仍精确。
2. `_get_tangential_state`：读取历史后统一做坐标系传输（原实现的注释承认"留在全局系，靠投影兜底"，
   但代码里**并没有投影**，注释与实现不符）。
3. `forces()`：每次更新历史后再投影一次，消除传输/累加舍入；
4. 接触丢失清零：候选对为空、或候选对全部不重叠时清空 `_tangential_state`；
   有接触时在 `_update_tangential_state` 内删除不在当前接触集里的键。
   仅在 `update_history=True`（步进拥有者）时执行，探针调用不改变历史。

语义影响面：法向不转动的构型（绝大多数现有回归用例）传输为恒等、投影为恒等，
数值逐位不变 —— 已由 `tests/test_friction_rolling.py`、`tests/test_dem3d_contact_invariants.py`、
`tests/test_threefield_resistance.py` 等 68 项邻域测试回归确认（全绿）。

## 6. 注意点（坑 / 局限）

- **坑 1：`import tensordem` 默认解析到别的 worktree。** 本机 `site-packages`/`PYTHONPATH` 里
  指向 `/root/tp-agent/work/m991/src/tensordem`，直接 `python -m pytest` 会**验证到别人的代码**：
  第一次跑本套测试时 7 项按预期全红，但那是 m991 的旧实现。必用
  `PYTHONPATH=<本工作树>/src`。这类"测试绿但测的不是自己的代码"会静默放过真正的缺陷。
- **坑 2：`forces()` 的返回值是总接触力（法向+切向）**，不是切向力。所有对标必须先扣掉
  `-|F_n| n`（本报告的每个数字都这么做）。直接把 `norm(force)` 当 `|F_t|` 会把锥判据放大成恒真。
- **局限 1：切向历史仍是 Python 逐接触对循环**（`_get_tangential_state` /
  `_update_tangential_state`），大接触数时是性能瓶颈；本轮只保证语义正确，未做向量化重写。
- **局限 2：能量账本没有切向摩擦耗散项。** `dem3d_energy.py` 只累计拖曳与接触法向阻尼，
  `mu > 0` 时 `energy_balance_residual_J` 必然把摩擦耗散算成残差 —— 这是下一个可做的欠账
  （须给出闭式 `int mu |F_n| |v_t| dt` 的对标），本次**未做**。
- **局限 3：本节全部是接触律级解析对标，不是冰力学/船-冰阻力验证**；转动自由度仍然缺席
  （rolling resistance 是 rotationless 替身），所以"滚"只是几何转动，不含角动量。

## 7. 误差判定（显式回答是否 <3%）

| 关键量 | 基准 | 实测相对误差 | 是否 <3% |
|---|---|---|---|
| 饱和切向力 `|F_t|`（mu=0.3） | `mu|F_n| = 3.0 N` 闭式 | 1.0e-15 | 是 |
| 未饱和切向力（mu=1，4 步） | `k_t Δs` 闭式 | ≤ 1.0e-12 | 是 |
| 切向力方向（法向分量） | 0（切平面） | 修复前最大 `|F_t| sin θ`（=100% 方向错误）；修复后 1e-14 N | 修复后是 |
| 刚体转动下 `|F_t|` 保持 | `k_t Δs` 全角度不变 | ≤ 1e-12 | 是 |
| 再接触继承切向力 | 0 | 修复前 3.0 N（相对无穷大）；修复后 8.9e-15 N | 修复后是 |

结论：所有闭式对标项误差 ≤1e-12，远优于 3% 门；**不存在**与实验数据的对标，本页不宣称任何
冰材料或船-冰阻力精度。
