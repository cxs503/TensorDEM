## 1 Why this study

The anchor's acceptance criterion is a *steady-state porosity of a dropped
packing* (10 000 spheres, frictionless / low-friction).  The production wave
ran N = 10000 for both tiers; what was never *quantified* is the finite-size
systematic — how far the N = 10000 value sits from the infinite-N limit.
This study reads the existing run JSONs at N = 1000 / 2000 / 4000 / 10000
(frictionless) and N = 2000 / 10000 (low-friction) and fits
`phi(N) = phi_inf + A N^{-p}` to the ladder.
