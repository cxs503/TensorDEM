# 碎冰翻转 6-DOF 浮冰倾覆动力学与航道清空宽度修正（IN22-N02）

模块 `src/tensordem/floe_6dof.py` · 基准 `benchmarks/channel_6dof_capsize.py` · 图 `benchmarks/channel_6dof_figures.py` · 工件 `artifacts/channel_6dof.json` · 测试 `tests/test_floe_6dof.py`

## 1 案例介绍

碎冰区航道穿越中，浮冰并不总是保持平放：船体与相邻冰块把冰盘压出倾角，冰盘一旦越过某一临界倾角就失去静平衡并翻滚（翻滚后要么侧立、要么换面平放）。H1 引擎（`tensordem.ice_channel`）把倾角做成**锁定自由度**：倾角只由一个单轴摆方程驱动，且不反馈到浮力、接触几何与清空宽度。本节点把浮冰提升为真正的六自由度刚体（x, y, z 平动 + roll, pitch, yaw 转动，四元数姿态），量化倾覆临界角 $\theta_s$，并回答『允许翻滚后清空宽度变多少』。

| 参数 | 取值 | 说明 |
|---|---|---|
| 浮冰几何 | 圆盘 R = 4.6–5.4 m（由场生成器反解） | 厚度 0.3 / 0.5 m 两档 |
| 冰/水密度 | 917 / 1025 kg/m³ | 柱状海冰；密度比 0.895 → 吃水 0.895 t |
| 重力 | 9.80665 m/s² | — |
| 计算域 | 120 m × 60 m | 开放边界，默认场生成器（六角点阵 + 覆盖率反解） |
| 覆盖率 | 0.6 / 0.7 / 0.8 | 3 档 |
| 种子 | 11, 12, 13 | 每档 3 个 |
| 船体 | L = 80 m, B = 20 m, V = 1.6 m/s, x₀ = -40 m | 等宽矩形船体（与 H1 一致） |

## 2 方法与工具链

**(1) 姿态表示。** 每个冰盘带一个单位四元数 $q$（本体系→世界系），角速度在本体系积分，姿态更新用指数映射的精确解 $q \leftarrow q \otimes \exp(\omega_b \Delta t/2)$ 并逐步归一化；因此长时间运行的四元数模长偏差只在舍入量级。

**(2) 倾斜圆盘的静水力学。** 冰盘是本体系内的圆柱 $\rho \le R,\ |\zeta| \le t/2$。取本体系水线法向 $n_b = R_{wb}^{\mathsf T} e_z$、水线偏置 $h = -z_{cg}$，则立柱 $(\xi,\eta)$ 的浸没轴长为 $L = \mathrm{clamp}(\zeta_{lim} + t/2, 0, t)$，$\zeta_{lim} = (h - n_{bx}\xi - n_{by}\eta)/n_{bz}$（$n_{bz}<0$ 时取镜像分支）。用径向 Gauss–Legendre × 方位中点求积一次性得到浸没体积 $V$、浮心 $r_{cb}$、浮力势能与浮力矩 $(R\,r_{cb}) \times F_b$；重力作用于质心，浮力—重力偶是唯一的姿态复原机制。

**(3) 倾覆判据（两条独立路线）。** 把升沉松弛到 $\rho_w V(z^*) = m$，得到姿态势能 $U_c(\phi)$ 与复原力矩 $M_r(\phi) = -\partial U_c/\partial \phi$。
- 力路线：$\theta_s = \arg\max_\phi M_r(\phi)$（受恒定外力矩时的失稳折点）；
- 能量路线：$\theta_s$ = $d^2U_c/d\phi^2$ 的首个零点（含升沉—姿态耦合的 Hessian）。
小角度极限另与经典稳性公式 $k_\phi = \rho_w g V\,GM$、$GM = KB + BM - KG = d/2 + R^2/(4d) - t/2$ 对照。

**(4) 动力学的两组对照。** `tilt_locked` 组逐步调用 H1 的 `IceChannelSimulation.step()`（倾角锁定，几何始终平放，`state_digest` 与 H1 逐位一致 = 回归锁）；`six_dof` 组积分完整姿态，水平接触力/船体力/拖曳力作用在水线压力中心（质心在水线下 $(1-\rho_i/\rho_w)t/2$，因此水平力会压出倾角），浮力矩来自倾斜静水力学；`six_dof_shoulder` 组追加船体肩部下压项 $F_z = -c\,|F_n|$（$c = \tan 15^\circ$），作用在接触侧冰缘 $R/2$ 处——这是船体骑上冰盘、把冰盘压入水下的真实机制。

**(5) 工具链。** PyTorch float64 全张量实现；场生成复用 H1 的六角点阵 + 覆盖率反解（`IceChannelSimulation.from_field`）；18 工况 × 3 组 × 2 时间步 = 108 次穿越分 36 个分片并行（本机 128 核，总 CPU 时间约 4.7 h）；判据数字全部由 `benchmarks/channel_6dof_capsize.py --aggregate` 直接写入工件，本文由 `benchmarks/channel_6dof_report.py` 从工件程序化渲染。

## 5 注意点与局限

- **判据 (c) 是 honest FAIL，原因已定位到度量而不是动力学。** 8/4 ms 的清空宽度全工况最差变化 25.34 %（阈值 5 %），但同一量的中位数只有 2.30 %，而**同组 54 次运行之间的种子间相对标准差是 14.69 %**——清空宽度定义为走廊内最小横向净空的两倍，单个冰块即可改变读数，其内在离散度是时间步敏感度的数倍；倾覆占比在 8/4 ms 之间差 0.0000（完全一致）。因此本节点如实记录 (c) FAIL，并给出该判据在极值统计量上不可满足的证据。

- **本节点没有推翻 H1，而是给出它的适用边界。** 平静水中的 5 m 半径、0.3–0.5 m 厚冰盘稳性极强（GM ≈ 10–14 m），恒定的水平接触力矩只能压出 1–3° 倾角，远低于 $\theta_s \approx$ 11.2–15.0°；只有当船体把冰盘**压下去**（肩部下压项）时，才会出现越过折点的翻滚。
- **求积在 90° 附近退化。** 冰盘侧立时每根立柱的浸没有/无是台阶函数，10×16 求积的浸没体积误差约 0.26 %，因此判据 (f) 在平衡姿态（|γ| ≤ 85°）与初始状态上测量，近 90° 的残差单独如实报告。
- **$\theta_s$ 只按厚度分档。** 冰盘半径在 4.6–5.4 m 内变化时折点变化很小（求积分辨率散布见 3.1），故按厚度取一个代表值；严格做法应逐盘给出。
- **清空宽度是极值统计量。** H1 定义为走廊内最小横向净空的两倍，单个冰块即可决定读数，因此种子离散大，ΔW 的显著性有限。
- **接触仍是投影几何。** 冰—冰、船—冰接触法向取投影平面内的方向，只把作用点抬到水线高度；真正的三维边缘接触（骑叠）未解析。
- **侧立次井的物理性。** 静水力学允许 90° 侧立成为局部极小（吃水从 0.45 m 变到 5 m），现实中这种姿态极难维持；模型因此可能高估『翻滚后稳定侧立』的比例。
- **集群不可用（平台侧问题，如实记录）。** 外协方节点的 torch 需要 GLIBCXX_3.4.32，而系统 libstdc++ 只提供 3.4.30（`libflexiblas.so.3` 亦需 LD_LIBRARY_PATH=/tmp/cl），本次 108 次穿越改在本机 128 核分片完成。
