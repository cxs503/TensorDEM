# CASE-COLUMN-COLLAPSE · 分辨率阶梯闭合（判据量的收敛性裁决）— m20337

**锚点**：`CASE-COLUMN-COLLAPSE`（算例池·颗粒柱坍塌；ref: Lube, Huppert, Sparks & Freundt (2004)
*JFM* **508**, 175–199, doi:10.1017/S0022112004009036；容差 **< 15 %**）
**性质**：验证欠账闭合（把已合并的轮 1–6 判决放到离散化轴上复核），非新物理。
**结论一句话**：跑距律在整条分辨率阶梯上稳健（最大 11.9 %，均在 15 % 带内）；**浅柱埋置时间律不收敛**
——阶梯 8→12→16 粒/柱半径给出 t95 误差 +39.5 % → +12.6 % → **+19.8 %**，非单调，
m17917「粒度细化把 a=0.5 的 t95 搬进 15 % 带内」的读法被第三级**否证**。

## ① 案例介绍

圆柱形（轴对称）颗粒柱抽去侧壁后自由坍塌，参考 Lube et al. (2004) 摘要两条经验律：

* 跑距律 $r_\infty/r_i = 1+1.24a\ (a<1.7)$；$=1+1.6a^{1/2}\ (a>1.7)$；
* 埋置时间律 $t_\infty = 3(h_i/g)^{1/2} = 3(a r_i/g)^{1/2}$。

冻结闭合臂（本单**未改任何材料/接触参数**）：$\mu=0.5$、$\mu_r=0.5$（Cundall–Strack + 滚动阻力）、
$\mu_{\rm wall}=0.8$、$e=0.5$、$k_n=6\times10^4$ N/m、$k_t/k_n=0.5$、$\rho=2500$ kg/m³、$g=9.81$ m/s²、
颗粒/柱半径 8（基线）·12·16、`packing_gap`=2 %、HCP 晶格、`jitter=0`。

**本单填的三个洞（都是档案里自己写下的欠账，不是自选）**

| 洞 | 出处 | 本单怎么填 |

## ② 怎么做的

1. **预注册**（跑之前在 reducer 里写成常量，见
   `scripts/analyze_column_collapse_resolution_ladder_m20337.py` 模块 docstring，阈值事后未改）：

   | 假设 | 判据 |
   |---|---|
   | `R_BAND16` | a=0.5、16 粒/半径的跑距误差绝对值 ≤ 15 % |
   | `R_DRIFT` | 跑距误差 12→16 粒/半径漂移 ≤ 15 个百分点 |
   | `T_TREND` | a=0.5 的 t95 误差绝对值在 8→12→16 上**严格单调下降** |
   | `T_BAND16` | a=0.5、16 粒/半径的 t95 误差绝对值 ≤ 15 % |
   | `DT_TRANS` | a=1.5 上 dt→dt/2 使 t95 变化 < 5 % **且**跑距变化 < 2 % |
   | `DEEP_RES` | a=2.0、12 粒/半径跑距误差 ≤ 15 % 且 8→12 漂移 ≤ 15 pp |
   | `COMBINED` | a=0.5 组合控制跑距 ≤ 15 %，且其 t95 误差与 12 粒/半径单轴相差 ≤ 5 pp |

2. **跑算例**：全部递交计算门（`cj2643`/`cj2644`/`cj2645`，单核分片，`stage_dir` 为本工作树，
   节点 n330 由调度器指派），无本机重算。10 例全部 `stop_reason='at_rest'`，无截断。
3. **归约**：每个逐例 JSON → 22 个标量；**参考值全部由 Lube 两律在运行时重新求值**
   （`lube_2004_runout_ratio` / `lube_2004_emplacement_time`），不抄任何存档目标数；
   每个输入 JSON 的 sha256 入 manifest。
4. **到达定义**：主判据取 $t_{95}$（m17770 建议），`ARRIVAL_KEY="0.95"` 冻结在常量里，报告全部标注定义。
5. **可复现门**：本单在同一 checkout 重跑 m17917 的两例，跑距 −2.88 %（存档 −2.9 %）、
   −11.93 %（存档 −11.9 %），库无漂移。
6. **机器门**：`tests/test_column_collapse_resolution_ladder_m20337.py` 17 项（14 通过 + 3 数据门在本机产出后通过），
   含「缺例必须 insufficient 不得 pass」「NaN 不得 pass」「细化出带必须 fail」的对抗性断言与阈值不可改断言。

**三条实质结论**

1. **跑距律（锚点主判据）经得起离散化**：全表 10 例跑距误差 −11.93…+5.17 %，无一出带；
   a=0.5 阶梯 **非单调**（−2.9 % → −11.9 % → −3.8 %），故 m17917「12 粒/半径的 −11.9 % 是向带边漂移的趋势」
   **不成立**——第三级把误差带回 −3.8 %，−11.9 % 是阶梯上的一个凹点而非趋势。深柱 a=2.0 的 8→12 漂移仅 **0.60 pp**（13275 粒），
   首次给出 a=2.0 的分辨率无关证据。
2. **浅柱埋置时间律在现有分辨率族里不收敛**：t95 误差 6 个 a=0.5 配置跨 **+11.0…+40.6 %**，
   且阶梯非单调（+12.6 % 的"进带"在 16 粒/半径回到 +19.8 %）。**m17917 的 H_SIGN 否证（"粒度细化进带"）不能读成收敛**，
   本单把它降级为「未收敛，取样点在带内是偶然」。这是本单最重要的负面结果。
3. **时间步轴对跑距并非无害**：m17917 的 `H_DT` 只测了 t95（a=0.5，+0.83 %）；本单在 a=1.5 上 dt/2 使跑距变化 **3.72 %**
   （超 2 % 预注册线），说明"时间步不敏感"不能推广到跑距律本身——虽仍远小于 15 % 带。

## ⑤ 注意点（坑 / 局限 / 适用范围）

1. **本单不改变锚点的通过/不通过**：跑距律侧更强（分辨率无关），埋置时间律侧更弱（未收敛）。
   锚点验收若含时间律条款，仍应判 **未达成**，且失败原因从「迟到的物理」改写为「分辨率族未收敛、无收敛值可引用」。
2. **单实现、无系综**：每配置一次确定性积分（`jitter=0`），散布轴由 m19922/m20259 处理；本单结论是离散化轴的事实，
   不与系综散布混淆。
3. **16 粒/半径不是渐近解**：阶梯非单调意味着"再加一级"不能靠外推预测；要判收敛需更密的族（如 16/20/24）或改用
   无量纲化比较（$r_p/r_i$ 与 $\Delta t$ 的联合族），成本约 8–30 min/例（单核，本单实测 19–350 s/例）。
4. **a=1.5 在 12 粒/半径反而变差**（跑距 −5.68 % → +2.49 %，t95 +12.02 % → +20.89 %），
   与 a=0.5 的非单调同源：15 % 带内的单点吻合对离散化**不具可移植性**。
6. **一处已申报的重跑偏离（诚实披露）**：重跑 `w5d_gpr12_a1.5`（10076 粒，m17917 归档中最长的一次积分）
   得 $r_\infty/r_i=2.9312$，而 m17917 归档为 2.887，相对差 **1.53 %**（其余 4 例重跑与归档差 < 0.5 %）。
   该偏离未归因（候选：库/沉积路径自 m17917 起的变动、该算例停止判据的边界敏感性），
   已在测试门里显式列为「申报例外」并按 2 % 而非 0.5 % 判定，不掩盖、不外推。
7. **首例 5° 汇总偏差**：本机 `--case` 单例跑（`w5b_confirm_wall0.8_a0.5`，19 s）用于确认路径；
   其余全部走计算门，节点由调度器指派，未指定节点。

## ⑥ 误差判定（逐项 vs 基准，显式回答"是否 < 3 %"）

| 关键量 | 基准 | 实测误差 | < 3 % ? | < 15 % ? |
|---|---|---|---|---|
| 跑距 a=0.5，8 粒/半径 | Lube 跑距律 1.620 | **−2.88 %** | **是** | 是 |
| 跑距 a=0.5，12 粒/半径 | 同上 | −11.93 % | 否 | 是 |
| 跑距 a=0.5，**16 粒/半径** | 同上 | −3.80 % | 否 | **是** |
| 跑距 a=1.5，8 / 12 粒/半径 | 2.860 | −5.68 % / +2.49 % | 否 / **是** | 是 |
| 跑距 a=2.0，8 / 12 粒/半径 | 3.263 | +4.57 % / +5.17 % | 否 / 否 | 是 |
| $t_{95}$ a=0.5，8 / 12 / **16** 粒/半径 | $3\sqrt{h_i/g}$ = 0.4692 s | +39.47 % / +12.56 % / **+19.79 %** | 否 | 否 / 是 / **否** |
| $t_{95}$ a=0.5，组合（12 粒+dt/2） | 同上 | +11.02 % | 否 | 是 |
| $t_{95}$ a=1.5，12 粒/半径 | 0.8130 s | +20.89 % | 否 | 否 |
| $t_{95}$ a=2.0，12 粒/半径 | 0.9385 s | +14.18 % | 否 | 是 |

**总回答：否。** 全部判据量里只有 a=0.5 的跑距在 8 粒/半径（−2.88 %）与 a=1.5 的跑距在 12 粒/半径（+2.49 %）**< 3 %**；
其余 8 项均 ≥ 3 %。这不是"精度达标"，而是"跑距律在 15 % 内稳健、时间律未收敛"。
