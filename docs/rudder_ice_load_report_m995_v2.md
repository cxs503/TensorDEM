## ① 案例介绍

**物理背景**：船舶在碎冰航道中操舵时，舵叶被冰的压溃/剥落压力加载，载荷经舵杆传入操舵装置。
设计实践（IACS UR F12 类规范、FSICR）用"舵设计冰载荷" `$F_R$` 定尺寸，而物理载荷来自颗粒尺度
压溃—剥落事件序列，幅值取决于冰厚、航速、舵角与冰温。本节点建链路：
**温度依赖冰强度 → DEM-FSM 冰-舵接触力时历 → 10 ms 包络 → 舵杆弯曲/扭转校核 → 与规则值比对**。

**几何与工况（参考工况）**：

| 参数 | 值 |
|---|---|
| 舵叶（展 × 弦 × 厚） | 0.90 × 0.60 × 0.08 m |
| 舵角 δ | 30° |
| 冰厚 h / 冰粒半径 r | 0.60 m / 0.075 m |
| 冰场点阵 | 9 × 11 × 4 = 396 粒，键 3677 根 |
| 船速 / 法向压入速度 | 2.0 m/s / v·sin δ = 1.00 m/s |
| 冰温 T | -10 ℃ |
| 名义加载面积 / 接触宽度 | 0.360 m² / 0.60 m |
| 显式时间步 dt | 3.709e-05 s（密度缩放 ×100） |
| 舵杆参考截面 | D_o = 0.60 m，壁厚 0.06 m |
| 压入力 / 键刚度 | 5.0e+07 / 5.0e+07 N/m |

## ② 怎么做的

1. **温度依赖冰强度**：`σ_ice(T) = σ_0·exp(-α(T-T_ref))`，对列状一年冰压缩强度文献锚点
   （-5…-30 ℃）在 ln σ 空间最小二乘标定 → σ_0 = 5.348 MPa
   @ T_ref = -10 ℃，α = 0.03264 1/K；
   锚点最大残差 **10.8 %**，σ(-30)/σ(-5) = 2.26。
2. **DEM-FSM 耦合**：冰场复用 `IceDEM3D` 键合球点阵（键力/接触表/显式积分），舵叶为刚性斜板
   （板面与冰前缘平行，宽平压入 = 设计侧推工况，`prepare = "broadside (flat-on-flat) indentation of the ice edge"`）；每个近接触颗粒带
   **断裂状态机** `FREE → ELASTIC → CRUSHING → CLEARED`：压入超过 `crush_strain·r` 进入压溃状态，
   接触力被 `p_crush·A_cell·w` 截断，`p_crush = σ_ice(T)·(v_n/v_ref)^0.2`；压入超过 `spall_strain·r`
   触发剥落 —— 不可逆断键 + 碎冰残余压力 `f_res = 0.6` 倍的压溃上限。`w` 是颗粒胞元落在叶片
   范围内的面积分数，用于消除基于球心检测的 O(r) 面积偏置（实测加权接触面积收敛到名义加载面积）。
3. **规则卡（UR F12 风格）**：`F_R = C_class·C_p·σ_ice(T)·(v_n/v_ref)^0.2·A_loaded`，
   `A_loaded = h·min(chord, h/sin δ)`，`C_p = 0.55`
   （面积效应带 0.5–0.7 的中值，**先于 DEM 计算设定**），`certified_rule_text =
   False`（需逐字取自规范文本的冰级/板格系数置 1，故为"规范风格"校核）。
4. **操舵装置校核**：`M = F·lever`、`Tq = F·lever_t`、`σ_b = M/W`、`τ = Tq/W_t`、
   `σ_vm = sqrt(σ_b² + 3τ²)` 对比 `σ_y/1.5 = 156.7 MPa`，给出 PASS/FAIL 与利用率。
5. **场量后处理（本次新增）**：参考工况重跑后在三个压入阶段（25 mm, 60 mm, 135 mm）
   对每个接触颗粒取 `p_grain = |F| / (w·(2r)²)`，按舵面弦向 b × 展向 z 坐标绘制压力场；同时给出
   面内矢量和（即规范比对用的法向载荷）与标量和，用于区分"逐颗粒压力"与"合力等效压力"。

**工具链**：PyTorch（CPU，4 线程）+ matplotlib；`scripts/benchmark_rudder_ice_load.py` 产出
`artifacts/rudder_ice_load/` 下的 `report.json`、`thickness.csv`、`design_load_scan.csv` 与 5 张 PNG；
新增场量图由 `artifacts/rudder_ice_load/plot_pressure_field.py` 生成
（`pressure_field.json` 为其数据记录）。`pytest tests/test_rudder_ice_load.py` = 24 项全绿（本单复跑：24 passed）。

## ⑤ 注意点（坑、局限与适用范围）

1. **原报告缺陷与本次修复**：报告 824 第 ④ 节只有文字描述、无图片链接，`figures` 字段只有
   `{name, caption}` 而无 `png_base64`，导致报告页无图可看。本报告两类图齐备并全部内嵌；
   新增的场量图用于补足"场量云图"这一缺项（原 5 张均为标量时历/扫描曲线）。
2. **场量图的粒度**：点阵间距 2r = 0.15 m，600 × 900 mm 舵面仅由 4 × 3 胞元覆盖，因此"压力场"
   本质是 20 个颗粒胞元的离散采样，不是连续云图；面内梯度被粗粒化抹平。加密到 0.06 m 量级
   才能看到真实的压力斑块结构（受算力限制，本节点只做到了载荷量的加密验证）。
3. **逐颗粒压力 vs 合力等效压力**：`p_grain = |F|/A` 的标量和对应 1156 kN，
   而面内矢量和为 866.7 kN——差值是盒型 SDF 法向在舵面边缘
   发生方向偏转所致（边缘颗粒法向含弦向/展向分量）。规范比对必须用矢量和（有效压力
   2.41 MPa = 0.45·σ_c），
   不能把逐颗粒压力标量和当载荷。
4. **规范系数为二次文献重建**：`C_p` 与冰级/面积项需按规范原文取值；本报告为"规范风格"校核。
   Korzhavin 上界（I = 2，窄压头）为独立上参考，DEM 低于它 -59.1 %，符合宽平接触无压头增强的物理。
5. **粗粒化 + 残余压力系数**：0.075 m 粒径下加载面仅跨 16 粒；`f_res = 0.6` 是唯一无第一性原理
   取值的参数，0.35/0.60/1.00 对应平均压力系数 0.26/0.45/0.75 σ_c（规范带 0.5–0.7 σ_c 落在其中），
   故 ±15 % 点比对本质上是该参数的选择问题，需独立碎冰压力实测才能收窄。
6. **剪切键破坏在粗粒场关闭**（`shear_breaking_strain = 1e9`，粗粒点阵的 Green-Lagrange 剪切度量
   未标定）；限载由拉伸断裂 + FSM 压溃上限提供。密度缩放 ×100 扭曲碎块惯性，dt 减半试验给出
   +0.0 % 变化，支持准静态假设。
7. **无模型试验数据**：本节点无试验时历，故不做实验交叉验证；比对对象为规范风格设计值与文献强度锚点。
8. **可复现性**：场量脚本重跑参考工况得到包络 866.7 kN
   （campaign 记录 866.7 kN），断键 225 /
   剥落事件 20 与 campaign 完全一致，说明工件与场量图同源。
   复现需 W5-N01 分支的模块（`agent/m995`），本单只改报告与工件，未改动业务代码。
