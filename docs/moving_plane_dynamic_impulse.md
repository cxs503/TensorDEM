# 移动工具边界的**动态** `tool_impulse`：闭式参考与 WITHHELD 解除

状态：验证欠账清偿（selfstart，2026-11-03）。`docs/dem3d_moving_plane_ledger_verification.md`
把冻结网络极限下的 `tool_work` / `tool_impulse` 升级为 REAL，但把**动态** `tool_impulse`
留作 `WITHHELD`（"动态情形没有独立参考，未做 ∫F dt 的独立数值积分对照"）。本单给出该量
的三条互相独立的参考，判定为 **REAL**：引擎相对误差 ≤ 5.6e-6（≪ 3 %），且账本满足解析
动量恒等式到 5e-12。

- 参考实现：`src/tensordem/moving_plane_impulse.py`
- 脚本：`scripts/verify_moving_plane_dynamic_impulse.py`
- 测试：`tests/test_moving_plane_dynamic_impulse.py`（14 例）
- 产物：`docs/moving-plane-dynamic-impulse/{audit.json,tables.md,figures/fig1_force_history.png,figures/fig2_convergence.png}`

## 1 案例介绍：为什么这个量值得审

`tensordem.moving_plane_boundary.MovingPlaneNetwork` 是控制体冰网络的可选"移动船体平面"边界：
一条以 C2 五次多项式 `smooth_plane(t)` 压入网络的平面，代替船体对冰网络的作用。它对外报告两个
账本，其中 `tool_impulse = ∫ F dt`（`F` 为平面对网络的罚接触合力）是**冲量/动量账**，
在冰区阻力与能量审计里与 `tool_work` 并列使用。

此前的证据结构是"半边真"：`tool_work` 有闭式静力解（`½Fδ`，相对误差 1.8e-5），而
`tool_impulse` 只在**冻结网络**（把弹性自由度锁死，`F = Σ P_i δ` 成为纯罚弹簧）下与闭式值
对到 5.2e-14 —— 那是平凡情形：真实运行中网络是弹性的、有惯性、会振铃，`∫F dt` 与冻结值
可以差一个量级（本单 ramp = 0.5 s 时冻结值 2.26 N·s vs 真实值 0.686 N·s）。也就是说
`WITHHELD` 覆盖的正是模型**实际运行**的工况。

| 参数 | 值 |
|---|---|
| 网格 | `nx × ny = 8 × 2`，`dx = dy = 0.125 m` |
| 节点 / 总自由度 / **自由**自由度 | 27 / 54 / **24**（y 全约束，左列 x 约束） |
| 域 / 厚度 | L = 1.0 m，H = 0.25 m，t = 0.1 m |
| 材料 | E = 1.0e5 Pa，ρ = 900 kg/m³（中心力弹簧，法向冻结） |
| 罚刚度 | `50E/L`，参考节点 tributary 权重合计 `ΣP = 125000 N/m` |
| 自然频率 | ω ∈ [34.16, 326.06] rad/s（周期 0.019–0.18 s） |
| 模块时间步 | `dt = 4.314e-4 s`（0.15 × 临界） |
| 平面行程 / 形状 | δmax = 1.0e-3 m，`Q(s) = s³(10 − 15s + 6s²)`（C2，两端 v、a 为零） |
| 静力量级 | `F_static(δmax) = 2.7506 N`（`dF/dδ = 2750.6 N/m`） |

## 2 怎么做的：为什么有闭式解

网络是**线性中心力弹簧**（`e = (u_j − u_i)·n`，法向冻结）+ **gap 一次**的罚接触。数值上
证实接触在全程保持激活（`gap_min > 0`，见 §3 表 E 末列），故活动集不变，自由自由度满足

```
M ü + A u = p(t) q − q⊙x_f ,   A = K_ff + Q_ff ,  q = diag(Q)_ff ,  x_f 初始坐标
```

`M` 为集中质量对角阵，`A` 对称正定（网络被左列锚固，无刚体模态，`ω_min = 34.16 > 0`）。
把 `u` 拆成瞬时静力解 `u_s(p) = A⁻¹(p q − q⊙x_f)` 与振动 `z`：

```
M z̈ + A z = −M A⁻¹ q · p̈(t) ;   z(0) = ż(0) = 0
```

`B = M^{-1/2} A M^{-1/2} = V Λ Vᵀ`，`w = M^{1/2}·A⁻¹ q` 为激振投影，于是

```
z(t) = M^{-1/2} V Z(t),  Z_k(t) = −w_k/ω_k · ∫₀^t sin(ω_k(t−s)) p̈(s) ds
J(T) = qᵀ(x_f T − 1∫p) + qᵀ A⁻¹(q∫p − q⊙x_f T) + qᵀ ∫₀^T z dt
∫₀^T Z_k dt = −w_k/ω_k² [ ∫₀^T p̈ ds − ∫₀^T p̈(s)cos(ω_k(T−s)) ds ]
```

关键便利：`p` 是五次多项式 ⇒ `p̈` 在 `[0, ramp]` 上是**三次多项式**、之后恒零，所以两个剩余
积分都是初等的（多项式–指数矩，`poly_cos_moment` 的复数递归闭式）。全程**不需要时间推进**，
不重用引擎的梯形求积，也没有任何拟合。

三条互相独立的参考路线：

| 路线 | 构造 | 复用引擎的什么 |
|---|---|---|
| ref-1 模态闭式 | 上式（特征分解 + 矩的正闭式） | 只用引擎的 `edges/k/n/mass/penalty/areas` 数组 |
| ref-2 ODE 积分 | `scipy` DOP853，`rtol 1e-12`，独立 RHS + 梯形求积 | 仅线性算子 |
| ref-3 动量恒等式 | 一次积分 `A∫u dt = ∫b dt − M u̇(T)` ⇒ 只用**引擎终态速度** + 闭式线代 | 引擎终态速度（状态，不是积分） |

三条路线连"线性算子"的组装都共享，但求解路径完全不同；ref-3 尤其重要——它不含任何时间积分，
所以能独立判定闭式本身，也能判定引擎账本的代数正确性。

### 附带的判据修正（README 级）

本单同时确认了一处**文档口径**问题（不是代码缺陷）：旧文档 §3 把"冻结网络"下的冲量闭式值
2.26494 N·s 与动态账本并列，容易被读成"动态值应当趋近 2.26 N·s"。实际动态值（ramp 0.5 s）
是 0.686 N·s。冻结值对应的物理是 `ΣP·δ` 的纯罚弹簧，与弹性网络不是同一极限；动态量应趋近的是
**准静态弹性**积分 `∫ F_static(p(t)) dt`（表 G）。

| 0.05 | 2.686090e-4 | 2.686090e-4 | 5.6e-09 |
| 0.20 | 1.426791e-2 | 1.426791e-2 | 3.1e-09 |

| 1.50 | 2.7501293401 | 2.7508098301 | **2.5e-04** |

T = 1.5 s 落在**保持段**（ramp = 1.0 s 之后）：该行 2.5e-4 的不一致出在**参考路线自己**——ref-2
用 12001 个均匀样本对持续振铃（326 rad/s）的力信号做梯形求积，保持段内振铃不衰减，梯形偏差

- 同一闭式在 T = 1.0 s（同一样本密度）与 ref-2 对到 2.9e-10；
- 在长 horizon 上由**无求积**的 ref-3 直接认证：ramp = 2.0 s、T = 2.0 s 时 ref-3 与闭式一致到
  4.9e-12（表 D），且引擎账本与闭式一致到 1.3e-8（表 E）。

因此 §6 的误差判定用 ref-1 ↔ ref-3 与 ref-1 ↔ 引擎两条路线，不用这一行。

## 5 注意点与局限

- **未发现缺陷**：本单是验证欠账清偿，不是修复单；`tool_impulse` 的端点力梯形求积与罚律代数
  都正确，O(dt²) 收敛符合格式。
- **闭式的前提**是"接触活动集不变"。本单用 `gap_min > 0` **实测**该前提（表 E 末列、
  `test_contact_stays_active_over_the_whole_ramp`），不是假定。若某工况出现脱离/再接触，
  本闭式不适用（需按活动集分段拼接），本单未实现。
- **阻尼未建模**：网络无阻尼，振铃不衰减，因此保持段内 `J` 的 O(dt²) 误差不再抵消（表 C 的
  T = 1.5 s 行即为参考路线自身在此处的采样偏差，见 §3 说明）。真实冰网络有接触阻尼，本单未覆盖。
- **适用范围**：二维控制体网络（线性中心力弹簧、冻结法向、小应变），不是三维键合 DEM；
  不外推到 `IceDEM3D` 的接触路径。
- **文档口径修正**：旧文档 §3 冻结闭式冲量 2.26494 N·s 与动态值并列易被误读，动态极限应为
  `∫F_static dt`（表 G）；旧条目已就地加注指向本文件，其余内容不改（append-only）。
- **本单未做**：罚刚度依赖的敏感性扫描（`50E/L` 只有单一取值）、三维版本、带阻尼网络、
  活动集切换工况。
