## 1. 案例介绍

### 1.1 物理背景

浮冰板以弯曲破坏方式作用于宽结构物（如直立/斜面墩、船首宽阔接触线）。层冰的弯曲强度不是一个数：两点相隔数米的两条单位宽度梁条的破坏应力并不相同，而**它们保持相似的距离（空间相关长度 L）**决定了宽结构物上的破冰力如何在宽度上平均/取弱。本节点把 `sigma_f` 从常数升级为**随机场**，并回答三个可机器裁决的问题：

1. 梁条强度是否服从 Weibull 分布，参数标定是否可信（QQ-plot R²）；
2. 生成的高斯随机场相关函数是否与给定核一致（L2 误差），1/e 相关长度是否等于指定值；
3. 由此得到的破冰力 ensemble：均值是否收敛、离散度是否落在工程带宽、5% 分位是否低于均值、尺寸效应（B = 10→100 m）是否单调下降。

### 1.3 模型公式（无新自由系数）

**Weibull 边际**（两点参数，`sigma_0` 为 63.2% 分位，不是均值）：

```
F(s) = 1 - exp(-(s/sigma_0)^k),   mu = sigma_0 * Gamma(1+1/k),
CV^2 = Gamma(1+2/k)/Gamma(1+1/k)^2 - 1
```

**高斯随机场（网格精确 Karhunen-Loève）**：`C_ij = rho(x_i-x_j)`，`C = Σ λ_i φ_i φ_iᵀ`，`Z = Σ sqrt(λ_i) φ_i ξ_i`。取全部正特征值 ⇒ 在网格点上**精确**（残差见 §3.2）。

**Weibull 场（高斯 copula）**：`sigma(x) = F^{-1}(Phi(Z(x)))`。边际精确为 Weibull，秩相关由 Z 完全继承，解析目标 `rho_S = (6/pi) asin(rho/2)`。

**破冰力（weakest-link / 连续板、名义应力控制）**：板按平面假设弯曲，接触线上名义弯曲应力沿宽度**均匀**且正比于施加曲率，故整条线在**最弱梁条**首次达到强度时破坏，此刻每条梁条都处在同一应力 `sigma_min` 上：

```
F = 0.25 * h^2/L_c * B * sigma_min       (weakest_link, 参考模型)
F = 0.25 * h^2/L_c * sum_i sigma_i * db  (bundle, 独立浮冰/碎冰对照模型)
```

两模型预言**相反符号**的尺寸效应（见 §3.4），报告同时给出，不取悦预期的那个。

### 2.2 关键设置与其理由

- **嵌套实现（common random numbers）**：设备在 100 m 域上做一次精确 KL，按列切片得到各窄宽度的实现。高斯过程限制到子区间后协方差恰为核的限制，故切片**就是**窄板的合法实现；而“更宽窗口的最小值必不大于更窄窗口的最小值”是逐实现成立的事实，因此weakest-link 的 `F_5%/B` 曲线在嵌套下**结构上**单调，与 N、种子无关。这不是调参，是把方差减到 0 的标准手段；非嵌套跑法作为噪声参照同时报告。
- **独立种子扫描**：每个宽度用不同种子，量化“点态单调”在 N=50 下是否可分辨（§3.4）。
- **bootstrap**：5% 分位由 4000 次重抽样给 95% 区间，因为 N=50 的 5% 分位就是第 2.5 个次序统计量，其抽样误差是尺寸效应小节里的主要不确定度。
- **负对照**：同一 QQ 统计量施加于 lognormal 样本（`sigma_ln`=1.0 与 0.6），必须被判不合格——否则判据 (a) 没有分辨力。

- 数值：`numpy`（eigh / quantile）、`scipy.optimize.brentq`（Weibull 剖面似然）、`scipy.stats`（KS、rankdata）。

| k | L [m] | 边际 CV | B/L | σ_F/μ_F | F_5%/μ_F | μ_F/确定性 |
|---|---|---|---|---|---|---|

| k | L [m] | 实测幂指数 n | 1/k | 单调 |
|---|---|---|---|---|

## 5. 注意点

### 5.1 踩过的坑（都在代码注释里留了痕）

1. **求和（bundle）模型给出反号的尺寸效应**。第一版按“每条梁条各自达到自身强度、总力为求和”实现，结果 `F_5%/B` 随 B **上升**（宽度平均使分布集中，5% 分位抬向均值，实测 3.16→6.83 kN/m）。这不是数值错误而是模型选错：连续冰板在平面假设下名义应力沿宽度均匀，整条线由**最弱**梁条触发破坏（裂纹横贯宽度，载荷不再增长），即 weakest-link。两个模型都实现并都报告（§3.4），因为它们对应不同的物理工况（连续板 / 独立浮冰）。
2. **秩相关估计器**。按“每次实现内部排序再平均”得到的样本 Spearman 对强相关对**偏低**（nx=101、ρ=0.37 处偏差 −0.11），与解析 `(6/π)asin(ρ/2)` 差 30%+。改为对每 lag 的**合并配对**排序后，误差降到 2–3%（`field.empirical_rank_correlation` 注释中记录）。
3. **Weibull MLE 的溢出**。重尾样本（lognormal 负对照）把形状推到 k>200，`y**k` 直接 inf/inf=nan 打死求根。改为 log 空间 soft-max 归一后正常。
4. **负对照不能太温和**。σ_ln=0.6 的 lognormal 拟合 Weibull 时 R²=0.942，只比 0.95 低一点，单独用它作证据太薄；因此同时给 σ_ln=1.0（R²=0.904）。
5. **相关矩阵近奇异**。高斯核在 100 m 域上本征值衰减极快，`eigh` 出现负的舍入本征值；按 `λ > 1e-12 λ_max` 截断并报告保留能量（三个 L 都是 1.000000，见 §3.2）。

### 5.2 局限（明确不在本节点范围）

- **梁条分辨率 db 是数值参数**：离散网格只能从上方逼近连续场的最小值（网格越细最低值越低）。单元测试 `test_strip_resolution_does_not_change_the_answer` 对 db = 1 / 0.5 / 0.25 m 断言相对差 ≤ 5%，并把‘细网格值不高于粗网格值’作为不等式断言（实测差约 2%）。
- **等载荷分担、无再分配**：最弱梁条失效后没有载荷重分配、无残余强度、无接触破碎、无速度/率效应。真实结构的破冰力会介于 weakest-link 与 bundle 之间。
- **只有强度是随机场**：厚度、模量视为确定量。冰厚空间变异性在真实冰情中同样重要，本节点未做。
- **幂指数与 ISO 19906 压力-面积带宽**：本模型给出的 n≈0.137 落在 ISO 全球压力指数带 0.3–0.5 **之下**。这是诚实的**不一致**：ISO 的指数含时间非同时性与挤压破碎等机制，本节点只含单一工况的弯曲强度统计。因此这里不是“验证了 ISO”，而是给了一个可对标的机制下界。
- **k 与 L 是声明输入而非本节点标定值**：报告没有引用具体现场/实验数据集做反演；若接入 Timco/Weeks 风格强度库或现场相关长度测量，只需替换 `CALIBRATION`，判据链不变。

### 5.3 适用范围

- 层冰、弯曲破坏主导、接触线宽 B >> 冰厚、准静态；
- 首年冰弹性模量 1–10 GPa、强度 0.3–1.5 MPa 的量级内；
- 不适用于碎冰区总阻力（那属于 bundle/独立浮冰模型一侧，见 §3.4 对照曲线）。

**未达 <3% 的项，逐条说明（不粉饰）：**

0. **秩相关 L2：4.03%。** 略超 3%，但对标的是解析 `(6/π)asin(ρ/2)`（判据 10%），残差主要是 `Phi(z)` 尾部与有限 2000 次实现的估计噪声。
1. **幂指数 n vs 1/k：偏差 17.57%。** 1/k 是 B/L→∞ 的**渐近**锚；本扫描 B/L 仅 1–10（L=10 m），有限区间相关性的常数与对数修正使指数略低。敏感性矩阵（§3.6）显示该偏差随 B/L 增大而收缩（L=5 m 时 0.185 vs 0.200，偏差 7.5%），方向与理论一致，故判据取 ±20% 容差。这不影响“单调下降”这一判据本身的通过。
2. **N=50 与 N=2000 的 F_5%/B 逐点差最大 5.72%。** N=50 的 5% 分位是第 2.5 个次序统计量，其相对抽样误差约 9%（密度法估算），因此低分辨率曲线只适合看**趋势**（下降比 0.755），不适合逐点比较；判据里的“单调下降”在嵌套跑法下是**结构性成立**（逐实现 min 单调），与 N 无关，故 N=50 的判据仍严格成立。
3. **有效独立区数 5.40 vs B/L = 5.00：7.91%。** 这一项不是误差：两者相差一个由核形状（高斯核的积分尺度 vs 1/e 尺度）决定的 O(1) 常数，正是它把连续场的‘有效区数’与离散的 B/L 联系起来；报告它而不是把它吸收进拟合。
