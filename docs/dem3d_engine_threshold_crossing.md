# 时步稳定判据的引擎级验证：越过阈值实测 + 耦合稳定域修正（d²+2g ≤ 4）

状态：验证欠账结清 + 已合并判据的一处数学更正（2026-11-04，selfstart）。
工具：`scripts/verify_engine_threshold_crossing.py`；判据测试：`tests/test_engine_threshold_crossing.py`；
生成物：`docs/dem3d-engine-threshold-crossing/{metrics.json, summary.md, fig1_growth_vs_dt.png, fig2_energy_histories.png}`。

## 1. 欠账是什么

`docs/dem3d_timestep_stability.md`（已合并）自己的证据表里有两行关键状态：

| 行 | 原状态 | 本单结论 |
|---|---|---|
| `Engine-level threshold crossing verified dynamically` | 【未验证】 | 【已证实】（本文 §4） |
| `Stability region is exactly d <= 2 and g <= 2` | 【已证实】 | **【已更正】**：矩形只是必要条件，真域为 `0 ≤ g ≤ 2` 且 `d² + 2g ≤ 4` |

第一行长期无法验证的原因是结构性的：`IceDEM3D.__init__` 拒绝 `dt > DEM3DConfig.recommended_dt`，
而引擎实际用的步长只有阈值的 1/45（实测 margin = 45.0），所以**通过公开构造器永远到不了阈值**。
第二行则是纯数学错误：对 `A = [[1−d², dt(1−g)], [−dt ω², 1−g]]`，两根都在单位圆内 ⟺
`|det| ≤ 1` 且 `|tr| ≤ 1 + det`，即 `0 ≤ g ≤ 2`、`d² + 2g ≤ 4`。旧的"矩形"在
`d = g = 1.5` 处通过两条轴向判据，却给出根 `0.25` 与 `−2`（ρ = 2）。

## 2. 案例与方法

物理背景：冰-船/冰-结构 DEM 用 semi-implicit（symplectic）Euler：
`v←v+dt·f/m`，`x←x+dt·v`，力 = 轴向键弹簧 + 接触弹簧 + 速度比例阻尼。该格式的稳定性是
"能不能算下去"的前提，也是 `recommended_dt` 与 `stability_report` 的唯一依据。

几何/参数表（`metrics.json: lattice`）：

| 项 | 值 |
|---|---|
| 晶格 | 7 × 5 × 2 = 70 粒子，459 键（轴向 + 面/体对角，13 邻域） |
| 半径 / 密度 | 0.025 m / 917 kg·m⁻³ |
| 键刚度 k_b | 2000 N/m，接触阻尼 0，摩擦 0 |
| 平衡态 | 位置与 rest_length 同步放大 1.002 → **零力平衡**且留 1e-4 m 接触间隙 |
| 扰动幅值 | 1e-9 m（应变 ~2e-8，远小于 breaking_strain 0.015，故保持线性、不触发断裂/接触） |

流程（全部参考量独立于引擎自述）：

1. **切线刚度矩阵**：对 `IceDEM3D.forces(update_fracture=False, update_history=False)` 逐列探针
   `K[:,k] = −(f(x0+δe_k) − f(x0))/δ`，δ = 1e-9（含 Richardson 复算 δ/10）。
   质量检查：平衡残差 1.8e-13 N，相对不对称 6.7e-9，Richardson 相对变化 6.3e-8。
2. **模态数据**：`K` 稠密特征分解 → `ω_max`；与 `stability.gershgorin_omega_bound` 比较。
3. **步进矩阵**：用引擎自己的更新式由 `K` 组装 2N×2N 的 `A`，稠密谱半径 = 预测 1；
   `stability.symplectic_euler_growth_factor(dt, ω_max, γ)` = 预测 2。
4. **引擎实测**：构造后在 `model.dt` 上**直接写入**越界步长（唯一可越界的内部通道，仅验证用），
   以 `A` 的主特征向量播种（纯模态），逐步行进，用 `‖z_n‖/‖z_0‖` 的 n 次方根读每步增长。
5. **分类**：ρ > 1 为指数增长；ρ = 1 的临界/稳定点用机械能（动能 + 键弹性能）的 log-log 斜率判别
   （斜率 ≈ 2 即 E ∝ n²，代数增长；|斜率| ≈ 0 即能量有界）。

## 3. 计算结果

**模态与保守度**（`summary.md`）：`ω_exact = 622.42 rad/s`，Gershgorin 界 `1064.43 rad/s`
→ 界比精确值**保守 1.7101 倍**（即 `recommended_dt` 在纯键弹性情形下保守 ~1.71 倍）；
6 个零模态（自由体的刚体模态）；`dt_crit = 2/ω = 3.213e−3 s`，引擎 `recommended_dt = 7.139e−5 s`，
引擎裕度 **45.01**。

**无阻尼穿越阈值（g = 0）**——每步增长率实测 vs 步进矩阵预测：

| d = dt·ω | ρ 稠密 | ρ 闭式 | ρ 引擎实测 | 相对误差 | 步数 |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 1.000 | 1.000000 | 1.000000 | 1.000000010 | 5.9e-10 | 800 |
| 1.980 | 1.000000 | 1.000000 | 1.000000020 | 3.7e-11 | 800 |
| 2.000 | 1.000000 | 1.000000 | 1.000001191 | 1.2e-06 | 800 |
| 2.010 | 1.221301 | 1.221301 | 1.221301790 | 5.7e-07 | 89 |
| 2.020 | 1.326584 | 1.326584 | 1.326584079 | 2.6e-07 | 63 |
| 2.100 | 1.877328 | 1.877328 | 1.877328006 | 2.1e-08 | 28 |

结论：**引擎实际步进 = 被分析的那个格式，逐位一致**；阈值在 d = 2 处是尖锐的（2.00 → 1.0000，
2.01 → 1.2213，一步之差的步长使每步放大 22%）。临界点 d = 2 上能量呈代数增长（实测
log-log 斜率 1.79–2.01，图 2 左：E ∝ n²，800 步内 E/E0 仅 2.4e3 而非指数爆炸）。

**阻尼耦合域（矩形判据 vs 精确判据）**：

| g = dt·γ | d = dt·ω | d²+2g | 矩形判据 | ρ 稠密 | ρ 引擎实测 | 结论 |
| ---: | ---: | ---: | --- | ---: | ---: | --- |
| 0.050 | 0.800 | 0.740 | stable | 1.000000 | 1.000000 | 有界（正确） |
| 1.000 | 1.400 | 3.960 | stable | 1.000000 | 1.000000 | 有界（正确） |
| 1.000 | 1.428 | 4.040 | stable | 1.040200 | 1.040200 | **引擎发散（矩形误判）** |
| 1.500 | 1.500 | 5.250 | stable | 2.000000 | 2.000000 | **引擎发散，引擎实测每步 ×2.0** |
| 1.950 | 0.800 | 4.540 | stable | 1.313344 | 1.313344 | **引擎发散（矩形误判）** |

`d = g = 1.5` 是决定性反例：`min(2/ω, 2m/c)` 认为安全（d=1.5<2、g=1.5<2），引擎实测每步放大
**2.000000 倍**（10 步 ×1024，28 步内位移从 1e-9 m 涨到 2e-5 m 量级）。去掉幅值上限后该点连续
1500 步也未触发 `FloatingPointError`（位移仅到 1.5e-3 m，键已按 `breaking_strain = 0.015` 断裂，
线性区已离开）——即**引擎不会替使用者报错，只会静默地给出非物理结果**。

## 4. 判据修正（已落 `src/tensordem/stability.py`）

- 新增 `coupled_timestep_limit(ω, γ) = 4 / (sqrt(γ² + 4ω²) + γ)`（无相减抵消的稳定写法），
  由 `d² + 2g = 4` 解得；`γ = 0` 退化为 `2/ω`，`ω = 0` 退化为 `2/γ`。
- `critical_timestep` 改为 `min(coupled, elastic, damping)`；单极限情形数值不变，耦合情形严格更小。
- `stability_report` 增 `coupled_dt_limit_s`、`axis_dt_limit_s`、`stability_region_value: (dt·ω)² + 2 dt·γ`、
  `growth_factor_including_rigid_modes = max(1, ρ_top)`，`binding_limit` 增加 `"coupled"` 分支。
- 只改判据，不改积分器、不改任何默认步长：引擎裕度 45 不变，历史回归工件逐位不变。

## 5. 注意点（坑与适用边界）

1. **PROBE 线性化误差**：前向差分探针带 O(δ/L0) 几何项，实测相对不对称 6.7e-9；再小 δ 会撞浮点噪声，
   所以 `K` 的精度只到 ~1e-8，实测/预测的 1e-7 级差异即来自此，不是引擎偏差。
2. **必须造出"零力平衡 + 接触间隙"**：晶格原始间距恰为 2R，任何压缩扰动都会激活单边接触弹簧
   （k_c = 5000 > k_b），破坏线性性。做法是把位置与 rest_length 同步放大 1.002。
3. **相邻模态的谱条件数**：`|λ| = 1` 处有大量退化模态（刚体 + 临界），用左特征向量投影或主特征向量
   播种都可，但**不能**在退化点指望"某一条特征向量"来定义主模态；临界点一律用能量代数增长判别。
4. **右/左特征向量**：`A` 非对称，本文用主特征向量播种 + 2-范数比值读增长率；这对实主特征值精确，
   对复共轭对（只出现在 ρ = 1 处）不敏感——故未用于临界判定。
5. **判决不含接触阻尼非比例项**：本文只覆盖键弹性 + 速度比例阻尼（C = cI，与 K 可交换）。
   `contact_damping` 的非比例情形仍是【推测】（原文即如此标注）。
6. **适用域**：结论是"线性化稳定域"，不是材料标定，也不涉及冰实验。

## 6. 误差判定（对解析基准逐项）

基准 = 步进矩阵 `A` 的稠密谱半径（独立于引擎），以及闭式 `symplectic_euler_growth_factor`（独立第二源）。

| 关键量 | 基准 | 实测误差 | 是否 < 3% |
|---|---| ---:|---|
| 每步增长率 ρ（d = 2.01 / 2.02 / 2.10） | 稠密谱半径 | 5.7e-7 / 2.6e-7 / 2.1e-8（相对） | **是**（<1e-6） |
| 每步增长率 ρ（g=1.5,d=1.5） | 2.0（闭式与稠密一致） | <2e-3（实测 2.000000） | **是** |
| 每步增长率 ρ（g=1.95,d=0.8） | 1.313344 | <1e-3 | **是** |
| 修正边界定位（g=1，d=0.99/1.01×√2） | d²+2g = 4 | 有界↔发散的翻转落在 ±1% 内 | **是** |
| 临界点能量指数（d = 2） | n² | 斜率 1.79–2.01 vs 2.0 → ≤10% | 否（10%，仅"代数增长"定性结论可用） |
| 闭式 ρ vs 稠密 ρ（全网格） | — | ≤1e-9 | **是** |

诚实边界：`FloatingPointError` 未能在 d = g = 1.5 处复现（1500 步后仍有限），因为断裂先发生；
"引擎会崩"这句话本单**不主张**，"引擎静默发散到非物理量级"才是被证实的结论。
