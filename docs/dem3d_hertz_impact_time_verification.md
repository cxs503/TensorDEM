# Hertz 接触时长验证：DEM3D 求解器 vs Johnson 解析解（m4747）

Protocol: `hertz-impact-duration-johnson-v1`
产物：`artifacts/hertz_impact_time_m4747/`（`evidence.json` / `duration_scaling.csv` /
`hertz_impact_duration.png`）；本文件所有数字由 `scripts/verify_hertz_impact_time.py`
程序化注入，零手抄。

## 1. 缺口：静态 Hertz 验证覆盖不到时间轴

`docs/dem3d_hertz_contact_verification.md` 与 `tests/test_dem3d_hertz_contact.py`
把 Hertz 律钉在**静态关系**上：$F=\tfrac43 E^*\sqrt{R^*}\delta^{3/2}$、势能、割线刚度，
求解器路径里只有一次自由落体对**峰值力**的复核（`test_elastic_impact_reproduces_hertz_peak_force`）。
这些锚点都约束不了时间轴：同一套 $k_h$ 若时间积分有问题，峰值力照样能对上，而**接触时长**会错。
m2536 恢复 Hertz 分支后，`t_c` 从未被任何文献基准复核过 —— 这是本单要清的验证欠账。

## 2. 解析基准（Johnson 1985, §4.2；Goldsmith 1960）

弹性 Hertz 撞击，$F=k_h\delta^{3/2}$，有效质量 $m$，入射速度 $v_0$：能量守恒给出
峰值重叠 $\delta_{max}=(5mv_0^2/4k_h)^{2/5}$，接触总时长

$$t_c = 2I\,\frac{\delta_{max}}{v_0} = C\left(\frac{5m}{4k_h}\right)^{2/5}v_0^{-1/5},\quad
I=\int_0^1\frac{du}{\sqrt{1-u^{5/2}}}=\frac25 B\!\left(\frac25,\frac12\right),\ C=2I .$$

本单从 Beta 函数（`lgamma`）独立求 $I$：$I=1.471637592$，$C=2.943275184$，
与教科书 2.94 相差 $+0.1114\%$（2.94 本身是三位有效数字）。
由此得到两条互相独立的判据：**绝对前因子** $C$ 与**指数** $t_c\propto v_0^{-1/5}$。

刚体平板约定（易错点）：颗粒撞刚性平板时只有颗粒变形，$1/E^*=(1-\nu^2)/E$（**不是**双体的
$2(1-\nu^2)/E$），$R^*=R$。用错这个因子会把 $k_h$ 差 2 倍，$t_c$ 差 $2^{-2/5}=0.758$ —— 本单初期
就踩过这个坑（见 §6）。

## 3. 怎么做的

| 项 | 设置 |
|---|---|
| 几何 | 2×2×2 颗粒盒，取最底层最靠内颗粒向下打速度 $-v_0$（`DEM3DConfig(nx=ny=nz=2)`） |
| 材料 | $R$ = 0.025 m，$\rho$ = 917.0 kg/m³，$m$ = 0.060018 kg |
| 接触 | `contact_model="hertz"`，$E$ = 1e+09 Pa，$\nu$ = 0.3，$k_h$ = 2.316687e+08 N·m$^{-3/2}$ |
| 耗散 | `contact_damping=0`、`drag=0`、`platen_damping=0`、$\mu=0$、`gravity=0`（只留 Hertz 弹性） |
| 键 | `bond_stiffness=1e-4` N/m（比接触刚度低 12 个量级 ⇒ 自由体问题） |
| 步长 | $\Delta t = t_c^{ref}/N$，$N$ = 600（远低于求解器稳定性上界 6.83e-07 s 之下） |
| 测量 | 颗粒-平板重叠 $\delta>0$ 的步数 $\times\Delta t$；进出接触面的真实时刻落在两个边界步内，分数部分相消 ⇒ 无偏、$O(\Delta t)$ |
| 负控 | 同一测量装置换成**线性**单边弹簧（`contact_model="linear"`, $k_p$ = 5000 N/m）：必须复现 $t_c=\pi\sqrt{m/k}$ 且**与速度无关** |

工具链：`src/tensordem/hertz_impact_time.py`（解析锚点 + 真实求解器测量，解析式全部自行推导，
不 import `dem3d.hertz_reduced_modulus`）→ `scripts/verify_hertz_impact_time.py`（证据）
→ `tests/test_dem3d_hertz_impact_time.py`（14 个断言）。图见
`artifacts/hertz_impact_time_m4747/hertz_impact_duration.png`（三联：时域重叠曲线 vs 独立 RK4、
对数-对数时长标度、$\Delta t$ 收敛）。

## 5. 误差判定（逐项，vs 解析基准）

| 关键量 | 基准 | 最差相对误差 | 是否 < 3 % |
|---|---|---:|---|
| 前因子 $C=2I$ | 教科书 2.94（三位有效数字） | 0.1114 % | **是** |
| 接触时长 $t_c$（Hertz，4 档速度） | Johnson $C(5m/4k_h)^{2/5}v^{-1/5}$ | 0.1667 % | **是**（远优于 3 %，且为 $-1/N$ 离散偏置） |
| 时长指数 $\mathrm{d}\ln t_c/\mathrm{d}\ln v_0$ | $-0.2$ | 拟合值 -0.200000，偏差 $1.94e-16$ | **是** |
| 峰值重叠 $\delta_{max}$（Hertz） | $(5mv_0^2/4k_h)^{2/5}$ | 0.0001 % | **是** |
| 重叠指数 $\mathrm{d}\ln\delta_{max}/\mathrm{d}\ln v_0$ | $+0.8$ | 拟合值 +0.800000 | **是** |
| 恢复系数 $e$（$\gamma_n=0$） | 1（无耗散弹性） | $<10^{-9}$（实测 1.000000） | **是** |
| 线性负控 $t_c$ | $\pi\sqrt{m/k}$ | 0.1667 % | **是** |
| 线性负控指数 | 0（与速度无关） | 拟合值 +0.000000 | **是** |

结论：m2536 恢复的 Hertz 分支在**时间轴**上与 Johnson 解析解一致，最差误差
0.167 %，全部判据 < 3 %。此前该能力的时间域证据等级只能算
`WITHHELD`（只有静态/峰值锚点），现升级为 **REAL**。

## 6. 注意点与局限

1. **$E^*$ 的刚体平板因子（本单实际踩到的坑）**：首版探针用双体 $E^*=E/(2(1-\nu^2))$，测得
   $t_c$ 偏长 **+39.7 %**、峰值重叠偏小 24 %，看起来像求解器 bug；修正为单体
   $E^*=E/(1-\nu^2)$ 后重叠与峰值力对到 $10^{-6}$。教训：拿到 >15 % 的偏差先怀疑基准的**约定**，
   再怀疑代码。`rigid_plane_hertz_stiffness` 因此把推导写进了 docstring，并有
   `test_rigid_plane_stiffness_uses_single_body_modulus` 钉住这个 2 倍。
2. **`last_bottom_platen_reaction_z` 的读数时序**：分离后该读数会留下微小残值（$O(10^{-21})$–$O(10^{-8})$ N，
   随速度增大），若用它判定"接触结束"会多算若干步（本单首版因此把 $t_c$ 高估近 1 倍）。
   本模块一律用**几何重叠 $\delta>0$** 作为接触判据 —— 这是无歧义的物理量。
3. **适用范围**：$\delta_{max}/R\le$ 1.2 %（本扫描 $v_0\in[0.25,2]$ m/s），即小变形 Hertz 域；
   大变形、塑性、$\nu\to0.5$、含阻尼（$\gamma_n>0$）的情形不在本基准内 —— 有阻尼时 $t_c$ 不再是
   Johnson 式，见 `docs/dem3d_hertz_restitution_closure.md` 与 `tensordem.contact_restitution`。
4. **一步量化偏置**：$N=600$ 时读数系统性偏小 0.167 %（恰为 $-1/N$），不是模型误差；
   要做亚 % 断言必须增大 $N$ 或做 Richardson 外推。
5. **单接触、无重力**：本验证隔离了接触律本身；网格/多体/重力耦合下的 $t_c$ 未在此覆盖。
