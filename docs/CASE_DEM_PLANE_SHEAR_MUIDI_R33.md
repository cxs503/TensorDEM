锚点：`CASE-DEM-PLANE-SHEAR-MUIDI`（算例池·平面剪切 mu(I) 流变律标定，`open`，容差 10 %，$I=10^{-3}\ldots0.3$）

## 1. 为什么做这件事（缺口在哪）

R31 用分层剖面仪量出：本算例达成的剪切率只有名义值的 **0.07–0.13**，滑移长度 $2.8h$，
于是判定「横坐标 $I$ 轴需重标」。R32 只把 $\phi$ 参考律的薄/厚层歧义量化，$\mu$ 的 FAIL
仍归因于「率敏感度 $b$ 只有论文的 1/3」。

本单先做一件 R24–R32 都没做的事：**审计装置本身的壁面运动学**。
`plane_shear_2d.RoughWallShearCell` 把粗糙壁建成两排「胶结颗粒」（grain-glued），
并把壁速 $\pm V$ 赋给这些颗粒。但 `_set_wall_kinematics` 只重设**y**坐标与**速度**，
`advance()` 的自由度积分也只推进自由盘：

```python
sysm.pos[free] += self.dt * sysm.vel[free]     # 只有 free
self._set_wall_kinematics(servo_vy)            # 只写壁粒 y 与 vel
```

⇒ 壁粒的 **x 坐标从不推进**。实测（`/tmp` 探针，200 步，$v_{wall}=0.6$ m/s）：

| 量 | 位移 |
|---|---|
| 底排壁粒 x 位移（应为 $Vt=8.41\times10^{-4}$ m） | **0.0** |
| 顶排壁粒 x 位移（应为 $-Vt$） | **0.0** |

于是所谓「移动粗糙壁」在几何上是一堵**冻结的波纹墙**：它只是携带了一个速度，
与物料的耦合仅剩切向摩擦律（饱和于 $\mu_p N$）。让粗糙壁成为率控制边界的机制——
**凸起扫过、把近壁盘「推」走**的几何互锁——完全不存在。本仓 3-D 路径没有这个缺陷
（`rough_wall_sweep` 的 graft 层是 "moving rigidly with the wall"），2-D 装置与之**自相矛盾**。
这也直接解释了 R31 的塞流/大滑移签名：不是体相局域化，而是装置没有施加剪切率。

## 2. 怎么做的

最小改动（`benchmarks/plane_shear_mu_i/plane_shear_2d.py`）：

* 新增算例字段 `wall_translate: bool = True`；`advance()` 在重设壁面运动学后把两排壁粒
  按 $\pm V\,dt$ **平动**（x 取模 $W$）。`False` 逐位复现归档轮次，作消融对照。
* 平动不改变壁排的**循环间隙序列**（整体平移 = 循环移位），故任何时刻壁粒最小间隙仍是
  原间距（$1.001d$），不会自重叠；最大间隙 $1.978d<2d$，自由盘仍无法从缝隙挤出
  （见 `test_advection_never_creates_wall_wall_contacts`）。
* 新增 `wall_translation_ablation.py`（单点驱动）、`run_wall_translation_campaign.py`
  （8 分片战役）、`analyse_wall_translation.py`（表格+图，程序化零手抄）、
  `test_wall_translation_r33.py`（5 条测试）。
* 接触物理、协议、判据尺子（`reference_2d`）、种子**全部不动**：同一算例、同一协议，
  只翻一个布尔量。

**读法（诚实）**：修复把 $\mu$ 的偏差方向从 **−42 %（偏低）翻到 +19…27 %（偏高）**。
即「$\mu$ 偏低」至少有相当一部分是**装置缺陷**（漏围压+滑移），而非纯物理；
但修复**没有**让锚点通过 10 %，残余 +20 % 与 R30 报的 $b=0.279$ 同量级，需单独归因。

## 4. 注意点 / 局限

1. **本轮所有点都不是锚点证据**：本机算力门限 118 s/命令，只能跑 $n\le762$、短 settle 的
   诊断探针；稳态未达（settle 45 的闭合率 0.193 < settle 20 的 0.631，非单调 ⇒ 未收敛，
   或高 $\phi$(0.830) 下剪切局域化，两者本轮**无法分辨**）。
2. **R31 的横坐标结论被本轮部分削弱**：R31 的 smoke 胞（200–240 盘在 $W{=}0.24\times0.14$
   里）$\phi\approx0.63$、$p/P=0.004\text{–}0.059$，是**欠填未加压**的胞，其塞流读数不能
   单独支撑「$I$ 轴需重标」。正式重标必须用填满且加好压的胞（见第 5 节战役）。
3. 壁排平动的最大间隙 $1.978d$ 距可挤出的 $2d$ 只有 1.1 % 余量；更宽的胞需检查此余量。
4. 本轮没有改动任何接触/流变物理，也不触碰归档 JSON；`wall_translate=False` 逐位复现
   （`config_digest` 相等，已入测试）。
