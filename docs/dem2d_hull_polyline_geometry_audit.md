# 二维船体 polyline 接触几何审计：割线矢高偏差与精确圆弧内核

**结论一句话**：`tensordem.hull_contact.polyline_contact_forces` 用弦线近似船首圆弧时，
弦到粒心的距离**必然大于**弧到粒心的距离，罚函数接触因此系统性低估压入深度与冰载荷：
中弦处弦压入深度精确等于 `delta_chord = delta_arc - s`（`s` 为矢高），相对力误差
`-s/delta`，且当 `delta <= s` 时**完全丢失接触**。以 `R/r_p = 10`、180° 船首为例，
`delta/r_p = 0.05` 时 `N = 32` 段的误差为 -24.09%，要压到 3% 需要 `N = 128`（-1.51%），
而工程常见的小压入量 `delta/r_p = 0.002` 即使 `N = 512` 仍有 -2.35% 的偏差；
`N = 32` 时该压入区间内有 3 个采样点**完全没有接触力**。
新增的精确圆弧内核 `tensordem.hull_geometry.arc_hull_contact_forces` 与闭式圆弧参考的
最大相对力误差为 2.33e-12，方向误差
1.21e-06°，作用-反作用残差
0.00e+00 N，几何离散误差为零。

## 1. 案例介绍

**物理背景**：破冰船船首与冰排的接触是船-冰相互作用 DEM 的载荷入口。二维破冰原型
`IceDEM` 原本使用竖直下压的刚性圆盘压头；合并后的 `hull_contact` 内核把它替换为
"沿给定折线轮廓平移的船体"，用粒子到折线的最近距离作为罚函数压入量。折线是对船首
曲线（本审计取圆弧，凸形）的**割线**离散，任何折线离散都会引入几何偏差，而该内核
此前只有 4 个接口级单元测试（力符号、作用-反作用、端点接触、输入校验），从未对
解析圆弧基准做过误差定量。本审计结清这笔验证欠账，并给出可直接替换的精确圆弧内核。

**几何与参数**（全部 SI，`stiffness = 1 N/m` 使力与压入量数值等价）：

| 符号 | 含义 | 取值 |
|---|---|---|
| `R` | 船首圆弧半径 | `r_p x {2, 5, 10, 20}` |
| `r_p` | 冰颗粒（圆盘）半径 | 1 m |
| `Theta` | 离散化的船首张角 | 180° |
| `N` | 弦段数 | {4, 8, 16, 32, 64, 128, 256, 512} |
| `dtheta` | 单段张角 = `Theta/N` | 随 `N` |
| `delta` | 解析弧压入深度 | `r_p x {0.002 ... 0.2}` |
| 罚函数 | `F = max(0, k*overlap - c*v_n) * n` | 与折线内核同律，`c = 0` |

## 2. 方法与关键关系

三种接触描述对同一粒子位置各求一次力（不积分、无冰排、无断裂，纯几何 + 接触律）：

1. **shipped polyline**：`hull_contact.polyline_contact_forces`（已合并内核，不改动）。
2. **sagitta-corrected polyline**：把顶点沿径向外移到 `R' = (R cos(dtheta/2) + s)/cos(dtheta/2)`，
   使中弦恰好落在"弧顶点 + 矢高"处，检验最廉价的修正是否够用。
3. **exact circular arc**：`hull_geometry.arc_hull_contact_forces`，距离对圆弧解析
   （角度落在弧内取 `|r - R|`，否则取到最近端点距离），同一罚函数律。

**独立解析参考**：脚本内用纯标量闭式 `delta = r_p + R - r` 与径向法向 `e_r(theta)`，
不调用任何内核，因此参考值与被测实现独立。

**核心恒等式（可精确验证，非渐近）**：设粒子中心位于某弦的法线上，半径 `r`，则
弦压入 `delta_chord = r_p + R cos(dtheta/2) - r`，而 `delta_arc = r_p + R - r`，两式相减得

    delta_chord = delta_arc - s ,  s = R (1 - cos(dtheta/2)) = 2 R sin^2(dtheta/4)

与 `r_p`、`delta` 无关。由此：相对力误差 `= -s/delta`；丢失去接触条件 `delta <= s`；
`N` 加倍误差除 4（二阶）。方向偏差上界 `dtheta/2`，在中弦与顶点处为零，中间呈锯齿
（"搓衣板"调制）。反解容差给出所需段数：

    N >= Theta / (2 * arccos(1 - delta*target_tolerance / R))

脚本 `scripts/audit_hull_polyline_geometry.py` 复现全部数据：
`python scripts/audit_hull_polyline_geometry.py --output outputs/dem2d_hull_geometry`。

## 4. 注意点与局限

- **只测几何与接触律**：单粒子单步、无冰排、无断裂、无浮力、无摩擦/切向、无时间积分；
  本审计不涉及载荷幅值的物理正确性，只回答"折线离散把接触几何带偏多少"。
- **罚函数刚性无关**：线性罚函数下力误差等于压入量误差，结论与 `k` 无关；若改用
  Hertz 型非线性律，误差按 `(delta_chord/delta_arc)^(3/2)` 放大，结论只会更差。
- **sagitta 修正不是解**：它把中弦过载替换为顶点过载（图 2 右侧），
  `N = 32` 时中弦误差 6.1e-13 但顶点过载可达 `s/delta` 量级；且顶点外凸会产生
  对真实弧不存在的"虚假接触"（浅压入时尤其明显）。正确做法是精确弧内核。
- **方向偏差是振幅调制的**：`N = 16` 时峰值 5.1°，随 `N` 线性下降；
  在冰排沿船首滑移的过程中，这会把真实的光滑法向力变成周期性的搓衣板力，可能伪造高频
  载荷成分——这一点对后续载荷谱分析有直接影响，本次只给上界，未做谱分析。
- **不适用于凹多边形轮廓**：最近点法在凹角处法向不唯一，本审计与内核均假设凸形船首。
- **未做**：把精确弧内核接进 `IceDEM`（`hull_profile` 目前只接受折线）；三维（`dem3d`）
  船首棱柱/回转体的同类偏差；弧-弧接触（多弧拼接处的端点衔接）。

## 5. 误差判定（关键量 vs 基准，逐项）

| 关键量 | 基准 | 误差 | 是否 < 3% |
|---|---|---|---|
| 精确弧内核接触力（全扫描，含浅压入 1e-4 m） | 闭式圆弧 `k(r_p+R-r)e_r` | 2.33e-12 | 是 |
| 精确弧内核法向方向 | 径向 `e_r` | 1.21e-06° | 是 |
| 精确弧内核作用-反作用 | 动量守恒 | 0.00e+00 N | 是 |
| shipped polyline 误差 vs 闭式 `-s/delta` | 推导恒等式 | 1.00e-12 | 是（模型自洽） |
| shipped polyline 丢接触阈值 vs 矢高 `s` | 闭式 `s` | 1.06e-07 | 是（模型自洽） |
| **shipped polyline 接触力（`R/r_p=10`, `N=32`, `delta/r_p=0.05`）** | 闭式圆弧 | -24.09% | **否** |
| **shipped polyline 接触力（`R/r_p=10`, `N=128`, `delta/r_p=0.05`）** | 闭式圆弧 | -1.51% | 是 |
| **shipped polyline 接触力（`R/r_p=10`, `N=512`, `delta/r_p=0.002`）** | 闭式圆弧 | -2.35% | 是 |
| sagitta 修正中弦（`N=32`） | 闭式圆弧 | 6.11e-13 | 是 |
| sagitta 修正顶点（`N=16`, `delta/r_p=0.05`） | 闭式圆弧 | +96.77% | **否** |

**判定**：已合并的折线船体内核在工程分辨率的段数下**不满足 3% 精度标准**（`N=32` 时
-24.1%，且浅压入下直接丢接触）；新增的精确圆弧内核把几何误差压到
机器精度，满足 <3% 且实际 <1e-10。因此对需要量化冰载荷的算例，应使用
`arc_hull_contact_forces`（分量弧船首）或把折线段数按
`N >= Theta / (2 arccos(1 - delta*tol/R))` 加密（见 Table 3：`delta/r_p = 0.01`、
`R/r_p = 10` 需 203 段，`R/r_p = 20` 需 287 段）。
