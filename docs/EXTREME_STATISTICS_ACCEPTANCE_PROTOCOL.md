# 极值统计量验收协议 (Extreme-Statistic Acceptance Protocol)

适用范围：TensorDEM 中一切以**场量极值统计量**作为设计判据的报告 —— 冰磨损/磨蚀
深度场的 P95、P99、最大值、测量斑 (survey patch) 分位数、冲刷与冲蚀深度分位数，
以及由这些量派生的寿命/涂层消耗结论。

本协议的存在理由：极值统计量的数值不是"网格收敛了就对了"的量。同一个物理过程，
**抽样误差**（有限接触事件、有限斑块落点）、**测度依赖**（单元平均分位数随单元面积
变化）、**数值误差**（投影/积分）三者会叠加成一个数，而 Roache GCI 只能回答第三种，
且它预设了连续极限存在。W10-N06 的 "P95 GCI = 19.8 %，未收敛" 正是这种混淆的产物：
本协议把三者拆开，逐项可机器裁决。

---

## 1. 定义义务（每个极值统计量必须声明）

| 编号 | 必须声明的项 | 说明 |
|---|---|---|
| S1 | 估计量与样本定义 | 分位概率 p、场的定义（单元平均/滑动窗/点值）、**记录网格尺度**（dx, dz）、截断与零单元处理 |
| S2 | 抽样不确定度 | 95 % 置信区间；来源必须写清（独立重复实现 / 块 bootstrap / 参数模型 profile） |
| S3 | 分辨率状态 | 要么"已收敛"（最细两级差异 ≤ 3 %），要么给出**外推连续值**与外推模型指数 β 及区间 |
| S4 | 空间聚簇 | 若区间来自空间样本，须给出极值指数 θ 或等效独立单元数，并说明所用 bootstrap 是否保留相关性 |
| S5 | 参数/场地 | 材料硬度、比磨损率、摩擦系数、冰况、单元面积、事件权重约定 |

未声明 S1–S5 的极值量，不得用于标定自由参数或对外发布。

## 2. 机器可裁决的 5 项判据

`tensordem.extreme_statistics.acceptance_protocol_evaluate()` 实现以下检查，
默认阈值见括号；判据数字必须与产物路径一同落报告 JSON。

| 判据 | 内容 | 默认阈值 | 失败含义 |
|---|---|---|---|
| **P1** | 三路中心一致：独立重复、块 bootstrap、Gumbel profile 三者的 P95 中心值相对偏差 | ≤ 3 % | 估计量实现或样本定义不一致 |
| **P2** | profile-likelihood 区间在蒙特卡洛下的覆盖率（名义 95 %） | ≥ 0.90 | 区间被低估（过窄），不得作为验收带 |
| **P3** | 每个分辨率上的 P95 都带区间 | 必须 | 存在无区间的裸数字 |
| **P4** | 分辨率状态已声明：最细两级差异 ≤ 3 %，或给出连续值 + β + 区间 | 必须 | 把测度依赖当成已收敛 |
| **P5** | 极值指数 θ 的块长（run length）稳定性平台长度 | ≥ 3 | θ 随去簇参数漂移，聚簇结论不可信 |

## 3. 规定算法（与实现一一对应）

1. **分布拟合**：GEV 三参数 MLE（解析梯度 + 多起点 L-BFGS-B），Gumbel 作为 ξ=0 的
   两参数特例（位置可解析消去）。区间一律用 **profile likelihood**
   （似然比 χ²(1) 截断）；delta 法只作为对照，不单独用于验收。
2. **覆盖率对拍**：以已知母体抽样本，统计区间覆盖真值频率；名义 95 % 时要求 ≥ 0.90。
3. **极值指数 ξ**：Hill（Fréchet 尾）+ 分块极大值随块长收敛；ξ 必须带区间。
4. **极值指数 θ（聚簇）**：runs 估计量 + 块估计量，run length 1…20 扫描，取漂移带内
   平台中位数；r=1 的 runs 估计量系统性偏低（本模块实测 3–9 %），报告中须注明。
5. **场分位数区间**：
   - *独立重复*（改种子重算整个场）→ 抽样误差的**地面真值**，验收以此为准；
   - *块 bootstrap*（二维循环块，块形 (bz,bx)）→ 仅在「场统计量由落点噪声主导」时可用；
   - *iid 单元 bootstrap* → 仅作反例，禁止用于验收。

   **IN37-N02 的实测反例（必读）**：冰磨损场的 P95 方差由*确定性活动度剖面*主导
   （水线下高斯峰 × 首部权重），不是落点噪声，故 iid 与块 bootstrap 都错：
   前者给 3.1–4.5 %（偏窄仍错）、后者给 23–37 %（重排单元破坏剖面行结构，严重偏宽），
   而独立重复给 0.42–0.75 %（真值）。因此**先做探针检验**：比较三类区间量级，
   若 bootstrap 与独立重复不一致即弃用 bootstrap；不允许只报一个 bootstrap 区间。
6. **分辨率律**：`q(h) = q_inf - B h^β` 最小二乘拟合（对重复起伏加权），β 带 bootstrap
   区间；**注意指数符号**——单元平均分位数随单元变小而**升高**并趋于有限点值，
   因此模型必须饱和而非发散。相邻两级的局部指数 β_local = −dln q/dln h 若单调衰减到 0，
   说明正在趋近连续极限；若 β_local 近似常数，则该区间内无连续极限（纯测度依赖）。
7. **双机制分辨率模型**：单元平均分位数 = 活动度剖面的确定性平滑 × 坑点散粒噪声。
   剖面由 `ActivityDistribution` 的可分离形式给出（零自由参数），散粒噪声的平均命中数
   由**空单元比例**反解（唯一拟合参数）：`mean(exp(-c a)) = 零单元比例`。
   模型须同时复现 (i) 各分辨率 P95 与 (ii) 重复实现的变异系数，否则视为未解释。

## 4. 报告模板（必须逐项给出数字）

```
统计量: <p, 场定义, 记录网格 dx×dz, 单元数>
S2 抽样区间: [lo, hi] (±x.x %), 来源 = <replicates(n=..)/block bootstrap/iid(仅对照)>
S3 分辨率状态: 最细两级差异 y.y %  vs 抽样半宽 x.x %  → <已收敛 | 外推连续值 q_inf ± ci, β=..>
S4 聚簇: θ = .. (平台 .. 点), 等效独立单元 ≈ 单元数 × θ
P1..P5: <通过/不通过 + 数字>
判定: <sampling-noise | measure-dependence | unresolved discretisation error>
```

## 5. 判定规则（`adjudicate_gci_vs_ci`）

- 配对分辨率差异的置信区间含 0 → `sampling-noise`：差异是噪声，不可作为收敛性证据。
- 显著且被分辨率模型复现（残差 ≤ 15 %）→ `measure-dependence`：差异是统计量的定义
  属性，必须连同**记录网格尺度**一起报告，必要时外推连续值；不得写成"数值误差"。
- 显著且模型不能复现 → `unresolved`：按离散误差处理，加密网格或改进投影。

## 6. 已知陷阱（随证据增长，只增不改）

1. **不要把 GCI 用在分位数上而不先声明连续极限存在性**：W10-N06 的 19.8 % 在 4 级加密
   序列上并不收敛，GCI 的观测阶回退到理论阶只是巧合。
2. **iid 单元 bootstrap 会把区间压窄**：磨损场的空间相关使相邻单元不独立，必须块 bootstrap。
3. **runs 估计量 r=1 有负偏**：报告的 θ 若不说明去簇参数，可被误读。
4. **profile 区间在小样本下不对称**：用 delta 法做对称近似会低估上侧尾部。
5. **分位数随单元面积变化是物理的**：稀释坑点在 σ→0 时无连续极限，报告必须带记录尺度。
6. **空单元反解命中数**依赖活动度剖面非均匀；用 exp(-c) 直接当零比例会高估命中数。
7. **单元重抽样 bootstrap 在剖面主导的场上是错的**：块 bootstrap 若不跨越剖面梯度，会把确定性结构当噪声，区间严重偏宽；必须与独立重复对拍后才可使用。
8. **θ 的块估计量要除以块长取整误差**：块数过少（<50）时 θ 偏大，扫描平台须 ≥3 点。
