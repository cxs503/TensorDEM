## 1. 这一轮问什么（R3 留下的欠账）

R3 把 `tau*(kappa)`（`kappa = k_n/(rho d^3 gdot^2)`）测到 `kappa = 361.7 … 5.79e5`（3.2 个数量级），
发现曲线是**弯的**：局部指数 `beta` 从 0.89 爬到 0.98（`n = 2(1-beta)` 从 0.21 降到 0.04）。
R2 与 R3 的"下一轮线索"都指向同一条：**弹性→惯性转变从未从下方被触碰过**。因此账本里描述另一支的两行
至今无法检验：

| 账行 | 量 | 参考 | 状态 |
|---|---|---|---|
| R1 | 惯性支 Bagnold 指数 `tau ~ gdot^n` | `n = 2` | 从未在自家数据上测到 |
| R2 | 弹性→惯性边界 `kappa_c` | `~1e4`（仅数量级，因子 3 带） | 从未在自家数据上测到 |

R4 用**最省的实验**补这一刀：`kappa` 反比于 `gdot^2`，所以"低 kappa"点反而**更便宜**（同应变下步数更少）。
真正的限制不是算力而是物理——软接触在高剪切率下重合度变大，小重合度有效性门先顶不住。这堵墙被**测量**出来，而不是被假设。

四条预注册问题（外加一条诊断）：

* **P1 可达性**：能往下走多远，被哪个门挡住（记为墙，不记为失败）；
* **P2 惯性支**：`kappa` 下降时 `n` 是否单调升向 Bagnold 的 2，且在最深有效点是否 `>= 0.5`；
* **P3 分解**：双项律 `tau* = A kappa + B`（弹性 + 惯性）是否在**同参数个数**下胜过单幂律（AIC），
  并复现 R3 从最硬单点读出的弹性系数 `A`；
* **P4 边界**：拟合交叉点 `kappa_x = B/A` 与 Campbell 图的 `kappa_c ~ 1e4`（R2 账行）是否相容；
* **P5 交叉校验**（诊断）：模型"惯性份额" `c/(kappa+c)` 与实测动能应力占比是否相差不超过一个量级
  ——若超出，`B` 就不是碰撞项而是"率相关接触项"，这是单幂律看不见的区别。

## 2. 怎么做的

**装置**：与 R3 完全同参的 2-D 双分散盘 Lees–Edwards SLLOD 盒（`phi=0.80`、`N=400`、`d_big/d_small=1.4`、
`e=0.7`、`mu=0.5`、`dt=0.004 t_c`、应变 `1.4`，平均窗 `0.7 → 1.4`），无壁面。
动力学内核一行未改——R4 只改**取点位置**与**分析**。

`kn1e4_g16.0` 与 `kn2.5e3_g8.0` 的 `tau*` 逐位相同（0.7335）：R3 已证明 `(k_n, gdot) -> (λ²k_n, λgdot)`
是该离散系统的**精确恒等**（时间步是接触时间的固定比例），这里再次复现——它是实现不变量，**不是**物理证据。

**拟合**（`two_term_stress_fit`，对数空间最小二乘，因测量误差是乘性的）：

* 双项律 `tau* = A(kappa + c)`，`c = B/A`；固定 `c` 时 `A` 有闭式解，故只剩 1 维搜索（对数网格 + 黄金分割细化），无需 scipy；
* 与单幂律**参数个数相同**（均 2 个），因此 AIC 对比是公平的；
* 交叉点置信区间用**参数化 bootstrap**：以本轮的实测种子散度扰动每个 `tau*`，重拟合 400 次取 16/84 分位；
* 拟合输入 = R4 的 8 个通过点 + R3 的 11 个通过点（只读复用，不重解释），合计 19 个 kappa，跨 4.81 个数量级。

**噪音底**：`kappa=90.42` 处 3 个种子 → `tau* = 2.364 / 2.192 / 2.036`，相对标准差 **7.47 %**（R3 在最硬端测到 6.25 %）。
本轮所有点、所有局部斜率的不确定度都由此传播，不另设"好看的"误差。

## 3. 结果

### 3.1 向下走 1.6 个数量级是可能的，然后撞墙

8 个点在 R3 地板以下通过全部物理门（`kappa` 从 361.7 降到 **9.04**，1.60 个数量级）。
第 9 个点 `kappa = 5.65` 撞的是**小重合度门**（平均重合 0.1330 > 门限 0.12；最大重合 0.451 仍在 0.5 内，
能量缺陷 0.126 也合格）。这堵墙是**物理的**，不是算力或收敛的：

* 重合度**不是** `kappa` 的干净幂函数（`d ln ovl/d ln kappa = -0.147`，残差 13.8 %）：硬端饱和在 0.028–0.03，
  因为 `phi=0.80` 的床本来就在 jamming 附近，重合度有一个**堆积几何地板**，不由刚度定；
* 因此"更硬就能达到更小重合度"这条外推在本盒里无效——门禁穿越点按实测窗口记为 `kappa ~ 2.5`（线性外推），
  实测已在 5.65 处失效；
* 结论：`phi=0.80` 的定容 2-D 线性弹簧盒，**可及窗口下界就是 `kappa ≈ 9`**（本轮实测），再往下必须换装置（降低 `phi` / 定压伺服）。

### 3.2 指数在整整一个数量级里**不动**

R4 内部相邻对的局部指数：

| pair | `sqrt(k_lo k_hi)` | `beta_local` | `n_local` | `sigma_n`（由 7.47 % 噪声传播） |
|---|---|---|---|---|
| kn1e3_g8.0 → kn1e4_g24.0 | 9.53 | 0.892 | 0.217 | 2.01 |
| kn1e4_g24.0 → kn1e3_g6.0 | 12.7 | 0.887 | 0.227 | 0.45 |
| kn1e3_g6.0 → kn1e4_g16.0 | 19.1 | 0.841 | 0.318 | 0.62 |
| kn2.5e3_g8.0 → kn1e4_g12.0 | 30.1 | 0.823 | 0.354 | 0.37 |
| kn1e4_g12.0 → kn1e4_g8.0 | 60.3 | 0.859 | 0.282 | 0.26 |
| kn1e4_g8.0 → kn1e4_g6.0 | 120.6 | 0.847 | 0.307 | 0.37 |

点估计在 `n = 0.22 … 0.35` 之间**无方向性地抖动**；每个两点斜率的 1σ 是 0.26–2.0（两点斜率是最不可靠的估计量，
R3 也记录过这一点）。所以本轮**不能**说"`n` 上升到 0.35 了"，只能说"`n` 在这一整个数量级里没有可分辨的变化"。

把 R3 的 11 点接上（19 点、4.81 个数量级）得到的全局单幂律：

```
tau* = 0.04302 * kappa^0.8935        (beta = 0.8935, n = 0.213)
RMS(ln 残差) = 10.3 %   vs  种子噪声底 7.47 %（比值 1.4）
```

即：**在 9 ≤ kappa ≤ 5.8e5 的整个可及窗口里，剪应力就是一个幂律，`n = 0.213`**（由种子噪声给 1σ ≈ 0.005 的统计误差；
点间散度 10.3 % 与 7.5 % 的噪声底相当，说明没有留下需要第二个机制解释的形状）。这既不是弹性极限（`n = 0`），
也不是 Bagnold（`n = 2`）。

### 3.3 弹性 + 惯性双项分解：被数据否定

| 量 | 双项律 `A kappa + B` | 单幂律 `C kappa^beta` |
|---|---|---|
| 参数个数 | 2 | 2 |
| `RMS(ln 残差)` | **19.8 %** | **10.3 %** |
| AIC（越小越好） | −38.06 | **−55.03** |
| ΔAIC（双项 − 单幂律） | **+16.98** | — |

* `A = 0.01689`（bootstrap 68 % CI [0.01645, 0.01737]）、`B = 0.2520`、`kappa_x = B/A = 14.93`（CI [13.52, 16.26]）；
* 双项律在最硬点（`kappa = 5.79e5`）过预测 `tau*` 24 %，这是它输掉 17 个 AIC 点的主要来源；
* `A` 与 R3 从最硬单点读出的 `tau*/kappa = 0.01357` 差 **24.4 %**：因为 `beta = 0.894 < 1`，
  单点的 `tau*/kappa` **不是**常数弹性系数，它随 `kappa` 漂移。R3 那条"系数"只能作为该点的局部比值，不能当 `A` 用。

因此 P3 的机制假设（"曲线弯 = 弹性支与惯性支相加"）在自家数据上不成立；**P4 的 `kappa_x` 随之失去物理意义**
（一个被排除模型的参数不能用来定位物理边界）。

### 3.4 惯性支是碰撞性的吗？（P5 诊断）

模型会给一个"惯性份额" `c/(kappa+c)`，最深点竟达 62 %；而**实测**动能应力占比只从 5.4e-2 升到 7.4e-2
（最硬端 2.3e-4）。逐点比值（实测/模型）：8.85 → 5.04 → 4.03 → 2.18 → 1.41 → 0.91 → 0.64 → 0.47 → 0.28 → 0.20 → 0.16 → 0.12 → 0.118。

预注册规则（"每个比值 ≥ 0.1 即 kinetic_consistent"）按字面判为 **kinetic_consistent**（最小 0.118），
但这是**边缘**判读，必须把话说明白：模型在 `kappa < 40` 要求 >27 % 的应力来自惯性支，而实测动能占比一直只有 7–8 %，
比值单调退化到 0.118（模型过述约 8.5 倍）。所以正确读法是：**若双项律成立，其 `B` 项必须是"率相关接触"而不是"动能"**；
而由于 3.3 已把双项律整体排除，这一条的主要价值是记录：本盒在 `I` 高达 1.2 时应力仍由接触承担（动能占比 7.4 %）。

注意 `mu_eff` 在整段几乎**不动**：0.512（`kappa=161`）→ 0.475（`kappa=9.04`），而惯性数 `I` 从 0.365 升到 1.199。
"`I>1` 就是惯性支"这个常识在这里**不成立**——这是下一轮可以直接攻击的问题（见 §8）。

## 4. 注意点（坑与适用范围）

1. **几何**：全程 2-D 圆盘，Campbell 是 3-D。指数的绝对值依赖维度（R1 的 `n=2` 结论维度无关，但系数依赖），
   所以本轮所有系数（`C=0.04302`、`A`、`B`）都只是 2-D 量，**不与文献系数比较**。
2. **`kappa` 定义**：`d` 取数均直径 1.2、`rho=1`。换 Sauter 直径或配位数加权尺度会让 `kappa` 整体乘一个常数，
   从而搬动 `kappa_x`——这条写在预注册的 `non_predictions` 里，不参与判定。
3. **两点斜率不可靠**：`sigma_n` 在相邻窄间距对上可达 2.0（间距只有 10 %）。"单调性"检验在预注册里是一次正检验，
   它没过；但这**不等于**证明了"`n` 不升"，只等于"在现有种子数分辨率下看不见升"。要把它变成"证明不升"，
   每个 `kappa` 至少需要 8–10 个种子（R2 已算过同一笔账）。
4. **门禁是诊断带，不是数值误差**：能量缺陷在 0.126–0.276（门限 0.30），R3 已证明它对 `dt` 减半不敏感
   （0.237→0.248），它是无张力钳位接触与带历史切向弹簧的模型级能耗；真正被判据保护的是 `dt` 收敛对与
   应力对称性缺陷。
5. **复用了 R3 的点**：拟合输入含 R3 的 11 点（只读，结论未改）。若有人改动 R3 的网格，本轮的 AIC 对比会随之改变——
   `analysis.json` 的 `prereg_sha256` 绑的是 R4 的预注册，`fit_input.n_r3` 显式记录复用数量。
6. **被测物理变了没有**：`kappa` 降到 9 时平均重合 11.8 %，线性弹簧仍在其有效域内（门限 12 %），
   但已接近"刚性盘"假设的边界；这也正是我们把 5.65 判为不合格而不是"更软的另一个数据点"的理由。

## 5. 误差判定（关键量 vs 基准，逐项，含"是否 <3%"）

| 关键量 | 基准 | 本轮结果 | 相对偏差 | <3 %？ |
|---|---|---|---|---|
| 全局剪切率指数 `n`（19 点，4.81 数量级） | 弹性极限 `n=0` | 0.213 ± 0.005（统计，种子噪声传播） | 绝对 0.213，约 40σ 偏离 0 | **否** |
| 同上 vs Bagnold | `n=2` | 0.213 | 绝对差 1.79 | **否** |

| 交叉点 `kappa_x` vs Campbell `kappa_c ~ 1e4` | 1e4（因子 3 带） | 14.93（CI [13.52, 16.26]） | 比值 1.49e-3 | **否**，且模型已被排除，此值不作边界 |
| 单幂律拟合优度 | 种子噪声底 7.47 % | RMS 10.3 % | 比值 1.38 | 否（但同量级，单幂律**充分**） |
| iso-kappa 恒等（`k_n·gdot` 标度） | 精确 0 | 0.00e+00 | 0 | 是——但这是恒等式，不是测量 |

**显式回答：本轮没有任何一项关键量以 3 % 精度被"证明"到其基准上。**
能说的是三件事：(i) 可及窗口被实测拓宽到 `kappa=9.04`（R3 地板以下 1.6 个数量级），
(ii) 在这个窗口里单幂律 **`n = 0.213`** 拟合到噪声底 1.4 倍以内，(iii) 弹性+惯性双项分解**被 AIC 排除**
（ΔAIC = +16.98），因此"曲线弯=两支相加"这一来自 R3 的机制假设在本装置上**不成立**。

## 8. 下一轮线索

1. **`I > 1` 却不是惯性支**：本轮最深点 `I = 1.20`、`mu_eff` 仅 0.475（`kappa=161` 处 0.512）。
   `mu(I)` 框架预测 `mu` 随 `I` 升，这里几乎不动甚至微降。要么 `I` 在这里不是控制量（软粒子 + 定容 + 大重合），
   要么 `mu(I)` 的 `I` 需要含刚度的形式。这是可直接做的对照：在 `kn` 固定 / 不同 `gdot` 与 `kn` 变化 / 同 `I`
   两组实验里比较 `mu`，能判定"`mu` 由 `I` 决定"是否成立。
2. **定压伺服是唯一能真正到达惯性支的路**（R2/R3 的第一条线索，本轮把它量化了）：
   定容 `phi=0.80` 的可及下界 `kappa≈9`（重合度墙），要再往下必须让床膨胀。建议在
   `tensordem.mu_i_rheology.simulate_servo_shear` 的**定压**装置上重做 `kappa` 扫描，观测量改为
   稳态 `phi(kappa)`（而不是 `tau*(kappa)`）——Campbell 图的突变性本来就发生在定压下。
3. **种子数换分辨率**：要把"`n` 不升"变成"`n` 在 ±0.05 内不变"，每个 `kappa` 需 ≥8 个种子；
   在最软端（3–5 s/点）这是目前最便宜的精度来源。
4. **3-D 复核**：本轮的 `n = 0.213` 与系数 `C = 0.04302` 都是 2-D 量。3-D 只需把内核换成球 + 体积分数，
   指数可作维度无关性检验（这也是 R3 留下的第 3 条线索）。
