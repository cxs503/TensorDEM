# TensorDEM 3-D 接触恢复系数映射欠账清偿：从「公式自洽」到「求解器实测」

## ① 案例介绍（物理背景 / 几何 / 参数）

`DEM3DConfig.restitution_coefficient` 是面向用户的**目标**恢复系数，但 3-D 求解器的法向接触律是
**压缩限幅**线性弹簧-阻尼：`F_n = max(k_n*delta - c_n*v_n, 0)`（`dem3d.py` 球-球、刀具、压板三个分支全部截断）。
历史上的 `e -> c_n` 映射复用的是**自由**振子恒等式 `e = exp(-pi*zeta/sqrt(1-zeta^2))`，该式只在法向力允许变号（粘性）时成立。
截断把分离后期的制动项删掉了，于是**实测回弹恒大于请求值**——单个参数偏差即超出工程 3% 带。
仓内 `docs/dem3d_contact_impact_analytic.md` 早已量化该偏差（v=0.3 时 +33 %）并建议「改用 `restitution_to_damping_clamped`」，
但**建议从未接线**：求解器仍在用错误映射，属于典型「验证欠账」。

本单把「解析研究」升级为「求解器实测闭环」，并把正确映射做成默认行为。

| 量 | 值 |
|---|---|
| 粒子半径 R | 0.025 m |
| 密度 rho | 917 kg/m³ |
| 单球质量 m | 0.060018 kg |
| 等效质量 m_eff（等质量对，求解器约定） | m/2 = 0.030009 kg |
| 法向刚度 k_n | 5000 N/m |
| 目标恢复系数网格 e | 0.1 … 0.9（步长 0.1） |
| 初速/间隙 | 0.5 m/s 迎面 / 0.01 m |
| 时间步 | config.recommended_dt x {1.0, 0.5, 0.25} |

## ② 怎么做的（方法 / 流程 / 关键设置 / 工具链）

1. **判据先行**：以「实测回弹 e_meas 与请求 e_target 的相对误差 < 3 %」为唯一验收线（离散时间步误差另作收敛旁证）。
2. **接入正确映射**：`DEM3DConfig` 新增 `restitution_mapping: {"clamped"(默认), "classic"(历史)}`，
   `pair_normal_damping` 属性把 e 反演为 c_n（`clamped` 走 `contact_impact.restitution_to_damping_clamped` 的二分反演，
   该式是本求解器真正积分的压缩限幅律的解析解；`classic` 保留历史自由振子恒等式，供复现旧基线）。
   反演结果 `lru_cache` 缓存，**每配置只算一次**，并提升到 `IceDEM3D.__init__`，逐步装配里不再重复求值。
3. **顺手修一处一致性缺陷**：`recommended_dt` 的阻尼稳定界原本只读 `contact_damping`（它只驱动刀具分支），
   完全不看球-球分支真正使用的 c_n；e 较小（阻尼大）时该界偏乐观。改为 `max(contact_damping, pair_normal_damping)`。
4. **闭环实测**：用 `contact_restitution.measure_dem3d_impact` 驱动**真实** `IceDEM3D`（2x2x2 盒子中挖出一对自由球，
   断开全部键、冻结其余粒子、关掉 drag），逐档测 e_meas；`both_free=True` 才与求解器的 m_eff=m/2 约定一致。
5. **反自证控制**：同一套实测对 `classic` 映射必须**失败**（否则说明探针测的是公式自己）；另加 e=0.1 边界与固定墙（m_eff=m）两个对照。
6. **工具链**：`scripts/audit_dem3d_restitution_mapping.py` 程序化产出 `artifacts/dem3d_restitution_mapping/{results.json, results.csv, figure.png}`，
   测试 `tests/test_dem3d_restitution_mapping.py`（20 项）为回归门。

## ⑤ 注意点（坑 / 局限 / 适用范围）

1. **m_eff 约定是关键坑**：求解器球-球分支固定按**等质量对** m/2 反演阻尼。若实际一端是固定墙，真实 m_eff = m，
   实测回弹会偏高 15 %–33 %（§3.4）。这不是映射错误，而是*建模约定*；文档与测试都已显式钉住，避免日后被当成回归反复"修"。
2. **适用带 e >= 0.2**：e=0.1 时 zeta≈0.9，接触力在接近段内即被截断，每接触只有几步，离散误差把实测抬到 +34 %。
   映射本身是解析精确的，失效的是**积分器分辨率**；因此只声明 e∈[0.2,1] 满足 3 %。
3. **仅覆盖线性法向律**：Hertz 非线性、粘附/拉伸接触、切向与滚动不在本单范围（切向另有 m2425 审计）。
4. **`classic` 保留但不再默认**：为复现历史基线保留开关，语义上等于「按自由振子恒等式取阻尼」而非「请求回弹系数」。
5. **既存红未清**：`tests/test_dem3d_restitution.py` collection error（`tensordem.restitution.clamped_contact_restitution` 缺失）与
   `tests/test_dem3d_contact_impact.py` 5 项失败均为**本单改动前既存**（stash 后在干净基线上复现同样 5 项），本单未新增失败；
   其中 `pair_impact` 走 `contact_damping` 而球-球分支按 e 反演，是另一条既存语义裂缝，建议另派单。

## ⑥ 误差判定（关键量 vs 基准，逐项，显式回答是否 <3 %）

| 关键量 | 基准 | 实测误差 | 是否 <3 % |
|---|---|---|---|
| e=0.2 实测回弹 | 请求值 0.2 + 压缩限幅解析解 | -1.53 % | 是 |
| e=0.3 实测回弹 | 请求值 + 解析解 | -1.34 % | 是 |
| e=0.5 实测回弹 | 同上 | -0.10 % | 是 |
| e=0.7 实测回弹 | 同上 | +0.51 % | 是 |
| e=0.9 实测回弹 | 同上 | +0.17 % | 是 |
| 带内最坏档（e>=0.2） | 请求值 | 1.53 % | 是 |
| e=0.3（历史 classic 映射） | 请求值 | +32.82 % | **否**（本单修复对象） |
| e=0.1（clamped，边界外） | 请求值 | +34.4 % | **否**（已声明适用带 e>=0.2） |
| 解析反演 vs 独立 RK4 积分 | 同一压缩限幅律两条独立路径 | 见 results.json `analytic_cross_check` | 是（e>=0.2 带内） |

结论：默认映射在 e∈[0.2,1] 内把「请求回弹」变成**可兑现的指标**（最坏 1.53 %），
此前同一指标在 e<=0.7 时超 3 % 带、e=0.3 时超 30 %。e<0.2 的失效已被显式声明，不做粉饰。
