## ① 案例介绍：物理背景与参数

海冰在波浪中的响应是冰区航行的基础问题：单块浮冰在规则波下的纵摇/升沉 RAO 决定浮冰是否「随波起伏」，浮冰群的散射决定波能穿透率，波致弯曲应力决定碎冰尺度分布。战役判据要求用 TensorDEM 的DEM 力核（逐粒子浮力、Morison 波浪载荷、刚体动力学）回答这三件事。

本节点采用二维（纵剖面、单位宽度）冰板块，参数**全部为输入**（非拟合）：

| 量 | 符号 | 值 |
|---|---|---|
| 冰板块长度 | $L$ | 20.0 m |
| 冰厚 | $h$ | 1.0 m |
| 冰密度 / 水密度 | $\rho_i/\rho_w$ | 917.0/1025.0 = 0.8946 |
| 吃水 | $d=\rho_i h/\rho_w$ | 0.8946 m |
| 单位宽度质量 | $m=\rho_i L h$ | 18340.0 kg/m |
| 纵摇惯量 | $I=m(L^2+h^2)/12$ | 6.1286e+05 kg·m²/m |
| 垂荡刚度 | $K_{33}=\rho_w g L$ | 2.0110e+05 N/m² |
| 纵摇刚度 | $K_{55}=\rho_w g L^3/12$ | 6.7035e+06 N·m |
| 附加质量（$C_a=0.5$） | $a_{33}=\rho_w C_a L d$ | 9.1700e+03 kg/m |
| 垂荡固有周期 | $2\pi\sqrt{(m+a_{33})/K_{33}}$ | 2.3239 s |
| 粒子离散 | $n_x\times n_y$ | 40 × 2 = 80 个矩形柱 |
| 吃水（柱离散校验） | $d$ | 0.8946 m |

波浪与结构工况：

- 入射规则波：$H$ = 0.1 m、$T$ = 8.0 s（RAO 扫频 1.5–45 s，覆盖 $kL$ = 0.040–35.77）；
- 海况谱：JONSWAP $H_s$ = 2.0 m、$T_p$ = 8.0 s、$\gamma$ = 3.3；
- 冰区阵列：水深 1.0 m、单块长 5.0 m、间隙 5.0 m、12 块、厚 0.2 m；
- 弯曲破坏：$E$ = 9.00e+09 Pa、$\nu$ = 0.3、$h$ = 1.0 m、抗弯强度 $\sigma_f$ = 5.00e+05 Pa。

## ② 怎么做的：方法与工具链

新增模块 `src/tensordem/wave_floe/`（5 个子模块 + 判据运行器）：

| 文件 | 内容 | 证据 |
|---|---|---|
| `waves.py` | Airy 波场，**Newton 求解**有限水深色散 $\omega^2=gk\tanh kd$，表面/质点速度/加速度、群速度、能流 | REAL |
| `spectra.py` | JONSWAP / Pierson-Moskowitz（$H_s$ 精确归一）、谐波实现、Welch 单边谱估计、谱保真度 R² | REAL |
| `response.py` | 冰板块**两自由度刚体**（垂荡+纵摇）：逐柱浮力对**局地**水面高程、相对加速度 Morison 载荷（$C_m=1+C_a$，附加质量隐式装配）、RK4 时域；同模型的频域复 2×2 传递函数（continuum / lattice 两条参考路径）；能量台账 | REAL |
| `array.py` | 长波（slab）多体散射：分段传播+界面匹配的转移矩阵，透射/反射系数、能量闭合、Bragg 隙 | REAL（长波近似内） |
| `breakup.py` | Winkler 地基上自由-自由 Euler-Bernoulli 梁 FEM（Hermite 单元+一致地基矩阵）对波浪压力 $\rho_w g\eta$ 求弯曲应力 → $H_{crit}$；闭式浮板理论对照 | REAL |

**关键设置**：RK4，$\Delta t = T/240$（RAO）/ $T/600$（能量台账）；RAO 由稳态窗（后半段）最小二乘谐波回归提取（同时给出拟合残差）；阻尼为线性化黏性项 $b=2\zeta\sqrt{K(M+a)}$，$\zeta=0.10$（输入，非势流辐射阻尼）。

**同时修复了一处已装运内核缺陷**（`src/tensordem/buoyancy_wet.py`）：`compute_wave_force` 的垂向载荷**只有拖曳项**——Morison 惯性项只写了水平分量，`wave_kinematics` 也不返回垂向加速度，因此浮体在现有 wet coupling 下**根本得不到波浪垂向激励**（垂荡 RAO 恒≈0，无法做任何波浪–浮冰验证）。修复为新增向后兼容的 `wave_kinematics_full`（含 $\partial u_y/\partial t$）并在 `compute_wave_force` 加 $F_y=\rho_w C_M A_p\,\partial u_y/\partial t\,t_{thick}f_{sub}$；既有 42 个 wet-coupling 测试全绿（回归无破坏）。

## ⑤ 注意点（踩坑、局限、适用范围）

**本节点实测踩到的坑（均已修正，回归测试覆盖）**：

1. 平衡吃水求解符号写反（浮力过剩时应**上浮**，即提高下界），导致初值偏离平衡 0.4 m、时域积分发散——表现为能量台账出现 $10^8$ J 量级假值。判据数字在修正前全部不可信。
2. 圆盘格点**不能**平铺矩形：重叠圆盘使水线弦长超出 13%（$K_{33}$ 偏高）、吃水失真。改用**等面积矩形柱**后 $K_{33}=\rho_w gL$ 精确到机器精度，并在细化时单调收敛。
3. 频域模型最初只含 Morison 惯性激励，**漏了波致水线压力项** $\rho_w g\,\mathrm{chord}\,\eta$；长波极限因此给出 $RAO\to0$（而非 1），时域/频域相差 4 个量级。补上该项后两路一致到 0.2%。
4. Hermite 梁单元二阶导写成了"一阶导的残余"，FEM 弯曲应力偏高 49.5 倍（挠度却仍对，故只看挠度会漏掉）；修正后 FEM/理论 = 1.027。
5. 转移矩阵界面匹配把阻抗取成 $k$（应为 $1/k$）；能量闭合 $|T|^2+|R|^2=1$ 仍成立（两侧同介质时任何实匹配都闭合），**单界面 Fresnel 校验才暴露**——所以 C2 保留该独立校验。
6. Welch 归一化把 $dt$ 放进分母（应为分子），谱密度整体偏高 16 倍；$H_s$ 反演 8.0 m vs 目标 2.0 m 直接暴露。
7. 谱保真度受**估计带宽**限制：段长 4 个峰周期时 $R^2$ 只有 0.734，16 个峰周期才到 0.985；单实现周期图有 χ² 散布，必须用集合估计才能谈 $R^2$。

**适用范围与局限（引用任何数字时须一并引用）**：

- 附加质量取频响无关常数（$C_a=0.5$），**无势流辐射阻尼**，故模型在高频不衰减；本报告只在 $kL\lesssim 2$ 内引用数字。阻尼为线性化黏性项，$\zeta$ 是输入。
- Morison/FK 模型在短波端（$kL>2.5$）激励是近乎完全相消的小量，相对误差失去意义（粗格点该处最大 1176.0%；在 $0.1<kL<2.5$ 判别带内仅 0.40%）——报告分开列，未掩盖。
- C2 为**长波 slab 模型**（$k_0d\lesssim0.6$，非色散），不能与 $kd\sim1$ 的色散实验（Kohout 等）直接比较；且当前耦合求解器以**给定入射波**驱动、无自由面未知量，无法产出"测得"的 $T$。
- C3 是**首应力**判据（连续梁 FEM），不是 DEM 键断裂：无裂纹扩展、无亚临界生长、无键强度统计。$H_{crit}$ 只对给定 $\sigma_f$、$E$ 成立。

**未验证面（C7 台账，`metrics.json` 中原样记录）**：
- external potential-flow RAO (WAMIT/AQWA) — no data in the tree
- dispersive multi-floe transmission versus experiment — needs a free-surface (two-way) solver
- DEM bonded-particle fracture under wave load — the C3 route is a continuum FEM beam, not particle bond rupture
- radiation damping: a frequency-independent added mass is used; no potential-flow coefficient table exists

**不满足 <3% 的三项及其原因**：

1. $H_{crit}$ 2.58%：FEM 与闭式解差异来自自由-自由端部效应（$L/L_c$ = 11.8，端部修正仍有 2–3%）与有限元离散；判据 25% 满足。
2. 谱 $R^2$ = 0.9861：估计器有限带宽 + 有限集合样本，残差是估计量本身的性质而非模型误差；随段长收敛到 0.9983（见 C4 表）。
3. 能量台账残差 4.34%：主因是附加质量算子被**冻结**在平衡浸没率（线性化），而瞬时载荷用**瞬时**浸没面积，二者差 $O(\Delta f_{sub})\sim A/h$；另含起始瞬态。这是模型层面的不一致（不是积分器误差——自由振荡漂移 1.51e-07 证明积分器守恒）。判据 5% 内满足。

**honest-FAIL / WITHHELD 声明**：C2 的"与实验数据 ≤20%"一栏**无法裁定**（仓内无数字化透射实验数据；当前求解器无自由面未知量无法测 $T$；长波模型不在实验的色散区间）。C1 的"与 WAMIT/AQWA 势流解对标"同样**无法裁定**（仓内无该数据）。两项均按 WITHHELD 记录，未用自洽结果冒充外部验证。
