# DEM3D Hertz 配对接触恢复系数：声明的 `restitution_coefficient` 是真的吗？

状态：**验证欠账结清（含一条 honest 否定结论）**。证据：`benchmarks/hertz_pair_restitution_verification.py`（数字全部程序化产出）、
`artifacts/hertz_pair_restitution/audit.json`、`tests/test_hertz_pair_restitution_verification.py`（10 项，全绿）。

## 1. 案例介绍（物理背景 / 参数）

`DEM3DConfig(contact_model="hertz")` 的**配对（球-球）**分支积分如下接触律

```
F_n = clamp( k_h δ^(3/2) - γ(δ) v_n , 0, ∞ )
k_h     = (4/3) E* sqrt(R*)            = 8.190725e+07 N·m^(-3/2)
k_s(δ)  = k_h sqrt(δ)                  割线刚度
γ(δ)    = 2 ζ sqrt(k_s(δ) m_eff)      = 2 ζ sqrt(k_h m_eff) δ^(1/4)
ζ       = |ln e| / sqrt(π² + ln²e)     ← 线性 Kelvin–Voigt 映射（由 restitution_coefficient 反推）
```

要点：`ζ` 不是用户输入，而是用**线性**弹簧-阻尼体系的映射从 `e` 反推，再套到 **Hertz** 律上；
阻尼带 `δ^(1/4)` 因子，使**局部**阻尼比 `γ/(2√(k_s m_eff)) ≡ ζ` 与压缩幅值无关（Hunt–Crossley 式构造）。
引擎实际表现出的恢复系数是否等于用户声明的 `e`，此前**无测试、无文档**；
已合并的 Hertz 文档（`docs/dem3d_hertz_contact_verification.md` 第 174 行）仍写 Hertz 阻尼"保持旧式绝对 `c_n`"、
"冲击恢复系数尚不能通过物理参数控制" —— 与代码不符（代码确有 restitution 分支），属**过期声明**。

| 量 | 符号 | 值 |
|---|---|---|
| 颗粒半径 | r | 0.025 m |
| 密度（冰） | ρ | 917.0 kg/m³ |
| 颗粒质量 | m | 0.060018 kg |
| 配对有效质量 | m_eff = m/2 | 0.030009 kg |
| 杨氏模量 / 泊松比 | E, ν | 1.0e+09 Pa, 0.3 |
| 配对等效模量 / 半径 | E*, R* | 5.494505e+08 Pa, 0.0125 m |
| 每颗粒冲击速度 | v | ±0.5 m/s（相对接近 1.0 m/s） |

## 2. 怎么做的（方法 / 工具链）

1. **独立参考解（不经过引擎代码）**：SDOF 方程按 SI 单位用经典 RK4 积分，步长由 Hertz 接触时标给出并做 3 级加密
   （4000/8000/16000 步），同时输出能量账 `∫F dδ = ΔKE`，闭合 1.8e-04~3.1e-04。
2. **引擎测量**：2×2×2 `IceDEM3D`，`sim.alive[:]=False` 取消全部键、`_park_idle` 停放多余颗粒，只武装 0/1 两颗粒正碰；
   `dt = recommended_dt × {1, 1/4, 1/16}` 三档验证时间步收敛。
3. **交叉校验**：另给一条一阶（小 ζ）能量损失积分 `1-e² = Σγ(δ)u²dt / E0`（40 点 Gauss–Legendre）。
4. 一个脚本产出 JSON + 4 联图；报告数字无手抄。

- 引擎与独立参考偏差 ≤ 0.019%：**引擎正确实现了它自己的接触律**（实现层无缺陷）。
- **实现正确 ≠ 标定正确**：声明的 `restitution_coefficient` 在 Hertz 分支被系统性高估，偏差从 e=0.9 的 +1.3% 单调放大到 e=0.3 的 +43.7%。

### 3.5 平板（platen）分支的边界

| 声明 e | 实测 e（platen，默认 platen_damping=0） |
|---|---|
| 0.9 | 1.000001 |
| 0.3 | 1.000001 |

Hertz 模型下平板分支用**绝对** `platen_damping`，`restitution_coefficient` 完全不起作用：默认值下冲击严格弹性（e=1.000001）。
旧文档第 174 行的说法**只对 platen/tool 分支成立**，对配对分支不成立。

### 3.6 一阶近似的适用范围（负控）

| 声明 e | ζ | 一阶求积 e | ODE 参考 e |
|---|---|---|---|
| 0.90 | 0.03352 | 0.900904 | 0.911715 |
| 0.70 | 0.11281 | 0.604997 | 0.742221 |
| 0.50 | 0.21545 | 0.000000 | 0.582279 |
| 0.30 | 0.35786 | 0.000000 | 0.431176 |

一阶解在 ζ≲0.11（e=0.9 行）与 ODE 相差约 1%；ζ 更大后崩掉（e=0.5/0.3 行算得 `1-e²`>1 → e=0），
因为推导假设压缩/恢复两相速度剖面镜像对称，忽略了**力被 clamp 到零**导致的提前分离。故一阶式只作小 ζ 交叉校验，不作主判据。

## 5. 注意点（踩坑 / 局限 / 适用范围）

1. **踩坑（自己踩的）**：第一版 RK4 修正项写成 `(k1+k2+k3)/6`（漏 `k4`、权重错），得 e=0.674、能量账差 48%；
   用「引擎律 + 半隐式 Euler + 引擎 dt」复算得 0.5829 与引擎一致，才定位到参考解而非引擎的错。
   教训：**参考解必须先自证**（能量闭合 + 步长收敛），再去判引擎。
2. 偏差机理：`γ ∝ δ^(1/4)` 在接触起始（δ→0 时弹簧力 δ^(3/2) 远小于阻尼力）与恢复末段都会把合力 clamp 到 0，
   **线性理论假设存在的那部分阻尼实际从不作功**，故耗能偏少、e 偏大。非符号错误，非时间步误差（3.2 节）。
3. 适用域：配对球-球、正向对心冲击、法向力非负钳制、`contact_damping_model="restitution"`。
   斜碰/带摩擦时法向结论不变（法向与切向解耦），但未逐一测量。
4. 本单**未改 src**：只交测量、判据与标定表。若要修，建议把 Hertz 分支的 ζ 反演改为「ODE/查表反演到目标 e」
   或新增 `hertz_restitution_calibration(e_desired)`；这属功能改动且会改变默认分支行为，需 owner 决策。
5. `hertz_stability_overlap_fraction` 只影响 `recommended_dt`，与本节结论无关。

## 6. 误差判定

| 关键量 | 基准 | 相对误差 | 是否 < 3% |
|---|---|---|---|
| 引擎 e（声明 0.9） | 独立 RK4 ODE 参考 | -0.000% | ✅ 是 |
| 引擎 e（声明 0.5） | 独立 RK4 ODE 参考 | -0.008% | ✅ 是 |
| 引擎 e（声明 0.3） | 独立 RK4 ODE 参考 | -0.019% | ✅ 是 |
| **引擎 e（声明 0.5）** | **声明的 e = 0.5** | **+16.45%** | ❌ **否** |
| **引擎 e（声明 0.3）** | **声明的 e = 0.3** | **+43.70%** | ❌ **否** |
| 引擎 e（声明 0.9） | 声明的 e = 0.9 | +1.30% | ✅ 是 |
| 标定反演残余（e=0.5） | 目标 0.5 | < 2e-3 绝对 | ✅ 是 |

**结论（honest）**：实现层（引擎 vs 其自身接触律）误差 < 0.02%，达标；**标定层不达标**——
冰力学最常用的 e≈0.2–0.6 区间，声明值与实测恢复系数相差 16%–44%，远超 3% 判据。
故该能力在「声明 e 即可用」意义上应判 **WITHHELD（带缺陷）**，本单给出可直接使用的标定反演表（3.4 节）。
默认分支行为未改动，未粉饰。
