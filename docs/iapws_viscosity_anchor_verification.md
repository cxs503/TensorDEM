# IAPWS 锚定验证：水黏度温度模型

## 1. 案例介绍

冰水浆体流变学模块（`tensordem.ice_slurry_rheology.closures`）中的 `viscosity_temperature` 函数使用二次多项式拟合 log(μ) vs T 来估算水的动力黏度。本验证将该模型与 IAPWS R12-2008 工业标准在 9 个参考温度点进行锚定对比，验证其在冰浆工作温度范围 [0, 40] °C 内的精度。

| 项目 | 设定 |
|---|---|
| 物理量 | 水的动力黏度 μ(T) |
| 温度范围 | 0 ~ 40 °C |
| 参考标准 | IAPWS R12-2008（常压） |
| 验收判据 | 最大相对误差 ≤ 0.5% |

## 2. 方法

- **锚定点**：9 个温度点（0, 5, 10, 15, 20, 25, 30, 35, 40 °C），IAPWS 参考值来自标准表 1。
- **模型**：`μ(T) = exp(a·T² + b·T + c)`，系数 `a = 1.876e-4, b = -3.257e-2, c = -6.329`。
- **验证**：逐点相对误差 + 全范围最大误差 + 单调性检查 + 0 °C/20 °C 收紧判据（≤ 0.2%）。

## 3. 计算结果

### 3.1 逐点对比

| T (°C) | IAPWS (Pa·s) | 模型 (Pa·s) | 相对误差 (%) |
|--------|-------------|------------|-------------|
| 0 | 1.7870e-3 | 1.7835e-3 | 0.196 |
| 5 | 1.5190e-3 | 1.5226e-3 | 0.235 |
| 10 | 1.3070e-3 | 1.3121e-3 | 0.388 |
| 15 | 1.1380e-3 | 1.1413e-3 | 0.293 |
| 20 | 1.0020e-3 | 1.0022e-3 | 0.017 |
| 25 | 0.8900e-3 | 0.8883e-3 | 0.195 |
| 30 | 0.7980e-3 | 0.7947e-3 | 0.410 |
| 35 | 0.7200e-3 | 0.7177e-3 | 0.313 |
| 40 | 0.6530e-3 | 0.6543e-3 | 0.203 |

**最大相对误差：0.410%（30 °C），低于 0.5% 验收线。**

### 3.2 验收判据汇总

| 判据 | 描述 | 阈值 | 实测 | 结果 |
|---|---|---|---|---|
| C1 | 9 个 IAPWS 锚定点逐点误差 | ≤ 0.5% | 最大 0.410% | ✅ PASS |
| C2 | 全范围最大误差 | ≤ 0.5% | 0.410% | ✅ PASS |
| C3 | 单调递减 | 严格递减 | 通过 | ✅ PASS |
| C4 | 0 °C 锚点（冰浆关键温度） | ≤ 0.2% | 0.196% | ✅ PASS |
| C5 | 20 °C 锚点（实验室参考） | ≤ 0.2% | 0.017% | ✅ PASS |

## 4. 注意点

- 该模型在 30 °C 处误差最大（0.410%），但仍远低于 0.5% 验收线。
- 对于冰浆应用（0 ~ 5 °C），模型精度优于 0.24%，完全满足工程需求。
- 该模型仅适用于 [-5, 50] °C 范围，超出范围会抛出 ValueError。

## 5. 误差判定

所有 9 个 IAPWS 锚定点的相对误差均 < 0.5%，**是否 < 3%？是，远优于 3%。**
