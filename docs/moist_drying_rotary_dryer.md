# 滚筒干燥机的含湿颗粒蒸发–传质耦合

**战役节点** `p380w2-n05-moist-drying` · **仓** TensorDEM · **模块** `tensordem.rotary_dryer`
（`psychrometrics` / `moist_transfer` / `moist_bed`）· **工件** `artifacts/moist_drying/`

本节点把 plan 380 n02 的**干颗粒热–力耦合**扩展到**含湿颗粒**：每颗粒携带干基含水率
`X`（= w，kg/kg 干基）与温度 `T_p`，与进气（`T_g`、湿度比 `Y_g`、气速 `u_g`）做对流传热
+ Ranz–Marshall 对流传质 + 潜热汇；恒速干燥期温度被**湿球温度**钉扎，降速期由薄层干燥
动力学（Lewis / Page）描述，并以气固**水量账本**与**能量账本**闭环。

---

## ① 案例介绍

### 物理背景

直热式（direct-heat）并流回转滚筒干燥机：热气自进料端进入并与湿颗粒并流，靠对流给热
蒸发水分。工业上此类设备用于矿料、化肥、砂石、生物质等。关键物理是**气侧供热与蒸发
需求的自限平衡**：气体一边降温增湿、一边把显热转成蒸发潜热；颗粒温度在恒速期被钉扎
在湿球温度附近，含水率降到临界含水率后进入降速期，颗粒温度开始向气温爬升。

## ② 怎么做的

### 状态量与方程

**每颗粒（集总热容，干基）**

```
m_s = ρ_p π d_p³/6 ,  m_w = X m_s ,  A_p = π d_p²
mdot = h_m A_p [ a_w(X) ρ_v,sat(T_p) − ρ_v,g ]                 (对流传质)
Q    = h A_p (T_g − T_p)                                       (对流给热)
m_s (c_ps + X c_pl) dT_p/dt = Q + Q_wall − mdot h_fg(T_p)      (潜热汇)
dX/dt = − mdot/m_s
```

**气侧（准稳态）**：气体停留时间 L/u_g ≈ 1.7 s ≪ 干燥时间 600 s，故每个时间步沿 z
做轴向推进，逐格做 3 次不动点迭代：

```
Y_out = Y_in + E/ṁ_a
h_out = h_in − Q/ṁ_a + E h_v(T_p)/ṁ_a ,  T_out = T(h_out, Y_out)
```

其中 `h` 为湿空气比焓（每 kg 干空气）、`h_v(T_p)` 为颗粒表面温度下的蒸汽比焓。

**颗粒相**：并流塞流（plug flow），在 `n_cells` 个全混格间以 `v_p = L/τ_res` 平流；
另由 `solve_steady_profile()` 用 RK4 沿 z 直接积分稳态两相 PFR（**另一套独立离散**，
用于交叉校核与参数扫描）。

### 物性闭式（`psychrometrics`）

| 量 | 关联式 | 参考 |
|---|---|---|
| p_sat(T) | Hyland–Wexler（ASHRAE Fundamentals ch.1） | ASHRAE 2021 |
| h_fg(T) | 2500.9 − 2.326·T[°C] kJ/kg（ASHRAE 线性律） | ASHRAE |
| μ(T) | Sutherland 1.458e-6 T^1.5/(T+110.4) | — |
| k(T) | ASHRAE 三次多项式（100–1000 K） | ASHRAE |
| D_AB(T,p) | 2.13e-5 (T/273.15)^1.94 (101325/p) | Marrero–Mason 型 |
| 湿球（Lewis=1） | (T_g−T_wb) = h_fg(T_wb)[Y_sat(T_wb)−Y_g]/c_pH | 经典 psychrometric 闭式 |

焓函数成对自洽：`h_fg(T) ≡ h_v(T) − h_l(T)` 对同一组 `c_p` 恒等成立（误差 0），
因此**能量账本残差只度量实现误差，不度量物性模型不一致**。

### 传质/传热闭式（`moist_transfer`）

```
Nu = 2 + 0.6 Re^0.5 Pr^(1/3) ,  Sh = 2 + 0.6 Re^0.5 Sc^(1/3)   (Ranz–Marshall 1952)
h = Nu k_f/d_p ,  h_m = Sh D_AB/d_p       （膜温 T_f = (T_p+T_g)/2 取物性）
```

**湿球钉扎的闭式（Lewis 因子版）**：恒速期定常解满足

```
h (T_g − T*) = h_m h_fg(T*) [ρ_v,sat(T*) − ρ_v,g]              (★)
```

该式即"带 Lewis 因子的 psychrometric 闭式"。**验证钩子**：把 `D_AB` 取为局部热扩散率
`α = k/(ρ c_p)`（`d_ab_override="alpha"`，即 Le = 1）并改用湿度比驱动力，则 (★) 与经典
查图湿球方程**逐位重合**（实测 312.537706 K vs 312.537706 K；差 3.7e-11 K）。这条恒等式
把"双闭式实现"钉在教科书闭式上，是本节点最重要的自证。

同时提供两种驱动力形式：`vapour_density`（任务书指定，默认）与 `humidity_ratio`。
二者在等温气体下只差动力学因子 `p/(p−p_v) ≈ 1.002`；在 T_p ≠ T_g 时 vapour-density 形式
自带 1/T 雅可比，会让钉扎温度比 Lewis=1 查图值低（400 K 进气时 2.2 K，305 K 时 0.91 K）。

### 吸附等温式与薄层动力学

降速期的水活度用锚定在平衡含水率的指数等温式（连续、单调）：

```
a_w = [e^{−κ(X_c−X)} − e^{−κ(X_c−X_e)}] / [1 − e^{−κ(X_c−X_e)}] ,  X_e < X < X_c
a_w = 1 (X ≥ X_c) ,  a_w = 0 (X ≤ X_e)
```

薄层模型：Lewis `X = X_e + (X_0−X_e)e^{−kt}`；Page `X = X_e + (X_0−X_e)e^{−(kt)^n}`，
四个参数全自由做最小二乘（`scipy.optimize.curve_fit`），R²/RMSE 用于判据 (e)。

### 数值与账本

* 气相准稳态推进 + 颗粒显式欧拉（`dt = 2 s`；单格颗粒热时间常数 ≈ 12.5 s，`dt/τ ≈ 0.16`）。
* **能量状态量用焓而非温度**：`H = (m_s c_ps + m_w c_pl)(T_p − T_ref)`，
  更新后 `T_p = T_ref + H/(m_s c_ps + m_w c_pl)`，使账本与状态更新逐位一致。
* 平流用通量形式，出流取**上一步（upwind）**状态，使内部项与边界项精确望远镜相消。

## ⑤ 注意点（踩过的坑 / 局限 / 适用范围）

### 踩坑（均已写进代码注释与测试）

1. **单位筒长表面积 = 存料/长度 × 比表面积**。第一版误写为 `ṁ_s × 6/(ρ_p d_p)`，漏了
   停留时间因子（少 120 倍），稳态 PFR 与瞬态全混格结论差 50 倍——正是"两套独立离散
   交叉校核"抓出来的；修好后两法随网格加密按 O(dz) 一致收敛。
2. **账本出流必须取上一步（upwind）状态**。第一版用更新后的 `X[-1]` 记账，与平流项不能
   望远镜相消，水量残差 1.3e-4（超出 1e-9 判据）；改后降到 1e-14。
3. **能量状态量必须用焓**。第一版按 `dT = (dH − …)/C` 显式积分，`O(dt²)` 不一致导致
   能量残差 7e-6；改为积分 `H` 再由 `H` 反解 `T_p` 后降到 1e-14。
4. **水活度在 X_c 处必须连续**。第一版写 `a_w = exp(−κ(X−X_c))`，X<X_c 时给 >1（非物理，
   过冷），改成锚定平衡含水率的归一化指数式（X_c 处 = 1、X_e 处 = 0、单调）。
5. **两种湿球不是同一个数**。vapour-density 驱动力形式比 Lewis=1 查图湿球低 0.9–2.2 K
   （Le = 0.855 所致）。判据 (a) 定义在"同一闭式对偶的自洽不动点"上，同时把 Lewis=1 极限
   与查图值的 3.7e-11 K 重合作为实现验证；两者差异在"误差判定"中如实列出。
6. **Re<0.1 时 Sh 偏差 8.4% 是关联式本身的性质**，不是实现误差：R–M 的
   `0.6√Re·Sc^{1/3}` 项在 Re = 0.1 已贡献 8.4%，故扩散极限用（i）Re ≤ 1e-3 的点值
   （偏差 0.8%）与（ii）√Re 外推截距（2.000000）两种方式验证。

### 局限

* **无机械 DEM 接触网络**：本模块是滚筒的**热–质**闭合，机械流动在
  `tensordem.drum_flow`；含湿颗粒与接触力（黏结、液桥）的耦合未做（`liquid_bridge`
  可作后续接点）。
* **集总热容**：Bi = h d_p/(2 k_p) ≈ 0.2–0.4，忽略颗粒内温度梯度；高 h/大颗粒需多壳层模型。
* **无收缩 / 破碎 / 磨损**：粒径与表面积恒定。
* **吸附等温式为模型假设**（指数型），未对特定物料标定；`κ` 是敏感性参数。
* **气侧准稳态**：忽略气体积存量与轴向返混（L/u_g ≪ τ_res，适用）。
* **全混格是一阶离散**（dz 收敛），出口含水率比 400 格 PFR 解低 5.6%；生产建议用
  `solve_steady_profile`（RK4）出轴向剖面，全混格法用于时间历程与账本类判据。
* **壁面接触导热/辐射在验证工况为 0**（直热式，气侧供热为主）；`wall_temperature`
  打开时 `energy_wall_source_J` 已计入账本并有测试覆盖，但未做壁面传热文献标定。
* **m7825 干颗粒基线工件不在本工作树**：退化负控 (f) 的基线由独立干路径
  （`simulate_dry_heating`，无任何传质项）以同一配置再生并登记于 `dry_baseline.json`
  （含 `note` 说明），因此该判据检验的是"含湿路径在 w→0、Y_g→0 时逐位退化为干路径"，
  而非对 m7825 工件的逐位复现。

两项 > 3% 的偏差（Whitaker 关联式散差 10.6%、全混格 vs PFR 出口含水率 5.6%）均有
**已知且可界定**的来源，已逐条声明，不掩饰。
