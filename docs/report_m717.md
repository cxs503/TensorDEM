## 1. 案例介绍

### 物理背景
SIR-PC2|I02|G6 节点要求在冰区航行全链（Ship-ICE-Resistance Phase 2）中运行 100k+ 碎冰颗粒的 DEM 模拟，验证规模化性能与物理合理性。碎冰场是极地船舶航行中船-冰相互作用的核心场景：船舶破冰后产生的碎冰在航道中漂移、堆积，对船体产生阻力与局部载荷。DEM 方法将碎冰离散为球形颗粒集合，通过接触力学与键断裂模型模拟冰的破碎、漂移与堆积过程。

## 5. 注意点

### 留档缺失（核心问题）
1. **m717 专属工件未持久化**：原单声明已成功交付，但仓库中无 m717 专属的运行时数据、日志或产物路径。所有可追溯数据均来自关联的 m705 缩放基准测试。
2. **原单 goal 截断**：`mass_conservation <` 阈值不完整，无法程序化验证该判据。
3. **scenario_key 不匹配**：m717 的 scenario_key 应为 `SIR-PC2|I02|G6`，但仓库中缩放数据的 scenario_key 为 `SIR-PC2|V02`（m705）。两者同族但非同一节点。

### 技术局限（继承自 m705）
1. **100k 单步测量**：受 120s shell 超时限制，100k 工况仅完成单步测量。
2. **Python cell-list 开销**：当前 dict-based 实现有显著 Python 开销，向量化 PyTorch 实现可提升 2-3×。
3. **无键断裂工况**：基准使用低速（0.01 m/s）避免键断裂，含断裂的缩放行为未测。

### 适用范围
- 关联工件 m705 数据适用于评估 TensorDEM 在 10k-100k 颗粒区间的缩放特性。
- 不可直接等同于 m717 的"碎冰场"场景——碎冰场涉及键断裂、多尺度粒径分布、自由面漂移等 m705 基准未覆盖的物理。
