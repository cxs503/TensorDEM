## 1. 案例介绍（物理背景 / 几何 / 参数）

碎冰在负温与孔隙水盐度下于接触面上重新冻结，形成**冻结键（freeze bond）**：
一层薄的新冰颈。冰区工程中它决定了碎冰拱能否成拱、能否自持，从而决定冰区
渠道内的输运阻塞与结构冰载荷。本节点把冻结键写成 DEM 黏结本构，并用它去打开
「冰拱」这个宏观自持现象。

### 1.1 强度律（声明为假设，不是实测律）

```
sigma_fb(dT, S, t) = A * dT^alpha * (1 + beta*S)^(-1) * t^gamma
sigma_s           = kappa_s * sigma_fb                (剪/拉双模式)
G_f               = 0.5 * softening_ratio * sigma^2 / k0   (软化长度 delta_f = ratio*delta_0)
```

* `dT` 过冷度 [K]、`S` 孔隙水盐度 [ppt]、`t` 固结时间 [s]；
* 参考律 `FREEZE_BOND_LAW_REFERENCE`：`alpha=1`、`beta=0.05 1/ppt`、`gamma=0.5`、
  `kappa_s=0.5`、`softening_ratio=10`，锚点 `sigma_fb=30 kPa @ (5 K, 0 ppt, 1 h)`，
  即相对 1.5 MPa 体积抗压强度 `kappa = 0.02`。
* **证据分级**：幂律形式与指数集 = WITHHELD（本节点只做实现自校，不做物理验证，
  见 §6）；断裂能恒等式 = REAL（可证）。

### 1.2 单元与装配

* `CohesiveBondSet`：向量化混合模式黏结单元。`delta_e=sqrt(max(delta_n,0)^2+delta_t^2)`，
  `t_e=(1-d) k0 delta_e`，损伤 `d = d(delta_max; delta_0, delta_f)` 使软化段
  **对分离线性**，故峰值牵引力恰为 `sigma_p`、破坏时耗散恰为 `G_f`。
* **单边单元**：压缩法向由冰–冰圆盘接触承担（薄冰颈在压紧后不承压），因此
  压–剪状态下键在 `sigma_s` 剪坏而不是被"压碎"。这一条是本节点最重要的建模决定，
  理由与替代方案见 §5。
* `assembly`：三角晶格密排圆盘（重叠量 `contact_gap_fraction=-2e-5` 的间距），
  冻结键只占接触的一部分（`bond_fraction=0.6`，即**再冻结碎冰**而非完整冰盖），
  冻结键强度按对数正态离散（`bond_strength_cv=0.25`）；圆盘接触与墙面用
  Cundall–Strack 切向历史 + Coulomb 上限。
* `solver`：位移控制准静态加载，修正 Newton（割线刚度 + 回溯），损伤历史变量在
  Newton 通道之间推进；能耗台账按状态函数累计。

## 2. 怎么做的（方法与工具链）

1. **本构实现**（`constitutive.py` / `cohesive.py`）：幂律 + 混合模式 + 损伤历史变量 +
   `refreeze()`（可逆强度史，保留已耗散能）。
2. **单键自校**（`single_bond_self_consistency`）：在 `(dT,S,t)` 网格上以单轴加载到峰值，
   把单元的峰值牵引力与解析幂律逐点比较；拉、剪两个模式都做。
3. **多键能量台账**（`solver.load_steps`）：
   `W_ext = ΔU + W_diss,bond + W_slip`，其中 `W_diss,bond = Σ G_f·A`（状态函数，
   由 `delta_max` 决定，单调不可逆），`W_slip` 为接触/墙面摩擦滑移功。
4. **渠道试验与力链拓扑**（`experiments.channel_arch_run` + `force_network`）：
   每步记录推板力、载荷盒力（**传递比** `T=F_loadcell/F_platen`）、侧墙推力、键损伤，
   并在强接触力子图上算**力链环数**（圈秩 `mu=E-V+C`）、跨通道环数、是否墙–墙连通。
5. **kappa 扫描与阈值**（`kappa_sweep` + `bilinear_breakpoint`）：对 `arch_count`、
   `transmission`、`mean_damage` 各做双段线性拟合求折点，并要求"折点可见"
   （水平跳变 >5% 量程或斜率相对变化 >25%），否则 **报 None 而不是编一个数**。
6. **自持协议**（`self_sustain`）：加载成拱 → 保持推板再平衡（拱是否松弛消失）→
   逐级过驱至断裂 → `refreeze()` 再冻结后松弛（拱是否复现）。
7. **与 Lindqvist 族并列**（`lindqvist.py`）：复用 `level_ice.formula.lindqvist_components`
   的系数台账（`ledger_sha256`），把 DEM 的"含/无黏结"推力比 `r` 附着其上，
   给出**区间**而非点预测。
8. **工具链**：纯 numpy/scipy + matplotlib（Agg）；`pytest` 三文件 23 例；
   一次全量运行 ~250 s（`scripts/run_freeze_bond_arch.py`）。

## 4. 注意点（踩过的坑 / 局限 / 适用范围）

**踩过的坑（全部已修，且都留了可复现判据）**

1. **符号约定**：键力一度写成"拉伸即推开"，Newton 用正定刚度矩阵必须解 `S·du=+r`；
   FD 对照通不过是因为力与雅可比同时反号（自洽的错），只能靠物理推理发现。
2. **耗散记账不能用钳位**：逐增量 `max(0, dW−dU)` 会把负增量丢掉，台账正好漏掉
   被钳掉的量（曾出现 −18 % 残差）。改为**状态函数** `W_diss(delta_max)`（单调不可逆、
   破坏时恰为 `G_f`）后残差降到 0.2 %。
3. **单位陷阱**：单元台账是 J/m²，装配层必须乘 `A`；曾因此把键耗散放大 50 倍
   （残差 −132 %）。
4. **Cundall–Strack 必须用矢量锚**：把切向锚存成"旋转坐标系里的标量"会在法向转角时
   凭空造滑移，摩擦功虚增一个量级；新接触必须以自身构型为锚（`xi=0`），
   否则会施加 `k_t·|相对位移|` 的虚假切向力。
5. **能量一致性约束**：显式 `G_f` 只有在 `G_f >= 0.5 sigma^2/k0` 时才自洽，否则
   `delta_f < delta_0`（键在弹性段内就得断）。kappa 跨两个量级时不可能固定 `G_f`，
   故改用**声明的软化比** `delta_f/delta_0=10`，`G_f` 由强度导出。
6. **几何化噪声**：抖动晶格 + 等半径会带来 1e-3 m 量级重叠（远超弹性量 1e-7 m），
   接触力瞬间 1e6 N。改为"等半径密排 + 强度对数正态离散"：几何规整、强度无序，
   墙面接触稳定。噪声进了强度而不是坐标。

**局限（明确声明，不可外推）**

* 2D 平面应变、中心力三角晶格（无转动弹簧，泊松比 1/3）、无率相关性
  （准静态协议，不描述冰的速率效应）；
* 键模量、接触刚度是**计算**参数；结论以 `kappa` 与归一化传递比表达，绝对力值不可比；
* 冻结键只占 60% 接触、强度对数正态 CV=0.25 —— 这是"再冻结碎冰"的声明性微观结构，
  未对任何实测碎冰级配/冻结率标定；
* `W_slip` 只在步末更新锚（步内冻结），故台账残差含这部分近似；
* 自持协议的"再冻结→复拱"未演示成功（见 §3.5），且"跨通道环数"在稠密堆积中不敏感；
* 幂律指数集无实测依据（WITHHELD）。

## 5. 与替代方案的关系

* **压碎支**：曾实现 `sigma_c=1.5 MPa` 的压缩损伤支，但它要求 `G_f >= 0.5 sigma_c^2/k0
  ≈ 750 J/m²`，否则压碎会带来非物理的巨大耗散（实测放大 10 倍）。改为单边单元
  （压缩交给接触）后既物理合理（薄颈不承压）又能量自洽。
* **成拱判据**：除本文用的圈秩/跨通道环，还评估了"墙–墙强连通"布尔量（在稠密受限
  堆积中恒为真，不敏感）与"载荷盒传递比下降"（方向被证伪）。三者的表现均写入 §3.3/3.5。

## 6. 误差判定（逐项，显式回答是否 <3%）

| 关键量 | 基准 | 误差 | <3%? | 说明 |
|---|---|---|---|---|
| 黏结单元峰值牵引力 | 本模块解析幂律（自校） | **1.2e-16** | ✅ 是 | 实现自校，**不是**物理验证 |
| 单键破坏耗散 | 声明 `G_f`（同一律导出） | **<1e-12** | ✅ 是 | 恒等式，REAL |
| 多键能量台账闭合 | `W_ext` | **0.66 / 0.33 / 0.17 %**（20/40/80 步） | ✅ 是 | 一阶收敛，非漏洞 |
| 双轴胞台账闭合 | `W_ext` | **0.04–0.05 %** | ✅ 是 | |
| 峰值强度 vs 实测冻结键强度 | 无（离线无数据） | — | ❌ **无基准** | 幂律形式与指数集 WITHHELD，本节点不声称物理验证 |
| 阻力增量 vs m5703 Lindqvist 实测列 | Lindqvist 参考列本身为经验锚 | 未比对（2D DEM 比值附着） | ❌ **不适用** | 只给区间 [下界, 上界]，声明为界不是预测 |
| kappa_c 阈值 | 无独立基准 | — | ❌ **无基准** | 三个判据并列，值本身是 DEM 结果 |

诚实结论：①②③ 与台账项**全部 <3%**（其中 ②③ 是恒等式/离散收敛，属实现级 REAL）；
④ 的 `kappa_c` 与 ⑤ 的阻力区间**没有独立实验基准**，只能作为 DEM 内部一致的结果与
**有界区间**报告，不外推为工程预测。
