# IceDEM 精确圆弧船首接入：把验证过的弧内核接进生产求解路径（并量化折线偏差的真实适用域）

日期：2026-11-03 · 仓：TensorDEM · 分支：`agent/m2664`

**一句话结论**：`tensordem.hull_geometry.arc_hull_contact_forces`（此前只能被审计脚本调用）
已接入生产路径 `tensordem.dem.IceDEM(hull_arc=CircularArc(...))`。接入后的弧船首与闭式罚函数
`k·overlap` 在全部扫描点误差 **0.000%**（机器精度），并且**等于折线族的极限**——动态压入 260 步，
弧船首的峰值工具反力与 `N=4096` 折线相差 **−2.7e-8**（33 盘冰排）/ **−8.7e-6**（4 盘小浮冰），
即弧内核不是"另一个模型"，而是同一物理律的精确实现。同时本单把
`docs/dem2d_hull_polyline_geometry_audit.md` 留下的 **−24.09%** 摆到它真正适用的域里：
该数只在"单接触、弦中点相位、浅压入 `δ/r_p ≲ 0.05`"时成立；动态压入的**峰值载荷**发生在
深压入区（`δ/r_p ≈ 0.8`），那里 `N=32` 折线已经只有 **−0.31%**。

## 1. 案例介绍

**物理背景**：破冰船船首与冰排的接触是船-冰相互作用 DEM 的载荷入口。二维原型 `IceDEM`
把船首表示为**折线**（`hull_profile`），用粒子到折线的最近距离作为罚函数压入量。折线是圆弧的
**割线**，割线到粒心的距离恒大于弧到粒心的距离，于是压入量被系统性低估、冰载荷被低估。
`docs/dem2d_hull_polyline_geometry_audit.md`（已验证合并）用闭式圆弧基准把这个几何偏差算清楚，
并给出精确弧内核 `arc_hull_contact_forces`，但当时代码里**只有审计脚本**用它：
`IceDEM` 的 `hull_profile` 参数只接受折线，生产算例跑的仍是折线。本单结清这条"内核有了、
生产没用"的落地欠账，并复核该审计结论在**动态积分算例**中到底折损多少。

**几何与参数**（全部 SI；`contact_stiffness = 2000 N/m`，`r_p = 0.025 m`，`thickness = 0.2 m`）：

| 符号 | 含义 | 取值 |
|---|---|---|
| `R` | 船首圆弧半径 | 0.25 m（`R/r_p = 10`） |
| `Θ` | 船首张角 | π（180°） |
| `R_pad` | 罚函数附加半径（`hull_radius = tool_radius`） | 0.1 m |
| `r_p` | 冰颗粒半径 | 0.025 m |
| `N` | 折线段数 | {8,16,32,64,128,512,4096} |
| `v_hull` | 船首竖直压入速度 | 0.2 m/s（向上） |
| `δ` | 弧压入量（kernel 的 overlap） | `r_p × {0.002…0.2}` |
| 冰排 | `11×3 = 33` 盘，两端固定；小浮冰 `2×2 = 4` 盘（自由） | — |

## 2. 怎么做的

1. **接入（`src/tensordem/dem.py`，最小改动）**：新增可选参数 `hull_arc: CircularArc`。
   - `hull_arcs()` 把存储的弧按 `hull_start + t·hull_velocity` 整体平移到当前时刻（与
     `hull_profile` 同一参考系约定），`forces()`、保守力回算、`mechanical_energy()`
     全部走弧分支；`hull_profile` 与 `hull_arc` **互斥**（同给即 `ValueError`）。
   - `snapshot()/from_snapshot()` 增加 `hull_arc` 字段；旧存档没有该字段时**照常恢复**
     （`hull_arc` 是可加字段，旧折线算例向后兼容），未知字段仍被拒绝。
   - 折线路径、刚体工具路径、判据与账本**未改动**。
2. **三段验证战役**（`scripts/dem2d_arc_bow_study.py`，全部驱动**生产对象**，不复制接触律）：
   - A `geometry`：单盘、静止船首、规定压入量，力对闭式 `k·δ`；扫 `N` 与 `δ/r_p`。
     采样点取**弦中点径向线**（割线离散的最坏相位；顶点处误差恒为 0，不能用来暴露偏差）。
   - B `sheet`：33 盘粘接冰排，动态竖直压入 260 步（`dt = 2.20e-4 s`），弧 vs 各折线。
   - C `floe`：4 盘小浮冰（小接触斑/碎冰工况），同法（`dt = 1.01e-3 s`）。
   - 判据：峰值工具反力、早期（前 0.30 s）载荷 RMS、接触盘数、能量与作用-反作用。
3. **工具链**：PyTorch 2.14 CPU / float64，`torch.set_num_threads(2)`；
   图 `scripts/dem2d_arc_bow_figures.py`（matplotlib → `docs/dem2d-arc-bow/*.png`），
   数 `docs/dem2d-arc-bow/study.json`（脚本直出，零手抄）。
   复现：`PYTHONPATH=src python3 scripts/dem2d_arc_bow_study.py && PYTHONPATH=src python3 scripts/dem2d_arc_bow_figures.py`。

### 3.1 战役 A：单盘力 vs 闭式弧（相对误差，负=低估）

|---|---|---|---|---|---|
| 0.002 | −100.000%（**丢接触**） | −100.000%（**丢接触**） | −37.649% | −0.037% | **0.000%** |
| 0.05 | −100.000%（丢接触） | **−24.091%** | −1.506% | −0.001% | **0.000%** |
| 0.20 | −96.074% | −6.023% | −0.376% | −0.000% | **0.000%** |

弧内核在**全部**扫描点误差 0.000%（|误差| < 1e-12），作用-反作用残差 `0.00e+00 N`，
法向方向误差 `0.000°`。`N=32 / δ/r_p=0.05` 的 **−24.091%** 与 `N=128` 的 **−1.506%**
同已发布审计逐位一致——同一结论在生产对象上被独立复现（此前只在审计脚本路径上证过）。

| 船首 | 峰值反力 [N] | 相对精确弧 | 早期 RMS |
|---|---|---|---|
| **精确弧** | **800.214** | **0.000%** | 0.000% |
| N=8 | 773.542 | −3.333% | **26.624%** |
| N=16 | 800.096 | −0.015% | **24.925%** |
| N=32 | 797.391 | −0.353% | 0.191% |

小浮冰的峰值误差**非单调**（N=16 优于 N=32）：单接触斑的误差取决于**弦相位**，即粒子恰好落在
弦中点（最坏，−s/δ）还是顶点（最好，0）；而早期 RMS 在 N≤16 时高达 25%——浅压入阶段整段载荷
都落在"丢接触/低估"区。这正是精确弧内核的价值：它把相位这类**非物理噪声**整体消除。

## 5. 注意点与局限

- **弧内核是可选路径**：`IceDEM` 默认仍是折线 + 刚体圆盘；本单不改变任何既有默认行为，
  旧存档、旧 CLI（`--hull-profile` CSV）逐位不变（回归 20 passed）。
- **仍是二维、单弧片**：`hull_arc_contact_forces` 支持弧片列表，但 `IceDEM` 当前只接一片
  （足够表示 180° 凸船首）；**多弧拼接的弧-弧接缝**、凹轮廓、三维船首棱柱/回转体
  **未做**（原审计列的另外两条欠账仍开放）。
- **`−24%` 是单接触最坏相位的上界，不是算例级误差**：动态算例里它被两件事稀释——
  (i) 峰值载荷出现在深压入 `δ/s ≈ 66`（`s = 3.0e-4 m`），(ii) 接触斑内多个粒子处于不同
  弦相位而互相平均。因此**不能用 −24% 去反驳或夸大已发布的折线算例峰值载荷**。
- **线弹性罚函数**：误差与刚度无关；若换 Hertz 型非线性律，折线偏差按 `(δ−s)/δ` 的非线性
  放大，结论只会更差（弧内核无此问题）。
- **未做载荷谱分析**：法向方向误差本单未扫（`N=32` 上界 `Θ/2N = 2.8°`），其对高频载荷成分的
  影响需专门算例，不在本单范围。

## 6. 误差判定（关键量 vs 基准，逐项）

| 关键量 | 基准 | 误差 | 是否 <3% |
|---|---|---|---|
| 弧船首单盘力（`δ/r_p` = 0.002…0.2 全扫描，生产 `IceDEM.forces()`） | 闭式 `k·(r_p+R_pad−r)` | **0.000%**（<1e-12） | **是** |
| 弧船首作用-反作用 | 动量守恒 | `0.00e+00 N` | **是** |
| 弧船首接触势能 | `½kΣoverlap²`（精确弧距离） | <1e-8（测试断言） | **是** |
| 弧船首 vs 折线族极限（33 盘冰排峰值载荷 / N=4096） | 折线收敛值 | **−2.7e-8** | **是** |
| 弧船首 vs 折线族极限（4 盘小浮冰） | 折线收敛值 | **−8.7e-6** | **是** |
| 折线 N=32 冰排峰值载荷 | 精确弧 | −0.307% | **是** |
| 折线 N=8 冰排峰值载荷 | 精确弧 | −8.281% | **否** |
| 折线 N=32 单接触最坏相位（`δ/r_p=0.05`） | 精确弧（同审计） | **−24.091%** | **否** |
| 折线 N=16 小浮冰早期载荷 RMS | 精确弧 | **24.925%** | **否** |

**判定**：弧船首路径**满足** 3% 标准且实为机器精度，并等价于折线族极限，可作为折线船首的
直接替代；折线船首的 −24% 上界在"单接触最差相位 + 浅压入"下**确实不满足** 3%，
但在动态压入的峰值载荷处（N≥32，深压入）已满足 3%——两个结论并存，适用域已在第 5 节写清。
