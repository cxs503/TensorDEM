# 巴西劈裂各向异性连续体基准：m2543 的 33% FAIL 是基准选错，不是求解器错

> 承接 `docs/dem3d_brazilian_hondros_closure.md`（mission m2543）§6 末尾明确挂账的两条路线
> 之一：**「把判据换成以格点各向异性连续体为基准（需要各向异性中心场解，本单未做）」**。
> 本文把那句「未做」做掉：用一套与 DEM 完全不同的离散（Q4 平面应力有限元）求出**用格点自己的
> 等效刚度张量构成的连续体**在巴西试件里给出的中心场，从而把 m2543 的缺口**逐项拆开并定量归因**。

## 1. 案例介绍

**物理背景。** 巴西劈裂（径向压缩）是冰/岩石抗拉强度的标准试件：圆柱沿一条直径受压，
中心出现垂直于加载方向的拉应力，试件沿加载直径裂开。解析基准是 Hondros (1959) /
ASTM D3967 的点载荷解（点载 `P`、直径 `D`、厚度 `t`）：

```
sigma_axial = -6 P / (pi D t)      (沿加载方向，压)
sigma_xx    = +2 P / (pi D t)      (垂直加载方向，拉，即"分裂应力")
ratio = sigma_axial / sigma_xx = -3
```

**争议点。** m2543 用**同一张键网络**的静力松弛解（残差 9.1e-08，完全平衡）测得中心场
`sigma_xx = +155.59 Pa`、`sigma_zz = -313.50 Pa`、主轴比 `-2.0149`，与 `-3` 差 32.84%，
于是判 **FAIL（结构性）**，并把主因归给「中心力格点的 Zener 各向异性 2.33」。归因当时**没有基准可对**：
用各向同性基准去判一个各向异性介质，本质上是「基准选错」与「求解器错」不可区分。
本文补上那个缺失的基准。

**算例参数（manifest `tensordem-dem3d-brazilian-v1 / brazil_elastic_field`）**

| 参数 | 值 | 说明 |
|---|---|---|
| 直径 D / 厚度 t | 0.30 m / 0.06 m | `cylinder_xz`，层数 3 |
| 压板载荷 P | 3.37231 N | 静力松弛终值（m2543 §3） |
| 分裂应力 `2P/(πDt)` | 119.27107 Pa | 解析恒等式，程序化计算 |
| 格点 Born 弹性常数 | C11=433333, C12=233333, C44=233333 Pa | Cauchy 固体 C12=C44 |
| Zener 各向异性 | 2.33333 | `C44/((C11-C12)/2)` |
| 中心窗口 | `|x|,|z| <= D/10 = 0.03 m` | **取自 DEM 代码**：`scripts/benchmark_dem3d_brazilian.py::centre_field` |
| 晶格间距 | 0.02 m（15 个颗粒跨径） | 窗口 = 1.5 个间距 |
| 等各向同性当量 | E=270 kPa, ν=0.35 | m2543 §5 |
| DEM 静力中心场 | `σ_xx=155.58995`, `σ_zz=-313.49622`, ratio `-2.0149` | 被复核对象 |

## 2. 怎么做的

**方法：Q4 双线性四边形平面应力有限元（`src/tensordem/anisotropic_continuum.py`）**

1. **本构降维。** 格点常数是 3-D 立方常数，试件在 y 向有自由面 → 广义平面应力
   `σ_yy=0` ⇒ `ε_yy = -(C12/C11)(ε_xx+ε_zz)`，于是
   `C~11 = C11 - C12²/C11 = 307692.24`、`C~12 = C12 - C12²/C11 = 107692.24`、`C~66 = C44 = 233333`
   （面内剪切不被降维触及）。面内 Zener 仍是 2.33333。
2. **网格。** 以方形栅格裁圆的"阶梯"网格（元素按**形心**在圆内入选），
   因此 `z=+R` 的栅格点恰好落在试件顶点并被两个单元共用 —— **加载直径精确等于 D**，
   与 `2P/(πDt)` 的比较才成立（若按"四角点全在圆内"入选，该顶点会退化成孤立悬挂节点）。
3. **边界条件（精确的对称条件，不引入伪反力）。** `u_x=0` 加在 `x=0` 整列、`u_z=0` 加在 `z=0` 整行；
   对 4 次面内对称材料 + 对称载荷这是精确约束，故约束反力必须为 0（实测 |ΣRx|/P ~ 1e-14，作为自检）。
4. **加载。** 默认点载荷：`(0,+R)` 加 `-P ẑ`、`(0,-R)` 加 `+P ẑ`；另备有限接触弧（patch）模式用于敏感性。
5. **取值。** 单元形心应力 `σ = D·B·u`；
   - **中心点** = 与中心节点相邻 4 个单元的面积平均；
   - **窗口值** = `|x|,|z| <= 0.03 m` 内的面积平均 —— 与 DEM 的 `centre_field` 窗口一致。
6. **验证链（三级，缺一不可）**
   - 一级：单刚**仿射补丁测试**（线性位移场必须精确给出 `σ=Dε`）；
   - 二级：各向同性试件对 Hondros 解析解（FE 机器本身的精度）；
   - 三级：各向异性试件对 DEM 静力解（本单的结论）。
   另外做 h 加密（n_radial = 20/30/40）、窗口宽度扫描、Zener 扫描与反演、接触弧扫描。

**工具链**：numpy 2.4 + scipy 1.16（`spsolve` 稀疏求解，10370 dof 约 5 s）、matplotlib（场云图）。
复跑：

```bash
PYTHONPATH=src python3 scripts/brazilian_anisotropic_reference.py          # ~96 s，写 artifacts/brazilian_anisotropic/
PYTHONPATH=src:scripts python3 -m pytest tests/test_anisotropic_continuum.py -q   # 14 passed
```

## 5. 注意点（坑与局限）

1. **加载轴会被写错。** 第一版把载荷加在 x 轴，得到"中心压 -3σ_t + 拉 +σ_t"，看起来完全像
   ×3 的错解；实际是巴西试件的**拉伸方向垂直于加载轴**：`σ_axial = -6P/(πDt) = -3σ_t`，
   `σ_transverse = +2P/(πDt) = +σ_t`。DEM 用 z 加载（`top_z/bottom_z`），故本模块默认 `load_axis="z"`。
   任何跨仓对比必须先对齐"谁是加载轴"，否则会把正确的场读成错 3 倍。
2. **元素入选判据决定加载直径。** 按"四角点在圆内"入选，顶点 `(0,R)` 会成为无单元的孤立节点，
   加载直径就小于 D，`2P/(πDt)` 的基准随之失效；必须按**形心**入选。
3. **等参 Jacobian 不是 1。** ξ,η∈[-1,1] 映射单位正方形时 det(J)=1/4，测试里若断言 det=1 会假红。
4. **窗口定义必须抄代码，不能凭记忆。** m2543 正文写「±1.5 个晶格间距」，代码里其实是
   `|x|,|z| <= 0.1 D` 的**方框**（=0.03 m，恰好 1.5 个间距），且是**逐颗粒平均值**而非面积平均。
   本文按方框面积平均对齐；窗口从 0 变到 0.03 本身就让比值动 4%（见 3.4），这一项不能忽略。
5. **反力自检比"看起来对"可靠。** 对称约束下的约束反力必须为 0；实测 ~1e-14，一旦模型/网格不对称
   就会立刻非零。这是最便宜的正确性守卫。
6. **局限（必须说清）**：
   - 本基准的刚度张量**来自格点自身**（Born/Affine 均匀化），所以它证的是
     **"格点是否收敛到自己的等效介质"**，**不是**物理验证——不涉及冰的真实模量/强度；
   - 各向异性连续体中心场无闭式解（Lekhnitskii 点力解给出的是无限板场，与本试件边界不同），
     故本文的"基准"是**独立离散的数值连续体**，不是解析解；其可信度由 §3.1 的解析验证（<0.1%）承载；
   - 残余 `+10.1%/-9.6%` 未在本单分解到"晶格间距 vs 逐颗粒 virial 体元 vs 键网近场"，
     要分解需要重跑 DEM 加密（本机 load15 ≥ 100，容量纪律下未做）。
7. **别把结论读成"求解器变好了"。** 同一份 DEM 输出没变；变的是**基准**。这类"改基准让误差变小"
   的操作极易变成 benchmark shopping，所以本文把三个基准并排列出（图 3），并保留"对 Hondros 仍是 32.84%"。

## 6. 误差判定（逐项显式回答"是否 <3%"）

| 关键量 | 基准 | 误差/偏离 | 是否 <3% |
|---|---|---|---|
| 单刚仿射补丁（σ=Dε） | 解析恒等式 | <1e-14 | 是 |
| 平面应力降维 vs 各向同性解析 | 解析 | ~2e-16 | 是 |
| FE 各向同性 σ_xx/σ_t | +1 | -0.077%（n=40） | 是 |
| FE 各向同性 σ_zz/σ_t | -3 | -0.058% | 是 |
| FE 各向同性主轴比 | -3 | +0.019% | 是 |
| FE 对称约束反力 | 0 | <1e-13·P | 是 |
| 各向异性网格 h 敏感性(窗口比) | n=40 值 | 0.004%（20→40） | 是 |
| **DEM 主轴比 vs 各向异性连续体（同窗口）** | -2.02443 | **+0.47%** | **是** |
| DEM σ_xx vs 各向异性连续体（同窗口） | 1.18446σ_t | **+10.14%** | **否**（但在 manifest 15% 内） |
| DEM σ_zz vs 各向异性连续体（同窗口） | -2.39785σ_t | **-9.62%** | **否**（但在 15% 内） |
| DEM 主轴比 vs Hondros 各向同性 | -3 | +32.84% | 否（= m2543 的 FAIL 数） |
| 反演 Zener vs 格点 Zener | 2.3333 | +1.4% | 是 |

**结论（honest verdict）**：m2543 的 `FAIL` 是**基准选择失配**，不是求解器缺陷。
在"格点自己的各向异性等效连续体 + 同一中心窗口"这个正确基准下，**主轴比误差 0.47%**，
两个应力分量 +10.1% / -9.6%，即**落在 manifest 的 15% 容差内**（但不满足 3%）。
各向异性解释了缺口的 108%，窗口平均 -9%，DEM 离散残差仅 +1%。
残留的 ~10% 分量误差**尚未定界**，需要用 DEM 加密（18→30 颗粒跨径）区分"离散"与"体元约定"，
本单未做（容量纪律）。
