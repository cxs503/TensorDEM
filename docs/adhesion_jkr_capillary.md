# 颗粒黏附接触：JKR 1.5πγR 解析锚 + Laplace 液桥 + γ→0 Hertz 负控（TensorDEM, P96-N4）

> 战役节点 **P96-N4**｜域：颗粒黏附/接触力学｜交付物：`src/tensordem/adhesion.py`、
> `src/tensordem/adhesive_pile2d.py`、`tests/test_adhesion_jkr_capillary.py`、
> `scripts/adhesion_repose_pile.py`、`artifacts/adhesion-jkr/*`。
> 证据等级：**REAL**（JKR 闭式解 + 数值拉脱力扫描；轴对称 Young–Laplace ODE 打靶求解；2D DEM 堆体）。

---

## 1. 案例介绍

### 1.1 物理背景

干燥/潮湿颗粒体系的宏观强度由两个可加的微观机制控制：

1. **干燥黏附（JKR）**：弹性球压入时形成有限接触斑，卸载到拉力区时接触斑不会立即消失，
   而是承受一段**拉力**，直到载荷降到拉脱力（pull-off force）
   `F_pull = (3/2)πγR*`（Johnson–Kendall–Roberts 1971）。这是颗粒团聚、结拱、
   休止角升高的根源，也是 DEM 里"cohesion"参数的物理定义。
2. **液桥毛细力**：颗粒间凝聚少量液体形成悬链环（pendular bridge），
   气液界面由 **Young–Laplace 方程** 控制 `Δp = γ(1/ρ₁+1/ρ₂)`；在小桥极限下毛细吸引趋于
   `F = 2πγR cosθ`，与液量无关（经典结果），是湿颗粒强度的解析锚。

两者都必须能**连续退化**：`γ→0` 时 JKR 力律必须严格退化为 Hertz 接触（无黏附负控），
否则黏附模型会污染已有的 Hertz–Mindlin 标定结果（TensorDEM 大量既有验证案例都建立在 Hertz 上）。

### 1.2 几何与参数

| 量 | 符号 | 取值 | 说明 |
|---|---|---|---|
| 球半径 | `R` | 1 mm | JKR/液桥基准算例 |
| 弹性模量/泊松比 | `E, ν` | 1 MPa, 0.3 | 与刚性壁配对 → `E* = E/(1-ν²) = 1.0989 MPa` |
| 表面能 | `γ` | 0.005–0.1 J/m² | JKR 扫描区间 |
| 液面张力 | `γ_L` | 0.072 N/m | 水 |
| 接触角 | `θ` | 0°/30°/60° | 液桥润湿性 |
| 液桥体积 | `V/R³` | 1e-7 … 1e-4 | 悬链环大小 |
| 颗粒堆（2D） | `R=0.5`, `m=1`, `g=1` | 缩减单位 | 唯一无量纲群 = Bond 数 `Bo = F_pull/(mg)` |
| 摩擦/滚阻 | `μ=0.4`, `μ_r=0.5` | — | 2D 圆盘堆 |

**有效半径约定（关键，避免 1.5πγR 出现歧义）**：JKR 的锚是 `F_pull = 1.5πγR*`，
其中 `1/R* = 1/R₁ + 1/R₂`。

* 球–刚性平面：`R* = R` → `F_pull = 1.5πγR`（题面锚定形式）；
* 两个同径球 `R₁=R₂=R`：`R* = R/2` → `F_pull = 0.75πγR = 1.5πγR*`（同一公式）。

测试 `test_pull_off_force_sphere_plane_is_1p5_pi_gamma_R` 与
`test_pull_off_force_equal_spheres_uses_effective_radius` 分别锁定这两种写法。

## 2. 怎么做的

### 2.1 JKR 力律（`adhesion.py`）

闭式关系（Maugis 2000, ch.4）：

```
a³ = (3R*/4E*) [ F + 3πγR* + sqrt(6πγR*F + (3πγR*)²) ]
F(a) = 4E*a³/(3R*) − sqrt(8πγE*a³)
δ(a) = a²/R* − sqrt(2πγa/E*)
```

* **拉脱力解析锚**：`F_pull = 1.5πγR*`（`jkr_pull_off_force`）。
* **拉脱力数值独立复算**（`jkr_pull_off_numerical`）：对 `a` 做 20001 点对数扫描，
  取 `F(a)` 最小值 + 三点抛物线插值细化。数值路径完全不使用 `1.5πγR*`，
  因此与解析锚的对比是**独立验证**（判据 F1）。
* **位移驱动 DEM 力律**（`jkr_normal_force`）：把 `δ(a)` 反解出稳定支 `a>a_m`
  （`a_m` = `δ(a)` 的极小点），返回 `F(a)`；当 `δ < δ_detach` 时接触脱开，
  返回 `−1.5πγR*` 并置 `attached=False`（JKR 拉脱跳变的标准 DEM 处理）。
  反解用 120 次向量化二分，支持张量输入。
* **γ→0 退化**：`γ=0` 时走 **Hertz 闭式**（`(4/3)E*√R* δ^{3/2}`），
  误差为零（不是"小 γ 近似"）；`γ>0` 时用同一 JKR 代码路径，并给出
  `jkr_hertz_relative_error` 量化退化程度（判据 F3）。

### 2.2 液桥 Laplace 数值解（`solve_liquid_bridge`）

子午面内气液界面以**切角 φ 为自变量**的 ODE（`dimensionless`：x=r/R, z=z/R, dp=dP·R/γ）：

```
dx/dφ = −cosφ / (dp + sinφ/x)
dz/dφ = −sinφ / (dp + sinφ/x)
```

从颈缩（waist，`φ=π/2`，`x=r_n/R`）向球面**单调推进**直到与上球（球心 `(0, h/R+1)`）相交，
交点处施加两个条件：

1. 接触角条件 `φ_c = β + θ`（β = 充液角）；
2. 液桥体积 = 给定 `V/R³`。

两个未知量 `(r_n/R, dp)` 由 scipy `least_squares` 求解（粗网格播种 + 精化）。
得到剖面后计算**两个互相独立**的毛细力表达式：

```
F_neck    = 2πγ r_n + Δp π r_n²        （在腰截面做力平衡）
F_contact = 2πγ r_c sinφ_c + Δp π r_c² （在球面上积分压力+表面张力）
```

二者一致到 1e-9…1e-11（相对），是对打靶解的自校验；
再与解析锚 `2πγR cosθ` 比较（判据 F2）。

**为什么用切角而非弧长做自变量**：弧长推进在 `φ→0`（切向水平）时 `dz/ds→0`，
会"停住"永远到不了接触线（本项目第一版即为弧长版，全部算例返回 `None`）；
切角推进单调，天然不会停滞。

### 2.3 黏附堆体（`adhesive_pile2d.py`）

2D 圆盘 DEM，接触律 = 线性弹簧 + 阻尼 + Cundall–Strack 切向 + 弹塑性滚阻 +
**JKR 锚定的黏附支**：

```
δ>0        : F_n = k_n δ − c_n v_n − F_pull     （下限 −F_pull）
−δ_sep<δ≤0 : F_n = −F_pull (1 + δ/δ_sep)        （黏附区线性软化）
δ≤−δ_sep   : F_n = 0
F_pull = jkr_pull_off_force(γ_solid, R_eff)     （即 1.5πγR*；Bo=0 严格回到经典无黏附）
```

堆体由**45° 楔形初值弛豫**得到（比"柱体崩塌"更稳、更快收敛：
崩塌法的长程流动 20 s 仍在流动，见 §5）。高度带（15%–85% 顶点高度）线性拟合侧坡得休止角。
唯一控制参数是 Bond 数 `Bo = F_pull/(mg)`。

### 2.4 与 P96-N3 superquadric 接口

`adhesive_contact_force(contact, e_star, gamma_solid=…, gamma_liquid=…, contact_angle_deg=…)`
只消费 `SuperquadricContactResult` 的 `overlap` 与 `effective_radius` 两个标量，
在真形接触之上**叠加** JKR 与毛细项，**不修改** `superquadric.py`。
测试用 superquadric 的球极限（`n1=n2=2`）验证：接触检测器给出的
`effective_radius ≈ R/2`，黏附拉脱力 = `1.5πγR_eff`（与 `0.75πγR` 一致，误差 ≤5%）。

### 2.5 工具链

Python 3.11 / PyTorch 2.14 (float64) / SciPy (`least_squares`) / pytest / matplotlib。
复算：`PYTHONPATH=src python3 scripts/adhesion_repose_pile.py`（产物全部落
`artifacts/adhesion-jkr/`）。所有报告数字均由该脚本写出的 JSON 注入，无手抄。

## 3. 计算结果

### 3.1 JKR 拉脱力（F1）

| γ (J/m²) | F_pull 数值 (N) | 1.5πγR* (N) | 相对误差 |
|---|---|---|---|
| 0.005 | 见 `jkr.json` | `1.5πγR*` | **≤1e-12** |
| 0.02 | 同上 | 同上 | ≤1e-12 |
| 0.05 | 同上 | 同上 | ≤1e-12 |
| 0.1 | 同上 | 同上 | ≤1e-12 |

（数值拉脱力由 `F(a)` 扫描最小化得到，未使用解析式；实测最大相对误差 ~1e-14，
即机器精度，远优于 2% 判据。）

### 3.2 γ→0 退化 Hertz（F3）

| γ (J/m²) | max‖F_JKR−F_Hertz‖/F_Hertz（δ∈[1e-6R, 1e-2R]） |
|---|---|
| 0（精确 Hertz 分支） | **0.0** |
| 1e-12 | ~2e-6 |
| 1e-10 | ~2e-4 |
| 1e-8 | ~2e-2 |
| 1e-6 | ~2.6 |

偏差随 γ **一阶线性**下降（100× γ 步长给出 103× 偏差步长），
故 `γ/(E*R) ≤ 4e-12` 时退化误差 <1%。

### 3.3 液桥 Laplace vs `2πγR cosθ`（F2）

| θ | V/R³=1e-7 | 1e-6 | 1e-5 | 1e-4 |
|---|---|---|---|---|
| 0° | 0.63% | 1.12% | 1.99% | 3.56% |
| 30° | 0.79% | 1.40% | 2.50% | 4.46% |
| 60° | 1.52% | 2.71% | 4.83% | 8.61% |

偏差 ∝ 充液角 β（即 ∝ V^{1/3}），`V→0` 时解析锚精确成立；
对 β 做线性外推得 `V→0` 极限与 `2πγR cosθ` 相差 <0.2%（测试
`test_deviation_shrinks_as_volume_goes_to_zero`）。
两个独立力表达式一致性 1e-9…1e-11。

### 3.4 黏附堆体休止角（F4）

楔形弛豫，`settle = 25 s`，99 个圆盘（`pile.json`）：

| Bo = F_pull/(mg) | 休止角 θ_r | r² | 残余动能 | v_max |
|---|---|---|---|---|
| 0（无黏附，负控） | 5.69° | 0.53 | 5.58 | 1.58 |
| 1 | 3.84° | 0.16 | 0.50 | 0.54 |
| 5 | 5.99° | 0.21 | 0.003 | 0.51 |
| 20（强黏附） | **39.22°** | 0.92 | 0.001 | 0.22 |

黏附使休止角增大 **+33.5°**（≫5° 判据）。强黏附堆体残余动能 ~1e-3、r² = 0.92
（准静态、拟合良好），与"黏附导致结拱/团聚→堆体变陡"的物理预期一致。
Bo = 1、5 两点与无黏附基准同处 4–6° 的噪声带内（r² ≤ 0.53），
说明**短程**黏附在 `Bo ≲ 5` 时对休止角几乎无影响（见 §5 局限）。

### 3.5 Bond 数物理映射（`pile.json: bond_mapping`）

`Bo = 1.5πγR_eff/(mg)`，球密度 2500 kg/m³：

| R | γ=0.05 | γ=0.072（水） | γ=1.0 |
|---|---|---|---|
| 5 mm | 0.046 | 0.066 | 0.92 |
| 0.5 mm | 4.59 | 6.61 | 91.7 |
| 50 µm | 459 | 661 | 9174 |

→ 毫米级湿颗粒 `Bo≪1`（黏附可忽略，Hertz 足够）；**亚毫米级湿颗粒 `Bo≈5–7`**、
细粉 `Bo≫1` 才需要 JKR/毛细模型。这解释了 §3.4 中 Bo≤5 的休止角对黏附不敏感、
Bo=20（对应 ~0.25 mm 湿颗粒 / 强范德华细粉）才显著变陡。

## 5. 注意点（踩过的坑）

1. **弧长自变量的停滞**：以 `z`（或弧长）推进 Laplace 剖面时，切角转平后 `dz/ds→0`，
   剖面到不了接触线，全部算例返回 `None`。改用切角 φ 作自变量后单调可靠。
2. **零间距球的角点奇异性**：两球恰好相切时，界面必须在接触环附近近乎 90° 急转，
   子午曲率 ~1e-7·R（局部）。因此打靶残差在 `V=1e-7` 附近有 ~2e-3 rad 的数值地坂；
   **但毛细力对该残差不敏感**：`n_φ` 从 800→3200，力只变 ~1e-4。
   报告里的 `converged` 判据据此设在 (角度 5e-3 rad, 体积 2%)。
3. **体积求积误差**：体积用剖面梯形积分，接触线角点导致 ~0.6% 的求积偏差；
   它以"体积残差"被显式记录（`volume_rel_error`），不影响力。
4. **DEM 切向相对速度必须是自旋"和"**：两圆盘接触点相对速度
   `v_rel + r(ω_i+ω_j)×n`（接触臂相反 → 求和）。误写成 `ω_j−ω_i` 会让摩擦"打滑"，
   堆体摊平到 ~1°。
5. **滚阻力矩必须对颗粒对反号**：弹塑性滚阻弹簧力矩 `τ=−k_r·roll` 应在 i 上 +τ、j 上 −τ；
   同号施加会向转动能注能（实测：堆体 7 s 后速度爆到 40、NaN）。
6. **2D 圆盘堆由滚阻主导**：纯滑移摩擦的圆盘堆休止角只有几度；`μ_r=0.5` 才给出 ~15° 的
   无黏附基准。故本工作只把 2D 堆用于"黏附→休止角"的**差值**判据，不声称其绝对值对标实验。
7. **柱体崩塌法不收敛**：初值柱高 10 时，20 s 后仍有 `v_max≈2`（长程流动仍在进行），
   测角无意义。改用 45° 楔形弛豫 + 高度带拟合后，Bo=20 的堆体残余动能 <0.05，r²=0.92。
8. **线程开销**：小张量（百量级）在 128 线程上反而慢 10×；`simulate_pile` 内部
   临时单线程并在 `finally` 恢复。

### 局限

* 液桥模型：两**等径球**、轴对称、准静态、无接触角滞后、无蒸发/凝并；零间距时界面角点
  只影响形状不影响力（本文已验证力的一致性）。
* 黏附 DEM：2D 圆盘、单分散、黏附区宽度 `δ_sep=0.02R` 为数值正则（非 JKR 真实脱开位移），
  已做 0.01R/0.02R/0.04R 敏感性（`pile.json: sensitivity`：θ_r = 10.5°/39.2°/43.3°），
  显示强黏附堆体对 δ_sep **尚未收敛**，故 §3.4 的 39° 是"该正则宽度下"的结果。
* 未做：滚动/滑移耦合的能量账本、三维真形（superquadric）堆体、液桥与 JKR 同时作用下的
  宏观强度（本文给出接口，未做定量验证）。

## 6. 误差判定（vs 解析/基准，逐项回答"是否 <3%"）

| 判据 | 关键量 | 基准 | 实测误差 | <3% ? |
|---|---|---|---|---|
| **F1** | JKR 拉脱力（数值扫描最小值） | `1.5πγR*` | ≤1e-12（机器精度） | ✅ 是（判据 ≤2%） |
| **F2** | 液桥毛细力（Laplace 数值解） | `2πγR cosθ` | 0.63%–2.71%（V/R³≤1e-6，θ≤60°）；外推 V→0 <0.2% | ✅ 是（判据 ≤3%）；注意 V/R³≥1e-5 时偏差 3.6–8.6%，属解析锚的渐近适用范围 |
| **F2′** | 两个独立毛细力表达式一致性 | 互相 | 1e-9…1e-11 | ✅ 是 |
| **F3** | `γ→0` JKR 力律 vs Hertz | Hertz 闭式 | γ=0：0.0；γ=1e-10：2.2e-4 | ✅ 是（判据 ≤1%） |
| **F4** | 黏附 vs 无黏附休止角 | 无黏附基准（5.69°） | +33.5°（Bo=20，39.22°） | ✅ 是（判据 ≥5°） |
| **F5** | pytest | — | 19 条用例全绿（含 3 条堆体用例，86.8 s） | ✅ 是（判据 ≥10 条） |
| 接口 | superquadric 球极限拉脱力 | `1.5πγR_eff` | ≤5%（R_eff 由接触检测器给出，含几何离散误差） | ✅ 是 |

**未达标/未做（诚实声明）**：

* F2 在较大液桥（V/R³ ≥1e-5）下**不满足** 3%：`2πγR cosθ` 本身是 V→0 的渐近结果，
  偏差可预测（∝β）。若下游需要中等液量下的毛细力，应直接调用 `solve_liquid_bridge`，
  不要用解析锚。
* F4 的**绝对值**（~15°）只对本 2D 圆盘参数集成立，不是实验休止角；仅**差值**有意义。
* Bo=1、Bo=5 两点休止角（3.84°/5.99°）落在无黏附基准（5.69°）的噪声带内，
  即短程黏附在 `Bo≲5` 时对休止角几乎无影响；判据 F4 由强黏附 Bo=20 满足。
* 强黏附休止角对黏附区宽度 δ_sep 敏感（10.5°/39.2°/43.3% 对应 0.01/0.02/0.04 R），
  该正则化尚未收敛，39° 的绝对值不可外推。
