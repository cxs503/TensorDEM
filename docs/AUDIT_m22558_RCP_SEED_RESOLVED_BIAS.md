# AUDIT m22558 · RCP 时间偏差门：种子分辨裁决

锚点：`CASE-DEM-RCP-PACKING-FRACTION`（算例池·随机密堆体积分数 RCP）。本审计只处理上一波留下的**一笔具体欠账**：m21401 把无摩擦刚性端（`mu=0, k_n=64000`）的时间偏差门判为边际 FAIL，理由是「|Δ| 略超阈，但与种子噪声不可分离」。那是**统计功效**问题，不是物理问题。

## 1 欠账的原文与本次要做的判定

m21401 的判据是单一的标量比较：`|Δ| < 5e-4`，其中 `Δ = φ(dt/2) − φ(dt)` 是两组**种子均值**之差。点估计与固定阈比较丢掉了误差信息：当 `|Δ| ≈ 阈值` 而种子标准差同量级时，既不能判通过，也不能判不通过。本审计把判据升级为**区间判据**，并补齐使判定成立所需的种子。

预登记规则（在读取新种子前写定）：95% 双侧区间 `[lo, hi]` 与容许带 `[-5e-4, 5e-4]` 的关系

| 关系 | 裁决 | 含义 |
|---|---|---|
| 区间完全落在带内 | `CONVERGED` | 偏差**已被认证**小于阈值 |
| 区间完全落在带外 | `BIASED` | 偏差**已被认证**大于阈值 |
| 区间跨越带边界 | `UNDECIDABLE` | 不下判断（不通过、也不失败） |

`certified` 只对 `resolved_from=interval` 的 `CONVERGED` 为真——只有点估计（两侧各一个种子）的档即使点估计在带内也不认证。

## 6 注意点与局限

1. 单侧只有 1 个种子时，误差按对侧标准差合并估计（`error_model=pooled_one_sided`，df = n粗+n细−2），这是**工程近似**而非严格 Welch；该档即使裁决为 `CONVERGED` 也不认证。
2. `seeds_needed_for_tol` 假设两档共享同一散布 σ（该算例的设计假设：dt 减半不应改变种子散布）；若该假设不成立，所需种子数会变。
3. `UNDECIDABLE` 不是失败也不是通过：它表示当前种子预算下该档的偏差与阈值不可分离。
4. 各档之间不正交：种子、盒宽、投放序列共享，故本表逐档裁决，不做跨档合并检验（合并会引入伪独立）。
5. 本审计不触及刚度外推阶次区间（见 m21145）、稳态判据（m17063）、φ 定义（m18395）。

时间偏差门的判定（本次审计的对象）不是相对误差，而是绝对偏差闸：`|Δ| < 5e-4`（约为 φ_ref 的 0.08%）。表中 `裁决` 一列即为该项的显式回答；凡 `UNDECIDABLE` 者一律不计为通过。
