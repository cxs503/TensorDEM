# AUDIT — RCP 沉积算例的「稳态」与「等静性」是否被证实

> Anchor: `CASE-DEM-RCP-PACKING-FRACTION`（feature_ledger, status=open）；仓 TensorDEM。
> 由 `benchmarks/case_rcp_deposition/steady_state_audit.py` 生成，本文所有数字由该脚本
> 从 `benchmarks/case_rcp_deposition/runs/` 程序化注入（run-set sha256 `24ce086d7d22d4f0…`，
> 生产跑次 6 个、刚度梯级 7 个）。**不新起任何仿真**：只用已落盘的
> `.npz` 末态位置/速度与 `history`。

## ① 案例介绍

随机密堆（RCP）验收词是「**落下堆积体稳态孔隙率**」（10000 球，无摩擦/低摩擦两档，
φ ∈ [0.62, 0.66]）。前序波次已经把 φ 的生产量做齐（μ=0 与 μ=0.1 各 3 种子），
但「稳态」两字只由动能阈值撑住，且报告里的体相配位数 `Z` 从未与任何计数基准对照。
本审计补的正是这两个**证据缺口**（不是重跑，而是对已有末态的独立复核）：

| 缺口 | 现证据 | 本审计给的证据 |
|---|---|---|
| 稳态 | `ke/(N m g d) < settle_tol` 持稳 4 个时间单位即置 `settled=True` | φ(t) 平台起点/长度/峰峰值 |
| 静止力平衡 | 无 | 由末态位置重算接触力，给出不平衡力比 |
| `Z` 的判读 | 只报数（6.37 / 5.81） | 与 Maxwell 等静值 $z_c=2d=6$ / $z_c=d+1=4$ 对照 + 接触阈值带 |

装置（与生产波一致）：单分散球 d=1、ρ=1、g=1，方形底周期胞 + z=0 摩擦地板，
线性弹簧-黏壶法向（e=0.1，$k_t=k_n/2$），速度 Verlet + Cundall-Strack 切向，$dt=t_c/20$，
N=10000，体相统计带取 $[2.5d,\ h_{surf}-2.5d]$。

## ② 怎么做的

1. **新模块** `src/tensordem/packing_steady_state.py`：只吃位置/速度，不碰求解器对象。
   `contact_network` 用 3×3 侧向镜像云复现周期边界接触（朴素 cKDTree 会漏掉跨边界接触，
   实测每粒子少计 ~0.3 个接触，z 从 6.03 修正到 6.371，**与求解器自报值逐位一致**——
   这本身就是一次实现交叉验证）；`static_equilibrium` 由末态位置重算法向弹性力与重力残差；
   `plateau_onset` 定位 φ(t) 的平台起点；`coordination_vs_tolerance` 把接触判定阈值变成带宽。
2. **等静性基准来自计数本身，不引外部数字**：无摩擦球每个接触提供 1 个法向约束、
   $3N$ 个平动自由度、无力矩约束 ⇒ $N_c=dN$ ⇒ $z_c=2d=6$；有摩擦（含滚动阻力）
   每接触 3 个约束、$6N$ 个自由度 ⇒ $N_c=2dN/3$ ⇒ $z_c=4d/3=d+1=4$。两式由
   `isostatic_coordination()` 实现，作为 `Z` 的对照值。
3. **判据先在脚本里写成门**（G20–G25），再跑；容差取算例已有系统误差门的同一量级
   （0.002 对应刚度/时间步门；残差门 2% 对应接触力量级）。诚实声明：本单在写门之前
   已对同一批工件做过探索性读数，故这些门是**描述性**的，不是盲预注册。
4. 工具链：`runs/*.npz + *.json` → 本脚本 → `runs/steady_state_audit.json` + 本文 + 图。

## ⑤ 注意点（坑、局限、适用范围）

1. **周期边界接触必须走镜像云**：naive `cKDTree` 只看见盒内欧氏距离，跨边界接触全丢，
   实测 z 偏低 0.34（6.03 vs 6.37），残差还会被系统性夸大。修正后与求解器自报 `Z` 逐位一致。
2. **摩擦档的残差不能当动力学误差读**：切向 Cundall-Strack 历史未落盘，本审计无法重算切向力；
   因此有摩擦档只做「是否落在 Coulomb 上界内」的检验，量级与 $\mu z\langle F_n\rangle$ 相符即说明
   残差来源是被有意省略的摩擦分支，而不是床层还在乱动。
3. **z 的阈值敏感度是被低估的系统误差**：软床在 $k_n=4000$ 的平均重叠 ~1e-3 d，
   边际接触的间隙同量级，硬阈值（overlap>0）成批丢接触；阈值放到 1e-3 d，z 移动 0.120–0.158。
   故等静性判读必须连阈值带一起报：超出量 ~0.35 仍大于带宽（G24 PASS），但单个 `Z=6.37` 的
   有效精度只有 ±0.15，把它当精确数引用会高估精度约 3 倍。
4. **刚度梯级上的 z 不能当收敛序列用**：$k_n$ 越大 $t_c$ 越小，而停止判据是「$t_c$ 归一化 dt +
   固定 settle 容差」，物理时间并不相等；硬阈值下最硬一级的 z 掉到 5.408（低于 $z_c=6$），
   同一档的少接触粒子比例升到 0.032，即这是**丢接触**的伪像，不是「欠堵塞」。
5. 适用范围：单分散、周期侧壁；生产档两档摩擦，另有 N=2000 的四档摩擦扫描（μ=0/0.1/0.3/0.5，唯一把 μ 单独变化的跑次组）。多分散与真实容器壁效应不在本审计内。

## ⑥ 误差判定（逐项 vs 基准，显式回答是否 <3%）

| 量 | 本审计 | 基准 | 偏差 | <3%？ |
|---|---|---|---|---|
| φ 稳态峰峰值（最差跑次） | 1.86e-03 | 平台容差 0.002 | 内 | 不适用（噪声量级，非与文献比） |
| 无摩擦档不平衡力/⟨F_n⟩（最大） | 0.0102 | 门 0.02 | 通过 | 是（该项为数值判据，无文献基准） |
| z（μ=0, 硬阈值） | 6.33–6.37 | $z_c=2d=6$ | +0.34…+0.37（阈值带 0.120–0.144） | 可分辨（超出量 > 带宽），但精度只到 ±0.15，非 3% 类误差 |
| z（μ=0.1, 硬阈值） | 5.81–5.84 | $z_c=d+1=4$（无限摩擦上界） | +1.81…+1.84 | 不适用：μ=0.1 远离无限摩擦极限 |
| z 随 μ 的下降（N=2000 四档） | 6.281 → 4.890（Δ=1.392，阈值带 ≤ 0.179） | 单调下降且向 4 收敛 | 一致（G26） | 是：Δ 远大于阈值带 |
| 摩擦序（z₀ − z₀.₁）在阈值带内 | ≥ 0.512 | 符号须为正 | 一致 | 是 |

**结论**：

* 「稳态」有独立证据了：6 个生产跑次全部在 φ(t) 上存在长度 7.0–11.0 个时间单位、峰峰值 ≤ 1.86e-03 的平台（G20 PASS）——`settled` 标志不再是唯一凭据。
* 无摩擦档是真正的静止力平衡：不平衡力中位数/⟨F_n⟩ = 0.0081–0.0102（门 0.02，G21 PASS）。
* 有摩擦档的残差（0.12–0.13 ⟨F_n⟩）落在 Coulomb 上界 μz=0.581 之内且与之同量级（G22 PASS）：残差来源是被有意省略的切向分支，不是床层还在乱动。
* 摩擦对配位数的排序在接触阈值带内稳健（最小正差 0.512，G23 PASS）。
* 等静性判读**可分辨**：无摩擦生产档 z 超出 $z_c=2d=6$ 的量 +0.341…+0.371，大于阈值带造成的移动（0.120–0.158），G24 PASS；即 `Z=6.33–6.37 > 6` 是实质结论，而引用它时必须同时给出阈值带（±0.12）。
* **honest FAIL**：刚度梯级上的 z 不是收敛序列（G25 FAIL）——硬阈值下最硬一级出现 z=5.408 < $z_c$=6，且少接触粒子比例同升。
  这不推翻 φ 的刚度外推（那是 φ 量的收敛），但**禁止**用梯级去读 z 的收敛。欠账留给下一单，
  需要的不是新算例，而是两点：(a) 末态额外落盘切向接触历史（可算真实力残差，闭合 G22 的
  残余不确定性）；(b) 梯级跑次改用相同*物理*沉降时间，z 计数带阈值带报告。
