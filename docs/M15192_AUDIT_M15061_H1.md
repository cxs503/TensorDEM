## ⑤ 注意点 / 坑

1. **`artifacts/` 被合并门禁滤除**：交付"有工件"与"工件在 main 里"是两件事；本单必须复跑才拿到可引用的树内工件。凡以 artifacts/ 为证据的 L3/L4 声明都要复跑一次再判。
2. **改内核后未重跑工件**：C3 energy_residual 9.75× 偏差纯属"工件停在修前代码"。内核修复越好，越容易漏重跑。
3. **手抄对照表 + PASS 标注脱钩**：`benchmark_ref_vs_got.json` 无生成脚本，出现"超容差仍标 PASS"。建议改为由 `run_validation` 生成（零手抄）。
4. **runner 恒 rc=0**：`main()` 无论 case 通过与否都 return 0，不能进 CI/门禁。
5. **C2 外部锚是"文献带"且无具体出处**：REPOSE_BAND_DEG=(25,40)° 在代码里是常量，docs 只写"文献带、WITHHELD"，未给可核对的文献题录 → 即便跑出角度也只能算 WITHHELD 级对照。
6. **集群队列拥堵**：30+ 作业排队最老 215 min，交付把关键算例押在队列上等于押在不可控资源上（本次两作业 3.5 h 未动）。
7. **C1 是真动力学不是自证**：浮冰从 z=0（50% 浸没）释放、由 DEM 浮力+接触+线性阻力积分到静止，再几何测浸没体积分数与解析 ρ_i/ρ_w 比 —— 不是把解析式抄进 got，非循环论证。

**为什么不是 L4**：L4 = 完整算例 + 误差分析 + 可复现。
(1) 锚点三判据里只有 1 条（浮态）有决定性解析基准且复现达标；
(2) 休止角**零数据**（job 3.5 h 未跑），清空率只有 18% 泳道扫过段、且其"ref=空泳道"被 0.488 直接否证 → 不是"完整算例"；

(4) 平台侧无复算行（`rows=0`，`CLAIMED_NOT_PROVEN`）。
L2/L3 要件齐备且经本单独立复算证实 → **L3**。
