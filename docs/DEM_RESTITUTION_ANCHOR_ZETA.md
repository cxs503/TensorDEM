# 法向接触恢复系数锚：声明的 ζ 到底等于多少恢复系数（polyhedron_floe3d 内核）

锚点：H1-BROKEN-ICE-DEM（in_progress，唯一未清判据 C2 碎冰堆积休止角 honest NOT_RUN）。
本单不开新的重算力算例，而是把 C2 迟迟不静止的**内核层原因**用解析基准量出来：
`ContactLaw.normal_damping` 声明 `c_n = 2 ζ √(k_n m_eff)`，那么**恢复系数 e 不是自由参数**，
它必须服从 Kelvin–Voigt 关系 `e(ζ) = exp(-ζπ/√(1-ζ²))`。此前本仓没有任何表面检查这一条
（`grep -rn restitution src/tensordem/polyhedron_floe3d/` 空），这就是一条**验证欠账**。

## 1 案例（几何/参数，全部程序化生成）
| 项 | 值 |
|---|---|
| 落体 | 正方柱（4 边形挤出），边长 0.10 m，体积 1.0e-3 m³，质量 0.917 kg |
| 密度 | ρ = 917 kg/m³（海冰，`SEA_ICE_DENSITY`） |
| 地面 | 固定半空间 `{z ≥ 0}`，`μ=0.3`，`μ_rolling=0`，`k_t/k_n=0.25` |
| 法向刚度 | k_n = 2.0e5 N/m（与 `case3_repose` 默认一致），ζ 网格 0.05/0.1/0.2/0.4/0.7 |
| 撞击速度 | v_in = 0.5 m/s，落体最低顶点距地面 2 mm（平face 着地） |
| 积分 | 显式，dt = 1e-4 s（另做 2e-4 / 5e-5 / 2.5e-5 收敛列） |
| 观测量 | e = \|v_out\| / v_in（首次脱离墙面那一步的 z 向质心速度） |

## 2 方法与工具链
1. 新增可复现台架 `benchmarks/polyhedron_floe3d_restitution_anchor.py`：建几何 → 平face
   释放 → 逐步积分到"接触过且已脱离" → 量 e；同时记录能量比 `E_end/E_0` 与解析 e。
2. 数值锚定 `tests/test_polyhedron_floe3d_restitution_anchor.py`（6 例，7.8 s 全绿）：
   低阻尼对解析 <3%、dt 收敛、e 随 ζ 单调降、大阻尼偏离量回归锁定、以及
   **"初始穿透=一步能量注入"陷阱**的显式记录。
3. 图 `artifacts/polyhedron_floe3d_restitution/restitution_anchor.png`（左：e(ζ) 实测 vs 解析；
   右：ζ=0.2 的 dt 收敛）。
4. 原始数字 `artifacts/polyhedron_floe3d_restitution/results.json`（零手抄，report 直接读）。

## 3 计算结果
| ζ | e 实测 | e 解析（Kelvin–Voigt） | 相对偏差 | 能量比 E_end/E_0 |
|---|---|---|---|---|
| 0.05 | 0.8607 | 0.8545 | **0.73 %** | 0.7409 |
| 0.10 | 0.7472 | 0.7292 | **2.46 %** | 0.5583 |
| 0.20 | 0.5760 | 0.5266 | **9.37 %** | 0.3317 |
| 0.40 | 0.3677 | 0.2538 | **44.87 %** | 0.1352 |
| 0.70 | 0.2134 | 0.0460 | **364.08 %** | 0.0455 |

时间步收敛（ζ=0.2）：dt=2e-4 → e=0.5590（偏差 6.14 %）；1e-4 → 0.5760（9.37 %）；
5e-5 → 0.5738（8.96 %）；2.5e-5 → 0.5728（8.76 %）。
→ **偏差不是积分误差**：细化 8 倍只动 1.7 %，剩下的是模型差异。

能量账：每个算例 `E_end/E_0 ≈ e²`（0.8607²=0.741 ✓，0.2134²=0.0455 ✓），
即**单接触路径没有凭空造能**，耗散账自洽。

## 4 结论（判定）
* **ζ ≤ 0.1：锚定通过**（≤2.5 %，"<3 %"成立）。
* **ζ = 0.2：9.4 %，超过 3 % 判据**，仍在工程可接受带内（<15 %），但不得声称等价。
* **ζ ≥ 0.4：不成立**（1.4×–4.6×），声明的 ζ 与 Kelvin–Voigt 阻尼比**不能互译**。

根因（代码定位）：`dynamics.py::_apply_wall/_apply_pair` 在 `f_n < 0` 时把法向力**截断为 0**
（无拉伸/无粘着分支），阻尼只在压缩半周做功，回弹半周不耗散 → 回弹比解析值更"活"，
且 ζ 越大偏差越大（解析值指数掉向 0，实测只线性下降）。这是**有意为之的建模选择**
（冰不会粘在船体上），但此前没有任何文档/测试说明"因此 e ≠ e_KV"。

## 5 注意点（踩坑与适用范围）
1. **`principal=True` 的体坐标系不是唯一的**：立方体惯量各向同性，`eigh` 返回任意正交基，
   于是"边长 0.1 的立方体"可能在体坐标系里是**斜放的**（顶点 z 跨 ±0.0707 而非 ±0.05）。
   按 `SIDE/2` 摆位 → 角先着地、初始穿透 **18.7 mm** → 罚函数弹性能一次性释放，
   实测被弹到 **6.63 m/s**（能量比 175–263）。**教训：摆位必须用世界系最低顶点**，
   台架里已改成 `position_z = clearance − min(world_vertices.z)`，并有测试锁定。
   同族陷阱：任何初始重叠都是"一步能量注入"，不是物理结果。
2. 该 e(ζ) 关系是**单接触、平face、无转动**的法向锚；真实碎冰堆（C2）是**多接触+面间错动**，
   堆的静止时间还取决于切向/滚动阻力与几何互锁，不能由本表直接推断休止角。
3. 文献带 25–40° 是 band 不是单点实验值；本仓无原始冰区数据集 → 休止角只能记 WITHHELD。
4. 本单**未做**：不改变接触律（截断是设计选择），不给"ζ=target 反解表"以外的修正；
   C2 休止角仍为 honest NOT_RUN（重算力算例在 128 核控制面 load15≈300 时不递交）。
