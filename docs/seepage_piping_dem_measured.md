# TensorDEM 渗流–管涌起始判据：**实测**链路（返修轮 m14594）

> 本文件取代 `docs/seepage_piping_verification.md` 中 C1/C2/C3/C5 的"measured"数字。
> 复核结论：原报告的 measured 输入是**解析解乘噪声/乘常数**（测试内 `u_meas = u_analytic*(1+0.05 randn)`、
> `i_c_measured = i_c_analytic*1.10`、`k_measured = k*1.15`），属 MOCK，不可作为验证证据。
> 本轮改为真实 DEM 接触网络求解，并按证据分级逐条登记（REAL / WITHHELD）。

## 1. 案例与模型

* 几何：边长 `L` 的随机密排球体周期元胞（`tensordem.bedcoupling.packing.make_random_close_packing`，
  最大重叠 0）沿 z 堆叠 2 层成柱，柱截面 = 周期元胞截面，底部为无摩擦刚性墙，顶部自由面。
* 材料：石英砂 `ρ_s = 2650 kg/m³`，`d = 1 mm`，`ρ_w = 1000 kg/m³`，`μ_w = 1e-3 Pa·s`，质量 600 球 / 3200 dof。
* 接触：法向线性弹簧–阻尼（`k_n = 200 N/m`，阻尼 0.6 临界）+ 切向粘性阻尼，**无库仑摩擦、无转动**
  （静态极限下无摩擦 → 对 `i_c` 是保守下界，见 §5）。
* 流体：准稳态 1-D Ergun 层流。由**实测床层孔隙率**反解表观流速，逐层（层厚 ≥ 2d）用**实测局部孔隙率**
  计算超静水压梯度，再按层内土体体积把压降摊到颗粒上：
  `f_i = (dp/dz)_slab · V_p,i / (1 - n_local)`。因 Ergun 对孔隙率是凸函数，逐层压降不等权平均会偏离
  床层平均，故对局部场做一次整体标定使**施加的整体梯度严格等于请求值**（标定因子入档：
  `homogenisation_factor ≈ 0.77`，即异质孔隙率使逐层压降比均匀场高约 30%，本轮已修正，原框架未计入）。
* 静力解：以总势能（接触 + 重力 + 浮力 + 渗流）为目标函数、解析梯度 `-F` 做 L-BFGS 能量极小化；
  收敛判据 = 单颗粒最大残余力 / 床层水下重（600 球算例 1.9%）。**梯度超过阈值时静态平衡不存在**，
  极小化会把颗粒整体推起（heave），即管涌起始的判据。

## 2. 结果（`artifacts/seepage_piping_dem/chain.json`，git `6bfda4dd`，运行 59 s）

| C2 临界水力梯度 | 静平衡延拓 + 基底反力线性零点 / heave 起始 | `i_c = 0.9269`，Terzaghi `0.9282`，偏差 **0.13 %** | < 15 % | **PASS** |

| 附加：流体动量台账 | 逐层拖曳 vs 超静水压梯度残差 | `3.9e-15` | < 5 % | **PASS** |

实测孔隙率 `n = 0.4431`（成床后），床高 13.48 mm；`γ' = 7192 Pa/m`；Terzaghi `i_c = (G_s-1)(1-n) = 0.928`。

### C2 梯度扫描（基底反力/水下重）

| i | 0.0 | 0.2 | 0.4 | 0.6 | 0.75 | 0.85 | 0.95 |
|---|---|---|---|---|---|---|---|
| base/weight | 0.997 | 0.788 | 0.568 | 0.353 | 0.190 | 0.085 | 0.000（无静平衡）|

线性拟合 `base/weight = 1.0025 - 1.0815 i` → `i_c = 0.9269`；`i = 0.95` 起能量极小化不再收敛、
自由面持续抬升 → heave 起始 `i ≈ 0.95`，与零点、Terzaghi 三者一致。这是**涌现**量：
渗流力由实测孔隙率场经 Ergun 反解得到，`i_c` 由"静态平衡是否还存在"判定，不是把 Terzaghi 公式抄一遍。

## 3. C1 为何 honest FAIL（诊断与改正方向）

平面切割把每个跨切面接触的竖向分量求和除以面积；底部切割应等于其上覆水下重。实测：
近底面（0.85H）仅为自重积分的 24 %，近顶面（0.15H）为其 2.5 倍，剖面比自重积分**更陡**。
同时**边界**量是一致的：`i = 0` 时基底反力/水下重 = 0.997，`i` 增大时线性下降到 0 —— 说明竖向力平衡在
边界上被正确复现，偏差出在**内部竖向应力的空间分配**上。可能原因（按可能性排序）：

1. 床层内竖向力链稀疏且强烈非均匀，13d 宽的柱在 O(1) 个力链尺度上做截面平均，统计代表性不足；
   需要更宽的柱（≥ 20–30d）或对多组随机实现取系综平均（当前只有单实现）。
2. L-BFGS 残余力 1.9 % 在近顶/近底自由面附近被放大（该处参考应力本身很小，百分比敏感）。
3. 无摩擦接触使颗粒可侧向自由重排，竖向应力可被横向重分布（真实砂土由摩擦维持更"柱状"的力链）。

未做的事如实记录：未加宽柱、未做系综、未引入摩擦，因此 C1 的 10 % 判据本轮**未达成**。
原文档"5.85 %"是 `u_analytic*(1+3% noise)` 的产物，与本轮实测无对应关系。

## 5. 证据分级与局限

* **REAL**：C1 剖面、C2 阈值、C5 台账、流体动量台账 —— 均由本次 DEM 运行产生。
* **WITHHELD**：C3（多孔尺度 Stokes/LBM 流解缺失；用"水力学半径"反推 `k` 与 Kozeny–Carman
  **代数恒等**：`k = φ r_h²/(8τ²)`、`r_h = 2φ/S_v` 回代即得 `k = φ³/(2τ²S²(1-φ)²)`，等于自己比自己，
  不能算验证）；C4（需双分散床中细颗粒真正被输运并计数逃逸，本轮算力预算不足未做）。
* 无摩擦、无转动 → `i_c` 偏保守（真实砂土因摩擦/剪胀会更高），故 C2 的 0.13 % 一致不应外推为
  "Terzaghi 公式在真实砂土中误差 0.13 %"；它只说明本模型的力平衡与 Terzaghi 一致。
* 单实现、单柱宽；静态极限；不含固结/瞬变。
