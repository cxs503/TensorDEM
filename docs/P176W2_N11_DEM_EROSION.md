## 2. 怎么做的（方法 / 流程 / 关键设置 / 工具链）

模块按「接触 → 单坑 → 流」三段拆开，每段只做一件事，且都可单独验证：

| 文件 | 内容 |
|---|---|
| `contact.py` | 塑性法向恢复系数（Johnson 四分之一次幂 `e_n=(v_y/v_n)^{1/4}`，屈服速度由 Hertz 解**推导**而非查表）、Coulomb 斜撞切向恢复（滑动/粘着两支）、平壁弹道闭式解 |
| `crater.py` | 单冲击：`E → 移除体积 → 球冠 → 坑深 h/坑半径 a`（二分反解，`h ≤ R` 几何护栏）、体积守恒的壁面沉积算子、Oka 锚定律 |
| `stream.py` | 多颗粒流：弹道→实测撞击 (v, α)→坑→恢复→再撞，累计 `E`、质量/能量账本、角度与速度扫描 |
| `breakage_bridge.py` | 破碎耦合钩子（等体积子代、质量守恒）+ 冲蚀核的 AST 依赖审计 |

**关键设置与理由**

1. **撞击角度不是抽样的，是从轨迹里量出来的。** 喷嘴高度 50 mm，粒子在重力下弹道飞行，撞击速度与角度由抛物线闭式解给出（`JointImpactKinematics`）；重力只把 30 m/s 提高到约 30.02 m/s（+0.05%），但让掠射粒子可以多次擦壁——这正是 DEM 相对「按分布抽样 α」多出来的信息。
2. **接触能量损失有物理来源。** 法向用 Johnson 塑性恢复（150 µm 砂粒在 0.5 GPa 硬度靶面上的屈服速度 v_y ≈ 0.04 m/s，故撞击全部落在塑性支），切向用 Coulomb 冲量上限 `μ(1+e_n)v_n`：掠射保持切向速度、正撞粘着。
3. **一次冲击 = 一个球冠坑。** 移除体积由冲蚀律给出，几何由球冠反解；`h > R` 属穿甲而非冲蚀，直接拒绝（物理护栏，不允许外推）。
4. **累计冲蚀率按磨粒通量定义。** 分母是穿过控制面的磨粒质量（每颗只计一次，弹跳多少次都还是同一克砂），不是接触质量——否则子撞击会把 `E` 稀释、把角度曲线压平（本节点实测：按接触质量算角度曲线会退化为 90° 单峰）。
5. **破碎从外面挂。** 冲蚀核不 import 任何破碎/PBM 模块（AST 审计），破碎通过 `on_impact` 回调注入，且子代等体积、质量严格守恒。

工具链：Python 3.11 / numpy / matplotlib(Agg)；复现 `python benchmarks/erosion_dem_verification.py`；单测 `python -m pytest tests/test_erosion_dem.py -q`（45 例）。

**与既有验证面的关系（不重复造面）**：`p176w1-n09`（`tensordem.erosion`）是纯本构库——角度函数、速度指数、DNV 速率代数式与事件账本，**假定**撞击 (v, α) 已给定；`p176w2-n08`（`tensordem.erosion_pbm`）把冲蚀与颗粒破碎的 PBM 耦合，工况为 90° 正撞。本节点补的是两者之间的空档：**撞击运动学由 DEM 轨迹积分给出**（弹道 + 塑性/摩擦恢复 +多次弹跳），**单冲击坑几何**（坑深/坑半径/体积沉积）与**多颗粒累计通量口径**的 E，外加与破碎模块的**结构解耦**证明。三者共用同一份材料库与角度函数（单一真源），不复制公式。

## 5. 注意点（坑 / 局限 / 适用范围）

1. **角度曲线必须按磨粒通量归一。** 用「接触质量」作分母会把掠射多次擦壁的子撞击算进分母，`E(α)` 被稀释成 90° 单峰（本节点早期实现实测退化为 90° 峰，见 `stream.py` 的注释）：弹跳多少次都还是同一克砂。
2. **Oka 不能给绝对速率。** 其前系数单位约定无法离线复现，故只借标度律与角度函数，绝对量级由**一个**锚承担（对 DNV 形状对拍拟合）。任何「Oka 绝对冲蚀率」的引用都必须带上锚的出处。
3. **DNV 铝材系数对是 ASSUMED。** `K` 只在锚里出现并互相抵消，进入形状对拍的只有 n；真实设计值必须回原标准查表。
4. **球冠单坑模型有适用边界。** `h ≤ R` 是硬护栏；当移除体积逼近半个球（≈ 穿甲）时会抛错而不是外推。软靶 + 高速 + 大磨粒组合会碰到这条边界，此时需要压痕/穿甲模型。
5. **沉积算子是体积守恒的**，所以 C4 的闭合残差在机器精度量级（1e-15），它验证的是算子与网格一致性，**不是**网格离散误差。网格离散误差需要另设「粗网格 → 加密」收敛研究（本节点未做，列入后续）。
6. **重力使撞击速度高 0.05%**、角度略变；这对判据无影响，但严格复现需同高度同重力。
7. **破碎只做单向耦合**：子代等体积分裂、质量守恒，未建颗粒-颗粒碰撞与磨粒自磨（attrition）反馈；多弹跳情形下子代也可能再次撞壁，本节点只跟踪一个子代。
