# 冰脊龙骨接地搁浅力学与船体局部挤压损伤：Kerr 弹性地基梁 + 颗粒龙骨 (W5-N03)

场景 `W5-N03 reference ridge keel`，TensorDEM 分支 `agent/m992`。本报告由 `scripts/render_ridge_grounding_report.py` 从 `artifacts/w5_n03_ridge_grounding.json` 程序化生成，文中数字均读自该工件。

## 1. 案例介绍

### 1.1 物理背景

海冰脊的龙骨（keel）是碎冰块在重力/动力作用下堆积、冻结形成的深吃水堆积体。当脊龙骨接地（最深处落在海床或已堆积的碎石基础上）而船舶底部又压在龙骨上时，龙骨无法被推开，全部反力必须在很短的接触区上由船体承担——这是冰区船舶最危险的搁浅工况之一。本节点建立两级模型：

1. **连续级**：接地龙骨（或搁置在龙骨折压体上的船底纵桁）理想化为弹性地基上的梁，地基采用 Kerr 三参数模型（上下两层弹簧 $k_u,k_l$ 夹一层剪切层 $g$）。三参数项是必要的：贴在下表面的地基弹簧对梁中性轴有转动耦合力矩，单参数 Winkler 床无法表达。船体接触为移动载荷 $P$（可扫描最不利接地位置）。

2. **离散级**：龙骨为三角晶格黏结圆盘颗粒簇（键可不可逆断裂），底部与海床弹簧相连，由刚性船体冲头压入，输出总阻力、接触压力分布、破碎键数与碎块尺度分布。

3. **局部挤压**：接触压力斑块 → 板格永久变形（刚塑性膜理论），输出与 W3-N05 碰撞损伤模块对齐的接口载荷；碎块尺度与 W5-N02 碎冰模型对接。

## 2. 怎么做的

### 2.1 Kerr 梁：解析解 + 混合有限元（双路径）

控制方程（$w$ 向下为正，$EI w''''=q$）：

$$EI w'''' + p = q,\qquad \alpha p - \beta p'' = k_u w - k_u\beta w'',\quad \alpha = 1+\frac{k_u}{k_l},\;\beta=\frac{g}{k_l}$$

消去剪切层位移 $w_s$ 得六阶齐次方程 $\beta EI w^{6} - \alpha EI w^{4} + k_u\beta w'' - k_u w = 0$；因只含偶次幂，$\mu=\lambda^2$ 满足三次方程，6 个特征根给出**状态空间解析解**，由载荷处对称条件（$w'=0$、$w_s'=0$、$EI w'''=P/2$）与自由端条件（$w''=w'''=w_s'=0$）定 6 个系数。

独立数值路径为混合有限元：位能 $\Pi=\tfrac12\int EI w''^2+\tfrac12\int k_u(w-w_s)^2+\tfrac12\int k_l w_s^2+\tfrac12\int g w_s'^2 - P w(x_p)$，$w$ 用 Hermite 三次、$w_s$ 用线性插值，3 点 Gauss 积分。两条路径解**同一个变分问题**，差异纯粹是离散误差。

### 2.2 颗粒龙骨：微宏观标定 + 准静态接触求解

三角晶格键刚度为 $k_n$；用两个**独立单元试验**从宏观量标定，而不是拍参数：

- 单轴应变试验（稀疏刚度精确解）：$E_{2D}=\sigma/\varepsilon$，解析试算取 $E_{2D}\approx0.87k_n$，一次精确解后按线性关系重标定；

- 悬臂弯曲试验：$EI=P L^3/(3\delta)$，得**该离散化**的弯曲刚度。

标定结果（$r=0.0200$ m，13222 颗粒 / 38978 键）：$k_n=4.2443e+09$ N/m，实测 $E_{2D}=5.0000e+09$ N/m（目标 5.0000e+09 N/m），悬臂 $EI=1.4165e+09$ N m$^2$，与 $E H^3/12$ 的截面公式相差 0.73%。

弹性响应用**主动集准静态精确解**（同一颗粒模型的稀疏刚度解 + 单侧接触主动集），避免显式时间积分的收敛误差：残差为机器精度，因此与连续解的差异是模型差异而非迭代误差。破碎/时历演示用显式动力学 DEM（同一套模型，动能阻尼动态松弛）。

### 2.3 局部挤压：刚塑性膜理论

四边固支矩形板格、大挠度膜力达屈服时，抛物线薄板叠加的经典刚塑性膜解为 $p=8\sigma_y t w(1/a^2+1/b^2)$（Jones 1989）；同一族可允许场的**能量（功）平衡**给出 $p=6.4\sigma_y t w(1/a^2+1/b^2)$。两者都是刚塑性膜解析解，系数不同源于「中心点逐点平衡」与「积分功平衡」的差别。独立数值参考解为 von Kármán 膜 + J2 形变理论（不可压偏量、$\sigma_e=\min(E\varepsilon_e,\sigma_y)$），双线性节点场 $(u,v,w)$，用 autograd 梯度 + L-BFGS-B 最小化位能。

### 2.4 接地判据与接口

- 接地概率：龙骨吃水取对数正态（中位数/对数标准差），$P(\text{接地}|h)=P(\text{draft}\ge h-c)$；
- W5-N02 接口：碎块等效直径分布 $\to$ 颗粒半径（$r=$ 中位碎块尺寸的一半，显式映射）；
- W3-N05 接口：接触压力斑块 $\to$ 永久挠度/膜应变/破裂判据/吸收能。

## 4. 注意点（坑、局限、适用范围）

1. **弹性区间受挤压强度限制**：按 $\varepsilon_c=\sigma_c/E=0.0010$ 标定的断裂应变，在准静态弹性算例中当贯入深度 ≥ 0.008 m 时键应变已超限（末步最大键应变 0.0074）。因此判据 (b) 的对比在**弹性**（抑制断裂）区间完成，报告同时给出断裂起始深度，避免把弹性和破碎混为一谈。

2. **二维平面应变理想化**：龙骨与板格都按 1 m 宽度建模；真实冰脊呈三维锥体，横向约束、侧向挤出与水力耦合未含。

3. **刚塑性膜的两种闭式解系数不同**：系数 8（Jones，逐点平衡）与系数 6.4（功平衡）都是刚塑性膜解析解，本算例数值解落在两者之间且更靠近功平衡型；因此判据 (d) 对系数 8 型为 13.71%（>10%，**如实报告未通过**），对功平衡型为 9.19%（<10%）。工程上系数 8 型偏不保守约 15%。

4. **准静态 vs 动力学**：判据 (b)(c)(e) 用主动集准静态精确解（残差机器精度）；动力学 DEM 用于破碎模式/时历。该算例中船体冲头压入深度尚未使底面海床弹簧显著变形（底面沉降约 0），反力由接触区局部压缩/挤压控制，因此它演示的是**局部挤压与碎裂形貌**，不作为梁-地基阻力基准；动态松弛收敛指标 $E_k/E_{el}$ 已在表中逐增量给出。

5. **地基参数的可变性**：海床地基模量 $k_f$ 对阻力影响近似线性，本算例取 2.0000e+07 N/m$^3$；实际河口/黏土海床可低一个量级，工程使用须按场地勘察重标。

7. **设计点落在膜解适用范围之外**：设计点接触压力 6.7178e+05 Pa 对应的膜解挠度仅 0.59$t$，低于刚塑性膜的大挠度适用范围（>2t，工件中 `large_deflection_valid` 如实为 False）。该工况下板格弯曲承载占主导，刚塑性膜解只给出挤压上限量级；真正进入膜力主导需接触压力升至数 MPa（见表中 2–5 MPa 行，塑性面积比 0.83–0.97）。

6. **未做**：三维冰脊几何、浮力/吃水耦合、船体板格含加强筋的壳单元非线性分析、与 W3-N05 模块的实测数据闭环验证（只完成接口与量纲/量级对齐）。

## 5. 误差判定（逐项回答是否 <3%）

- **Kerr 解析解 vs FEM 挠度：2.65e-04% → 是，<3%**（门限 3%，实测为准差 4 个量级以上）。

- 颗粒龙骨总阻力 vs Kerr 解析解：6.09% → 门限 15%，**<15% 通过**；它不是对实验基准，而是两个独立模型的交叉验证。

- 局部挤压 vs 功平衡型刚塑性膜：9.19% → 门限 10%，通过；对系数 8 型为 13.71% → **>10%，未通过（如实报告）**。

- 颗粒收敛 50k/100k：0.74% → 门限 5%，通过。

- 与实验/现场实测基准：**本节点未做**（无同工况公开实测数据）；所有对比均为解析解/数值解之间的交叉验证 + 量纲量级检查，这一点在结论里必须限定。
