# 有限振幅升沉周期验证：结清 `ice_floe_physics_validation.md` §6 的唯一未验证项（m2843）

状态：验证欠账结清（verifier 席 selfstart，2026-11-03）。本单**不改物理模型、不动 `src/`**，只补一条被判为
"未验证"的公开声明，并给出可复现的判据。

被结清的原文（已合并的 `docs/ice_floe_physics_validation.md` §6）：

> **Small-amplitude only.** The period anchor uses `2e-3 R`; the nonlinear (finite-amplitude)
> heave period is not verified and is expected to differ.

## 1. 案例介绍（物理背景 / 几何 / 参数）

二维挤出圆盘浮冰（`tensordem.buoyancy_wet`, `model="2d"`），海水中的升沉（heave）自由振动。

| 量 | 值 | 说明 |
|---|---|---|
| 半径 `R` | 0.5 m | 冰盘横截面半径 |
| 挤出厚度 `t` | 1.0 m | 平面应变，单位厚度 |
| 冰密度 `rho_i` | 917 kg/m³ | — |
| 水密度 `rho_w` | 1025 kg/m³ | 海水 |
| 重力 `g` | 9.81 m/s² | 与水动力配置一致 |
| 质量 `m` | 720.31 kg | `rho_i pi R^2 t` |
| 浸没分数 `f_eq` | 0.89463 | `rho_i/rho_w`，**接近全浸没** |
| 平衡中心高度 `y_eq` | −0.3377671 m | 模块 `solve_floating_equilibrium` 与闭式二分差 2.6e-13 m |
| 静水回升刚度 `k` | 7414.0237 N/m | 模块有限差分 vs `rho_w g t w(y_eq)`：相对差 **5.7e-11** |
| 小振幅周期 `T_0` | 1.9583147 s | `2 pi sqrt(m/k)` |
| 阻尼 | 0 | `wet_drag_coeff = 0`：参考解为保守系统，故必须关阻尼 |

**为什么这个工况天然强非线性**：`f_eq = 0.895` 使圆盘几乎全浸没，水线宽度
`w(y) = 2 sqrt(R² − y²)`（即瞬时刚度 `k(y) = rho_w g t w(y)`）在 ±0.3R 振幅带内变化约 3 倍
（图 1b）。恢复力对 `y_eq` 不对称：**上抬变硬、下沉变软**（图 1a）。因此除周期随振幅漂移外，
即使从对称位置释放，时间平均吃水也会偏离 `y_eq`（非线性整流/rectification）。

## 2. 怎么做的（方法 / 关键设置 / 工具链）

参考解**不共用被测代码路径**：模块内部用 `arccos` 圆缺公式再数值求导；本单用另一条路——**闭式势能**。

1. **浸没面积**（独立推导，`s = R sin(phi)` 代换）：
   `A_sub(y) = R²(pi/2 + phi + sin(phi)cos(phi))`，`phi = asin(−y/R)`；
   `|y| > R` 时取完全浸没/完全干燥的常值（`A_sub(−R) = pi R²`, `A_sub(R) = 0`）。
2. **面积原函数**（解析）：`Pi(y) = int A_sub dy = y A_sub(y) − (2/3)(R² − y²)^{3/2}`；
   因 `dA_sub/dy = −w(y)`，有 `dPi/dy = A_sub − y w + y w = A_sub`。
   单元测试以数值微分验证该恒等式（1e-7 级），**修正项符号写反是这条路上最容易犯的错**
   （`+` 会给出 `A_sub − 2 y w`，本单第一版即踩中，被该恒等式当场抓住）。
3. **势能**：`V(y) = m g (y − y_eq) − rho_w g t [Pi(y) − Pi(y_eq)]`，`−dV/dy` 即恢复力。
4. **精确非线性周期**（能量求积）：
   `T(E) = 2 ∫ dy / sqrt(2(E − V)/m)`，代换 `y = c + d cos(theta)` 把两端反转点
   `1/sqrt` 奇性消掉（端点极限为 `sqrt(d m / |F|)`）。
5. **求积必须分段**：在 `y = ±R` 处圆盘转为全浸没/全干，`d³V/dy³` 奇异；不分段则规则退化为一阶，
   在 `A/R = 0.3` 处留下 **1e-4 的平台**——它与模型误差同量级，会被误判为模型的错
   （本单先踩此坑，分段后 64 阶 Gauss–Legendre 收敛到 1e-10）。
6. **被测侧**：`tensordem.buoyancy_wet.compute_buoyancy_force` 逐颗计算浮力，扣除重量后以仓库
   相同的辛欧拉（symplectic Euler）次序 `v += a dt; y += v dt` 积分；周期由速度符号变化插值定位
   反转时刻（两个半周期之差），平均吃水取反转区间上的梯形积分。
7. 工具链：`benchmarks/floe_heave_finite_amplitude.py`（战役 + `heave_report.json`）、
   `benchmarks/floe_heave_figures.py`（三张图）、`tests/test_floe_heave_finite_amplitude.py`
   （15 个断言，含 4 个负控）。本文所有数字均由这两个脚本写入
   `artifacts/floe_heave/heave_report.json`，**无手抄**。

`(omega dt)²/24 = 1.7e-06`（`omega = 3.20 rad/s`）一致——加密后按 `dt²` 收敛，说明残差是指积分器阶数，
不是参考解的误差。

**非线性的两条定量结论**（本节是本单的物理增量）：

1. **周期漂移近似 `c A²` 且不对称**：上行 `c_+ ≈ 0.70 R^{-2}`（`A/R = 0.3` 时 +6.26 %），
   下行 `c_- ≈ 0.43 R^{-2}`（−0.386 %/… 即 +3.86 %）。等幅上抬比下沉周期长 2.3 %（`A/R = 0.3`），
   因为上抬进入水线更宽、刚度更高的区段，下行则相反。
2. **平均吃水整流为负**：所有振幅下 `<y> − y_eq < 0`（圆盘平均**坐得更低**），
   `A/R = +0.3` 时 −0.0215 m（约 0.43 R 的百分之 4.3），与求积一致到 1.3e-05 m。

**负控**（`heave_report.json → negative_controls`）：

| 控制 | 替换 | 结果 |
|---|---|---|
| C1 零浮力 | 恢复力 → 0 | 反转点 0 个，无振荡（如期失败） |
| C2 线性化刚度 | `F = −k(y_eq)(y − y_eq)` | `A/R = 0.30` 处周期偏差 **6.26 %**（>5 %，如期失败） |
| C3 过浮力 | `rho_w × 1.3` | 周期偏差 22.2 %（如期失败） |

**C2 的一个诚实记录**：该控制最初在 `A/R = 0.05` 处判定，偏差只有 **0.096 %**，低于 1e-3 阈值——
即"线性化控制在该振幅下无法失败"，控制本身失效。已改为在 `A/R = 0.30`（漂移 6.3 %）判定，
并在单元测试中断言 >5 %。这是"控制必须能失败"这条纪律的一个真实反例。

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

**踩过的坑**

1. **原函数符号**：`Pi = yA − (2/3)(R²−y²)^{3/2}`，写成 `+` 时 `dPi/dy = A − 2yw`，势能整体错号，
   周期变成 0（求积全是空区间）。被"导数=面积"的恒等式测试当场抓住——先写这条测试再写参考解是便宜的保险。
2. **求积端点极限**：`d sin(theta)/sqrt(2(E−V)/m)` 在反转点是有限非零值 `sqrt(dm/|F|)`；
   返回 0 会留下一处跳跃，Simpson 退化为一阶，出现 1.7e-4 的"平台"，极易被误读成模型误差。
3. **`y = ±R` 处须分段**：圆盘转为全浸没/全干，`d³V/dy³` 奇异；不分段则 `A/R = 0.3` 下行通道
   误差卡在 1e-4。分段后 64 阶 Gauss–Legendre 收敛到 1e-10。
4. **仿真侧漏掉重量项**：只把 `compute_buoyancy_force` 当恢复力（不扣 `mg`）时，圆盘单调加速上浮
   到 `y ≈ 15 m` 且没有反转点——首个版本正是这样拿到 NaN 周期。
5. **控制必须能失败**：见 §3 的 C2 记录。

**局限（不得越界解读）**

- 只验证**单圆盘、单自由度、无阻尼**的竖向运动；不加附加质量、自由面变形、波浪阻尼、表面张力。
  真实浮冰的升沉周期会被附加质量显著拉长（`T ∝ sqrt(m + m_a)`），本单不涉及。
- 只覆盖 `model="2d"`；球体（`model="3d"`）的有限振幅升沉未验证。
- 只覆盖 `|A| ≤ 0.3 R`；`A/R > 0.3` 时下行通道会越过 `y = −R` 进入全浸没恒力区（自由飞行段），
  周期继续快速增长，本单未做该区段。
- 不是实验/冰池验证：判据是解析能量积分与守恒性，不代表圆盘+中心力键能代表真实海冰。
- `tests/test_ice_floe_physics.py` 在所检出主干上有 **16 个既有失败**（本单未改 `src/`，与本次改动无关，
  已如实记录，留给后续单分诊）。
- 运行时间：全战役 12 条通道 + 加密 + 负控 ≈ 50 s（单线程）；测试 ≈ 6 s。

## 6. 误差判定（关键量 vs 基准，逐项回答"是否 < 3%"）

| 关键量 | 基准 | 度量 | 相对误差 | < 3 % ? |
|---|---|---|---|---|
| 平衡中心高度 `y_eq` | 闭式面积二分 | 绝对差 | 2.6e-13 m | 是 |
| 静水刚度 `k_heave` | `rho_w g t w(y_eq)` | 相对 | 5.7e-11 | 是 |
| 小振幅周期 `T_0` | 能量求积（`A/R = 2e-3`） | 相对 | <1e-4 | 是 |
| 周期 `A/R = ±0.05` | 能量求积 | 相对 | 1.1e-07 | 是 |
| 周期 `A/R = ±0.30`（最大漂移 6.26 %） | 能量求积 | 相对 | 2.4e-08 ~ 7.8e-08 | 是 |
| 平均吃水整流 `A/R = ±0.30` | 能量求积 | 绝对 | ≤1.3e-05 m（相对 3.6e-05） | 是 |
| 恢复力曲线（41 点，`|y| ≤ 0.95R`） | `rho_w g t A_sub − mg` | 相对 | <1e-12 | 是 |

结论：**全部关键量相对误差 ≪ 3 %**（最差 1.07e-07，出现在周期）。因此
`docs/ice_floe_physics_validation.md` §6 的 "nonlinear heave period is not verified" 一项可以
改为已验证，适用范围如上（单圆盘 2-D、无阻尼、`|A| ≤ 0.3R`）。
