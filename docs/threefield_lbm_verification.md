# Analytic verification of the D3Q19 + Smagorinsky propeller-race solver

Module: `src/tensordem/threefield/wake_lbm.py` (unchanged) · harness:
`src/tensordem/threefield/wake_lbm_verification.py` · driver:
`scripts/verify_wake_lbm_analytic.py` · tests:
`tests/test_threefield_wake_lbm_verification.py` · artefacts:
`artifacts/wake_lbm_verification/`.

## 1. The debt this closes

The three-field ice–hull–propeller campaign grades the propeller race
(`docs/THREEFIELD_ICE_HULL_PROPELLER.md`, §3.2 and §6) by

* comparing the resolved axial profile with an **empirical Gaussian** (worst
  core-shape error 5.80 %, R² = 0.994–0.999),
* a thrust vs excess-momentum-flux balance (19 % → 6 % along the domain,
  attributed to the bounded-domain pressure term), and
* mass-flux constancy (0.1 % between stations),

and then records the headline limitation: *"The LBM race is under-resolved
(10 cells per diameter): the functional form is verified, the spreading law is
not."*  None of those checks can separate a **wrong kernel** from
**under-resolution**: a mis-scaled relaxation time, a mirrored streaming stencil
or a mis-normalised Smagorinsky stress would each move the profile, the momentum
budget and the spreading law in the same direction as coarse resolution does.

Before this work the solver kernel of `wake_lbm.py` had **no comparison with a
closed-form solution** — the evidence grade of "D3Q19 + Smagorinsky, τ₀ = 0.5005,
Cs = 0.14" in the campaign table was, in the strict sense of the platform
evidence ladder, `WITHHELD`: asserted from the source text, never independently
computed.  This increment supplies the missing ladder and, in the process,
corrects one published constant convention.

## 2. Method

Nine rungs, each anchored on a closed form rather than on the solver.  The
production kernels (`_equilibrium`, `_macroscopic`, `_effective_tau`, `_stream`,
`_apply_boundaries`, `step`) are used unchanged; the periodic rungs replace only
the streaming/boundary pair by a wrap, and that substitution is compensated by
rung V3, which exercises the real bounded closures.

| rung | quantity | anchor (independent of the solver) |
|---|---|---|
| V1 | equilibrium moments | `Σf = ρ`, `Σ f c = ρu`, `Σ f c c = ρ(c_s² δ + u u)`, `Σ w = 1`, `Σ w c_x²c_y² = 1/9` |
| V2 | streaming stencil, 19 directions | `torch.roll` scatter reference with the wrapped edge cells masked |
| V3 | bounded closures (inlet equilibrium, convective outlet, free-slip walls) | uniform flow `u = (U_in,0,0)`, `ρ = 1` is an exact fixed point |
| V4 | collision + periodic shift | mass and momentum conservation |
| V5 | viscosity | `γ = ν k²`, `ν = (τ₀ − ½)/3`, measured by log-linear fit of the mode amplitude |
| V6 | Galilean invariance | the same decay rate in a frame moving at `U = 0.04` |
| V7 | Smagorinsky `τ_eff` | closed form on a prescribed analytic `f = f^eq + f^(1)` field |
| V8 | SGS-damped decay | `dA/dt = −k²A(ν₀ + (4/3π)Cs²kA/√2)` from the mode projection of `∂_t u = ∂_x(ν∂_x u)` |
| S1 | eddy-viscosity convention | `ν_t/(Cs²|S|)` against the textbook value `1` |

Derivation of the two anchors that are not textbook results:

* **V7.**  With `Π_ij = Σ_k c_ki c_kj f_k^neq`, a shear wave `u_y = A sin(kx)` has
  `f_i^(1) = −3w_i ρτ c_ix c_iy A k cos(kx)`, so the *full* tensor norm is
  `(√2/3)ρτ|du_y/dx|`.  The code forms the norm from the six Voigt components
  `(xx,yy,zz,xy,xz,yz)`, i.e. it counts each shear component **once**:
  `|Π|_single = |Π|_frobenius/√2 = (1/3)ρτ|du_y/dx|`.  Substituting into
  `18√2 Cs²|Π|/ρ` gives `τ_eff = (τ₀ + √(τ₀² + 6√2 Cs²τ₀|S|))/2`.
* **V8.**  Projecting `∂_t u = ∂_x(ν∂_x u)` on `sin(kx)` with
  `ν = ν₀ + (CsΔ)²|∂_x u_y|` and `<|cos|³> = 2/(3π)` gives the ODE above.

Supporting numbers:

* **V1**: `Σw − 1 = 0`, `Σ w c_x²c_y² − 1/9 = 0` (both exact in float64), so the
  lattice weights and the `c_s² = 1/3` relation are exact, not tuned.
* **V2**: the 19-direction stencil matches the independent scatter reference in
  **all** 20 520 population values (bitwise), so no direction is mirrored or
  component-swapped.
* **V4**: mass error 4.29e-14 and momentum error 3.33e-14 over 400 steps — the
  collision conserves both moments to roundoff.
* **V5**: relative error 0.31 % (τ₀ = 0.55), 0.255 % (τ₀ = 0.7), 0.000276 %
  (τ₀ = 1.0).  The residual is the finite-`k` correction, and the `O(k²)` study
  shows it: `nx = 16, 32, 64` give 1.136e-2, 3.096e-3, 7.898e-4 at
  `k = 0.393, 0.196, 0.098` — observed orders 1.87 and 1.97 per `k²` step, i.e.
  the shear-mode dispersion is second-order accurate.  At the race resolution
  (10 cells per diameter, `k ≈ 0.3`) this predicts a viscosity error of the same
  1 % order.
* **V6**: decay rate 6.4454e-4 (fixed frame) vs 6.4144e-4 (bulk `U = 0.04`):
  fractional change 4.81e-3, i.e. the moving frame changes the *viscosity* by
  0.5 %.  The earlier apparent 8.4× "failure" was a measurement artefact, not a
  solver defect: a transverse perturbation is *advected* (`u_y = A sin(k(x−Ut))`),
  so a sine-only projection decays at `kU ≫ νk²`.  The harness therefore measures
  the complex mode amplitude `√(⟨u sin⟩² + ⟨u cos⟩²)`; the phase drift was
  anti-correlated with the prediction exactly at `ω = kU` (measured
  `7.85e-3` per step at `kU = 7.854e-3`), which is itself a positive check.
* **V8**: modelled rate enhancement over pure viscosity 1.000 vs measured 1.0036;
  worst deviation from the ODE 0.58 % over 400 steps.

## 4. Finding: the Smagorinsky constant is 16 % high, not what its name says

`LBMConfig.smagorinsky_cs` is documented and used in the campaign as the
**Smagorinsky constant** (Cs = 0.14 in the report table, 0.16 default).  Because
the stress norm counts shear components once (Voigt) instead of twice
(Frobenius), the closure delivers

    ν_t = (Cs Δ)² |S| / √2 ,   i.e.  Cs_eff = 2^(-1/4) Cs = 0.8409 Cs .

Measured at τ₀ = 0.5006, Cs = 0.16: `ν_t/(Cs²|S|) = 0.70703` against the textbook
`0.70711` (deviation 1.1e-4, the finite-strain residual of the quadratic),
`Cs_eff = 0.1345`.  Consequences stated honestly:

* the campaign's `Cs = 0.14` acts as `Cs_eff = 0.118`, and the default 0.16 as
  0.1345 — both inside the usual engineering range (0.10–0.20), so no published
  conclusion changes, but the number in the table does not mean what its label
  says;
* the V8 rung uses the *measured* convention, not the nominal constant, so a
  future fix of the normalisation cannot silently pass the decay test;
* the fix itself (multiplying the norm by √2, or documenting `Cs` as "Voigt") is
  deliberately **not** applied here: it would change every existing race artefact
  and must be a separate, re-run increment.  This document is the audit trail.

## 5. Notes, pitfalls, scope

1. **Physical vs measurement convention.**  A sine-only projection cannot
   measure a moving-frame decay rate (see V6).  Any future shear-wave test in
   this repository must use the complex amplitude.
2. **`LBMConfig` requires `disk_x ≥ 8` and `disk_x ≤ nx − 4`**, so the smallest
   legal box is `nx = 12`; the harness respects this (and that constraint is
   itself unexplained in the source — flagged, not changed).
3. **What is *not* covered.**  (a) The actuator-disk forcing law has no
   closed-form anchor: it is a proportional controller that drives the disk cells
   to a target race velocity, and its gain (`disk_perturbation`) is a modelling
   choice.  (b) The inlet/outlet/wall closures are verified only in the sense that
   they admit a uniform state exactly (V3); their *accuracy* in a non-uniform
   flow (zero-gradient outlet reflection, free-slip wall slip length) is not
   anchored.  (c) All rungs are in incompressible low-Mach lattice units; no
   dimensional calibration is implied.  (d) Turbulence statistics, the spreading
   law and the race's absolute thrust are untouched: the campaign's honest FAIL
   on the spreading law (β_measured = −0.012 vs 0.085) stands and is *not*
   repaired by kernel verification.
4. **Cost.**  The whole ladder is 103 s on one core (largest box 64×8×8,
   6 531 steps), so it is CI-able; the test module runs a reduced subset in 42 s
   together with the existing three-field tests.

Caveat that must travel with this table: agreement at the 1e-2 level or better
certifies the **kernel**, in lattice units, on periodic/simple-bounded
configurations.  It does not upgrade the *physical* grade of the propeller-race
model, which remains limited by resolution (10 cells per diameter), the
actuator-disk idealisation and the unre-verified Lindqvist/Riska baselines
(`docs/threefield/FORMULAS.md`, WITHHELD).
