# IN27-S3 冰-船 DEM 压碎清除算子成熟化：质量/能量守恒破碎-清除替换 δ>0.25 m 阈值，交付力统计与 floe 运动学

节点 **P103W2C-N02** · 仓库 `TensorDEM` · 工况矩阵 9 例 (v ∈ [1.0, 3.0, 5.0] m/s, h_ice ∈ [0.5, 1.0, 1.5] m)

## 1. 案例介绍（物理背景 / 几何 / 参数表）

冰区船舶的总体性能设计需要用 DEM 计算船-冰相互作用的**载荷统计**与**碎冰运动学**。历史实现用一条经验阈值：碎块相对船体的压入深度 δ > 0.25 m 即从仿真中删除（“压碎清除”）。该操作不守恒——质量、动量与动能直接消失，且阈值与任何物理量无关。本节点把该阈值替换为**质量/能量守恒的破碎-清除算子**：接触冲量累积到冰强度判据即分裂父块（ΣV_child = V_parent、动量继承、扣减表面能 γΔA），只有当碎块尺寸低于数值分辨率下限 h_min 时才清除，且清除的质量/动量/动能全部记账。

**模型与几何**：冰层按与 IN27-S2 相同的 jittered 点阵（固相率 0.55、d50 = 0.18 h_ice、对数正态体积谱）离散为 floe；船首局部为 V 形首（半进角 20°、外飘 10°），船体以 v 推进 1.0 m。floe 为平动等效球（不解析自转/互锁，为本文档声明的简化），floe-floe 为弹性接触（压碎封顶只作用于船体界面），船体接触为弹性-理想塑性（压碎封顶）弹簧。

**船体总纵载荷**（ζ_i = L/2 − |y_i − y_c| / sin β 为 floe 距船舯的站位）：

```
VBM = Σ_i F_z,i ζ_i     HBM = Σ_i F_y,i ζ_i     TBM = Σ_i [(y_i−y_c)F_z,i − (z_i−z_c)F_y,i]
```

## 2. 怎么做的（方法 / 流程 / 关键设置 / 工具链）

1. **算子**（`tensordem.breakage_clearance`）：每步由 DEM 时程给出各 floe 的船体接触冲量 J_i、罚函数弹簧储能增量、阻尼/摩擦耗散与压入深度 δ_i。破碎判据为累积压碎冲量 |J_i| > σ_c A_i τ_b（单步压力被 σ_c 封顶，故必须用冲量累积而不是瞬时压力）；子块数 n 取“表面能可支付”的最小值：γ ΔA(n) ≤ E_avail，ΔA(n) = π d²(n^{2/3}−1)。子块按 Fibonacci 球面排布（相切不互穿），继承父块动量，表面能从子块平动动能中扣除。清除只在 d < h_min 时发生，质量/动量/动能写入台账。
2. **能量台账**：W_in（船体驱动面功）= E_surface + E_penalty + E_dissipation + ΔKE + E_clearance。压碎用塑性偏移 δ_p 记账（弹性部分 δ_e = min(δ−δ_p, δ_c)），因此罚函数储能不会在封顶后无限增长；罚函数储能上限的越限部分单列为“数值污染指标”。floe 内部接触功与储能属内力，按定义与 ΔKE 严格抵消，不计入台账（否则重复计数——本节点踩过的坑，见第 5 节）。
3. **迁移**：在 IN27-S3 的 9 工况（v×h_ice）上，新旧两种规则各跑一遍：旧规则 = 关闭破碎 + δ>0.25 m 删除；新规则 = 破碎 + h_min 清除。记录 VBM/HBM/TBM 时程，按 24 个等时块取极值并做 GEV 拟合（scipy 形状参数 c = −ξ）。
4. **收敛**：h_min ∈ {0.10, 0.05, 0.025}（dt 固定）与 dt ∈ {2e-4, 1e-4, 5e-5}（h_min 固定）双轴细化，用 Roache GCI（安全系数 1.25）评估观测阶与不确定度。
5. **负控**：(a) σ_c → 10¹⁵ Pa 关闭破碎，应退化为纯罚函数接触且质量守恒；(b) h_min = 0 关闭清除，实体数爆炸守卫必须触发。
6. **工具链**：numpy/scipy（cKDTree 邻居、genextreme 拟合）+ matplotlib；`scripts/in27_s3_breakage_clearance.py` 一键复现，pytest 覆盖 C1–C6。

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

- **坑 1：冲量判据不能写成瞬时压力判据。** 压碎封顶 F ≤ σ_c A 使接触压力永远不可能超过 σ_c，若直接比较瞬时压力则破碎永不触发；必须累积冲量（损伤变量）。
- **坑 2：内力不能计台账。** floe-floe 冲量的功等于 −(弹簧储能 + 耗散)，若既把它计入输入功又把储能/耗散计为汇，残差立刻涨到 20 %+（本节点实测 9–23 %）。最终把内部接触功排除、只记船体驱动面功与船体单元汇，残差降到 0.02 % 量级。
- **坑 3：摩擦功已在冲量功里。** 摩擦直接作用于 floe，其功包含在冲量功中；再记一次耗散会重复计数（实测残差 3.3 %，与摩擦功完全等值）。
- **坑 4：封顶弹簧必须用塑性偏移。** 否则罚函数储能 0.5kδ² 在封顶后无界增长，台账必然失衡；改记 δ_e = min(δ−δ_p, δ_c) 后每步精确闭合。
- **坑 5：破碎子块不能重叠。** 若子块出生在父块同一位置，瞬间互穿会产生巨大人造压碎功（实测残差 100 %+）；Fibonacci 球面排布后消失。
- **坑 6：碎块弹性变形能的去向。** 父块破碎时其船体弹簧储能不随子块走，必须作为显式汇记账（`add_sink_energy`），否则残差约等于该储量（实测 6.6 %）。
- **局限 1：floe 为平动等效球**，不解析自转、互锁与真实多面体形状；形状效应对压力场的偏差由 IN27-S2 的球元代理研究给出，本链不重复。
- **局限 2：质量缩放 500 倍**（准静态 DEM 惯量缩放）。速度统计因此是“缩放惯量 DEM”意义下的量，适合做相对比较（新 vs 旧、工况间），不宜直接对标实船碎冰抛射速度。
- **局限 3：VBM/HBM/TBM 为船体总纵载荷的 DEM 积分**，力臂用首部站位近似，不含船体梁刚度回弹；作为载荷统计口径是自洽的，但不是规范级的船体梁响应。
- **适用范围**：层冰-船首挤压（crushing-dominated）工况；h_ice/h_min ≥ 10 的分辨率区间；δ 超过板厚量级的极端撞深需另做结构响应耦合。
