## ① 案例介绍（物理背景 / 几何 / 参数）

抽去侧壁后圆柱形颗粒柱的**轴对称坍塌**（Lube, Huppert, Sparks & Freundt 2004）。该文摘要给出两条经验律
（本仓库 `granular_column/axisym.py` 已按原文实现，目标值运行期由公式求值、无手抄）：

* 跑距律 $r_\infty/r_i = 1+1.24a\ (a<1.7)$；$=1+1.6a^{1/2}\ (a>1.7)$
* 埋置时间律 $t_\infty = 3(h_i/g)^{1/2} = 3(a r_i/g)^{1/2}$

锚点容差 15 %。前序：轮 1–5（跑距 5/5 闭合）、m17534（时间律验证欠账）、m17917（浅柱收敛）、
m18261（冻结 $d/r_i$ 的细化 + 到达定义族，H1/H3/H4/H5 均被否证）。

**本单审计对象**：轮 5 归档语料 25 例的**原始末态坐标**（`runs/case_column_collapse_lube2004/cases/*.json`，
源工作树 `work/m17111`，逐文件 sha256 入 `manifest_sha256.json`）。此前所有轮次都只读**标量**
（`runout_radius_p995`、`runout_ratio_p995`、`t_reach_by_fraction` …）：标量无法回答三件事——

1. 报出的数**真的**是从这次运行的坐标算出来的吗（防手抄/防漂移）？
2. 沉积体**对称吗**？径向量（$r_{p995}$、$r_{\max}$）只在统计轴对称时才是可解释的跑距代理。
3. 这个**量本身**分辨到什么精度？若分辨率与判据容差同量级，"通过/不通过"的措辞就得改。

| 项 | 值 |
|---|---|
| 几何 | $r_i=0.48$ m（实测 $r_{p995}=0.4727$），$a_{\rm nom}\in\{0.5,1,1.5,2,3\}$，$a_{\rm meas}=0.545\ldots3.087$ |
| 颗粒 | 单分散球 $r=0.03$ m（8 粒/柱半径）或 0.02 m（12 粒），$\rho=2500$ kg/m³，981–19687 粒 |
| 初始 | HCP 排布，`packing_gap` 0.02，`jitter` 0（无系综） |
| 接触 | 线性弹簧-阻尼法向 + Cundall-Strack 切向（饱和 $\mu|F_n|$）+ 滚动弹簧（饱和 $\mu_rR|F_n|$）+ 底板 |
| 参数臂 | $\mu=0.5$；$\mu_r\in\{0.4,0.5\}$；$\mu_{\rm wall}\in\{\mu,0.8,1.0\}$；$t$ 臂 $\Delta t$ 或 $\Delta t/2$；$\mu$ 律 constant / $\mu(I)$ |
| 终止 | 24/25 例 `at_rest` |
| 归档量 | 末态坐标 + 时间历史（124 采样点）+ 能量账 + 判据块 |

## ② 怎么做的（方法 / 流程 / 关键设置 / 工具链）

1. **新模块 `deposit_audit.py`**（纯 numpy、只吃 `(n,3)` 坐标，不 import 求解器，故审计不可能改动被审对象）：
   * `horizontal_com_drift`：水平质心漂移 —— 初始圆柱与底板同轴 ⇒ 轴对称坍塌的水平质心**不可能**平移，
     漂移量就是积分器/配对顺序的对称性破坏度；
   * `azimuthal_moments` + `azimuthal_uniform_floor`：足印的方位质量矩
     $A_m=\lvert\sum_i r_i e^{im\theta_i}\rvert/\sum_i r_i$，零假设 =「角度 i.i.d. 均匀、半径分布固定」，
     蒙特卡洛给出同 $n$ 的**采样地板**（"实测 $A_m$ 是噪声地板的多少倍"而非拍一个阈值）；
   * `azimuthal_shuffle_floor`：**角度置换**零假设（问的是"半径与角度是否相关"，**不是**各向同性 —— 置换保留
     角度多重集，故看不见真实各向异性；本单把它作为对照并列报告，见 ⑤-2）；
   * `floor_clearance`：$z-r$ 的最小值 = 底板接触重叠上界（穿透 = 求解器缺陷）；
   * `edge_effective_count` / `subsample_noise`：跑距量是**极端次序统计量**——有多少颗粒真正决定它、
     以及随机归档子样本下它的 1σ 分辨率；
   * `decimation_bias`：**规则**（等距）子样本对各量的影响 = 归档截断模型；
   * `shape_factor`：沉积体离"同底面圆锥"多远（$H_{\rm eq}=V/(\pi R_{\rm out}^2)$，圆锥 $\Rightarrow H=3H_{\rm eq}$），
     描述性量，**不宣称任何参考值**。
2. **预登记假设**（写在脚本 docstring，先于执行）：`H_INT`（报数↔原始坐标可复算，$\le10^{-9}$）、
   `H_ARCH`（归档完整性）、`H_SYM`（$\text{drift}\le5\times10^{-3}R_{\rm out}$）、
   `H_ANISO`（中位/max 的 $A_1,A_2$ 相对均匀角零假设地板）、`H_FLOOR`（$\min(z)-r\ge-0.2r$）、
   `H_SUB`（4× 规则子样本对 $r_{p995}$ 的影响 $\le1\%R_{\rm out}$）。
   `H_METRIC`（跑距量 25 % 子样本 1σ $\ge3\%R_{\rm out}$）**是在看过 1 个探索性算例之后**才写下的，
   顺序在此如实申报；判据在语料级计算前固定。
3. **归约**：25 例 × 约 40 个标量 → `cases_deposit_audit.csv`（32 KB，替代 12 MB 原始坐标），
   逐文件 sha256 入 manifest；参考值一律**由两条律重新求值**（`lube_2004_*`），不抄任何存下来的目标数。
   参考律按**实测**长宽比 $a_{\rm meas}$ 求值（比前几轮按名义 $a$ 更严，见 ⑤-3）。
4. **机器门**：31 项 pytest —— 机械层用**解析可知**的合成构型（纯偶极/四极、等距环、体积均匀圆锥
   $H=3H_{\rm eq}$ 精确成立、径向简并沉积体任何子样本必须给出同一量）+ 输入校验；
   数据层把本文每个数字断言住（CSV 回归 + 与原始坐标互校）。
5. 工具链：Python 3.11 + numpy + matplotlib(Agg)；**未启动 DEM**，未递交集群。

## ⑤ 注意点（坑 / 局限）

1. **归档截断是真实缺陷，且偏向大算例**：19687 粒的两例只存 4922 个坐标（stride 4）。**存下来的标量仍是对全粒子集算的**
   （$H_{INT}$ 在 23 个完整归档例上相对差 0.0），因此判据本身不受影响；但**任何事后复算**（对称性、形状、作图、再归约）
   都只能在这个子样本上做：这两例的质心"漂移" 1.6e−2 $R_{\rm out}$、$A_1$ 4e−2 全是子格点偏移的伪像，
   不是物理也不是求解器缺陷。规则建议：**归档要么全存，要么随机抽样，且必须把 `n_particles` 一并存入分析脚本的断言里**。
2. **结构化 vs 随机子样本差近一个量级**（表 3 / fig 2）：HCP 格点的等距子样本取到的是**另一个子格点**，
   其外边界与母格点不同，$r_{p995}$ 摆幅 24.8 %；随机 25 % 子样本只有 3.1 %。凡是"每 k 个存一个"的归档约定都会放大边缘量误差。
3. **方法学坑（本单踩过并修正）**：最初把"角度置换"当各向同性零假设——**错**。置换保留角度多重集，
   真实各向异性照样保留（等径情形下甚至**精确不变**，见 `tests::test_permutation_floor_cannot_see_anisotropy_when_the_radii_are_equal`）；
   正确的零假设是**重抽均匀角、保留半径分布**（`azimuthal_uniform_floor`）。两者在本单并列报告。
4. **跑距量是极端次序统计量**：$r_{p995}$ = 半径 99.5 % 分位 + 一颗半径，只由 $n_{\rm eff}$ 中位 23 粒（最小 6 粒）决定；
   深柱末态存在"飞溅"外环（fig 4），个别孤粒跨过 20 % 的半径差。故**任何"跑距符合到 3 % 以内"的表述都不成立**——
   量自身 25 % 子样本 1σ 就是 3.1 %（表 3），这不是求解器精度，是度量分辨率。
5. **参考律取值口径**：本单按**实测** $a_{\rm meas}$ 求值（更严）；轮 5 按名义 $a$。$a=0.5$ 例两者差 −2.9 % vs −6.4 %，
   差异全部来自初始 HCP + 2 % 格隙使实测柱比名义更高（$a_{\rm meas}=0.550$）。引用时必须带口径。
6. **只归档末态坐标**：沉积体的**演化过程**不可审计（无逐帧坐标），故"爬行尾"只能用时间历史（124 采样点）判读，
   无法直接检验末态是否仍是准静态。集料局限：单种子、单初始构型（无系综），$H_{ANISO}$ 是"统计轴对称"而非逐例精确对称。

   `R_a1_g16`/`R_a3_g12` 缺口与 H4（格隙）/H5（$\Delta t$）的待解释部分——如实申报。

## ⑥ 误差判定（逐项 vs 基准，显式回答「是否 < 3 %」）

| 关键量 | 基准 | 实测误差 | < 3 % ? | < 15 % ? |
|---|---|---|---|---|
| 报数 vs 原始坐标（$r_{p995}$、$r_{\max}$，23 例） | 归档坐标复算 | **0.0**（逐例精确） | **是** | 是 |
| 跑距 $r_\infty/r_i$（闭合臂 5 例，$a_{\rm meas}$ 口径） | Lube 跑距律 | −9.9 … +4.5 % | 否 | **5/5 是** |
| 跑距，全 25 例 | 同上 | 中位 7.84 %，区间 −9.9 … +39.5 % | 否 | 21/25 是 |
| **跑距量自身分辨率（25 % 子样本 1σ）** | 无（度量性质） | **中位 3.10 %**、max 6.89 % | **否**（⇒ <3 % 的符合性不可主张） | — |
| 埋置时间 $t_{95}$（同语料） | $3\sqrt{h/g}$ | −5.2 … +34.1 % | 否 | 多数否 |
| 水平质心漂移（完整归档 23 例） | 0（同轴初值） | 中位 5.8e−5、max 4.65e−4 $R_{\rm out}$ | 是 | 是 |
| 方位各向异性 $A_1,A_2$ | 均匀角零假设地板 | 中位 0.0050 / 0.0080 × 地板 | — | 是（max 1.79 × 地板，仍在 5 × 内） |
| 底板穿透 | $z\ge r-0.2r$ | 最深重叠 0.0838 r | 是 | 是 |

**总回答：否。** 本单唯一达到"< 3 %"的是**内部一致性**（报数 = 原始坐标复算，精确到 0.0）与对称性、底板量；
**对实验基准的比较没有任何一项达 3 %**，而且这一结论有结构性原因：跑距量自身的 1σ 分辨率就是 **3.1 %**（25 % 归档），
**因此"跑距符合 Lube 律到 3 % 以内"在本语料上不可主张**，能主张的最强表述是"5/5 在 ±15 % 带内，单例误差 −6 … +5 %，
该区间与度量分辨率同量级"。所有数字由 31 项 pytest 断言住（含与原始坐标的互校）。
