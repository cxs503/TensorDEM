# AUDIT m23050 · RCP 沉积算例池：实现等价性证书（跨摘要数值惰性的静态证明 + 减尺运行时臂）

锚点：`CASE-DEM-RCP-PACKING-FRACTION`（算例池·随机密堆体积分数 RCP；Scott 1960 / Bernal & Mason 1960；验收带 0.62–0.66；10000 球，无摩擦/低摩擦两档）。

**本单性质**：补 `AUDIT_m22824` §2 预登记、`AUDIT_m22977` §4 记为 `NOT_RUN` 的那张**复现证书**。本单不改求解器方程、不动 TensorPlatform，只把「换摘要改不改数值」从假设变成证据。

## 1 欠账为什么还在，以及为什么不能靠等作业

m22824 递交 `cj4410`–`cj4415`、m22977 改用 `stage_dir` 重递为 `cj4495`–`cj4500`，目标都是「同 spec 同种子，用当前实现重跑，比较落定位置与全部标量」。两批都未回件：第一批在节点 staging 阶段因 GitHub 不可达失败（调度面报 `succeeded`，`cj4414`/`cj4415` 的作业日志原文可见 `Couldn't connect to server`），第二批本单开工时仍在排队。本单不再第三次把同一张单押在队列上，而是把同一个问题换成一个**更强、且不依赖队列**的问法：

> 两个摘要之间，**从 `run_deposition` 可达的代码对象**是否逐字节相同？

若相同，则两个摘要对**任何**输入都不可能产生不同的数 —— 这是对全域的陈述；而一次重跑只是**一个样本**。这不是「用推理代替测量」：比较的是编译后的 code object（``co_code`` + 常量表 + 参数布局，递归进嵌套 code），不是人眼看 diff。额外再给一条**减尺运行时臂**（本地、N=600、短 t_max）作为测量，用来堵住「静态相同但实际不同」的非源码因素（解释器/模块级状态）。

## 2 方法：两个缺陷分开处理

`impl_sha256` 只戳**一个文件**，这带来两个不同的坑，证书必须分别覆盖：

| 缺陷 | 后果 | 本单的处理 |
|---|---|---|
| 只戳一个文件，不覆盖导入闭包 | `deposition_packing` 从 `tensordem.granular3d_core` 导入 `damping_ratio`（恢复系数约定）；该模块改了，摘要不变而物理可能变 | 对**仓库内局部导入闭包**逐模块做同一判定，并把该模块**被导入的符号**作为根 |
| 摘要变 ≠ 数值变 | 追加一个后处理函数、改文档字符串、加一个调用方不传的默认参数都会改摘要而一个数都不改 | 判定只看**可达代码对象**与模块级语句，不看文件哈希 |

裁决词汇（预登记，不产生第六种）：`IDENTICAL_SOURCE` / `EQUIVALENT_PATH`（可达函数全部逐字节相同、无删改）/ `EQUIVALENT_PATH_SHARED_STATE`（仅模块级语句变）/ `NEEDS_RUNTIME`（可达函数被改或删，必须实测）/ `MISSING_SOURCE` / `UNPARSED`。只有前三种允许「不重跑直接比较数值」；`MISSING_SOURCE` **不是**通过。

实现：`src/tensordem/prov_equivalence.py`（纯源码分析，无领域语义）；驱动：`benchmarks/case_rcp_deposition/impl_equivalence_certificate.py`；测试：`tests/test_rcp_impl_equivalence.py`。

## 6 注意点与局限

1. **静态臂比一次重跑强，但不是同一件事**：它证明「同摘要差异不改变可达代码」，因此对该摘要下的**所有**算例（含 N=10000、含未重跑过的种子）都成立；但它不测量浮点结果，若存在源码之外的影响（numpy/scipy 版本、BLAS 路径、CPU 指令集差异），静态臂看不到。运行臂正是为此存在，只覆盖一个减尺配置。
2. **可达性分析是保守的**：按名字解析调用（`foo()`／`self.foo()`／`mod.foo()`），动态派发解析不到的被调方会落在可达集**之外**。方向是对的：漏判只会让裁决显得更乐观吗？不会 —— 被改函数仍会出现在 `modified` 列表里由人复核；评审可以把任何 `EQUIVALENT*` 降级为 `NEEDS_RUNTIME`，不能反向升级。
3. **不覆盖第三方版本**：算例 JSON 没有记录 numpy/scipy 版本，本证书也不能替代它。这是一条仍然存在、未被修补的溯源缺口（建议入账，见 §8）。
4. **运行臂是减尺的**（N=600、t_max=12、本地 <10 min 政策），它的落定判据 `settled` 在多数臂上为 false —— 它比较的是**同一时刻的同一条轨迹**，不需要物理落定；因此它不能用来支持任何 φ 的物理结论。
5. **未处理 `cj4495`–`cj4500`**：本单没有取消它们。若它们回件，`submission_ledger.py` → `provenance_audit.py` 的路径仍在，可给出 N=10000 的直接测量；本证书与之不冲突，二者一致时互相加强。

## 7 误差判定（逐项，显式回答是否 <3%）

本单产出的是**等价性裁决**，不是新的物理量，故不存在「计算值 vs 文献值」的误差；按要求逐项说明：

| 量 | 本单结果 | 基准 | 相对误差 | <3%？ |
|---|---|---|---|---|
| 位置差 `beca38735d16_vs_b44c19146425` | 0.000e+00 m | 0（同 spec 同种子的确定性重现） | 0 | 是（严格 0 或 ≤1e-12） |
| 位置差 `cf4b761c6e92_vs_b44c19146425` | 0.000e+00 m | 0（同 spec 同种子的确定性重现） | 0 | 是（严格 0 或 ≤1e-12） |
| φ（N=600 减尺） | 见表 §5 | 0.6366（Bernal & Mason 1960） | — | **不适用**：减尺臂未落定，不作为物理证据 |

结论：本单**没有**产生可对标的 φ 误差；`AUDIT_m22824` §4 的 φ 验收结论保持不变，其前置条件（跨摘要数值惰性）现由 §3–§5 提供证据。
