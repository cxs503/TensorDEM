## 1. 案例介绍

### 1.1 物理对象

颗粒破碎总体平衡方程（population balance, breakage only）

```
dn(v,t)/dt = -S(v) n(v,t) + ∫_v^∞ S(v') b(v|v') n(v',t) dv'
```

`n(v,t)` 为体积 `v = d³` 的数目密度，`S(v)` 为选择函数（单位 1/s），`b(v|v')` 为女儿分布。
`m9455`（`tensordem.erosion_pbm.pbm`，Kumar–Ramkrishna 固定枢轴有限体积格式）已证明该算子的三条恒等式：
质量 `Σ_k v_k n_k` 精确守恒（两枢轴权重 `w = (v_{k+1}-v_d)/(v_{k+1}-v_k)`）、数目每事件精确 +`n_frag`、
以及 `S=const` + 等分二元破碎时的解析级联 `N_k(t) = e^{-St}(2St)^k/k!`。

**但"守恒"不等于"收敛"**：前两条是算子结构恒等式，对任意网格都成立，因此它们无法回答
"网格够不够密"。本节点补的正是缺的那把尺子。

### 1.2 两个算例

| | 算例 A（阶数验证） | 算例 B（物理应用，继承 `p176w2-n08`） |
|---|---|---|
| 女儿规则 | `equal`，2 子（落在枢轴上） | `gaudin`，α=2.5，3 子（落在枢轴之间，系综均值，固定种子） |
| 选择函数 | `S = 4.0 (v/v_0)^{1/3}` 1/s | Weibull 强度 × 冲击应力代理（`meanfield_selection`） |
| 初始条件 | 1 颗 `d_0`，两枢轴放置 | 同上 |
| 时间推进 | 精确（均匀化级数），按 `t=1.5 s` 单点取值 | 同左，`t = 0.4 s` |
| 用途 | 无采样噪声，可验证观测阶 | GCI 幅度、细粉地板、冲蚀率拆解 |

算例 B 物性（`erosion_pbm.study.CASE`）：磨粒 `d_0 = 150 µm`、`ρ_p = 2650 kg/m³`、Weibull `σ_0 = 10 MPa, m = 2.6`、
冲击 `u = 30 m/s (cv 10%)`、`α = 90° (σ 6°)`、碰撞频率 50 /s、靶材铝合金 `Hv = 0.5 GPa`。

### 1.3 网格

`LogLogGrid(v_min, v_max, N, R)`：边 `ln V_k = ln v_min + L·f(k/N)`，`f(ξ) = (e^{βξ}-1)/(e^β-1)`，`β = ln R`。

* `R = 1`：`ln v` 均匀梯（`N` 等分，`q = N/(octaves)` 段/倍频程）；
* `R > 1`：**对数-对数可变网格**——局部 bin 宽从 fines 端到 coarse 端按 `R` 指数拉伸（局部宽增长几何比 `R^{1/N}`）；
* 加密：`N → fN`，**`R` 不变**，所有局部对数宽除 `f` ⇒ 三档加密的加密比 `r = f` 精确成立（这是可变网格能上 Richardson 的前提）；
* 枢轴 = 边界的几何中心 `sqrt(V_k V_{k+1})`；`R=1` 时等分二元女儿 `v/2` **精确落在枢轴** `sqrt(V_{k-q}V_{k-q+1})` 上（C2 的前提）。

## 2. 怎么做的（方法与工具链）

### 2.1 计量学三件套

1. **解析 bin 积分**（`LogLogGrid.moment`）：bin 内数密度对 `v` 取常值时
   `∫_{V_k}^{V_{k+1}} v^p n dv = n_k (V_{k+1}^{p+1}-V_k^{p+1})/((p+1)ΔV_k)` 有闭式 ⇒ 报告的矩是重建分布的积分，
   而不是把颗粒压到枢轴上再求和。`p=0` 严格等于 `Σ n_k`；`p=1` 给出算术 bin 均体积。
2. **Richardson / Roache GCI**（`richardson_gci`）：`p = ln((f_c-f_m)/(f_m-f_f))/ln r`，
   `f_ex = f_f + (f_f-f_m)/(r^p-1)`，`GCI = 1.25|f_f-f_ex|/|f_ex|`。非单调/退化序列 **显式打旗**（`p=nan, certified=False`），不静默钳位。
3. **精确时间推进**（`propagate`）：算子线性常系数，`exp(At) n0 = e^{-λt} Σ_k (λt)^k/k! P^k n0`，`P = I + A/λ ≥ 0`（均匀化），
   用算子作用 `Pv = v + (M(Sv) - Sv)/λ` 施加（稀疏 mat-vec）。截断尾 `tail` 随结果返回 ⇒ 时间误差可审计。

> **为什么必须换推进器**（本轮踩到的坑，见 §5）：`scipy.linalg.expm` 在这个强非正态算子上直接返回 NaN
> （`cond(A) ~ 1e10`，Padé 分母在 57582 行的低秩结构上失效）；`solve_ivp(DOP853, atol=1e-30)`
> 在 `K=144` 就要 79 s、`K=576` 不可行。均匀化级数在 `K=576` 上 15 ms（5 个时间点），
> 尾项 `≤6e-16`，且把时间轴从网格研究里彻底移除——GOOD：测到的误差 100% 是离散误差。

### 2.2 闭合的解析锚（本节点的"标定尺"）

两枢轴权重满足 `w v_k + (1-w) v_{k+1} = v_d`（这就是质量守恒的来源）。把同一组权重作用在**解析 bin 均体积**上，
则 `∫v n dv / Σ v_k n_k = (1+r)/(2√r) = 1 + (r-1)²/(8r)`，`r` 为局部 bin 比 —— 一个 **与分布无关的闭式预测**。
本轮在四档网格上复算，实测与预测相对差 `< 1e-15`（`measure_factor_check`，下图 2），
说明 GCI 机器本身是被标定过的，而不是"自证"。

| 段/倍频程 q | 1 | 3 | 6 | 12 | 24 |
|---|---|---|---|---|---|
| bins | 24 | 72 | 144 | 288 | 576 |
| 最大相对误差 | 2.45e-12 | 2.54e-12 | 2.57e-12 | 2.68e-12 | 2.66e-12 |

等分二元女儿不再落在枢轴上，解析解根本没有对应的离散系统。metrics 里该条以 `reference_applicable: false` 显式标注，
**不是**求解器缺陷（见 §5.3）。

## 5. 注意点（坑、局限、适用范围）

### 5.1 上一版失败的根因：初始条件把 O(h) 偏差伪造进质量台账

若把进料放进"包含 `d_0` 的那个 bin"并给单位权重，则被追踪的质量 `Σ v_k n_k = v_pivot ≠ v_0`：
`q=2` 时偏高 **19%**、`q=3` 时 **12%**、`q=24` 时 **1.5%**（`v_pivot/v_0` 的网格依赖）。
后果是 (a) C1 的"相对漂移"起点本身就带网格偏差；(b) 由该偏差主导的序列会给出**假的 `p ≈ 1`**，
而真实格式在自相似网格上是二阶。修正：`initial_particle()` 用**两枢轴权重**放置进料
⇒ `Σ v_k n_k(0) = v_0` 精确（实测 1e-16），观测阶随之变成 2.0，且 `M0` 的粗网格偏差从 7% 降到 2%。
**教训**：网格研究的第一件事是让初始/边界数据在任何网格上都是同一个物理量。

### 5.2 两个"看起来能算"的时间推进器都不可用

`scipy.linalg.expm` 在本算子上返回 NaN（非正态、`cond ~ 1e10`，Padé 分母病态，且**无 warning**，最容易静默污染）；
`solve_ivp(DOP853, atol=1e-30)` 在 `K=144` 需 79 s（微小尾部 bin 控制步长），完全不可用于 3 档 × 多族研究。
均匀化级数 + 稀疏算子作用把单次推进压到 15 ms，且截断尾可报 ⇒ 网格研究的时间轴是干净的。

### 5.3 解析级联只在自相似梯上是参考

等分二元破碎把 `sqrt(V_jV_{j+1}) → sqrt(V_{j-q}V_{j-q+1})` 的前提是 `q` 段/倍频程的**均匀**对数梯。
可变（梯度）网格上该映射不存在，实测"误差"=100%。所以：
C2 在均匀梯上认证时间推进；**可变网格的离散化误差只能由矩/GCI 测**，两者不可混用。

### 5.4 Gaudin 女儿的采样噪声地板限制了可判阶范围

女儿矩阵是系综均值，固定种子下仍是**伪随机**样本。换种子后 `M2^int` 变 1.5e-3、`d50` 变 3.6e-3，
与网格差同量级 ⇒ 物理算例的 `M0/M2/d50` 观测阶（1.43/1.53/NaN）不可用于认证阶数；
可信的是 GCI 幅度（≤4e-4）。若要把物理算例的阶也判到 ±10%，需要把女儿矩阵换成确定性求积
（或把样本量提 2 个数量级），代价是矩阵构建时间线性上升。

### 5.5 地板 bin 在质量上不是中性的

当女儿体积 `v_d < v_min` 时，两枢轴规则把它整颗放进 bin 0（权重 1）。对**数目**精确，
对**质量**则是 `n_frag × v_0` vs 真实 `v_d` ⇒ 地板活跃时质量台账会**凭空增加**。
因此在 C1 里主动避开地板活跃的配置（`m=20`，实测份额 2e-10），
并把地板活跃度本身做成 C6 的显式判据 —— 而不是继续默认"细粉可以忽略"。

### 5.6 `R` 的参数化：必须用**整体**梯度比，不能用每 bin 增长比

最初用"每 bin 宽比 `γ`"参数化，加密时 `γ` 固定会让整条网格的形状随 `N` 改变（`R` 从 2.2 变 1.22），
序列因此**非单调**（实测 `p = nan`，`monotone = False`）。
改用整体梯度比 `R`（`f(ξ)=(e^{βξ}-1)/(e^β-1)`）后，加密严格保持形状，`r = f` 精确成立，`p` 回到 1.05–1.31。
另注意 `width_grading` 必须用**对数宽**之比，算术宽之比被体积跨度（本例 ~5.8e4）淹没。

### 5.7 Richardson 的符号陷阱

`f_ex = f_f + (f_f - f_m)/(r^p-1)`。若代码里用 `d = f_m - f_f`，则必须写成 `f_ex = f_f - d/(r^p-1)`。
本轮初版写成 `f_f + d/(...)`，GCI **幅度**碰巧不变（`|±d/(r^p-1)|` 相同），但外推值偏离真值 `2Ch^p` —— 
这类错误只会在"外推值 vs 已知真值"的测试里暴露，故合成序列测试（`test_richardson_recovers_first/second_order`）是必需的。

### 5.8 适用范围

* 结论适用于**线性破碎算子 + 固定枢轴两枢轴格式**；换成"移动枢轴/矩方法/直接积分法"需重做名义阶（§2.4）；
* `S(v)` 的求积用了与网格无关的同一套配置（81×41 确定性求积），误差为共模、不会伪装成网格效应，但它本身不是零；
* 冲蚀率拆解里的 13.1% 是 `p176w2-n08` 的 C4 构造（解析系综 vs RP-O501），本轮**复算得到 13.116%**；它**不是**解析基准，
  不能用"<3%"衡量（见 §6）。

## 6. 误差判定（逐项，显式回答"是否 < 3%"）

| 关键量 | 基准 | 误差 | < 3%？ |
|---|---|---|---|
| `Σ v_k n_k` 漂移 | 算子不变量（精确） | 7.2e-16 | ✅ |
| 解析级联 `e^{-t}(2t)^m/m!` | 闭式解析解 | 2.7e-12 | ✅ |
| 测度因子 `∫v n dv/Σv_k n_k` | 闭式 `(1+r)/(2√r)` | 4.4e-16 | ✅ |
| `M0`（渐近三档 GCI） | Richardson 外推 | 2.1e-5 | ✅ |
| `M1^int`（GCI） | Richardson 外推 | 1.3e-4 | ✅ |
| `M2^int`（GCI） | Richardson 外推 | 4.2e-4 | ✅ |
| 去除质量（细侧 GCI） | Richardson 外推 | 4.5e-4 | ✅ |
| Oka vs DNV-RP-O501 | **跨相关式**（非解析基准） | **13.16%** | ❌ **否，且不应 < 3%** |

最后一行必须显式说明：它是两条**经验相关式**之间的偏差（速度指数 2.34 vs 2.6 在包线 `U∈[20,40]` 上的对数距离），

在这 13.16% 里，**网格只占 0.024%**，所以它不能、也不该被归咎于离散化。
若强行把它写成 "<3%" 只能靠把对比点撤到锚点附近，属于选择性报告，此处不做。
