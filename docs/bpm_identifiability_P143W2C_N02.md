## 1. 案例介绍

### 1.1 物理背景

粘结颗粒模型（Bonded Particle Model, BPM）把脆性材料（冰、岩石）的宏观强度建立在"键的强度分布 + 键网络拓扑"上。工程标定的真正难点不是"凑出一组参数"，而是**可辨识**：微观键强度分布的 Weibull 模量 m_bond 与试件尺度观测到的尺寸效应指数 2/m 之间是否存在稳定的映射，以及这个映射在数值参数（质量缩放 β、加载率）变化下是否漂移。m7272 曾用纯统计管线（`bpm_calibration.calibrate_bpm` 吃外部传入的应力历史）声称清偿了 m6335 的"UCS 偏低 54.8%" honest FAIL，但那条管线从未真正运行 DEM 试件——本节点把这条链路接到引擎上，用真实粘结试件的位移控制单轴加载重新裁决。

### 1.2 几何与参数

| 项 | 值 |
|---|---|
| 试件 | 简单立方粘结球阵 cross_n×cross_n×n_layers（n_layers = 5/9/17 → t = 0.1/0.2/0.4 m）|
| 颗粒半径 | R = 0.0125 m（间距 2R，标距 L0 = (n_layers−1)·2R，截面 A = (2R·cross_n)²）|
| 键刚度 / 接触刚度 | k_b = 9.6e5 N/m, k_n = 1.875e6 N/m |
| 键断裂应变（中位）| ε_b = 0.015（拉伸），γ_b = 0.03（剪切）|
| 键强度离散 | Weibull，中位数固定为 ε_b，m_bond = 6（负控取 m_bond = 0 → 常数）|
| 密度 | ρ = 917 kg/m³（质量缩放：ρ_eff = β·ρ）|
| 边界条件 | 底层面 hard support，顶层面位移控制（拉伸 +z / 压缩 −z）|
| 准静态阻尼 | 全局粘性 drag = m/(decay_steps·dt)，decay_steps = 15（无量纲化，跨 β 一致）|

### 1.3 加载协议（load–relax 分步）

每个增量：ramp 阶段以恒定速度施加 Δε，随后 hold 阶段把驱动速度置零并让阻尼把残余动能衰减掉，在 hold 末尾读载荷。这样 KE/外功 判据度量的是**读数时刻**的数值惯性，而不是"恒速压头必然带着的动能"。恒速 ramp 协议保留为对照（它确实过不了 1e-3，见 §5）。

## 5. 注意点（坑 / 局限 / 适用范围）

1. **引擎球状工具无条件生效**：试件颗粒一旦被崩飞就会撞上工具球并把假载荷注入顶面反力，本次把 `tool_gap` 推远到 100 m 才拿到干净的 σ–ε（这是本地调试中第一次出现的"应力单调涨到337 kPa"假象的根因）。
2. **恒速 ramp 边界条件过不了 1e-3 门槛**：位移控制恒速驱动的顶层面自身动能 ∝ n·m·v²，KE/外功 与 β、与加载率² 成正比；只有 load–relax 协议（hold 末读数）才能同时满足准静态门槛与可承受的步数。本模块保留 `protocol="ramp"` 作为该门槛的负对照。
3. **尺寸效应公式的选择**：任务规定 σ_t = σ_0 t^(−2/m)（面积型 weakest-link）。本试件固定截面、变厚度，体积 ∝ t，若按体积型 weakest-link 应为 t^(−1/m)。两种指数都拟合了（`fit_area_law` / `fit_volume_law`），判据用任务规定的 −2/m。
4. **E 与强度不能同时由单一 k_b 标定**：把 k_b 提到 9.6e5 N/m 是为了让 UCS 落进 3–7 MPa，代价是 E 只有 ~0.1 GPa 量级（真实冰 5–10 GPa）。这是 BPM 的经典刚度-强度非同时可辨识问题，本次如实报告而未强行凑数。
5. **文献区间互相重叠**：三个区间都描述 −10 °C 附近的冰，"命中 2 个"是自洽性检查不是独立性证据；三个源都未在本工作树内数字化（`digitized=false`）。
6. **负控的强形式**：m_bond = 0 时试件强度是确定性的，尺寸效应斜率≈0，估计器返回预置退化带[0, 100]——这正是判据 (b) 里"不含退化区"的含义（CI 不是那个哨兵区间）。
7. **β 手臂分为两条**：分步(staged)手臂里 ramp 步数固定，物理时长与 sqrt(beta) 成正比，整条轨迹因此被构造成 beta 不变（漂移恰好 0.00%）——这验证的是「准静态率随 sqrt(beta) 缩放的规律」，而不是独立测惯性；真正有牙的探针是固定物理加载率手臂（sigma_t 漂移 2.28%，E 漂移 8.64%）。报告把两者分开列，不把 0.00% 当唯一证据。
8. **加载率无关性检验功效不足**：每个 (beta, 率) 组合只有 1 个试样，而单族强度的试样间 CoV 本身就有 2.7-8.8%，因此 10.42% 的 compression 率漂移无法与键强度抽样噪声分离。该子判据判 FAIL（数字如此），但结论应读作「该设计下不可分离」，而不是「压缩强度率相关」。
9. **负控在引擎层面失败（重要负面结果）**：把键强度设为常数（m_bond = inf）后，试件强度仍随厚度单调下降（1.203 -> 1.072 -> 0.785 MPa），尺寸效应拟合 m = 6.50、CI 宽度 0。即尺寸效应可由几何/边界驱动产生，**不能**唯一反演键强度分布的 m——原判据「常数键强度 ⇒ 不可辨识」的前提不成立。估计器层面的负控（合成常数强度）仍正确返回退化带。
10. **残余强度的两面性**：触点层面 `dual` 精确等于 μ_d（0% 超预测），但在**含残余键骨架**的试件层面，`tanh` 反而给出更低残余（因为它把粘着触点也按 μ<μ_s 打折）。因此"双系数更保守"的严格结论限定在触点层面，试件层面只报"dual 比单系数低"。
