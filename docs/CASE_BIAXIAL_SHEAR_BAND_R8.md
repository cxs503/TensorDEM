## ① 案例介绍（物理背景 / 几何 / 参数）

平面应变双轴压缩：矩形颗粒试样在位移控制顶压板下压缩，两侧伺服到恒定围压
σ₃ = 100 kPa；密实胶结颗粒材料在偏应力峰值后把变形局部化为一条（或共轭一对）
剪切带，倾角 θ 自 σ₃ 轴量起。文献基准：密实 Hostun 砂平面应变双轴 55–60°
（Desrues & Viggiani 2004, IJNAMG 28:279–321），R4–R7 沿用 60° 作为容差锚点
（注意：55–60 的**中点实为 57.5°**，R4–R7 文本把它称作"中点"是一处刻意的保守写法，
本轮同时给出对 57.5 与对 60 的两个相对误差）。

本轮不改物理、不改材料、不改协议：几何、材料、接触律、停机规则全部沿用 R7
（24 × 48 抖动圆盘格、35 % 冻结键、墙摩擦 0.55、4000 步固结、应变率 0.05 /s、
`post_peak_strain = 0.05`、`late_window_fraction = 0.8`、`strain_target = 0.12`、
`strain_cap = 0.22`）。**唯一变化是测量算子**。

| 项 | 取值 |
|---|---|
| 试样（本轮实跑，n = 4） | 种子 53, 67, 79, 83（R7 八种子中最低的四个，覆盖两种停机原因） |
| 保真度 | **smoke 保真**：16 × 32 格、600 步固结、`strain_target = 0.08` |
| 围压 / 键率 / 墙摩擦 | 100 kPa / 0.35 / 0.55 |
| 算子 | 已发表 Radon 聚焦 + R8 匹配滤波带模型拟合 + R8 谱惯量 |

## ② 怎么做的（方法 / 流程 / 关键设置 / 工具链）

1. **补 R7 对抗评审 §4.3 第 2 项欠账**（"未独立复现量测算子"）。新增
   `tensordem.biaxial_band_independent`：
   * `band_model_fit` —— 对 γ 场拟合显式带模型
     `γ = c₀ + A₁ exp(-u₁²/2σ²) + A₂ exp(-u₂²/2σ²)`，`u₁` 为到倾角 α 直线的距离，
     `u₂` 为到其**共轭（镜像）**直线的距离。高斯脊是剪切带的标准理想化；共轭项
     使算子在试样真实的 X 形局部化下**良定**。不投影、不分箱、不最大化任何方差比，
     并自报 `R²` 与共轭幅值比。
   * `spectral_band_angle` —— γ 场栅格化（格元 = 2 个平均粒径，晶格周期被排除在
     保留波数带外）+ Hann 窗 + 2D FFT；带法向 = 谱惯量张量最大特征向量。（该算子
     在共轭对上失效，见 ③ 的包络表——这是本轮**实测**出的适用边界，不是猜测。）
2. **先量化算子偏置，再把算子用到试样上**：`recover_angle_sweep` 在**试样同一几何类**
   （24 × 48 抖动三角格）上施加已知倾角的高斯脊（半宽 2/4/7 模型单位，5 % 颗粒噪声，
   共轭比 0 / 0.7 / 1.0，3 个晶格实现），比较三个算子对已知角的偏差。
3. **用改后的协议重跑试样**（`run_r8_independent_estimator.py --shard i`），对晚期窗口
   的累计 γ 场与逐对增量 γ 场分别用三个算子测量；带的局部剪胀角用带坐标（模型拟合的
   θ 与 σ 决定掩膜）单独测量，从根上绕开 R7 因"整体剪胀角不物理"而 WITHHELD 的困难。
4. 工具链：`src/tensordem/biaxial_band_independent.py` →
   `benchmarks/biaxial_shear_band/run_r8_independent_estimator.py --envelope / --shard i / --assemble`
   → `estimator_envelope.json` + `cache/*.json` → 本文与图（全部数字由 JSON 程序化注入）。

## ④ 注意点（踩过的坑 / 局限 / 适用范围）

1. **保真度限制（最重要）**：本轮实跑为 smoke 保真（16 × 32、600 步固结、应变 0.08），
   与 R7 的 24 × 48 / 4000 步 / 应变 ≥0.12 不同保真度，因此 3.2 的数值**不能**与 R7 的
   8.33 % 直接相减当作"算子修正量"。**只有包络表 3.1 与 R7 同保真度无关，可独立使用。**
2. **全保真重算未在本轮完成**：8 个全保真作业（cj4724 … cj4731）已递交计算队列，
   排队位次 ~131 起，等待超时后仍为 queued；本轮据此把结论降级为"包络 + smoke 保真复现"，
   不声称完成全保真独立复现（如实记为 not_run，不是 passed）。
3. **谱惯量算子只在单带下有效**：包络表 3.1 是实测边界，写进 docstring 与测试
   （`tests/test_biaxial_band_independent.py::test_spectral_degrades_on_conjugate_pair`）。
4. **匹配滤波的 σ 网格有上下界**（1–15 模型单位）：更宽/更窄的带会被夹到边界，
   σ 落边界时应视为不可信（本轮 4 例 σ 均在边界附近，R² 0.55–0.64，属可拟合但不高）。
5. **文献带原文未核**：55–60° 仍沿用 R4 起的引用（Desrues & Viggiani 2004），
   本轮没有该文原文可查（R7 对抗评审 §4.3 第 3 项欠账仍未清）。
