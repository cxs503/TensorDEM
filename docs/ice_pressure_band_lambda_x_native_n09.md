## 1. 案例介绍（物理背景 · 几何 · 参数）

冰与结构挤压时接触面压力呈斑块（压力带）结构；沿面相关长度 `lam_x` 决定设计冰压的空间平均尺度。工程文献常直接引用 `lam_x/h = 1.5–3`（`h` 冰厚），但未给出该数字的估计量定义、有限记录偏差、不确定度与**记录长度门槛**。本节点把 `lam_x` 做成可审计估计量，并用原生 DEM 检验该带的物理来源。

两类原生实验的几何与数值参数（程序注入）：

**(a) 合成标定实验**（已知解析 ACF）：两族场（谱合成周期实现 / 精确 AR(1)），目标 ACF `R(r)=exp(-|r|/lam)`，`dx = 0.05 lam`，`K = L/lam in [3, 50]` （14 个对数格点），每格点每族 800 条实现；标定与残差两级分别使用**独立随机种子**。

**(b) 块体尺度长域 DEM**（`tensordem.ice_pressure_band.block_band`，本节点新增）：刚性圆盘块体床被夹在刚性船体面（x=0）与伺服加载的冰板之间，y 方向周期，记录长度 B = 数十倍冰厚；块体尺寸 D/h 为控制变量。

| 参数 | 取值 | 说明 |
|---|---|---|
| 冰厚 h | 0.200 m | 归一化尺度 |
| 记录长度 B | 16.000 m = 80 h | 沿面长域 |
| 块体尺寸 D/h | 1.0 / 1.5 / 2.0 / 3.0 / 4.0 | 控制变量（5 档 × 4 seed） |
| 床深 Lx | 1.600 m = 2 D | 两排块体 |
| 目标挤压应力 | 1.50 MPa | 伺服（加载）控制，非位移控制 |
| 接触时间 / 时步 | 4.00 ms / 16.67 µs | 刚性块体；运行全程最大重叠 17.1 %（含初始压密瞬态）|
| 摩擦 / 滚动阻力 | μ=0.50, μ_r=0.20 | 干接触，粘性库仑切向 |
| 沉积网格 dy | D / 20 | 压力『传感器』足印 |
| 测量口径 gauge | 1.0 D | 预注册（连续性压力场的最小口径）|

## 2. 方法（流程 · 关键设置 · 工具链）

1. **偏差修正（两级经验标定）**：`lam_corr = lam_hat / [rho(K̂)(1+delta(K̂))]`，`K̂ = L/lam_hat`。`rho(K)=E[lam_hat]/lam` 由第一套种子实测；`delta(K)` 为插值式修正的残差，由**第二套独立种子**实测（插值式修正律在 K 小时高度非线性，修正值的均值 ≠ 均值的修正；`delta` 即这一 Jensen/插值差项）。两表均按 K 记录，在 log K 上做 3 点 `(1/4,1/2,1/4)` 平滑。**K < 3 一律给 `nan`（不予认证）**。
2. **充分性门槛 K\***：在 17 个 K 上用 3 个独立种子（每格 2000 条记录）实测修正后偏差，门槛定义为「从此 K 起，**每个种子**在每个更大的 K 上 |bias| ≤ 5%」。另在 3 个**全新**种子上做 9 格（3 seed × 3 L = K\*·(1,1.5,2)）逐格确认。
3. **方差标度**：二维 (L, λ) 网格（λ ∈ {0.25,0.5,1,2}，K ∈ [16,256]，300 条/格）回归 `log Var(λ̂/λ)` vs `log(λ/L)`（理论斜率 +1，等价于判据里对 `L/λ` 的 −1），另做固定绝对 L 的 λ 扫描（相对 sd 理论 +0.5，绝对 sd +1.5）。
4. **负控**：白噪声 60 条、严格周期场（周期 50 格）、相关场 60 条；估计器在 `diagnose_regime` 判定后**分流**：白噪声判『无相关』，周期场返回**主周期**（FFT 峰 + 抛物线细化）并显式扣留 λ。
5. **块体尺度 DEM**：20 次独立运行（5 档 D/h × 4 seed），每次记录 16 张压力快照，取时间平均剖面的相关长度（同口径 + 同标定修正），并做**口径阶梯**、**打乱对照**、**无核块体载荷 ACF**（每块壁面法向力序列，与传感器足印无关）。
6. **自校验不变量**（机器可判，见 §3.5 表）：整体力平衡（壁面力 = 压板力）、伺服载荷误差、准静态比、接触重叠、打乱对照塌缩。

工具链：Python 3.11 / numpy 2.0 / scipy 1.17；集群双节点 loong64 运行标定与 DEM；matplotlib 生成图；本文件由 `scripts/pressure_band_native_docs.py` 从 JSON 渲染。

| bias | -25.5 % | -17.7 % | -12.2 % | -11.3 % | -7.2 % | -0.7 % | -1.4 % | +2.4 % | +3.6 % |

| bias | +4.7 % | +3.0 % | +1.3 % | +1.1 % | +0.6 % | +0.2 % | +0.6 % | +0.5 % |

**A1 判据（K≥3 全部 |bias|<5%）不成立，如实记 FAIL**，三条独立证据说明这不是『修正式不够灵活』：

1. 实测：K=3 时 crossing 修正后仍 -25.5 %（3 种子 × 2000 条平均；同格的单种子样本外值为 crossing -26.5 %、expfit -41.2 %、integral -43.9 %）。
2. **上限实验（灵活修正族）**：把修正写成任意正函数 `f(K̂)`（`log f` 为 log K̂ 的 3 阶多项式），在独立训练集上以『每个 K 的集合均值无偏』为目标拟合，再在 3 个新种子上评估：K=3 处 crossing 残余 -2.3 %（确实进了 5%），但同一族在 K≥3 全域的残余最大 |bias| = crossing +13.1 %、expfit +32.1 %、integral +12.3 %——它把 K=3 的偏差换成了 K≈5–8 的偏差（逐 K 见 `calibration.json` 的 `ceiling` 字段）。结论：**不存在让整个 K≥3 区间都过 5% 的记录级乘性修正**；这是可辨识性限制，不是修正式不够灵活。
3. 原因是可辨识性而非算法：`lam_hat` 与 `K̂` 一一对应，同一观测值在不同真 K 下都会出现；K=3 时单条记录的修正后相对散度达 0.93（集合均值本身在几百条记录规模上就有 10% 量级抖动）。交付的标定以**集合均值**为目标，因此修正值的中位数在 K=3 偏低 -51.4 %；中位数与均值不能同时无偏（偏态分布），报告口径必须与标定目标一致（见 §5 第 4 条）。

## 5. 注意点（坑 · 局限 · 适用范围）

1. **伺服加载而非位移加载**：位移控制下 13% 压缩会把床体推到 46 MPa（重叠 20%），远离冰挤压物理区；本节点改为**载荷伺服（1.5 MPa）**，并用力平衡/准静态比/重叠三个不变量把关。伺服需要足够的压密步数：settle 20000 步时 D/h=4 只到目标的 0.6 倍（载荷误差 41%），提高到 45000 步后全部档位载荷误差 ≤ 1.7e−5。
2. **重叠是全程最大值**：报告的重叠含初始压密瞬态（多分散 8%、两排床体），稳态窗口内远小于该值；不把它当作稳态重叠使用。
3. **bang-bang 伺服会极限环**：速度式比例伺服在刚性床上以 v_max 振荡；改用**带惯性与阻尼的加载 ram** 后载荷误差降到 1e−5 量级（§3.5 表）。
4. **两级修正是必需项，不是装饰**：插值式修正 `λ̂/ρ(L/λ̂)` 在 K 小时的散度使修正值的均值与均值的修正相差数十个百分点（实测 `delta(3)` = -0.356）；只做单级修正会在 K=3 留下 -34.0 % 量级残差。
5. **门槛对噪声敏感，必须按 cell 判**：种子平均后 K\* 会给到 5.5，但逐 seed 判据要求到 12.6；报告采用后者（更保守，与 9 格确认的语义一致）。
6. **K=3 处均值门槛不可达（honest FAIL）**：见 §3.1 三条证据。工程上若必须用 3 个相关长度的记录，应报**中位数与区间**（修正后中位数偏差可小于均值偏差），而不是集合均值；或把记录加长到 K ≥ K\*。
7. **`integral` 不作报告估计量**：其方差不服 λ/L 律、小 K 偏差不可用 K 修正；仅作一致性对照。`spectral` 在本数据的 K 范围内不可标定（上一节点结论，未重复）。
8. **DEM 简化**：平面圆盘块体 + 滚动阻力近似棱角块体、无破碎、无浮力、无热效应；两排床深、单分散度 8%。块体形状的影响未量化（局限）。
9. **时间平均 vs 瞬时**：报告量是时间平均剖面的相关长度，瞬时场是点接触（δ 相关），快照中位数见 §3.5 列；文献压力带是瞬时结构，读者不可把两者混用。
10. **口径依赖是结论不是缺陷**：λ_x 没有『与仪器无关』的值；任何引用 λ_x 的场合必须同时给出 gauge。

## 6. 误差判定（逐项，显式回答「是否 < 3%」）
