# P387W2-N09 冰水浆体流变学三层验证面

## ① 案例介绍

冰水混合浆体（ice-water slurry）是碎冰场等效流体模型、冰浆管道输送、冰水两相流简化模型的物理基础。本节点从离散冰块到连续等效流体建立标度桥接，实现三层验证面：

| 项目 | 设定 |
|---|---|
| 物理域 | 冰-水两相流，离散颗粒→连续等效流体 |
| 浓度范围 | φ = 0.05 ~ 0.55（体积分数） |
| 最大堆积分数 | φ_max = 0.60（随机密堆） |
| 本征黏度 | [η] = 2.5（球形），角状颗粒 [η] = 3.375 |
| 温度范围 | 0 ~ 40 °C（影响载流黏度） |
| 剪切速率 | 5 ~ 80 s⁻¹（DEM Couette 剪切） |
| 颗粒直径 | d = 5 mm |
| 接触模型 | 线性法向 + Coulomb 切向 + 滚动阻力 |
| 流体耦合 | Stokes 拖曳背景（单向耦合） |

## ② 怎么做的

**第一层：浓度-黏度标度律**
- Krieger-Dougherty 公式：η_r = (1 - φ/φ_m)^(-[η]φ_m)
- Eilers 公式：η_r = (1 + [η]φ/(2(1-φ/φ_m)))²
- 互裁误差：|KD - Eilers| / mean(KD, Eilers)

**第二层：剪切速率依赖性**
- DEM Couette 剪切池（2D 周期 x，壁面 y=0/H）
- Irving-Kirkwood 应力张量（virial 公式）从颗粒接触计算剪切应力
- Stokes 拖曳背景流：u_f(y) = γ̇·y
- 多剪切率扫描检测剪切稀化-增稠转变

**第三层：形状效应与温度效应**
- 形状因子：球形 [η]=2.5，角状 [η]=3.375（shape_factor=1.35）
- 温度-黏度：IAPWS 数据二次拟合 log(μ) vs T

**负控**
- NC1：φ=0 → η_r=1.0（纯水）
- NC2：φ→φ_max → η_r 发散

**工具链**
- 模块：`tensordem.ice_slurry_rheology`（closures / dem_slurry / verification）
- 测试：`tests/test_ice_slurry_rheology.py`（41 用例）
- 工件：`artifacts/ice_slurry_rheology/`

## ⑤ 注意点

1. **DEM 模型简化**：本 DEM Couette 池使用 Stokes 拖曳背景（单向耦合），未包含润滑力。剪切稀化行为主要由颗粒重排引起，剪切增稠需要润滑力模型才能完整捕捉。
2. **形状效应浓度依赖性**：角状/球形黏度比值随浓度增加而增大，在 φ < 0.15 时比值 < 1.2，φ ≥ 0.20 时比值 ≥ 1.2。
3. **KD/Eilers 偏差**：两公式在低浓度区（φ < 0.30）偏差 < 5%，在高浓度区（φ > 0.40）偏差增大至 ~11%。
4. **质量守恒**：DEM 模拟中粒子数恒定，质量守恒误差为 0（精确守恒）。
