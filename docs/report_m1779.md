## 1. 案例介绍（物理背景 / 几何 / 参数表）

### 1.1 物理问题

碎冰场中冰块尺寸分布（Floe-Size Distribution, FSD）是连接冰块尺度断裂与场尺度行为（船舶阻力、冰压力、波浪衰减）的关键可观测量。传统方法**预设** FSD 形式（如对数正态或幂律），而本工作让 TensorDEM **预测** FSD：从 DEM 碎片级联中校准断裂核 $K(d,d') = \nu(d')\,\beta(d|d')$，再驱动群体平衡方程从单尺寸初始场演化至稳态幂律。

同时，碎冰场阻力需反馈至船舶总体性能——本单实现了 `broken_ice_resistance` 验证面，将 FSD 演化结果与 Lindqvist 锚、MT Uikku 实尺度试验及碎冰闭合公式对标。

### 2.2 关键方法要点

1. **断裂核校准**：β(d|d') 不做参数拟合，直接用实测碎片目录 bootstrap（对数正态抖动 + 面积归一化）；ν(d) 由单冰块首断应变尺寸律独立测量（Nelson-Aalen 风格风险率估计量，正确处理右截断）。

2. **质量守恒**：子体分配采用两点枢轴方案（Kumar & Ramkrishna 1996），每个采样事件严格守恒面积（Σx² = 1），离散算子机器精度守恒。

3. **幂律拟合**：微分数密度 n(d) = N_k / ΔD_k 在 log-log 空间最小二乘拟合，排除底部和源截面；同时报告累积约定指数 α−1。

4. **阻力反馈**：`broken_ice_resistance` 将平面视图中冰块 DEM 的接触力经沉没修正后与 Lindqvist 三分量锚对标，实现 FSD→阻力的闭环。

## 5. 注意点（踩坑 / 局限 / 适用范围）

### 5.1 AC2 诚实 FAIL（准静态）

准静态微分指数 α = 3.415 超出验收窗口 [2.0, 3.0]。这是**物理正确的结果**：
- 通量守恒律给出 α = 1 + ν_measure + q = 3 + q（面积守恒 ν_measure=2）
- DEM 测得 q = 0.439 > 0（大冰块更容易断），因此 α > 3 是必然
- 累积约定指数 α−1 = 2.415 在窗口内——验收准则未明确约定，属规范歧义
- 动态仪器（spall）测得 q = −0.130（弱，R² = 0.34），故 α = 2.869 通过

**教训**：FSD 指数必须标注约定（微分 vs 累积），两者差 1，恰好是验收窗口宽度。

### 5.2 两套仪器必要且原因即结果

- 速率控制压板 → **夹持端磨蚀崩落**（最大子体 0.99 父体），不是冰块断裂
- 拉伸断裂（spall） → **对半分**（两个子体 d/√2），是真正的冰块断裂
- 物理结论：压板加载的应力集中导致边界效应，不能用于校准 FSD 核

### 5.3 分辨率限制

- 格点间距 0.03 m 为子体尺寸下限，大格点产生更多单节点碎屑
- 子体**数量**不尺度不变（32×16 vs 48×24：5.59 vs 7.14，差 −22%）
- 质量加权统计量可传递（质量中位数残差 2.2%）

### 5.4 阻尼必须关闭

- 键阻尼耗散短波格点噪声远超标称 5% 临界比
- 实测 ζ = 0.02 时阻尼移除 12× 输入功
- 保守格点（ζ = 0）才能闭合能量台账

### 5.5 通量守恒律在动态核不适用

- 离散算子的有效宽度指数 r = 9.357（R² = 0.843），远非 delta 谱假设
- 预测 α = 1 + q + r = 10.23，实测 2.869——离散数值扩散主导
- 如实报告，不做修正

### 5.6 阻力反馈局限

- `broken_ice_resistance` 是**验证面**（非新求解器）：平面视图 DEM + 沉没修正
- 缺失物理：三维沉没效应、动量通量——由 submersion_model 解析修正
- 线性弹簧在穿透增大时过刚（3× 高估），挤压限制律修正

### 5.7 适用范围

- 2D 中心力格点：无弯曲力矩，绝对强度和表面能为模型数
- 仅指数和比值传入群体平衡
- 风险率仅对承载冰块测量（脱落碎片不能断裂），q 和 ν_ref 为碎冰场下界
