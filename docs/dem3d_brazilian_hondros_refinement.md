# 巴西劈裂（Hondros）验证欠账第二单：加密不能让判定收敛，因为判定量本身不可定义

本单结清 `docs/dem3d_brazilian_hondros_closure.md` §5 留下的唯一未做项：

> 局限：未做晶格分辨/接触弧加密扫描（recipe 已写进 §6），故"加密后能否进 15%"未知。

**结论先行（honest）：`加密后能否进 15%` 这个问题不可回答——不是"能"也不是"不能"，
而是该判定量（`|x|,|z| ≤ D/10` 窗口的键维里应力均值）在 30–52% 的幅度上依赖于一个
从未被物理论证的自由参数（平均体积）。容差 ±15% 小于该自由参数的摆幅，所以
PASS/FAIL 可以由换一个窗口任意翻转。闭单把 `D/10` 当既定窗口、把 FAIL 归因于
"格点各向异性"，其结论方向不为错，但**置信度被高估**：同一份平衡态，换个窗口就能"过"。
本单把这条判据降级为 WITHHELD（判据不成立），并给出可执行的替代判据。**

同时本单反向确认了闭单的根因一：Born 弹性常数的 Zener 各向异性 `A = 2.3333` 与
`ν` 在 N=15/20/25/30 上**逐位相同**，即它是材料属性、尺度不变，加密确实动不了它。

---

## 1. 案例介绍（物理背景 / 几何 / 参数表）

巴西劈裂（diametral compression）是岩石与冰的标准间接拉伸试验：圆盘在上下压板间沿
直径受压，理想点载荷解（Hondros 1959 / ASTM D3967）给出中心拉应力
`σ_t = 2P/(πDt)`、主应力比 `σ_zz/σ_xx = -3`。DEM 试件是**中心力（仅法向）键合球柱体**，
它是不是一个各向同性连续体，正是要验的东西。

几何在整个扫描中**严格不变**（几何相似设计）：`D = 0.30 m`、`t = 0.06 m` 固定，
只改晶粒数 `N`（跨直径），晶粒半径 `r = 0.15/N`，厚度向 `ny = t/(2r) = 0.2N`
保证厚度恒为 5 个晶粒、颗粒各向同性。`N = 15` 逐位复现 manifest 原算例
（`r = 0.01 m, ny = 3`，由测试钉住）。

| 参数 | 值 |
|---|---|
| manifest 算例 | `tensordem-dem3d-brazilian-v1 / brazil_elastic_field` |
| 几何 | `cylinder_xz` 键合球柱体，`nx = nz = N`，`ny = 0.2N` |
| 试件直径 D / 厚度 t | 0.3000 m / 0.0600 m（**恒定**） |
| 晶粒半径 | `0.15/N` m（N=15/20/25/30 → 0.010/0.0075/0.006/0.005 m） |
| 颗粒数 | 447 / 1104 / 2205 / 3888 |
| 键刚度 / 压板刚度 | 2000 N/m / 5000 N/m |
| 无量纲行程 `travel/D` | 2.3638e-3（恒定，= 闭单的 7.0913e-4 m / 0.30 m） |
| 求解 | 静力能量最小化（L-BFGS + 20 段载荷连续化），残差 `|F|_inf/h² ≤ 1e-4 Pa` |
| 基准 | Hondros (1959) / ASTM D3967：`σ_t = 2P/(πDt)`，`σ_zz/σ_xx = -3` |
| 容差 | `centre_tension_rel_tol = 0.15`，`centre_principal_ratio_tol = 0.15` |

## 2. 怎么做的（方法 / 流程 / 关键设置 / 工具链）

两条互不依赖的测量，都复用闭单已验证的求解器（`scripts/brazilian_lattice_static.py`，
其 numpy 力场与引擎 `forces()` 逐点一致，误差 <1e-10）：

1. **分辨率扫描** `scripts/brazilian_hondros_refinement.py`：对 N = 15/20/25/30 各求
   一次静力平衡（同一无量纲行程），报告中心场、主应力比、张力误差、沿加载直径散布，
   并同时算出该键集在同一格点上的 Born 弹性常数。**N=15 必须逐位复现闭单**
   （`-2.0149` / `+30.4507%` / 散布 `8.829`），实测复现成功，故扫描锚定可信。
2. **估计量收敛诊断** `scripts/brazilian_hondros_estimator.py`：**只求解一次**，
   把同一个已松弛构型在 11 个不同的平均半宽 `w/D ∈ [0.02, 0.25]` 与 7 个
   直径条带 `a/D` 上重新测量。每个窗口同时给出均值、逐颗粒标准差 `σ` 与标准误
   `SEM = σ/√n`。这一步把"随窗口变化（系统）"与"抽样噪声"分开：
   若窗口间摆幅 ≫ 2·SEM，则摆幅是系统的；若在噪声内，则任何窗口都不可信。

关键设置：两者都跑静力解而非显式 ramp。理由沿用闭单：静力解是 `t→∞`、无阻尼极限，
残差 1e-7 量级，因此"没平衡够"这一解释已被排除，剩下只能谈判据与材料。

> **规模坦白**：本机 load15 全程 ≥100（曾达 328，nproc=128，他席并发），按容量纪律
> 只做轻量活。故分辨率扫描止于 N=30，N=35/40 未跑；`N=30` 单点 57 s 已接近
> 调度窗上限。这不影响结论：误导性不在"点不够多"，而在 N=15 就会翻脸（见 §3.2）。

## 3. 计算结果

### 3.1 分辨率扫描（D、t、行程全固定，只改晶粒数）

| N | 颗粒 | 中心窗颗粒数 | 接触弧比 | 中心 σ_xx [Pa] | 中心 σ_zz [Pa] | σ_zz/σ_xx | 主应力比误差 | 张力误差 | 沿直径散布 | Zener A |
|---|---|---|---|---|---|---|---|---|---|---|
| 15 | 447 | 27 | 0.0669 | 155.590 | -313.496 | **-2.0149** | 32.84% | **+30.45%** | 8.829 | 2.3333 |
| 20 | 1104 | 64 | 0.4457 | 497.184 | -1365.724 | -2.7469 | 8.44% | **-15.90%** | 12.671 | 2.3333 |
| 25 | 2205 | 125 | 0.0401 | 240.793 | -487.476 | **-2.0245** | 32.52% | **+25.89%** | 6.729 | 2.3333 |
| 30 | 3888 | 216 | 0.3580 | 773.668 | -1898.794 | -2.4543 | 18.19% | **-4.23%** | 16.945 | 2.3333 |

三件事一眼可见：

* **误差不单调**：`+30.5% → -15.9% → +25.9% → -4.2%`。一个正在被"加密解决"的
  离散误差应当形如 `O(h^p)` 单调趋零；这不。所以要么物理没在收敛，要么测量没在收敛。
* **散布不降反升**：沿加载直径 `σ_xx` 的相对散布 8.83 → 12.67 → 6.73 → 16.95，
  而分析解在该直径上是**常数**。散布比均值本身大一个量级，说明单颗粒应力场是强涨落的。
* **Zener A = 2.3333 四位不变**，`C12 = C44`（Cauchy 固体，残差 0.0）。中心力格点
  的 `A = C44/((C11-C12)/2) = 7/3` 是刚度比值，与 `h` 无关 —— 这是"加密动不了根因一"
  的算术证明。

### 3.2 估计量收敛诊断（一次求解，多种测量体积）

以 **N=25**（噪声最低、小窗口仍含颗粒）为例，只改平均半宽 `w/D`：

| `w/D` | 颗粒数 | 中心 σ_xx [Pa] | 主应力比 | 张力误差 | SEM/|均值| |
|---|---|---|---|---|---|
| 0.02 | 5 | 252.248 | -1.9214 | **+31.88%** | 8.80% |
| 0.05 | 45 | 248.582 | -1.9539 | +29.96% | 2.67% |
| **0.10**（闭单窗口） | 125 | 240.793 | -2.0245 | **+25.89%** | 1.64% |
| 0.15 | 245 | 227.930 | -2.1465 | +19.16% | 1.29% |
| 0.20 | 495 | 199.811 | -2.5196 | **+4.46%** | 1.34% |
| 0.25 | 845 | 148.336 | -3.1902 | **-22.45%** | 2.13% |

`w/D = 0.10` 落在 **FAIL**（+25.9%），`w/D = 0.20` 落在 **PASS**（+4.5%），
`w/D = 0.25` 甚至翻到负侧。这是**同一份平衡态**，唯一变量是一个从未被论证的窗口。

三分辨率的系统摆幅 vs 抽样噪声：

| N | 锚点误差 (`w/D=0.10`) | SEM | 窗口系统摆幅 | 2·SEM 噪声带 | 摆幅/噪声 |
|---|---|---|---|---|---|
| 15 | +30.45% | 3.70% | **47.32%** | 25.82% | 1.83 |
| 20 | -15.90% | 2.69% | **32.38%** | 10.58% | 3.06 |
| 25 | +25.89% | 1.64% | **52.41%** | 5.35% | 9.80 |

抽样噪声随 N 按 `1/√n` 正常下降（3.70 → 2.69 → 1.64%），但**系统摆幅不降**
（47 → 32 → 52%），摆幅/噪声从 1.8 涨到 9.8。即：不是"点太少"，是**窗口均值本身
随体积系统性变化**，且变化幅度常驻在容差之上。N=15 时噪声带（25.8%）本身就已超过
15% 容差，连 N=15 的 FAIL 都不能算数。

**补充诊断（否掉一个看似自然的替代判据）**：Hondros 张力沿整条加载直径是常数，
所以"取整条直径条带的 `σ_xx` 均值"看似更自然。实测 N=15 条带均值
`σ_xx = 0.014 Pa`，即基准 `119.271 Pa` 的 **0.012%**（误差 -99.99%）。原因是条带均值
把中心拉区与两个加载点附近的强压区（点载荷解在其处奇异）几乎完全抵消，端部奇异
被离散接触分辨掉后净和趋零。所以该判据也**不可用**——不是模型错，是这个平均量与
Hondros 的"常数"陈述不指向同一个量。本单如实记录，不做粉饰。

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

* **坑：把"平均体积"当常量写死。** `D/10` 是线性尺度，含 `0.1D/(2r) = N/20` 个晶格
  间距：N=15 时窗口只有 1.5 个间距、N=25 时 2.5 个。同一 `w/D` 在不同 N 下**不是
  同一个物理平均体积**。这正是固定 `w/D` 的误差序列必然非单调的原因，也是闭单
  "加密没帮助"印象的直接来源。任何应力窗判据都必须以**晶粒数**归一，而非以 D 归一。
* **坑：处理器/格点对齐。** N 为偶数时颗粒位于 `±h/2`，`|x|,|z| ≤ 0.02D` 的小窗口
  可能一个颗粒都没有（N=20 实测 n=0）。N 为奇数时颗粒恰在对称轴上，中心窗口直接
  落在单个颗粒上（N=15 时 `w/D ≤ 0.06` 三个窗口给出**完全相同**的 3 颗粒读数）。
  奇偶差异是 σ_xx 在 N=20 跳到 497 Pa、N=30 跳到 774 Pa 的一部分来源。
* **坑：先修判定框，再怪物理。** 本席一开始以为会看到"误差单调下降但停在某个平台"，
  结果先看到的是非单调——这时正确动作是去查估计量，而不是继续加分辨率。用一个
  不收敛的尺子量东西，加密只是买更贵的错误。
* **局限一：分辨率只到 N=30。** 受容量纪律约束（load15 ≥100），N=35/40 未跑。
  但 §3.2 在 N=15 就已证明判据失效，加密再多也救不回一个不可定义的量。
* **局限二：仍是弹性静力解，无断裂。** 本单不涉及裂纹扩展路径、不断言强度值。
* **局限三：未与真实验/文献数据集对照。** 只有解析基准（Hondros 点载荷）。
  有限接触弧的 Hondros 修正解本单未实现——因为一旦证明"中心应力依赖于平均体积"，
  引入更精细的参考值也无法修复判据，属无效投入。
* **适用范围**：结论只针对"用键维里应力窗口均值判中心场"这一验证方法，不否定
  DEM 算出来的位移场、载荷 P、以及 `2P/(πDt)` 这个恒等式本身（后者定义上精确）。

## 6. 误差判定（逐项显式回答是否 <3%）

| 关键量 | 基准 | 误差 | 是否 <3% |
|---|---|---|---|
| 分裂应力定义 `2P/(πDt)` | 解析恒等式 | <1e-12 | **是** |
| 两板载荷平衡 | 牛顿第三定律 | 9.4e-11 | **是** |
| 静力平衡残差 | 0 | 9.30e-08 | **是** |
| N=15 锚点复现闭单值 | 闭单 155.590 Pa / -2.0149 | <1e-3 相对 | **是** |
| 中心主应力比 `σ_zz/σ_xx` | -3（Hondros） | 32.84%（N=15）/ 18.19%（N=30） | **否** |
| 中心拉应力 `σ_xx` | `2P/(πDt)` | 30.45%（N=15）/ 4.23%（N=30，但非单调） | **否（不可判）** |
| 沿加载直径均匀性 | 0（点载荷解） | 883% → 1695% | **否** |
| **判据本身**：窗口摆幅 | 应 ≪ 15% | **32%–52%** | **否** |

**honest verdict：本单不给"通过/不通过"，给"判据不成立"。** 具体地说：

1. 闭单 `FAIL（结构性）` 的方向性归因（中心力格点非各向同性，`A=2.3333` 尺度不变）
   **成立且被本单强化**（Zener 四位不变、Cauchy 残差 0.0）。
2. 但把 `+30.45%` 当作"物理偏差的定量值"**不成立**：同一平衡态在 `w/D=0.20` 给出
   `+4.5%`。因此 `中心拉应力误差` 一项既不能判"是"也不能判"否"，正确分级是
   **WITHHELD（判据不可定义）**，而非 FAIL。
3. `N=30` 恰好落入容差（-4.23%）**不是收敛证据**——序列非单调，单点入带不构成
   收敛；脚本的自动判定已强制要求单调性，故输出 `NON-MONOTONE` 而非"通过"。

**可执行的替代判据（建议，任一即可解悬）**：

* **A. 判据改造（推荐）**：应力窗以**晶粒数**归一（如 `±4h`，`h=2r`），并附一张
  该窗口的 `SEM/|均值|` 收敛表；同时把"窗口敏感性"本身作为验收项（要求
  `摆幅 < 容差`），即先证明尺子够硬。
* **B. 换基准**：用该键集的**各向异性连续体解**（Born 常数 `C11/C12/C44` 已知，
  `A=2.3333`）作参考，而非各向同性 Hondros。这需要一笔 2D 各向异性弹性 BVP 求解，
  属另一单。
* **C. 换量**：放弃"中心点应力"，直接判**位移/变形**（位移场无窗口平均问题）
  或判**载荷-行程刚度**，后者与 `E` 只有一个标定常数之遥。
