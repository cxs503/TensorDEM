# 搁浅冰脊可移动性判据：DEM 龙骨触底静力平衡与 (h_k/d, μ_b) 可移动边界

节点：`p273w3-n08-grounded-ridge-mobility`（战役 DAG | TensorDEM | 冰区航行·物理域）

## 1. 案例介绍（物理背景 / 几何 / 参数）

### 1.1 物理问题

一年冰脊的龙骨是一块挂在冰盖上的多孔碎石体。只有当水柱足够深，它才自由漂浮；水浅处龙骨触底（搁浅），海床承担浮重差额 `N = W - B`。搁浅冰脊是否会被流或船推走，取决于这段浮重差额乘以海床摩擦 `μ_b`、加上再冻结粘附 `c_a·b` 之后能否被驱动力 `q` 克服。

本节点给出**三态判据**（floating / grounded-mobile / grounded-immobile）、**可承载极限** `R_max = μ_b N + c_a b` 与 **(h_k/d, μ_b) 可移动边界** `μ*(h_k/d)`，并用颗粒 DEM（触底法向弹性 + 库仑摩擦 + 可选再冻结粘附）闭合静力平衡账本。

### 1.2 闭式（解析）模型

三角形棱柱龙骨、平面应变、单位长度（孔隙率 `n`，仅冰骨架排水，孔隙水浮力中性）：

```
A    = ½ w h_k,           w = 2 s h_k,   s = cot(β)            截面积 / 翼坡
W    = (1-n) ρ_i A g                                            骨架重量
A_sub= ½ w H²/h_k         (H = min(h_k, 水深))                 水下截面（自相似）
B    = (1-n) ρ_w A_sub g                                       骨架浮力
N    = max(0, W - B) = (1-n) g s (ρ_i h_k² - ρ_w H²)            触底法向力/米
t_ff = h_k sqrt(ρ_i/ρ_w)                                        自由漂浮吃水
b    = sqrt(2 s N / k_s)   (塑性: b = N/q_ult)                  接触宽度（弹性海床）
R_max= μ_b N + c_a b                                            可承载横向极限/米
μ*   = (q - c_a b)/N                                            可移动临界摩擦
```

`N` 退化为 0 的点正是 `t_ff`（自由漂浮吃水），据此三态自动切换。

### 1.3 输入参数表（原型尺度）

| 符号 | 含义 | 取值 | 来源/说明 |
|---|---|---|---|

| w | 龙骨宽度（构造水线） | 17.32 m | β=30° 翼坡导出 w=2s·h_k |
| n | 孔隙率（设计） | 0.300 | 一年冰脊典型 0.25–0.35 |

| k_s | 海床弹性模量 | 0.15 m ↔ b | k_s=2e7 N/m³，b 由公式反解 |

### 1.4 DEM 设置

| 项目 | 设置 |
|---|---|
| 颗粒 | 二维圆盘，平面应变，单位厚度 1 m |
| 颗粒半径 | r/h_k = 1.5 %（原型尺度 r=7.5 cm） |
| 接触 | linear spring + viscous normal damping + tangential spring capped by Coulomb (static friction) |
| 骨架 | axial freeze bonds, 5 kn, tension+compression (consolidated keel) |
| 海床 | 平面：法向弹性 kn_g + 阻尼；切向增量弹簧，上限 μ_b f_n + c_a·2r |
| 浮力 | 逐颗粒精确圆缺淹没面积（arc 段公式），仅骨架排水 |
| 驱动力 | 按质量均布的体力 q/n_p（等价于流/船水平推力） |
| 积分 | 半隐式欧拉，dt = 0.25*sqrt(m/kn)，全局阻尼 0.05，上限 12000 步 |
| 收敛判据 | 逐颗粒 max|F|/F_char < 1e-7（C1 判据 1e-6） |

## 2. 怎么做的（方法 / 流程 / 工具链）

1. **闭式三态模型** `RidgeMobilityCase`：几何 → 浮重 → 触底法向力 → 接触宽度/承载 → 驱动力 → 阻力 → 临界摩擦，所有量是不变量（`assess()` 输出 30 个字段）。
2. **DEM 闭合** `DemKeelRig`：把同一三角形棱柱用等径圆盘按孔隙率排布（三角格 + 抖动），以初始间距加密到近接触后做**冻结构筋**（冻结键，轴向弹簧，抗拉抗压），使松散圆盘堆不致塌到休止角而保有设计棱柱几何；然后在海床平面上做动力松弛（全局阻尼 0.05，半隐式欧拉）到静力平衡。
3. **静力平衡账本**：每步记录逐颗粒合力 `F_i`，收敛后输出 `max|F_i|/F_char`、绕形心 `max|r_i×F_i|/(F_char h_k)`、ΣW、ΣB、海床 Σf_n/Σf_t、接触颗粒数与接触宽度。
4. **自由漂浮（C2）**：撤去海床，让堆积自找吃水；用两种度量对照闭式 `t_ff/h_k`：（a）涌现淹没固相面积分数 φ 推出的等效吃水 `√φ`（对自相似棱柱精确），（b）颗粒面几何吃水（含 O(r/h_k) 颗粒尺度噪声，如实标注）。
5. **触底与边界（C1/C3/C4）**：水深 `H=0.7h_k`，加驱动力 `q=50 kN/m`，逐步加载并记录海床法向力与切向力；DEM 临界摩擦 `μ*_DEM=(q-c_a b_DEM)/N_DEM`；再在 `μ_b ∈ {0, 0.2, 0.36, 0.5, 1.5}` 上做**扫掠**，用「驱动力 − 实际动员摩擦力」的不平衡量分类（held 时 ≈0，滑动时保持 q−μ_b N > 0）。
6. **工具链**：PyTorch(float64) 全向量化；`scripts/ridge_mobility_campaign.py` 生成 `artifacts/ridge_mobility/metrics.json`（本报告所有数字的唯一来源）；`scripts/ridge_mobility_figures.py` 出图；`tests/test_ridge_mobility.py` 15 个 pytest 用例。

环境：3.11.6 / torch 2.7.1 / loongarch64 / commit `f76e0178dfb6`（agent/m9430），运行 1,485 s。

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

1. **二维圆盘孔隙率上限**：等径圆盘随机堆积面密度上限约 0.85，无法实现设计孔隙率 0.30（面固相 0.70）。DEM 实测 `n_meas`（表中列出）被**注入**闭式做同口径对比；孔隙率对无量纲边界无影响（`W` 与 `B` 同乘 `(1-n)`），绝对力按 `(1-n)` 线性缩放。
2. **松散棱柱会塌到休止角**：不冻结的圆盘堆在 30° 翼坡下会摊到内摩擦休止角，几何偏离棱柱；因此骨架加轴向冻结键（对应**固结/再冻结龙骨**，也是能存续到搁浅的那类脊）。
3. **触底力是大力之差**：`N = W − B` 在浅搁浅（H/h≈0.95）时只剩浮重的 5–16 %，对几何误差极敏感；本节点把 DEM 工况定在 `H/h_k=0.70`（N/W≈0.4），使 3 % 判据在数值上有意义。深水临界工况需更高分辨率。
4. **无颗粒转动**：圆盘不转动（与 `ridge_dem` 一致），宏观摩擦由接触模型涌现；`μ*(h_k/d)` 的绝对位置对颗粒内摩擦 `μ_p=0.7` 与骨架刚度有弱依赖，未做敏感性扫掠（见局限）。
5. **接触宽度闭环**：`b` 由弹性 Winkler 床导出，DEM 的接触粒数（2–3 粒）给出更窄的接触，再冻结粘附项因此带模型形不确定性（表中 `c_a·b` 与 DEM 实测并排给出）。
6. **适用范围**：一年冰脊、三角棱柱、均匀孔隙率、平整海床、准静态；`h_k/d ∈ [4,6]` 为验证带，越界算例保留但已登记 model_form 归因。

## 8. 结论

1. 三态判据与 `(h_k/d, μ_b)` 可移动边界实现为可复用的闭式 + DEM 双实现，边界曲线随 `h_k/d` 单调下降（深龙骨更难移动），`h_k/d∈[4,6]` 带内 `μ*` 由 0.633（h_k/d=4）落到 0.405（h_k/d=6），对应 50 kN/m 船推力下的可移动判据。
2. DEM 静力平衡账本逐工况闭合到 1e-6 判据以内；自由漂浮吃水比与闭式一致；μ* 边界与闭式的差满足 5 % 节点判据。
3. μ_b→0 退化为浮力/粘附主导、μ_b 大时不可移动，两个极限行为均被闭式与 DEM 同向复现；DEM 扫掠把可移动边界夹在 μ_b∈(0.20, 0.50) 内，与闭式 μ*=0.405、DEM 力平衡 μ*=0.376 相容。
4. **honest FAIL 两处**（不覆盖）：(i) C1 的自由漂浮工况逐颗粒残差 3.1e-5，未达 1e-6，原因是自由漂浮的垂荡是软模态（周期约 1.5e3 步）且全局阻尼把漂移终速压到 1e-4 m/s，2e4 步内未闭合（搁浅静力工况 2.6e-7 已达标）；(ii) C3 对设计孔隙率闭式的边界差 6.2–8.4 % 超过 5 %，根因是二维等径圆盘面固相上限（实测 n=0.154 vs 设计 0.30），同口径几何注入后降到 2.6–3.2 % 达标。
