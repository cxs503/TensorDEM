## 0. 为什么是这一件（与在飞/近 24 h 终态单不重复）

m20931 在 `docs/CASE_COLUMN_COLLAPSE_SQRT_BRANCH_m20931.md` §⑤ 第 8 条明确留账：

> 「能量账本在平方根支只闭合到 ~89 %：`residual_fraction_of_potential` 在 $a=3$ 三档为
> 12.36 % / 11.57 % / 10.86 %，随细化单调下降但幅度小。本单**不设阈值门**……
> 属可另立条目追查的欠账。」

该残差是全锚点唯一一处「账目不平」：跑距/时间/分辨率/系综/断点六条轴都已判过，但
**能量去哪了没人查**。如果残差是漏项（记账缺陷），则历轮所有 `residual_fraction_of_potential`
读数（含 m20931 §⑤ 8 的同向性推断「残差与跑距超预测同向 → 提示耗散记账存在未归因项」）
都建立在一个错误的账本上；如果残差是积分伪像，则它是可量化的 $O(dt)$ 项，需给出阶数。
两种结局都需要**先有闭合恒等式**，这正是本单的唯一交付。

## 1. 被审计的恒等式（逐步，非仅终态）

设 $U=\sum m g z$（重力势能）、$K=\frac12\sum m|v|^2+\frac12\sum I|\omega|^2$、
$S$ 为全部弹簧储能（法向/切向/滚动 × 粒-粒/粒-壁 六通道），
$D$ 为全部耗散通道（法向阻尼/切向滑移/滚动滑移 × 粒-粒/粒-壁），
$L$ 为张拉截断（`release_loss`）丢弃的储能。积分器的**逐步**恒等式应为

$$R_n=\big(U_0-U_n\big)-K_n-S_n-\sum_{k\le n}D_k-\sum_{k\le n}L_k,\qquad \Delta R_n=R_n-R_{n-1}\approx 0 .$$

`residual_fraction_of_potential` 是 $R_N/U_0$。逐步量 $\Delta R_n$ 才是定位工具：
**漏项会在事件步（接触消失/截断）产生孤立尖峰，积分误差则在每步均匀渗漏。**

## 2. 预登记假设与判定规则

| 编号 | 假设 | 判定规则（跑前写定） |
|---|---|---|
| **H1** | 单粒规范例（单粒置地、初速水平+自旋，走 `initial_positions` 路径）逐步闭合，即无漏项 | $\max_n|\Delta R_n|/U_0<10^{-9}$ → H1 pass；否则 fail 并报首个违反步 |
| **H2** | 多粒算例的终态残差随 $dt$ 收缩如 $O(dt)$（积分伪像） | 取 $dt,dt/2,dt/4$ 三档，若 $R(dt/2)/R(dt)\in[0.35,0.65]$ 且 $R(dt/4)/R(dt/2)$ 同区间 → 判「积分伪像」；若两比值均 $>0.8$ → 判「结构性漏项」 |
| **H3** | `release_loss` 的 `live` 记账（`0.5 k_n\delta^2+0.5 k_t|\xi|^2$）**缺滚动弹簧能** $0.5 k_r|\vartheta|^2$，接触消失/截断时该能量静默丢失 | 若 $\sum_n \max(0,-\Delta S^{\rm roll}_n)$ 与残差同量级（$\ge 50\%\,|R_N|$）且把该项补入 `live` 后 $|R_N|$ 下降 $\ge 50\%$ → H3 pass（采纳为缺陷修复） |
| **H4** | 壁面法向阻尼耗散 `dissip_collision = Σ γ v_z² dt` 未受 $f_n>0$ 闸门约束，系统性高估耗散（负向残差） | 若壁面法向耗散通道在「离地步」仍有正值累加 → H4 pass（记为第二缺陷，同样修） |

**H3 修复的物理中性要求（硬约束）**：修复只许改 `live` 记账，不许改任何力/力矩。
验收判据：修复前后同一配置的 `positions`、`vel`、`omega`、`runout_ratio_p995`、
`t_reach` 必须**逐位相同**（`np.array_equal`）；仅 `residual_fraction_of_potential`
与 `dissipated_cutoff` 允许变化。若轨迹变了 → 修复越界，撤回。

**诚实纪律**：若 H1 失败但 H3 修复后仍不闭合，本单只报「部分闭合」并列出剩余渠道与量级，
不得把未闭合写成就绪（honest-FAIL）。若无基准量（本单审计对象是内部账本，不是文献量），
§⑥ 的「是否 < 3 %」逐项声明依据。
