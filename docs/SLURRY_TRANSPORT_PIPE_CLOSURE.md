## 1 案例介绍

### 1.1 物理背景

绞吸/耙吸挖泥船的水力输送链是**船舶总体性能里的"生产率"闭环**：

```
颗粒物性 (d50, ρs) → 单颗粒悬浮速度 w_s → 临界淤积速度 V_c → 浓度-压降 i_m(C_v)
      → 泥泵工况点 (Q*, H*) → 轴功率 P_shaft → 生产率 Q_bank [m³/h 土方]
```

每一环都是可用实验/文献裁定的物理判据。本节点的目标不是再写一批经验公式，而是把这条链
**每一环都做成可机器裁定的判据**（A1–A7），并给出**独立的数值裁定器**（L/D=5 周期小段 DEM-CFD）
去裁经验闭合——疏浚工程真正的风险是"用错口径的经验系数"，而不是公式写不出来。

### 1.2 原型算例（设计工况，A4/A5 使用）

| 量 | 符号 | 值 |
|---|---|---|
| 排泥管直径 | D | 0.40 m |
| 管线长度 | L | 800 m |
| 粗糙度 / 局部损失 | ε/D, ζ | 1.0e-3, 5.0 |
| 海水密度/粘度 | ρ_f, μ | 1025 kg/m³, 1.07e-3 Pa·s |

程序算出：**w_s = 0.14937 m/s**、**ρ_m = 1268.75 kg/m³**、**V_c = 3.7102 m/s**（Durand，F_L=1.0520）。

### 1.3 DEM-CFD 验证算例（A6/A7-DEM 使用）

D=0.10 m、段长 L=5D=0.50 m、板宽 W=0.02 m（y 周期）、槽高 H=D/2=0.05 m
（槽水力直径 2H=D，与经验式同口径）、d=4 mm 砂、ρ_s=2650、ρ_f=998.2 kg/m³、μ=1.002e-3 Pa·s、
C_v=0.10 → **N=1512 颗粒**，w_s=0.4429 m/s，V_c=1.597 m/s。

## 2 怎么做的

### 2.1 五环闭合链（`src/tensordem/slurry_transport/`，6 个模块）

| 模块 | 内容 | 关键实现选择 |
|---|---|---|
| `closures.py` | Schiller-Naumann 阻力、力平衡数值反解 w_s、分区闭式、Rubey 对拍、RZ 阻碍 | 数值解=**对数空间二分**（1e-16…1e3 m/s，300 次），残差 <1e-12；分区按**自洽 Re**，不用 Ar 阈值 |
| `critical_velocity.py` | Durand `V_c=F_L√(2gD(S_s−1))`（F_L 表+对数插值）+ Cleanaway 型 `K_c(C_v/0.1)^m√(2gD(S_s−1))`；√D 标度与量纲审计 | F_L/K_c 表**作为数据随仓发布**，带 `provenance` 字段与 `set_durand_fl_table()` 覆盖接口 |
| `pressure_drop.py` | 64/Re、Colebrook 隐式反解、Swamee-Jain/Haaland 独立互裁；清水梯度；**导出式**悬浮附加梯度；Durand 型归约；**经典 Durand 附加梯度**（K=85, m=1.5，带 band） | Colebrook 用 x=1/√f 不动点+半步平均，残差 ~5e-15；导出式 `i_e=C_v(S_s−1)w_s/V·κ` **无拟合常数** |
| `pump_pipe.py` | 管道特性、泵曲线（含转速亲和）、工况点、轴功率恒等式、NPSH、生产率 | 需求曲线 U 形（`i_e∝1/V` 在 Q→0 发散）→ 与泵曲线**两个交点**；扫描取稳定（最高流量）根 |
| `pipe_dem.py` | L/D=5 周期板段 DEM-CFD：接触（线性弹簧-阻尼+库仑切向）、**Gidaspow 阻力**（Ergun 稠密支 + SN×RZ 稀相支）、OU 湍流弥散、**截面解析的载液动量方程** + 对数律壁面函数 | 载液压降由混合物流量约束反解（解对 G 线性→两次三对角解）；Δp/dx 是**实测**量，动量残差 3% |
| `verification.py` | A1…A7 七个裁定面：每面返回"极限/实测/是否通过" | 无硬编码 pass；`run_all()` 汇总门表 |

### 2.2 DEM-CFD 模型边界（显式声明）

**解析**：颗粒-颗粒/颗粒-壁面接触；浮重；局部阻碍阻力；湍流弥散；**载液流向动量**（截面 25 格，
粒子阻力作为动量汇，壁面用对数律函数给出 τ_w=ρu_τ²）；阻力对流体动量汇 → 附加压降。

**闭合（未解析）**：一维+ 剪切面（丢弃流向对流，局部充分发展）；混合长湍流
`μ_t=ρκ²l_m²|du/dz|ε³`（床内阻尼）；OU 弥散 σ=c_t u*、τ_t=0.05H/u*；载液动量按**准稳态**求解
（粘性调整时间 H²/ν_t≈80 s ≫ 颗粒时间尺度 0.1 s）。

**几何**：x、y 周期，z 两道实壁；H=D/2 使槽水力直径=经验式 D；板宽仅 5d（准二维板段），
换来 1500 颗粒量级上足够长的统计窗口。

### 2.3 关键方法选择（第一版到最终版的教训）

第一版把载液速度剖面**给定**为 1/7 幂律。结果：床层无法阻塞水流，床内空隙流速仍等于主流速，
附加压降被高估 **6 倍**（κ=6.4，而滑动床摩擦上界只给 0.066）。改为
**截面解析动量方程 + 流量约束反解 Δp/dx** 后：

* 清水极限（C_v≈0）实测 i_m=0.06593 vs Colebrook 0.06573 → **偏差 0.3%**（载液求解器验证）；
* 有砂时动量残差降到 **3%**；κ 落到 4.7–6.9（床载/跃移，物理上合理）。

### 2.4 工具链与算力

## 5 注意点（踩过的坑，按发现顺序）

1. **Ar 阈值分区会误判**：Ar=14.5<36 判 Stokes，但真实 Re=0.79，Stokes 高估 12.8%（顶掉 A1 的 2% 门）。
   改为"用预测 Re 自洽分区"后误差 1.7e-15。无量纲阈值的等价性只在自相似极限成立。
2. **Rubey 的方向**：惯性极限等效 Cd=4/3>0.44 ⇒ 对粗颗粒是**下界**（−49% @2 mm）；第一版单元测试写反被测试抓出。
3. **DEM 空隙率分箱**：z 分箱薄于 2d 时均匀点阵被解析成单层，ε 报 0.42（真值 0.90），阻力放大 6 倍 → 起手数值爆炸。
4. **阻力显式积分会炸**：RZ 阻碍在密实区放大 1e4 倍 → 半隐式松弛 `Δv=(1−e^{−dt/τ})u_rel`，无条件稳定且反作用力 `mΔv/dt` 保持动量账精确。
5. **载液剖面必须解，不能给定**：给定 1/7 幂律剖面 → 床层无法阻塞水流 → 附加压降高估 **6 倍**。
6. **壁面通量必须用 dz/2**：用 dz 把壁面剪切算成一半，载液压降差 2 倍；另需**准稳态**载液求解
   （粘性调整时间 H²/ν_t≈80 s ≫ 颗粒时间 0.1 s）。
7. **Gidaspow 稠密支必需**：只用 SN×RZ（即使 ε 截断在 0.4）床层阻力小 6 倍，床内空隙流速仍等于主流速，固相阻力高估约 3 倍。
8. **工况点有两个根**：需求曲线 U 形，naive 括区两端同号 → 误报"无解"；必须扫描取稳定根。
9. **中性浮力负控在 DEM 里不成立**：无重力时颗粒仍被切变携带 → 闭式一致口径 9.5% 伪附加梯度；
   阻力功口径 0.41%。负控因此由解析面（结构性 0.0）与阻力功口径共同裁定，另一个口径如实披露。
10. **稳态判断要看漂移**：中性浮力算例 i_e 前后半窗漂移 20.6%，说明 3 s 不够；其余算例 ≤1.2%。

## 6 局限与适用范围

1. **一维+ 剪切面**：丢弃流向对流与流向非均匀（弯管、变径、局部沉积不覆盖）。
2. **混合长湍流 + 对数律壁面函数**：湍流为闭合；床内阻尼用 ε³ 的经验形式，未标定。清水极限与 Colebrook
   偏差 0.3% 说明载液部分可用，但**有床**时的壁面剪切仍是最大的不确定源（实测 τ_w 与 Colebrook 差 1.5–6 倍。
   故 A6 采用"由 Colebrook 在同样液流量下给 i_w"的工程分解，并把另一口径（实测壁面剪切）作为带内敏感性：主算例
   i_e 从 0.171 变到 0.099，即 Durand 偏差从 18% 变到 −53%。）
3. **载液份额定义**：Durand 的 i_e 依赖"清水梯度"取哪条闭式（纯水 μ 还是 Einstein 混合 μ），
   实测两个口径给出 +18.1% / −6.0% —— 25% 的门与这个定义不确定性同量级，判据通过但不宣称为高精度。
4. **DEM 规模**：1512 颗粒、准二维板段（W=5d）、z 向仅 12 个颗粒直径、单算例 3 s。统计窗口短（中性浮力算例未收敛）。
5. **F_L / K_c 表的绝对出处为 WITHHELD 级**：表值随仓发布并带 provenance 与覆盖接口，但本环境无法核对原图读数
   （图表读数带 ±20%）。A3 因而以**结构**（量纲齐次、√D 斜率、两式互裁带）为主张。Durand 附加梯度常数 K 同理
   （band 85–150，K=150 时主算例偏差 44.9%）。
6. **未覆盖**：浆体非牛顿性（黏土/淤泥屈服应力）、管道倾角、砾石破碎、气蚀动态、泥浆对泵性能的降额修正。
   这些是后续节点。
