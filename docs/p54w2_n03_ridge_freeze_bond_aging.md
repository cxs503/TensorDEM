## 1. 案例介绍

冰脊（ice ridge）由浮冰碰撞堆积形成，水下部分称**龙骨（keel）**，深 10–30 m，
由初始无胶结的碎冰块（rubble）构成。龙骨形成后，在低于冰点的孔隙水环境中接触点
发生烧结/冻结，形成**冻结键（freeze bond）**，碎冰体因此逐渐获得黏聚力——
这就是冰脊的"龄期固化"（consolidation）。本节点定量回答两件事：

1. 冻结键生长 `t` 小时后抗拉强度 `σ_b(t)` 有多大、如何随龄期增长；
2. 以这些键为基础，龙骨总阻力 `R_keel(t)` 随龄期增长多少。

| 编号 | 实验事实 | 原文位置 |

## 2. 怎么做的

### 2.1 模型（形式 + 锚定）

```
σ_b(t) = k(S) · σ_n · φ(ΔT) · (1 − exp(−t/τ_g))            (1)
k(S)   = k_w (1 − β·min(S, S_cap))     水中成键（E&S-2）
       = k_dry                        干接触（E&S-1 空气）
φ(ΔT)  = min(1 + (ΔT/ΔT*)^0.5, 4)     ΔT = T_f(S) − T ≥ 0
τ_g    = τ_ref · exp(−S/S_τ) · exp(Q/R · (1/T − 1/T_ref))  (Arrhenius)
T_f(S) = 273.15 − 0.054·S             海水冰点线性折减（Assur 近似）
```

* 时间律形式取烧结饱和律（Timco & Frederking 1990；Mellor 1983）；
* 渐近值 `σ_b,∞` 完全是 E&S 的压力/盐度实验律，从他们 3 min 观察窗**外推到全饱和**，
  再用 `φ(ΔT)` 推广到更冷孔隙水（E&S 实验在 0 ℃ 附近）；
* `τ_g` 的活化能是**声明参数**（不是测量值），选值使 −10 ℃ 下键在数小时饱和——
  与冰脊固化时间尺度一致；
* 键网络形成（bonded fraction）另由 `τ_c = 24 h` 描述：新龙骨无键，完全固化后每个接触都有键。

### 2.2 集成进 `ridge_dem`

`aged_material(material, model, age_s, ...)` 把龄期映射为
`RidgeMaterial(bond_tensile_strength, bond_shear_strength, freeze_bond_fraction)`，
即 `ridge_dem` 的键强度与键密度都由老化律驱动。验证分两层：

1. **键元层（精确可证）**：两根圆盘单键，在指定拉伸位移下半静态求力
   （`RidgeAssembly.forces(dt=None, update_memory=False)`），检验
   `(1∓10⁻⁶)·σ_b A/k` 处键"存活/断裂"，断裂力误差 ~10⁻¹⁰；
2. **网络层**：`generate_keel_assembly` 在 5 个龄期生成的键数随龄期单调增长。

### 2.3 龙骨阻力

```
R_keel(t) = μ · W' + χ · σ_b,shear(t) · φ_b(t) · A_c          (2)
W' = (ρ_w − ρ_i) g (1 − n) H²/2   （单位脊宽浮重，不随龄期变）
μ  = tan φ_0 = 0.2515            （DEM 双轴单元 t→0 无键试件实测摩擦角 14.12°）
χ  = Δc_DEM / σ_b,shear = 7.94 kPa / 21.30 kPa = 0.373   （DEM 微→宏黏聚传递，实测）
A_c = H · 1 m                     （需剪断的接触面积/单位脊宽）
φ_b(t) = 1 − exp(−t/τ_c)          （键网络占比）
```

`t = 0` 时 `σ_b(0)=0`、`φ_b(0)=0`，故 `R_keel(0) = μ W'`：**退化为无键龙骨阻力**。

## 5. 注意点（踩过的坑与局限）

1. **原文自相矛盾：σ_n = 450 Pa 还是 3.8 kPa**。E&S 正文 p. 401 说 Fig. 11/12 的法向压力
   是 450 Pa，而 Fig. 11 图注写 3.8 kPa。模型按**正文**取值：留出误差 12–14 %。
   若按图注（3800 Pa）复算，3 条平台数据的误差变成 **864 % / 855 % / 855 %**
   （`study.json → validation_caption_variant`，判据 `caption_variant_pass = false`）。
   判据在于：图注读数会与作者自己的 Eq. (6) 相差一个量级，故正文读数是自洽的——
   这一取舍与两种读数都已落盘，未作粉饰。
2. **`cite` 与 `withheld` 的边界**：`k_w`、`k_dry` 是标定参数（各锚 1 条数据），
   其余 8 条为留出；因此 §3.2 的 14.11 % 是**留出误差**，不是自证。
   活化能 Q、硬化 φ(ΔT)、κ=0.5、τ_c 均为声明参数，仓库内无 −10 ℃ 实验序列可比 → 证据级 WITHHELD。
3. **DEM 体元探针分辨率不足（否定结果，入账）**：
   - 双轴单元对 kPa 级键力只有 +1.6 % / −4.5 % 的峰值偏应力响应（两围压档符号相反），
     且 50 kPa 档伺服围压控制误差达 150 %（`confining_error = 1.50`），
     只有 150 kPa 档控制良好（0.0017）；
   - 速度驱动平板压入的"峰值"实为惯性瞬态（0.4–0.5 MN/m），准稳态值随龄期
     14.30 → 6.79 → 3.19 → 29.85 kN/m **非单调**，属碎体混沌重排。
   结论：在 `ridge_dem` 现有微观参数（k=10⁷ N/m 罚接触、μ=0.55）下，
   **体元尺度无法分辨 E&S 量级（kPa）的龄期效应**；键元尺度可以（误差 10⁻¹⁰）。
   要让体元也分辨，需软化接触刚度或改用速率无关的驱动——超出本节点范围，已记为能力缺口。
4. **无键双轴试件的"黏聚力"是假象**：c(0) = 67.4 kPa（无任何键）说明无旋转圆盘试样
   在 10 % 应变内并不满足 Mohr–Coulomb 直线；因此 χ 只能用**增量** Δc 定义，
   不能用绝对 c。这一点与 `ridge_dem` 自带的 `calibrate_rubble_strength` 文档口径一致。
5. **适用范围**：均一温度/盐度、无热梯度、无排盐、无融化/蠕变损伤（只增不减）；
   E&S 实验仅到 4 min 与 0 ℃ 附近，向 −10 ℃、240 h 的外推由式 (1) 的形式与声明参数承担，
   不是实测外推。
6. **与 P54-W2-N04 的区分**：N04 已有指数饱和律 + Lindqvist 总阻力（无实验锚、无盐度、
   无 DEM 集成）；本节点新增的是 **E&S 实验锚定与留出验证**、**盐度/冰点折减耦合**、
   **`ridge_dem` 材料老化接口与键元精确性证明**，以及**体元分辨率否定结果**。

**结论**：判据 (a)–(d) 全部机器通过（`criteria_all_pass = true`）；
但"σ_b,∞ vs 实验 < 3 %"**不成立**（12–14 %）——这是 E&S 自身 Eq. (6) 与平台实测值的
系统差，模型把它如实保留而不是用拟合消掉。R_keel 的**形状**（随龄期单调、t=0 退化）
由已验证的律确定，**幅值**由 χ 的不确定度支配，已给出敏感性带。
