## 1. Case

A single sphere settles from rest in a quiescent fluid. The reference solution is the closed-form solution of the *linear* (Stokes-drag) particle equation of motion with added mass and buoyancy,

`m_eff dv/dt = (m_p - rho_f V_p) g - 3 pi mu d v`, `v(t) = v_t (1 - exp(-t/tau))`,

`v_t = (rho_p - rho_f) g d^2 / (18 mu)`, `tau = (rho_p + C_a rho_f) d^2 / (18 mu)`. Note `v_t` is independent of `C_a` — added mass delays the approach but does not move the asymptote.

| parameter | value |
|---|---|
| d | 3.0000e-05 m |
| rho_p | 2500.0 kg/m^3 |
| rho_f | 1000.0 kg/m^3 |
| mu | 1.0000e-03 Pa s |
| g | 9.80665 m/s^2 |
| C_a | 0.50 |
| v_t (closed form) | 7.354987e-04 m/s |
| tau (closed form) | 1.500000e-04 s |
| Re_t | 0.0221 |

## 2. Method

* **Baseline**: closed-form solution above, derived by hand (independent of the solver's own drag closure).

* **Integrator A**: forward Euler, the scheme used by the published case (`tensordem.two_way_coupling.particle_ode.integrate_particle`).

* **Integrator B**: new exponential (linearly implicit) integrator `integrate_settling_exponential` — freezes the drag rate `k = a_drag/(u_f - v)` over a step (secant estimate from one predictor probe, so it is exact at the first step where `u_f - v = 0`) and advances with `v_{n+1} = v_inf + (v_n - v_inf) e^{-k dt}`. Both integrators drive the **same** force assembly, so closures are unchanged.

* **Linear-limit case** (`d = 3 um`, `Re ~ 1e-5`): the Schiller–Naumann correction `0.15 Re^0.687` is < 1e-4, so the closed form is a rigorous baseline.

* **Estimator**: `tau_fit = -sum(t)/sum(ln(1-v/v_inf))` over the points with `v < 0.9 v_inf`, identical to the estimator used by the published case. For the exact discrete decay this returns exactly `-dt/ln(1-dt/tau)`.

## 5. Notes / limits

* The residual (`1.07e-02`) of the exponential integrator against the *linear* closed form equals the Schiller–Naumann correction `0.15 Re_t^0.687 = 1.09e-02` at `Re_t = 0.0221`: the residual is the drag closure, not the time scheme.
* Forward Euler is stable for the drag term only while `dt < 2 tau`; for micron-size particles `tau ~ d^2` shrinks fast, so DEM-CFD runs with a stiff drag channel need either much smaller `dt` or an exponential/L-stable advance.
* The published terminal-velocity gate (1.07 % vs Stokes) is *not* affected by this finding — the terminal velocity is a fixed point and is integration-error free. Only the *transient/relaxation* number was mis-attributed to physics.
* Domain-free: no ship/ice constants; the case pool supplies the parameters.
