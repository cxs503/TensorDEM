## 1. 案例介绍

`tensordem.moving_plane_boundary.MovingPlaneNetwork` 是控制体冰网络（`BoundaryNetwork`）
的可选"移动工具"边界：一条以 C2 五次多项式 `smooth_plane(t)` 从 `x = L` 压入网络的平面，
用于代替船体对冰网络的作用。它在 `moving_step()` 里维护两个能量/动量账本：

- `tool_work`：执行器对网络的功，按步首/步末罚函数端点力均值 × 平面位移累积；
- `tool_impulse`：`-mean_force · dt` 累积。

物理背景：船体压入冰层的做功必须与网络储能、动能守恒，否则阻力/能量审计（冰区阻力的
主要输出之一）会带系统性偏差。此前**没有任何参考值**：`tests/test_moving_plane.py` 只检查
`tool_work > 0`、重启一致性，以及 `energy + U_pen - tool_work < 1 %`（且只在 300 步、未走完
升压段的窗口内成立）。

| 参数 | 值 |
|---|---|
| 网格 | `nx × ny = 8 × 2`（方形网络，`dx = dy = 0.125 m`） |
| 节点 / 自由度 / 自由自由度 | 27 / 54 / 48 |
| 域 | L = 1.0 m，H = 0.25 m，厚度 t = 0.1 m |
| 材料 | E = 1.0e5 Pa，ρ = 900 kg/m³（中心力弹簧，ν = 1/3 等效） |
| 罚刚度 | `penalty = 50 E / L = 5.0e6 N/m`（作用在 3 个右端参考节点的 tributary 面积上） |
| 时间步 | `dt = 4.314178e-4 s`（模块自定 0.15 × 临界） |
| 平面行程 | `δmax = 1.0e-3 m`（C2 升压 + 保持） |

## 2. 怎么做的

网络是**线性中心力弹簧**（`e = (u_j − u_i)·n`，法向冻结），罚接触是一次型 gap 的二次项，
因此冻结活动集后总势是二次型，可以**精确求解**：

```
(K + P) u = −P (x − plane)        ⇒ u 对 plane 仿射
F_plane(plane) = Σ_i P_i (x_i + u_i − plane)   ⇒ 对 plane 仿射
W_static(δ) = 0.5 · F(δ) · δ = U_spring(δ) + U_pen(δ)   ⇒ 闭式
```

`K` / `P` 由模块自身的 `edges / k / n / penalty / areas` 组装（不是另写一套模型），并用
Jacobian 一致性把参考模型钉在引擎力律上。非自治系统的能量平衡（平面位置是显式时间参数，
固定支座不做功）为 `W_tool(t) = ΔKE + ΔU_spring + ΔU_pen`。

流程：A 参考模型一致性 → B 罚律/面积/罚能量代数 → C 静力仿射性与 `dU/dδ = F` 热力学一致性
→ D 升压时间扫描（准静态收敛阶）→ E 时间步细化（求积收敛阶）→ F 冻结网络极限（求积精确性）。

## 3. 计算结果

**A/B/C 精确恒等式（对解析解）**

| 检查 | 参考 | 实测 | 相对误差 |
|---|---|---|---|
| 组装 K 复现 `forces()`（内部弹簧力，随机 u） | −K u | 5.55e-17 N（量级 0.597 N） | **9.3e-17** |
| tributary 面积和 | H·t = 0.025 m² | 0.025 m² | **0（精确）** |
| 罚律逐节点力 `F_i = P_i·gap_i` | 解析 | 引擎 | **0（精确）** |
| 罚能量 `U_pen = ½Σ P gap²` | 解析 | 引擎 `forces()[3]` | **0（精确）** |
| 非加载方向 / 非右端节点外力 | 0 | 0 | 0 |
| 静力 `F(δ)` 仿射性（7 个 δ∈[1e-5,1e-3]） | 常数刚度 | 30.55 kN/m，散布 1.0e-10 | **1.0e-10** |
| `F(δ=0)` | 0 | 0.0 | 0 |
| `dU/dδ = F`（相邻静力解差分） | F | 差分 | **5.0e-11** |
| 闭式功 `½F(δ)δ` vs 储能 `U_spring+U_pen` | 1.37531e-3 J | 1.37531e-3 J | **2.1e-12** |

**D 升压时间扫描**（`W_exact = 1.375306e-3 J`，`dt = 0.5 dt_crit`）

| 升压时间 T [s] | `W_tool` 相对误差 | 能量平衡残差 `(W−E)/W_exact` | KE / W |
|---|---|---|---|
| 0.05 | +3.75e+00 | −1.05e-04 | 2.03 |
| 0.10 | +1.55e+00 | −2.96e-05 | 0.140 |
| 0.25 | +7.996e-02 | −9.94e-07 | 7.33e-03 |
| 0.50 | +3.169e-04 | −1.95e-09 | 1.77e-04 |

准静态收敛拟合斜率 **−6.83**（T ∈ [0.25, 2] s）；能量平衡恒等式在**最快**升压（T = 0.05 s）
下也只有 **1.0e-4** 相对残差——即账本在任何升压速度下都闭合，残差来自无阻尼振铃，不来自记账错误。

**E 时间步细化（T = 0.5 s 固定）**

| 子步数 | 步长 [s] | `W_tool` 相对误差 | 平衡残差 |
|---|---|---|---|
| 1 | 4.314e-04 | +3.169e-04 | −7.80e-09 |
| 2 | 2.157e-04 | +3.169e-04 | −1.95e-09 |
| 4 | 1.079e-04 | +3.169e-04 | −4.88e-10 |

而不是求积误差——这正是准静态极限需要用 T 扫描而不是 dt 细化的原因。

|---|---|---|---|
| `tool_work` | 5.25000e-4 J | 5.25000e-4 J | **4.1e-16** |

## 5. 注意点与局限

- **未发现缺陷**：本单是对已合并功能的验证欠账清偿（把 2 个测试的"自洽"升级为"对解析解"），
  不是修复单；`tool_work` / `tool_impulse` 与罚律代数均正确。
- **未覆盖的物理**：给定升压速度下 `W_tool` 本身包含无阻尼振铃贡献（T = 0.5 s 时 +3.2e-4），
  这是网络无阻尼的物理属性，不是账本误差；真实冰网络有接触阻尼，此处未建模。
- **罚刚度随 E 缩放**：`penalty = 50E/L` 与网络刚度同为 E 量纲，因此**不存在 E→∞ 的刚体极限**
  （本单曾误设该检查，已删除并在 JSON 中改记 `C_stiffness_share`）。罚刚度占右端 x 自由度
  总刚度的绝大部分（见 JSON），故平面力 ~ 罚刚度 × 穿透。
- **动态 `tool_impulse` 的 WITHHELD 已结清**（见 `docs/dem3d_moving_plane_dynamic_impulse.md`）：
  对引擎实际积分的同一线性模型求模态闭式解并解析积分，接触完整工况（T ≥ 0.25 s）引擎账本
  与解析值吻合到 3.5e-07 ~ 1.3e-08；快速升压（T ≤ 0.1 s）因振铃脱开接触、线性参考越界，
  已显式标注而不计入达标读数。
- **适用范围**：二维控制体网络（线性中心力弹簧、小应变、冻结法向），不是三维键合 DEM；
  结论不外推到 `IceDEM3D` 的接触/滚阻路径。
- **平衡残差阶 1.34 < 2**：半步速度（velocity-Verlet 变体）在端点力求均值时对能量平衡只给出
  介于 1 与 2 之间的收敛阶，属已知的求积阶损失，未在本单修改数值格式。
