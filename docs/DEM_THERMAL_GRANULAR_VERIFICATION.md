## 1. 案例介绍（物理背景 / 几何 / 参数）

### 1.1 (a) 颗粒链接触热传导

两个弹性冰球受压接触，Hertz 接触斑半径

```
a_c = (3 F R_eff / (4 E*))^(1/3),  R_eff = R/2,  E* = E / (2(1-ν²))
```

热量穿过接触斑时受**收缩热阻**（Carslaw & Jaeger 点热源经典解，两块同性半空间圆形等温接触斑）：

```
R_c = 1 / (4 k a_c)          [K/W]
```

球体内部（两对面接触斑之间）按长度为 `2R`、截面 `πR²` 的杆件计体积热阻：

```
R_s = 2R / (k π R²) = 2 / (π k R)
```

于是 N 球链的**解析串联热阻**为 `R_chain = (N−1) R_c + N R_s`，稳态温度场为分段线性、在每个接触面跳变 `q R_c`，`q = ΔT / R_chain`。由于 `R_c / R_s = π R / (8 a_c)`，在典型 `a_c/R ≈ 0.04` 时收缩热阻约为体积热阻的 10 倍，链的等效导热率

```
k_eff / k = R_s / (R_s + R_c) = 1 / (1 + π R / (8 a_c))
```

比固体导热率低一个量级——这正是冰/颗粒堆积床低导热率的物理根源（与 `tensordem.thermal.packed_bed` 的 Zehner-Schlünder / Krupiczka 结论一致）。

参数表（`ChainCase` 默认值，冰）：

| 量 | 值 | 量 | 值 |
|---|---|---|---|
| 球数 N | 8（稳态）/ 8（瞬态） | 半径 R | 5.0 mm |
| 每球单元数 m | 4 | 接触力 F | 20 N |
| 导热率 k | 2.2 W/(m·K) | 密度 ρ | 917 kg/m³ |
| 比热 c_p | 2050 J/(kg·K) | E / ν | 9.0 GPa / 0.31 |
| T_hot / T_cold | 272.15 / 252.15 K（稳态） | Hertz 斑 a_c | **1.960×10⁻⁴ m** |

派生量（`thermal.json:contact_law`）：`R_c = 579.7 K/W`、`R_s = 57.9 K/W`、`R_c/R_s = 10.02`、
`R_chain = 4520.9 K/W`、`q = 4.424×10⁻³ W`、`k_eff/k = 0.0908`。

### 1.2 (a2) 冰键热–力耦合门

冰键（冰–冰/冰–钢胶结）强度受**蠕变限制**：Glen 定律 `ε̇ = A σⁿ exp(−Q/RT)` 在固定应变率下反解给出

```
σ(T) = σ_ref · exp[(Q/(nR)) (1/T − 1/T_ref)],  Q = 60 kJ/mol, n = 3, σ_ref = 1.0 MPa @ −10 °C
```

即同样载荷下**高温（接近融点）的冰键更弱**（0 °C 时约为 −10 °C 的 71.6 %）。门（gate）的问题：一端加热的颗粒链，中间接触上的冰键在什么时刻/什么热端温度下失效？`σ_ref` 绝对量级为 CALIBRATED（冰胶结强度 0.5–1.5 MPa 区间），只有温度**形状**参与判据。

### 1.3 (b) 颗粒柱坍塌与 µ(I) 流变

矩形槽内干颗粒柱（初始长 `L0`、高 `H`，长宽比 `a = H/L0`）在粗糙底板上释放，最终堆积形态由 `a` 通过幂律控制。文献锚（本次逐字核对，见 §5 溯源）：

* **轴对称**（Lube, Huppert, Sparks & Freundt, JFM 508, 175–199, 2004，摘要原文）：
  `a < 1.7: r∞ = r_i (1 + 1.24 a)`；`a > 1.7: r∞ = r_i (1 + 1.6 a^{1/2})` → **指数 1/2**；
  `t∞ = 3 (h_i/g)^{1/2}`。
* **二维矩形槽**（Lajeunesse, Monnier & Homsy, Phys. Fluids 17, 103302, 2005）：
  `ΔL/L0 ∝ a`（`a ≲ 3`，**指数 1**）、`∝ a^{2/3}`（`a ≳ 3`）；Lube et al., PRE 72, 041301, 2005 给出 2D 相伴结果（`a ≈ 1.8` 分界）。

本实现跑**二维矩形槽**，因此与 Lajeunesse 的 2D 指数对标（Lube 2004 的 ½ 为轴对称，仅作几何对照）。

数值设置（`CollapseCase`，全部 case 共用）：宽 12 粒 × 高 `a·L0`，`R = 12.5 mm`（`L0 = 0.30 m`），
`ρ = 2500 kg/m³`、厚度 0.03 m、`k_n = 3.0×10⁴ N/m`、恢复系数 0.5（ζ = 0.216）、
`µ_s = 0.40, µ_2 = 0.75, I_0 = 0.30`（Jop 律）、`µ_roll = 0.10`、`g = 9.81 m/s²`，
时间步 `Δt = 0.1/ω_contact`（≈ 5.5×10⁻⁵ s），最大 45000 步，停止判据「流动动能衰减到自身峰值的 1 %，连续 500 步」。
粒子数 288（a = 1）～1440（a = 5）；最大重叠率 ≤ 1.7 %（软接触有效性内）。

µ(I) 闭合：每步由**实测**速度剖面（8 个 y 分箱、中心/前向差分取最大剪切率）与**实测**底板法向力
（`Σ f_n,wall /(足迹宽 × 厚度)`）计算 `I = γ̇ d / √(P/ρ_p)`，再取 `µ(I) = µ_s + (µ_2−µ_s)/(1+I_0/I)`
作为该步所有接触的摩擦系数（**平均场**闭合，逐接触局部 I 需要引擎接受空间变化的摩擦系数，列为扩展项）。

## 2. 怎么做的（方法 / 流程 / 工具链）

### 2.1 热传导链（两条独立路径）

1. **离散算子 A（网络求解）**：节点式 1D 网络——每球 `m` 个体电阻（`kA/h`）串联，相邻球的两个界面节点之间用收缩热阻
   `1/R_c` 连接（界面节点重复计数，符合物理：收缩发生在两个表面之间）；两端节点 Dirichlet 固定；
   `scipy.sparse.linalg.spsolve` 解稀疏方程组。
2. **解析式 B（闭式）**：`R_chain` 串联求和 + 分段线性温度走查（`analytic_chain_temperature`）。
3. **2D 推广**：`n_x × n_y` 方格节点网络（等值链 `R_link`）与闭式 `R = (n_x−1)/n_y · R_link` 对标；
   另加纯解析校验「温度场只是 x 的函数」。
4. **瞬态**：同一 RC 网络的隐式 Euler（算子 LU 只分解一次并缓存），参考解取**同一算子**的矩阵指数
   （`scipy.linalg.expm`，Dirichlet 节点消元）——这样比较只暴露时间离散误差；再用 3 个 dt 测收敛阶；
   另把最慢模态与连续体板 `τ₁ = L²/(π²α_eff)`（α_eff 用链的堆积热容）对比。
5. **冰键门**：解析路线 = 闭式 `T_bond(T_hot)` 线性关系 + 对 `σ(T)=F/A_bond` 二分求临界温度 + 精确 RC 瞬态求失效时刻；
   模拟路线 = 隐式 Euler 逐步推进 + 每步判定 `σ(T_bond(t)) ≤ F/A_bond`；两条路线之差即门的结果。

### 2.2 颗粒柱坍塌（DEM + 账本）

1. 在既有 `tensordem.granular2d.engine.DiskSystem`（Hertz-Mindlin + 法向阻尼 + Cundall-Strack 切向 + 滚动阻力，cKDTree 邻域）
   之上搭建**闸门式释放**：底板 + 后墙，柱体初始静止格子排布，之后自由坍塌（不改变引擎任何一行代码）。
2. 每步按 §1.3 的实测 I 更新 `µ`（`DiskConfig` 为 frozen dataclass，用 `dataclasses.replace` 换新配置）。
3. **runout 定义与敏感性**：x 方向按粒径分箱，箱内**局部堆积高度**达到
   `k·d`（k = 0.5/1/2/3/4）才算「堆积」，取首个连续 3 空箱之前最后一箱的右边界为趾部（`deposit_front`）。
   二维圆盘会抛出孤立远粒，原始最大 x 完全不可用（本次 a = 2 的原始 max/L0 达 31），故必须做高度过滤；
   k 的敏感性在 §3.3 给出。
4. **势能–耗散账本（前向测量，非恒等式）**：每步显式求一次接触状态，按接触级第二定律

   ```
   D = max(0, −(W_contact + ΔE_elastic)),   W_contact = Σ f·v_{k+1}·Δt
   ```

   累积，其中 `ΔE_elastic = Δ(k_n ov²/2) + Δ(f_t²/2k_t)`（+ 开启滚动阻力时的 `Δ(k_r roll²/2)`），
   接触按稳定 key（`i·n+j`；墙 `n²+idx`）跨步匹配，消失的接触其储能记为归零。
   `W` 用位置更新实际使用的速度 `v_{k+1}`（半隐式 Euler 下位移即 `v_{k+1}Δt`），与弹簧压缩一致，
   避免 O(Δt) 系统偏差（改用 `v_k` 时闭合误差 3.8 %，改 `v_{k+1}` 后 1.4 %）。
   机械项 `E_pot, E_kin, E_elastic` 独立测量，闭合误差 = `|E_pot(0) − (机械项 + D)| / E_pot(0)`。
   滚动阻力在账本 case 中关闭（引擎未在接触记录中暴露滚动弹簧功，见 §5 局限）。
5. **计算**：`run_cluster`（外协方双节点 loong64，128 核/节点）单节点 13 进程并行，13 个 case 墙钟 ≈ 4–5 min；
   工件由 `fetch` 取回 worktree。全部结果可复现：相同 seed → 相同 `state_digest`（测试覆盖）。

工具链：Python 3.11 / numpy 2.0.1 / scipy 1.17.1 / matplotlib 3.10.8；集群节点 numpy 2.0.1、scipy 1.17.1（loong64）。

## 3. 计算结果

### 3.1 判据 (a)：颗粒链稳态温度 vs 解析解（门槛 5 %）

| 量 | 数值 | 相对量 |
|---|---|---|
| max\|T − T_analytic\| | **7.96×10⁻¹² K**（跨度 20 K） | 7.96e-12 / 20 = **3.98×10⁻¹³** |
| 热流（场测得 vs 闭式） | 4.4238926×10⁻³ W | 相对差 1.1×10⁻¹³ |
| k_eff（场测得 vs 闭式） | 0.22530700255 vs 0.22530700255 | 相对差 1.0×10⁻¹³ |

**判据 (a) 通过**（远优于 5 %）。必须说明：1D 网络能**精确表达**分段线性解析解，因此这项验证考的是
「接触律 + 网络装配 + 求解器」的正确性，而非空间离散截断误差（后者在 2D 方格与瞬态项考核）。

瞬态（同一算子 vs 矩阵指数）：dt = τ/500, τ/1000, τ/2000 时最大相对误差
`2.78×10⁻⁴ → 1.39×10⁻⁴ → 6.94×10⁻⁵`，**收敛阶 1.0002 / 1.0001**（隐式 Euler 一阶，符合预期）。
最慢模态 `τ = 3236.9 s`，连续体板 `τ₁ = 3606.9 s`，偏差 **10.3 %**（集中参数阶梯 vs 连续体，作为诊断项报告，非门槛）。

### 3.2 判据 (a2)：冰键热–力耦合门（门槛 5 %）

`F = 0.042 N`、`A_bond = π(0.1 mm)² = 3.142×10⁻⁸ m²` → 应力 **1.337 MPa**；
键位于第 1 个接触（距热端 20.5 % 的串联热阻处）。冷态（`T_hot = T_cold = 253.15 K`）键温 253.15 K、
强度 1.435 MPa（安全）；热端升到 −0.5 °C（272.65 K）时键温 268.65 K。
临界键温 `T_bond,crit = 255.05 K`（σ = 1.337 MPa）对应热端 **`T_hot,crit = 255.54 K`（温升仅 2.39 K）**。

| 路线 | 失效时刻 |
|---|---|
| 解析（闭式剖面 + 精确 RC 瞬态二分） | **111.84 s** |
| 模拟（隐式 Euler 逐步判定） | **111.37 s** |
| 相对差 | **0.42 %** |

**门通过**（< 5 %）。物理上成立：键强度随同系温度升高而下降（0 °C 强度 = −10 °C 的 71.6 %），
热端升温 → 键温上升 → 承载力跌破外载 → 失效。

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

1. **判据 (a) 的「精确」是结构性的**：1D 网络可精确表示分段线性解，故 4×10⁻¹³ 的相对误差不代表空间收敛性好，
   只代表接触律/装配/求解正确。真实几何（2D/3D 随机堆积）需要 `packed_bed` 那类场算子与两道算子互检。
2. **收缩热阻公式的适用面**：`R_c = 1/(4 k a_c)` 是「等温圆形接触斑 + 其余绝热」的半空间经典解；
   真实冰–冰接触有界面粗糙度/准液层，`interface_thermal` 里的 CMY 模型（`contact_heat_transfer_coefficient`）
   才覆盖压力–粗糙度效应。本模块明确只取理想 Hertz 斑 + 收缩热阻。
3. **`R_s` 是「等截面杆」近似**：忽略了接触斑附近的扩散热阻；若需要 `a_c/R ≪ 1` 的高阶修正，应换
   Cole–McGaw/球内球谐解，登记为扩展项。
4. **runout 的量测定义对结果影响极大**：二维圆盘坍塌会抛出孤立远粒（原始 max/L0 可达 31），
   必须做高度过滤；不同阈值给出 p = 1.11…1.40。因此「实验 vs 模拟」的比较**必须声明趾部判据**，
   本文把 5 个阈值的敏感性全列出。
5. **本模拟与实验的流态差异（判据 b 失败原因）**：a) 二维圆盘无形状咬合（滚动阻力 µ_roll = 0.1 只是代理），
   b) 颗粒数 288–1440 远小于实验 ~10⁵（有限尺寸使表层占比过高），c) µ(I) 是**平均场**闭合，
   实验流层内的局部 I 空间分布被抹平。三者都使床面更易流动（ΔL/L0 偏大约 29 %，且未出现 a^{2/3} 分支）。
6. **账本残差 3 % 的来源**：不是时间离散（dt 减半不变），而是接触事件记账（接触生成/消失、
   引擎摩擦锥截断时切向弹簧状态重整）。已用「消失接触储能归零」处理，仍有 ~3 % 残差；
   小规模 case（6000 步、40 粒）0.24 %，说明残差随接触事件数增长。
7. **滚动阻力未进入账本**：引擎把滚动弹簧状态留在私有属性（`_state_roll`），
   本模块尽力映射后仍见 6.9 % 差距（a = 1.5 小 case），故账本 case 关闭滚动阻力；
   扫描 case 用 µ_roll = 0.1 作为形状代理。这是**已知限制**，不粉饰。
8. **平均场 µ(I) 的适用范围**：I 由 8 个 y 分箱的速度剖面最大剪切率与底板压力估计，
   对「薄流层/分层流」会低估局部 I；准静态极限（I→0）退化为 µ_s，符合 Jop 律但无法表达
   界面附近 µ 的空间竞争。
9. **可复现**：相同 `seed` 与配置下 `state_digest` 完全一致（测试覆盖）；集群与本地 numpy/scipy 版本一致，
   但集群为 loong64 架构（与 GitHub CI x86 不同），判读浮点末位时需注意。

## 6. 误差判定（逐项给出「是否 < 3 %」）

| 关键量 | 基准 | 误差 | < 3 %？ | 判据 |
|---|---|---|---|---|
| 链稳态温度场 | 闭式串联/分段线性解析解 | **3.98×10⁻¹³**（相对跨度；绝对 7.96×10⁻¹² K） | ✅ | (a) 门槛 5 %：**PASS** |
| 链热流 / k_eff | 闭式 `R_chain`、`k_eff/k` | 1.0×10⁻¹³ | ✅ | 同上 |
| 2D 方格网络两面热阻 | `(n_x−1)/n_y·R_link` | **5.7×10⁻¹⁵** | ✅ | — |
| 瞬态（隐式 Euler） | 同算子矩阵指数 | 6.9×10⁻⁵（τ/2000） | ✅ | 收敛阶 1.000 |
| 最慢模态 τ | 连续体板 `L²/π²α` | **10.3 %** | ❌ | 诊断项（集中参数固有），非门槛 |
| 冰键失效时刻 | 解析（闭式 + 精确瞬态） | **0.42 %** | ✅ | (a2) 门槛 5 %：**PASS** |
| runout 指数（默认趾部 2d，a≤3） | Lajeunesse 2005 2D p = 1 | **21.3 %** | ❌ | (b) 门槛 10 %：**FAIL** |
| runout 指数（任一颗粒趾部） | 同上 p = 1 | **11.4 %** | ❌ | 同上，最好情形仍 FAIL |
| runout 绝对值（a = 2） | Lajeunesse `ΔL/L0 ≈ 2` | **+29 %**（2.583） | ❌ | 参考量级对照 |
| 势能–耗散闭合（a = 2, 45k 步） | 前向实测 D vs 势能释放 | **3.04 %** | ❌ | (c) 门槛 2 %：**FAIL**（小 case 0.24 % PASS） |
| 惯性数扫描 I 跨度 | — | I_mean 0.051–0.060（g 跨 16×） | — | 无基准，声明原因：无对应实验 |

**是否 < 3 % 的显式回答**：(a) 与 (a2) 是「是」（10⁻¹⁴ 与 0.42 %）；(b)、(c) 是「否」（21.3 %/11.4 % 与 3.04 %），
且已在 §5 给出失败归因；`τ` 与 runout 绝对值的 10.3 %/29 % 也如实超 3 %。
