第 2 轮（m20304）判 FAIL 的原因是**控制**而非物理：侧向伺服的限速要么大到撞墙、要么小到没有权力（实测围压 30× 设定值）。本轮把伺服整个移出测量回路，改用**定容剪切**（DEM 文献的标准临界状态试验），于是「应力路径是否被边界条件污染」这个问题被结构性消除。结论随之变得可读：**测得的 φ_cv 远低于 Rowe 的二维理论极限，误差 50 %**。这不是数值失误，而是一个对本算例池 ref 选择的**否定性结论**（§5.3）。

## 1 案例介绍（物理背景 / 几何 / 参数）

平面应变双轴压缩：无胶结圆盘组件置于四面刚性墙，顶板位移控加载，侧墙在固结阶段伺服到 σ₃，剪切阶段改为**运动学定容**（宽度与高度之积不变）。物理量：`sin φ = (σ₁−σ₃)/(σ₁+σ₃)`（c=0，无黏聚）。

| 量 | 值 | 说明 |
|---|---|---|
| 颗粒 | 2D 圆盘 r = 0.75 m，ρ = 917 kg/m³ | 与 case 池其余算例同材料族 |
| 试样 | 24 × 48 抖动三角格（jitter 3 %） | 锚点尺寸，同 CASE-DEM-BIAXIAL-CELL-KNOWN-ANGLE |
| 接触 | kn = 1×10⁷ N/m，kt/kn = 0.5，μ = 0.55 | 无胶结 `freeze_bond_fraction = 0` |
| 墙 | 摩擦 0（OSS 常规：侧墙无剪牵引） | 保证侧向读数是纯法向应力 |
| 固结 | 4000 + 6000 步各向同性 100 kPa | 侧向伺服 |
| 剪切 | ε̇_a = 0.01 s⁻¹，Δt = 4.97×10⁻⁴ s，120 716 步，ε_a 到 0.451 | 惯性数 **I = 1.44×10⁻³ ≪ 0.01**（准静态） |
| 边界 | **定容**：V = W·H = const | 伺服在剪切开始时释放 |
| 基准（预声明，沿用第 2 轮，先于本轮任何运行固定） | Rowe 1962 D=0：φ_cv = arctan μ = **28.81°**；对照 Bolton 1986：33° | 容差 8 %（算例池） |

## 5 注意点（踩过的坑 / 局限 / 适用范围）

**5.1 小应变体变和不是等体积判据。** 精确定容时 `ε_a + ε_lat`（工程应变）在 ε_a = 0.05 处已给出 −0.0025 的假体变，到 ε_a = 0.3 会到 −0.13；用它做闸门会把完美定容的路径判成「持续压缩」。必须用对数测度：`ln(H₀/H) + ln(W₀/W) ≡ 0`（本轮实测 3×10⁻⁶）。

**5.2 伺服被结构性移除，但代价是 k₀ 不见了。** 定容下侧向应力是输出（100 → 245 kPa），p 不再恒定；因此摩擦角只能用应力**比**定义（本文件即如此），且 `servo_on_target` 闸门被替换为 `lateral_walls_loaded`（σ_h > 0）。这是边界条件变更后**物理上必须**的替代，已在跑之前写死在代码与判据模块里。

**5.3 50 % 的偏差不是数值误差，是 ref 选错。** 二维圆盘滚动无阻力（本引擎无滚动摩阻），宏观临界摩擦由「滑动 + 滚动」共同承担，可动用的 sinφ_cv = 0.247 只有颗粒摩擦 μ = 0.55 的 ~0.45 倍。Rowe 的 D=0 极限 `φ_cv = arctan μ` 是**三维有咬合/转动受阻**材料的结论，把它当成二维圆盘组件的临界角基准，是把形状效应当成了数值误差。第 2 轮在方法学上否掉了 38° 的 Bolton 反解，本轮在数值上否掉了 28.81° 的可达性 —— **本算例池条目缺一个「二维圆盘」语境的合法基准**（见 §7 建议）。

**5.4 临界状态接近但未到。** q 相对漂移 11.1 % 超过 5 % 闸门：φ 在 0.20–0.30 段 12.9°、0.30–0.40 段 16.1°、0.40–0.45 段 14.4°，仍在 2–3° 振幅内摆动（剪切带形成后的局部化 + 有限试样涨落）。所以 14.31° 的**数字本身**应读作 `φ_cv = 14.3 ± 1.5°`，而不是 0.01° 精度的定论；但相对于 28.81° 的 14.5° 差距远大于这个不确定度，**否定性结论不受影响**。

**5.5 本轮只落盘了 5 个分片中的 1 个。** cj2765 在 51 min 时仍 `running`，取回的工件只含 `anchor_24x48_mu055_p100`。分辨率（16×32）、颗粒摩擦（μ=0.30）、围压（200 kPa）、应变率（ε̇=0.005，其积分步数翻倍）四个敏感性工况的结论**尚不可写**，不预判、不用外推。

**5.6 适用范围。** 二维平面应变、无胶结、圆盘、无滚动摩阻、无黏聚（c=0）；`wall_friction = 0` 是 OSS 常规设定，若改为粗糙侧墙需重测（第 1 轮曾记录粗糙墙把 φ 拉低 5.3° 的剪牵引偏置）。
