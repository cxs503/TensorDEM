# 二元颗粒床分凝（bidisperse segregation）验证面 — P70-N03

**状态（honest）：实现完成、单元测试通过、生产规模物理验证 FAIL。**
本文件记录已建成什么、测到什么、为什么没通过判据，以及下一步的修法。
判据数字见 `artifacts/p70n03/acceptance.json`，逐案结果见 `runs/p70n03/*.json`。

## 1. 物理背景与目标

二元球床在竖直振动下会自发改性分凝：大颗粒上升到自由面（巴西坚果效应），
细颗粒在每次振动的膨胀相里向下渗流。同样机制在重力倾倒成堆时表现为粗颗粒
沿坡面滚到外缘。本节点的目标是**证明 TensorDEM 能自发产生分凝（而非参数注入）**，
并输出可被稳性/结构侧消费的货堆形态量（分区质量矩 → ΔTCG / ΔGM / 底板压力峰值）。

仓库原有的颗粒内核 `tensordem.granular3d_core` 是**单分散**的（`Material3D.radius`
全局单值，`build_pairs` 用固定半径），无法表达二元床，因此新建了
`tensordem.bidisperse_segregation`（逐颗粒半径的接触内核 + 两种驱动 + 可测量分凝指数）
与 `tensordem.segregation_stability`（分区质量矩 → 稳性量的闭式映射与审计）。

## 2. 方法

### 2.1 接触内核（`src/tensordem/bidisperse_segregation.py`）

* 法向：线性弹簧-阻尼 `F_n = max(k_n δ - γ v_n, 0)`，`γ = 2ζ√(k_n m_eff)`，
  `ζ = |ln e|/√(π²+ln²e)`（与 `granular3d_core` 同一约定）；
* 切向：Cundall–Strack 增量弹簧，饱和于 `μ F_n`；逐对状态用**排序键 + searchsorted**
  向量化保存（避免 dict/逐对 Python 循环）；
* 滚动：速率受限滚动弹簧，饱和于 `μ_r r_eff F_n`；
* 壁面：地板（可动）+ 四周侧壁 + 顶盖，均为平面摩擦接触，逐颗粒增量切向状态；
* 邻域搜索：按半径分类用各自截止半径（细-细、粗-粗、粗细交叉），
  候选对数量与真实接触数同量级（单用 `2 r_max` 会膨胀 `(r_max/r_typ)³`）；
* 刚度由**目标静载侵入量**（`OVERLAP_TARGET = 2 % r_small`）反推：
  `k_n = ρ_b g H (2r_s)² / (0.02 r_s)`，`dt = 0.06 t_c`（软球 DEM，见 §5 局限）。

### 2.2 构型与驱动

| 项 | 取值 |
|---|---|
| 尺寸比 `d_l/d_s` | 1.0（等径负控）、1.5、2、3、4 |
| 粗颗粒体积分数 | 0.2、0.4 |
| 构型 | `box3d`（三维盒）、`quasi2d`（深度 1.15 d_l 的单层球板） |
| 颗粒数 | 设计 2×10⁴–1×10⁵；**实际可用 4×10³**（见 §4） |
| 振动 | `Γ = Aω²/g ∈ {1,1.5,2,2.5,3}`，`f ∈ {15,25,40,60} Hz`，30 个周期 |
| 倾倒 | 顶部喷嘴冻结注入后释放建堆 |

### 2.3 分凝指数

* `S = (f_coarse,top − φ_coarse)/φ_coarse`，顶层 = 自由面下 20 % 床高，
  以**体积分数**计；节点文本里的细颗粒写法等价于
  `S_fine = −φ/(1−φ)·S`（同时输出 `S_thin`：自由面下 3 d_l 的薄层变体）。
* `v_up`：粗颗粒质心相对全床质心的上升速度（末段 40 % 时间窗最小二乘斜率），
  `rise_per_cycle = v_up/f`。
* 稳态窗口取末段 40 %，报均值 ± 标准误。

### 2.4 稳性/结构传导（`src/tensordem/segregation_stability.py`）

床被读成 `n_x × n_z` 分区质量矩表，闭式给出

```
M = Σ m_b ,  KG_c = Σ m_b z_b / M ,  LCG_c = Σ m_b x_b / M ,  ρ_b = M / V_box
A_FS = Σ_i l_i B √(1+s_i²) ,  I_FS = A_FS B²/12 ,  s_i = |dh_i/dx|
ΔGM = −ΔKG_c·M/Δ + (−λ_grain ΔI_FS/Δ)      (λ_grain = 0.12, CALIBRATED)
Δtrim = −ΔLCG_c/L_hold
```

每个闭式量都与一次独立求和（逐颗粒直接求和 / 分区求和）对拍，审计误差落 JSON：
这是验收判据 (e) 的机器可算形式。底板压力按 x 分条记录时间序列，输出峰值、
峰值/静压比与总载荷平衡误差。

## 3. 结果（N = 4×10³，30 周期；44/59 例成功）

```
尺寸比扫描（Γ=2, f=25 Hz, φ=0.2, 3 seeds）
 s=1.0   S = -0.073, -0.020, -0.001     ← 负控（应 |S|≤0.02）
 s=1.5   S = -0.273, -0.389, -0.329
 s=2.0   S = -0.558, -1.000, -0.674
 s=3.0   S = +0.471, -0.349, +0.208
 s=4.0   S = +0.322, +0.057, +0.068
Γ 扫描（s=2, f=25 Hz）: S = -0.692, -0.618, -0.697, -0.618, -0.618  (Γ=1…3)
```

关键观察（均为**逆向**结果）：

1. **粗颗粒不上浮而下沉**：s=2 时顶层粗颗粒体积极少（S ≈ −0.56…−1.0），
   与巴西坚果效应方向相反；只有 s≥3 出现正的 S 且种子间符号不稳。
2. **S 对 Γ 与 f 完全不敏感**（同一 seed 下 4 位小数相同）：
   Γ 扫描与频率扫描都没改变床的组态，说明振动**没有有效驱动床体**。
   `A/d_s` 在 Γ=2、f=25 Hz 时仅 0.1（`A = Γg/ω² = 0.8 mm` 对 6–8 mm 颗粒），
   远低于实验/文献常用的 `A/d ≈ 0.5–2`，属于"驱动器太弱"的配置错误，
   而不是分凝物理的否证。
3. 上述两点叠加：初始沉降（`settle`）阶段会先把重的大颗粒压实到底部，
   形成 S(0) ≈ −0.6 的**初态偏析**；随后弱振动几乎不再改组，S(t) 被初态冻结。
4. 质量账通过（相对误差 5×10⁻¹⁵），但部分算例结束时床体出现非有限值，
   导致分区/传导审计出现 NaN（详见 §4）。

`artifacts/p70n03/` 中的图：`fig_S_size_ratio.png`（S 对尺寸比，含 ±0.02 负控带）、
`fig_S_gamma.png`（S 对 Γ，展示无依赖）、`fig_S_time.png`（S(t)）、
`fig_transmission.png`（ΔVCG 与 ΔGM）。

## 4. 未通过项与根因（honest FAIL）

| 判据 | 结果 | 说明 |
|---|---|---|
| (a) 等径负控 \|S\|≤0.02 | **FAIL**（\~0.073 峰值，3 seed 不同） | 4×10³ 颗粒下顶层粗组仅 \~80 颗，统计噪声 σ(S)≈0.1；噪声解释了超限，但按判据如实记 FAIL |
| (b) S 随尺寸比严格单调 + 指数 p | **FAIL** | S 非单调且多为负（粗沉）；p 无从拟合 |
| (c) 质量守恒 ≤1e-9、质心加权一致 | 部分通过 | 质量相对误差 5×10⁻¹⁵ ✔；质心/分区审计在部分算例 NaN ✘ |
| (d) Γ_c ±30 % 与 Γ→∞ 饱和 | **FAIL** | S 与 Γ 无依赖，无法拟合阈值/饱和 |
| (e) ΔTCG/ΔGM 闭式 vs 分片求和 ≤1e-6 | 单元测试通过 / 战役算例 NaN | 闭式映射本身在测试床（700 颗）审计误差 <1e-12 |
| (f) 三 seed S 变异系数 ≤15 % | **FAIL** | CV 0.18–3.8 |

**根因 1（阻断级）：N ≥ 10⁴ 时内核在沉降阶段产生非有限位置。**
证据：`scripts/_diag_settle_m7300.py`/`_diag_mode_m7300.py`/`_diag_step_m7300.py`
（N=2×10⁴、s=2、box3d）。已定位的事实：
* 非有限值**优先出现在壁面接触力**（`_wall_contacts` 的 `f_n`/`f_t`），
  粒子对接触力此前都是有限的；此时 `max_overlap = 0`、`v_max ≈ 0.26 m/s`；
* 与摩擦/滚动无关（`mu=0` 依旧复现），与 `dt` 弱相关（`dt` 缩到 1/5 只是把
  失稳步数从 ~200 推到 ~1500），与刚度有关（`k_n = 800` 时 2500 步稳定，
  `k_n = 3206` 时 ~200 步失稳）；
* 同一配置在不同节点上失稳步数不同（200 / 600 / 1200），提示存在
  **读取未初始化内存或依赖数组内容的分支**，而不是纯数值不稳定。
* 已排除：初始侵入（修好 packing 后 `max_overlap = 0`）、粗-粗初始重叠
  （`free()` 空间检查保证）、摩擦/滚动状态饱和（已核对 cap）。
* 尚未定位：`wall_tang` 的逐颗粒增量状态在"某一维无活动接触时整体清零"
  与"逐墙 cap"之间存在状态失配，是最可疑的一处（见 §6 待办 1）。

**根因 2（物理级）：驱动强度与初态。**
`A/d` 太小（0.1–0.3）+ 沉降阶段已发生尺寸偏析，导致 S(t) 被初态支配。
下一轮应：`A/d ≈ 0.5–2`（即用 f = 8–15 Hz 达到 Γ = 2–3），并在沉降阶段
做**反偏析初始化**（用等径床 + 随机标签后缩放半径，或用分层交替构造），
使 S(0) ≈ 0；再把 ΔS = S(end) − S(0) 作为主判据（同时报绝对 S）。

## 5. 适用边界与局限

* **软球 DEM**：`k_n` 由 2 % 静载侵入量反推（N=4×10³ 时 `k_n ≈ 900–1300 N/m`），
  接触时间被放大；无量纲参数（Γ、A/d、尺寸比、体积分数）保持物理一致，
  但接触力峰值、声速类量不可用于定量结论。
* `quasi2d` 是**单层球板**（深度 1.15 d_l），不是真正的二维圆盘系统；
  本战役中该构型全部失败（同根因 1）。
* 壁面滚动阻力关闭（只有壁面摩擦）。
* 顶层厚度取床高 20 %（另报 3 d_l 薄层变体）：4×10³ 颗粒时顶层粗组样本量不足，
  S 的统计噪声 ≈0.1，**负控判据需要 ≥2×10⁴ 颗粒**才有意义（这正是生产规模必须
  修好的原因）。
* 文献锚（`Γ_c ≈ 1–2`、`v_up ∝ (d_l/d_s − 1)^p` 的 p≈1）本轮**未能用**：
  既没有可用的 Γ 依赖，也没有可用的 v_up（均 NaN）。报告不引用未核实的数值。
