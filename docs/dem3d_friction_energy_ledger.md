# DEM3D 能量账本摩擦通道：闭式 stick-slip 对标（验证欠账清偿）

状态：**已清偿**（m3468 报告「局限 2」点名的下一个欠账）。
证据：`tests/test_dem3d_friction_energy_ledger.py`（12 项全绿）+
`scripts/verify_dem3d_friction_energy_ledger.py` + 本目录 JSON/CSV/PNG。

## 1. 欠账

`EnergyAuditedIceDEM3D` 累计拖曳/法向阻尼/工具阻尼/断裂释放，但**没有切向摩擦项**。
`friction_coefficient > 0` 时库仑通道对相对运动做真实功，
`energy_balance_residual_J` 把全部摩擦功静默算成残差——m3468 复核时已点名
（"须给出闭式 ∫ μ|F_n||v_t| dt 的对标"）。

## 2. 修复（最小改动）

- `dem3d.py`：`forces()` 每次调用记录瞬时摩擦功率 `P_f = Σ F_t·v_t`
  （当前状态+存储历史的纯函数，probe 安全，`update_history=False` 不改变它）；
  顺带修一个潜在崩溃：`_alive_bond_for_pairs` 在零键结+有接触候选时
  `IndexError`（空 `_bond_keys` 索引越界）。
- `dem3d_energy.py`：新增 `cumulative_friction_dissipation_J`，
  `step()` 按 `P_f·dt` 累计（与其他 rate 同一 pre-step 约定），进入残差平衡、
  `diagnostics()`、`state_dict()`；旧 checkpoint 缺该键时按 0 加载（向后兼容）。
- 记账口径：`D_f = ∫ F_t·v_t dt`（切向力对的机械功率）。stick 段它等于
  d/dt(½k_t|δ_t|²)（储能），slip 段退化为 μ|F_n||v_t|（真耗散）——两种机制
  下平衡都闭合，因为它是**实际施加力的功率**，不依赖储能/耗散拆分。

## 3. 基准（独立于求解器）

两球子系统（R=0.05 m, m=0.48014 kg, k_n=k_t=5000 N/m, δ_n=2e-3 m,
F_n0=10 N, v_t0=0.1 m/s, μ=0.3）：球 0 固定，球 1 初速纯切向；每步施加跟踪外力
`-k_n·overlap·n` 精确抵消法向接触力，隔离切向子系统。参考轨迹=1-D 律
`m x'' = -k_t x`（stick）/ `-μF_n(x)`（slip），`F_n(x)=k_n(2R-√(d²+x²))`，
RK4×200000 步 + Simpson 积分；stick 段另有精确解 `x=(v_t0/ω)sin ωt`。

## 4. 结果（程序化注入，零手抄）

| 关键量 | 基准 | 实测 | 相对误差 | <3%? |
|---|---|---|---|---|
| stick 段 D_f(T) | RK4 参考 | 2.4199e-03 J | 0.80% | 是 |
| stick 段 D_f(T) | 精确谐波解 ½k_t x² | 2.4007e-03 J | 0.80% | 是 |
| slip 段 D_f(T) | RK4 参考 | 2.3794e-03 J | 0.56% | 是 |
| slip 段切向行程 | RK4 参考 | 1.0895e-03 m | 0.01% | 是 |
| 平衡残差（μ=0.3，含 D_f） | μ=0 对照 -8.71e-07 J | 1.21e-05 J | 相对 0.10% | 是（离散地板） |
| 修复前口径残差 | 摩擦功 2.3794e-03 J | 2.3673e-03 J | 0.51% | 是 |
| dt 收敛（D_f 误差） | 一阶 | 0.56% → 0.27% → 0.12% | 比值 2.11/2.23 | 是 |

**核心结论**：加入 D_f 后 μ=0.3 的残差（0.10%）与 μ=0
对照（-0.01%）同处离散地板；修复前口径的残差
（2.367e-03 J）≈ 摩擦功（2.379e-03 J）——
缺陷与修复都被同一组数字钉住。

## 5. 注意点 / 局限

- 跟踪外力在 pre-step 状态精确抵消法向力，overlap 漂移 O(dt²)；全程几何漂移
  <0.4% δ_n，已含在参考的 F_n(x) 几何修正里。
- 只覆盖**库仑摩擦通道**。滚动阻力通道（mu_r）的功仍未入账（其力对沿滑移
  方向的力偶，功率 = -rr·v_rel），列为后续欠账；本基准 mu_r=0。
- 切向历史仍是 Python 逐对循环（m3468 局限 1，未动）。
- 本单是接触律级解析对标，不是冰力学/船-冰阻力验证。
