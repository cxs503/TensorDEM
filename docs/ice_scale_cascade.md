# 冰模型试验缩尺效应：双尺度级联 + Cauchy 全匹配坍缩判据

模块 `tensordem.ice_scale_cascade` · 驱动 `benchmarks/ice_scale_cascade.py` ·
工件 `artifacts/ice_scale_cascade/`（`summary.json`、`report.md`、`figures/`）·
原始记录 `runs/ice_scale_cascade/cases/*.json`（每例一份，含 `state_digest`）

## 1. 物理问题

冰区船舶的模型试验要在冰池里以 1:λ 的几何缩尺复现实船的破冰/碎冰阻力。把结果搬回实船，
经典说法是**无量纲坍缩**：以碎冰压溃强度 σ_f、冰厚 t、船长 L 为重复变量

    R* = R/(σ_f t²) = f(Fn, Σ, Mod, t/L, φ, μ)
    Fn = v/√(gL),  Σ = σ_f/(ρ_i g t),  Mod = E/σ_f,  φ = 冰密集度,  μ = 摩擦系数

- **P-Cauchy（全匹配）**：所有长度 /λ、v/√λ、σ_f/λ、E/λ ⇒ 六个群全部匹配，R* 应与 λ 无关。
- **P-Froude+强度（工程惯用）**：Fn 与 Σ 匹配，但**模型冰的弹性模量无法自由缩放**，
  `E_m = E_p λ^{-p_E}`（本节点取 p_E = 0.5，另测 p_E = 0 的极端假设）⇒
  `Mod` 失配 `q = λ^{1-p_E}`。
- **P-失配**：在 Cauchy 基础上把 `Mod` 人为偏移 Δ = ±10/20/30 %。

任务要的正是**可证伪**的检验：如果 DEM 在无量纲空间里不坍缩，偏差 δ(λ) 的定量律是什么，
以及它是否能被数值混杂（时间步、接触数、初始场）解释掉。

## 2. 方法

### 2.1 DEM 核（复用仓内既有物理，不新造接触律）

`tensordem.ice_channel.IceChannelSimulation`：平面视图罚函数接触 DEM，浮冰=等厚圆盘
（质量 `m = ρ_i π r² t`），法向 `F_n = k_n·pen − c_n·v_n`（截断 ≥0），

    k_n = 2 σ_c t / √frac,   c_n = 2 ζ √(k_n m),   c_t = 2 ζ_t √(k_n m)（Coulomb 圆锥 μ）

加二阶水阻、升沉/纵倾/艏摇模态、静水浮力平衡初始化。船长 L = 4B、冰盘半径 0.35B、
域 14B×6B、密集度 0.7（=152–158 个浮冰），船体为给定速度的矩形，阻力取
`R = mean(−F_hull,x)` 于预定义稳态窗（艏进 3R、艉离 3R 内）。

**尺度协变性（解析）**：令长度 ×s、σ ×s、v ×√s（ρ、g 不变），则
`k_n pen ~ (s²)(s) = s³`、`c_n v ~ s^{5/2}s^{1/2} = s³`、水阻 `ρ·side·v² ~ s³`、
升沉刚度 `ρ g A_wp ~ s²`（升沉周期 ~√s）⇒ 所有力 ∝ s³，`R* = R/(σ_f t²)` 与 λ 无关。
**这是本节点能用 DEM 做缩尺实验的前提**，也给出了判据的物理基准。

### 2.2 `Mod = E/σ_f` 在 DEM 里的表示（明确的建模假设）

DEM 里唯一的柔度是罚函数穿透比例 `frac`；`k_n` 是弹性接触刚度的数值替身（圆盘面内一级近似
`k_n ~ E t`），于是

    √frac = 2σ_f/(c_E E)  ⇒  frac ~ (σ_f/E)² ~ Mod⁻²

只有比值 `q = Mod/Mod_ref` 有物理含义，锚点取 `frac_ref = 0.05 @ Mod_ref = 5000`
（`REFERENCE_FRACTION`、`REFERENCE_MODULUS_RATIO`）。锚点取 0.05 而非仓内默认 0.01，
是为了让 `Mod` 通道可观测：`frac→0` 时接触趋于刚体，R* 饱和，偏差律会退化为 0。
**这是假设不是定律**，见 §5 局限。

### 2.3 三套协议与数值混杂控制

| 协议 | 长度 | v | σ_f | E | 匹配的群 |
|---|---|---|---|---|---|
| P-Cauchy | /λ | /√λ | /λ | /λ | Fn, Σ, Mod, t/L, φ, μ 全匹配 |
| P-Froude+强度 | /λ | /√λ | /λ | /λ^{p_E} | Fn, Σ, t/L, φ, μ；**Mod 失配 λ^{1−p_E}** |
| P-失配 | /λ | /√λ | /λ | /λ·q | 同上，Mod 失配 q = 1+Δ |

数值混杂被逐一控制（不是假设，是**测**出来的）：

1. **时间步**：`dt = 0.25·0.5·√(m_min/k_n)`，Cauchy 下 `dt ~ √s`，即 dt 自己跟着 Froude 时间
   缩放。**反例检验**：ρ 收敛阶梯 dt_scale = 0.5/0.25/0.125/0.0625。
2. **接触数**：几何相似 + 同种子 ⇒ 浮冰数、`contacts/floe` 与 λ 无关；另有 5 组纯数值扰动
   （初始场抖动 0.02/0.16、种子、dt）测 δ 对接触数的敏感度。
3. **精确协变性（最硬的检验）**：λ 比值为 **4^k** 的两例，所有长度按 2 的幂缩放、
   Froude 速度按 2 的幂缩放（√ 后仍为 2 的幂），二进制浮点**零舍入** ⇒
   结果必须**逐位相同**。比值 2^{奇数} 不满足（√v 引入舍入），故排除。
4. **实现集合**：同工况换初始场种子（4 个实现/工况）测**实现散布**，给出任何单次
   坍缩陈述的数值噪声地板。

### 2.4 设计（39 例，全部预注册在 `design_tasks()`）

Cauchy λ∈{1,5,10,20,40}；Froude+强度 λ∈{5,10,20,40}（p_E=0.5）+ p_E=0 极端假设 λ∈{10,20}；
失配 Δ∈{−0.3,−0.2,−0.1,+0.1,+0.2,+0.3} @λ=10；分辨率阶梯 4 级；接触数扰动 5 组；
实现集合 3 种子 × 4 工况。

## 3. 结果

锚点：λ=1、`frac`=0.05、152 冰盘、4 个实现，**R\* = 0.17643**（s.e. 0.01708）。

### 3.1 判据（机器判定，数字由程序注入）

| 判据 | 结果 | 数字 |
|---|---|---|
| (a) P-Cauchy max\|δ\| < 15 %（全部工况取最佳估计） | **FAIL** | 19.89 % |
| (a-ens) 仅集成均值工况 | **PASS** | 2.60 % |
| (a-exact) λ 比值 4^k 配对须逐位相同 | **PASS** | max 相对差 0.000e+00 |
| (b) P-Froude+强度 \|δ\|~λ 拟合 R² > 0.90 | **FAIL** | R² = 0.663（指数 −0.764） |
| (c) contacts/floe 变化 < 10 % ⇒ \|δ\| 变化 < 5 % | **FAIL** | 16.17 pp（保场子集 dt：PASS，3.02 pp） |
| (d) 分辨率 \|ΔR\|/R < 3 % | **PASS** | 1.40 % |

**实现散布（噪声地板）：19 个实现 / 5 个工况，合并相对标准差 15.7 %**
（逐工况：λ=1 19.4 %、λ=10 21.2 %、λ=20 14.9 %、q=0.7 14.1 %、q=1.3 8.8 %）。

### 3.2 Cauchy 坍缩

| λ | n | R\*（集成均值） | s.e. | δ [%] | 单实现 δ [%] | contacts/floe |
|---|---|---|---|---|---|---|
| 1 | 4 | 0.17643 | 0.01708 | 0 | 0 | 0.0787 |
| 5 | 1 | 0.16139 | – | −8.53 | +11.52 | 0.0777 |
| 10 | 4 | 0.17185 | 0.01818 | −2.60 | −2.33 | 0.0742 |
| 20 | 4 | 0.17453 | 0.01298 | −1.08 | +11.52 | 0.0760 |
| 40 | 1 | 0.14134 | – | −19.89 | −2.33 | 0.0718 |

**精确配对本检验**：λ=10 与 λ=40（比值 4）、λ=5 与 λ=20（比值 4）在**同种子**下
`R*` 完全相同，相对差 **0.000e+00**（`summary.json → exact_covariance`）。
即：**该 DEM 的 Cauchy 协变是精确的**，不是近似的；观测到的 10–20 % 偏差不是物理缩尺效应。

### 3.3 工程协议与偏差律

| λ | p_E | q = Mod 比 | δ [%] |
|---|---|---|---|
| 5 | 0.5 | 2.236 | −13.18 |
| 10 | 0.5 | 3.162 | −11.96 |
| 20 | 0.5 | 4.472 | −11.53 |
| 40 | 0.5 | 6.325 | −2.29 |
| 10 | 0 | 10.0 | −9.30 |
| 20 | 0 | 20.0 | −0.75 |

失配族 δ(Δ(E/σ_f)) 在 Δ = ±10/20/30 % 上为
{+10.0, −16.6, +2.2, −4.8, −16.5, −5.6} %（λ=10）：
三种预注册形式（线性 / 二次 / 幂律）全都不显著，
最优的幂律 `|δ| = 35.8·|Δ|^0.93` 的 R² = 0.0014。
**结论：`Mod` 通道在本 DEM 与本集合规模下不可辨识**（诚实负面结果）。

### 3.4 分辨率与接触数

dt_scale 阶梯 R\* = 0.16276 / 0.14134 / 0.15826 / 0.16047（0.5/0.25/0.125/0.0625），
最细两级相对差 **1.40 % < 3 %**（判据 d PASS）；但 0.25→0.125 之间有 12 % 跳变——
与实现散布同量级（同一工况换种子可达 21 %），说明它是**混沌轨迹发散**而非时间离散误差。

接触数扰动（相对 base）：

| 旋钮 | Δ(contacts/floe) | Δδ [pp] |
|---|---|---|
| dt_half（保场） | +4.38 % | +3.02 |
| field_jitter_coarse | +0.88 % | +8.15 |
| seed_a | +9.85 % | +16.17 |
| seed_b | −0.30 % | +4.44 |
| field_jitter_fine | +12.23 % | +15.43 |

**保场旋钮（只改 dt，初始场逐位相同）通过判据 (c)**：接触数变 4.4 % 只让 δ 变 3.0 pp。
改种子/抖动会换掉初始场实现，其 δ 变化（≤16 pp）不是接触数混杂，而是 §3.1 的实现散布。

## 4. 结论（三条，均可复核）

1. **DEM 侧：Cauchy 协变精确成立。** λ 比值 4^k 的两例 `R*` 逐位相同（0.000e+00），
   说明接触律（含阻尼、水阻、升沉）在 Froude+Cauchy 缩放下同质，数值实现没有泄漏
   绝对尺度（dt 跟 √s 走、域/冰盘/船长都等比）。
2. **计量侧：单实现坍缩陈述的噪声地板是 15.7 %。** 接触网络的混沌使
   "换种子"这一最小扰动就能产生 9–21 % 的 R* 变化；因此
   **任何以 15 % 为门限的单实现 DEM 缩尺检验都处在噪声地板上**，
   判据 (a) 的字面 FAIL（19.89 %）应读作"该实验设计的分辨率不足"，而不是"Cauchy 坍缩被否定"。
   集成均值（n=4）下 δ = −2.6 %/−1.1 % 与 0 相容（s.e. ≈ 7–10 %）。
3. **物理侧：`Mod = E/σ_f` 通道在碎冰阻力里不显著。** 工程协议把 `Mod` 失配 λ^{0.5}
   （λ=40 时 6.3 倍），实测 δ 却非单调（−13.2 % → −2.3 %），R² = 0.663；
   失配族的 δ(Δ) 拟合 R² = 0.001。原因是本模型的接触是**刚塑性罚函数**：
   柔度只改变穿透量，不改变压溃面积的主导项；真实冰盖的 `E/σ_f` 敏感性主要来自
   **弯曲破坏与弹性能回弹**，而本核没有断裂/弯曲（`ice_channel` 明示无断裂模型）。

## 5. 局限与适用范围（必须连同数字一起引用）

- **无断裂/弯曲**：冰盘是刚性圆盘，不能裂开或弯曲。因此 §4.3 的"`Mod` 不显著"是
  **本核范围**的结论，不能外推为"实船模型试验里 E/σ_f 不重要"；真实敏感性主要走弯曲通道。
  该核给出的是**碎冰-结构接触/挤压/摩擦**通道上的下界。
- **`frac ↔ Mod` 映射是假设**：`frac = 0.05·(5000/Mod)²` 由 `k_n ~ E t` 与
  `k_n = 2σ_c t/√frac` 推得，只有一级几何因子，锚点是把默认 `frac` 当作
  `Mod_ref` 的取值约定。
- **二维平面视图 + 等厚冰盘**：无厚度方向破碎、无冰脊、无侧向约束；
  阻力是"整厚平面体"的合力（N），不是单位宽度量。
- **噪声地板 15.7 %**：本集合每个工况只有 1–4 个实现，δ 的不确定度 ~7–10 %；
  要提高分辨率必须扩集合（每工况 ≥16 个实现才能把 s.e. 压到 ~4 %）。
- **单点工况**：只用 Fn=0.071、Σ=111、φ=0.7、μ=0.3 一个物理点，没有 Fn 扫描，
  δ(λ) 的普适性未测。
