# FEM→DEM 断裂场：六方最密堆积（HCP）补齐 + 解析锚点验证（m3689）

状态：功能补全 + 验证欠账清偿。基线仓 TensorDEM，分支 `agent/m3689`。

## 1. 案例介绍（为什么这是欠账）

`docs/icebreaking_development_roadmap.md`（Increment 2.5，Known limits）自陈：
「Current implementation uses simple cubic lattice; does not support hexagonal
close-packed or random packing」。这不是排版问题，而是一层**物理偏差**：

| 格型 | 配位数 Z | 堆积率 φ | 单粒子格胞体积 | 每胞空隙 |
|---|---|---|---|---|
| 简单立方 SC（原实现） | 6 | π/6 = 0.5235988 | 8r³ | 47.64 % |
| 六方最密 HCP（本次） | 12 | π/(3√2) = 0.7404805 | 4√2 r³ = 5.656854 r³ | 25.95 % |

即：SC 冰场里 47.6 % 的格子是空隙，接触配位数只有 6（真实多晶冰近似 12）。
对船舶冰载荷问题，这直接影响惯性、浮态（Archimedes）、断裂路径与波速——
冰场"太松"会把破碎能、接触力峰值系统性压低。SC 与 HCP 均**保持接触半径 r
不变**（因此接触律、键截断、时间步判据全部不动），只改变"每个粒子代表多大体积"。

## 2. 怎么做的（方法/流程）

1. **几何**（`src/tensordem/fracture_gen.py`）：新增 `_generate_hcp_lattice`，
   ABAB 堆垛：层内沿 x 的行间距 2r、行距 √3 r，层间距 2√(2/3) r，
   B 层整层位移 (r, r/√3)。由此四个邻向族
   (2r,0,0)、(r,√3r,0)、(r,r/√3,2√(2/3)r) 及其符号/奇偶像**长度全部恰为 2r**，
   故 `build_bond_topology` 的 2.02r 截断无需改动即自动得到 12 配位。
   裁剪约定：HCP 分支保证**所有球心满足 lo+r ≤ x ≤ hi−r**（球完全在域内），
   SC 分支逐位保持历史行为（`torch.arange(xmin+r, xmax, 2r)` 半开区间）。
2. **质量映射闭环**（`src/tensordem/fracture_mass_mapping.py`）：格胞体积改为
   格型相关——SC `8r³`、HCP `4√2 r³`；`particle_mass(..., packing)`、
   `packing_fraction`、`mass_radius_factor`、`packing_coordination_number`、
   `expected_lattice_bond_lengths` 全部给出闭式；`normalise_packing` 支持
   `hcp / hexagonal / abab` 等写法并拒绝非法值。`mass_mode="sphere"`（冻结的
   旧契约）与格型无关，逐位不变。
3. **配置与字段透传**：`FractureGenConfig.packing`（默认 `"sc"`）→
   `generate_fracture_field` → `FractureField.packing`；
   `FractureField.particle_cell_volume / particle_mass / mass_radius /
   volume_fraction` 全部按格型取值。
4. **测量与判据**（新增 `src/tensordem/lattice_packing_audit.py`）：配位数直方图、
   最小球心距、每粒子方向指纹 S4 = Σ_{j~i} n_{j,x}⁴、仿射单轴模量
   `E/k = (1/(N V_cell)) · ½ Σ_b l_b² n_{b,x}⁴`（内点加权，避免边界键被静默丢弃）。
   基准全部**手推闭式**、写在测试里，不复用实现公式。

## 3. 计算结果（程序化注入，r = 0.05 m，h = 2r = 0.1 m）

| 量 | SC 实测 | HCP 实测 | 闭式基准 | 相对误差 |
|---|---|---|---|---|
| 最近邻距离 | 0.100000000000 m | 0.100000000000 m | 2r = 0.1 | 0（≤1e-12 绝对值） |
| 内部配位数 Z | 6 | 12 | 6 / 12 | 整数恒等 |
| 方向指纹 Σ n_x⁴ | 2.0 | 2.5 | 2.0 / 2.5 | ≤1e-12 绝对 |
| 仿射轴模量 E/k | 10.0000 1/m | 17.6777 1/m | 1/h = 10 ; 5/(2√2h) = 17.677670 | <1e-12 |
| E_HCP/E_SC | — | 1.767766953 | 5/(2√2) = 1.767766953 | 0（<1e-12） |
| 格胞体积 | 8r³ | 5.656854 r³ | 4√2 r³ | <1e-15 |
| 单粒子 cell 质量 | ρ8r³ | ρ4√2r³（=SC 的 1/√2 = 70.71 %） | 闭式 | <1e-15 |
| 堆积率（有限尺寸实测/跨域体积） | 0.523599（逐位精确） | 0.618→0.660→0.691（L=0.8/1.2/2.0 m） | π/(3√2)=0.7404805 | 有限尺寸亏损，单调查单调逼近 |

大规模实测：L = 2.0 m（20 个球径）HCP 场 N = 10164 粒子 / 24084 键，L=1.2 m
N = 2051，L=0.8 m N = 564；SC 同样域 8000 / 1728 / 512（SC 逐位填满自身格胞，
故其实测堆积率恒为 π/6）。HCP 域内粒子数比 SC 多约 1.27 倍（小尺寸，随尺寸→√2）。

## 5. 注意点（坑与局限）

* **有限尺寸亏损**：HCP 分支为保证球在域内，按整行/整层裁剪，边界会丢整行，
  实测堆积率低于 0.7405 且随尺寸单调上升（本次 0.618→0.691）。这是裁剪约定
  而非格型错误：同为内部的 12 配位、2r 键长、S4 = 2.5 与闭式模量均可逐位核验。
  判据因此写成"单调逼近 + 大尺寸 > 0.90×精确密度 + SC/HCP 比 → √2"，不硬套 3 %。
* **方向指纹的坑**：手推 S4 时最初把 HCP 的层内"沿 x 的行"只算 1 条键，得出
  Σ n_x⁴ = 1.5；实测 2.5（±x 两条行内键各贡献 1）。修正后的闭式才与实现一致——
  这正是"公式写得对 ≠ 按求解器方式用它是对的"。
* **引擎集成未做**：`IceDEM3D.__init__` 用 `DEM3DConfig` 自建立方网格及其派生数组
  （pairs/rest_lengths/bonded），外部 HCP 键网不能无损热替换；本次只核验 HCP 场满足
  引擎全部不变量（唯一半空间键对、l 与几何一致、无重叠、Z ≤ 12），未做端到端步进。
* **不做**：随机/多分散堆积、FCC 堆垛、HCP 键刚度标定（E_HCP 更大意味着同一
  宏观模量下 k 需除以 1.7678，属标定层，不在本单）。

| 关键量 | 基准 | 实测 | 相对误差 | < 3 % ? |
|---|---|---|---|---|
| 最近邻键长 | 2r | 2r | 0 | **是** |
| 内部配位数 | 12（HCP）/6（SC） | 12 / 6 | 0（整数） | **是** |
| 方向指纹 Σ n_x⁴ | 2.5 / 2.0 | 2.5 / 2.0 | ≤1e-12 | **是** |
| 仿射轴模量 HCP | 5k/(2√2h) | 17.677670 /k | <1e-12 | **是** |
| 模量比 E_HCP/E_SC | 5/(2√2)=1.767767 | 1.767767 | <1e-12 | **是** |
| 格胞体积 / cell 质量 | 4√2r³ / ρ4√2r³ | 逐位相符 | <1e-15 | **是** |
| 有限尺寸堆积率（L=2.0 m） | π/(3√2)=0.7404805 | 0.6908（跨域口径） | 6.7 % | **否（如实声明）** |

最后一行如实不达标：它度量的是**裁剪域的体积占比**，不是格型的堆积率；格型本身
由配位数/键长/指纹/模量四项逐位验证。若要 < 3 %，需改用周期性边界或整数倍
球径的域，属后续增量。
