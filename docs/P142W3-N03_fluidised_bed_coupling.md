## 1. 案例介绍（物理背景 / 几何 / 参数表）

颗粒–流体两相流的最小可证单元要回答一个问题：**给定的相间拖曳闭包，在多大误差内复现四个经典锚点**（Ergun 压降、单颗粒终端速度、Richardson–Zaki 阻碍沉降、Wen–Yu 起始流化），以及**三力账本是否闭合**。本节点不引入任何船舶/冰区常量：几何是两个理想化单元——(i) 周期立方胞内 N 个单分散球组成的随机密堆积固定床（体积平衡孔隙率 0.380，颗粒直径 1 mm）；(ii) 单颗粒/抖动简立方阵列沉降柱（无接触）。

## 2. 怎么做的（方法 / 流程 / 关键设置 / 工具链）

1. **闭包（已有模块，未改动）**：Ergun(1952) 逐颗粒形式 `F = V_p u [150 μ(1−ε)/(ε³d²) + 1.75 ρ_f|u|/(ε³d)]`，Wen–Yu(1966)/Gidaspow(1994) 分支 `F = ½ρ_f C_D(εRe)|u|u (πd²/4) ε^−1.65`，混合分支阈值 ε = 0.8。
2. **起始流化 U_mf（新）**：三条独立路径求同一物理量——(a) Wen–Yu 关联 `A_r = 1650 Re_mf + 24.5 Re_mf²`；(b) Ergun 二次式闭式解 `A U + B U² = (1−ε)(ρ_p−ρ_f) g`；(c) 以**闭包自身的压降**（逐颗粒、局部孔隙率）与床重梯度相等做二分求根。三者差值是闭包/关联式间的真实差异，而非代码误差。
3. **三力账本（新）**：速度 Verlet 积分无接触颗粒柱（kick–drift–kick），每步分别记录 `F_drag`、`F_pressure`（=−V_p∇p，即浮力）、`F_gravity` 三个合力与总动量 p；判据用 Verlet 恒等式 `p_{n+1} − p_n = Δt/2 (ΣF_n + ΣF_{n+½})` 检验账本完整性，并用稳态窗 `|ΣF|/W_bed` 检验物理平衡。
4. **分辨率收敛（新）**：N = 600/1200/2400 三套随机密堆积（同一目标孔隙率、同一核半径 1.5 d）与 3 套沉降胞（8/10/13 胞/边），比较 `dp/dz`（Re_s ≈ 2/50/499）、`U_mf`、稳态沉降速度的 `(max−min)/mean`。
5. **反控（预注册，全部跑，不删）**：N1 静水浮力（∇p = −ρ_f g）替代混合物浮力；N2 拖曳力「施加但不记账」；N3 密床错用 Wen–Yu 分支；N4 时间步减半看 dt 依赖残差是否按阶收缩。
6. **工具链**：numpy（全部闭包与积分）、matplotlib（图）、pytest（31 项单元 + 6 项端到端验收）；单核运行 103 s，未上集群（集群路径作为 N→∞ 细化的升级手段记录在预注册 §8）。

## 5. 注意点（坑 / 局限 / 适用范围）

1. **单向耦合，流体动量不解析**：流场是给定的（均匀表观速度或闭腔体积守恒回流），拖曳反作用力未被流体求解器接收。三力账本因此只对**颗粒相**闭合；两相总动量守恒（含流体反冲）不在本节点的证据范围内，需要真正的 CFD–DEM 双向耦合。
2. **点颗粒、无接触**：颗粒间无碰撞/摩擦，颗粒体积不占据流体网格。密相（ε < 0.5）只作为**闭包求值域**出现，不作为可压缩床层动力学；`dp/dz` 的局部孔隙率路径是闭包自洽性检验，不是「解析床层」的验证。
3. **沉降速度对分辨率不敏感是模型性质，不是收敛性证据**：均匀 ε 点颗粒闭包的 u_p 与 N 无关（三条分辨率差异 ~1e-14）。判据 ⑤ 的信息量实际来自**局部孔隙率压降**与 U_mf（0.23–0.29 %）。若换用解析床层或含接触的模型，该项必须重测。
4. **Wen–Yu 关联与 Ergun 闭式本身相差 -4.88 %**：两者是不同年份的经验/半经验式，判据 ④ 的 10 % 容差主要容纳这一「关联式间差异」，而非数值误差。系数对 (1650, 24.5) 与出版写法 (33.7, 0.0408) 因四舍五入相差 ≤0.5 %（本算例 -0.098 %）。
5. **Gidaspow 分支在 ε = 0.8 不连续**：本节点所有算例都远离该阈值（0.38 或 ≥0.80 且使用 Wen–Yu 分支），但跨阈值扫掠时会出现跳变，属已知局限，未做平滑。
6. **随机堆积单种子**：每种分辨率一个种子；孔隙率统计给出 std ≈ 0.013（核尺度），体积平衡孔隙率精确为 0.380。
7. **适用范围**：Re_s ∈ [1, 1000]（Ergun 稀疏区上限）、ε ∈ [0.36, 0.96]、单分散球、无黏结/无破碎。
