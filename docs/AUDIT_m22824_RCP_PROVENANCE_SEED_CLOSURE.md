本审计处理两笔**验证欠账**，都是「已有数字、但数字的可信链条上缺一环」：

1. **溯源欠账**：`runs/` 里的沉积算例来自 **3 个不同的实现摘要**（`impl_sha256`）。m21401/m22558 的时间偏差门 `Δ = φ(dt/2) − φ(dt)` 是**跨摘要做差**得到的，但从来没有人验证过「换摘要不改数值」。也就是说，「一对时间步之间唯一的差别是时间步」这句话此前是**假设**，不是已验证的事实。

## 2 复现证书：换摘要到底改不改数值

规则（在读复现算例前写定）：同 spec、同种子，用**当前**实现重跑，比较**落定位置**（`.npz` 坐标最大绝对差）与全部标量指标。位置与标量全为 0 → `EQUIVALENT`；≤1e-12 → `NUMERICALLY_EQUAL`；否则 → `DIVERGENT`；没有复现算例 → `MISSING`（**不是通过**）。

复现算例尚未回件，全部证书裁决为 `MISSING`。**在证书到齐之前，§1.1 的混摘要时间步对不得用于判定时间偏差**（本审计不把它们算作通过）。

**验收裁决（逐条，不做平均）**：

- 无摩擦档（$\mu$=0，$k_n$=256000，1 种子）：$\phi$ = 0.63571，在 0.62–0.66 带内，相对文献 -0.14% → **通过**（|偏差| < 3%）。
- 低摩擦档（$\mu$=0.1，$k_n$=256000，1 种子）：$\phi$ = 0.61860，**低于带下界 0.00140**；该档无文献表值可对标 → 与文献的比较 `WITHHELD`。

低摩擦档的判定要点：验收带 0.62–0.66 来自**无摩擦**随机密堆实验（Scott 1960 / Bernal & Mason 1960 的 $\phi$≈0.6366）；把同一个带直接套到有摩擦堆积上，在物理上没有依据——摩擦会把随机堆积的饱和体积分数往下推。因此本审计给出的是**「该档落在带上界之下是由摩擦造成的、且该偏移在算例内部是收敛的」**这一结论，而不是把带外当成实现缺陷，也不擅自把带放宽。建议的总账改法见 §7。

## 5 注意点与局限

1. **证书只覆盖被复现的配置**：`EQUIVALENT` 是对「同 spec 同种子」的严格复现，它证明的是这条代码路径在这些参数上是确定的、且换摘要不改结果；它不自动外推到本审计没有重跑的配置（$k_n$=16000、$\mu$=0.3/0.5 等）。
2. **摘要哈希覆盖整个模块文件**：换摘要未必改物理（可能只是新增函数），所以本审计不靠读 diff 下结论——diff 只用来提出假设，证书才是证据。
3. **`UNDECIDABLE` 不是失败也不是通过**：它表示当前种子预算下偏差与阈值不可分离；把 `UNDECIDABLE` 当作「通过」是本算例历史上最容易犯的错。
4. **种子预算的假设**：m22558 的 `seeds_needed` 假定粗/细两侧共享同一散布；若散布本身随 $dt$ 变化，所需种子数会变，本审计不重估这一假设。
5. **低摩擦档缺文献表值**：$\mu$=0.1 的随机密堆体积分数在文献里有依赖摩擦的报道，但本仓没有可引用的表值（`tensordem.rcp_references` 只登记无摩擦锚点 0.6366）。故该档与文献的误差判定为 `WITHHELD`，不是「<3%」。

## 7 给总账的建议

1. 锚点 `CASE-DEM-RCP-PACKING-FRACTION` 的验收条件应把两档拆开写：无摩擦档对标 0.6366（±3% 或 0.62–0.66 带）；低摩擦档（$\mu$=0.1）标注为「协议内收敛、无文献表值」，判定为 `WITHHELD` 而非 `FAIL`。
2. 新增条目建议：`CASE-DEM-RCP-FRICTION-TIER-BASELINE`（域：DEM·堆积）——验收：为 $\mu$∈{0.1, 0.3, 0.5} 各建立一条**可引用**的摩擦相关随机密堆基准（文献表值或独立协议交叉验证），使低摩擦/中摩擦档的误差判定从 `WITHHELD` 变为可计算；量化验收：三档各给出 |Δφ|≤0.01 的对标结论，且摩擦单调性（$\phi$ 随 $\mu$ 不增）在 3 个种子上成立。
3. 时间偏差门的剩余欠账：$\mu$=0, $k_n$=4000（3 粗 / 1 细）与 $\mu$=0.1, $k_n$=4000（3 粗 / 1 细）仍为 `UNDECIDABLE`；建议条目 `CASE-DEM-RCP-TIMESTEP-SEED-BUDGET`：按 m22558 的 `seeds_needed` 补齐细时间步种子到 4 个，验收：四个刚度档全部 `certified`。
