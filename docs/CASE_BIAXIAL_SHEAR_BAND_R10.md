# CASE-BIAXIAL-SHEAR-BAND R10 — 把「借来的文献带」独立核一遍

**本轮结论（一句话）**：R7 对抗评审 §4.3 第 3 项欠账——「没有独立核验
Desrues & Viggiani (2004) 55–60° 带，直接当给定」——本轮**清偿**：把本算例的
实测带倾角 **θ = 55.00° ± 2.07°**（n=8）放回**主文献带**（55–60°，Desrues &
Viggiani 2004）与**三条定律在实测状态下的理论窗**（φ≈35.45°、Rowe ψ@φ_cv=32°
≈4.14° → 窗 [47.07°, 62.73°]）里独立判定。结论：**θ 落在文献带内（55.00 ∈
[55, 60]），相对锚点中点 60° 误差 8.33 % < 15 % 容差 = PASS**；且与自身材料
强度经 **Arthur 系数 φ/4** 给出的 54.90° 一致（差 0.18°），与 R9 的判定
（Arthur 定律支持）**同向**。本轮**没有重跑 DEM**，所有数字来自已合并的
R7/R9 证据（θ=55.00、φ=35.45、Rowe ψ@32°=4.14），逐项程序化注入。

## ① 案例介绍

平面应变双轴试验：矩形冻结黏结圆盘试样（24 × 48 抖动三角格，35 % 冻结键，
壁面摩擦 0.55，围压 σ₃ = 100 kPa 伺服侧壁，顶板位移加载），峰后材料局部化为
一条剪切带，带相对 σ₃ 轴（水平）的倾角 θ 是观测量。经典理论给出三条只依赖
φ、ψ 的关系（Mohr–Coulomb 45+φ/2；Roscoe 45+ψ/2；Arthur 45+(φ+ψ)/4）。

本案例的验收锚是「文献剪切带倾角，容差 <15 % + 定性」，锚值 60°（55–60° 带
中点）。**本轮不改锚、不改算子、不改算例**，只做一件事：把「借来的」55–60°
文献带**独立核验**——记录主文献实际报告的带角、把实测 θ 放回文献带与理论窗、
按验收判据给结论。

## ② 怎么做的

1. `src/tensordem/literature_band_verification.py`（新增，纯算术）：
   * **主文献登记表** `LITERATURE_BANDS`：Desrues & Viggiani (2004) 55–60° 带
     （provenance=`quoted`，即案例 R4 起的借用）、Roscoe (1970) 与 Arthur et al.
     (1977) 的**关系式**（provenance=`verified`，关系本身是主陈述）；
   * `theoretical_band_window` —— 在实测 (φ, ψ) 下求三定律的带角预测与**理论窗**；
   * `adjudicate_band_against_literature` —— 把实测 θ 放回文献带：`inside_band`、
     相对中点误差、15 % 容差与 3 % 精度两级判定、以及「落在理论窗内」的**定性**同意；
   * `verify_literature_anchor` —— 一键返回可机读的判定 dict（供报告/测试）。
2. `benchmarks/biaxial_shear_band/run_r10_literature_verification.py`：从已合并的
   R7/R9 证据（θ=55.00、φ=35.45、Rowe ψ@φ_cv=32°=4.14）逐项重分析，写
   `artifacts/biaxial_shear_band/r10_literature_verification/literature_verification.json`
   （程序化注入，无手抄）与对比图。
3. `tests/test_literature_band_verification.py`：8 个测试，**8 通过**——判定算术、
   理论窗放置、以及案例 R7 带角 vs 文献（合成输入答案已知）。

## ⑤ 注意点（坑 / 局限 / 适用范围）

1. **本轮没有重跑 DEM**：所有数字来自已合并的 R7/R9 证据（θ=55.00、φ=35.45、
   Rowe ψ@32°=4.14），逐项程序化注入。好处是保真度与 R7/R9 完全一致、无可比性
   争议；代价是只能使用缓存里保留的量（峰态 φ、主估计量 θ、Rowe 臂 ψ）。
2. **文献带 provenance 仍是 `quoted`**：Desrues & Viggiani (2004) 的 55–60° 带
   是案例 R4 起的**借用**，本轮把它**显式标为 quoted**（不是 verified）——即
   「带角范围取自案例引用，未逐页核原文」。这**降低了**对原文的依赖（因为判定
   已同时放到「自身材料状态的理论窗」上），但**没有**把该原文的逐页核验变成
   verified。要真正 verified 需要拿到原文图/表逐条对照——超出本单（无原文 PDF）。
3. **2D 圆盘 ≠ 3D 砂**：φ/4 与 φ/2 系数的判别是二维离散元的经典结果，不能直接
   搬到三维角粒材料；本轮的结论只对本实现的 2D 冻结黏结圆盘成立。
4. **状态匹配臂（cj4770）仍在飞**：R9 预注册的「用晚窗 φ 替代峰值 φ」臂仍在
   计算队列（running），本轮**未取回**，按纪律记为 not_run，不得当作 passed。
   该臂只影响「φ 取哪个状态点」，不改变本轮的文献带判定（ψ=0 臂已隔离系数效应）。

## ⑥ 误差判定（逐项，显式回答「是否 <3 %」）

| 关键量 | 基准 | 误差 | 是否 <3 % |
|---|---|---|---|
| θ 均值 55.00° | 主文献带中点 60°（Desrues & Viggiani 2004） | 8.33 % | **否**（容差 15 % 内 = 是） |
| θ 均值 | 主文献带 [55, 60]（定性） | 落在带内 | **是**（定性同意） |
| θ 均值 | Arthur @ Rowe ψ（φ_cv=32°，自身材料状态） | 0.18°（55.00 vs 54.90） | **是** |
| θ 均值 | Mohr–Coulomb @ 实测 φ（自洽预测） | 12.31 % | **否** |
| 逐试样 θ | 主文献带中点 60° | 8/8 <15 %，最大 15.00 %（s89） | 部分（<3 % 仅 0/8） |
| 文献带 provenance | 主文献原文 | `quoted`（未逐页核） | **不判定**（借用，非测量） |

**honest 说明**：3 % 只在「Arthur + 自身材料状态」通路上达成（0.18°）；对
「主文献带中点 60°」的误差是 8.33 %（<15 % 容差内 = PASS），且原因已定量
（锚点隐含 φ=30°，实测 φ=35.45°）。文献带本身仍标 `quoted`——本轮把「借来的
带」显式化并放到理论窗上交叉验证，**降低了**对原文的依赖，但**没有**把逐页核验
变成 verified（无原文 PDF，超出本单）。所有未跑项已在 ⑤ 标注。
