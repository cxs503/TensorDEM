# CASE-DEM-SHEAR-CAMPBELL-ELASTIC-LIMIT — R5: 稳态窗口 fabric 时间平均（把 R4 的「头号嫌疑」做成数字）

> 锚点: `CASE-DEM-SHEAR-CAMPBELL-ELASTIC-LIMIT`（feature_ledger，open）· 仓库 TensorDEM · 第 5 轮
> 参考: Campbell, C. S. (2002) *Granular shear flows at the elastic limit*, J. Fluid Mech. **465**, 261-291, DOI 10.1017/S002211200200109X
> 预注册: `runs/fabric_timeavg/prereg.json`（脚本 sha256 `8f667a99db3ac995`）

## ① 案例介绍（物理背景 / 几何 / 参数表）

R4 把 Campbell 弹性极限的**系数**结构做到了 PASS（`A = tau d/k_n` 在 kappa ≳ 2.3e4 饱和到 +5.7%），
但它那条可证伪的闭包——「两个几何常数（a_xy, f_norm）能预测**另一批独立跑出来的**浓度图的剪切应力」
——FAIL：P4（a_xy 与浓度无关）与 P5（外样本预测）双双失败，密端系统性过冲 +31.2%。
R4 把原因写成了**嫌疑**而没有量化：

> 「单快照 fabric … 是 P5 系统性正偏的首选嫌疑，本轮未消除」

即：fabric 常数是在**末态一张快照**上量的，而它们要解释的应力是**稳态窗口上的时间平均**。
R4 自己的诊断已经显示这个差可以有多大：快照配位数与时间平均最多差 14.2%。

本轮不争论这个嫌疑，而是把它**消除**：模拟器在应力平均的**同一个稳态窗口**内累计接触网络统计量，
并把剪切 virial 精确拆成法向/切向两支，使 `f_norm` 成为**实测的时间平均**而不是快照残差。

| 参数 | 取值 | 说明 |
|---|---|---|
| 粒子数 | 400 | 2-D 圆盘，与 R2–R4 同一台装置 |
| 体积分数 | 0.71 / 0.76 / 0.80 | 与 R4 fabric 栅格完全相同 |
| 刚度 k_n | 1e+04 | kappa = 5.79e+03 – 5.79e+03（同一台装置） |
| 剪切率 | 1.0 | $\dot\gamma$ |
| 时间步 | 0.004 t_c | 与 R1–R4 相同 |
| 应变窗口 | 0 → 1.4，平均窗口 0.7 → 1.4 | fabric 与应力在**同一窗口**平均 |
| 种子 | 20261112 / 20261113 / 20261114 | 3 个/浓度 |
| 采样 | 每 0.01 应变一个样本（每点约 70 个） | 时间平均的分辨率 |

## ② 怎么做的（方法 / 流程 / 关键设置 / 工具链）

1. **能力先行**：`simulate_plane_shear(case, fabric_statistics=True)` 在既有采样点（应变 ≥ 平均窗口起点、
   每 0.01 应变）额外累计接触网络量——配位数 Z、平均重合格 <ov>、$\langle n_x n_y\rangle$、
   重合加权 $\langle ov\,n_x n_y\rangle$——并同时把剪切 virial 拆成
   `tau_contact = tau_normal + tau_tangential`（**逐样本恒等式**，不是拟合）。
   开关默认关闭；关闭时输出与历史工件**逐位相同**（未改任何一个已发布数字，测试断言这一点）。
2. **先预注册**：`fabric_timeavg.py --prereg` 在跑任何一个 fabric 点**之前**写下 5 条预测、阈值
   （15% 台账容差原样、6.25% 种子噪声底）与两条诚实规则，写入 `prereg.json`。
3. **同一台装置、只换估计器**：栅格、种子、k_n、时间步与 R4 逐项相同；R4 的快照估计器在同一批点上
   一并重算，所以「快照 vs 时间平均」是**同点对照**，不是跨轮比较。
4. **外样本腿不变**：R2 浓度图（22 个过门点，±壳内 10 点 + 控制/速率/散布点）**只用于预测**，
   从不回拟合、不重跑。
5. **判决程序化**：`--analyse` 按预注册规则原样套用，`--check` 断言恒等式与台账记账；
   本文件与表格由本脚本从 `analysis.json` 插值生成（零手抄）。

### 3.5 EPILOGUE（探索性；判在判决之后写，不替换 P1/P3 的 FAIL）

EXPLORATORY - written after the pre-registered verdicts; P1/P3 stay FAIL, nothing is refitted into them

- a_xy keeps a real concentration dependence (P1 FAIL) while f_norm's concentration spread collapses once it is a time average (41.2% -> 4.3%), so the closure needs a_xy(phi), not a new constant
- a_xy(phi) = +0.8868 -0.8727·phi（对 9 个点自身残差最大 3.7%）；
  f_norm(phi) = +1.1034 -0.4186·phi（自身残差最大 2.9%）

| 检验 | 点数 | 最差残差 | 是否在 15%% 内 |
|---|---|---|---|
| 两常数闭包（P3，预注册） | 22 | +22.1% | 否 |
| phi 线性闭包，样本内 | 22 | +6.9% | 是 |
| phi 线性闭包，**留一浓度**交叉验证 | 19 | +8.7% | 是 |

留一浓度交叉验证（LOCO）的做法：每次**拿掉一个浓度**、用另两个浓度重拟合两条直线，
只预测落在被拿掉浓度带内的 R2 点——被预测浓度**从不进入拟合**，所以这是诚实的泛化数字。

## ⑤ 注意点（坑 / 局限 / 适用范围）

1. **R4 的头号嫌疑被证伪，但不是「快照没用」**：a_xy 的快照偏差只在 1/9 个点超过噪声底
   （最大 8.3%），而且**符号非系统**；真正塌的是 `f_norm`（散布 41.2% → 4.3%）。
   所以 R4 用 a_xy 解释过冲**指向了错的量**：过冲主要来自 f_norm 的快照偏差把分母压小。
2. **phi=0.71 只有 1 个过门点**：另两个种子（Z = 1.165 / 1.346）落在配位数门（≥1.5）外，
   但三个种子的 a_xy 时间平均是 0.268/0.272/0.276（散布 3%），所以该浓度行的结论不靠单点运气；
   本轮**没有**为了让点过门而重跑或调栅格（诚实规则第 1 条）。
3. **2-D 限制照旧**：全部 2-D；Campbell 原文 3-D。a_xy 的**数值**依赖几何，**结构**不依赖。
4. **系数腿对文献仍是 WITHHELD**：Campbell 的表在付费墙后（`reference_anchors.json`），
   本轮所有「A」都是本装置实测量，没有任何一句「与 Campbell 一致」。
5. **LOCO 只有 3 个浓度**：留一浓度等价于用 2 点定一条直线，外推能力有限；
   它给的是「独立浓度上不外推崩掉」的证据，不是精度证明。
6. **f_norm 的定义变了**：本轮 f_norm = 法向力承担的剪切 virial 份额（时间平均），
   与 R4 的「A_normal/A_total」残差定义不同；这正是 R4 注意点 2 里点名的欠账，现在补上了。

## ⑥ 误差判定（关键量 vs 基准，逐项回答「是否 < 3%」）

| 关键量 | 基准 | 本轮结果 | 相对偏差 | < 3% ? |
|---|---|---|---|---|
| 法向/切向 virial 拆分 | 恒等式（=0） | 4.2e-16 | 0 | **是**（恒等式，非测量） |
| 因子化恒等式（时间平均输入，逐点最差） | 1.0 | +4.1% | +4.1% | **否** |
| a_xy 浓度散布（=0 才是常数） | 0 | 41.9% | 41.9% | **否**（且 >15% 门 = P1 FAIL） |
| f_norm 浓度散布（时间平均） | 0 | 4.3% | 4.3% | **否**（<15% 门 = P2 PASS） |
| 两常数闭包外样本（最差） | A_meas | +22.1% | +22.1% | **否**（>15% = P3 FAIL） |
| 探索 phi 线性闭包 LOCO（最差） | A_meas | +8.7% | +8.7% | **否**（<15% 但非预注册） |
| 种子噪声底（a_xy，同浓度三胞胎） | —— | 2.6%–3.0% | —— | 否 |
| 系数 A vs Campbell 表 | 付费墙 | A_inf 见 R4 | 无参考 | 不可判定（WITHHELD） |

**明确回答：本轮除代数恒等式外，没有任何关键量达到 3%。**

原因不是算得粗：a_xy 的种子噪声底本身就有 3% 量级，
在这个分辨率下本轮能说的是三件事：(i) **R4 的嫌疑被证伪**——a_xy 的快照偏差不超噪声底；
(ii) **真正的偏差源是 f_norm**，时间平均把它的浓度散布从 41.2% 压到 4.3%；
(iii) 因此两常数闭包仍然 FAIL（P3 最差 +22.1%，好于 R4 但未进 15%），
而**保留 a_xy 的浓度依赖 + LOCO 交叉验证**后，闭包在 19 个独立点上做到最差 +8.7% ——
这是下一轮可以直接预注册的形式，不是本轮的成绩。

## 下一轮线索

1. **把 LOCO 闭包变成预注册**：`a_xy(phi)`、`f_norm(phi)` 两条直线 + 留一浓度，
   在两到三个新浓度（0.73 / 0.78）上做**真正的外样本**——那才是把系数腿从「结构解释」推到「预测」的路。
2. **f_norm 的物理**：它现在有清晰定义（法向力剪切份额，时间平均 ≈ 0.77–0.80）且几乎与浓度无关，
   但缺一个独立理论值（切向弹簧历史决定它）——可做「同一摩擦系数下 f_norm 是否随 k_t/k_n 变」的判别实验。
3. **a_xy(phi) 的成因**：需要在 fabric 张量上做各向异性分解（contact-normal vs branch-vector），
   判断浓度依赖来自分支长度分布还是接触方向分布。
