# P165-W2-N06: Superquadric Curvature Analytic Verification Report

## ① 案例介绍（物理背景 / 几何 / 参数）

**模块**: `tensordem.superquadric_curvature` — 超二次曲面（superquadric）曲率的闭式解析计算。

**物理背景**: 超二次曲面是 DEM 非球形颗粒接触力学中的关键几何描述。父模块 `superquadric_kernel` 使用中心差分法（finite differences）从解析梯度数值计算 Hessian，在 `eps_rel=1e-6` 时主曲率相对误差约 15%。本模块提供精确解析 Hessian，消除数值微分误差。

**几何定义**:
```
S = |x/a|^n2 + |y/b|^n2,     H = S^(n1/n2)
F = H + |z/c|^n1 - 1         (F = 0 在表面上)
```

**参数范围**: `a,b,c > 0`（半轴），`n1,n2 ≥ 2`（形状指数），`n1,n2 ≥ 40` 时为方块极限（block limit）。

## ② 怎么做的（方法 / 关键设置 / 工具链）

1. **解析公式验证**: 对球体（n1=n2=2, a=b=c=R），曲率应精确为 k1=k2=1/R
2. **椭球高斯曲率交叉验证**: 与椭球闭式公式 `ellipsoid_gaussian_curvature` 比对
3. **网格收敛阶**: 独立网格估计器 `principal_curvatures_mesh` 以 O(N^-2) 收敛到解析值
4. **差分收敛阶**: 遗留 FD 估计器以 O(h^2) 收敛，记录生产参数 eps=1e-6 的误差
5. **方块极限**: n≥40 时平面中心曲率→0
6. **对称性**: 对称形状在对称点曲率相同
7. **负对照**: 非表面点应报错
8. **梯度/Hessian 不变量**: |grad F| = 2/R（球），Hessian 对称，K=k1·k2，H=(k1+k2)/2

**工具链**: `pytest` 27 项测试，全部通过。

## ⑤ 注意点（踩过的坑 / 局限 / 适用范围）

1. **API 格式**: `superquadric_gradient` 返回 (n_points, 3)，`superquadric_hessian` 返回 (n_points, 3, 3)——测试编写时需注意索引方式
2. **方块极限**: n≥40 时仅在面中心曲率→0，边缘/角点曲率很大（~25），这是几何特性而非 bug
3. **非表面点**: 函数不显式检查点是否在表面上，而是通过内部索引失败（IndexError）——测试需捕获多种异常类型
4. **适用范围**: n1,n2 > 40 时隐式模型切换到 max-norm（方块）分支，此时平面曲率为零是构造性的
