## ② 方法

### 1. 凸多面体惯性张量闭式

利用散度定理将体积分转化为四面体求和。对每个面三角形 (v₀, v₁, v₂) 与原点构成四面体，其惯性张量有闭式表达：

$$I_{ij} = \rho \left(\text{tr}(S) \delta_{ij} - S_{ij}\right)$$

其中二阶矩张量 $S_{ij} = \frac{V}{20}(S2_{ij} + S1_i \cdot S1_j)$，$S1_i = \sum_k v_{k,i}$，$S2_{ij} = \sum_k v_{k,i} v_{k,j}$。

符号体积保证原点在多面体外时仍正确。

### 2. Poinsot 解析解

Euler 方程 $I\dot{\omega} = L \times \omega$ 在无外力矩时有 Jacobi 椭圆函数解析解。对 $I_1 < I_2 < I_3$：

**绕最大惯量轴 (轴3) 转动**：
$$\omega_1 = \sqrt{B_1} \cdot \omega_{2,\max} \cdot \text{cn}(\tau, k)$$
$$\omega_2 = \omega_{2,\max} \cdot \text{sn}(\tau, k)$$
$$\omega_3 = \sqrt{A_3} \cdot \text{dn}(\tau, k)$$

其中 $\tau = \Omega t + \tau_0$，$\tau_0$ 由初始条件确定（通过不完全椭圆积分 $F(\arcsin(\omega_2(0)/\omega_{2,\max}), k)$）。

### 3. 四元数积分

采用指数映射法（与 TensorDEM floe_6dof 一致）：
$$q_{n+1} = q_n \otimes \exp(\omega \Delta t / 2)$$

其中 $\exp(\theta \hat{n}) = [\cos\theta, \sin\theta \cdot \hat{n}]$。此方法对常角速度精确，且天然保持单位四元数约束。

### 4. 守恒量验证

- 角动量：$L = I\omega$，无外力矩时 $|L|$ 守恒
- 动能：$T = \frac{1}{2}\omega^T I \omega$，无外力矩时守恒
- 使用 RK4 积分 Euler 方程，验证守恒量漂移

## ⑤ 注意点

### 踩过的坑

1. **Euler 方程符号**：标准形式为 $I\dot{\omega} = L \times \omega$（不是 $\omega \times L$）。符号错误会导致角速度演化方向完全相反。

2. **Poinsot 解的相位**：Jacobi 椭圆函数 sn(0)=0, cn(0)=1, dn(0)=1，因此需要计算初始相位 τ₀ 以匹配任意初始条件。τ₀ 通过不完全椭圆积分第一类 $F(\phi, k)$ 计算。

3. **恒定力矩下的 L 增长**：在体坐标系中，由于 $\omega \times (I\omega)$ 非线性项，L 并不严格线性增长。仅在小角速度近似下 L ≈ L₀ + M·t 成立。

4. **四面体体积公式**：凸多面体分解为四面体时，需使用有符号体积以保证原点在多面体外时结果正确。

### 适用范围

- 惯性张量闭式：仅适用于凸多面体（凹多面体需特殊处理）
- Poinsot 解析解：仅适用于无外力矩、主惯量矩不相等的情况
- 指数映射四元数积分：对常角速度精确；对角速度快速变化时需减小步长

### 局限

- Monte Carlo 数值积分验证仅达到 ~1% 精度（受限于样本数）
- 未测试退化情况（如两个主惯量矩相等）
- 未测试大角速度/高能量情况下的数值稳定性
