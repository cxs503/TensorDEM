# CASE-DEM-PLANE-SHEAR-MUIDI — 平面剪切 mu(I) 流变律标定（TensorDEM）

> 算例池锚点（owner 2026-11-12 算例池令）。ref：da Cruz et al. 2005,
> Phys. Rev. E **72**:021309；GDR MiDi 2004, J. Fluid Mech. **509**:165–194
> （任务单引文 "Eur. Phys. J. E 14:341" 为 GDR MiDi 2004 的误记，mu(I) 律原文
> 出处为 JFM 509:165，本单按 JFM 版引用）。
> 容差判据：**<10%**；指标：mu 与 phi vs 惯性数 I 曲线（I = 1e-3..0.3）。

## ① 问题与 ref 出处

稠密颗粒流的有效摩擦系数与体积分数只依赖惯性数
`I = γ̇ d / sqrt(P/ρ_p)`（μ(I) 流变律）：

```
mu(I)  = mu_s + (mu_2 - mu_s)/(I_0/I + 1)
phi(I) = phi_c + (phi_j - phi_c)/(I_0/I + 1)
```

玻璃珠参考常数（da Cruz 2005 表 I / GDR MiDi 2004 §III；本环境无外网，
常数取自仓内既有文献锚 `tensordem.brash_ice_rheology.mu_i.LITERATURE_JOP`
与 `granular_column.scaling`，与 Jop, Forterre & Pouliquen 2006 Nature
441:727 一致，零手抄）：

| 常数 | 值 | 含义 |
|---|---|---|
| mu_s | 0.36 | 准静态极限 (I→0) |
| mu_2 | 0.84 | 碰撞极限 (I→∞) |
| I_0 | 0.30 | 特征惯性数 |
| phi_c | 0.58 | 低 I 体积分数 |
| phi_j | 0.64 | 高 I 体积分数（剪切致密化） |

**诚实声明**：本环境出站 HTTP 被策略拦截，ref 常数未经在线核验，来自仓内
既有文献锚（直接 import 仓内常量，非手抄）。

## ② 方法与实现

**复用**仓内恒压伺服直剪盒 `tensordem.mu_i_rheology.simulate_servo_shear`
（x 周期、y 光滑侧壁、z 摩擦底板+粗糙压板、压板恒应力伺服；IN102-N02
粗粒化战役同款装置，未改核心代码）。协议：HCP 填充 → 恒应力固结（伺服
收敛到目标法向应力 ±8% 窗口 400 样本）→ 以 `gamma_dot = I·sqrt(P/ρ)/d`
剪切至应变 0.2，后 60% 样本取均值。

**标定（本单核心）**：装置的宏观 mu 由微摩擦 (mu_p, mu_r) 决定，与 mu(I)
律的 mu_s 不是同一量。标定协议（先诊断后定参，诊断留痕
`.scratch/m16080/diag_mucontact.py`）：

| 诊断 | mu_p | mu_r | mu_eff(I=1e-2) | vs ref 0.376 |
|---|---|---|---|---|
| A | 0.36 | 0.0 | 0.3225 | -14% |
| B | 0.5 | 0.0 | 0.1999 | -47% |
| C（采用） | 0.5 | 0.05 | **0.3850** | **+2.2%** |

**关键坑**：mu_r=0.0 时颗粒自由转动、宏观 mu 塌掉一半（B 行）；mu_r=0.05
恢复。mu_p=0.5/mu_r=0.05 与 IN102-N02 k=1 缓存逐位复现（0.3850 vs 0.385）。

## ⑤ 收敛性 / 参数敏感性（≥2 点）

1. **mu_r 敏感性（决定性）**：mu_r 0.0→0.05 使 mu_eff(I=1e-2) 从 0.1999
   跳到 0.3850（+93%）。滚动阻力是该装置的隐性控制参数，任何 mu(I) 标定
   必须显式声明 mu_r。
2. **mu_p 敏感性**：mu_p 0.36→0.5（mu_r=0 下）使低 I 段 mu 从 0.3225 掉到
   0.1999；mu_p=0.36/mu_r=0 组合整体 -50%（`runs/sweep_mu036.json` 留档）。
3. **有限尺寸**：y 向仅 5d、z 向 6 层；m14960 已量化 3 层盒体 mu 偏低
   19%，本装置 6 层+周期 x 为仓内最大直剪盒，低 I 段 -9% 的残余偏差部分
   归因于此（未做 8 层盒体对照，列为后续）。
4. **phi 测量口径**：装置自带 slab 口径（`solid_fraction`）受 HCP 层化
   伪影污染（报 0.33–0.39），本单改用整床口径 `V_p/(W·D·h_bed)`；两口径
   均入 `runs/sweep.json`。

## ⑥ 失败模式与工件

- **phi(I) 判据 FAIL**：整床 φ=0.522 恒定（无 I 依赖），ref 0.58→0.61。
  根因：恒压伺服下床高不随剪切膨胀（plate_h 全 I 恒定 0.0478），装置未
  复现剪切致密化；且初始床 φ=0.52 低于 ref phi_c=0.58（盒体对 N=294 偏大）。
  不粉饰：phi 判据不通过，mu 判据部分通过（低中段）。
- **mu 高 I 段 -13%~-18%**：装置在 I>0.1 后跟不上律的上升（碰撞应力贡献
  不足，e=0.3 偏低 + 盒体有限），mu_2 不可辨识。
- **mu 低 I 段 -9%~-10%**：贴边通过，若 ref 常数带 ±5% 不确定度则不稳健。
- 工件：`benchmarks/plane_shear_mu_i/{run_sweep.py, analyse.py,
  test_plane_shear_mu_i.py, runs/sweep.json, runs/analysis.json,
  figures/{mu_of_I,phi_of_I,error_vs_I}.png}`。
- 复现：`python3 benchmarks/plane_shear_mu_i/run_sweep.py &&
  python3 benchmarks/plane_shear_mu_i/analyse.py`（~4 min CPU，单核）。
- 生态摩擦：knowledge search 引擎离线（:8021 connection refused），开工
  三查退化为仓内 grep（已做：mu_i_rheology / brash_ice_rheology /
  coarse_graining / m14960 直剪盒系列）。

## 结论（honest）

**部分达标**：mu(I) 在 I∈[1e-3, 3e-2] 复现 ref 曲线（最坏 -9.9%），
I>0.1 段与 phi(I) 全段不达标。锚点**不关闭**，留 fail_stage=high_I_mu +
phi_flat 给下一轮（两轮法接棒：下一轮靶子=致密化协议/更大盒体/更高 e）。
