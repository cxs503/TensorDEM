This document re-evaluates the existing N=10000 deposition results against
**friction-dependent RCP reference values** from the literature, addressing
a systematic issue in the original validation: the use of a single
frictionless reference (φ = 0.6366) for all friction tiers.

Every number below is computed from the existing run JSONs in
`benchmarks/case_rcp_deposition/runs/` and the reference table in
`src/tensordem/rcp_references.py` (zero hand-copying).

---

## 1. The Problem: Single Reference for All Friction Tiers

The original validation gates (G1–G16 in `docs/CASE_RCP_DEPOSITION.md`)
compare all results against a single reference value:

| Reference | φ_ref | Source |
|---|---|---|
| Single | 0.6366 | Scott 1960; Bernal & Mason 1960 |

This is physically incorrect. The Random Close Packing fraction depends
systematically on the inter-particle friction coefficient μ:

- **Frictionless (μ = 0)**: φ_RCP ≈ 0.64 — the canonical value
- **Low friction (μ ≈ 0.1)**: φ_RCP ≈ 0.62–0.63 — frictional contacts stabilise looser configurations
- **Moderate friction (μ ≈ 0.3)**: φ_RCP ≈ 0.60
- **High friction (μ ≈ 0.5)**: φ_RCP ≈ 0.58–0.59
- **Very high friction (μ → ∞)**: φ_RLP ≈ 0.56 — the Random Loose Packing limit

The consequence: the mu=0.1 hard-sphere limit (φ_inf = 0.61705) was
compared against the frictionless reference (0.6366), yielding a -3.07%
error that **failed** the G13 gate. But this comparison is physically
inappropriate — the mu=0.1 result should be compared against the mu=0.1
reference, not the mu=0 reference.

## 5. Physical Interpretation

The friction-dependent RCP behaviour is well-established in the literature:

1. **Force chain stabilisation**: Frictional contacts can sustain shear
   stresses that would cause collapse in the frictionless case, allowing
   looser packings to remain mechanically stable.

2. **Continuous transition**: φ_RCP decreases continuously from ~0.64
   (μ=0) to ~0.56 (μ→∞), with no sharp transition. The decrease is
   steepest at low μ and flattens at high μ.

3. **RLP vs RCP**: At very high friction, the poured packing approaches
   the Random Loose Packing limit (φ_RLP ≈ 0.56), which is the minimum
   volume fraction for a mechanically stable disordered packing under
   gravity.

The TensorDEM deposition results are consistent with this physical picture:
- μ=0: φ = 0.642 (near the canonical RCP)
- μ=0.1: φ = 0.626 (slightly lower, as expected)
- μ=0.3: φ = 0.605 (further decrease)
- μ=0.5: φ = 0.593 (approaching RLP)

---

## 6. Recommendations

1. **Adopt friction-dependent references** for all RCP validation gates.
   The single-reference approach systematically penalises frictional results.

2. **Update G13** (and any future friction-tier gates) to use
   `get_reference(mu, method="nearest")` from `tensordem.rcp_references`.

3. **Extend the reference table** as new literature becomes available,
   particularly for intermediate friction values (μ=0.2, 0.4, 0.7).

4. **Consider polydispersity**: The current references are for monodisperse
   spheres. Polydisperse packings have higher RCP values and should be
   treated separately.
