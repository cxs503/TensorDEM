# 巴西劈裂中心场定谳（下）：-3 的缺失是「立方各向异性」而非「加密不够」

本单承 `docs/dem3d_brazilian_hondros_closure.md`（下称"上篇"）。上篇用静力松弛证明 900 步的
`WITHHELD` 不是"步数不够"，把巴西试件中心场判为 **FAIL（结构性）**：中心主应力比 `-2.015`
（Hondros 点载荷解 `-3`）、中心拉应力比 `2P/(πDt)` 高 **30.5 %**。上篇同时留下一个明确悬空的问题：

> 未做晶格分辨/接触弧加密扫描（recipe 已写进 §6），故"加密后能否进 15 %"未知。

本单回答它，并且不是靠"把格点加密再看"——那只能同时改变两个变量。本单引入**第三个模型**：
把键网络的 *Born（Affine）弹性张量* 交给一个**没有晶格间距的连续体有限元**，用同样的直径、厚度与
实测接触弧比去解同一个劈裂问题。于是判据变成可分离的：

* 若连续体（携带与键网络相同的弹性张量）也复现 `≈ -2.03`，缺失来自**本构各向异性**，任何加密都救不了；
* 若连续体接近 `-3`，缺失来自**离散化**，加密才是解药。

结论（提前给出）：**前者**。DEM 三档分辨率的中心比 `-2.015 / -2.072 / -2.006`（均值 `-2.03`，
对 1.8 倍分辨率不敏感、无朝 `-3` 的趋势），携带同一 Born 张量的立方连续体给出 `-2.036`（平面应力）
/ `-1.898`（平面应变），与 DEM 逐档相差 **1.0 % / 2.1 % / 1.1 %**；而同几何同载荷的**各向同性**连续体
给出 `-3.13`，与 DEM 相差 **35 %**。`-3` 的缺失是 26 邻域中心力网络的立方（Cauchy 固体）各向异性
（Zener 2.333），**属于键模型，不属于分辨率**。

## 2. 怎么做的

### 2.1 新增连续体参考（`scripts/brazilian_aniso_continuum.py`）

四分之一圆盘（`x, z ≥ 0`，`y` 为厚度方向）平面应力/平面应变 Q4 有限元：

* **网格**：极坐标结构化网格，圆心用退化四边形（collapse）闭合，避免中心开孔污染待测量；
  环数 = 周向份数 = 20 / 60 / 160（6400 / 43200 / 307200 单元级别）。对称面 `x=0` 施加 `u_x=0`、
  `z=0` 施加 `u_z=0`；劈裂载荷为接触弧 `|x| ≤ w/2` 上的一致节点竖向力（摩擦压板只传竖向力）。
* **本构**：立方对称、晶轴对齐 x/y/z。平面应力消元 `ε_yy = -(C12/C11)(ε_xx+ε_zz)` 得
  `D11 = C11 - C12²/C11`、`D12 = C12 - C12²/C11`、`D33 = C44`；平面应变取 `D = [[C11,C12],[C12,C11]]`、`D33 = C44`。
* **两条分支**：`isotropic-plane-stress`（`C11=λ+2μ`、`C12=λ`、`C44=μ`）用作**自校验**；
  `cubic-plane-stress` 用上面的 Born 张量作**参考**。
* **度量与 DEM 完全同定义**：中心取 `|x|,|z| ≤ D/10` 窗口的面积加权均值（DEM 用同窗口的粒子均值），
  轴向剖面同样 8 个 `z/D` 分箱；一切量再按 `P/(Dt)` 无量纲化，故与载荷幅值无关。

### 2.2 自校验（先证明参考模型可信，再拿它当尺子）

1. **均匀应变 patch test**：线性位移场 → 恢复应力与 `D·ε` 逐项一致（机器精度）。
2. **各向同性极限对 Hondros**：弧比 → 0.2 % 时中心比 `-3.1159`、`σ_xx/(P/Dt) = 0.6012`
   （Hondros `2/π = 0.6366`），即 `4.2 % / 5.6 %`。
3. **网格收敛**：环数 20 → 160 只改变中心比 `0.39 %`（`-3.1396 → -3.1272`）。
4. **平面应力消元 vs 离散键网络**：把 `ε_yy = -(C12/C11)(ε_xx+ε_zz)` 的均匀应变直接加在
   **26 邻域键网络**上，用独立写法（`σ_ij = Σ kL²(n·ε·n)n_i n_j / a³`）算 virial 应力，
   得 `σ_yy = 0`、`σ_xx = D11ε_xx + D12ε_zz`、`σ_xz = C44 γ`，相对误差 `< 1e-12`
   → **FEM 用的 D 矩阵与 DEM 的键力律是同一个本构，不是两套模型**。

### 2.3 三档格点 + 连续体对照（`scripts/brazilian_aniso_attribution.py`）

* DEM：同一张键网络的静力松弛解（上篇的 `solve_static_equilibrium`，L-BFGS + 20 段载荷连续化，
  收敛判据 `|F|∞/间距² ≤ 1e-4 Pa`），`nx = nz = 15 / 21 / 27`，同一行程。
* 连续体：每档 DEM 用**它自己实测的接触弧比**配一个立方连续体解（apples-to-apples）。
* 产物：`artifacts/dem3d_brazilian_aniso/attribution.json`（全部工况 + 全部度量 + Born 常数 +
  manifest 容差）、`fig1_ratio_convergence.png`（左=比值收敛，右=轴向剖面）。

**DEM 加密扫描（静力平衡，线性区）**

| nx=nz | 间距/D | 接触弧比 | 颗粒 | 中心比 σzz/σxx | σxx/(P/Dt) | 拉应力误差 vs Hondros | 平衡残差(相对) |
|---|---|---|---|---|---|---|---|
| 15 | 0.0667 | 0.0669 | 447 | **-2.0149** | 0.8305 | 30.45 % | 9.1e-08 |
| 21 | 0.0476 | 0.0477 | 951 | **-2.0721** | 0.7903 | 24.14 % | < 1e-7 |
| 27 | 0.0370 | 0.0371 | 1587 | **-2.0058** | 0.8026 | 26.08 % | < 1e-7 |

— 分辨率提高 1.8 倍，中心比在 `-2.006 … -2.072` 之间**无趋势摆动**（极差 3.3 %），
既没有朝 `-3` 收敛，也没有朝其它极限收敛。

**连续体对照**

**逐档对齐（DEM 自测弧比 → 同弧比连续体）**

| DEM | 接触弧比 | DEM 中心比 | 立方连续体中心比 | 相对差 | DEM σxx/(P/Dt) | 连续体 σxx/(P/Dt) |
|---|---|---|---|---|---|---|
| nx=15 | 0.0669 | -2.0149 | -2.0354 | **1.0 %** | 0.8305 | 0.7500 |

## 5. 注意点（坑、局限）

* **踩过的坑一：squircle 映射在弧角退化。** 最初用 `x = Ru√(1-v²/2), z = Rv√(1-u²/2)` 把方形映到
  四分之一圆盘，该映射在 `u=v=1` 处 `det J = 0`（方角折叠到圆弧点），外层单元被压扁，整场无意义
  （中心 `σ_xx` 只有载荷量级的 1e-3、支座反力只有施载的 2 %）。已改成极坐标网格 + 中心退化四边形，
  并在 `quarter_disc_mesh` docstring 里留警告，避免后人重走。
* **踩过的坑二：单元自由度排布必须是交错序。** `B` 矩阵按 `(u_x0,u_z0,u_x1,u_z1,…)` 交错排布，
  若 dof 映射用块序 `(u_x0..u_x3,u_z0..u_z3)`，装配会落到错误的自由度上：解仍然光滑、平衡残差仍然为 0，
  **只有均匀应变 patch test 能暴露它**（恢复应力是精确值的 38 倍）。这就是本单坚持先做 patch test 的原因。
* **踩过的坑三：小矩阵千次调用会被 BLAS 线程池吃掉。** 逐单元 2×2 Gauss 循环在 128 核忙机上
  跑 6400 单元用了 24 分钟 CPU / 56 秒墙钟；改成 `einsum` + 解析 2×2 逆后降到 1 秒。
  容量纪律（load15 ≥ 100）下这属于"轻量活"的关键前提。
* **局限一：平面应力/平面应变的包络，不是三维解。** 试件 `ny=3`、厚度 `D/5`，`y` 面自由但不无限薄。
  平面应力给 `-2.035`、平面应变给 `-1.898`；DEM 落在平面应力一侧（松弛试件中心 `σ_yy = -0.42 Pa ≈ 0`，
  与平面应力假设一致）。中心**拉应力**上 DEM（0.79–0.83）比立方连续体（0.75）还高 5–11 %，
  这部分残差归因于三层试件的三维效应与表面截断的键集，本单**没有**量化，故不宣称收敛到连续体。
* **局限二：Born（Affine）张量是上界。** 内部自由度不弛豫，真实格点比 Affine 软；本单只用它做
  *方向性* 参考（比值 `C12/C11`、`C44/(C11-C12)` 对整体刚度尺度不敏感），没有把它当作定量模量。
* **局限三：轴向均匀性指标在点载荷下失真。** manifest 的 `axial_uniformity_rel` 包含 `z/D = ±0.44`
  分箱，点载荷解在载荷点附近发散，连续体与格点都会得到大数（DEM 6.1–13.3，各向同性 FEM 两个数量级）。
  该指标不适合作为"对点载荷解"的判据，本单只报告不作判决。
* 未做：三维有限元（含自由 y 面与真实弧面接触）、键模型升级（加切向/弯曲刚度以把 Zener 压到 1）后的重跑。

## 6. 误差判定（逐项显式回答是否 <3 %）

| 关键量 | 基准 | 误差 | 是否 <3 % |
|---|---|---|---|
| 均匀应变 patch test 应力 | `D·ε` | < 1e-12（相对） | **是** |
| 平面应力消元 vs 离散键网络 virial | 同一本构恒等式 | < 1e-12 | **是** |
| 各向同性平面应力矩阵 vs 教科书矩阵 | `E/(1-ν²)[[1,ν],[ν,1]], (1-ν)/2` | < 1e-12 | **是** |
| 施载/支座反力平衡 | 牛顿第三定律 | 1e-14（相对） | **是** |
| DEM 静力平衡残差 | 0 | 9.1e-08 | **是** |
| FEM 网格收敛（环 60→160） | 自收敛 | 0.07 % | **是** |
| **立方连续体中心比 vs DEM（15/21/27）** | DEM 静力解 | **1.0 % / 2.1 % / 1.1 %** | **是** |
| 立方连续体中心比 vs 各向同性极限 | `-3.13` | 35.0 %（= 归因强度） | 否（这正是结论） |
| 各向同性 FEM 中心比 vs Hondros `-3` | -3 | **4.24 %** | 否（FE 对载荷点对数奇异的离散误差） |
| 各向同性 FEM 中心拉应力 vs `2P/(πDt)` | 0.6366 | **5.6 %**（弧→0.2 %） | 否（同上） |
| 立方连续体中心比 vs Hondros `-3` | -3 | **32.1 %** | **否**（结构性） |
| 立方连续体中心拉应力 vs `2P/(πDt)` | 0.6366 | **17.8 %** | **否**（结构性） |
| DEM 中心比 vs Hondros `-3` | -3 | **32.8 %** | **否**（结构性） |
| DEM 中心拉应力 vs `2P/(πDt)` | 0.6366 | 24–30 % | **否**（结构性） |
| DEM 中心拉应力 vs 立方连续体 | FEM | 5.1 % / 6.6 % / 10.7 % | 否（三维/表面键集残差，未量化） |

**honest verdict：manifest 的 15 % 容差在本键模型下不可达，且原因已定谳为立方各向异性。**
证据链：①携带同一 Born 张量、**没有任何晶格间距**的连续体自己也差 Hondros 32 %（比值）/ 17.8 %（拉应力）；
②三档格点（间距差 1.8 倍）的中心比与连续体逐档相差 1–2 %，对分辨率不敏感；
③各向同性连续体在同一弧比下把 Honda 复现到 4.2 %（自校验），说明"到不了 -3"不是离散化/接触弧的锅。
因此 15 % 容差只有两条出路：**(A) 把基准从点载荷 Hondros 换成同 Born 张量的各向异性连续体解**
（本单已给出可复跑实现与产物），或 **(B) 升级键模型**（加切向/弯曲刚度，把 `Zener` 从 2.33 压到 1，
使网络接近各向同性连续体）。粗糙化/加密都不是出路。
