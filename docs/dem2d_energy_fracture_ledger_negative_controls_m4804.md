# 2-D energy/fracture ledger: negative controls that stay green (m4804)

**问题**：`main` 上 `tests/test_dem2d_energy_fracture_ledger_negative.py` 常红
（7 个负控中 6 个 FAILED），整仓 CI 归零。该文件把「注入故障后要求配平**仍然闭合**」
写成断言，于是它按设计必然失败；这种「故意红」的编码方式让 `python -m pytest -q`
永不可能绿，也没有把「检查对故障敏感」这件事变成可判定的机器断言。

**修法**：把负控写成**拒收**断言而不是故意失败的断言——

```python
assert not _closes(corrupted)      # 被篡改的账本必须被配平检查拒收
```

同一份证据（篡改后配平被打破）保留，但期望结果从「测试红」变成「谓词返回假」，
于是套件是绿的；而一旦容差被放松或篡改变成空操作，`_closes(corrupted)` 会返回真，
这些测试立刻转红——即负控的**灵敏度本身**被机器守住。

代码与数据：`tests/test_dem2d_energy_fracture_ledger_negative.py`（被测与负控）、
`scripts/negative_controls_m4804.py`（变异证明）、
`scripts/plot_m4804_ledger_negative_margins.py`（本页表格与图，程序化生成）。

## 1. 物理场景与账本恒等式

7×3 键合圆盘冰格（`DEMConfig` 默认 SI 单位，`tool_speed=0.2 m/s`，模拟 0.12 s，
刀盘压入破碎 21 根键）：

    dE_mech − W_tool − W_external + Q_damping + E_fracture − E_pair_contact = 0

其中 `E_pair_contact` 是「键断裂时仍相互重叠的颗粒保留的排斥接触势」——它没有离开
系统，因此必须记回来（`tests/test_accounting_ledger_validation.py` 的结论）。

## 2. 做法

1. 正控：未篡改账本的相对残差必须 < 0.5 %（`TOL = 5.0e-3`），能量尺度取
   `|W_tool| + |Q_damping| + |E_fracture|`。
2. 负控：对单通道乘 0 / 3 / −1（`copy.deepcopy` 后篡改，原 sim 只读），要求
   - 配平检查**拒收**（`not _closes`），
   - 观测残差**等于解析值** `pristine + sign·(factor−1)·value`（相对误差 1e-9），即
     测试能指认是被哪个通道破坏的，而不是「只要非零就算通过」，
   - 余量 ≥ 3×tol（防止余量贴容差、结论脆弱）。
3. `W_external` 在无外载场景恒为 0，符号翻转是空操作；因此额外跑一个施加均匀节点
   载荷（每颗粒 y 向 −0.05 N）的场景，把符号翻转负控放在那里，并把「无载场景下该
   负控无效」作为一条**显式的范围限制测试**记录，而不是含糊跳过。
4. 两个 fixture 为 module 级（sim 只读、篡改走深拷贝），套件从 12.5 s 降到 4.4 s。

## 4. 变异证明（负控非空转）

`scripts/negative_controls_m4804.py` 对本测试文件注入三种缺陷，要求**转红**，
随后从内存副本还原并要求**转绿**：

| 变异 | 期望 | 观测 |
|---|---|---|
| 把 `TOL` 从 0.5 % 放宽到 100 % | 负控转红（配平会接受被篡改账本） | 11 failed / 3 passed |
| 把篡改改成空操作（`*= factor` → `*= 1.0`） | 负控转红（没有真正注入故障） | 12 failed / 2 passed |
| 从恒等式中删掉 `fracture_release_J` 项 | 正控转红（恒等式对通道敏感） | 2 failed（`-k positive_control`） |

三例均在还原后回到 14 passed。

## 5. 注意点与适用范围

- 「< 0.5 %」是**记账闭合**判据，不是离散化精度判据：残差不随时间步细化而消失
  （见 `tests/test_accounting_ledger_validation.py` 的说明），不要把它当物理精度指标。
- 无外载场景下 `external_work_J` 恒为 0，符号翻转负控在该场景**无证据力**；本文件用
  `test_external_work_sign_flip_is_vacuous_without_load` 显式锁定这一点，并把真正的
  符号翻转负控放在加载场景（余量 6.6×tol，最薄的一环）。
- 负控只证明「单通道故障可被检出」，不证明多个通道同时相消式篡改可被检出
  （例如同时把 `E_fracture` 与 `E_pair_contact` 按同量补偿）——那需要一个独立的
  物理量作为锚，本文件未覆盖。
- 余量最低的两项是 `external_work_J`（6.6×）与 `pair_contact_acquired_J`（8.0×），
  都与该通道在场景中的量级小有关；若把场景持续时间缩短，这两项可能贴到 3× 门槛，
  负控会以「margin >= 3」失败来提示，而不是静默变弱。

## 6. 误差判定

| 量 | 基准 | 观测 | 是否 < 3 % |
|---|---|---|---|
| 正控相对残差（未篡改，无载） | 0（账本恒等式应精确闭合） | 2.80e-3 | 是（0.28 %） |
| 正控相对残差（未篡改，加载） | 0 | 2.87e-3 | 是（0.29 %） |
| 篡改残差 vs 解析式 `pristine + sign·(f−1)·v` | 解析式（无自由参数） | 相对偏差 < 1e-9 | 是 |
| 每个负控余量 / 容差 | ≥ 3 | 最小 6.6 | 是（2.2 倍门槛） |
