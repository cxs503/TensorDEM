# 颗粒离析验证面的可复用教训（Granular segregation verification — durable lessons）

**适用范围**：TensorDEM 内所有「颗粒组分空间结构」类验证面（离析/分层/成带/偏析），以及任何用

## L1 浓度型指标有采样底噪，不能单独用作负控

- **规则**：凡是以「某组分在某区域的浓度偏离名义值」定义的离析度（$S=\langle|\phi-\phi_0|\rangle/\phi_0$），
  在**完全混合**的有限颗粒床里必然非零，量级 $\sim 1/\sqrt{N_{bin}}$。用 `S < 1e-6` 之类阈值判「单分散负控」
  只会得到一个恒 FAIL 或恒 PASS（若结构上退化）的假判据。
- **证据**：上次尝试等径负控 max|S|=0.062（阈值 0.02）→ 判据失效；本面同量级底噪由
  `metrics.permutation_null` 直接给出（置换零模型的 S_null_mean/std），每个 S 都附 z。
- **机制**：有限颗粒数 → 环带占用率涨落 → 浓度剖面涨落，与物理离析同量级。
- **做法**：负控必须用**结构上恒为零**的指标（本面用粒径-径向位置相关系数 $\rho_{d,r}$，单分散时
  直径方差为 0 ⇒ 恒等于 0）；浓度型指标只用于「相对零模型显著」的判决，永不用于绝对阈值。

## L2 置换零模型必须只打破「被检验的关联」

- **规则**：检验「物种标签与空间的关联」时，零模型应**置换位置**（物种标签与半径留在原位），
  即保持位置多重集与物种配比不变。
- **反例（都实测过）**：
  1. **跨全部颗粒置换标签** —— 破坏标签-粒径耦合，各实现的名义面积分数 $\phi_0$ 也变，零分布被人为放大
     （实测：混合床观测 S=0.082 而零均值 0.198，z=-1.9 的荒谬结果）。
  2. **类内置换位置** —— 类的位置集合不变，零分布退化（std≈0），z 无意义（实测 z=-1.0 的伪值）。
- **回归保护**：`test_permutation_null_is_flat_for_random_arrangement`（随机床 |z|<3）与
  `test_permutation_null_detects_artificial_segregation`（人工分层 z>5）。

## L3 带自旋自由度的软球 DEM：滚动阻力不足会让静止床永不静止

- **规则**：切向摩擦作用于接触点会给颗粒自旋，若滚动阻力矩不足耗散，床层维持「数值沸腾」态
  （残余 rms 速度不随时间衰减），所有「静止初态」「负控」结论都被污染。
- **证据**（$d$=20 mm、$k_n$=5e4 N/m、$dt$=1.5e-4 s、5000 步）：$\mu_r$=0.02 → rms 0.094 m/s、spin 85 rad/s；
  $\mu_r$=0.05 → 0.0029 m/s、spin 7；$\mu_r$=0.10 → 0.0031 m/s、spin 1。
  $\mu_r\in[0.05,0.1]$ 也是粗糙颗粒的常规取值区间。
- **派生规则**：静止初态要**显式验证**并记录（本面 `diagnostics.settle_rms_speed` + 动能淬火轮次），
  不能只按「跑了 N 步」假定已静止。
- **回归保护**：`test_static_drum_is_a_negative_control`。

## L4 RSA 建床：最大颗粒优先 + 自适应放大区域

- **规则**：随机顺序吸附（RSA）若把小颗粒先放、大颗粒后放，会在大粒径比与高填充时**卡死**
  （大颗粒最后找不到孔洞；实测比值 3 只能放 451/550）。改为**粒径降序插入**并把区域按填充率自适应放大，
  即可在 0.3–1.5 s 内建成 0.15–0.65 填充的床。
- **旁证**：插入顺序不影响初始**径向**分布（实测初始 $\rho_{d,r}$=0.000/-0.014/+0.019），
  只影响局部接触拓扑，故不构成方向性偏置。
- **回归保护**：`test_make_bed_places_all_particles_inside_drum_without_overlap`、
  `test_bed_is_well_mixed_initially`。

## L5 离析是「多转」现象：短窗运行只能证明噪声

- **规则**：滚简/振动床的组分结构在**数转到数十转**尺度上才建立。按转数（而非物理秒数）规划算例，
  并在报告里给出 S(rev) 时间历程；单快照 + 短窗的「方向 PASS」不可采信。
- **证据**：本面 8 转 pilot 中 $\rho_{d,r}$ 由 ~0 线性增长到 0.11（$d_l/d_s$=2，约 +0.011/转，
  z=2.6 未达显著），因此验收矩阵改用 16 转（并附 28 转饱和对照）。

## L6 负控的设计错误比正控更容易犯：幅度型负控会被「本底」和「底噪」双重污染

- **规则**：负控不能只写「幅度 → 0」，必须指定 (i) 用哪个**无量纲、结构上可为零**的指标、
  (ii) 该指标的**本底**（例如沉降形成的静止床残余结构）、(iii) 该指标的**采样底噪**。
  若期望信号低于底噪，则该子项**不可判定**，应在预注册时就不要写进去。
- **证据（本面实测）**：
  1. 「$d_l/d_s\to1$ 幅度单调增」子项在 1.05/1.10 处期望幅度 ≤0.02，而核-壳差底噪 ~0.02–0.05 ⇒ 判据不可判定（实测序列 0.0046 / 0.0276 / 0.0077 / 0.0213 非单调）。
  2. 「$\\omega\to0$ 幅度→0」子项：静态沉降床本身就有 0.074 的核-壳差本底（沉积分层），
     与离析工况同量级 ⇒ 单调性不成立（0.0736 / 0.0223 / 0.0359）。
  3. 「填充率→1 抑制离析」子项被**实测反例**否决：fill 0.65 的 $\\rho_{d,r}$=+0.27 反而**强于** fill 0.30 的 +0.16，
     即在高填充下自由面变短、再混合减弱，离析被强化。负控必须选物理上确实会关闭机制的参数。
- **派生做法**：负控指标优先用**结构零 + 无分箱**的统计量（本面 $\\rho_{d,r}$），
  且用「静止床残余基线」而不是 0 作为零点。

## L7 单快照显著性是噪声受限的：时间平均 + 自相关修正才是可判定的统计量

- **规则**：以离散颗粒快照做统计检验时，$N$ 颗粒的单快照相关系数标准误约 $1/\\sqrt{N}$
  （本面 $N$=581 ⇒ ±0.04）。若物理信号同量级，单快照 z 会随机跨越阈值
  （实测 $d_l/d_s$=3 终态 $\\rho$=-0.019 判 mixed，而准稳态均值 +0.086、z=+3.8）。
- **做法**：预注册时就规定「末段若干快照的均值 + 自相关修正标准误」或「多快照联合置换零模型」
  （后者需在运行中保留末段快照位置）；单快照 z 只作辅助证据。
- **代价提示**：这类修正若在看过数据后才引入，只能作为**事后补充**明确标注，不能用来改写预注册判据。

## L8 判据阈值必须预注册，并在数据到达前记录修正

- **规则**：把「方向/标度/负控」的阈值、参照带、比较域写进 `prereg/*.json`；
  若建模过程中必须修正（本例：$\mu_r$ 0.02→0.10、填充率上限 0.75→0.65、ω 网格避开 cataracting 区），
  在 `amendments_after_seeing_data` 里写明「改了什么 / 为什么 / 是否在验收运行前」。
- 说明：运行前修正 = 设计选择；运行后修正 = 需要显式声明为事后调整，且不得覆盖 honest FAIL。
