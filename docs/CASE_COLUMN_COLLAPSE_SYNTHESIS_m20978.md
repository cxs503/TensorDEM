# CASE-COLUMN-COLLAPSE · 轴对称颗粒柱坍塌综合验证报告（m20978）

**锚点**：`CASE-COLUMN-COLLAPSE`（算例池·颗粒柱坍塌）
**基准**：Lube, Huppert, Sparks & Freundt (2004) *JFM* **508**:175-199, doi:10.1017/S0022112004009036
**容差**：< 15 %（跑距律）；时间律单独判定
**仓**：TensorDEM · 分支 `agent/m20978`

## ① 案例介绍（物理背景 / 几何 / 参数表）

圆柱形颗粒柱（初始半径 $r_i$、高 $h_i = a r_i$，高宽比 $a$）在粗糙水平面上移除侧向支撑后自由坍塌。
参考实验给出两条经验律：

$$r_\infty/r_i = \begin{cases} 1 + 1.24a & a < 1.7 \\ 1 + 1.6\sqrt{a} & a > 1.7 \end{cases}, \qquad t_\infty = 3\sqrt{h_i/g} = 3\sqrt{a r_i/g}$$

**冻结闭合臂**（经轮 1–6 标定，m18691 确认）：

| 参数 | 值 | 说明 |
|---|---|---|
| $\mu$ | 0.50 | 颗粒间接触摩擦 |
| $\mu_r$ | 0.50 | 滚动阻力 |
| $\mu_w$ | 0.80 | 底板摩擦 |
| $e$ | 0.50 | 恢复系数 |
| $k_n$ | 6.0×10⁴ N/m | 法向刚度 |
| $k_t/k_n$ | 0.50 | 切向/法向刚度比 |
| $\rho$ | 2500 kg/m³ | 颗粒密度 |
| $g$ | 9.81 m/s² | 重力 |
| 粒/$r_i$ | 8（基线） | 分辨率 |
| 初始堆积 | HCP + 2% 格隙 | 确定性晶格 |

## ② 方法（怎么做的 / 流程 / 关键设置 / 工具链）

1. **内核**：TensorDEM 3D 接触（线性弹簧-阻尼法向力 + Cundall-Strack 切向弹簧 + 滚动阻力），速度 Verlet 积分。
2. **几何**：`tensordem.granular_column.axisym` 模块，HCP 圆柱堆积，t=0 释放。
3. **Runout 度量**：径向 99.5% 分位 + 颗粒半径（与矩形版本同一套 0.5% 尾部剪除）。
4. **终止判据**：KE < 10⁻⁵ × PE0，持续 160 步（`at_rest`）。
5. **参考值**：全部由 Lube 两律在**实测**长宽比 $a_{\rm meas}$ 上运行时求值，零手抄。
6. **测试门禁**：`tests/test_axisym_column_lube2004.py`（13 项）+ `tests/test_axisym_column_edge_cases.py`（72 项，本单新增）。

### 3.2 埋置时间律

| 长宽比 $a$ | 分辨率 | $t_{90}$ 误差 | $t_{95}$ 误差 | 判定 | 出处 |
|---|---|---|---|---|---|
| 0.5 | 8–16 粒/$r_i$ | +11…+42 % | +12…+40 % | ❌ 不收敛 | m20337 |
| 1.0 | 8–16 粒/$r_i$ | −2.3…+2.3 % | — | ✅ < 3 % | m20873 |
| 3.0 | 8–12 粒/$r_i$ | −1.4…−1.8 % | — | ✅ < 3 % | m20873 |

**结论**：时间律在 $a \ge 1$ 上成立（< 3 %），在 $a=0.5$ 上不收敛（非单调，+12…+40 %）。

### 3.3 分辨率收敛性

- **跑距律**：全分辨率族稳健（最大 15.4 %），$a=1$ 的 12→16 漂移仅 2.4 pp。
- **时间律**：$a=0.5$ 非单调（+39.5 % → +12.6 % → +19.8 %），不收敛。
- **深端反例**：$a=3$ 在 12 粒/$r_i$ 首次出带（+15.4 %），8 粒/$r_i$ 在带内（+8.1 %）。

### 3.4 初始状态敏感性

- **晶格 vs 无序**：m20811 显示无序堆积（pluviation 生成）在 $a=0.5, 1.0$ 上仍在 15 % 带内。
- **可容许抖动**：m20259 显示 jitter > 0.005 $r_p$ 产生穿透，不可容许成员误差达 +42 %。
- **系综散布**：可容许成员间 σ/mean < 2 %（m20259）。

## ⑤ 注意点（坑 / 局限 / 适用范围）

1. **深端出带**：$a=3$ 在 12 粒/$r_i$ 超 15 % 线 0.4 pp。这是锚点历史上第一次出带点。
   不应读成「深端物理失效」，而应读成「15 % 判据在深端高分辨率处不被满足」。
2. **时间律定义差异**：DEM 沉积尾段为蠕变，实验把「突然停止」定义为 $t_\infty$，
   两者定义差一个尾段。在 $a \ge 1$ 上用 $t_{90}$ 可达 < 3 %。
3. **单实现、无系综**：每配置一次确定性积分（`jitter=0`），散布轴由 m19922/m20259 处理。
4. **适用范围**：干颗粒、轴对称、HCP 初始堆积、单分散球体。
5. **未做**：多分散/颗粒形状/初始体积分数敏感性；$a=3$ 的 16 粒/$r_i$ 档；
   $a \in (1.7, 2.0)$ 断点邻域的新长宽比点。

## ⑥ 误差判定（逐项，显式回答「是否 < 3 %」和「是否 < 15 %」）

| 关键量 | 基准 | 最佳误差 | 最差误差 | < 3 % ? | < 15 % ? |
|---|---|---|---|---|---|
| 跑距律（全族） | Lube 两律 | −2.9 % ($a=0.5$, 8 粒) | **+15.4 %** ($a=3$, 12 粒) | **否** | **91 % 通过** |
| 时间律 $a \ge 1$ | $3\sqrt{h_i/g}$ | −2.3 % | +2.3 % | **是** | 是 |
| 时间律 $a=0.5$ | 同上 | +11.0 % | +40.6 % | **否** | **否（不收敛）** |

**总回答**：
- 跑距律：**否**（无一例 < 3 %），但 91 % 在 15 % 带内。
- 时间律：在 $a \ge 1$ 上 **是**（< 3 %），在 $a=0.5$ 上 **否**（不收敛）。
