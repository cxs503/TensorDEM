## 1. 案例介绍

### 1.1 物理背景：覆盖率不等于冰情

冰区航行阻力（Lindqvist / IACS / 离散元冰-船耦合）对碎冰场的要求从来不是单一标量覆盖率 φ，
而是**两个**相互独立的量：

1. **面积分数** φ = Σ A_i / (Lx Ly)（多少水面被封冻）；
2. **接触网络** —— 哪些浮冰彼此接触、接触点数（配位数 Z = 2N_c/N）、以及该网络是否贯通
   （力链能否跨越计算域）。阻力的主要来源是浮冰间的力链与浮冰-船体的挤压破碎，若浮冰
   互不接触，DEM 里就只有自由漂浮的刚体，冰阻力趋于零。

IN22-N01（`tensordem.fsd_packing`）用多分散圆盘 + 随机顺序吸附（RSA）+ 松弛压实生成碎冰场：
RSA 在 φ ≈ 0.36–0.49 即堵塞，继续提高 φ 只能靠压缩，而压缩必然留下重叠（wave-1 在
φ ≥ 0.85 的重叠判据 FAIL）。IN32-N01（`tensordem.polygon_floe_field`）换用**给定面积的
Laguerre 镶嵌**，把每个 cell 绕自身形心按 s = √φ 收缩：覆盖率精确、重叠严格为零，但代价是
每个浮冰周围出现一圈"平台间隙"（φ = 0.90 时最小 SAT 间隙 0.094 m），**接触集恒为空**：

```
$ python -c "from tensordem.polygon_floe_field import *; f=generate_polygon_floe_field(LogNormalFSD(0.5), coverage=0.85, n_floes=200, seed=11); print(f.contacts(cutoff=1e-2)['i'].size)"
0
```

于是"φ ≥ 0.85 无重叠"这个指标被满足了，而它想代表的物理（密集、互锁、能传力的碎冰盖）没有。
本节点的目标就是把这两件事**同时**做到：φ 精确、重叠 ≲ 1e-13 m、并且接触网络贯通。

### 1.2 几何与参数

| 项 | 取值 / 来源 |
|---|---|
| 计算域 | 周期矩形 Lx × Ly = Σ A_i / φ，长宽比 1.6 |
| 浮冰数 | 250（验收扫描）/ 400–2000（生成器能力） |
| 尺寸分布 | `PowerLawFSD(2.5)`、`LogNormalFSD(0.5)`、`BimodalFSD()`、`DeltaFSD(5.0)`（中位半径 5 m，wave-1 类） |
| 浮冰面积 | A_i = π a_i²，a_i 取 FSD 的 (k+1/2)/N 分位后随机指派 |

## 2. 怎么做的

### 2.1 复用的两个已验证组件

* **给定面积的 Laguerre 镶嵌**（`laguerre_field.py`，IN32-N01 已验证）：权重的 Newton 迭代
  使用精确面积 Jacobian（边通量 ℓ_ij/(2|d_ij|)，即半离散最优传输的图 Laplacian），
  覆盖恒等式 Σ A_cell = Lx Ly 作为自校验（cover = 1 到 1e-16，否则硬报错）。
* **凸多边形精确 SAT**（`polygon_contact.py`，IN32-N01 已验证）：分离时给出精确顶点-边距离，
  重叠时给出最小平移深度（MTV）与 CFP 接触点、力臂。

### 2.2 批量 SAT 内核（新增，求解器用）

压实内循环每步要做上千对判定，标量版 Python 循环太慢。新增 `sat_pairs`：把两个多边形的
边法向拼成 2C 条候选轴，一次 `einsum` 求出所有顶点投影极值，穿透深度取
min_axis min(max_a − min_b, max_b − min_a)（凸多边形的精确 MTV）。位移搜索用
`fast_pairs`（分块显式最小像距离矩阵）替代逐体 KD 树循环。

两者都在测试里与参考实现对齐：`sat_pairs` 的深度与 `polygon_gap` 一致到 4e-16；`fast_pairs`
与 `candidate_pairs` 返回**完全相同**的配对集合与最小像位移。

### 2.3 第一次尝试（失败）：各向同性吸引 + 非重叠投影（诚实的否定结果）

最直接的想法是把压实写成界面能的投影梯度下降

  E(x) = Σ_(i,j) (g_ij)_+²,  g_ij = SAT 有符号间隙

每步：所有间隙 > 容差的近邻对互相吸引（面积加权、保 Σ A_i x_i），然后用 SAT 投影把重叠推回
容差内。物理上这对应"冻结黏结把浮冰拉在一起"。

实测（§3.5）：φ = 0.85、N = 250 时运转 40 步后 **Z = 1.26、248 个孤立簇、不贯通**，能量只降
约百分之几。原因是结构性的：**周期盒内浮冰面积固定、各向同性的对势合力相互抵消**，宏观上
没有任何机制把 15% 的自由面积搬到某处形成引道，系统只能局部贴靠后停住。这条路径因此被
否证（保留 `compact_floe_field` 作为可选精修器，它确实能闭合局部间隙、且不破坏面积守恒）。

### 2.4 采用的构造：固结区（consolidated zone）+ 引道区

真实冰盖里自由面积不是均匀摊开的：它集中在**引道**，其余部分是**再冻结的固结冰盖**
（浮冰彼此贴合、共享冰缘）。这个物理图像可以直接写成面积预算：

* 固结区：让浮冰**填满自己的 Laguerre cell**（T_i = A_i，尺度 s = 1）。相邻固结 cell 由
  构造共享一条边，SAT 间隙恒为 0 —— 这就是接触；该区域的接触图就是 Laguerre 邻接图本身，
  平面极限 Z → 6，且沿带状区域贯通。
* 引道区：cell 目标面积 T_i = f · A_i / φ_L，浮冰按 s = √(φ_L/f) 收缩，浮冰之间留空水。

面积记账是**恒等式**而非拟合：如果固结区承载的浮冰面积为 A_C，则

```
Σ T = A_C + f (A_tot − A_C)/φ_L = Lx Ly
⇒  f = φ_L (Lx Ly − A_C)/(A_tot − A_C)        （离散整块指派带来的残差 ≤ 半个浮冰）
```

再令引道浮冰尺度为 √(φ_L/f)，则每块浮冰的面积都精确回到其 FSD 面积 A_i，于是
**Σ A_i = φ Lx Ly 自动成立**（实测相对偏差 ≤ 6e-7，见 §3.1），而固结区仍保持尺度 1（接触不
被破坏）。φ_L 本身再做 2–3 次一维不动点迭代，使"引道区实际局部覆盖率 s_L² = φ_L/f"命中请求值。

**固结区如何选**（`zone_order` + `_select_by_area`）：在环面上按"压结坐标"排序浮冰，取前缀直到
前缀面积达到 A_C：

| zone | 压结坐标 | 结果 |
|---|---|---|
| `band`（默认） | 到最近一条带中心线的环向距离（`n_bands`、`band_axis` 可调） | 带状固结区，沿带方向贯通 |
| `disc` | 到随机点的环向距离 | 孤立固结斑块（不贯通，用于对照） |
| `random` | 随机置换 | 空间不相关的固结集（位点渗流阈值下的对照） |

### 2.5 独立验证面

验收数字**不取求解器自己的内核**，而取已验证的 `polygon_contact.contact_set`（精确 SAT）与
独立的面积栅格化 `union_coverage`（3×3 周期像 + 半平面精确判定，含"被覆盖两次"的面积），
接触图拓扑用 `contact_percolation`（并查集 + 周期 BFS 展开，判定是否存在贯通簇）。

### 2.6 工具链

纯 float64 NumPy/SciPy；测试 `pytest`；图 `matplotlib`；扫描与 pytest 由
`benchmarks/in26_n01_compaction_acceptance.py` 一次跑完并把所有数字写进 JSON（零手抄）。

## 4. 注意点（踩过的坑与局限）

1. **"无重叠"与"有接触"必须由两个不同的机制提供。** 只要浮冰面积固定、盒子面积固定，
   把每个 cell 绕形心等比收缩就永远不会重叠、也永远不会接触；想同时拿到两者，必须让
   **一部分浮冰填满 cell**（s = 1）而把自由面积集中到别处。这是本节点最重要的结构性认识。
2. **各向同性吸引在周期盒里是死路。** 合力抵消（§3.5），能量与配位数几乎不动。任何"把盒子
   压小一点"的直觉在周期盒 + 固定面积下都不成立：盒子面积由 Σ A_i/φ 锁定。
3. **离散整块指派会放大到引道区。** 固结区前缀只能取整块浮冰，A_C 的残差 ≤ 半个浮冰面积；
   但引道区只占 15% 的面积，若不做 f 补偿，引道浮冰面积会偏差 1.6%（早期版本实测
   s_L²/φ_L = 0.984）。必须用 §2.4 的 f 吸收，否则 FSD 二阶矩超差。
4. **栅格化的两个方向都错过一次。** (i) 内外判别用 `side ≥ 0`：对 CCW 多边形，边法向
   (dy, −dx) 指向外侧，内点在 **≤ 0** 一侧，符号写反导致覆盖率恒 0；(ii) 周期跨缝不能"先裁剪
   再平移"，必须平移**整像**再用未平移的网格判定（否则跨缝浮冰只计一半）。
5. **`np.roll` 不能用于补齐的多边形批。** 最后一块活顶点的后继是顶点 0 而不是 padding 槽；
   批量 SAT 用 `_next_vertex` 按 count 构造后继。
6. **局部引道覆盖率必须如实报告。** s_L² 与请求的 φ_L 相差 ~1%（f 的一维不动点收敛残差），
   工件里两者都写。
7. **`zone="random"` 不是万能的阴性对照。** 固结面积份额 83% 时随机位点集本身也超过三角
   格子渗流阈值（~0.5），因此也会"贯通"；真正干净的阴性对照是 IN32-N01 的缓冲场（接触点恒 0）。
8. **局限。** (i) 场是几何构造 + 静态接触网络，**没有积分接触律**（法向/切向力、破碎、翻倒），
   动力学问的是 wave-3 的活；(ii) 只有平移（+可选刚性缩放），没有转动，故不存在真实的互锁
   咬合；(iii) Laguerre cell 凸，凹形/钩状碎块无法表示；(iv) 固结区引入了大尺度结构（带状），
   冰情因此**各向异性**（`band_axis` 是物理参数而非数值参数）；(v) 本节点未能复现 IN22-N01
   文档里记录的 H1 `state_digest = 684aa4c4…d316c`：产生该摘要的参数组未入库，因此单分散锁
   改为锚定**本节点工件中固化的场摘要**（见 §3.3）并叠加"与 IN32 生成器逐位一致 + H1 场可
   确定复现"两条。

## 5. 误差判定

| 量 | 基准 | 实测误差 | < 3% ? |
|---|---|---|---|
| 覆盖率 φ（名义，面积记账） | 请求值 φ | 见 §3.1（≤ 6e-7 相对） | **是** |
| 覆盖率 φ（栅格化并集，独立实现） | 请求值 φ | 见 §3.1（≤ 6.3e-4 相对） | **是** |
| 最大 SAT 重叠 | 0 m（判据上限 0.01 m） | ≤ 5e-14 m | **是**（优于判据 11 个量级） |
| 固结区 cell 面积 vs FSD 目标 | A_i | 求解器 2.2e-6 相对 | **是** |
| 浮冰面积一阶矩 m1 / 二阶矩 m2 | FSD 解析矩 | 见测试（m1 ≤ 5e-3、m2 ≤ 1e-2 相对） | **是**（m2 在 1% 量级，与 IN32 判据同档） |
| 单分散极限 vs IN32 场 | 逐位 | 0（数组全等 + SHA-256 相同） | **是** |
| 配位数 Z（固结区） | 平面六边形极限 6 | 见 §3.2（4.9–5.6） | 是（无实验基准，作一致性指标） |
| 接触网络贯通 | 布尔 | 见 §3.2（全部 True） | **是** |

**说明**：配位数、簇数没有实验基准（本仓无实测碎冰场接触统计），按一致性指标报告
（平面极限 6、带状固结区内接近 6），不作为已标定的物理预测。其余各项要么对解析值、
要么对同一运行中的独立实现校验。
