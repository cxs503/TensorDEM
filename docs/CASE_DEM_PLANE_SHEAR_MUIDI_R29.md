## ⑤ 注意点 / 局限（含未完成部分）

* **8 应变长窗没有跑出来**：`cj4332`（8 核，8 组合）递交后排队 63 分钟仍在 `queued`
  （当时集群 73 个作业在飞）；本机被计算调度令硬拦（后台进程被禁、shell 单次调用上限
  120 s，而单核一次 8 应变跑需 5-14 分钟），因此**长窗证据缺席**。R28/R27 的第一优先项
  由此变成一张可复现的预注册单，而不是本轮结论。所以本轮**不改变**锚点判定。
* 基准律是 **3-D 玻璃珠** 拟合，本装置是 **2-D 圆盘**（2-D 随机密堆 0.8404 vs 3-D 0.64）：
  $\phi$ 只作方向/单调性证据，不作定量判据。
* 引用三元组在仓内有两个读法（0.36/0.84/0.30 与 0.379/0.641/0.279）；包络 oracle 已把
  「换个读法就能过关」这条出路封死（最小可能最差误差 174-689 %）。
* 单点落在包络内不构成辩护——包络问题是曲线级问题（见
  `test_verdict_curve_envelope_cannot_rescue_a_factor_three_deficit`）。
* $\phi$ 与 $p_{bulk}/p_{wall}$ 的读数在 $w=0$ 分支系统性偏离（0.72），是 R27 遗留的
  维里归一化线索，本轮未结。
