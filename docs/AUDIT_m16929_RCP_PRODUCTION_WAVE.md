## ① 案例介绍（物理背景 / 几何 / 参数）

随机密堆（RCP）是无摩擦单分散球**倾倒堆积**后的稳态体积分数，文献基准
`phi_rcp = 0.6366`（Scott 1960; Bernal & Mason 1960，机型可读锚 `benchmarks/rcp_jamming_audit/runs/audit.json`）。账本判据：体积分数落在 [0.62, 0.66]，并要求 **10000 球、无摩擦/低摩擦两档**；
精度标准 < 3 %。

本次复核的装置（`src/tensordem/deposition_packing.py`）与原先一致：
单分散球 d=1、rho=1、g=1（无量纲），方形底周期胞 + z=0 摩擦地板，
线性弹簧-黏壶法向（e=0.1，k_t=k_n/2），dt=t_c/20，速度 Verlet + Cundall-Strack 切向弹簧。

## ② 怎么做的（要核的问题 / 方法 / 工具链）

**要核的问题**：合并版报告 `docs/CASE_RCP_DEPOSITION.md` 的参数表写「N particles: 2000 (production)」与「seeds: production tiers: 3 seeds each」，
但 `plan.json` 的 production 波是 12 个 `N = 10000` 案例，且 `runs/` 里
每个生产档只有 2 个种子。即：文档把**筛选尺度**当成了生产尺度，并宣告了
一份**未执行**的种子覆盖。两个陈述都没有数据支撑——是欠账，不是造假。

**做法**：
1. 直接执行 `plan.json` 的完整 production 波（索引 0–11，12 个 `N=10000`
   案例：两档摩擦 × 3 种子、k_n 4000/16000/64000 刚度梯度、dt/2 时间步探针）。
2. 用**同一选择规则**（`aggregate.py`：production 尺度 = 两档摩擦都覆盖的
   最大 N）分别统计「合并时的筛选集 N≤4000」与「完整集」，得到 before/after。
3. 在 `aggregate.py` 里把「种子覆盖」从**手写断言**改成**读数据的表格行**，
   并新增两道可机器裁的闸门：
   - `G15_production_size`：`N_production >= 10000`（账本字面判据）；
   - `G16_seed_coverage`：每个生产档 `>= 3` 个独立种子（文档的自身承诺）。
4. 工具链：`shard.py`（一例一进程，集群/本机同一入口）→ `debt_audit.py`（本文档）
   → `aggregate.py`（主报告与图）。

## ⑤ 注意点（坑 / 局限 / 适用范围）

1. **种子散度随 N 收缩**：N=2000 时两档 std 为 1.3e-3 / 1.0e-3，
   N=10000 时降到 2e-4 / 4e-4 量级——这是有限尺度涨落的正常行为，
   也说明原先「2 个种子」的均值不足以支撑 3 % 判据的余量讨论。
2. **软球系统偏差仍在**：生产 k_n=4000 的有摩擦档落在基准带内但偏低，
   硬球极限与基准的差额见 §3.3，未因换尺度而变小。
3. **基准是倾倒实验**，装置同为倾倒，方法匹配；残余差来自单分散软球
   理想化 + 周期侧壁。
4. **本单不算 6.5 万步以上的长时老化**：判据是 KE 稳定 4 个重力时间，
   更长的二次压实（若存在）不在测量范围内。
