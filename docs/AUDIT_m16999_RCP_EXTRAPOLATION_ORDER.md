## ① 案例介绍

随机密堆（RCP）判据的**生产量**（$\phi$ 落在 [0.62, 0.66]，两档摩擦）在上一波已经用
$N=10000$、3 种子满足；残留的欠账不是生产量，而是**软球→硬球外推的可核性**：
上一波给出的 $k_n\to\infty$ 截距 `mu=0: 0.63644`、`mu=0.1: 0.61705` 来自
**三级刚度**拟合（4000/16000/64000）。三个点恰好定三个参数
（$\phi_\infty, C, p$），该拟合**无法自证**——它没有留出任何可以被它预测错的测量。
本单补第四级 $k_n=256000$（两档），用「拟合最粗三级→预测最硬一级」把它变成可证伪的检验；
并补 $k_n=64000$ 处的半步长探针，把有摩擦档观察到的阶数异常（$p\approx0.5$，
而线性弹簧压缩性对应 $p=1$）归因到刚度系统误差或 Cundall-Strack 一阶时间积分。

装置与生产波完全一致（`src/tensordem/deposition_packing.py`）：单分散球 $d=1$、$\rho=1$、
$g=1$，方形底周期胞 + $z=0$ 摩擦地板，线性弹簧-黏壶法向（$e=0.1$，$k_t=k_n/2$），
速度 Verlet + Cundall-Strack 切向弹簧，$dt=t_c/20$。

| 量 | 设置 |
|---|---|
| $N$ | 10000 |
| $k_n$ 梯级 | 4000, 16000, 64000 |
| 摩擦档 | $\mu=0$ 与 $\mu=0.1$ |
| 新增跑次 | $k_n=256000$ 两档（$dt=t_c/20$）、$k_n=64000$ 两档（$dt=t_c/40$） |
| 基准 | $\phi_{rcp}=0.6366$（Scott 1960; Bernal & Mason 1960） |

## ② 怎么做的

1. **留一级预测**：库内新函数 `tensordem.deposition_packing.extrapolation_selfconsistency`
   用最粗三级定 $\phi_\infty, C, p$，再按同一幂律预测最硬一级，与该级实测比较，
   给出 `prediction_error`（样本外误差）与 `limit_shift`（纳入该级后截距的移动量，即外推自身误差棒）。
2. **时间步锚点**：$k_n=4000$ 与 $k_n=64000$ 各跑 $dt=t_c/40$，用两点 Richardson
   $\phi(dt\to0)=2\phi(dt/2)-\phi(dt)$ 去掉一阶时间误差，检查梯级残余是否仍非 $p=1$。
3. **闸门化**：`G17_extrapolation_selfconsistency_mu*`（预测误差与截距移动都 < 0.002）、
   `G18_timestep_at_stiffest_mu*`（最硬级时间步收敛），与主报告的 `G1–G16` 同一判据家族。
4. 工具链：`run_case.py`（一例一进程）→ 本脚本（`order_audit.py`，生成本文与图）
   → `aggregate.py`（主报告同步纳入新梯级与新闸门）。

### 3.3 Friction scaling (already-served smaller-N runs, no new compute)

The reference is a *frictionless* random close packing; a frictional
pour is expected to be looser, so part of the `mu = 0.1` gap is physics.
The served `mu = 0, 0.1, 0.3, 0.5` runs at small N give that scaling:

| mu | phi (N=2000, k_n=4000) | Delta vs previous mu | seeds |
|---|---|---|---|
| 0 | 0.63746 | &mdash; | 2 |
| 0.1 | 0.62433 | -0.01313 | 2 |
| 0.3 | 0.60454 | -0.01979 | 1 |
| 0.5 | 0.59310 | -0.01144 | 1 |

At production size (N=10000) the measured `mu = 0` minus `mu = 0.1` gap is **0.01609**, i.e. the same order as the -1.6 % deviation the frictional tier shows against the reference. Reading the whole -3 % of the frictional intercept as a numerical error is therefore wrong: a friction-induced offset of this size is physical here (monotone in mu, `G19`). The numerical part of the gap is the extrapolation error bar quantified in §3.1b, not the -3 %.

## ⑤ 注意点（坑 / 局限 / 适用范围）

* **三级拟合天生不可检**：三参数三个点，残差恒为零；上一波把该截距当结论引用，
  本单的 `prediction_error` 才是它的误差棒。第四级之前，「外推误差 < 3 %」这句话是假设不是测量。
* **有摩擦档的阶数不是 1**：$\mu=0.1$ 相邻对的 $p$ 见 §3.2；若它与时间步锚点的标度一致，
  说明该档的刚度梯级里混入了一阶切向历史误差，硬球截距应带更宽的误差棒。
* **摩擦档 vs 无摩擦基准**：$\phi_{rcp}=0.6366$ 是无摩擦（可滚动）随机密堆值；
  有摩擦倾倒体本身就该更低（实验上 $\phi$ 随 $\mu$ 单调下降，本仓 $N=2000$ 的
  $\mu=0,0.1,0.3,0.5$ 四点同向），所以「有摩擦档偏离基准 3 %」里**物理项与数值项混在一起**——
  本文只量化数值项（截距移动、时间步误差），不把剩余差额当纯误差。
* 判据 $N=10000$、两档摩擦的生产量不受本单影响（仍为上一波口径）；本单只动外推。
* 未做：$k_n=1000000$ 级的第五级（成本约 2×）、长时二次压实、非单分散/非球形修正。
