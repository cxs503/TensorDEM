## ① 案例介绍

MT Uikku 是 Riska et al. (1998) 的全尺度冰区试航（波罗的海，运输船），
仓库 `benchmarks/dem3d/ship_ice_validation/mt_uikku_level_ice.csv` 收录 10 个
**平整冰（level ice）** 工况（test 103/104/205/206/301/302/303/401/402/403）：
冰厚 0.63–1.04 m，冰漂移速度 0.2 / 0.5 / 1.0 m/s，弯曲强度 540–1029 kPa，
压缩强度 1748–5389 kPa；表-3 给出实测平均/标准差/最大值阻力（401–403 无最大值）。
同一 CSV 还附带 4 个经验公式（Lindqvist / Riska / Jeong / Keinonen）的预测值。

被审计对象：`src/tensordem/ice_broken_field/mt_uikku_validation.py`（M4），
它把 M3 的**碎冰场**（浮冰半径 3 m、浓度 C = 0.6–0.9、压碎律 `F_n = σ_c h w`）
当成对上述平整冰试验的验证面。

## ② 怎么做的

只读审计 → 复现 → 归因，不改求解器本体（改动会触及 M3 的 Lindqvist 验收带，
属模型重新验收范围，不是审计编辑）：

1. **读代码**：`verify_mt_uikku()` 的判据聚合、`run_mt_uikku_case()` 的算例表、M3 接触律。
2. **发现 3 类缺陷**（下文 ⑤）：相关系数硬编码、速度溯源错误、接触几何缺陷。
3. **修 M4 表面**（本单交付）：
   - 算例表改为**只从 CSV 读取**（`load_mt_uikku_cases()`），速度字段用
     `ice_drift_speed_m_s`；内嵌兜底表保留但打 `FALLBACK_EMBEDDED` 标记；
   - 删除硬编码 `0.85`，改为**数据驱动的跨工况 Pearson/Spearman**
     （`score_cases()` 纯函数，判据旗标由数字派生，绝不直接断言）；
   - 时序相关系数显式 `WITHHELD`（仓库无实测时历，"常数不得冒充统计量"）；
   - 新增 `overall_verdict = "WITHHELD"` + `verdict_reasons`，以及
     `steady_state_reach()` 稳态可达性判据（船体长 121.9 m，要求扫过 ≥3 倍船长）。
4. **归因实验**（`scripts/m4_mt_uikku_audit.py`）：对同一 10 工况做 2×2 矩阵——
   L0 出厂几何+出厂速度 / L1 出厂几何+实测漂移速度 / L2 修正几何+出厂速度 /
   L3 修正几何+实测漂移速度——把误差来源拆开，并与 CSV 自带 4 个经验公式同尺对照。
   dt = 0.01 s、t_total = 60 s、seed = 42，与出厂设置一致。

## ⑤ 注意点（缺陷清单与判定）

**F1 证据造假（已修，阻塞级）** 旧版 `verify_mt_uikku()` 里
`correlations.append(0.85)  # placeholder (would need actual time series)`，
该常数被直接当作 `rho ≥ 0.7` 判据的结果上报，且 `tests/test_ice_broken_field.py`
用 `assert result["correlation_criterion_pass"]` 把这个常数断言成"通过"——
即**判据通过是代码自己写的，不是数据算出来的**。本单删除常数，改为跨工况
Pearson/Spearman；时序 rho 显式 `WITHHELD`。

**F2 速度溯源错误（已修，阻塞级）** 旧表把试验速度写成 3/5/7 kn
（表里没有这个字段），实跑 1.54/2.57/3.60 m/s；CSV 记录的是**冰漂移速度**
0.2/0.5/1.0 m/s，即 DEM 被跑快了 3–7 倍。且 `ship_speed_kn` 是**推导量**而非输入量，
现已改为派生属性。注：修速度后误差并未变小（L1 2414 % > L0 1472 %），
说明"跑太快"掩盖了更深的问题——见 F3。

**F3 接触几何缺陷（已量化，未改求解器）** `ship_hull_signed_distance()` 对壳外点
一律返回常数 `1.0`，且只有**浮冰中心进入船体**才算接触，返回的"壳内深度"被直接
当成压入量（最大 13 m），Hertz 弦宽 `2√(2Rδ)` 再被手工截到 `2R`——
于是每条被"吞进"船体的浮冰贡献 `σ_c h 2R` ≈ 8 MN 的恒定力，且旧版侧向推移
（0.5 v dt）让浮冰**滞留壳内**，形成永不消失的假阻力。这正是 L0 高估 15 倍的机制。
改为圆盘–多边形真有符号距离 + 精确弦宽 `2√(2Rδ−δ²)` + 沿船体法向的轴向量分解后，
误差从 1472 % 降到 103 %，仍差 2 个量级——因为碎冰场模型里根本没有平整冰
所需要的连续压碎/挤压阻力机制。

**F4 制度性混淆（已声明，未解）** CSV 的 10 个工况是**平整冰**（C = 1.0，
表内无浓度列；旧模块按冰级假设 0.9/0.8/0.7/0.6，属 ASSUMED），而 M3 是**碎冰场**。
维护链路 `tensordem.broken_ice_resistance.validation` 的 C4 判据已因同一理由
声明 `WITHHELD`——两条链路对同一数据源的判定必须一致，本单让 M4 与之对齐。

**F5 稳态不可达（已声明）** 实测漂移速度下 60 s 只扫过 12 m ≈ 0.1 倍船长
（船体长 121.9 m），"后 50 % 均值"仍是启动瞬态。稳态判据要求 ≥3 倍船长，
在 0.2 m/s 下需 1830 s（≈18 万步），出厂时长差 30 倍。

**F6 结论**：M4 不能作为 MT Uikku 的验证证据。旧的"8–15 倍高估"不是模型能力，
而是浮冰滞留假象；修正后仍差 2 个量级，说明**碎冰场模型族不适合平整冰阻力**，
MT Uikku 打分应走 `broken_ice_resistance`（经验链，C4 已 WITHHELD）并补录
破损冰航道工况 304–306 / 404–406。

## ⑥ 误差判定（逐项，显式回答）

| 关键量 | 基准 | 本实现误差 | 是否 <3 % |
|---|---|---|---|
| 平均阻力（L0，出厂原状） | MT Uikku 实测均值 | 1471.8 % | **否** |
| 平均阻力（L3，速度+几何皆修） | 同上 | 103.1 % | **否** |
| 跨工况相关系数（L0） | — | 0.043（判据 ≥0.7） | **否** |
| 时序相关系数 rho | 实测时历 | 无数据 → `WITHHELD` | 无法判定（不伪造） |
| 负控制 h_i = 0 → R = 0 | 0 N | < 1 N | 是 |
| 算例表 vs CSV 溯源 | 10 工况全字段 | 全等（测试断言） | 是 |
| 参考带：CSV 自带经验公式 | 实测均值 | 22.7–51.4 %（r 0.87–0.94） | 否（仅作对照） |

**诚实结论：本单不产生"MT Uikku 验证通过"的结论；M4 判为 `WITHHELD`（结构性）+
平均阻力判据 `FAIL`。** 本单的实质增量是证据完整性（去掉伪造统计量）、
数据溯源（CSV 单一真源 + 3–7 倍速度修正）、以及把 15 倍偏差归因到具体缺陷
（几何吞壳 + 滞留），并给出可复现的 2×2 归因矩阵。
