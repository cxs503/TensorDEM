## ① 案例介绍

圆柱形颗粒柱（$r_i$, $h_i=a r_i$）在粗糙水平面自由坍塌。参考：Lube et al. (2004) JFM 508.

参考公式（运行时求值）：
```
Lube, Huppert, Sparks & Freundt (2004) JFM 508, 175-199, doi:10.1017/S0022112004009036, abstract: r_inf = r_i(1 + 1.24a) for a < 1.7; r_inf = r_i(1 + 1.6a^(1/2)) for 1.7 < a; t_inf = 3(h_i/g)^(1/2) = 3(r_i/g)^(1/2)a^(1/2)
```

## ② 方法

* 内核：TensorDEM 3D 接触（线性弹簧-阻尼+Cundall-Strack+滚动阻力），速度 Verlet。
* 几何：HCP 圆柱堆积，t=0 释放。
* Runout：径向 99.5% 分位 + 颗粒半径。

* 构型：(μ,μ_r,μ_w)=(0.5,0.5,0.8)，经轮 1-5 标定。

## ⑤ 注意点

1. 底板摩擦是关键杠杆：μ_w=0.8 使 a=3 从 +18.3% 降至 +5.6%；μ_w=1.0 非单调变差。
2. 历时判据系统性偏差（+15%~+54%）：DEM 蠕变尾段 vs 实验「突然停止」定义差异。
3. 分辨率不确定度 ~5-7 个百分点（8→12 粒/r_i）。
4. 接触局部 μ(I_c) 证伪：I_c ≪ I_0，不是柱坍塌的合适应变率代理。
5. 适用：干颗粒、轴对称、HCP 初始堆积。
