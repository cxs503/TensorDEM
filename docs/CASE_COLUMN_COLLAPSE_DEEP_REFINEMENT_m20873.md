## ① 案例介绍（物理背景 / 几何 / 参数）

半径 $r_i=0.48$ m、高 $h_i=a r_i$ 的圆柱颗粒柱在粗糙刚性底板上瞬间失去侧向约束后重力驱动坍塌，
沉积后的无量纲跑距服从 Lube et al. (2004) 的两段标度律：

$$r_\infty/r_i = 1+1.24a\ (a<1.7),\qquad r_\infty/r_i = 1+1.6\,a^{1/2}\ (a>1.7);\qquad t_\infty = 3\sqrt{h_i/g}.$$

本单只补 m18261 自己申报、m20337 与 m20559 都未闭合的**两格**，并把它们所在的两条阶梯
（$a=1$：8/12/16；$a=3$：8/12）整条重算，使 $a=1$ 与 $a=3$ 的细化证据端到端可机读、零手抄。

冻结闭合臂（**未重调任何参数**，m18261 `CLOSING_ARM` 原样）：$\mu=0.5$、$\mu_r=0.5$（Cundall–Strack +
滚动阻力）、$\mu_{\rm wall}=0.8$、$e=0.5$、$k_t/k_n=0.5$、$\rho=2500$ kg/m³、$g=9.81$ m/s²、
初始 HCP 晶格 + 2 % 格隙、`jitter`=0、seed=12345、`dt_scale`=1、`duration_factor`=8、`sample_stride`=5。
细化口径（m18261 冻结）：$r_i$ 与无量纲接触刚度 $\delta/d=\pi\rho g d^2/(6k_n)$ 固定 ⇒
`radius = 0.24/gpr`、`kn = 6e4 (d/0.03)^2`。

**三条实质结论**

1. **a=1 的第三档补齐，细化成立**：8/12/16 三档全在 15 % 带内（−9.88 / −6.63 / −9.02 %），
   12→16 漂移仅 **2.40 pp**。m18261 留给 a=1 的 `incomplete` 由此**闭合为 supported**。
2. **深端（$a=3$）出现第一条出带反例**：$a=3$ 从 8 粒/半径的 +8.09 % 走到 12 粒/半径的
   **+15.40 %**——**超出 15 % 判据 0.40 pp**。这是锚点历史上**第一次**在跑距律上出现出带点
   （此前 6 个长宽比/多分辨率共 15 例无一出带）。故 `P3`/`P6` 记 **fail**，
   深端「跑距分辨率无关」**不能**宣称；`P4`（漂移 7.31 pp ≤ 15 pp）虽 pass，
   但**不可**用「漂移小」掩盖「绝对值出带」——这是本单要防的读法错误。
3. **第二预言（埋置时间）在 $a\ge 1$ 上其实成立，且达 <3 %**：$a=3$ 两档 $t_{90}$ 误差
   **−1.39 % / −1.79 %**，$a=1$ 三档 −2.26 / +2.26 / −0.75 %。结合 m20337 的浅端失败
   （$a=0.5$ 全族 +11…+41 % 且非单调），可把锚点的时间条款改写为
   **「$a\ge1$ 成立（≤2.3 %），$a=0.5$ 不成立」**，而不是笼统的「时间律被否证」。

## ⑤ 注意点（坑 / 局限 / 适用范围）

1. **m20559 的「fetch 不返回工作树输出」在本单未复现**：`cj3021`/`cj3022` 的 fetch tar 内
   含 `repo/runs/case_column_collapse_time_m18261/cases/*.json`（5339 条）。故该基础设施欠账
   应改记为「曾经发生、现已不可复现」；本单仍保留日志内 payload 通道作为旁路。
2. **一处口径缺陷被本单的 provenance 断言抓出**：m20337/m19922/m20259 的存档把 Lube 律在**名义**
   $a$ 上求值；本单主判据改为**实测** $a_{\rm meas}$（m20533 口径），并断言存档列
   `ref_runout_ratio == lube(a_nominal)` 后才重算。两种口径在 $a=2$ 上差约 0.5 pp、在 $a=0.5$ 上差约 3 pp。
3. **一处不可复现的算例漂移（诚实申报）**：`R_a3_g8` 本次 $r_\infty/r_i=4.1193$，m18261 存档为 3.984
   （相对差 **+3.4 %**）；同批 `R_a1_g8`（2.1060 vs 2.106）、`R_a1_g12`（2.0782 vs 2.079）几乎逐位复现。
   漂移未归因（候选：库/沉积路径变动、该例停止判据的边界敏感性），已在报告里显式标注；
   `P4` 用**本次同批**的两点算漂移以保内部一致，若改用存档值则为 9.8 pp，同样 pass，结论不翻转。
4. **单实现、无系综**：每配置一次确定性积分（`jitter=0`），系综散布轴由 m19922/m20259 负责，
   本单结论是离散化轴的事实，不与系综散布混淆。0.40 pp 的出带量级小于 m20337 记录的
   12→16 档漂移（8.13 pp），故**不应**读成「深端物理失效」，而应读成
   「**15 % 判据在深端高分辨率处不被满足**」——这正是验收条款要的答案。
5. **穿透过门未记录**：m18261 协议 `return_positions=False`，不落粒子重叠计数，
   故 `P7` 的重叠子句记 `not_run`，不以 `stop_reason` 代替（诚实分级）。
6. **未做**：多分散/颗粒形状/初始体积分数敏感性；$a=3$ 的 16 粒/半径档（N≈4.6 万，单例 > 20 min）；
   $a\in(1.7,2.0)$ 断点邻域的新长宽比点。

## ⑥ 误差判定（逐项，显式回答「是否 <3 %」）

| 关键量 | 基准 | 误差 | <3 % ? | <15 % ? |
|---|---|---|---|---|
| 跑距 `R_a1_g16`（本单补格） | Lube 跑距律 @$a_{\rm meas}$ | −9.02 % | **否** | 是 |
| 跑距 `R_a1_g8 / g12`（重算） | 同上 | −9.88 % / −6.63 % | 否 | 是 |
| 跑距 `R_a3_g12`（本单补格） | 同上（平方根支） | **+15.40 %** | **否** | **否（超线 0.40 pp）** |
| 跑距 `R_a3_g8`（重算） | 同上 | +8.09 % | 否 | 是 |
| 跑距 $a=2$ 深端 8/12（存档） | 同上 | +4.04 % / +4.58 % | 否 | 是 |
| $t_{90}$ `R_a3_g8 / g12` | $3\sqrt{h_i/g}$ @$a_{\rm meas}$ | **−1.39 % / −1.79 %** | **是** | 是 |
| $t_{90}$ `R_a1_g8 / g12 / g16` | 同上 | −2.26 % / +2.26 % / −0.75 % | **是** | 是 |

**显式回答「是否 <3 %」**：跑距律**无一例**达 3 %（最好 +4.04 %，存档）；埋置时间律在
$a\in\{1,3\}$ 的 5 个算例上**全部 <3 %**（最大 2.26 %），但 $a=0.5$ 达不到（m20337：+11…+41 %）。
故「<3 %」只在时间律的中/深端长宽比上成立，跑距律不成立。
