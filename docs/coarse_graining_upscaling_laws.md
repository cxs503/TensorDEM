## 1. 物理背景

离散元（DEM）不可能按真实砂粒数量模拟船舶/海冰工程尺度的颗粒材料。粗粒化（coarse-graining,
up-scaling）把 N 个半径 R 的细粒替换为 N/f³ 个半径 fR 的粗粒（定常固体密度），并重新标定接触
参数，使**宏观响应不变**。困难在于：接触层面的无量纲量不止一个，"保持哪一个"决定了整条标度律，
而不同宏观观测量对口径的敏感度不同——这正是本节点要量化并给出失效边界的对象。

接触本构（与仓库参考内核 `tensordem.granular3d_core` 完全一致）：
法向线性弹簧-阻尼 `F_n = max(k_n δ − γ v_n, 0)`；切向 Cundall–Strack 增量弹簧饱和于 `μ F_n`；
滚动弹簧饱和于 `μ_r R F_n`。接触时间 `t_c = π√(m_eff/k_n)`，`m_eff = m/2`。

## 2. 定标律（两口径）

| 量 | 口径A `contact_time` | 口径B `stiffness_invariant` |
|---|---|---|
| 半径 R | f·R | f·R |
| 质量 m / 转动惯量 I | f³·m / f⁵·I | f³·m / f⁵·I |
| 法向刚度 k_n | **f³·k_n** | **f·k_n** |
| 切向刚度 k_t | f³·k_t | f·k_t |
| 滚动刚度 k_r = k_t R² | f⁵·k_r | f³·k_r |
| 阻尼 γ = α·2ζ√(m_eff k_n) | f³·γ | f²·γ |
| 恢复系数 e、摩擦 μ、滚阻 μ_r、重力 g | 不变 | 不变 |
| 接触时间 t_c | 不变 | f·t_c |
| 时间步 Δt = t_c/20 | 不变 | f·Δt |
| 颗粒波速 c = R√(k_n/m_eff) | f·c | 不变 |
| 接触力 F | f⁴·F | f²·F |
| 应力 / 模量 σ, E_eff | **f²·σ** | **不变** |
| 无量纲刚度 k_n/(m g) | 不变 | f⁻² |

**推导要点**

* 口径A：`t_c = π√(m_eff/k_n)`，`m_eff ∝ f³` ⇒ `k_n ∝ f³`；滚动刚度按 `k_r = k_t R²` 随之 `f⁵`；
  恢复系数不变 ⇒ `ζ` 不变 ⇒ `γ = 2ζ√(m_eff k_n) ∝ √(f³·f³) = f³`。力 `F = k_n δ`，`δ ∝ f` ⇒ `F ∝ f⁴`，
  应力 `∝ F/R² = f²`，模量 `E ~ k_n/R ∝ f²`。**k_n/(m g) 严格不变 ⇒ 重力驱动的准静态相似性保持。**
* 口径B：`c = R√(k_n/m_eff)` 不变 ⇒ `k_n ∝ f`；`E ~ k_n/R ∝ f⁰` 不变；`k_r ∝ f³`；`γ ∝ √(f³·f) = f²`。
  **代价**：`t_c ∝ f`（接触时间变长），`k_n/(m g) ∝ f⁻²`（相对重力变软，自重驱动的重叠率 ∝ f）。
* **阻尼由恢复系数反解**：闭式 `γ = 2ζ√(m_eff k_n)`（`ζ = |ln e|/√(π²+ln²e)`）只在无"只压不拉"
  截断的线性振子下给出目标 e；实际内核 `F_n = max(...)`, 恢复段提前脱开，实测 e 偏高
  （示例：目标 e=0.30 时闭式给出实测 0.41–0.46）。因此实现 `calibrated_damping_scale()`：用同一
  接触律做单对心碰撞数值标定，反解乘子 α 使**实测**恢复系数命中目标（残差 ≤1e-3）。α 只依赖无量纲
  步长比 Δt/t_c（两口径都不变），故上表的 γ 指数与 e 不变性不受影响。
* **负控（错误定标）**：`mass_only`（只放大质量不改刚度）使 `t_c ∝ f^{3/2}`；
  `kn_f3_for_stiffness`（把口径A的 k∝f³ 用在要求刚度不变的问题上）使 `E_eff ∝ f²`。
  两者都必须被宏观判据拒绝。

实现：`src/tensordem/upscaling/law.py`（`SCALE_TABLE` / `APPLICABILITY` / `stability_gate` 与代码同源，
文档表格与 JSON 一致）。

## 3. 三个宏观算例（协议）

| 算例 | 装置 | 观测量 | 无量纲协议 |
|---|---|---|---|
| `shear` | 周期性直剪盒（x 剪切方向、y 周期），**恒载压板**（σ_n = 200 Pa 死载，非伺服增益） | 宏观摩擦系数 μ_macro = τ/σ_n、摩擦角 φ = atan μ | 应变率 1.0 1/s，`I = γ̇ d√(ρ/σ) ≈ 7e-3` 准静态 |
| `repose` | 旋转滚筒（y 轴，Froude 相似） | 休止角 θ_r（自由面斜率鲁棒拟合，30 张快照） | Froude 数 `ω²R_d/g = 0.051` 不变 |
| `ucs` | 单轴压缩（侧向周期 ⇒ 零侧应变），上下粗糙压板 | 约束模量 E_eff = dσ_axial/dε（ε∈[5e-4,3e-3]）、力-位移首峰 | 工程应变率 0.40 1/s |

两种模式：

* `similar`：所有长度 ×f，颗粒数不变 —— 隔离**定标律误差**（本节点的判据主体）；
* `fixed_domain`：试样尺寸保持 f=1，颗粒半径 ×f（N→N/f³）—— 叠加**分辨率/RVE 误差**（真实粗粒化的代价，f=2 实测）。

基础材料（f=1）：R=1 mm、ρ=2500 kg/m³、k_n=100 N/m（k_n/(m g)=1.0e6）、k_t=k_n/2、
e=0.30（标定后实测 0.2995）、μ=0.5、μ_r=0.05、g=9.81 m/s²、Δt=t_c/20。

## 5. 适用域与失效边界（声明）

**口径A（k_n ∝ f³，接触时间不变）**
* 适用：重力驱动的准静态流动与强度类问题（休止角、直剪强度、料仓/堆积、准静态贯入），
  力-位移曲线的**形状**相似（力按 f⁴ 归一）。
* 保留：t_c、k_n/(m g)、e、μ、μ_r；颗粒波速 ∝ f（动态问题会更快）。
* 失效边界：任何**以绝对刚度/应力/波速表述**的判据。E_eff、应力按 f² 偏大（f=2 即 +300%，
  f=8 +6300%），波速 ∝ f。因此不能用于波传播、弹性加载刚度、地震响应类问题——除非按 f² 反归一。

**口径B（k_n ∝ f，刚度/波速不变）**
* 适用：要求宏观刚度、应力水平与颗粒波速不变的场景（单轴/三轴模量、动力压实、波传播）。
* 保留：E_eff、σ、c；t_c ∝ f。
* 失效边界：自重驱动问题的可压缩性。接触重叠率 `δ/R = 4σR/k_n` 在自重力下 ∝ f；
  以 10 颗粒直径床深自重应力为基准，f=1 时 δ/R≈1.2%，f=8 时≈9.4%，**超过 2% 线性接触律有效限**
  （图中 `fig_validity_boundary.png`）。即：口径B在 f≳2–4 之后对重力主导的流动/强度问题不可信。

**负控**：`mass_only`（t_c ∝ f^{3/2}）与 `kn_f3_for_stiffness`（E_eff ∝ f²）均被宏观判据拒绝（见结果段）。

**时间步稳定性门**：Δt = t_c/20 对两口径所有 f 都满足（`stability_gate`：≥20 步/接触周期、
重叠率 ≤2%、`v_max Δt/R ≤5%`、阻尼为正且 e<1）。判据⑤另在实测中检查：`v_max < 10 v_ref`
（v_ref = √(gH)）与沉降段总能量单调不增。

## 6. 局限（如实）

1. **单分散球 + 线性接触**：Hertz–Mindlin 或非球形颗粒的标度指数不同（Hertz 需要 k_n ∝ f^{?} 的
   另一套推导），本工作不覆盖。
2. **f=8 的统计量有限**：`similar` 模式颗粒数与 f=1 相同（~300–600 粒），但 `fixed_domain` 真实
   粗粒化只做到 f=2（f=4 时试样只剩 ~10–30 粒，已在文档中声明不可信而非硬跑）。
3. **μ_r 视为不变**：无黏结干颗粒的常用假设；有黏结/湿颗粒（冰区湿冰、冻结核）需要额外标定。
4. **剪切盒为恒载压板、周期边界**：无限层近似，无侧壁拱效应；剪切应变窗口 0.084（窗口后段平均），
   未跑到完全临界状态，各 f 用同一协议因此横向可比。
5. **E_eff 为约束（oedometric）模量**（侧向周期、零侧应变），与真三轴 Young 模量差一个
   `(1−ν)/((1+ν)(1−2ν))` 因子；判据用它是因为它对 k_n/R 的标度最干净（口径B严格不变）。

**结论**：定标律本身（接触时间、阻尼-恢复系数反解、刚度/波速指数、力与应力指数）已验证到解析/机器精度；
但"宏观不变量在 300–600 粒、1–3 个实现的系统上落在 5%/10% 带内"这一**机器判据在本轮系统规模下不可达**。
要把 ①③④ 做成，需要：更大系统（f=1 时 ≥10⁴ 粒以使粗粒仍保有 RVE）+ 更多实现（≥5）+ UCS 的无重力
预压固结协议（本轮尝试未稳定，已记录），或者改用无侧向约束的真三轴 + 卸荷模量。
