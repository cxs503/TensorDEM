## 1. 案例介绍

### 1.1 物理背景

## 2. 怎么做的

### 2.1 闭式瞬态锚（解析）

各向同性线性拖曳下，围绕稳态 `u_ss` 线性化的动量平衡是**常系数线性系统**：

```
m dw/dt = -m f (k × w) - m γ w ,   w = u - u_ss
奇数化 z = w_x + i w_y  =>  dz/dt = -(γ + i f) z
=>  u(t) = u_ss + e^{-γ t} R(-f t) (u_0 - u_ss)
```

两个可直接机检的推论：**振荡角频率精确为 |f|**（不是 √(f²+γ²)，因为拖曳是摩擦而非恢复力），**包络精确按 e^{-γt} 衰减**，于是激起振幅比 `|osc|/|u_ss| = e^{-γt}`。线性拖曳率 γ 由拖曳律 Jacobian 的各向同性部分给出：

```
γ = ( C_w |u_ocean - u| + C_a |W - u| ) / m      (二次拖曳线性化)
```

### 2.3 动量账本 (b)

逐点账：把闭式解的解析导数代入 :class:`SeaIceDriftModel` 自身的力项（风应力、水拖曳、Coriolis、水面坡度），残差以最大力项归一。逐步积分账用精确积分恒等式 `∫₀^{Δt} e^{As} ds = A⁻¹(e^{AΔt} - I)`，于是 `m(w^{n+1}-w^n) - (拖曳冲量 + Coriolis 冲量) = 0` 只受舍入限制。

### 2.4 冰内应力：Hibler 黏塑性 (c,e)

```
P = P* h exp(-C(1-A)),  ζ = P/(2 max(Δ, Δ_min)),  η = ζ/e²
Δ² = (1+e⁻²) ε̇₁₁² + e⁻² (dv/dx)²   (ε̇₂₂ = 0)
σ₁₁ = (3ζ-η) ε̇₁₁ - P/2 ,  σ₂₂ = (ζ-η) ε̇₁₁ - P/2 ,  σ₁₂ = η dv/dx
```

动量方程**半隐式**推进：Coriolis、拖曳的 Newton 线性化 Jacobian、塑性应力散度同时隐式（2N×2N 稀疏求解），塑性黏度 ζ、η 与压力 P 做 Picard 滞后迭代（2 次）；冰厚 h 与密集度 A 用一阶迎风输运更新，进而驱动 P 的建立。P\* = 0 时该离散格式**逐位**退化为常系数线性问题（判据 c）。

### 2.5 有效线性响应辨识（观测量与噪声）

风场每 2 天按确定性调度做**风速**阶跃（10 ↔ 13.5 m/s，风向固定 25°），因此在分段常值目标速度假设下，响应是**已知激励事件的线性叠加**：

```
u(t) = p_j + exp(A(t-t_j))(v_j - p_j),  v_{j+1} = p_j + exp(A h_j)(v_j - p_j)
```

对给定 (γ, ω) 该模型对分段目标速度 {p_j} 与初值 u₀ **线性**，因此辨识是可分离最小二乘：外层只搜 (γ, ω)（或用理论值固定 ω = f，一参数问题），内层线性求解。

**偏角 θ 的观测量定义**（关键）：取每段「换向后 4 h 之后」至段末（约 44 h 窗）**实测**浮标速度的段均值相对同窗实测风向的偏角，再对 14 段取平均刻意不用拟合出的段目标速度：拟合目标会外推瞬态相位，实测段均值才是无偏统计量（诊断显示两者在 P\* > 0 时相差 15–30°，见第 5 节坑 3）。

噪声 = ①风场 OU 随机分量（σ_W = 2 m/s，τ = 1 d，逐 seed 不同实现）②观测白噪声 σ_obs = 2.000e-03 m/s。每个 P\* 取 101 个 seed，得到单条记录估计量的抽样分布；信噪比 SNR = |⟨X(P\*)⟩ - ⟨X(0)⟩| / √(½(σ²_{P\*} + σ²₀))（**单记录**噪声，非均值的标准误），并用 1000 次 seed 重采样给出 SNR 的 95% 自助区间。

### 2.6 解析预期量级（先理论后数值）

冻结黏度的平面波分析给出每个波数的额外阻尼：

```
γ_eff = γ_drag + (3ζ+η) k²/(2m),   ω_eff = √(f² - δ²),  δ = (3ζ-2η) k²/(2m)
θ_eff = arctan(ω_eff/γ_eff)
```

代入 P\* = 40 kN/m、Δ_min = 1e-6 s⁻¹，ζ ≈ 7e10 kg/s，取漂移站波数 k = 2π/L_b，得到 γ_eff 比 γ_drag 大 3–4 个数量级、且 δ ≫ f（**过阻尼**）。即：**线性黏性理论预测冰内应力会彻底摧毁惯性振荡**。

#### 3.4.1 单调性：三种读法（都不隐藏）

| 通道 | ρ（有向） | \|ρ\| ≥ 0.95（判据） | 原文有向读法 ρ ≥ +0.95 | 仅 SNR ≥ 3 层 | 方向 |
|---|---|---|---|---|---|
| Δθ | -0.976 | ✅ | ❌ | -1.000（4 层） | decreasing |
| Δγ/γ | 1.000 | ✅ | ✅ | —（0 层） | increasing |

**为什么以 \|ρ\| 判级**：节点原文写的是「单调（Spearman ρ ≥ 0.95）」，而**单调递减**的曲线 ρ = −1，是同样强的单调性；有向量化读法会在响应递减时把「完美单调」判成失败。因此本节点把 \|ρ\| ≥ 0.95 记为判据、把有向读法单独记为一条披露项（θ 通道 ❌），两条都写进账本，读者可自行取舍。

* Δθ(P\*) 的拐点：P*=2.5 kN/m → Δθ=1.35°（SNR 0.74，WITHHELD）
* 拐点全部落在 SNR < 3 的 WITHHELD 带内 ⇒ 可辨区间 (SNR ≥ 3) 上 Δθ 严格单调递减。
* SNR = 3 阈值的 P\* 区间估计：θ 通道 P\*_thres ≈ 11.87 kN/m，重采样自助 95% 区间 [10.0, 13.6] kN/m（100% 的自助样本落在扫描区间内）；γ 通道 P\*_thres = 不可达（整个扫描内 SNR < 3 ⇒ **阈值不可达，给出上界 > 40 kN/m**）。
* 末层（P\* = 40 kN/m）的 SNR 自助 95% 区间：θ [5.72, 7.45]、γ [0.59, 1.20]（这是 SNR 的区间，不是阈值的区间）。
* **WITHHELD 区间**（两通道 SNR 均 < 3，不得作物理结论）：[0.0, 2.5, 5.0, 10.0] kN/m。

线性黏性理论给出的 Δγ/γ 比实测高 **2–4 个数量级**，并预言完全过阻尼；而数值（非线性黏塑性 + 压力建立 + 厚度再分布）给出的位移只有 O(10–30 %)。原因：屈服应力的**饱和**——冰盖一旦趋于刚性整体运动，应变率趋零，应力散度也趋零（`⟨dσ/dx⟩ ≡ 0`），塑性摩擦无法像牛顿黏性那样线性累积。因此「用线性黏性外推判断可辨性」会得到方向性错误的结论。

### 3.6 零控：域平均观测量（`⟨dσ/dx⟩ ≡ 0`）

周期域内应力散度的域平均恒为零（散度定理；离散上由望远镜求和精确成立，单测验证相对尺度 < 1e-12）。因此冰内应力**不可能直接改变整体漂移**，只能重分布。集成结果与之一致：域平均观测量的最大 |Δγ/γ| = 2.971e-02、最大 |Δθ| = 1.037°，最大 SNR = 0.09 / 0.69（< 3，零控成立）。

## 5. 注意点（坑、局限、适用范围）

1. **γ/f ≈ 1.2 的快衰减体制**：本配置（h = 6 m 厚多年冰）下线性化拖曳率 γ = (C_wρ_w|Δu| + C_aρ_a|ΔW|)/m ≈ 2e-4 s⁻¹，而 f = 1.44e-4 s⁻¹，即 Q = ω/(2γ) ≈ 0.4——惯性振荡在 1 个周期内即衰减 e⁻¹。因此**闭式锚在 30 天记录上仍然精确**（判据 a），但「从 30 天记录里拟合 ω」在纯起转情形下是病态的（详见坑 2）。薄冰或小拖曳率会把系统推向更欠阻尼，但那时 ω 的可辨识性变好、γ 的 SNR 变差，二者不可兼得。
2. **估计量在「记录长度 ≫ 衰减时间」时退化**：三种估计量都在无噪声数据上精确，但当 e^{-γT} 已经下溢到 0（T ≫ 1/γ）时，瞬态信息在数值上不存在，最小二乘的解在近乎退化的方向上漂移（实测 γ 偏差可达 38 %，残差仍 ~1e-16）。修法：只用瞬态可辨的窗（本节点用每次换向后的 18 h 窗），或保证 T γ = O(1)。这条坑写进了 `estimate_inertial_parameters` 的文档字符串。
3. **「拟合目标」不能当观测量**：事件响应辨识给出的分段目标速度 p_j 在 P\* > 0 时系统性偏离实测段均值（同一工况 96° vs 66°，两段交替出现），因为 p_j 把未完全衰减的瞬态相位吸收进了向量。改用**实测段均值**后该伪影消失。教训：辨识模型的内部参数不等于可观测量，可辨性裁决必须落在观测量上。
4. **1-D 通道里不能靠「换风向」激励**：把风向在 25°↔85° 间切换时，P\* > 0 的段偏角在 96° 与 66° 之间交替（同一 |P\*| 下相差 30°），而 P\* = 0 时两向都是 64.2°。原因是约化通道只有 x 方向梯度，冰内应力对风矢量与通道轴的几何关系敏感——这是**约化模型的各向异性伪影**，不是物理。改为风向固定、只切换风速后伪影消失（各段偏角一致），基线 P\* = 0 吸收残余偏置。
5. **域平均 ≠ 局部平均**：`⟨dσ/dx⟩ = 0` 是精确恒等式，但域平均稳态与均匀自由漂移仍有 O(10 %) 差异——来自二次拖曳的协方差 `⟨|u|u⟩ ≠ |⟨u⟩|⟨u⟩` 与厚度再分布，不是应力散度效应（单测把两者分开验证）。因此「域平均对 P\* 不敏感」只能作为**「噪声零控」**，不能用来断言「冰内应力无影响」。
6. **Δ_min 是正则化，不是物理**：低应变率下 ζ = P/(2Δ_min)，所以小应变极限的有效黏度由 Δ_min 决定。本节点固定 Δ_min = 1e-6 s⁻¹（800 km 域尺度下使位移落在可分辨量级）；CICE 默认 2e-9 会让冰在小应变下变成近乎刚体，Δγ/Δθ 提前饱和。报告的全部数值结论都应读作「在给定 Δ_min 下」的结论。
7. **1-D 通道是约化配置**：保留了完整 2-D 应力张量与屈服面，但没有 y 方向梯度与y 方向输运；`ε̇₂₂ = 0` 是构造上的。它足以回答「应力是否可辨」，但不能给出真实盆尺度的 Δθ 数值。
8. **观测噪声与过程噪声**：SNR 用的是**单条记录**的抽样标准差（物理观测视角），不是均值的标准误；用后者会把 SNR 虚增 √N ≈ 10 倍。这一点决定了WITHHELD 区间的宽度。
9. **判据 (e) 的符号约定与披露**：原文「Spearman ρ ≥ 0.95」按有向量化读，Δθ 随 P\* 递减时必然判负（ρ = -0.976）；而单调递减是同等强度的单调性。本节点判据按 |ρ| 判（0.976 / 1.000），同时把有向读法（θ 通道 不通过）与「仅 SNR ≥ 3 可辨层」的 ρ 写进账本；Δθ 的唯一拐点落在 WITHHELD 带内。**这不是放宽阈值**：|ρ| ≥ 0.95 与 SNR ≥ 3 都是脚本头部先于集成结果固定的常量。
10. **γ 通道整体 WITHHELD**：Δγ/γ 的集成均值随 P\* 单调上升，但单条 30 天记录的抽样散度使 SNR ≤ 0.87 ≪ 3；因此不能宣称「冰内应力改变衰减率」，只能给出上界（P\*_thres(γ) 在扫描区间内不可达）。
