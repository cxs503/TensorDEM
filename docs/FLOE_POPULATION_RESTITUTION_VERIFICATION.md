# floe-population 软球引擎：恢复系数 e 的解析复核（验证欠账 → 缺陷 + 修复）

锚点：`NEW`（总账无对应 slug；建议新条目见文末 §⑦）
仓库：TensorDEM ｜ 模块：`src/tensordem/floe_population/soft_sphere.py` ｜ 任务：m16653 ｜ 分支：`agent/m16653`

**一句话结论**：引擎把恢复系数 `e` 作为物理输入，但**从未被任何测试核对过**它实际产生的 e。
复核发现：在引擎自己的稳定步长 `recommended_dt()` 下，实测 e 相对误差 **中位数 ≈20%、最坏 92.6%**，
且**弹性接触（e=1）会凭空多出 11–21% 动能**；碎冰（ice-like `e ≈ 0.3–0.6`）也偏 17–34%。
新增 `restitution_dt()`（接触半周期 / 80 步）后，所有 `e ≥ 0.2` 的实测误差 ≤ **2.4%**，动量零漂移。
稳定步长语义**未改**（不动生产算例数字），缺陷以"新增正确步长 + 调用方建议 + 测试钉住"的方式落地。

## ① 案例介绍（物理背景 / 参数）

`floe_population` 用一台周期软球 DEM 作为"量测仪器"：碰撞核、`g(σ)`、破碎率都从这台引擎里**数**出来。
接触是线性弹簧-阻尼器（Kelvin–Voigt 型）：

```
F_n = k_n δ - c_n δ̇ ,   c_n = 2 ζ √(k_n m_eff) ,   m_eff = m_i m_j/(m_i+m_j)
ζ(e) = -ln e / √(π² + ln² e)                       （ContactModel.damping_ratio）
```

`e` 直接决定碰撞后的动能分配，因此它**是**碰撞统计闭合的标定支点；`e` 错了，碰撞核与破碎率的输入就错了。

| 参数 | 值 | 说明 |
|---|---|---|
| `k_n` | 2000 | 接触刚度（无量纲，单位密度 m=r³） |
| 半径 | 0.5 | 两球等径，m = 0.125，m_eff = 0.0625 |
| 相对法向速度 | 0.1 | 迎面 head-on |
| `restitution` e | 1.0, 0.8, 0.6, 0.4, 0.3, 0.2, 0.1 | 扫描 |
| `dt` | t_c/2.5（= `recommended_dt()`）、t_c/40、t_c/80、t_c/2…t_c/80 | 分辨率扫描 |
| 初始间隙相位 | 0.017 / 0.033 / 0.05（另 probe 用 3 相位） | 检验"落在步内哪一相位"的敏感性 |
| 盒子 | 8×8×8 周期 | 无壁、无重力 |

## ② 怎么做的（方法 / 工具链）

1. **解析参考（闭式，无拟合）**：线性弹簧-阻尼器的相对坐标是阻尼谐振子，故
   接触时长 `t_c = π / (ω√(1-ζ²))`，`ω = √(k_n/m_eff)`；
   恢复系数 `e = exp(-πζ/√(1-ζ²))`。
   `ContactModel.damping_ratio` 正是上式的反函数，所以"实测 e 必须等于给定 e"不是约定而是**恒等式**，
   偏差只可能来自**离散积分误差**。测试 `test_damping_ratio_is_the_exact_inverse_of_the_restitution`
   验证该映射自逆（<1e-12）。
2. **量测**：两球迎面碰撞，记录接触前相对法向速度 `v_in` 与脱离后 `v_out`，`e_meas = -v_out/v_in`
   （脱离后相对速度反向，取负号）；同时记录接触时长、最大重叠、动量漂移。
   探针：`benchmarks/floe_population_restitution/probe.py`（`--json` 生工件，零手抄）。
   工件：`docs/artifacts/floe_population_restitution/probe.json`、
   `docs/artifacts/floe_population_restitution/contact_resolution.json`。
3. **分辨率扫描**：`dt/t_c = 0.4, 0.2, 0.1, 0.05, 0.025` × 6 个 e × 3 个相位；另单独扫 t_c/40、t_c/80 × 7 个 e × 3 相位。
4. **引擎侧最小改动**：新增 `SphereAssembly.restitution_dt(steps_per_contact=80.0)`，
   返回 `t_c,min / 80`，其中 `t_c,min = π√(m_min/(2k_n))`（最轻球对、**取 ζ=0**：阻尼只会拉长接触，故无阻尼周期是保守上界）。
   `recommended_dt()` 语义**保持不变**（它是弹性稳定界，生产算例数字不动），docstring 加 `.. warning::` 指向新方法。
5. **验证**：`tests/test_floe_population_restitution.py`（9 个用例），与既有 `tests/test_floe_population.py` 一并跑绿。

## ⑤ 注意点 / 坑

1. **稳定 ≠ 准**：`recommended_dt()` 的文档写的是"弹性限稳定步"，它把键合刚度 `bond_stiffness=4000` 与配位数一起算进最高频率，
   对**无键合**的球对它退化为 ~2.5 步/接触——稳定性够，响应精度不够。原 docstring 没写这一层，容易被当成"准"。
2. **弹性接触会造能量**（+21%）：这是粗步长下把弹簧势能采样到零交叉点附近的必然结果；`e=1` 都不能守恒，说明该步长不能用于任何以 e 为输入的统计。
3. **强耗散更难分辨**（反直觉）：e=0.1 时接触更长、阻尼力更大，粗步长把"反弹"算成"弹回"（e_meas≈0.6）。冰区常用 e=0.1–0.3，正落在最糟区间。
4. **相位依赖**：同一 e、同一 dt，初始间隙落在步内不同相位可差 20 个百分点（3.1 的区间宽就是这个），所以单相位验证会低估误差——本轮全部报告 3 相位最坏值。
5. **未改 `recommended_dt` 语义**：生产算例（`study.py` / `field.py`）仍用它，改它会使既有工件失效且本轮无力重跑全战役。修复以"新增正确步长 + 显式警告 + 测试钉住缺陷"落地，切换调用方的建议已写进文末 §⑦。
6. **量测口径**：`e_meas` 用脱离后一拍的速度（此时弹簧力已为零，速度恒定），与接触前速度比值；若在接触中取样会把势能误算成动能。

## ⑥ 误差判定（逐项，显式回答"是否 <3%"）

| 关键量 | 基准（闭式） | 实测 | 相对误差 | <3%？ |
|---|---|---|---|---|
| ζ(e) 映射自逆 | e = exp(-πζ/√(1-ζ²)) | `damping_ratio` 反解 | <1e-12 | **是** |
| 接触时长 t_c（e=0.6，dt=t_c/400） | π/(ω√(1-ζ²)) = 1.779268e-02 | 与解析差 ≤2 个采样步 | ≤0.11 % | **是** |
| 实测 e（e=1.0，`restitution_dt`） | 1.0 | 1.0000 | 0.00 % | **是** |
| 实测 e（e=0.6，`restitution_dt`） | 0.6 | 0.6126 | **2.1 %** | **是** |
| 实测 e（e=0.3–0.4，`restitution_dt`） | 0.3 / 0.4 | 0.2919 / 0.3935 | 2.7 % / 1.6 % | **是** |
| 实测 e（e=0.2，`restitution_dt`） | 0.2 | 0.1952–0.2036 | ≤2.4 % | **是** |
| 实测 e（e=0.1，`restitution_dt(160)`） | 0.1 | 0.1017 | 4.1 %（160 步下 <3 %） | 80 步下 **否**，160 步下是 |
| 实测 e（e=0.6，**`recommended_dt`**） | 0.6 | 0.495–0.753 | **17.5–25.5 %** | **否（缺陷本体）** |
| 动量守恒 | 0 | 0.00e+00 | 精确 | **是** |
| 弹性动能守恒（`restitution_dt`） | 1 | 1±1e-3 | <0.1 % | **是** |

**回答**：新增步长下 e ≥ 0.2 全部 **< 3 %**（最坏 2.4 %）；e = 0.1 需双倍分辨率。
原稳定步长下 **不达标（中位 20 %、最坏 92.6 %）**，本条**不粉饰**：它是本轮复核出的真实缺陷，已用测试
`test_stability_step_alone_does_not_resolve_the_restitution` 钉死（未来若 `recommended_dt` 变得能分辨接触，该测试会主动失败提示更新文档）。
