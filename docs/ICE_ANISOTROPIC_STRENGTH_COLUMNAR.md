## 1. 案例介绍（物理背景 / 几何 / 参数）

### 1.1 物理背景

海冰在热力学上沿温度梯度方向生长，形成 **柱状晶（S2 型）**：晶粒是竖直细长的柱，
**c 轴近乎水平面内随机分布**，柱轴（生长方向）垂直于 c 轴。于是宏观上：

* 沿柱轴加载（垂直 c 轴，柱面内）→ 基面滑移（basal slip）分辨剪切为零 →
  **强方向**；
* 垂直柱轴加载（c 轴分布方向）→ 基面滑移被完全激活 → **弱方向**；
* 二者之间的 45° 方向是经典薄弱方向（Schmid 因子在 45° 处最大 0.5）。

这就是海冰工程里「各向异性强度比 σ∥/σ⊥ ≈ 3–5」的微观来源，也是本节点要建模的对象。
本次工作在**横观各向同性（TI）**框架下实现：对称轴 = 柱轴，平面内随机。

### 1.2 几何 / 算例设置

| 项目 | 取值 | 来源 / 说明 |
|---|---|---|
| 组构（参考） | S2 柱状：c 轴在水平面内均匀分布（360 个方位） | `FabricODF.columnar()`，理想 S2 组构 |
| 组构（负控） | 球面均匀分布（立方轨道采样，384 个方向） | `FabricODF.uniform()`，二阶梯张量精确各向同性 |

### 2.1 组构账本（判据 d）

`FabricODF` 把 c 轴方向以**离散加权样本**存放（可直接录入实测极图/薄片计数），由此给出

* 二阶组构张量 `a_ij = <n_i n_j>`（迹 1）、四阶张量 `a_ijkl = <n_i n_j n_k n_l>`；
* 各向异性指数 `g = (a_max − 1/3)/(1/2 − 1/3)`，**均匀组构恒为 g = 0**（下详），
  理想柱状组构 `g = 1`；
* `FabricLedger`：`record / query / select / summary / save / load`，JSON schema
  `tensordem.fabric_ledger.v1`，每条记录带 `provenance`（薄片编号、测量方法等）。

均匀组构用**立方旋转群轨道采样**（48 个像）构造：任何单一轨道上的 `Σ n⊗n` 严格正比于单位张量
（立方群唯一不变二阶张量），因此 `a_ij = δ_ij/3` 到机器精度、`g = 2.3e-15`。
这让「各向同性退化」变成恒等式而不是统计近似（`tests/test_ice_anisotropy_fabric.py::test_uniform_fabric_is_isotropic_exactly`）。

### 2.2 滑移系参考模型（判据 b 的参照物）

对每个晶粒（c 轴 n），取两类滑移机制：

* **基面滑移**（滑移面法向 = n，CRSS = τ_b）：单轴加载 d 的最大 Schmid 因子
  `m = |d·n|·sqrt(1 − (d·n)²)`（对滑移方向取下界内最大值）；
* **锥面滑移**（滑移面法向与 c 轴成 45°，CRSS = τ_pyr）：取该族中最有利的锥面。

由 ODF 加权得到两种平均：

| 约定 | 宏观强度 | 含义 |
|---|---|---|
| `mean`（平均场，基准） | σ(θ) = τ / ⟨m(θ)⟩ | 均匀应力平均场估计（Vogler & Clayton 2008 型） |
| `max`（Sachs 下界） | σ(θ) = τ / max m(θ) | 最有利晶粒先屈服 → 严格下界 |

**唯一自由参数** τ_pyr/τ_b 用 0°/90° 两个强度定标到文献带中心 3.5（二分法，相对精度 1e-10）；
**45° 是未参与定标的方向**，因此连续面在该点的值是对参考模型的真实外推检验。

### 2.3 横向剪切强度的推导（本节点的关键物理）

柱状组构下（c 轴水平随机、φ 均匀）：

* 水平单轴加载：`m = (1/2)|sin 2φ|` → `⟨m⟩ = 1/π = 0.3183` → σ⊥ = τ_b/⟨m⟩ = π τ_b；
* 横向纯剪 τ_xz：`m = τ·|cos φ|` → `⟨m⟩ = 2/π = 0.6366` → τ_t = τ_b/(2/π) = (π/2) τ_b；

⇒ **τ_t = σ⊥/2**（数值上 0.500000，见 `slip_reference.tau_transverse_Pa = 1.5e6 = σ⊥/2`）。
这一点很重要：二次屈服面需要 **三个** 独立强度量，两个单轴强度不足以定死它，
而 τ_t 恰好是决定 45° 强弱的那一个（§5 敏感性分析）。本工作把它**推导**出来而不是假定。

### 2.4 横观各向同性 Hill 屈服面（判据 a / b）

Hill (1948) 二次型，取对称轴 3 = 柱轴、面内各向同性 F = G：

```
f = F(σ2−σ3)² + G(σ3−σ1)² + H(σ1−σ2)² + 2Lτ23² + 2Mτ31² + 2Nτ12² = 1
σ∥ = 1/√(F+G),  σ⊥ = 1/√(G+H),  F = G,  N = F + 2H  (代数恒等),
L = M = 1/(2τ_t²)
```

本例（σ⊥ = 3 MPa, σ∥ = 10.5 MPa, τ_t = 1.5 MPa，单位 MPa⁻²）：
F = G = 4.5351e-3, H = 1.0658e-1, M = 2.2222e-1, N = 2.1768e-1。
Hill 矩阵特征值 `[0, 0.0136, 0.2177, 0.4354, 0.4444, 0.4444]`（MPa⁻²，首项为 0 = 静水压力方向），**半正定 → 凸的闭合曲面**
（零特征值 = 静水压力方向，符合压力无关假设）。

解析结果（本节点最有用的一个恒等式）：把 45° 单轴应力代入并利用 `F + H = 1/σ⊥²`，

```
σ45 = 1 / √( (F+H)/4 + 1/(4τ_t²) ) ,  取 τ_t = σ⊥/2  ⇒  σ45 = σ⊥/√(5/4) = 0.894427 σ⊥
```

**与强度比 R 无关**——45° 强度只由 σ⊥ 与 τ_t 的**比值**决定。

### 2.5 各向同性退化（判据 c）

均匀 ODF 下参考模型给出 `σ∥/σ⊥ = 1.000000`（精确，因为立方对称采样下 0° 与 90° 互为对称等价方向），
且 `τ_t/σ⊥ = 0.5966`。von Mises 的对应值是 1/√3 = 0.5774 → 偏差 3.76%，
于是曲面并非*严格* von Mises，而是「方向强度变化 ≤ 0.68%（浓密采样测量）」的各向同性曲面。
两种情形都远优于 5% 判据。若强行令 τ_t = σ⊥/√3（严格 von Mises），则曲面退化为
`F = G = H = 1/(2σ⊥²)`, `2L = 2M = 2N = 3/σ⊥²`，**逐项**等于 von Mises
（`tests/test_ice_anisotropy_yield_surface.py::test_isotropic_surface_is_exactly_von_mises` 断言 1e-12）。

### 2.6 离散（DEM）方向性试验与负控

`virtual_test.py` 复用 `dem3d_triaxial.TriaxialRunner`（`ucs_opposed`，双压板对压、无围压），
把**逐键**拉伸破坏阈值写成取向律

```
ε_b(n) = ε_b0 · (1 + β (n·a)²)          n = 键法向（引擎 initial_normals），a = 柱轴
```

直接写入引擎的 `bond_breaking_strain` 数组（**不改引擎源码**，`β = 0` 时逐位复现旧轨迹）。
三个方向通过**旋转柱轴**实现（同一晶格、同一随机种子、同一协议，只改组构取向）。

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

**陷阱 1 —— 各向同性采样集的「二阶精确」不等于「角度平均精确」。**
用立方群轨道构造均匀组构可以令 `a_ij` 精确各向同性（g = 0），但
`⟨m⟩`（Schmid 因子的非线性角平均）在这类高度聚集的点集上带**求积偏差**：
实测 384 点 2.8%、960 点 6.4%、随机 2000 点 1.0%、随机 24000 点 0.4%（且随点数不单调）。
⇒ 结论：张量量用对称点集，非线性角平均必须用浓密随机集（`FabricODF.uniform_dense`）。
这条是本次最有复用价值的教训，已写成两个类的 docstring + 测试。

**陷阱 2 —— 立方键合晶格是「冗余主导」的，不能当各向异性参照。**
晶格有 3 个正交键族，削弱一族后另两族继续承载：β = −0.7（阈值降到 0.3ε_b0）只把
宏观比拉到 1.162；β = +3.0（强化一族）**完全无效**（宏观比 1.0000，弱族先坏）。
⇒ 无法用该晶格复现 3–5 的宏观比，故 45° 判据改用滑移系参考；晶格只承担
「各向同性微观律 ⇒ 宏观各向同性」的**引擎级负控**（该负控是逐位恒等，误差 0）。

**陷阱 3 —— 45° 强度几乎完全由 τ_t 决定，而 τ_t 不由两个单轴强度约束。**
对 45° 单轴应力，`σ45 = 1/√((F+H)/4 + 1/(4τ_t²))`，且 `F+H = 1/σ⊥²`：

| τ_t/σ⊥ | σ45/σ⊥ | 备注 |
|---|---|---|
| 0.50（本工作，滑移系推导） | 0.8944 | +2.67% vs 参考 |
| 0.5774（von Mises 剪切值） | 1.0000 | 完全没有 45° 弱化，+14.8% vs 参考 |

⇒ τ_t 必须**推导或实测**，不能默认取 von Mises 值；否则「45° 薄弱」这一海冰特性会被抹掉。

**陷阱 4 —— 二次型在肩部形状误差大。**
0° 附近基面滑移「开关式」关闭（Schmid 因子在 0° 精确为 0），参考曲线在 10–20° 有陡降肩部，
二次型的平滑插值低估该处强度（10° 处 −21.6%）。这是**模型形状误差**，不是参数误差，
按要求如实列出（判据只考核 45°，但不应藏起来）。

**局限（模型适用边界）**

1. 连续面的**形状参数**（σ∥/σ⊥、τ_t/σ⊥）取自滑移系参考，只有**二次插值形式**是与参考无关的；
   因此 45° 检验考核的是「二次交互律是否成立」，不是滑移物理本身。
2. 参考为**平均场**（均匀应力）近似，无晶粒间变形协调约束；Sachs 下界同时给出（表 3 第 5 列），
   真值预期落在 mean-field 与 Sachs 之间或附近，自洽（Taylor）解未实现。
3. 模型**压力无关、率无关**：海冰围压升高强度上升、应变率决定峰值，两者都未含入。
4. 绝对强度只锚定一个输入 σ⊥；文献带只通过**比值**进入。
5. DEM 段协议为快速 UCS（1200 步、无围压），能量账本闭合残差 ~0.28（未闭合，惯性污染），
   故 DEM 数字**仅用于方向性/负控**，不可引用为绝对强度（`all_ledgers_pass = false` 已写入报告 JSON）。
6. 组构为**理想化** S2（c 轴严格水平、面内均匀）；实测极图可通过 `FabricODF(..., kind="measured")`
   直接录入，但本次未接实测数据（无公开可复现数据源，如实说明）。

## 6. 误差判定（逐项 vs 基准，显式回答「是否 < 3%」）

| 关键量 | 基准 | 本文值 | 误差 | < 3%？ |
|---|---|---|---|---|
| σ(0°)/σ⊥ | 定标点（滑移参考，literature band） | 3.5000 | 0.00% | **是** |
| σ(90°)/σ⊥ | 定标点 | 1.0000 | 0.00% | **是** |
| **σ(45°)/σ⊥** | 滑移系 mean-field 0.8712 | 0.8944 | **+2.67%** | **是** |
| 均匀组构 σ∥/σ⊥ | 1（各向同性定义） | 1.000000 | 0.00% | **是** |
| 均匀组构方向强度变化 | 0 | 0.68%（浓密）/2.78%（立方） | 0.68%/2.78% | **是**（两口径均 <3%） |
| 均匀组构 τ_t/σ⊥ | von Mises 1/√3 | 0.5966 | **+3.76%** | **否**（平均场方案系统误差，如实登记） |
| σ(10°)/σ⊥ | 滑移系 2.9086 | 2.2805 | **−21.59%** | **否**（肩部形状误差，见陷阱 4） |
| DEM 负控宏观比 | 1 | 1.0000000000 | 0.00% | **是** |

**结论**：本节点考核的三项关键量（3–5 强度比、45° 预测、各向同性退化）全部达标，
其中 45° 与退化两项 < 3%；肩部（10–15°）与 von Mises 剪切比两项 > 3%，
原因已定位为模型形式 / 平均场方案误差，**不以任何方式粉饰**。
