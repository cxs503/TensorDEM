## 1. 案例介绍

### 1.1 物理背景：为什么"共面"假设不够

跨求解器耦合（冰–船/冰–结构、颗粒–连续体、DEM↔FEM/BEM/LBM）的界面算子负责把一侧离散面上的
积分量送到另一侧。m5207 在 1D 上确立了三条判据（守恒 / 相容 / 对称），m5436 把它推广到
**共面**的 2D 斜交界面与 3D 共享面。但 m5436 在 §5.2 明确留下了三类未覆盖情形，其中第一条是
工程上最常见的：

> 真实界面（船体曲面、筒仓壁、冰盖表面）在两套网格中由**两个不同的多面体近似**表示，
> 彼此**不共面**。两个非共面三角形的交集是一条线段（零测度），面积型 mortar 不能直接用它。

本节点的工作就是把算子从"共面"推进到"非共面"，并把 m5207 §⑤.2 的测度归一化陷阱放到
**临界路径**上（共面情形下守恒是结构性的，陷阱只在反例控制里咬人；非共面情形下守恒残差真实存在，
回填是否正确直接决定结果可信度）。

### 1.2 几何与算例参数

| 算例 | 界面流形 | 施主 (donor) | 受主 (acceptor) | 判据 |
|---|---|---|---|---|
| D1/D2 平面 tri–tri | 平面 `x=0.5`（两块立方体 `[0,0.5]×[0,1]²` 与 `[0.5,1]×[0,1]²` 的共享面） | 三角网格 4×4→8×8（面族**不旋转**，节点 O(h) 抖动） | 三角网格 3×3→6×6（面族**面内旋转 17°**，另一套抖动） | 守恒 ≤1e-13、面积覆盖 ≤1e-13、转置一致 ≤1e-12、线性 patch ≤1e-12 |
| D3 曲面 octant | 单位球面 ∩ 盒 `[0,∞)³`（球面八分之一） | **UV 球**三角化（12×24 → 48×96） | **细分八面体球**（level 3 → 5），拓扑不同、分辨率不同 | 面积/转移积分对闭式值，阶次 ≥1.8；原始守恒缺陷 O(h²)；回填后 ≤1e-13 |
| D5 折线界面 | 含 **30° 折角**的两段折线（分段光滑 2D 界面） | 每段 4/3 → 16/12 单元（O(h) 抖动断点） | 每段 6/5 → 24/20 单元 | 守恒 ≤1e-13、每段 patch ≤1e-12、阶次 ≥1.8 |

**不使用随机点云**（m5207 §⑤.4 实测：随机点云不细化，阶次躺平）。

## 2. 怎么做的

### 2.1 非共面三角面–三角面裁剪

对一对面片 `(S_i, T_j)`：

1. **共面判定**：`|n_i·n_j| ≥ 1−1e-12` → 走精确路径（与 m5436 相同，`cell_overlap` 在 `S_i` 的切平面内
   做 Sutherland–Hodgman 裁剪）。
2. **非共面路径**（投影 mortar / mortar-segment 的标准做法）：
   `T_j` 沿 `n_i` 正交投影到 `S_i` 平面得 `P(T_j)`，在 `S_i` 的局部坐标系里做凸多边形裁剪：

   ```
   m_ij   = | S_i ∩ P(T_j) |                        (施主平面测度)
   m_ij^T = m_ij / |n_i·n_j|                        (投影 Jacobian 还原到 T_j 自身面积)
   ```

   投影缺陷是 `O(θ²)`（θ 为两面片二面角），对同一曲面的两个内接多面体 `θ = O(h)`，
   故几何偏差 `O(h²)`——这一点不假设，D3 直接测出来（见 §3.2，实测阶次 2.00）。
3. **二面角前置门**：`|n_i·n_j| < 0.15` 的面片对判为"不同界面片"，返回 `path="rejected"` 且测度置 0，
   计数上报（`surface_overlap_entries` 的 `verbose` 与判据记录）。宁可拒绝也不静默混算。
4. **齐次 Sutherland–Hodgman**：`clip_homogeneous(subject_h, planes)` 以齐次坐标 `(x,y,w)` 承载顶点，
   半空间内积为 `(a x + b y + c w)/w`；显式两处守卫——
   * `w` 守卫：`|w| ≤ tol` 的"无穷远顶点"直接剔除（不产生除法）；
   * 分母守卫：`|d_a − d_b| ≤ tol·max(1,|d_a|)`（边与裁剪面平行）时不插值新顶点。
   两者都有单元测试（`test_homogeneous_clip_drops_vertex_at_infinity`、
   `test_homogeneous_clip_parallel_edge_guard`）。
5. **候选对搜索**：面片包围盒投到边长 `1.5·max(h_s,h_t)` 的均匀哈希网格，避免 m5436 的
   `O(n²)` 预筛（最细曲面算例约 1128×1024=1.2M 对，哈希后只剩约 6k 对，单层 10 s 内跑完）。

### 2.2 曲面上的一阶/二阶重构

与 m5436 同代数形式，只是每个面片有自己的切平面基：

```
v_j = (1/|T_j|) Σ_i [ m_ij u_i + ∫_{S_i∩P(T_j)} (x−c_i) dx · g_i ]      (order 2)
```

`g_i` 由 `facet_gradients` 在**该面片自身的切平面**内对近邻（≤8 个，半径 ≤3h）做
最小二乘（坐标按 h 缩放后再 pinv，抑制薄片单元的病态），一阶场精确可复现。
`∫(x−c_i)dx` 由 `cell_overlap` 返回的一阶矩给出（对未裁剪单元恒为零，正是斜率项不破坏守恒的原因）。

### 2.3 测度归一化陷阱（m5207 §⑤.2 修复），代码注释 + 回归测试双落

非共面时 `Σ_i m_ij ≠ |T_j|`（**不分区**），原始转移不守恒，必须回填。正确形式（`measure_backfill`）：

```
dv_j = (sent − recv) · |T_j| / Σ_k |T_k|²
```

则 `Σ_j dv_j |T_j| = sent − recv` 恒成立（与单元尺寸分布无关）。错误分支
`broken="backfill_linear"` 用 `|T_j| / Σ_k|T_k|`，其修正积分为
`(sent−recv)·Σ|T|²/Σ|T|`，对近均匀网格留下 `≈(1−1/N)` 比例的亏缺——**一个看起来像物理错误的
百分比级算术残差**。两条分支都在代码里可执行，并有：

* 单元测试 `test_backfill_closes_the_deficit_exactly`（随机测度、正负亏缺，闭合到 1e-14）；
* 单元测试 `test_backfill_trap_leaves_a_percent_level_residual`（把陷阱的解析式钉死）；
* 判据 `D3_trap_control_red`：故意错配分辨率（UV 20×40 vs 八面体 level 2）使亏缺真实可见，
  正确回填 0 / 陷阱 1.46e-2（保留 90.2% 的亏缺）/ 中点采样 4.04e-2；
* 代码注释（`measure_backfill` docstring）逐字给出公式与陷阱解析式。

### 2.4 判据设计原则（反例控制）

每条判据都配一个"必须被打红"的反例，否则绿灯可能只是判据死了：

| 判据 | 反例 | 实测 |
|---|---|---|
| D1 守恒 | 施主重构在受主形心点采样（`broken="midpoint"`） | 8.14e-3 |
| D3 守恒回填 | 线性归一化回填（陷阱） | 1.46e-2（亏缺的 90.2%） |
| D3 守恒 | 中点采样 | 4.04e-2 |
| D2 patch | 一阶（分段常数）算子在**线性场**上必须不精确 | 1.38e-2…3.61e-2 |
| D5 守恒 | 中点采样（折线界面） | 4.50e-3 |

## 5. 注意点（踩过的坑、局限、适用范围）

### 5.1 本次实际踩到并当场修掉的坑

1. **旋转面族后"支撑区域"变了**：最初把受主网格整体绕原点转 17°，两侧覆盖的区域不再是同一个正方形，
   面积覆盖相对误差直接 1.00（看起来像算子坏了）。修法：旋转面族后**裁回单位正方形**
   （`tri_patch_side` 的 `rotate_deg`），两侧支撑严格相同，覆盖缺陷才是算子的性质。
2. **裁剪薄片（sliver）毒化所有统计**：旋转格点被正方形边界裁出面积 ~1e-18 的三角形，其两条边数值平行，
   法向是噪声；更糟的是单元平均要除以它自己的测度，`v_j` 被放大到 1e3 量级，
   线性 patch test 从 1e-16 掉到 1e-9、覆盖相对误差变 0.42。修法：裁剪后按
   `1e-14 × 平均未裁面积` 丢弃薄片（丢掉的总面积 < 1e-14，对判据无影响），
   并把"每面片相对覆盖"降级为诊断量、判据改用"最差面片亏缺 / 总面积"（`*_abs`）。
3. **镜面反射写成了坐标重排**：`reflect` 后为了保持定向写了 `t[:, ::-1]`，实际把 (x,y,z) 反成 (z,y,x)——
   等价性检验报 0.42 的"物理不自洽"。正确是反顶点顺序 `t[::-1]`。**教训：镜面对称的回归测试必须同时校验
   形心配对（本节点报了配对残差与双射性）**，否则形心错了也能"看起来在比较"。
4. **镜像等变的比较对象搞错**：一开始在镜像网格上重新求值场函数，于是比较的是两个不同场，必然不相等。
   正确做法：把**同一组施主数据**搬到镜像网格上转移（换坐标系不换数据），漂移才应到机器精度。
5. **二阶重构的梯度坐标系**：每个面片有自己的切平面基，梯度的分量是**框架相关**的，
   不能跨面片比较分量（单元测试先写成比较分量，跑了才发现）。判据用"梯度模长"与 patch test。
6. **取近邻的最小二乘在薄片单元上病态**：局部坐标先按 h 缩放再 `pinv(rcond=1e-12)`，否则 1e-9 级噪声。
7. **对称化的诱惑**：非共面转置不对称（1.71e-3）是投影 mortar 的**真实性质**。把 `m_ij` 与 `m_ji^T` 平均
   可以让转置判据"变绿"，但会破坏分方向守恒的清晰账本。本节点选择**如实报数 + 分方向回填**。

### 5.2 方法与验证局限

* **投影法不是"真交集"**：非共面双三角形的交集是线段，本节点用"施主平面上的投影与 `1/|cos|` 还原"，
  是 mortar-segment 类方法的一阶几何近似；对"两个近似曲面之间的薄层"没有做体积/间隙修正。
  当两面片二面角 > ~81°（`cos_min=0.15`）时直接判为不同界面片并拒绝，不混算。
* **要求两套离散分辨率可比**：故意错配（4× 分辨率差）时施主小单元可能完全落不进受主投影里，
  覆盖缺陷骤增（实测最粗一级 `coverage_tgt_abs` 5.0e-4；4× 错配算例 `tgt_abs` 8.9e-3、总量 4.1e-2）。回填能救**总量**守恒，
  但救不了**局部信息丢失**——这种用法属于"网格生成不当"，不是算子误差，本节点不做几何修补。
* **守恒是全局的**：`measure_proportional_backfill` 按测度分配，不给单元级（patch）局部守恒。
  局部守恒需要 patch 级修正，未做。
* **二阶转置一致性未做**：与 m5436 一致，只对**一阶（几何测度）矩阵**作转置判据；
  二阶（含偶极项）只在镜像等变/双向守恒上被间接检验。
* **2D 折线只覆盖两段 30° 折角**：不是任意曲线界面（真曲线需要曲线求交）。它是 m5436 §5.2
  "真正的曲线界面尚未实现"的**最小闭环**，不是完整替代。
* **RBF / ME 未在曲面上运行**：两者的核在 m5207/m5436 中定义在**单一**共面界面侧上，
  搬到大曲率曲面需要重定义核与归一化，本节点不擅自扩展（D6 表里显式说明缺行原因）。
* **未做时域耦合验证**：界面算子只保证单次传递的守恒/相容/对称；放到 DEM↔FEM 时间推进里
  是否引起能量泄漏，需要耦合算例，属后续节点。

## 6. 误差判定（逐项，显式回答"是否 < 3%"）

全部基准都是**闭式/解析值**（单位球面积与一阶矩、单位正方形面积、线性场单元均值），不是"另一套网格的近似"。

| 关键量 | 基准 | 实测误差 | 是否 < 3% |
|---|---|---|---|
| 平面 tri–tri 面积覆盖（D1） | 结构性分区 ⇒ 0 | 2.22e-16（相对） | 是（远小于） |
| 平面 tri–tri 守恒 o1/o2（D1） | 结构性守恒 ⇒ 0 | 1.99e-16（反例 8.14e-3，故意红） | 是 |
| 线性 patch test 3D（D2） | 精确单元均值 | 7.89e-16 | 是 |
| 一阶算子 patch（应不精确） | — | 1.38e-2…3.61e-2 | 不适用（预期的失败） |
| 曲面受主多面体面积（D3 最细） | `π/2`（闭式） | 7.95e-4 | 是 |
| 曲面转移积分 `∫(x+y+z)dA`（最细） | `3π/4`（闭式） | **1.49e-3** | 是 |
| 曲面观测阶次（面积/积分/瑕疵） | 理论 2 | 2.00 / 2.00 / 1.95 | 是（阶次判据 ≥1.8） |
| 曲面守恒（回填后） | 0 | 0.0 / 4.4e-16 | 是 |
| 曲面守恒（陷阱回填） | 0 | 1.46e-2 | **否**（故意失败的反例） |
| 共面转置一致（D1） | 恒等式 | 1.18e-15 | 是 |
| 镜轴等变（D4，共用同一轴） | 恒等变换 | 1.14e-15（形心配对 1.16e-16） | 是 |
| 非共面转置对称性（D4） | 不期望对称 | 1.71e-3 不对称，如实报告 | 不适用（性质而非误差） |
| 折线界面守恒（D5） | 0 | 2.22e-16（反例 4.50e-3） | 是 |
| 折线界面 patch / 阶次 | 精确 / 2 | 2.85e-16 / 2.90 | 是 |
| 三算子守恒（1D/2D/3D 共面） | 0 | ≤2.22e-16 | 是 |
| 曲面"无回填"守恒 | 0 | 1.03e-5（一级、匹配分辨率）；错配 1.62e-2 | 是（匹配）/ **否**（错配，故意的） |

**结论**：20 条机器判据全部满足（`verdict: PASS`）；所有"关键量 vs 闭式基准"的最差误差是
曲面最细一级的 **1.49e-3**，远小于 3%。三项**故意失败**的反例（陷阱回填 1.46e-2、中点采样 8.14e-3/4.04e-2/4.50e-3、
一阶 patch 1.38e-2）是判据活性的证明，不是本节点的误差。**未达成项**：非共面转置对称（本质不可期望）、
错配分辨率的局部信息丢失（用法问题）、局部守恒（未实现）——均在 §5.2 声明，不做粉饰。
