## ① 案例介绍

刚性球（半径 R）以准静态方式垂直贯入无粘性颗粒床，测深度相关阻力 F(z)，与 Brzinski III,
Mayor & Durian, PRL **111**, 168002 (2013)（arXiv:1307.4638v2）Eq.(2)
`dF = alpha mu (rho_bulk g z) dA` 及其积分 Eq.(3c)/(3d) 对照，标定无量纲摩擦放大系数 alpha。

**关键隐含前提**：Eq.(3c)/(3d) 是**半无限床**（semi-infinite bed）的结果 —— 阻力来自贯入器
湿表面上的静水压型围压。如果床很薄，贯入器下方那层颗粒被夹在刚球与刚性底板之间受压，
测到的是**受限压缩力**，不是颗粒拖曳。

| 参数 | 符号 | 定义/取值 | 文献 |
|---|---|---|---|
| 颗粒直径 | d | 4.0e-3 m | 3.0e-4 m |
| 贯入球半径 | R | R/d = 2…4（粗粒化） | 1.27e-2 m（R/d ≈ 42） |
| 底板净空（几何） | c | `c = bed_depth − penetrate_over_r·R`，本次以 R 为单位 | 容器深 ≫ R |
| 颗粒摩擦 | mu_grain | 0.40（颗粒-颗粒）；文献 mu 是介质内摩擦 tan22° | 0.40 |
| 贯入速度 | v | 0.05 m/s（基准），倍速 0.025/0.10 | ~1e-5 m/s |
| alpha | — | 拟合量 | 35 ± 5 |

## ② 怎么做的

**R3 的改动（本轮 PR 的全部内容）**

1. **底板净空变成一等公民**（`PenetrationConfig`）：新增 `floor_clearance_over_r` /
   `floor_clearance_over_d` 派生属性、`min_floor_clearance_over_r = 3.0` 判据、
   `floor_clearance_is_marginal` 标志；`validate()` 硬拒「贯入器触底」，`validate(strict=True)`
   拒「净空 < 3 R」。默认仍向后兼容（老算例可复现）。
2. **每个算例记录都带 `protocol_warnings`**：净空不足 / 粗粒化 R/d / Froude 数 v/√(gR) > 0.05
   三条非致命告警进 `result.json`，并新增 `geometry.floor_clearance_over_r` 记账 ——
   R2 的教训是「净空从来没被记录，导致 10 倍偏差整整一轮被归错因」。
3. **加性污染的判别诊断** `alpha_vs_window()`：固定拟合下限、逐级抬高上限，得到 alpha 阶梯。
   纯 Eq.(3c)/(3d) 型线 → 阶梯水平（±1% 内）；若存在与深度无关的**加性**多余力（薄床底板、
   装夹偏置、加载器常力）→ 浅窗口 alpha 偏大、阶梯单调下降。全局单点拟合无法把两者分开。
   该判别同时被单元测试用「无污染/含 2 N 加性污染」两条合成线锁住。
4. **扫描协议工具** `scripts/penetration_sweep.py`：一次一个轴（`floor` 净空 / `rate` 速度 /
   `rd` 粗粒化），支持 `--shard i/n` 分片；`scripts/penetration_sweep_report.py` 汇总
   `study.json` → 表 + 图（数字全部从记录读，零手抄）。
5. **倍速预置参数返修（缺陷）**：`preset('rate2x')` 原来是 1.0 m/s = 基准速度的 **20 倍**、
   `slow` 0.25 m/s = **5 倍**，却挂着「2x / slow」的名字 —— 一个「2 倍速对照」跑的是 20 倍速，
   等于自己没通过自己的准静态性检验还看上去通过了。现在二者由 `BASE_SPEED = 0.05 m/s`
   派生（0.025 / 0.10），并有测试锁死。

**几何审计（程序化，结果见 `artifacts/case_penetration/preset_floor_audit.json`）**：
本仓全部 7 个预置算例的底板净空都 < 1.1 R ≈ 3–4 个颗粒直径。也就是说 R2 那次 FAIL 的几何，
不是「跑偏了一个参数」，而是**默认构造就是受限压缩几何**。

## ⑤ 注意点 / 踩坑

- **R2 的归因错误**：把 10× 偏差直接写成「粗粒化 R/d 未收敛」，而几何净空 1.9 R 从未被记录。
  教训 → 净空、Froude 数这类**协议前提**必须进算例记录（本轮 `protocol_warnings`）。
- **「2 倍速对照」其实是 20 倍速**：预置参数与名字脱钩，准静态性检验事实上从未做过。
  教训 → 倍速预置必须从 `BASE_SPEED` 派生，并用测试锁死。
- **单点全局拟合不可辨识**：`alpha_fit` 一个数把「斜率不足」与「加性常数」混在一起；
  窗口阶梯才分得开（R2 里 alpha_free = 90.9 / alpha_shape = 349.3 / 拟合截距自由，三者互不
  自洽，就是不可辨识的征兆）。
- **mu 的语义**（未解决）：文献 mu 是介质内摩擦 tan(安息角)，DEM 输入是颗粒-颗粒摩擦，
  本轮未做安息角标定；即使净空修好，这一项仍可能带来 O(2) 的偏差。
- **v/√(gR) = 0.178**（R/d=2）：文献 ~1e-5 m/s 是纯准静态；本轮 0.05 m/s 的 Froude 数不在
  完全可忽略区，故 `rate` 轴（0.0125 / 0.05 / 0.2）必须与净空轴一起读，否则两种污染混淆。

## ⑥ 误差判定

| 关键量 | 基准 | 本轮值 | 相对误差 | 是否 < 3% |
|---|---|---|---|---|
| alpha（R2 记录，R/d=2，净空 1.9 R） | 35 ± 5 | 349.3 | 898% | ✗ |
| 底板净空 c（base 预置） | ≥ 3 R（半无限前提） | 1.067 R | −64%（不足） | ✗ |
| 底板净空 c（rd2 预置，R2 实际算例） | ≥ 3 R | 1.900 R | −37%（不足） | ✗ |
| alpha 阶梯水平性（无污染合成线） | 35（解析） | 34.91–35.14 | 0.7% | ✓ |
| 倍速预置与基准速度之比 | 0.5 / 2.0 | 0.5 / 2.0（修前 5 / 20） | 0%（修后） | ✓ |

**结论**：本轮**不宣称 alpha 已达到 3%（或 15%）判据** —— 净空对照扫描未收敛，无新数字。
可判定的部分是几何审计（7/7 预置违反半无限前提）与工具自检（合成线 ±0.7%），这两项达标。
alpha 的精度判定留待 §③(b) 回填后按 `ACCEPTANCE['penetration_force_error'] ≤ 0.15` 重判。
