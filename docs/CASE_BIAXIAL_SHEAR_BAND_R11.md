# CASE-BIAXIAL-SHEAR-BAND R11 — 把「φ 取哪个状态点」的敏感性定量化

**本轮结论（一句话）**：R9/R10 的「Arthur 定律在全部声明 φ_cv 值上都被支持」结论
**在实测峰值 φ = 35.45° 处成立**（峰值落在稳健窗 [34.0°, 35.5°] 内），但该稳健窗
**只有 1.5° 宽**——比预注册的 [33°, 38°] 余量**窄得多**。因此「φ 取哪个状态点」
（峰值 vs 晚窗）的敏感性是**真实、已定量**的欠账：若在飞的状态匹配臂 cj4770
（用晚窗 φ 重建）给出的 φ 落在 [34.0°, 35.5°] 之外，R9/R10 的「Arthur 在全部
φ_cv 上支持」声明就会翻转。本轮**没有重跑 DEM**，用纯算术把这条敏感性欠账
**从「未跑」变成「已定量、已标为真实风险」**。

## ① 案例介绍

平面应变双轴试验：矩形冻结黏结圆盘试样（24 × 48 抖动三角格，35 % 冻结键，
壁面摩擦 0.55，围压 σ₃ = 100 kPa 伺服侧壁，顶板位移加载），峰后材料局部化为
一条剪切带，带相对 σ₃ 轴（水平）的倾角 θ 是观测量。经典理论给出三条只依赖
φ、ψ 的关系（Mohr–Coulomb 45+φ/2；Roscoe 45+ψ/2；Arthur 45+(φ+ψ)/4）。

本案例的验收锚是「文献剪切带倾角，容差 <15 % + 定性」，锚值 60°（55–60° 带
中点）。R7 给出实测带倾角 **θ = 55.00° ± 2.07°**（n=8）；R9/R10 用实测
φ≈35.45°（峰）与 Rowe 应力–剪胀关系（φ_cv 声明区间 26–34°）判定：
**Arthur 定律被支持**（平均 |误差| 2.81–3.35 %），Mohr–Coulomb 不被支持
（12.31 %）。

**本轮不改锚、不改算子、不改算例**，只做一件事：把 R9/R10 明确记为 `not_run`
的**状态匹配臂**（cj4770，用晚窗 φ 替代峰值 φ）所回答的「φ 取哪个状态点」的
敏感性，**用纯算术定量化**——不等待在飞的 DEM 重算，先把结论的稳健边界画出来。

## ② 怎么做的

1. `benchmarks/biaxial_shear_band/run_r11_phi_state_sensitivity.py`（新增，纯算术）：
   * 在**物理可行**的 φ 状态点区间 **[30°, 40°]**（0.5° 步长，21 点）上扫，
     覆盖实测峰值 35.45° 与任何合理的峰后/晚窗值；
   * 对每个 φ，在**全部声明 φ_cv ∈ {26, 28, 30, 32, 34}** 上重跑 R9 判定
     （`adjudicate` + `stress_dilatancy_psi_deg`，Rowe/Bolton），
     得到「Arthur 在全部 φ_cv 上支持」的**稳健窗**；
   * 输出：稳健窗 [φ_low, φ_high]、窗宽、峰值是否在窗内、预注册 [33, 38]
     余量是否达成、以及逐 φ 的 Arthur/MC 误差表（程序化注入，无手抄）。
2. `tests/test_r11_phi_state_sensitivity.py`（新增）：5 个测试，**5 通过**——
   断言峰值在稳健窗内、窗是窄的（[34, 35.5] 而非 [33, 38]）、MC 在 [30, 40]
   全程不进入 3 % 精度、峰值处 Arthur 是最近定律且 <3 %。
3. `benchmarks/biaxial_shear_band/make_r11_figures.py`：从 JSON 渲染对比图
   （左：Arthur/MC 误差 vs φ 状态点，含 3 %/15 % 线与稳健窗；右：稳健窗 flag）。

## ③ 计算结果

### 3.1 稳健窗（核心数字）

| 量 | 数值 |
|---|---|
| 带倾角 θ（R7/R9/R10 主估计量，不变） | **55.00° ± 2.07°**（n=8） |
| 实测峰值 φ | **35.45°** |
| **稳健窗**（Arthur 在全部 φ_cv 上支持） | **[34.0°, 35.5°]** |
| 稳健窗宽 | **1.5°** |
| 峰值在窗内 | **是**（35.45 ∈ [34.0, 35.5]） |
| 预注册 [33, 38] 余量 | **未达成**（窗只到 34.0–35.5） |
| 判定 | **NARROW**（峰值在窗内，但窗窄于预注册余量） |

### 3.2 逐 φ（φ_cv = 32 臂，R9/R10 头条臂）

| φ | Arthur 误差 | MC 误差 | 在稳健窗内 |
|---|---|---|---|
| 30.0 | 4.76 % | 8.33 % | 否 |
| 32.0 | 3.77 % | 9.84 % | 否 |
| 33.0 | 2.71 % | 10.57 % | 否 |
| 33.5 | 2.19 % | 10.93 % | 否（φ_cv=34 臂 3.04 % 超 3 %） |
| **34.0** | **1.67 %** | **11.29 %** | **是** |
| **35.0** | **0.64 %** | **12.00 %** | **是** |
| **35.5** | **0.13 %** | **12.35 %** | **是** |
| 36.0 | 0.37 % | 12.70 % | 否（φ_cv=26 臂 3.34 % 超 3 %） |
| 38.0 | 2.36 % | 14.06 % | 否 |
| 40.0 | 4.29 % | 15.38 % | 否 |

**读出**：
* **峰值 35.45° 处**：Arthur 误差 0.13 %（<3 %），MC 12.35 %——R9/R10 结论成立。
* **窗边界**：下界 34.0° 由「φ_cv=34 臂 Arthur 误差 3.04 % 刚超 3 %」决定；
  上界 35.5° 由「φ_cv=26 臂 Arthur 误差 3.34 % 刚超 3 %」决定。
  即**不是** φ 本身，而是**某个 φ_cv 臂**在窗边把 Arthur 推出 3 % 精度。
* **MC 全程不进入 3 %**：在 [30, 40] 上 MC 误差 8–15 %，判别力来自
  φ/4 vs φ/2 系数差（~7°），与 R9 的 `psi=0` 臂结论同向。

### 3.3 峰值处（φ_cv = 32 臂，R9/R10 同源）

| 量 | 数值 |
|---|---|
| Arthur 预测 | 54.93° |
| Arthur 误差 | **0.13 %**（<3 % = 是） |
| MC 预测 | 62.75° |
| MC 误差 | 12.35 %（<3 % = 否） |
| 判别间距 | 7.26° |

## ⑤ 注意点（坑 / 局限 / 适用范围）

1. **本轮没有重跑 DEM**：所有数字来自 R7/R9/R10 的实测均值（θ=55.00、
   φ_peak=35.45），逐项程序化注入。好处是保真度与 R7/R9/R10 完全一致；
   代价是只能使用缓存里保留的量（峰态 φ、主估计量 θ），因此**不能**回答
   「晚窗 φ 实际是多少」——那是 cj4770 的活。
2. **稳健窗窄是真实发现，不是缺陷**：R9/R10 的「Arthur 在全部 φ_cv 上支持」
   声明**只在 φ ∈ [34.0, 35.5] 上成立**。这**不是**说 R9/R10 结论错了（峰值
   35.45 在窗内，结论在峰值处成立），而是说**该声明的稳健边界只有 1.5°**——
   若 cj4770 的晚窗 φ 落在窗外，需要重新审视「Arthur 在全部 φ_cv 上支持」。
   这正是把 `not_run` 欠账变成「已定量、已标为真实风险」的意义。
3. **窗边界由 φ_cv 臂决定**：下界 34.0° 是 φ_cv=34 臂（Arthur 3.04 %），
   上界 35.5° 是 φ_cv=26 臂（Arthur 3.34 %）。即**不是** φ 本身把 Arthur 推出
   3 %，而是**某个声明 φ_cv** 在窗边。这提示：若 φ_cv 的声明区间本身有不确定性，
   稳健窗会更窄——φ_cv 是声明值（R9 已说明），不是拟合值。
4. **2D 圆盘 ≠ 3D 砂**：φ/4 与 φ/2 系数的判别是二维离散元的经典结果，
   不能直接搬到三维角粒材料；本轮的结论只对本实现的 2D 冻结黏结圆盘成立。
5. **cj4770 仍在飞**：状态匹配臂（用晚窗 φ 重建）仍在计算队列（running，
   已 29+ 小时），本轮**未取回**其晚窗 φ 结果，按纪律记为 `not_run`。R11 的
   意义是**先**把「φ 取哪个状态点」的敏感性边界画出来（[34.0, 35.5]），
   让 cj4770 取回后能直接对照：若其晚窗 φ 在窗内，R9/R10 结论稳健；
   若在窗外，需按 R11 的边界重新判定。

## ⑥ 误差判定（逐项，显式回答「是否 <3 %」）

| 关键量 | 基准 | 误差 | 是否 <3 % |
|---|---|---|---|
| θ 均值 55.00° | 主文献带中点 60°（Desrues & Viggiani 2004） | 8.33 % | **否**（容差 15 % 内 = 是，R7/R10 不变） |
| θ 均值 | Arthur @ 峰值 φ=35.45（φ_cv=32，自身材料状态） | **0.13 %** | **是** |
| θ 均值 | Mohr-Coulomb @ 峰值 φ=35.45 | 12.35 % | **否** |
| 稳健窗宽 | 预注册 [33, 38] 余量 | 1.5° vs 5°（未达成） | **不适用**（这是敏感性边界，不是测量误差） |
| 峰值 φ | 稳健窗 [34.0, 35.5] | 35.45 ∈ 窗内 | **是**（定性） |
| 晚窗 φ（cj4770） | 稳健窗 | **未取回**（not_run） | **不判定**（在飞，非测量） |

**honest 说明**：3 % 在「Arthur + 峰值 φ + 自身材料状态」通路上达成（0.13 %）；
对「主文献带中点 60°」的误差仍是 8.33 %（<15 % 容差内 = PASS，R7/R10 不变）。
本轮**新增**的诚实发现是：R9/R10 的「Arthur 在全部 φ_cv 上支持」声明**只在
φ ∈ [34.0, 35.5] 上成立**（稳健窗 1.5° 宽，窄于预注册 [33, 38] 余量）——
这是把 `not_run` 欠账变成「已定量、已标为真实风险」的增量，不是把结论改错。
所有未跑项（cj4770 晚窗 φ）已在 ⑤ 标注。
