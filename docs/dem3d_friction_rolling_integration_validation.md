## 1. 案例介绍

**物理背景。** 冰区船舶总体性能中，DEM 冰场与船体/冰–冰接触的切向分量直接决定接触摩阻、
碎冰堆积角与破冰阻力里「摩擦—挤压」的贡献；滚动阻力则在碎冰滚动输运与堆积体流动中起作用。
TensorDEM 的 `IceDEM3D` 接触分支（`SIR-PC2|F05`）声明了两条本构：

1. **切向 Coulomb 弹簧（Cundall–Strack 增量模型）**：累积切向相对位移 δ，施加
   `F_t = k_t δ`，并按 `|F_t| <= mu F_n` 截断；`k_t = k_n`。
2. **滚动阻力**：`T_r = mu_r R |F_n|`。当前求解器**没有转动自由度**，因此该阻力矩必须
   折算成等效力对才能进入运动方程。

**几何/工况（单接触 benchmark，无实体几何，纯运动学驱动）。**
两个半径 R=0.025 m 的球，法向重叠量 5 mm，形成解析法向力；每一步恢复几何并规定相对切向
速度，从而把切向分支单独隔离出来（法向力为精确常数）。

| 参数 | 符号 | 值 | 备注 |
|---|---|---|---|
| 球半径 | R | 0.025 m | — |
| 接触刚度 | k_n = k_t | 5000 N/m | — |
| 法向重叠 | Δ | 5.0e-3 m | Δ = 0.1 × 2R |
| 法向力（解析） | F_n = k_n Δ | 25.0 N | 精确常数 |
| 时间步 | dt | 1.0e-4 s | 低于保守稳定限 1.34e-4 s |
| 摩擦系数 | mu | 0.05 / 0.1 / 0.2 / 0.3 | 对应 F_limit = 1.25 / 2.5 / 5 / 7.5 N |
| 粘着极限位移 | a_stick = mu F_n / k_t | 0.25 … 1.5 mm | 弹性—滑移转换尺度 |
| 滚动阻力系数 | mu_r | 0 / 0.01 … 0.1 | — |
| 驱动速度 | v_rel | 1.0 m/s（粘着段 0.01 m/s） | 运动学规定 |

## 2. 怎么做的（方法与工具链）

**验证策略：先造判据，再动手。** 已有 `tests/test_friction_rolling.py` 的「Coulomb 饱和」用例
只断言 `sim.step_count == 1`（烟测），无法发现集成层缺陷。本单先把每条本构写成闭式判据，
再用运动学驱动 patch 逐条对照：

| 判据 | 闭式参考 |
|---|---|
| 粘着段弹力 | `F_t = k_t · v_rel · t`（δ < a_stick） |
| 滑移段饱和力 | `|F_t| = mu F_n` |
| 持久化滑移量 | `|δ| <= a_stick`（增量模型必须存**截断后**的位移） |
| 摩擦反向所需滑移 | `s_rev = a_stick`（±1 个积分步量子），与滑移历史无关 |
| 法向旋转后的切向力 | `F_t · n = 0`（δ 必须投影到当前切平面） |
| 分离后重接触 | 切向力 = 0，接触记忆随接触消亡 |
| 滚动阻力 | `F_t = -mu_r F_n`（切向、反对相对运动），耗散率 `P = -mu_r F_n |v_rel|` |
| 滑移功 | 总功 `F_limit(s - a_stick/2)`，耗散功 `F_limit(s - a_stick)` |

**缺陷定位过程**（只读探针 `scripts/probe_friction_defects.py`，保留作为回归探针）：

1. 长时滑移后检查持久化 δ：实测 `δ = 1.0e-2 m`，是 `a_stick` 的 **20 倍** →
   代码只截断**力**不截断**位移**，弹簧状态无限棘轮。
2. 反向驱动后检查 `F_t` 符号：始终停在「旧方向」，直到棘轮量被完全退回（需 0.02 m 滑移，
   是正确值的 40 倍，且随滑移时长线性增长）。
3. 旋转法向后检查 `F_t·n`：出现 **5 N**（= mu F_n，即 20% 法向力）的伪法向分量 →
   持久化 δ 用全局坐标保存、从不投影到当前切平面。
4. 完全分离 50 步后再接触：`_tangential_state` 仍保留 1 个 pair，且零相对速度下自发产生
   **5 N** 切向力 → 接触记忆不随接触消亡，字典无界增长。
5. 纯滚动阻力（mu=0, mu_r=0.05）：力全部落在 **z 向**（1.25 N），而滑移方向是 y →
   `F_i = n × F_rr` 与相对速度正交，耗散功率实测 **0 W**（应为 -1.25 W）：
   这是一个不做功的横向踢力，不是阻力。

**修复（最小改动，均在 `dem3d.py`）：**

| # | 缺陷 | 修复 |
|---|---|---|
| 1 | 只截断力、不截断持久化 δ | 把 `tang_disp *= scale` 后**持久化截断后的位移**，`F_t = k_t δ_clamped` |
| 2 | 存储 δ 不投影到当前切平面 | 取回时 `δ ← δ - (δ·n) n` |
| 3 | 接触记忆跨分离存活 / 字典无界 | `_update_tangential_state` 改为**按当前活动接触重建**字典；无接触时清空 |
| 4 | 滚动阻力力偶与运动正交、零耗散 | 新增 `_rolling_resistance_force`：等效力对沿切向**反对相对切向速度**，大小 `mu_r F_n`，力矩仅作诊断（杠杆臂 R 沿法向）；原 `_compute_rolling_resistance_torque` 保留为兼容包装 |

符号约定与法向/切向弹簧一致：作用在 `ci` 上的力与相对速度 `v_j - v_i` 同向，则
`F_i·v_rel > 0`、配对功率 `-F_i·v_rel < 0`，即耗散。

## 4. 注意点（踩过的坑 / 局限 / 适用范围）

1. **「公式对」≠「按求解器的方式用得对」。** 饱和力 2.5 N 在修复前后都正确；错的是**状态**
   （持久化位移不截断、不投影、不清理）。这类缺陷只有时间推进 + 反向/旋转/分离工况才暴露，
   单步烟测永远抓不到。
2. **滚动阻力在无转动自由度的求解器里本质上是近似的。** 本修复把它降维成沿切向的等效力对
   （量级 mu_r F_n），因此它**与 Coulomb 摩擦并联叠加**，等效切向极限为 `(mu + mu_r) F_n`
   （已由 `test_rolling_and_coulomb_add_up` 固定）。它不是「滚动阻力矩」的严格离散：
   真正的力矩需要角速度自由度与 `omega` 相关本构。适用范围：mu_r 作为小量（≲0.1）的附加耗散。
3. **接触记忆按步重建。** 依赖 `forces()` 每步只调用一次的用法；若同一时刻重复调用
   `forces()`（不推进时间），δ 会按调用次数重复累积——这是既有语义，本单未改（`diagnostics`
   路径本身不推进位移）。
4. **法向旋转后的 δ 投影会丢弃法向分量信息**，这是 Cundall–Strack 的标准做法（切向弹簧不
   存储法向位移），但意味着剧烈法向旋转的接触有轻微能量不一致（量级小于一个 a_stick 的弹性能）。
5. **粘着/滑移转换依赖 `k_t = k_n`**（库内写死）。a_stick 因此随 mu 线性变化；若后续引入
   独立 k_t，需重新标定 a_stick。
6. **接触断裂判据使用了全部键（含已断键）的位移场做最小二乘**（`_objective_shear_strain`），
   本单在探针中发现：把晶格外的颗粒瞬移到远处会污染邻近颗粒的应变估计并误触发剪切断键。
   常规模拟中碎键粒子仍在原邻域附近，影响有限，但这是**已记录的建模隐患**，未在本单修复。

**本仓库既有的red项（与本单无关，未修，仅留证）**：
`tests/test_dem3d_hertz_contact.py`、`tests/test_fracture_gen_mass_footprint.py`、

## 5. 误差判定

| 关键量 | 基准 | 误差 | < 3% ? |
|---|---|---|---|
| 粘着段 F_t | k_t v t | 2.8e-16 | 是 |
| 滑移段 \|F_t\|（mu=0.05…0.3） | mu F_n | ≤ 8.3e-16 | 是 |
| 持久化 δ | ≤ a_stick | 比值 1.0000000 | 是 |
| 反向滑移（0.05/0.1/0.2 s 历史） | a_stick + ≤1 量子 | +1.0 量子（dt·v 分辨率） | 是（历史离散度 0 m） |
| 法向旋转伪法向力 | 0 | 1.8e-14 N | 是 |
| 分离后重接触切向力 | 0 | 0.0 N | 是 |
| 滚动阻力 F_t / 耗散率 | -mu_r F_n / -mu_r F_n v | 7.1e-16 / 9.1e-16 | 是 |
| 滚动横向力 | 0 | 0.0 N | 是 |
| 滑移总功 / 耗散功 | F_limit(s-a_stick/2) / F_limit(s-a_stick) | 5.3e-3 / 5.6e-3 | 是（一阶收敛，比值 4.0） |

**结论：全部关键量相对误差 < 3%（绝大多数到机器精度）；唯一 0.5% 量级的滑移功残差可证为
时间步离散（细化 dt 4 倍误差降 4 倍），非模型误差。**
