## 1. 案例介绍（物理背景与参数）

### 1.1 物理背景

冰区船舶总体性能中，DEM 冰场与船体/冰-冰接触的切向分量直接决定：
- 接触摩阻力（船体与碎冰的滑动摩擦）
- 碎冰堆积角（滚动阻力控制休止角）
- 破冰阻力中「摩擦—挤压」贡献

Mission 670 的目标是在 `TensorDEM` 的三维 bonded-sphere DEM 引擎 `dem3d.py` 中实现：
1. **Coulomb 摩擦**：Cundall-Strack 增量切向弹簧，`|F_t| ≤ μ|F_n|`
2. **滚动阻力矩**：`T_r = μ_r R_eff |F_n|` 抵抗相对旋转
3. **恢复系数参数化**：法向阻尼由目标恢复系数 e 映射

### 1.2 关键参数

| 参数 | 符号 | 典型值 | 备注 |
|---|---|---|---|
| 摩擦系数 | μ | 0.0–0.3 | Coulomb 摩擦系数 |
| 滚动阻力系数 | μ_r | 0.0–0.2 | 无量纲 |
| 法向刚度 | k_n | 5000 N/m | 接触弹簧 |
| 切向刚度 | k_t | 10000 N/m | Cundall-Strack 弹簧 |
| 粒子半径 | R | 0.025 m | 冰球半径 |
| 粒子质量 | m | 0.060 kg | 密度 917 kg/m³ |
| 恢复系数 | e | 0.1–0.9 | 法向粘壶映射 |

## 2. 怎么做的（方法与工具链）

### 2.1 实现位置

- **主代码**：`src/tensordem/dem3d.py`
  - `DEM3DConfig` 新增字段：`friction_coefficient`, `rolling_resistance_coefficient`, `static_friction_coefficient`, `dynamic_friction_coefficient`, `friction_transition_velocity`
  - 接触力计算：`_rolling_resistance_couple()` 实现旋转代理力偶
  - 切向状态：`_tangential_displacement` 存储每个接触的切向位移历史

- **辅助模块**：
  - `src/tensordem/contact_tangential.py`：Cundall-Strack 切向弹簧
  - `src/tensordem/tangential_verification.py`：验证引擎
  - `src/tensordem/rolling_resistance.py`：Ai et al. (2011) 滚动阻力模型库

### 2.2 验证方法

**Anchor R（恢复系数映射）**：
- 半隐式 Euler 积分单接触法向碰撞
- 检测速度穿零事件，线性插值得回弹速度
- 判据：`|e_meas - e_target| / e_target < 0.5%`

**Anchor T（切向粘滑滞回）**：
- 恒法向力下谐波切向位移驱动 `δ(t) = a sin(2πt/T)`
- 闭式基准：平行四边形滞回环面积 `W = 4μF_n(a - μF_n/k_t)`
- 判据：相对误差 < 0.5%

**滚动阻力验证**：
- 单接触旋转代理力偶：`f_j = -μ_r|F_n|v̂_rel`，`f_i = -f_j`
- 守恒律检查：`f_i + f_j = 0`（线性动量守恒）
- 耗散性检查：`f_j · v_rel ≤ 0`（严格耗散）
- 积分级验证：滑移减速度 `a = μ_r F_n / m` 与解析值对比

## 5. 注意点（踩坑与局限）

### 5.1 发现的缺陷与修复

**滚动阻力力偶方向错误**（已修复）：
- **症状**：旧版 `force = torque / R` 导致力垂直于滑移方向
- **后果**：滑移减速度误差 42%，虚假 binormal 速度 101% of v0，动能不单调（增能）
- **修复**：`f_j = -μ_r|F_n|v̂_rel`，`f_i = -f_j`，确保力严格对抗滑移

**力偶符号约定错误**（已修复）：
- **症状**：对 (i,j) 对，i 上的力为 `-|f|v̂_rel` 而非反应力 `+|f|v̂_rel`
- **后果**：取决于 cell list 返回顺序，可能驱动滑移而非抵抗
- **修复**：严格 Newton 第三定律 `f_i = -f_j`

**切向状态未投影**（已修复）：
- **症状**：`compute_tangential_force` 截断力但未投影位移状态
- **后果**：反向加载时零力 crossing 误差 300%（0.012 m vs 0.003 m）
- **修复**：`advance_tangential_contact` 新增状态投影 `δ_t ← δ_t · min(1, δ_s/|δ_t|)`

### 5.2 局限性

1. **无旋转自由度**：`IceDEM3D` 无粒子取向/角速度/扭矩方程，滚动阻力只能实现为切向力偶（旋转代理），非真实扭矩
2. **Ai et al. (2011) 约定差异**：文献用有效半径 R* = R/2，实现用接触力臂 R，故 `μ_r_Ai = 2 μ_r_impl`，文献值须折半使用
3. **小 μ_r 数值噪声**：μ_r = 0.02 时减速度误差 6.6%（阻力小，数值噪声占比大）
4. **未做物理验证**：本报告为 code-versus-analytic 验证，非海冰力学实验对标

### 5.3 适用范围

- 适用于冰 rubble DEM、碎冰堆积角、破冰阻力摩擦贡献
- 不适需真实旋转动力学的场景（如球磨、颗粒流变学）
- 摩擦系数 μ 与滚动阻力系数 μ_r 需实验标定
