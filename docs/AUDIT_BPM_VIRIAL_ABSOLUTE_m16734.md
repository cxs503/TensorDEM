# AUDIT m16734 — BPM 逐粒子 virial 应力仪的**绝对量级**: 与面切割牵引力的独立对标

锚点：**NEW:CLOSE-GAP-BPM-VIRIAL-INSTRUMENT**（`docs/dem_calibration_gap_ledger.md` §2 「仍未接线：`bpm_calibration_feasibility.virial_stress_tensor`」——本条把它接上共享应力仪 并补上从未做过的**绝对量级**验证）。

## ① 案例介绍

`bpm_calibration_feasibility` 的巴西圆盘判据 AC5（Hondros 圆心主应力比 → −3，容差 15 %）只消费**同一张量两个主应力的比值**，因此该仪器的**绝对量级从未被检验**：一个整体偏 2 倍或偏 25 % 的仪器在 AC5 上是完全看不出来的。面切割牵引力 `granular3d.stress.plane_stress`（穿面接触的力之和 / 面积）是与之无任何共用代数的**独立路径**。

被检对象：简单立方键合试件 `SpecimenGeometry(n_layers, cross_n=4, R=0.0125 m)`，颗粒半径 0.0125 m，参考参数 `REFERENCE_VECTOR`（k_b=2.56e5 N/m）。状态构造：对整段标距施加**均匀仿射应变**并把所有颗粒固定（纯静力学，无动力学污染）——正是 virial 定理要求体平均与面切割一致的唯一状态。

## ② 怎么做的

1. `src/tensordem/bpm_calibration_feasibility.py`：新增 `pair_stress_state()`（**唯一**一处写下应力仪的力律：存活键轴力 `k_b(L−L0)` + 未键合对的法向排斥 `k_c·overlap`）与 `specific_volume()`；`virial_stress_tensor()` 不再自算配对张量，改用共享仪 `granular3d.stress.contact_outer`（`l ⊗ f`，l=x_j−x_i，f=作用于 i 的力），并新增两个显式选项：`scatter='half'|'legacy'`（配对计数）与 `volume_per_particle`（比容）。
2. `scripts/verify_bpm_virial_absolute_m16734.py` 产出全部数字与图；本文由 `scripts/render_bpm_virial_audit_m16734.py` 从 JSON 渲染。
3. 判定先于跑数：C1 = 体平均等于面切割牵引力 × 拉伸因子 (1+ε)；C2 = 旧实现的两个因子**可解析预测**（2(n−1)/n 与 1/n）。

### 3.2 残差结构：不是 bug，是 Cauchy/名义应力之差

| 仿射应变 ε | 体平均 vs 面切割 相对误差 | 比值 / ε |
|---|---|---|
| 1.0e-04 | 1.000e-04 | 1.000000001 |
| 5.0e-04 | 5.000e-04 | 1.000000000 |
| 1.0e-03 | 1.000e-03 | 1.000000000 |
| 2.0e-03 | 2.000e-03 | 1.000000000 |

比值在所有 ε 上 = 1.000000000（9 位）⇒ 残差**恰为**拉伸因子 (1+ε)：virial 给当前构形 Cauchy 应力，面切割按参考面积给名义应力，一阶差即 ε。缺陷修好后误差判据（<3 %）成立，且这是**物理解释**而非拟合。

### 3.3 变异（非空转）检验

状态：n_layers=5，ε=-2.0e-03，预断键比例 0.25 → 死键 152 根、接触分支 19 对（两支同时非零）；参考 σ_zz = -6.151e+04 Pa（面切割 -6.443e+04 Pa）。

## ⑤ 注意点与局限

* 只对**均匀仿射**状态做了精确对标：非均匀状态（真实剪切带）里体平均与面切割之差是真实的应力梯度项，不能当误差。
* 应力仪仍**不含**切向/滚动分支（引擎把该历史私有化）：张量因此恒对称，摩擦不对称量不可测——本轮没有假装修好这一条。
* `scatter='legacy'` 保留只为复现 m16734 之前的数字，不得用于新结论。
* 面切割只给穿过面的**法向行**，三轴同时验证需要三个方向的面切割，本轮只做 z 轴（受载轴）。

## ⑥ 误差判定（关键量 vs 基准逐项）

| 关键量 | 基准（独立路径） | 误差 | 是否 <3 % |
|---|---|---|---|
| 修正后体平均 σ_zz（n=9, ε=+2e-3） | 面切割牵引力 | 0.200 % (= ε，可解析) | **是** |
| 旧实现 σ_zz（n=9, ε=+2e-3） | 面切割牵引力 | 78.13 % | 否（缺陷已修复） |
| 代数恒等式 sum_p V_p σ_p = sum_c l⊗f | 共享仪 contact_outer | 3.6e-14（绝对元，双精度 ulp 级） | 是 |

结论：修正后体平均应力与独立面切割牵引力的差**恰为仿射拉伸因子 (1+ε)**，ε→0 时收敛为 0；旧实现相对真值偏高 33 %（n=3）→ 5.7 %（n=17），且在 AC5 圆盘格子上另有 24.6 % 的系统性量级偏差。
