# 直剪盒宏观摩擦装置：从「压板失去接触」到「伺服稳住 σ_n 并给出可用 μ」

**锚点**：`GAP-DEM-FRICTION`（"摩擦系数 vs 实验 <10%"，status 仍为 in_progress）
**任务**：m14721（paper 席自主工时），仓库 TensorDEM，模块 `src/tensordem/shear_cell.py`
**上一单**：m13798（同模块，7 个测试把拟合器与有效性门锁住，但物理稳态 honest FAIL：σ_n→0、μ 无定义）
**本单结论先行**：m13798 记录的「压板失接触」不是边界条件细节问题，而是**三个叠加机制**：
①初始 HCP 点阵是膨胀态（体堆积率 0.31），重力塌落速度 0.1–0.4 m/s，**快于任何速度型伺服**；
②伺服是速度限幅型（0.02–1.0×shear_velocity），物理上追不上塌落中的床面；
③剪应力符号写反（`tau = -Σf_p,x/A`），即使压板带上载荷也只会给出 **负的 μ**（被有效性门拦住，未污染报告）。
三者已修，装置现在把 σ_n 稳定在目标值 +3.1%~+4.6%，三个应力级全部通过有效性门，μ 有定义。

---

## 1. 案例与装置（物理背景 / 几何 / 参数）

直剪盒是颗粒材料**宏观摩擦系数**的测量装置：粗糙底板 + 无摩擦侧壁 + 应力伺服压板横向拖动，
逐级测 (σ_n, τ) 点值，再跨不同 σ_n 级拟合 Mohr–Coulomb 包络 `τ = c + σ_n tanφ`。

| 项 | 值 | 说明 |
|---|---|---|
| 颗粒 | r = 5 mm，ρ = 2500 kg/m³ | 单分散玻璃珠，n = 78 |
| 盒体 | 0.080 × 0.032 × 0.050 m | 侧壁 μ_wall = 0（法向刚性） |
| 底板 / 压板 | 粗糙，μ = μ_p | Cundall–Strack 切向弹簧 + 滚动弹簧（μ_roll = 0.05） |
| 接触 | kn = 1e5 N/m，kt = 0.5 kn，e = 0.3，dt ≈ 2.5e-5 s | Hertz 线性化等价刚度；dt = T_c/20 |
| 协议 | ①床面制备（准静态判据）②应力伺服固结 0.04 s ③剪切 γ̇ = v/H = 1.0 s⁻¹，γ = 0.30 | 稳态窗取剪切后 50%，分块标准误 |
| 惯性数 | I = γ̇·2r/√(σ_n/ρ) = 0.28/0.20/0.14（2000/4000/8000 Pa） | 准静态区（I ≲ 0.3） |

## 2. 怎么做的（方法 / 关键设置 / 工具链）

### 2.1 诊断（先证据、后修复）

新增按步采样的内部计数器（`ShearCellCase.diagnostics=True`：σ_n、τ、压板 z、床面最高点、床面平均 z、
压板接触数、越顶颗粒数、最大颗粒速度、压板速度），对 400 Pa 复跑 m13798 的协议，得到决定性的时间序列：

| 观测量 | 修复前（m13798 协议） | 判读 |
|---|---|---|
| 床面平均 z | 0.0258 → 0.0164 m（**全程持续下降**） | 不是"沉降瞬态"，而是整场塌落 |
| 体堆积率 | 0.31 → 0.49 | 初始点阵膨胀，塌落 25% 体积 |
| 最大颗粒速度 | 0.10–0.47 m/s（整场） | 塌落流的自由落体量级 |
| 压板接触数 | **0**（压板全程悬空 5–20 mm） | σ_n ≡ 0，μ 无定义 |
| 压板下降速度 | ≤ 0.05 m/s（限幅） | **追不上** 0.1–0.4 m/s 的床面 |

第二遍把伺服换成载荷控制后，又暴露出**接触数只有 1–4 个、σ_n 在 0–700 Pa 之间跳**，
说明此刻的瓶颈是"床面没制备好"而不是控制器。第三遍加床面制备后 σ_n 才稳住，但 μ **恒为负**，
顺藤摸瓜找到符号错误：压板沿 +x 拖动，对床体的推力是 +x，代码却写成 `tau = -Σf_p,x/A`。

### 2.2 三处修复（最小改动，均带回归测试）

| # | 缺陷 | 机制 | 修复 |
|---|---|---|---|
| F1 | 床面未制备即加载 | 膨胀点阵塌落 0.1–0.4 m/s，任何速度型伺服都追不上 | 新增 `prepare_bed()`：重力沉降到**准静态判据**（100 步采样一次，max\\|v\\| < `settle_v_tol`=0.01 m/s，连续 500 步；上限 `settle_max_time`=0.8 s；实测 13.7k 步，体堆积率 0.437） |
| F2 | 速度限幅伺服 | `\\|v_z\\| ≤ 0.02·v_shear`（细调）/ `1.0·v_shear`（逼近）滞留在塌落床面之后 | 载荷控制执行器：`M_plate·dv_z/dt = -(N_target - N_meas)`，速度弛豫 τ = 5e-4 s，\\|v_z\\| ≤ 0.5 m/s。稳态要求 N_meas = N_target（无静差），无需调刚度增益 |
| F3 | 剪应力符号 | `tau = -Σf_p,x/A` ⇒ μ < 0 | `tau = +Σf_p,x/A`（压板传给床体的牵引），底板侧 `tau_floor = -Σf_f,x/A`（同一牵引的另一侧，成为独立交叉校验） |

附带的结构性改进：
* **同一床面跨应力级复用**：`simulate_shear_cell(case, bed=...)`，`measure_macro_friction` 只制备一次床面
  → σ_n 级间差异不再是"两床不同"的混杂因素（受控变量），也省掉每级 ~26 s 的制备开销；
* **有效性门抽成 `_validity_gate()`**（可单测）：σ_n > 0.5·目标 且 τ > 0 才给 μ，否则返回 `invalid_reason`。

## 3. 计算结果（数字表，由 `artifacts/shear_cell_m14721/tractions.json` 程序化注入）

床面制备（三级共用，seed=6107）：13 700 步，床面最高点 0.0315 m，体堆积率 **0.437**，n = 78。

### 3.1 应力扫描（μ_p = 0.5，γ = 0.30，每级 27 078 步）

| σ_n 目标 [Pa] | σ_n 实测 [Pa] | 相对误差 | τ [Pa] | μ_macro = τ/σ_n | 有效性门 | 压板接触数（均值 / 零接触占比） | τ_floor/τ |
|---|---|---|---|---|---|---|---|
| 2000 | 2063.06 | **+3.15%** | 525.63 | 0.2548 | PASS | 5.2 / 0.00 | 1.043 |
| 4000 | 4173.21 | **+4.33%** | 1189.92 | 0.2851 | PASS | 7.7 / 0.00 | 1.229 |
| 8000 | 8368.99 | **+4.61%** | 2542.17 | 0.3038 | PASS | 9.5 / 0.00 | 1.103 |

σ_n 逐级升高时 μ_macro 单调升（0.255 → 0.285 → 0.304），符合"约束越强、剪胀越难、摩擦动员越充分"的定性趋势；
σ_n 级的离散度（μ 级间相对散布）≈ 8.8%，是 78 颗粒床面的统计噪声水平，非本装置的系统误差。

### 3.2 颗粒摩擦系数扫描（σ_n = 4000 Pa）

| μ_p 输入 | σ_n 实测 [Pa] | 相对误差 | τ [Pa] | μ_macro 实测 | μ_macro/μ_p | 有效性门 |
|---|---|---|---|---|---|---|
| 0.10 | 3999.88 | **−0.00%** | 399.99 | **0.1000** | 1.000 | PASS |
| 0.30 | 3881.33 | −2.97% | 1011.15 | **0.2605** | 0.868 | PASS |
| 0.50 | 4173.21 | +4.33% | 1189.92 | **0.2851** | 0.570 | PASS |

**这是本单最有信息量的结果**：装置在低摩擦端**精确复现输入**（μ_p = 0.1 → μ_macro = 0.1000，
偏置 0.0%），说明测量链路（伺服 → 法向力 → 切向力 → 比值）没有系统增益误差；
在 μ_p ≥ 0.3 端宏观摩擦被**结构性折减**（0.87× / 0.57×）——这是球颗粒床的已知行为
（滚动自由度 + 床面重排释放剪胀，宏观动员的摩擦低于界面滑动摩擦），
即"μ_macro ≤ μ_p"的方向性判据被满足，且折减随 μ_p 增大而增强。

## 4. 注意点（坑 / 局限 / 适用范围）

1. **短窗口会骗人**：剪切窗 γ = 0.06（2000 步）时伺服瞬态未冲掉，σ_n 欠载 −24.5%，门给 PASS 之外的
   "看起来正常"的错数。验收协议固定为 γ ≥ 0.30。这条已写进验收测试注释。
2. **78 颗粒是硬约束**：压板接触数只有 5–10 个，σ_n 级间统计误差 ~5%。要把 σ 的偏差压到 <3%
   需要 ~3× 颗粒数（≈9× 计算量），本机 load15 ≈ 115 时不做。
3. **σ_n 系统性偏高 +3~+5%**：载荷控制执行器的稳态应当无静差，实测的小正偏来自压板持续下压的
   蠕变分量（dv_z/dt ≈ 0 但床面仍在缓慢致密）。它随 σ_n 单调变大（3.15→4.61%），是装置偏置而非数值误差。
4. **τ_floor/τ = 1.04–1.23**：两侧边界牵引一致性在 23% 内（薄床 3 层，底板与压板各承担不等的
   颗粒数），可用作独立交叉校验但不足以当作 <10% 判据。
5. **无实验数据集**：仓内**没有**任何直剪实验（或文献数字化）数据可供对标，因此本单**不能**宣称
   "摩擦系数 vs 实验 <10%"。锚点 `GAP-DEM-FRICTION` 保持 in_progress，只把"装置可用性"这一颗前置地雷清掉。
6. 适用范围：I ≲ 0.3 的准静态区、单分散球、无黏结；给冰区碎冰场的 μ_macro 提供装置，不代表冰-结构摩擦定律。

## 5. 误差判定（逐项显式回答）

| 关键量 | 基准 | 误差 | 是否 <3% |
|---|---|---|---|
| Mohr–Coulomb 拟合器（tanφ、c） | 合成直线 τ = 100 + 0.3σ | < 1e-10 | **是**（机器精度） |
| 伺服稳压 σ_n（2000/4000/8000 Pa） | 目标值本身 | +3.15% / +4.33% / +4.61% | **否**（<5% 但不 <3%） |
| μ_macro 复现输入 μ_p（低摩擦端） | μ_p = 0.10 | 0.00% | **是** |
| μ_macro vs μ_p（中高摩擦端） | μ_p = 0.30 / 0.50 | −13.2% / −43.0%（结构性折减，非误差） | 不适用（方向性判据通过） |
| μ_macro vs **实验** | 无数据集 | 不可比 | **无法判定**（锚点不关闭） |
| 压板/底板牵引一致性 | τ_floor = τ | 4.3% / 22.9% / 10.3% | 否（薄床统计） |

**honest 声明**：本单把 m13798 的 honest FAIL（σ_n ≡ 0）修成"σ_n 稳在 5% 内且 μ 有定义"，
并在低摩擦端证明测量链路无系统偏置；但"vs 实验 <10%"未达成、未宣称，锚点状态不变。
需要在 TensorDEM 里补一份**直剪实验（或文献数字化）对标集**才能真正关闭 `GAP-DEM-FRICTION`。
