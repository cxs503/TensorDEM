## 1 案例介绍

`src/tensordem/threefield/wake_lbm.py` 是仓内唯一真实流体求解器：D3Q19 BGK + Guo 型螺旋桨作动盘
+ Smagorinsky 亚格子闭合 + 侧向自由滑移壁面 + 均匀入流/零梯度出流。它的产物（尾流速度尺度与
湍流混合尺度）经 `thermal.py` 的 Ranz–Marshall + Stefan 条件折算成浮冰融化率，再由 `coupling.py`
并进冰‑桨‑船质量账。也就是说：**边界条件不是数值细节，而是直接进入冰质量损失率的一环**。

被复核的是实际发表的算例（`scripts/run_threefield_coupling.py::_lbm_config`）：

| 参数 | 取值 |
|---|---|
| 域 | nx × ny × nz = 72 × 36 × 36（四分之一域，两条对称面用自由滑移切出） |
| 松弛时间 / 运动黏性 | tau0 = 0.5005，nu = 0.0005/3 = 1.667e-04 |
| Smagorinsky 系数 | Cs = 0.14 |
| 入流 / 射流速度 | U_in = 0.04 / U_jet = 0.12（Ma ≈ 0.12/3**0.5:.3f·... 低 Mach） |
| 作动盘 | D = 10 格，x = 8，厚度 3，高斯径向分布，15 % 目标噪声，2 % 入流噪声 |
| 步数 / 平均窗 | 2100 步（流经时间 L/U_in = 1800 步 → **1.17 个流经**），从 1260 步起平均 840 个样本 |

## 2 怎么做的

五项独立检查，参考量一律取**闭式解或精确离散恒等式**，且全部走求解器自身核
（`_equilibrium` / `_macroscopic` / `_apply_boundaries` / `thrust_lattice`），不另写一套边界：

- **A 匀速流不动点**：均匀来流是离散动理学方程、精确 streaming 与三种边界（Dirichlet 入流、
  零梯度出流、镜面反射壁面）的**精确解**。参考 = 零漂移（`u ≡ U_in`，`u_y = u_z ≡ 0`，`rho ≡ 1`）。
  任何漂移只能来自边界代码。
- **B 镜面壁面**：自由滑移必须**不渗透**（壁面法向速度 `u_n = 0` 精确，进/出质量严格相等）且
  **无切向牵引**（反射把 `c_n` 取反、`c_x` 与另一个切向分量不变，故交换的轴向动量恒为零 → 无伪
  阻力）。阴性对照：故意把反射表改成同时翻转 x，审计必须报警。
- **C 开放边界账本**：4200 步内每 10 步记录箱质量、轴向动量、入/出口面通量 `J_in = Σ c_ix f_i`、
  以及求解器自记的作动盘冲量；给出相对质量漂移率、通量不均衡、以及「充填时间」（`J_out/J_in`
  连续落入容差带所需的流经数）。
- **D 已发表基准复核**：用**当前代码**（含 m2949 的 Smagorinsky 范数修正）重跑发表协议的
  2100 步算例，把 σ_fit、R²、超动量通量、U_c、质量通量逐项与 `THREEFIELD_ICE_HULL_PROPELLER.md`
  §3.2 印刷值对照；再用同长度平均窗（840 样本）在 4200 步（2.3 个流经）复核一次。
- **E m2949 遗留 honest-FAIL 收口**：m2949 记录 tau0 = 1.4 剪切波衰减率误差 −3.14 % 并留作
  「分辨率问题，留作下一步」。本单在 N = 32（波数减半）重测六档 tau0，判定该 FAIL 是否属截断误差。

工具链：`PYTHONPATH=src OMP_NUM_THREADS=8 python scripts/audit_threefield_wake_boundaries.py`
（torch 2.7.1 CPU；发表几何 float32，剪切波 float64；全套约 12 min，本机 load15 ≈ 105 的争用条件下）；
`PYTHONPATH=src python -m pytest tests/test_threefield_boundary_verification.py -q` → **11 passed**。

## 3 计算结果

### 3.1 A 匀速流是整套有界格式的精确不动点

| 配置 | 步数 | max abs(u_x − U_in) | max abs(u_y,u_z) | max abs(rho − 1) | 相对质量漂移 |
|---|---|---|---|---|---|
| laminar tau0=0.6 | 200 | 2.62e-15 | 0.0 | 7.33e-15 | 6.71e-15 |
| sgs tau0=0.5005 Cs=0.14 | 200 | 6.68e-15 | 0.0 | 1.85e-14 | 1.51e-14 |

两个配置（层流 cs=0 与 SGS cs=0.14、tau0=0.5005）都在 1e-14 量级的舍入地板上，横向速度**逐位为零**。
结论：自由滑移壁面不产生伪边界层，入流/出流对不产生伪质量源，Smagorinsky 闭合在零应变处
精确退回 tau0（否则匀速流会立刻被人工黏性扰动）。

### 3.2 B 镜面壁面：不渗透、零切向牵引（float32 舍入地板上的精确性）

| 算例时刻 | 壁面 max abs(u_n) | 质量进/出相对失配 | 轴向动量交换（相对） | 反射表切向失配 | max abs(u) |
|---|---|---|---|---|---|
| 2100 步（发表协议） | 0.0 | 3.53e-08 | 2.2e-09 | 0.0 | 0.162 |
| 4200 步（2.3 个流经） | 0.0 | 3.53e-08 | 2.2e-09 | 0.0 | 0.138 |

`u_n` 与反射表失配都是**精确零**；质量与轴向动量的进/出失配停在 float32 的舍入地板
（3.53e-08 与 2.2e-09，相对 eps32 = 1.19e-7 分别
30 % 与 2 %）。
阴性对照（把反射表改成同时翻转 x）在测试中被捕获（`test_corrupted_reflection_table_is_caught`），
说明这三项指标确实对「类无滑移缺陷」敏感，而不是恒真的装饰。

**注意（本单自身的诚实项）**：`audit.json` 的 `failures` 列表把上述 float32 残差判成了失败，原因是脚本里
壁面判据写成了 float64 的绝对阈值 1e-14。该阈值已在脚本中改为按算例 dtype 取（float32 用 1e-6，
float64 用 1e-13）；本报告表格引用的是**记录值本身**，判定按 dtype 后的地板解释，未改动任何记录数字。

### 3.3 C 开放边界账本

| 量 | 值 |
|---|---|
| 记录长度 / 流经时间 | 4200 步 / 1800 步·流经⁻¹ → 2.33 个流经 |
| 作动盘冲量率（thrust_lattice） | 0.0699（发表值 0.0707，偏差 -1.12 %）|
| 箱质量相对漂移率 | 2.63e-08 /步（4200 步累计 1.1e-02 %）|
| `<J_in − J_out>/<J_in>` | -0.337 % |
| 末样本 `J_out/J_in` | 1.0024 |
| 充填到 ±1 % 所需流经 | 110 步 = 0.061 个流经 |
| 充填到 ±2 % / ±5 % | 记录起点即已落入（0 步）|

结论（与原假设相反，如实记录）：入/出口通量比**很快**就落进 1 %（0.06 个流经），因此
`J_out/J_in` **不能**当作充填诊断——Dirichlet 入流与零梯度出流本身就吸收了不均衡。真正可信的正向
结果是**箱质量漂移率 2.6e-8/步**（4200 步累计 1.1e-4 相对）：这一对开放边界在**质量账**上是中性的，
不给耦合链注入伪质量源。动量不均衡 -0.34 % 与 0.35 % 的量级说明
面通量口径本身受入流 Dirichlet 态影响，故动量结论改用 D 项「超动量通量 vs 推力」这条与背景通量
相减后的口径。

## 4 注意点（踩过的坑 / 局限 / 适用范围）

1. **壁面判据必须按 dtype 取阈值**。发表算例是 float32（`dtype="float32"`），其舍入地板 1.19e-7；
   用 float64 的 1e-14 绝对阈值会把舍入判成物理缺陷（本单第一版就报了 4 条假失败）。相对残差
   （进/出失配 / 面质量）才是尺度无关的正确口径。
2. **`J_out/J_in` 不是充填诊断**。Dirichlet 入流 + 零梯度出流本身吸收不均衡，通量比在 0.06 个流经内
   就进 ±1 %。真正的守恒判据是箱质量漂移率与「超通量/推力」这类与背景相减的口径。
3. **超动量通量对平均窗长度敏感**（同站 2100 步 1.19 vs 4200 步 1.15），故本类结论必须同时给出
   平均窗与流经数，不能只给一个比值。
4. **未覆盖**：自由滑移壁面在真实湍流下对对数层/剪切层的精度（本文只证明「零牵引 + 不渗透」这一
   精确性质）；出流零梯度在回流区（本文算例无回流）的适用性；更细网格下的边界层分辨率。
5. **容量纪律**：本单全部算例为单机 CPU、总量约 2.6e8 格点步，未起新的重型并行作业（load15 ≈ 105）；
   发表几何的 4200 步延长算例是本单最贵的一项（约 4 min）。
