## 1. 案例介绍（物理背景/几何/参数）

船舶穿透冰脊时，阻力来自龙骨：船体把受约束的碎冰块推开、抬起、剪切，这是**颗粒
力学**问题，不是连续体问题。经验公式（Lindqvist 1989 及其族）把它压缩成"摩擦系数
× 被排开碎石重量"。本节点给出同一问题的颗粒尺度侧。

几何（平面应变，单宽）：三角龙骨包络，吃水深度 `h_k`、水线宽 `w_k`，`y=0` 为水线
（mouldline），龙骨尖端在 `y=−h_k`；碎冰块为二维圆盘，粒径服从幂律数密度
`n(d) ∝ d^{−p}`，`d ∈ [0.15, 2.0] m`、`p = 1.8`（预注册）；船体为刚性楔形体（半角
`α`），沿 +x 以速度 `V` 推入；水线以上由刚性盖板（代表固结层+帆）约束，龙骨两侧
为刚壁包络。

| 参数 | 值 | 来源 |
|---|---|---|
| 龙骨深 `h_k` / 宽 `w_k` | 6.0 m / 20.0 m（基准算例 4/14 m） | 任务取值范围 h_k∈[5,20], w_k∈[20,60] |
| 粒径分布 | 幂律 p=1.8, d∈[0.15, 2.0] m | 预注册 |
| 冰密度 / 水密度 | 917 / 1025 kg·m⁻³ | 常数 |
| 弹性模量 / 泊松比 | 1.0 GPa（基准算例 0.2 GPa，碎石接触软化） / 0.30 | 数值软化，已声明 |
| 颗粒摩擦 / 滚动摩擦 / 恢复系数 | 0.55 / 0.05 / 0.40 | 微力学输入 |
| 冻结粘结强度 σ_n / σ_t | 20 kPa / 10 kPa（×粘结面积 2·min r） | 冰脊碎石冻结键量级 |
| 楔半角 `α` / 速度 `V` | 30° / 1.0 m·s⁻¹（扫描 15/30/45°, 0.5/1/3） | 任务取值 |
| 船体-冰摩擦 | 0.30 | 输入 |
| 上覆压力（帆+固结层） | 7.5 kPa（基准算例等效单位重 1250 N/m³） | 有效应力化，已声明 |
| 时间步 | 由 Hertz 准则 `dt = 0.08·2π/ω_min` 定（基准算例 1.84 ms） | `stable_timestep` |

## 2. 怎么做（方法/流程/关键设置/工具链）

1. **装料**：粒径幂律抽样 → 三角包络内最大颗粒优先的随机顺序吸附（RSA）→
   几何重叠松弛 + 半径增长（`_relax_packing`）→ 得到无重叠的可容许密堆（实测
   固相率 0.69）。
2. **接触**：Hertz 非线性法向（`(4/3)E*√R*·δ^{3/2}`）+ 恢复系数定标的法向阻尼；
   Mindlin 切向增量弹簧（Cundall–Strack，`k_t/k_n = 2(1−ν)/(2−ν)`），饱和于
   `μF_n`，滑移功入账；滚动阻力按"逐颗粒耗散力矩"实现（成对同号力矩会反对称地
   给一颗颗粒注入能量——这是本轮踩到的坑，见 §5）。
3. **冻结粘结**：轴向/切向线性弹簧 + 拉/剪强度上限，断裂时把弹簧储能记入
   `bond_fracture_energy`。
4. **船体楔**：凸区域最近点接触（两面 + 顶点），法向 Hertz + Coulomb 切向，
   楔为运动学刚体（给定 V），反力 `face_force` 即每单位船长的阻力。
5. **后处理**（每 250 步一个测量窗）：
   - 力链：`F_n > 2⟨F_n⟩` 为强接触，做力权织物张量的主轴（力链方向）、强接触
     载荷占比、并查集连通分量（力链拓扑）、跨窗游程（力链寿命）；
   - 应力：接触应力张量 `σ_ij = −(1/A)Σ f_i l_j`，特征分解给最大/最小主压方向与
     动员摩擦 `sin φ = (σ1−σ3)/(σ1+σ3)`；
   - 剪切带：格元内位移梯度最小二乘 → 等效剪应变 γ → 高热单元 γ 权 PCA 主轴；
   - 孔隙率：高斯粗粒化局部固相率（体跟随，避免欧拉窗物料流失伪信号）。
6. **经验锚**：`R_L = μ_h·ρ_i·g·(1−n)·h_k/sin α`（Lindqvist 族龙骨摩擦结构），
   系数集 `WITHHELD`，同时给 μ_h∈[0.4,1.0] 的偏差带。
7. **工具链**：NumPy float64 向量化积分（速度 Verlet + 梯形功积分）、pytest、
   matplotlib、JSON 工件。

## 5. 注意点（踩过的坑/局限/适用范围）

1. **能量台账缺项（C2 失败的直接原因）**：`EnergyLedger` 只累计颗粒–颗粒接触与
   粘结的弹性储能，**未计壁面与楔面的 Hertz 弹性项**。在封闭包络被压死的状态下
   这两项恰是主导弹簧，残差因而被放大到 −1.5×10³。修复方向明确（把 wall/wedge
   的 `δ`、`k` 缓存进 `elastic_energy`），本轮未做。
2. **封闭包络导致塞积（C7 失败的主因）**：盖子 + 两侧刚壁 + 三角形尖端构成**闭合
   容器**；楔从侧壁推入时物料无处可去，只能压缩 → 阻力比 Lindqvist 锚高 170 余倍。
   真实冰脊中碎冰可沿脊轴方向流动、可把固结层顶裂上拱。正确修法：让盖板可**上拱**
   （自由面 + 上覆压力边界），或把二维切片做成周期性以表示沿脊不可压方向的流动。
   这是本节点最关键的一条否定性结论：**"刚性闭合包络 + 侧向推入"不是船体穿透冰脊
   的正确边界条件**。
3. **剪切带测不出（C4）**：物料被压死在楔面附近，位移场高度局部化，高热格元不足
   （<4），PCA 无法定向。剪切带需要在能真正"流动"的边界条件下才成形——与 (2) 同源。
4. **双轴标定器不稳定**：独立的摩擦角标定（`biaxial_friction_angle`，伺服围压 +
   轴向压缩）在当前实现下会发散，已改成**发散即抛异常**（不再静默返回 φ=0）；
   因此 §3 的 φ 用的是穿透算例自身的动员摩擦，属于"自标定"，C4 的角度预期值因此
   带循环性，已在预注册里声明。
5. **滚动阻力实现**：把同一个偶矩同号加给两颗颗粒会给其中一颗注入能量（反对称），
   是早期 NaN 爆炸的根因之一；现改为逐颗粒耗散力矩（各自反对自旋）。
6. **装配无预压**：几何松弛把重叠驱到 0，因而初始状态无接触力（力链要靠贯入产生）。
   真实龙骨在固结层与帆压下处于 kPa 量级有效应力状态，正确的做法是伺服压密或半径
   过盈后让接触求解器平衡——过盈量需按目标应力（kPa）标定，4% 过盈会给出 10 MPa
   （高 3 个量级），未标定完成。
7. **适用范围**：二维平面应变、单宽；面外逃逸无法表示；冻结键为率无关弹脆；粒径
   截断 0.15 m 以下细粒缺失；模量 1 GPa 为数值软化值（真实冰 ~9 GPa）。
