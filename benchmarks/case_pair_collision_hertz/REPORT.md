# CASE-PAIR-COLLISION: Two-Sphere Hertz Impact Restitution Coefficient Benchmark

## ① 问题描述与参考出处

**物理问题**: 两个相同弹性球体以大小相等、方向相反的速度对心碰撞，接触力遵循经典Hertz接触定律：

$$F_n = \frac{4}{3} E^* \sqrt{R^*} \delta^{3/2}$$

耗散采用Tsuji型非线性阻尼器：

$$\gamma_n(\delta) = 2\zeta \sqrt{m_{\text{eff}} k_s(\delta)}$$

其中 $k_s(\delta) = \frac{4}{3} E^* \sqrt{R^*} \sqrt{\delta}$ 为割线刚度。

**参考出处**:
- Hertz接触力公式: Hertz, H. (1882), "Über die Berührung fester elastischer Körper"
- 峰值重叠解析解: Goldsmith, W. (1960), *Impact: The Theory and Physical Behaviour of Colliding Solids*, Edward Arnold, Eq. 5.6, p.152
- 接触时间解析解: Goldsmith (1960), Eq. 5.8, p.153
- Tsuji阻尼映射: Tsuji, Tanaka & Ishida (1992), *Powder Technology* 71, 239-246

**容差判据**: <3%

## ② 方法与实现

**实现路径**: 复用TensorDEM现有Hertz接触能力 (`tensordem.dem3d.IceDEM3D` with `contact_model="hertz"`)，在2×2×2晶格中隔离出一对自由球体进行碰撞模拟。

**参考解**: 独立RK4积分器（与DEM引擎代码路径完全独立），在相对坐标系中积分Hertz接触律。

**关键设置**:
- 时间步: dt = 0.4 × recommended_dt (Hertz稳定性 bound)
- 接触模型: Hertz + Tsuji非线性阻尼
- 阻尼约定: `contact_damping_model="restitution"` (默认)
- 拖曳力: drag=0 (隔离接触耗散)

## ⑤ 收敛性与参数敏感性

### 5.1 时间步收敛
峰值重叠误差在dt×0.4时达到0.0001%，进一步细化到dt×0.2时误差略有上升(0.0002%)，表明数值解已在dt×0.4处充分收敛。接触时间误差稳定在2.59%，主要来源于离散时间步对接触起止时刻的量化误差（约1个时间步的离散化偏差）。

### 5.2 速度敏感性
恢复系数在0.25~1.0 m/s范围内变化仅0.0002（0.8257~0.8259），验证了Tsuji阻尼模型的速度独立性理论预测。这与Hertz-Tsuji接触律的理论预期一致：非线性阻尼γ~δ^(1/4)使得恢复系数与速度无关。

⑦ 第 2 条判定「请求的恢复系数 e_target 未被交付」（e=0.5 → 16.46%，e=0.8 → 3.23%），

本节把它**修掉**并给出闭合证据；⑦ 的判定与 ①②③④⑤⑥ 原文保持不变以便追溯。

### 8.1 问题再表述与判据（先定判据，后看结果）

| 项 | 内容 |
|---|---|
| 待判定命题 | `restitution_coefficient` 在 `contact_model="hertz"` 下是否为**物理参数**（设多少就实得多少） |
| 基线（缺陷） | `contact_damping_model="restitution"`：`zeta = |ln e| / sqrt(pi^2+ln^2 e)`（线性理论） |
| 修复候选 | `contact_damping_model="restitution_calibrated"`：`zeta*` 为**Hertz 恢复系数曲线的逆映射**（新增 `tensordem.contact_calibration`） |
| 判据 | `max |e_measured − e_requested| / e_requested < 3%`（平台精度线；本单同时报告更严的 0.3% 观察值） |
| 无需拟合的参数 | 校准曲线 `G(zeta)` 由无量纲 ODE 求得，不含任何按本例数据回归的系数 |

被否定的第三条路线：直接把默认映射改成校准值。**否决理由**=仓库内既有 Hertz 结果
（`docs/dem3d-hertz-restitution`、`tests/test_dem3d_hertz_restitution_verification.py` 等）
依赖默认约定位对位不变；故校准为**显式 opt-in**，默认轨迹逐位不变（下方 8.3 有实测对照）。

### 8.2 方法：相似性归约 + 逆映射（与引擎代码路径独立）

令 `delta = D u`、`t = T tau`（`D`=弹性极限峰值重叠，`T = sqrt(m_eff/(k sqrt(D)))`，
`k=(4/3)E* sqrt(R*)`），Hertz + Tsuji 阻尼的相对运动方程归约为

```
u'' = -max( u^(3/2) + 2 zeta u^(1/4) u' , 0 ),   u(0)=0, u'(0)=sqrt(4/5)
```

即 `e_real = G(zeta)` 是**普适曲线**：与半径/密度/杨氏模量/冲击速度全部无关
（`u'(0)=sqrt(4/5)` 由弹性极限能量积分给出）。截断项 `max(·,0)` 是引擎的单边接触投影
（分离末期阻尼项会变成拉力，引擎不允许拉力）；两项不能省——省掉它 `e` 会低 0.8%
（`tests/test_contact_calibration.py::test_one_sided_dashpot_clip_matters`）。

`G` 用无量纲 RK4（`dt=1e-4`，分离事件用三次 Hermite 定位）数值求值；逆映射用割线迭代，
`|G(zeta*) − e| / e < 1e-9`。引擎侧只把 `zeta` 换成 `zeta*`，**接触力核、时间积分、
质量/刚度约定一个字都没动**（`src/tensordem/dem3d.py` 仅新增一个分支 + 一处校验），
因此校准不可能「拟合」出好结果——一致性来自 8.2 的相似性归约本身。

### 8.5 注意点与适用边界

1. **只对 Hertz 分支有意义**：线性罚函数分支的阻尼是常量 `2 zeta sqrt(k m_eff)`，线性映射在该分支
   本来就是精确的；故 `restitution_calibrated` 与 `contact_model="linear"` 同时使用会被**显式报错**
   （而不是静默退化成默认映射）。
2. **单边截断已建模**：`max(·,0)` 不可省。它说明「线性理论 + 单边接触」本身就会有 ~0.8% 的偏差，
   任何用解析 `zeta(e)` 公式直接下结论的场合都该先确认符号约定。
3. **无拉力假设**：引擎接触不能受拉。真实冰-冰接触若有黏结/粘连，需另一条本构（`bond` 分支），
   校准结论不外推到有黏结拓扑的算例。
4. **适用 ζ 范围**：本单实测覆盖 e∈[0.5,0.8]×v∈[0.25,1.0] m/s；曲线 `G` 本身在 `zeta∈(0,0.6)`
   单调（`e≈0.29` 以上）都可反解，`e→0` 一侧为过阻尼不出反跳，属物理而非数值限制。
5. **完整测试与负载**：本机（99）当时 load≈300，故基准跑在后台/集群；`wall_time_s` 字段为实测墙钟，
   受系统负载影响，不作为性能结论。
